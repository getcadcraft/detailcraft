# DetailCraft: browser edition

DetailCraft as plain files: put the folder on any web server and open it in your browser. No account, no install, nothing to build. Your files stay on your computer.

- **Get it:** `detailcraft-browser-edition-v0.7.0.zip` from [Releases](https://github.com/getcadcraft/detailcraft/releases) (checksum beside it). It unzips to a folder with an INSTALL.md that covers servers and updating.
- **Build it from a clone:** `node devshell/edition.mjs` ([BUILDING.md](../BUILDING.md#the-browser-edition)).
- **Use it now:** https://getcadcraft.com/use/detailcraft

On the desktop, DetailCraft runs inside [CadCraft Studio](https://github.com/getcadcraft/studio).
