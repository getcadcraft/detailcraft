DetailCraft มีไฟล์ของตัวเองหนึ่งไฟล์ คือโมเดล และการส่งออกห้าแบบ ทุกการบันทึกและทุกการส่งออกเป็นการดาวน์โหลด ไม่มีการอัปโหลดอะไรและไม่มีอะไรถูกเก็บบนเซิร์ฟเวอร์

## ไฟล์โมเดล

โมเดล DetailCraft บันทึกเป็น `<name>.detailcraft.json` โดย `<name>` คือชื่อโมเดลในพาเนล {{ui:โมเดล}} เก็บกริด ระดับ ชิ้นส่วน (พร้อมรูและคอป) การเชื่อมต่อและการตั้งค่าของมัน ฐานราก และหน้าตัดที่กำหนดเองของคุณ

ชิ้นส่วน เครื่องหมาย สลักเกลียว รอยเชื่อม และเหล็กเส้นไม่ได้ถูกเก็บ: DetailCraft คำนวณใหม่จากโมเดลทุกครั้งที่เปิด นั่นคือเหตุผลที่ไฟล์โมเดลมีขนาดเล็ก

### บันทึก

1. พิมพ์ชื่อในช่อง {{ui:ชื่อ}} ที่ด้านบนของพาเนล {{ui:โมเดล}}
2. เลือก {{ui:บันทึก}} ในกลุ่ม {{ui:ไฟล์}} หรือกด {{key:Mod+S}}
3. เบราว์เซอร์ดาวน์โหลด `<name>.detailcraft.json` แถบสถานะบอกว่า "บันทึก … แล้ว (ดาวน์โหลดแล้ว)" และจุดที่ต้นชื่อแท็บเบราว์เซอร์หายไป

การบันทึกแต่ละครั้งเป็นการดาวน์โหลดใหม่ เบราว์เซอร์ไม่เขียนทับไฟล์ที่คุณเปิด ตามการตั้งค่า มันเติมตัวเลขในชื่อ เช่น `Frame (1).detailcraft.json` หรือถามว่าจะบันทึกที่ไหน เก็บเวอร์ชันของคุณเองโดยเปลี่ยนชื่อไฟล์ที่ดาวน์โหลด

:::chromium
Chrome และ Edge บันทึกลงโฟลเดอร์ Downloads เว้นแต่เปิด **Ask where to save each file before downloading** ในการตั้งค่าดาวน์โหลดของเบราว์เซอร์ เปิดหากคุณต้องการเลือกโฟลเดอร์และชื่อไฟล์ทุกครั้ง
:::

:::firefox
Firefox บันทึกลงโฟลเดอร์ Downloads หรือถามทุกครั้งหากเปิด **Always ask you where to save files** ในการตั้งค่า
:::

:::safari
Safari บันทึกลงโฟลเดอร์ Downloads หากต้องการเปลี่ยนโฟลเดอร์ ให้เปิด **Safari, Settings, General, File download location**
:::

### เปิด

1. เลือก {{ui:เปิด}} ในกลุ่ม {{ui:ไฟล์}} หรือกด {{key:Mod+O}}
2. เลือกไฟล์ `.detailcraft.json`

หรือลากไฟล์จาก {{pick:mac=Finder|windows=File Explorer|linux=ตัวจัดการไฟล์ของคุณ}} ไปวางบนมุมมอง มุมมองบอกว่า "วางโมเดล DetailCraft หรือไฟล์ IFC ที่นี่เพื่อเปิด" ขณะที่คุณลาก

หากโมเดลที่เปิดอยู่มีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก DetailCraft ถามก่อน: {{ui:ยกเลิก}}, {{ui:ทิ้งการเปลี่ยนแปลง}} หรือ {{ui:บันทึกก่อน}}

DetailCraft ตรวจทุกช่องของไฟล์ก่อนใช้ สิ่งใดที่ใช้ไม่ได้จะถูกละไว้และแถบสถานะบอกว่าอะไร เช่น "ชิ้นส่วน 2 ชิ้นไม่ถูกต้องและไม่รวม" โมเดลที่บันทึกโดย DetailCraft รุ่นใหม่กว่าถูกปฏิเสธพร้อมข้อความแทนที่จะเปิดแบบถูกครึ่งเดียว

### สิ่งที่เปิดได้

ไฟล์โมเดลของมันเอง (`.json` ไม่เกิน 50 MB) และไฟล์ IFC (`.ifc` IFC2X3 หรือ IFC4 ไม่เกิน 200 MB) ไฟล์ IFC ที่เปิดหรือนำเข้าด้วย {{ui:นำเข้า IFC}} กลายเป็นโมเดลใหม่ของคาน เสา ชิ้นส่วน แผ่น กริด และระดับ พร้อมรูและคอปที่ตัดอยู่ในนั้น และสลักเกลียวของมันเป็นสลักเกลียวหลวม รายงานแสดงสิ่งที่ถูกละไว้ ดู [ส่งออก IFC](topic:ifc-export#import) ยังไม่เปิด DWG, DXF หรือโมเดลของโปรแกรมทำรายละเอียดอื่น การลองแสดง "DetailCraft opens its own models (.detailcraft.json) and IFC files (.ifc)."

## งานที่สูญหาย ไฟล์ล่าสุด แอปเดสก์ท็อป

- ขณะที่โมเดลมีการเปลี่ยนแปลงที่คุณยังไม่ได้บันทึก DetailCraft เก็บสำเนาในเบราว์เซอร์นี้ หากแท็บหรือเบราว์เซอร์หยุดก่อนที่คุณบันทึก ครั้งต่อไปที่คุณเปิด DetailCraft มันถาม **กู้คืนงานของคุณไหม**: กู้คืนสำเนาหรือปล่อยไป ดู [กู้คืนงานของคุณ](common:recover)
- โมเดลที่คุณเปิดเมื่อเร็ว ๆ นี้แสดงรายการบนหน้าเริ่มต้นเมื่อเบราว์เซอร์ยอมให้ DetailCraft เปิดอีกครั้ง คลิกอันหนึ่งเพื่อเปิดใหม่
- ในแอปเดสก์ท็อป {{ui:บันทึก}} เขียนโมเดลกลับลงไฟล์ที่คุณเปิด (ในเบราว์เซอร์ดาวน์โหลดสำเนา) และการดับเบิลคลิกโมเดล DetailCraft หรือไฟล์ IFC เปิดใน DetailCraft

## การส่งออก

ทุกการส่งออกใช้ชื่อโมเดล เลือกในกลุ่ม {{ui:ผลลัพธ์}}

| ปุ่ม | ไฟล์ | มีอะไรอยู่ข้างใน |
|---|---|---|
| {{ui:IFC}} | `<name>.ifc` | IFC4: ชั้น กริด ทุกชิ้นส่วนเหล็กเป็นการเอ็กซ์ทรูดหน้าตัดพร้อมรูและคอป แอสเซมบลี สลักเกลียวและสลักเกลียวฝัง ฐานราก และเหล็กเส้นทุกเส้น ดู [ส่งออก IFC](topic:ifc-export) |
| {{ui:ไฟล์ NC}} | `<name> NC.zip` | ไฟล์ DSTV `.nc1` หนึ่งไฟล์ต่อเครื่องหมายชิ้นส่วน ดู [ส่งไฟล์ NC ไปโรงงาน](topic:nc-export) |
| {{ui:BOM}} | `<name> BOM.csv` | สามตารางในไฟล์เดียว: ชิ้นส่วน แอสเซมบลี และสลักเกลียวกับสลักเกลียวฝัง ดู [เครื่องหมายและรายการวัสดุ](topic:marks-and-bom) |
| {{ui:การดัด}} | `<name> bending schedule.csv` | ทุกเครื่องหมายเหล็กเส้นในฐานราก ดู [ฐานรากและเหล็กเส้น](topic:footings-and-rebar) |
| {{ui:แบบขยาย}} | `<name> <mark>.pdf` | หนึ่งแผ่น (A3 เว้นแต่คุณเลือกขนาดอื่น) สำหรับชิ้นส่วนที่เลือก (เหล็กรูปตัว I และแผ่น) ดู [ทำแบบขยาย](topic:shop-drawings) |
| {{ui:แบบ}} | `<name> drawings.pdf`, `<name> <sheet>.pdf`; `<name> <sheet>.dwg` หรือ `.dxf` หลายไฟล์ใน `<name> drawings DWG.zip` (หรือ `DXF.zip`) | ผัง รูปด้าน และแบบแอสเซมบลีบนขนาดแผ่นที่คุณเลือก DWG และ DXF ในขนาดเต็ม 1 หน่วย = 1 mm บนกระดาษ ดู [แบบแปลนทั่วไปและแบบแอสเซมบลี](topic:drawings) |

### หมายเหตุเกี่ยวกับไฟล์ CSV

- ขึ้นต้นด้วย byte-order mark เพื่อให้โปรแกรมสเปรดชีตอ่านอักขระที่มีเครื่องหมายได้ถูกต้อง
- เซลล์ที่ขึ้นต้นด้วย `=`, `+`, `-` หรือ `@` (และไม่ใช่ตัวเลขธรรมดา) ได้เครื่องหมายอะพอสทรอฟีนำหน้า เพื่อไม่ให้สเปรดชีตรันมันเป็นสูตร
- ความยาวเป็นมิลลิเมตรและน้ำหนักเป็นกิโลกรัม

### หมายเหตุเกี่ยวกับ PDF

ข้อความใน PDF ใช้ฟอนต์ Helvetica มาตรฐาน อักขระที่มันไม่มี (นอกชุดยุโรปตะวันตก) พิมพ์เป็น "?" และแถบสถานะบอกจำนวน

## หน่วย

DetailCraft ทำงานเป็นมิลลิเมตรตลอด: กริด ระดับ พิกัด หน้าตัด รู และทุกการส่งออก ชื่อหน้าตัดเก็บรูปแบบที่เผยแพร่ (W12x50 เป็นชื่อเรียกของสหรัฐอเมริกา แม้ว่าขนาดแสดงเป็น mm) ยังไม่มีการป้อนเป็นหน่วยอิมพีเรียล

## ออนไลน์และออฟไลน์

การเปิด การบันทึก และการส่งออกทั้งหมดเกิดขึ้นในเบราว์เซอร์ของคุณ จึงทำงานเหมือนกันทั้งมีและไม่มีการเชื่อมต่อ เมื่อ DetailCraft โหลดแล้ว

หากต้องการใช้ DetailCraft โดยไม่มีการเชื่อมต่อภายหลัง ให้เลือก {{ui:บันทึกสำหรับออฟไลน์}} ในแถบแอปขณะออนไลน์ ปุ่มนับขึ้น ("Saving 3 of 20") แล้วเขียนว่า {{ui:พร้อมใช้ออฟไลน์}} สำเนาที่บันทึกรวมไลบรารีกราฟิก 3D (ประมาณ 2.6 MB) และวิธีใช้นี้ เมื่อบันทึกแล้ว มุมมอง 3D ทุกการส่งออก และวิธีใช้ทำงานออฟไลน์ได้ทั้งหมด รายละเอียด และสิ่งที่ยังต้องใช้การเชื่อมต่อ: [การทำงานแบบออฟไลน์](common:offline)

:::offline
คุณออฟไลน์อยู่ หากแถบแอปแสดง {{ui:พร้อมใช้ออฟไลน์}} การเปิด การบันทึก และการส่งออกทำงานตามปกติ หากไม่ ให้เปิดแท็บนี้ไว้ อย่ารีโหลดจนกว่าจะกลับมาออนไลน์ และบันทึกโมเดลของคุณตอนนี้
:::

ยังไม่มีการบันทึกบนคลาวด์ และยังไม่มีบิลด์เดสก์ท็อป สำรองไฟล์ `.detailcraft.json` ของคุณเหมือนที่คุณสำรองไฟล์งานอื่น ๆ เพิ่มเติมใน [ไฟล์ของคุณไปที่ไหน](common:your-files)

## งานที่ยังไม่ได้บันทึก

DetailCraft เก็บโมเดลไว้ในแท็บที่เปิดอยู่เท่านั้น หากคุณปิดหรือรีโหลดแท็บโดยมีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก เบราว์เซอร์ถามว่าจะออกจากหน้าหรือไม่ ถ้อยคำเป็นของเบราว์เซอร์เอง บันทึกด้วย {{key:Mod+S}} บ่อย ๆ
