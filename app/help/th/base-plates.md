การต่อแผ่นฐานจะวางแผ่นไว้ใต้เสา ตัดเสาให้สั้นลงเท่ากับความหนาของแผ่น เชื่อมทั้งสองเข้าด้วยกัน และเพิ่มสลักยึดสี่เส้นผ่านรูในแผ่น

:::warning
ขนาดเป็นค่าเริ่มต้น ไม่ใช่การออกแบบ DetailCraft ไม่ตรวจการรับแรงแบก (bearing) ความแข็งแรงของสลักยึด หรือระยะฝังลึก
:::

## เพิ่มแผ่นฐาน

1. เลือก {{ui:เลือก}} ({{key:V}}) แล้วคลิกเสา เสาต้องตั้งตรง
2. เลือก {{ui:แผ่นฐาน}} ในกลุ่ม {{ui:เชื่อมต่อ}} หรือ {{ui:เพิ่มแผ่นฐาน}} ในพาเนล {{ui:คุณสมบัติ}}
3. แถบสถานะแสดงว่า "เพิ่มแผ่นฐานพร้อมสลักยึดสี่เส้นแล้ว" และเลือกการเชื่อมต่อใหม่ไว้

เสาหนึ่งต้นมีแผ่นฐานได้หนึ่งแผ่น ถ้ามีอยู่แล้ว แถบสถานะจะแสดงว่า "เสาต้นนี้มีแผ่นฐานอยู่แล้ว"

## เปลี่ยนค่า

เลือกแผ่นฐาน (คลิกที่แผ่นหรือสลักยึด) ใต้ {{ui:แผ่น สลักเกลียว และแนวเชื่อม (mm)}}:

| การตั้งค่า | ค่าเริ่มต้น | หน้าที่ |
|---|---|---|
| ความหนาของแผ่น | 25 | เสาจะสั้นลงเท่านี้ |
| ความยาวแผ่น | 450 | ตามความลึกของเสา |
| ความกว้างแผ่น | 400 | ตามความกว้างของเสา |
| ขนาดเส้นผ่านศูนย์กลางสลักยึด | 20 | ขนาดของสลักยึด |
| ขนาดเส้นผ่านศูนย์กลางรู | 33 | รูในแผ่น |
| เกรดสลักยึด | F1554 Gr 36 | เกรดของสลักยึด เป็นข้อความ |
| ระยะห่างสลักยึด (ตามความลึก) | 350 | ระหว่างจุดศูนย์กลางของสลักยึด ตามความยาวแผ่น |
| ระยะห่างสลักยึด (ตามความกว้าง) | 300 | ระหว่างจุดศูนย์กลางของสลักยึด ตามความกว้าง |
| สลักยึดยื่นเหนือแผ่น | 100 | จากด้านบนของแผ่นถึงปลายบนของสลักยึด |
| สลักยึดฝังใต้แผ่น | 450 | จากด้านล่างของแผ่นลงไปในคอนกรีต |
| ขนาดแนวเชื่อมฟิลเลต | 8 | รอบฐานเสาทั้งหมด |
| วัสดุของแผ่น | A36 | ข้อความ |
| ช่องว่างกราวต์ | 0 | ช่องว่างระหว่างด้านบนของคอนกรีตกับด้านล่างของแผ่น |
| ตัวเสริมแข็ง (stiffener) | ไม่มี | เลือก ไม่มี, 2 (ตรงแนวเอวเสา) หรือ 4 (และตั้งฉากกับเอวเสาด้วย) ดูด้านล่าง |
| ความหนา, ความสูงของตัวเสริมแข็ง | 12, 150 | |
| ความลึกของตัวล็อกเฉือน (shear lug) | 0 | ตัวล็อกยื่นลงใต้แผ่นเท่าไร; 0 = ไม่มีตัวล็อก |
| ความหนา, ความกว้างของตัวล็อกเฉือน | 25, 150 | |
| แหวนรองแผ่น | ไม่มี | ใส่ทุกสลักยึด หรือไม่ใส่เลย |
| ขนาดแหวนรอง, ความหนา | 0, 0 | 0 = ขนาดขั้นต่ำจาก AISC Design Guide 1 สำหรับสลักยึดนั้น |

ความยาวสลักยึด = ระยะฝัง + ช่องว่างกราวต์ + ความหนาของแผ่น + ระยะยื่น ด้วยค่าเริ่มต้นจะได้ 575 mm

## รายละเอียดฐาน: กราวต์ ตัวเสริมแข็ง ตัวล็อกเฉือน แหวนรอง

ทั้งสี่รายการปิดอยู่ในแผ่นฐานใหม่ และในแผ่นฐานจากโมเดลที่สร้างก่อน DetailCraft 0.4

- **ช่องว่างกราวต์** แผ่นจะอยู่สูงจากด้านบนของคอนกรีตเท่ากับค่านี้ และสลักยึดจะยาวขึ้นเท่ากัน AISC Design Guide 1 (2.10) แนะนำ 1 in. บนพื้นสำเร็จ และ 1½ ถึง 2 in. บนฐานรากหรือเสาตอม่อ ควรเพิ่มมากขึ้นสำหรับแผ่นขนาดใหญ่ และแผ่นที่มีตัวล็อกเฉือน
- **ตัวเสริมแข็ง** แผ่นตั้งที่เชื่อมกับเสาและแผ่นฐาน จากผิวเสาออกไปจนถึงขอบแผ่น เป็นรูปสี่เหลี่ยมผืนผ้า (ยังไม่มีการตัดมุมหรือเรียวเข้า) **2** ตั้งตรงแนวเอวเสา อยู่ด้านนอกของแต่ละปีก **4** เพิ่มอีกสองแผ่นตั้งฉากกับเอวเสา อยู่ระหว่างปีก ยืดออกไปถึงด้านข้างของแผ่น สำหรับเสาท่อ จะวางอยู่กลางแต่ละด้าน แต่ละแผ่นเชื่อมกับเสาและแผ่นฐานทั้งสองด้าน
- **ตัวล็อกเฉือน** แผ่นที่เชื่อมรอบด้านใต้แผ่นฐาน ตรงแนวความลึกของเสา อยู่กึ่งกลาง DetailCraft จะเตือนถ้าลึกไม่มากกว่าช่องว่างกราวต์ ตัวล็อกนี้ไม่เจาะช่องในฐานราก [การตรวจการชน](topic:clash-check) จึงไม่รวมตัวล็อกและฐานรากเข้าไปด้วยเหตุผลนี้
- **แหวนรองแผ่น** แหวนรองสี่เหลี่ยมหนึ่งอันบนสลักยึดแต่ละเส้น วางบนแผ่นฐาน และอยู่ในชุดประกอบของเสาเป็นชิ้นหลวม (ส่งมาพร้อมเสา ไม่ได้เชื่อม: Design Guide 1, 2.6) เมื่อขนาดและความหนาเป็น 0 DetailCraft จะใช้แหวนรองขั้นต่ำจาก AISC Design Guide 1 ฉบับที่ 2 ตาราง 2.3 สำหรับสลักยึดนั้น สลักยึดแบบเมตริกจะใช้ขนาดนิ้วที่สูงกว่าถัดไป (สลักยึด M20 ได้แถว 7/8 in. คือ 2½ in. × 5/16 in.) พาเนลคุณสมบัติจะแสดงขนาดที่ใช้ รูของแหวนรองคือเส้นผ่านศูนย์กลางของสลักยึด + 1/16 in. ซึ่งเป็นตัวเลือกของ DetailCraft เพราะตารางไม่ได้กำหนดไว้ DetailCraft จะเตือนเมื่อสลักยึดอาจยื่นไม่พอสำหรับแหวนรองและน็อต (ระยะยื่นน้อยกว่าความหนาของแหวนรอง + เส้นผ่านศูนย์กลางของสลักยึด)

ตาราง 2.3 ของ Design Guide 1 ยังแนะนำขนาดรูสลักยึดในแผ่น: 1-5/16 in. สำหรับสลักยึด ¾ in., 1-9/16 in. สำหรับ ⅞ in., 1-13/16 in. สำหรับ 1 in. DetailCraft ไม่เปลี่ยนขนาดรูที่คุณกำหนด

แถบเตือนจะปรากฏเมื่อรูสลักยึดอยู่ใกล้ขอบแผ่นน้อยกว่า 1.2 × เส้นผ่านศูนย์กลางของรู เมื่อสลักยึดอยู่ภายในเส้นรอบเสา หรือเมื่อแผ่นเล็กกว่าเสา

## คัดลอกไปยังเสาที่คล้ายกัน

1. เลือกแผ่นฐาน
2. เลือก {{ui:นำไปใช้กับที่คล้ายกัน (n)}} หรือ {{ui:คล้ายกัน}} ในเมนู {{ui:เพิ่มเติม}} ของกลุ่ม {{ui:เชื่อมต่อ}}
3. เสาตั้งตรงทุกต้นที่มีหน้าตัดเดียวกัน ไม่มีแผ่นฐาน และไม่ได้ตั้งอยู่บนเสาอีกต้น จะได้รับสำเนาหนึ่งชุด

## แผ่นฐานและฐานราก

แผ่นฐานไม่จำเป็นต้องมีฐานราก และฐานรากไม่รู้จักแผ่นฐานที่อยู่เหนือมัน สลักยึดไม่ได้ผูกกับเหล็กเสริมของฐานราก วางฐานรากด้วย {{ui:ฐานราก}} ดู [วางฐานรากพร้อมเหล็กเสริม](topic:footings-and-rebar)
