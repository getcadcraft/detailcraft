## สิ่งที่คุณจะได้เรียนรู้

วิธีให้ผู้ช่วย AI (หรือสคริปต์ที่คุณเขียน) ทำงานกับ DetailCraft และวิธีตัดสินใจว่ามันแก้ไขอะไรได้บ้าง

DetailCraft **ไม่มี AI ของตัวเอง** และไม่ส่งข้อมูลไปที่ใด คุณนำผู้ช่วยมาเอง คือโปรแกรมใดก็ได้ที่ใช้ Model Context Protocol (MCP) DetailCraft เพียงให้เครื่องมือแก่มัน และคุณเลือกเองว่าจะให้ใช้อะไรบ้าง

## เปิดใช้งาน

1. เปิด {{ui:การตั้งค่า}} (ไอคอนฟันเฟืองบนแถบแอป หรือ {{key:Mod+,}}) แล้วไปที่แท็บ {{ui:DetailCraft}}
2. ภายใต้ {{ui:ผู้ช่วย}} ติ๊ก **ให้ผู้ช่วย AI และสคริปต์ใช้ DetailCraft** ค่าเริ่มต้นคือปิดไว้จนกว่าคุณจะเปิด
3. เลือกสิ่งที่มันทำได้: **อ่าน** ถูกติ๊กไว้เป็นค่าเริ่มต้น ติ๊ก **แก้ไข** **บันทึก** หรือ **ส่งออก** เฉพาะเมื่อจำเป็นต้องใช้

เครื่องมือที่อยู่นอกสิทธิ์ที่คุณติ๊กจะไม่ถูกเสนอให้ผู้ช่วย และหากมันขอใช้เครื่องมือนั้นอยู่ดี DetailCraft จะปฏิเสธและบันทึกไว้ในบันทึกกิจกรรม การปิดสวิตช์จะยกเลิกการเชื่อมต่อทั้งหมดในครั้งเดียว

## เชื่อมต่อผู้ช่วยของคุณ

ผู้ช่วยเชื่อมต่อผ่าน **CadCraft Studio** บนคอมพิวเตอร์ของคุณ Studio รันเซิร์ฟเวอร์ขนาดเล็กที่มีเพียงคอมพิวเตอร์เครื่องนี้เข้าถึงได้ และป้องกันด้วยโทเคนที่สร้างใหม่ทุกครั้งที่เริ่มทำงาน ใน Studio ให้เลือก {{ui:เชื่อมต่อผู้ช่วย}} แล้วคัดลอกที่อยู่และโทเคนไปใส่ในผู้ช่วยของคุณ (Studio แสดงการตั้งค่าที่ต้องวางให้) อย่าแชร์โทเคนให้ใคร

:::note
แท็บเบราว์เซอร์ไม่สามารถเปิดการเชื่อมต่อให้ผู้ช่วยได้ ในแอปบนเบราว์เซอร์ สวิตช์จะไม่มีผลจนกว่าคุณจะใช้ CadCraft Studio บนคอมพิวเตอร์ของคุณ
:::

## คุณยังควบคุมอยู่

- **ทุกการเปลี่ยนแปลงคือหนึ่งขั้นย้อนกลับ** มีป้ายกำกับว่าเป็นของผู้ช่วย (เช่น "Assistant: add beam" หรือ "Assistant: add gussets") {{key:Mod+Z}} จะย้อนการเปลี่ยนแปลงล่าสุดของผู้ช่วยทั้งชุด คำสั่ง `undo` ของผู้ช่วยเองจะย้อนเฉพาะขั้นของมันเท่านั้น ไม่ใช่ของคุณ เว้นแต่มันจะขอเป็นพิเศษ
- **มันรอคุณ** ขณะที่คุณกำลังวางสมาชิก ย้ายชิ้นส่วน หรือวาง DetailCraft จะปฏิเสธการเปลี่ยนแปลงของผู้ช่วยและบอกให้ลองใหม่
- **คุณรู้ได้เมื่อมีการเชื่อมต่อ** ปุ่มในแถบแอปจะระบุชื่อผู้ช่วยขณะที่เชื่อมต่อ คลิกเพื่อดูว่ามันทำอะไรได้ หรือเพื่อ **ยกเลิกการเชื่อมต่อ**
- **กิจกรรม** {{ui:การตั้งค่า}} › {{ui:DetailCraft}} › {{ui:ผู้ช่วย}} › {{ui:กิจกรรม}} แสดงทุกการเรียก ว่าเกิดเมื่อไร ใช้เครื่องมือใด และเสร็จหรือถูกปฏิเสธ {{ui:บันทึกบันทึกกิจกรรม}} จะเก็บสำเนาไว้

## ผู้ช่วยขอทำอะไรได้บ้าง

ความยาวทั้งหมดเป็นมิลลิเมตร จุดเป็น `[x, y, z]` โดย z ชี้ขึ้น ตามที่อยู่ในโมเดล

| เครื่องมือ | สิทธิ์ | ทำหน้าที่ |
|---|---|---|
| `app_info`, `model_describe` | อ่าน | โมเดลที่เปิดอยู่: กริด ระดับ เฟส สมาชิกตามชนิดและหน้าตัด การเชื่อมต่อ ฐานราก บันได ชิ้นส่วน น้ำหนักเหล็ก ปัญหา |
| `parts_list` | อ่าน | เครื่องหมายชิ้นส่วนพร้อมหน้าตัด วัสดุ ความยาวที่ตัด จำนวน น้ำหนัก เฟส และเครื่องหมายชุดประกอบ กรองตามชนิด หน้าตัด เครื่องหมาย หรือเฟสได้ |
| `problems_list` | อ่าน | สิ่งที่แท็บ {{ui:ปัญหา}} แสดง แต่ละรายการพร้อมเรื่องที่เกี่ยวข้อง |
| `clash_check` | อ่าน | [การตรวจการชน](topic:clash-check) พร้อมค่าความคลาดเคลื่อนและเฟส |
| `selection_get` | อ่าน | สิ่งที่คุณเลือกอยู่ |
| `selection_set` | แก้ไข | เลือกสมาชิก การเชื่อมต่อ ฐานราก หรือบันได (ตาม id หรือเครื่องหมายชิ้นส่วน) เพื่อแสดงให้คุณเห็น ไม่เปลี่ยนแปลงอะไร |
| `member_add` | แก้ไข | คาน เสา ค้ำยัน หรือแผ่นระหว่างสองจุด |
| `connection_add` | แก้ไข | แผ่นปลาย แท็บรับแรงเฉือน แผ่นฐาน การต่อ หรือแผ่นเสริมมุม ตรงจุดที่สมาชิกที่กำหนดมาบรรจบกัน เหมือนที่ปุ่ม {{ui:เชื่อมต่อ}} ทำ |
| `undo` | แก้ไข | ย้อนขั้นล่าสุดของผู้ช่วย |
| `model_save` | บันทึก | การบันทึกของ DetailCraft เอง |
| `model_export` | ส่งออก | IFC ไฟล์ NC รายการวัสดุ ตารางการดัด ไฟล์ KISS หรือรายการตัด เหมือนที่ปุ่ม {{ui:ผลลัพธ์}} สร้าง |
| `usd_export` | ส่งออก | โมเดลเหล็กเป็น USD (.usda, .usdc หรือ .usdz) เหมือนที่ {{ui:ผลลัพธ์}} › {{ui:USD}} เขียน (ดู [ส่งออกโมเดลเหล็กเป็น USD](topic:usd)) ใน Studio สามารถเขียนไฟล์ลงโฟลเดอร์ที่คุณอนุญาตได้ |

## หากบางอย่างไม่ทำงาน

- **ผู้ช่วยไม่เห็นเครื่องมือของ DetailCraft:** ตรวจว่าสวิตช์เปิดอยู่ในหน้าต่างนี้ และหน้าต่างเปิดอยู่ใน Studio
- **"ต้องมีสิทธิ์แก้ไข"** (หรือบันทึก ส่งออก): ติ๊กสิทธิ์นั้นภายใต้ {{ui:ผู้ช่วย}} แล้วขออีกครั้ง
- **"The person is placing a member":** ทำสิ่งที่คุณทำอยู่ให้เสร็จ (หรือกด {{key:Esc}}) แล้วให้ผู้ช่วยลองอีกครั้ง
- **ข้อผิดพลาด "401" หรือ "token":** โทเคนเปลี่ยนแล้ว (Studio เริ่มใหม่ หรือ {{ui:โทเคนใหม่}}) คัดลอกโทเคนใหม่ไปใส่ในการตั้งค่าของผู้ช่วย
