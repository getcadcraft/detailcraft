นี่คือสิ่งที่เปลี่ยนไปใน DetailCraft 0.9 เทียบกับ 0.8.1 รุ่น 0.9 เพิ่มขนาดเหล็กแบบ UK แบบขยายของชิ้นส่วนทุกชิ้นในครั้งเดียว แท็บ {{ui:Analysis}} ที่ใหญ่ขึ้นสำหรับเฟรม และการมองเห็นตัวชี้เมาส์ของกันและกันเมื่อทำงานร่วมกัน

## ใหม่

### เหล็กแบบ UK และแบบขยาย

- **ขนาดเหล็กแบบ UK** รายการโปรไฟล์มี 976 ขนาดจาก Steel for Life Blue Book: UB, UC, PFC, EA, UEA, CHS, SHS และ RHS โดยหน้าตัดกลวงที่ขึ้นรูปเย็นแยกไว้ต่างหาก (ชื่อขึ้นต้นด้วย CF) ชื่อเขียนโดยขึ้นต้นด้วยตระกูลก่อน เช่น UB305x165x40 หรือ SHS100x100x5.0 และการพิมพ์ตามที่แบบเขียนก็ใช้ได้เช่นกัน: 305x165x40 UB, L100x100x10, SHS100x5 ดู [แคตตาล็อกโปรไฟล์](topic:profile-catalog)
- **มุมที่ขาไม่เท่ากัน** มุม UEA เก็บทั้งสองขาไว้ผ่าน IFC ทั้งขาเข้าและขาออก และผ่านไฟล์ NC และการสะท้อนจะกลับชิ้นส่วนจากหัวจรดท้าย
- **แบบขยายทุกชิ้นพร้อมกัน** เลือก {{ui:Shop drawing}} ในกลุ่ม {{ui:Output}} โดยไม่ได้เลือกอะไร หน้าต่างจะแสดงเครื่องหมายชิ้นส่วนทั้งหมด ดูตัวอย่างใดก็ได้ และ{{ui:Download all}} จะบันทึก PDF ไฟล์เดียวที่มีหนึ่งหน้าต่อเครื่องหมาย แต่ละหน้ามีหัวเรื่องว่า "แผ่น 3 จาก 42" {{ui:Download this sheet}} บันทึกเฉพาะแผ่นที่คุณกำลังดูอยู่ ตอนนี้ช่อง ฉาก และหน้าตัดกลวงก็มีแผ่นด้วย ดู [สร้างแบบขยาย](topic:shop-drawings)
- **โปรไฟล์ของฉัน** โปรไฟล์ที่กำหนดเองสามารถเก็บไว้สำหรับทุกโมเดลใหม่ ในแบบฟอร์มโปรไฟล์ที่กำหนดเอง ให้ติ๊ก {{ui:Keep in My profiles}} ไว้ รายการ {{ui:My profiles}} ที่อยู่ด้านล่างมี {{ui:Keep}} {{ui:Use here}} และ {{ui:Remove}} รายการนี้เก็บไว้ในเบราว์เซอร์นี้ (ได้ถึง 200 รายการ) ไม่ใช่ในบัญชีของคุณ ดู [แผ่นและโปรไฟล์](topic:plates-and-profiles)

### การวิเคราะห์

- **ลำดับที่สอง (P-Delta)** ติ๊ก {{ui:Second order (P-Delta)}} ถัดจาก Run ในแท็บ {{ui:Analysis}} แล้วแรงตามแนวแกนจะกระทำบนเฟรมที่โก่งตัว แผ่นและพื้นแข็งยังคงเป็นลำดับที่หนึ่ง พร้อมคำเตือน ดู [แรง ปฏิกิริยา และการโก่งตัว](topic:frame-analysis)
- **ความถี่ธรรมชาติ** บล็อก {{ui:Finite elements: natural frequencies}} ใต้ผลลัพธ์จะหาโหมดต่ำสุดของโมเดลเดียวกัน พร้อมคาบและมวลโมดอลที่มีผล และแสดงโหมดบนโมเดล ดู [แรง ปฏิกิริยา และการโก่งตัว](topic:frame-analysis)
- **แรงลมและช่วงที่ตั้งแผ่นดินไหว** มีสามบล็อกใหม่ในแท็บ {{ui:Analysis}}: {{ui:Wind loads (ASCE 7 directional procedure)}} {{ui:Seismic site and system (ASCE 7)}} และ {{ui:ASCE 7 load combinations}} ดู [แรงลม ช่วงที่ตั้งแผ่นดินไหว และชุดแรงรวม ASCE 7](topic:wind-seismic-combinations)

- **ติดตามผู้ใช้** เปิด {{ui:People}} ในเซสชัน แล้วเลือก {{ui:Follow}} ที่ชื่อหนึ่ง มุมมองของคุณจะเลื่อนตามเขา ผู้จัดเซสชันเลือก {{ui:Ask everyone to follow me}} ได้ ดู [ติดตามผู้ใช้ในเซสชัน Live](topic:follow-in-live)

## แก้ไขแล้ว

- โปรไฟล์ที่กำหนดเองหายไปเมื่อคุณเริ่มโมเดลใหม่
- ช่อง ฉาก และหน้าตัดกลวงไม่อยู่ในชุดแบบขยาย

## ข้อจำกัดที่ควรรู้

- บล็อกแรงลม ช่วงที่ตั้งแผ่นดินไหว และไฟไนต์เอลิเมนต์เป็นเครื่องช่วยตรวจสอบ วิศวกรของคุณต้องตรวจทานผลลัพธ์ ไม่ใช่การตรวจตามข้อบังคับ การค้นหา USGS ทดสอบกับตัวแทนไม่ใช่กับบริการจริง
- ไฟไนต์เอลิเมนต์และ P-Delta ถูกตรวจกับคำตอบจากการคำนวณมือและคำตอบแบบปิด ไม่ใช่กับอาคารจริง การวิเคราะห์การโก่งยังไม่ได้สร้าง
- ยังไม่มีผู้ผลิตเหล็กในสหราชอาณาจักรลองใช้ขนาดเหล็กแบบ UK และไฟล์ NC สำหรับมุมที่ขาไม่เท่ากันยังไม่เคยทำงานบนเครื่องจริง
- ชุดแบบขยายมีเฉพาะ PDF
- ภาษาอื่นนอกจากภาษาอังกฤษเป็นฉบับร่างจากเครื่อง
- ตัวติดตั้งของ Windows ไม่ได้ลงนามรับรองโค้ด (More info แล้ว Run anyway) ภาพดิสก์ของ macOS ยังไม่ได้ผ่านการรับรองโดย Apple (คลิกขวาแล้ว Open)

การเปลี่ยนแปลงก่อนหน้าอยู่ในบันทึกรุ่น 0.8 และ 0.8.1 ที่ด้านล่างของหน้านี้

## รุ่นก่อนหน้า: 0.8 และ 0.8.1

นี่คือสิ่งที่เปลี่ยนไปใน DetailCraft 0.8 (1 พฤศจิกายน 2026) และ 0.8.1 (2 พฤศจิกายน 2026) เทียบกับ 0.7 รุ่น 0.7 ตรวจสอบเมมเบอร์เหล็ก รุ่น 0.8 วางแผนการยก เสนอจุดต่อ ตรวจฐานราก และเหล็กเส้น และสร้างโครงผนัง พื้น และหลังคาจากไม้และเหล็กบางรีดเย็น

### ใหม่

**การติดตั้ง**

- **แผนการติดตั้งและภาพยนตร์** ในแท็บ {{ui:Erection}} อธิบายเครน (ตั้งอยู่ที่ไหน ตะขอสูงสุด และอุปกรณ์ยึดที่ไม่อยู่ในตาราง) แล้วพิมพ์แถวของตารางน้ำหนักยกของเครน DetailCraft ยกโมเดลทีละหนึ่งชุดประกอบ ตามลำดับเฟสและทีละชั้น และตรวจแต่ละการยกกับตารางที่รัศมีนั้นและขอบเขตความปลอดภัยที่คุณตั้งไว้ {{ui:Save movie}} เขียนไฟล์ HTML เดียวที่เล่นแบบออฟไลน์ได้ในเบราว์เซอร์ใดก็ได้ แม้แต่บนโทรศัพท์ การยกที่เกินตาราง ผ่านตาราง หรือสูงเกินไป อยู่ใน {{ui:Problems}} นี่คือแผนจากตัวเลขของคุณ ไม่ใช่แผนการยกจริง ดู [แผนการติดตั้งและภาพยนตร์](topic:erection-movie)

**จุดต่อ**

- **ออโตไพลอตจุดต่อ** แท็บ {{ui:Autopilot}} ดูทุกจุดต่อที่ไม่มีการเชื่อมต่อ และเสนอหนึ่งข้อจากรูปร่างของหน้าตัด ได้แก่ แผ่นฐาน แผ่นเฉือน แผ่นปลายสำหรับคานที่คุณทำเครื่องหมายว่าเป็นคานโมเมนต์ จุดต่อแบบทาบ และแผ่นค้ำ ใส่แรงกระจายสม่ำเสมอหรือแรงเฉือนปลายหนึ่งข้าง แล้วจำนวนสลักเกลียวจะตามกำลังออกแบบของสลักเกลียว {{ui:Add them all}} เพิ่มข้อเสนอทั้งหมดเป็นหนึ่งขั้นของการเลิกทำ เป็นค่าเริ่มต้นให้ตรวจทาน ไม่ใช่การออกแบบจุดต่อ
- **การตรวจความสร้างได้** {{ui:Problems}} สำหรับสลักเกลียวที่ประแจเข้าไม่ถึง สลักเกลียวที่อยู่ใกล้กันเกินไปสำหรับลูกบล็อก รอยเชื่อมแบบฟิลเลตที่เกินขนาดจำกัด และหน้าตัดกลวงที่กักน้ำไว้ การเข้าถึงรอยเชื่อมเป็นของใหม่: รอยเชื่อมแบบฟิลเลตรอบทิศที่หัวเชื่อมเข้าไม่ถึงจะถูกแสดงพร้อมชิ้นส่วนที่กีดขวางและสัดส่วนของรอยเชื่อมที่ได้รับผลกระทบ ดู [การตรวจความสร้างได้](topic:constructability)

**ฐานรากและเหล็กเส้น**

- **การตรวจฐานราก** แท็บ {{ui:Foundation}} ตรวจฐานเดี่ยว ฐานรวม และฐานแผ่นบนดินที่คุณอธิบาย: แบริ่ง การเลื่อน และการพลิกคว่ำจากแรงใช้งาน การดัด แรงเฉือน การเจาะทะลุ การพัฒนาความยาว และเหล็กขั้นต่ำจากแรงที่คูณแล้ว (ACI 318-19) เสาที่อยู่ใกล้ขอบหรือมุมจะถูกตรวจด้วยหน้าตัดที่ตัดตามขอบของฐาน การทรุดตัวมาจากโมดูลัสของดิน แผ่นยืดหยุ่นจะถูกแก้บนสปริงจากโมดูลัสของชั้นดินรอง และกลุ่มเสาเข็มกับกำแพงกันดินมีแผงของตัวเอง แรงที่เสาใส่เข้าไปได้ทั้งพิมพ์เองหรือนำมาจาก {{ui:Analysis}} ดู [การตรวจฐานราก](topic:foundation-checks)
- **แผนที่ความแออัดของเหล็กเส้น** แท็บ {{ui:Congestion}} วาดแผนที่ความร้อนของฐานแต่ละฐานเมื่อมองจากด้านบน: ตรงที่เหล็กเส้นเหลือที่ว่างน้อยเกินไปให้คอนกรีตไหลลงไป เทียบกับกฎระยะห้องว่าง และหากคุณใส่ให้ ขนาดมวลรวมที่ใหญ่ที่สุดและหัวเขย่า ดู [แผนที่ความแออัดของเหล็กเส้น](topic:rebar-congestion)

**การวางโครงและการจัดหา**

- **การวางโครงไม้และเหล็กบางรีดเย็น** แท็บ {{ui:Framing}} วางโครงแผงผนัง พื้น และหลังคาพร้อมชิ้นส่วนทุกชิ้น รายการตัด สต็อกที่ต้องซื้อ และแบบขยายตามสัดส่วน {{ui:Place as members}} วางชิ้นส่วนลงในโมเดล และ{{ui:PDF sheets}} บันทึกหนึ่งแผ่นต่อแผงหนึ่งแผง ขนาด ระยะ และหัวเสาเป็นของคุณ DetailCraft ไม่ได้ตรวจว่าจะรับน้ำหนักได้หรือไม่ ดู [แผงโครงไม้และเหล็กบางรีดเย็น](topic:framing-panels)
- **สต็อกของผู้จัดหาและระยะเวลารอ** แท็บ {{ui:Supply}} อ่านรายการสต็อกของผู้จัดหา (CSV) และแสดงสำหรับหน้าตัดแต่ละชนิดที่รายการตัดต้องการซื้อว่ามีพอในสต็อกหรือไม่ และต้องรอนานเท่าไร หน้าตัดที่ขาดและที่มาช้าอยู่ใน {{ui:Problems}} ไม่มีการสั่งซื้อใด ๆ ดู [สต็อกของผู้จัดหาและระยะเวลารอ](topic:supplier-stock)

**การวิเคราะห์และการออกแบบ**

- **สิ่งที่พังก่อน?** ในแท็บ {{ui:Analysis}} ปุ่มจะหาชุดแรงรวมเพื่อกำลังที่ควบคุม เมมเบอร์ที่อ่อนที่สุด แรงที่เพิ่มขึ้นได้อีกเท่าไรก่อนเมมเบอร์แรกถึงขีดจำกัด และแผ่นปลายหรือแผ่นเฉือนที่อ่อนที่สุดเมื่อทราบกำลังเฉือนของสลักเกลียว ต้องมีชุดแรงรวมและข้อบังคับการออกแบบก่อน แรงแบริ่ง การเฉือนบล็อก รอยเชื่อม และการงัดยังไม่ได้ตรวจ ผู้ช่วย AI ที่เชื่อมต่ออยู่ของคุณถามได้เช่นกัน
- **Live** ติ๊ก {{ui:Live: solve again after each edit}} แล้วเฟรมจะถูกคำนวณใหม่หลังการแก้ไขทุกครั้ง
- **คอนกรีต และอื่น ๆ** เสาเพรียวในเฟรมที่ไม่มีการโยกถูกออกแบบสำหรับโมเมนต์ที่ขยายแล้ว (ACI 318-19 6.6.4.5) คาบแผ่นดินไหวรับได้จากการวิเคราะห์ด้วยวิธี Rayleigh พื้นที่ทำจากแผ่นจะได้เหล็กที่แต่ละชั้นต้องการจากโมเมนต์ของมัน และแรงเฉือนทางเดียว ดู [ตรวจชิ้นส่วนคอนกรีตและสร้างแรงแผ่นดินไหว](topic:concrete-and-seismic)
- **สำหรับวิศวกรตรวจ** ผลลัพธ์ของฐานราก คอนกรีต และสิ่งที่พังก่อนเป็นเครื่องช่วย แรงลมยังไม่ได้สร้าง

**ในทุกแอป**

- **ภาษา** คู่มือช่วยเหลือมี 54 ภาษา ภาษาอื่นนอกจากภาษาอังกฤษเป็นฉบับร่างจากเครื่องจนกว่าผู้พูดภาษานั้นจะตรวจอ่าน มีสิบภาษาใหม่ (ลิทัวเนีย ลัตเวีย บอสเนีย มราฐี เตลูกู แอลเบเนีย แอฟริกานส์ ฟิลิปปินส์ สวาฮีลี และอุซเบก)
- **แถวของแถบเครื่องมือ** {{ui:Settings}} › {{ui:General}} › {{ui:Toolbar rows}} เลือกตัดบรรทัด 2 แถว หรือ 1 แถว แถบที่พอดีอยู่แล้วจะคงเดิม ส่วนที่เหลือเลื่อนไปด้านข้าง
- **ตารางคุณสมบัติ** ช่องของฐานใช้ตารางร่วม มีหมวดที่ยุบได้และความหนาแน่นแบบกะทัดรัด การคำนวณที่พิมพ์เป็นตัวเลขอย่าง 2*450 ยังใช้ได้
- **อุปกรณ์ป้อนข้อมูล** แทรกพัด ปากกา เมาส์ 3 มิติ จอยควบคุม และ MIDI สามารถควบคุมแอปได้ ดู [นำทางใน 3D](topic:navigate-3d)
- **พาเนลปัญหา** คำเตือนของการตรวจใหม่ข้างต้นปรากฏในพาเนล {{ui:Problems}} เดียวกันกับเดิม
- **เชื่อมต่อ AI ของคุณ** ผู้ช่วยของคุณเอง เชื่อมผ่าน CadCraft Studio ใช้ได้กับทั้งแปดแอป และเห็นเฉพาะสิ่งที่คุณอนุญาต การเชื่อมต่อด้วยคลิกเดียว ตัวเชื่อมแบบโฮสต์ และคีย์ API ของคุณเองใน Studio ยังมาไม่ถึง ดู [ใช้ DetailCraft กับผู้ช่วย AI](topic:use-with-ai-assistants)

### แก้ไขแล้วในรุ่น 0.8.1

- **ภาษาใน Studio** Studio และรุ่นแพ็กเกจสามารถเปลี่ยนภาษาขณะทำงานได้ ก่อนหน้านี้เป็นภาษาอังกฤษเท่านั้น ยังไม่ได้ทดสอบบนทุกแพลตฟอร์ม แจ้งเราหากภาษาไม่เปลี่ยน
- **การเลือกด้วยหน้าต่างข้าม** ตัวติดตั้งรุ่น 0.8.1 มีพฤติกรรมการเลือกด้วยหน้าต่างที่ถูกต้องอยู่แล้วในบิลด์เว็บ 0.8 ตัวติดตั้งรุ่นเก่าไม่มี
- **แท็บเล็ตแนวตั้ง** ความสูงของตารางที่เหลือถูกมอบให้พื้นที่วาด และเลย์เอาต์แผ่นเริ่มที่ 760 px หรือน้อยกว่า

### ยังไม่มีในรุ่นนี้

- **ส่ง NC ไปยังเครื่องจักร** ยังไม่เปิดให้ใช้
- **แรงลม** สำหรับคอนกรีตยังไม่ได้สร้าง และการตรวจคอนกรีตและฐานรากเป็นของวิศวกรที่จะตรวจทาน
- **การลงนามรับรองโค้ด** ตัวติดตั้งของ Windows และ .dmg ของ macOS ไม่ได้ลงนาม ดังนั้น Windows อาจแจ้งเตือน และ macOS ขอให้คลิกขวาแล้วเลือก Open

การเปลี่ยนแปลงก่อนหน้านี้อยู่ใน [มีอะไรใหม่ใน 0.7](topic:whats-new-0-7)
