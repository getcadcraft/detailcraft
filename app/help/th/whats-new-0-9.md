นี่คือสิ่งที่เปลี่ยนแปลงใน DetailCraft 0.9 เทียบกับ 0.8.1 เวอร์ชัน 0.9 เพิ่มขนาดเหล็กของอังกฤษ แบบขยายสำหรับทุกชิ้นส่วนในครั้งเดียว แท็บ {{ui:Analysis}} ที่ใหญ่ขึ้นสำหรับโครงเฟรม และการมองเห็นเคอร์เซอร์ของกันและกันเมื่อทำงานร่วมกัน

## ใหม่

### เหล็กอังกฤษและแบบขยาย

- **ขนาดเหล็กของอังกฤษ** รายการโปรไฟล์มีขนาด 976 รายการจาก Steel for Life Blue Book ได้แก่ UB, UC, PFC, EA, UEA, CHS, SHS และ RHS โดยแยกหน้าตัดกลวงที่ขึ้นรูปเย็นออกไป (ชื่อของหน้าตัดเหล่านั้นขึ้นต้นด้วย CF) ชื่อเขียนโดยเรียงตามตระกูลก่อน เช่น UB305x165x40 หรือ SHS100x100x5.0 และการพิมพ์ตามที่แบบเขียนก็ใช้ได้เช่นกัน: 305x165x40 UB, L100x100x10, SHS100x5 ดู [แคตตาล็อกโปรไฟล์](topic:profile-catalog)
- **มุมไม่เท่ากัน** มุม UEA เก็บทั้งสองขาไว้ผ่านการนำเข้าและส่งออก IFC และผ่านไฟล์ NC และการสะท้อนจะพลิกชิ้นงานกลับหัวท้าย
- **แบบขยายทั้งหมดในครั้งเดียว** เลือก {{ui:Shop drawing}} ในกลุ่ม {{ui:Output}} โดยไม่ได้เลือกอะไร หน้าต่างจะแสดงรายการ part mark ของชิ้นส่วนทุกชิ้น แสดงตัวอย่างของชิ้นใดก็ได้ และ {{ui:Download all}} บันทึก PDF ไฟล์เดียวที่มีหนึ่งหน้าต่อ part mark โดยมีชื่อหน้าว่า "แผ่น 3 จาก 42" {{ui:Download this sheet}} บันทึกเฉพาะแผ่นที่คุณกำลังดูอยู่ ตอนนี้ช่อง มุม และหน้าตัดกลวงก็มีแผ่นด้วย ดู [สร้างแบบขยาย](topic:shop-drawings)
- **โปรไฟล์ของฉัน** ตอนนี้โปรไฟล์กำหนดเองเก็บไว้ให้ทุกโมเดลใหม่ได้ ในฟอร์มโปรไฟล์กำหนดเอง ให้ติ๊ก {{ui:Keep in My profiles}} ค้างไว้ รายการ {{ui:My profiles}} ที่อยู่ข้างใต้จะมี {{ui:Keep}}, {{ui:Use here}} และ {{ui:Remove}} รายการเก็บไว้ในเบราว์เซอร์นี้ (ได้สูงสุด 200 รายการ) ไม่ได้เก็บในบัญชีของคุณ ดู [แผ่นและโปรไฟล์](topic:plates-and-profiles)

### การวิเคราะห์

- **ลำดับที่สอง (P-Delta)** ติ๊ก {{ui:Second order (P-Delta)}} ถัดจากปุ่มเรียกใช้ในแท็บ {{ui:Analysis}} แล้วแรงตามแนวแกนจะกระทำกับโครงเฟรมที่โก่งตัว แผ่นและพื้นแข็งยังคงเป็นลำดับที่หนึ่ง พร้อมคำเตือน ดู [แรง ปฏิกิริยา และการโก่งตัว](topic:frame-analysis)
- **ความถี่ธรรมชาติ** บล็อก {{ui:Finite elements: natural frequencies}} ใต้ผลลัพธ์จะหาโหมดต่ำสุดของโมเดลเดียวกัน พร้อมคาบและมวลโหมดที่มีผลจริง และแสดงโหมดบนโมเดล ดู [แรง ปฏิกิริยา และการโก่งตัว](topic:frame-analysis)
- **แรงลมและที่ตั้งแผ่นดินไหว** มีสามบล็อกใหม่ในแท็บ {{ui:Analysis}}: {{ui:Wind loads (ASCE 7 directional procedure)}}, {{ui:Seismic site and system (ASCE 7)}} และ {{ui:ASCE 7 load combinations}} ดู [แรงลม ที่ตั้งแผ่นดินไหว และการรวมกรณี ASCE 7](topic:wind-seismic-combinations)

### การทำงานร่วมกัน

- **เคอร์เซอร์และชื่อ** ในเซสชัน Live ตัวชี้ของแต่ละคนจะถูกวาดในโมเดลพร้อมชื่อและสีของเขา และสิ่งที่เขาเลือกจะมีกรอบล้อม
- **ติดตามบุคคล** เปิด {{ui:People}} ในเซสชันแล้วเลือก {{ui:Follow}} ที่ชื่อ มุมมองของคุณจะเคลื่อนตามของเขา ผู้จัดเซสชันเลือก {{ui:Ask everyone to follow me}} ได้ ดู [ติดตามบุคคลในเซสชัน Live](topic:follow-in-live)

### ในทุกแอป

- คำแนะนำเครื่องมือ (tooltip) เป็น Bootstrap tooltip การ์ดเคล็ดลับเริ่มต้นมีปุ่มปิด แถบแท็บเลื่อนไปด้านข้างเมื่อไม่พอดี และชื่อแท็บของเบราว์เซอร์แสดงชื่อเอกสารที่เปิด ตามด้วย DetailCraft และ CadCraft

## แก้ไขแล้ว

- โปรไฟล์กำหนดเองหายไปเมื่อคุณเริ่มโมเดลใหม่
- ช่อง มุม และหน้าตัดกลวงหายไปจากชุดแบบขยาย

## ข้อจำกัดที่ควรรู้

- บล็อกแรงลม แผ่นดินไหว และไฟไนต์เอลิเมนต์เป็นเพียงเครื่องมือช่วยตรวจ วิศวกรของคุณต้องตรวจทานผลลัพธ์ ไม่ใช่การตรวจตามมาตรฐาน การค้นหา USGS ทดสอบกับตัวจำลอง ไม่ใช่บริการจริง
- ไฟไนต์เอลิเมนต์และ P-Delta ตรวจกับคำตอบด้วยมือและคำตอบแบบปิด ไม่ใช่อาคารจริง การวิเคราะห์การโก่งเดาะยังไม่ได้สร้าง
- ยังไม่มีผู้ผลิตเหล็กในสหราชอาณาจักรที่ทดลองใช้ขนาดของอังกฤษ และไฟล์ NC สำหรับมุมไม่เท่ากันยังไม่เคยรันบนเครื่องจักร
- ชุดแบบขยายเป็น PDF เท่านั้น
- ภาษาอื่นนอกจากภาษาอังกฤษเป็นฉบับร่างจากเครื่อง
- ตัวติดตั้ง Windows ไม่ได้ลงนามรหัส (More info แล้ว Run anyway) ดิสก์อิมเมจ macOS ยังไม่ได้ notarize (คลิกขวา แล้ว Open)

การเปลี่ยนแปลงก่อนหน้านี้อยู่ในหมายเหตุของ 0.8 และ 0.8.1 ด้านล่างของหน้านี้

## ก่อนหน้านี้: 0.8 และ 0.8.1

นี่คือสิ่งที่เปลี่ยนแปลงใน DetailCraft 0.8 (1 พฤศจิกายน 2026) และ 0.8.1 (2 พฤศจิกายน 2026) เทียบกับ 0.7 เวอร์ชัน 0.7 ตรวจสอบชิ้นส่วนเหล็ก ส่วน 0.8 วางแผนการยก เสนอการเชื่อมต่อ ตรวจฐานรากและเหล็กเสริม และจัดโครงผนัง พื้น และหลังคาไม้และโครงเหล็กบาง

### ใหม่

**การติดตั้ง**

- **แผนการติดตั้งและภาพยนตร์** ในแท็บ {{ui:Erection}} อธิบายเครน (ตั้งอยู่ตรงไหน ตะขอสูงสุด และอุปกรณ์ยกที่ไม่อยู่ในตารางโหลด) แล้วพิมพ์แถวของตารางโหลดของเครน DetailCraft ยกโมเดลทีละหนึ่งแอสเซมบลีตามลำดับเฟสและทีละชั้น และตรวจแต่ละการยกกับตารางที่รัศมีนั้นและกับระยะสำรองที่คุณตั้งไว้ {{ui:Save movie}} เขียนไฟล์ HTML หนึ่งไฟล์ที่เล่นแบบออฟไลน์ในเบราว์เซอร์ใดก็ได้ แม้แต่บนโทรศัพท์ การยกที่เกินตารางโหลด เลยตาราง หรือสูงเกินไปจะอยู่ใน {{ui:Problems}} นี่เป็นแผนจากตัวเลขของคุณ ไม่ใช่แผนการยกฉบับสมบูรณ์ ดู [แผนการติดตั้งและภาพยนตร์](topic:erection-movie)

**การเชื่อมต่อ**

- **ออโตไพลอตการเชื่อมต่อ** แท็บ {{ui:Autopilot}} ตรวจทุกจุดต่อที่ยังไม่มีการเชื่อมต่อ และเสนอการเชื่อมต่อจากรูปร่าง ได้แก่ แผ่นฐาน แท็บเฉือน แผ่นปลายสำหรับคานที่คุณทำเครื่องหมายเป็นคานโมเมนต์ แผ่นต่อ และแผ่นค้ำ ใส่โหลดสม่ำเสมอหรือแรงเฉือนปลายหนึ่งด้าน แล้วจำนวนโบลต์จะเป็นไปตามกำลังออกแบบของโบลต์ {{ui:Add them all}} เพิ่มข้อเสนอทั้งหมดเป็นหนึ่งขั้นเลิกทำ ทั้งหมดเป็นค่าเริ่มต้นให้ตรวจทาน ไม่ใช่การออกแบบการเชื่อมต่อ
- **การตรวจความสามารถในการก่อสร้าง** {{ui:Problems}} สำหรับโบลต์ที่ประแจเข้าไม่ถึง โบลต์ที่ชิดเกินไปสำหรับซ็อกเก็ต การเชื่อมฟิลเลตที่นอกขนาดจำกัด และหน้าตัดกลวงที่กักน้ำ การเข้าถึงจุดเชื่อมเป็นของใหม่: การเชื่อมฟิลเลตรอบทิศที่ปืนเชื่อมเข้าไม่ถึงจะแสดงพร้อมชิ้นส่วนที่กีดขวางและสัดส่วนของการเชื่อมที่ได้รับผลกระทบ ดู [การตรวจความสามารถในการก่อสร้าง](topic:constructability)

**ฐานรากและเหล็กเสริม**

- **การตรวจฐานราก** แท็บ {{ui:Foundation}} ตรวจฐานเดี่ยว ฐานรวม และแผ่นฐานบนดินที่คุณอธิบาย ได้แก่ แรงแบริ่ง การเลื่อนและการพลิกคว่ำจากโหลดใช้งาน การดัดงอ แรงเฉือน การเจาะทะลุ การยึด และเหล็กขั้นต่ำจากโหลดที่คูณแล้ว (ACI 318-19) เสาที่อยู่ใกล้ขอบหรือมุมจะถูกตรวจด้วยหน้าตัดที่ถูกตัดด้วยขอบฐาน การทรุดตัวมาจากโมดูลัสของดิน แผ่นยืดหยุ่นถูกแก้บนสปริงจากโมดูลัสของชั้นรองดิน และกลุ่มเสาเข็มกับกำแพงกันดินมีแผงของตัวเอง โหลดเสาพิมพ์เองได้หรือดึงจาก {{ui:Analysis}} ก็ได้ ดู [การตรวจฐานราก](topic:foundation-checks)
- **แผนที่ความแออัดของเหล็กเสริม** แท็บ {{ui:Congestion}} วาดแผนที่ความร้อนของแต่ละฐานจากมุมมองด้านบน ตรงไหนที่เหล็กเหลือที่ว่างน้อยเกินไปให้คอนกรีตไหลลงไป เทียบกับกฎระยะสุทธิ และถ้าคุณใส่ไว้ก็เทียบกับมวลรวมขนาดใหญ่สุดและหัวเครื่องสั่น ดู [แผนที่ความแออัดของเหล็กเสริม](topic:rebar-congestion)

**โครงและการจัดหา**

- **โครงไม้และโครงเหล็กบาง** แท็บ {{ui:Framing}} จัดโครงแผงผนัง พื้น และหลังคาพร้อมทุกชิ้น รายการตัด วัสดุที่ต้องซื้อ และแบบขยายตามสเกล {{ui:Place as members}} วางชิ้นส่วนในโมเดล และ {{ui:PDF sheets}} บันทึกหนึ่งแผ่นต่อแผง ขนาด ระยะ และคานหัวเสาเป็นของคุณ DetailCraft ไม่ตรวจว่าโครงรับโหลดได้หรือไม่ ดู [แผงโครงไม้และโครงเหล็กบาง](topic:framing-panels)
- **สต็อกของซัพพลายเออร์และระยะเวลารอ** แท็บ {{ui:Supply}} อ่านรายการสต็อกของซัพพลายเออร์ (CSV) และแสดงสำหรับแต่ละหน้าตัดที่รายการตัดต้องซื้อว่ามีเพียงพอในสต็อกหรือไม่ และต้องรอนานเท่าใด รายการขาดและหน้าตัดที่ส่งช้าอยู่ใน {{ui:Problems}} ไม่มีการสั่งซื้อใด ๆ ดู [สต็อกของซัพพลายเออร์และระยะเวลารอ](topic:supplier-stock)

**การวิเคราะห์และการออกแบบ**

- **อะไรพังก่อน?** ในแท็บ {{ui:Analysis}} ปุ่มนี้หาการรวมกรณีกำลังที่ควบคุม ชิ้นส่วนที่อ่อนที่สุด โหลดที่เพิ่มขึ้นได้อีกก่อนชิ้นส่วนแรกถึงขีดจำกัด และแผ่นปลายหรือแท็บเฉือนที่อ่อนที่สุดเมื่อทราบกำลังเฉือนของโบลต์ ต้องมีการรวมกรณีและมาตรฐานการออกแบบก่อน ไม่ได้ตรวจแรงแบริ่ง block shear รอยเชื่อม และ prying ผู้ช่วยที่เชื่อมต่ออยู่ของคุณก็ขอให้ทำได้เช่นกัน
- **Live** ติ๊ก {{ui:Live: solve again after each edit}} แล้วเฟรมจะถูกแก้ใหม่หลังการแก้ไขทุกครั้ง
- **คอนกรีตและอื่น ๆ** เสาเรียวในเฟรมที่ไม่โยกถูกออกแบบสำหรับโมเมนต์ขยาย (ACI 318-19 6.6.4.5) คาบแผ่นดินไหวรับได้จากการวิเคราะห์ด้วยวิธีของ Rayleigh พื้นที่ทำจากแผ่นจะได้เหล็กที่แต่ละชั้นต้องการจากโมเมนต์ และแรงเฉือนทางเดียว ดู [ตรวจชิ้นส่วนคอนกรีตและสร้างโหลดแผ่นดินไหว](topic:concrete-and-seismic)
- **สำหรับวิศวกรตรวจสอบ** ผลการตรวจฐานราก คอนกรีต และอะไรพังก่อน เป็นเพียงเครื่องมือช่วย ยังไม่ได้สร้างโหลดลม

### ในทุกแอป

- **ภาษา** ความช่วยเหลือมี 54 ภาษา ภาษาอื่นนอกจากภาษาอังกฤษเป็นฉบับร่างจากเครื่องจนกว่าผู้พูดภาษาแม่จะอ่าน ภาษาใหม่สิบภาษา ได้แก่ ลิทัวเนีย ลัตเวีย บอสเนีย มราฐี เตลูกู แอลเบเนีย แอฟริกานส์ ฟิลิปปินส์ สวาฮีลี และอุซเบก
- **แถวของแถบเครื่องมือ** {{ui:Settings}} › {{ui:General}} › {{ui:Toolbar rows}} เลือกตัดบรรทัด 2 แถว หรือ 1 แถว แถบที่พอดีอยู่แล้วจะคงเดิม ส่วนที่เหลือเลื่อนไปด้านข้าง
- **กริดคุณสมบัติ** ช่องของฐานใช้กริดร่วม มีหมวดที่พับได้และความหนาแน่นแบบกะทัดรัด การคำนวณที่พิมพ์ เช่น 2*450 ยังใช้ได้
- **อุปกรณ์ป้อนข้อมูล** แทร็กแพด ปากกา เมาส์ 3D คอนโทรลเลอร์ และ MIDI ควบคุมแอปได้ ดู [นำทางใน 3D](topic:navigate-3d)
- **พาเนลปัญหา** คำเตือนของการตรวจใหม่ข้างต้นปรากฏในพาเนล {{ui:Problems}} เดิมเหมือนเดิม
- **เชื่อมต่อ AI ของคุณ** ผู้ช่วยของคุณเอง เชื่อมผ่าน CadCraft Studio ทำงานกับแอปทั้งแปดและเห็นเฉพาะสิ่งที่คุณอนุญาต การเชื่อมต่อด้วยคลิกเดียว ตัวเชื่อมต่อที่โฮสต์ไว้ และคีย์ API ของคุณเองใน Studio ยังมาไม่ถึง ดู [ใช้ DetailCraft กับผู้ช่วย AI](topic:use-with-ai-assistants)

### แก้ไขใน 0.8.1

- **ภาษาใน Studio** Studio และรุ่นแพ็กสามารถสลับภาษาขณะทำงานได้ ก่อนหน้านี้มีเฉพาะภาษาอังกฤษ ยังไม่ได้ทดสอบบนทุกแพลตฟอร์ม โปรดแจ้งเราหากภาษาไม่เปลี่ยน
- **การเลือกด้วยหน้าต่างข้าม** ตัวติดตั้ง 0.8.1 มีพฤติกรรมการเลือกด้วยหน้าต่างที่ถูกต้องอยู่แล้วในบิลด์เว็บ 0.8 ตัวติดตั้งรุ่นเก่าไม่มี
- **แท็บเล็ตแนวตั้** พื้นที่กริดที่เหลือไปยังผืนผ้าใบ และเลย์เอาต์แผ่นเริ่มที่ 760 px หรือน้อยกว่า

### ยังไม่อยู่ในเวอร์ชันนี้

- **ส่ง NC ไปยังเครื่องจักร** ยังไม่เปิดให้ใช้
- **แรงลม** สำหรับคอนกรีตยังไม่ได้สร้าง และการตรวจคอนกรีตและฐานรากให้วิศวกรตรวจทาน
- **การลงนามรหัส** ตัวติดตั้ง Windows และไฟล์ .dmg ของ macOS ไม่ได้ลงนาม ดังนั้น Windows อาจแสดงคำเตือน และ macOS ขอให้คลิกขวา แล้ว Open

การเปลี่ยนแปลงก่อนหน้านี้อยู่ใน [มีอะไรใหม่ใน 0.7](topic:whats-new-0-7)
