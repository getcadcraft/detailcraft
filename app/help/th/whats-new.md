นี่คือสิ่งที่เปลี่ยนไปใน DetailCraft 0.8 (1 พฤศจิกายน 2026) และ 0.8.1 (2 พฤศจิกายน 2026) เมื่อเทียบกับ 0.7 0.7 ตรวจสอบสมาชิกเหล็ก ส่วน 0.8 วางแผนการยก เสนอจุดต่อ ตรวจฐานรากและเหล็กเส้น และวางโครงผนัง พื้น และหลังคาไม้และโครงเบา

## ใหม่

### การติดตั้ง

- **แผนการติดตั้งและภาพยนตร์** ในแท็บ {{ui:Erection}} อธิบายเครน (ตำแหน่งที่ตั้ง ตะขอที่สูงที่สุด และอุปกรณ์ยกที่ไม่อยู่ในตาราง) แล้วพิมพ์แถวของตารางโหลดเครน DetailCraft จะยกโมเดลทีละแอสเซมบลี ตามลำดับเฟสและทีละชั้น และตรวจแต่ละการยกกับตารางที่รัศมีนั้นและกับระยะขอบที่คุณตั้งไว้ {{ui:Save movie}} เขียนไฟล์ HTML หนึ่งไฟล์ที่เล่นแบบออฟไลน์ได้ในเบราว์เซอร์ใดก็ได้ แม้บนโทรศัพท์ การยกที่เกินตาราง ผ่านตาราง หรือสูงเกินไปจะอยู่ใน {{ui:Problems}} นี่คือแผนจากตัวเลขของคุณ ไม่ใช่แผนการยกจริง ดู [แผนการติดตั้งและภาพยนตร์](topic:erection-movie)

### การเชื่อมต่อ

- **ตัวช่วยอัตโนมัติของการเชื่อมต่อ** แท็บ {{ui:Autopilot}} ดูทุกจุดต่อที่ยังไม่มีการเชื่อมต่อ และเสนอหนึ่งการเชื่อมต่อจากรูปร่าง: แผ่นฐาน แผ่นเฉือน แผ่นปลายสำหรับคานที่คุณทำเครื่องหมายเป็นคานโมเมนต์ การต่อ และแผ่นเสริม ป้อนโหลดสม่ำเสมอหรือแรงเฉือนปลายหนึ่งด้าน แล้วจำนวนโบลต์จะตามกำลังออกแบบของโบลต์ {{ui:Add them all}} เพิ่มข้อเสนอทั้งหมดเป็นหนึ่งขั้นของการเลิกทำ ข้อเสนอเป็นค่าเริ่มต้นให้ตรวจทาน ไม่ใช่การออกแบบการเชื่อมต่อ
- **การตรวจความสามารถในการก่อสร้าง** {{ui:Problems}} แสดงโบลต์ที่ประแจเอื้อมไม่ถึง โบลต์ที่อยู่ใกล้กันเกินกว่าซ็อกเก็ต รอยเชื่อมฟิลเลตที่เกินขนาดจำกัด และหน้าตัดกลวงที่กักน้ำ การเข้าถึงรอยเชื่อมเป็นของใหม่: รอยเชื่อมฟิลเลตรอบด้านที่หัวเชื่อมของช่างเชื่อมเอื้อมไม่ถึงจะแสดงพร้อมชิ้นส่วนที่บังอยู่และสัดส่วนของรอยเชื่อมที่ได้รับผลกระทบ ดู [การตรวจความสามารถในการก่อสร้าง](topic:constructability)

### ฐานรากและเหล็กเส้น

- **การตรวจฐานราก** แท็บ {{ui:Foundation}} ตรวจฐานราก ฐานรวม และแผ่นฐานบนดินที่คุณอธิบาย: การรับน้ำหนัก การเลื่อนไถลและการพลิกคว่ำจากโหลดใช้งาน; การดัด แรงเฉือน การเจาะทะลุ ระยะยึดเกาะ และเหล็กขั้นต่ำจากโหลดที่คูณตัวประกอบ (ACI 318-19) เสาที่อยู่ใกล้ขอบหรือมุมจะถูกตรวจด้วยหน้าตัดที่ถูกตัดตามขอบของฐานราก การทรุดตัวคำนวณจากโมดูลัสของดิน แผ่นยืดหยุ่นจะถูกแก้บนสปริงจากโมดูลัสของชั้นรองพื้น และกลุ่มเสาเข็มกับกำแพงกันดินมีแผงของตัวเอง โหลดเสาป้อนเองได้หรือนำมาจาก {{ui:Analysis}} ดู [การตรวจฐานราก](topic:foundation-checks)
- **แผนที่ความแออัดของเหล็กเส้น** แท็บ {{ui:Congestion}} วาดแผนที่ความร้อนของแต่ละฐานราก เมื่อมองจากด้านบน: ตำแหน่งที่เหล็กเส้นเหลือที่ว่างน้อยเกินไปให้คอนกรีตลงไปถึง เทียบกับกฎระยะช่องว่างสุทธิ และถ้าคุณใส่ขนาดมวลรวมที่ใหญ่ที่สุดและหัวเครื่องสั่น ดู [แผนที่ความแออัดของเหล็กเส้น](topic:rebar-congestion)

### การวางโครงและการจัดหา

- **การวางโครงไม้และโครงเบา** แท็บ {{ui:Framing}} วางโครงแผงผนัง พื้น และหลังคาพร้อมทุกชิ้น รายการตัด สต็อกที่ต้องซื้อ และแบบขยายตามมาตราส่วน {{ui:Place as members}} วางชิ้นส่วนในโมเดล และ {{ui:PDF sheets}} บันทึกหนึ่งแผ่นต่อหนึ่งแผง ขนาด ระยะ และทับหลังเป็นของคุณเอง DetailCraft ไม่ได้ตรวจว่าจะรับน้ำหนักได้หรือไม่ ดู [แผงโครงไม้และโครงเบา](topic:framing-panels)
- **สต็อกของซัพพลายเออร์และระยะเวลารอ** แท็บ {{ui:Supply}} อ่านรายการสต็อกของซัพพลายเออร์ (CSV) และแสดงสำหรับแต่ละหน้าตัดที่รายการตัดต้องซื้อ ว่ามีพอในสต็อกหรือไม่ และต้องรอนานเท่าใด รายการที่ขาดและหน้าตัดที่ล่าช้าอยู่ใน {{ui:Problems}} ไม่มีการสั่งซื้ออะไรเลย ดู [สต็อกของซัพพลายเออร์และระยะเวลารอ](topic:supplier-stock)

### การวิเคราะห์และการออกแบบ

- **อะไรพังก่อน?** ในแท็บ {{ui:Analysis}} ปุ่มจะหาชุดกำลังที่ควบคุมอยู่ สมาชิกที่อ่อนที่สุด โหลดเพิ่มได้มากแค่ไหนก่อนสมาชิกแรกจะถึงขีดจำกัด และแผ่นปลายหรือแผ่นเฉือนที่อ่อนที่สุดเมื่อทราบกำลังเฉือนของโบลต์ ต้องมีชุดโหลดและมาตรฐานการออกแบบก่อน ยังไม่ได้ตรวจแรงแบกทาน การเฉือนบล็อก รอยเชื่อม และการงัด ผู้ช่วยที่เชื่อมต่อไว้ของคุณถามได้เช่นเดียวกัน
- **สด** ติ๊ก {{ui:Live: แก้ใหม่หลังการแก้ไขทุกครั้ง}} แล้วโครงจะถูกคำนวณใหม่หลังการแก้ไขทุกครั้ง
- **คอนกรีตและอื่นๆ** เสาเพรียวในโครงที่ไม่โยกถูกออกแบบสำหรับโมเมนต์ที่ขยายแล้ว (ACI 318-19 6.6.4.5) คาบแผ่นดินไหวรับได้จากการวิเคราะห์ด้วยวิธีของ Rayleigh พื้นที่ทำจากแผ่นจะได้เหล็กที่แต่ละชั้นต้องการจากโมเมนต์ของมัน และแรงเฉือนทางเดียว ดู [ตรวจสมาชิกคอนกรีตและสร้างโหลดแผ่นดินไหว](topic:concrete-and-seismic)
- **สำหรับวิศวกรให้ตรวจ** ผลของฐานราก คอนกรีต และอะไรพังก่อนเป็นเพียงเครื่องช่วย ยังไม่ได้สร้างโหลดลม

### ทุกแอป

- **ภาษา** คู่มือมีถึง 54 ภาษา ภาษาที่นอกเหนือจากภาษาอังกฤษเป็นฉบับร่างจากเครื่องจนกว่าผู้พูดเจ้าของภาษาจะอ่าน; สิบภาษาเป็นของใหม่ (ลิทัวเนีย ลัตเวีย บอสเนีย มาราฐี เตลูกู แอลเบเนีย อาฟรีกานส์ ฟิลิปิโน สวาฮีลี อุซเบก)
- **แถวของแถบเครื่องมือ** {{ui:Settings}} › {{ui:General}} › {{ui:Toolbar rows}} เลือกได้ว่าจะให้ห่อบรรทัด 2 แถว หรือ 1 แถว แถบที่พอดีอยู่แล้วจะคงเดิม ส่วนที่เหลือจะเลื่อนในแนวนอน
- **กริดคุณสมบัติ** ช่องของฐานรากใช้กริดที่ใช้ร่วมกัน: หมวดหมู่ที่ยุบได้และความหนาแน่นแบบกะทัดรัด การคำนวณที่พิมพ์ เช่น 2*450 ยังใช้ได้
- **อุปกรณ์ป้อนข้อมูล** แทร็กแพด ปากกา เมาส์ 3 มิติ ตัวควบคุม และ MIDI ใช้ควบคุมแอปได้ ดู [การนำทางใน 3D](topic:navigate-3d)
- **แผงปัญหา** คำเตือนของการตรวจใหม่ข้างต้นปรากฏในแผง {{ui:Problems}} เดิมเช่นเดียวกับก่อนหน้านี้
- **เชื่อมต่อ AI ของคุณ** ผู้ช่วยของคุณเอง เชื่อมผ่าน CadCraft Studio ทำงานกับแอปทั้งแปดและเห็นเฉพาะสิ่งที่คุณอนุญาต การเชื่อมต่อด้วยคลิกเดียว ตัวเชื่อมที่โฮสต์ และคีย์ API ของคุณเองใน Studio ยังมาภายหลัง ดู [ใช้ DetailCraft กับผู้ช่วย AI](topic:use-with-ai-assistants)

## แก้ไขใน 0.8.1

- **ภาษาใน Studio** Studio และรุ่นที่แพ็กไว้เปลี่ยนภาษาขณะทำงานได้ ก่อนหน้านี้มีเพียงภาษาอังกฤษ ยังไม่ได้ทดสอบบนทุกแพลตฟอร์ม โปรดแจ้งเราหากภาษาไม่เปลี่ยน
- **การเลือกด้วยหน้าต่างข้าม** ตัวติดตั้ง 0.8.1 มีพฤติกรรมการเลือกด้วยหน้าต่างที่ถูกต้องอยู่แล้วในบิลด์เว็บ 0.8 ตัวติดตั้งรุ่นเก่าไม่มี
- **แท็บเล็ตในแนวตั้ง** พื้นที่กริดที่เหลือถูกมอบให้แคนวาส และการจัดวางแผ่นจะเริ่มที่ 760 px หรือน้อยกว่า

## ยังไม่มีในรุ่นนี้

- **ส่ง NC ไปยังเครื่องจักร** ยังไม่เปิดให้ใช้
- **โหลดลม** สำหรับคอนกรีตยังไม่ได้สร้าง และการตรวจคอนกรีตกับฐานรากมีไว้ให้วิศวกรตรวจทาน
- **การลงนามโค้ด** ตัวติดตั้ง Windows และไฟล์ .dmg ของ macOS ยังไม่ได้ลงนาม ดังนั้น Windows อาจแสดงคำเตือน และ macOS จะขอให้คลิกขวา แล้วเลือก เปิด

การเปลี่ยนแปลงก่อนหน้านี้อยู่ใน [มีอะไรใหม่ใน 0.7](topic:whats-new-0-7)
