ข้อจำกัดส่วนใหญ่จะอธิบายไว้ในแถบสถานะด้านล่างของหน้าจอ หรือในแท็บ {{ui:ปัญหา}} อ่านสองที่นี้ก่อน ข้อความด้านล่างถูกอ้างตามที่ DetailCraft แสดง

## มุมมอง 3D หายไป

**"เบราว์เซอร์นี้ไม่สามารถเริ่มกราฟิก 3D (WebGL) ได้ โมเดล รายงาน และการส่งออกยังใช้งานได้"**

เบราว์เซอร์ไม่สามารถเริ่ม WebGL ซึ่งเป็นกราฟิก 3D ที่ DetailCraft ใช้วาดภาพ

1. อัปเดตเบราว์เซอร์เป็นเวอร์ชันล่าสุด
2. เปิดการเร่งความเร็วด้วยฮาร์ดแวร์ แล้วเริ่มเบราว์เซอร์ใหม่ (ดูด้านล่าง)
3. อัปเดตไดรเวอร์กราฟิก หรือลองเบราว์เซอร์อื่น เดสก์ท็อประยะไกลและเครื่องเสมือนมักไม่มี WebGL
4. ระหว่างนี้คุณยังทำงานต่อได้: วางชิ้นส่วนด้วยฟอร์ม {{ui:เพิ่มตามกริด}} อ่านรายงาน และส่งออกได้ มีเพียงการคลิกในมุมมองเท่านั้นที่ต้องใช้ WebGL

:::chromium
ในการเปิดการเร่งความเร็วด้วยฮาร์ดแวร์ ให้เปิด **การตั้งค่า ระบบ** แล้วเปิด **ใช้การเร่งความเร็วด้วยกราฟิกเมื่อพร้อมใช้งาน** จากนั้นเปิดเบราว์เซอร์ใหม่
:::

:::firefox
ในการเปิดการเร่งความเร็วด้วยฮาร์ดแวร์ ให้เปิด **การตั้งค่า ทั่วไป ประสิทธิภาพ** ยกเลิกการเลือก **ใช้การตั้งค่าประสิทธิภาพที่แนะนำ** แล้วเลือก **ใช้การเร่งความเร็วด้วยฮาร์ดแวร์เมื่อพร้อมใช้งาน** เริ่ม Firefox ใหม่
:::

:::safari
Safari เปิด WebGL เป็นค่าเริ่มต้น หากมุมมองยังไม่เริ่ม ให้อัปเดต macOS และตรวจว่าไม่มีส่วนขยายใดบล็อกอยู่
:::

## การคลิกในมุมมองไม่ทำงาน

- **ไม่มีจุดตัดใกล้จุดที่คลิก** เครื่องมือวางจะจับได้เฉพาะจุดตัดกริดเท่านั้น การคลิกห่างจากจุดทุกจุดจะไม่ทำอะไร ให้เลื่อนเข้าใกล้จนจุดสว่างขึ้น
- **เครื่องมือคือ {{ui:เลือก}} และคุณคลิกพื้นที่ว่าง** ซึ่งจะล้างการเลือก
- **คุณลาก** การกดและปล่อยที่ห่างกันเกินไปไม่กี่พิกเซลถือเป็นการลาก ซึ่งจะหมุนหรือแพนมุมมอง
- **ชิ้นส่วนถูกตัดออก** ใน {{ui:ผัง}} และ {{ui:รูปด้าน}} เหล็กที่อยู่นอกส่วนที่ตัดจะถูกซ่อนและคลิกไม่ได้ ให้สลับไป {{ui:3D}}
- **จุดตัดอยู่ผิดระดับ** ใน {{ui:3D}} จุดตัดของหลายระดับอาจซ้อนกันบนหน้าจอ การคลิกจะเลือกจุดที่ใกล้ที่สุด ให้ใช้ {{ui:ผัง}} หรือ {{ui:รูปด้าน}} แทน

## ข้อความขณะวาง

| ข้อความ | ควรทำอย่างไร |
|---|---|
| ไม่มีระดับเหนือ Level 2 ให้เสาไปถึง เพิ่มระดับก่อน | เพิ่มระดับใน {{ui:ระดับ}} หรือคลิกระดับที่ต่ำกว่า |
| เลือกจุดอื่นสำหรับปลายอีกด้าน | คุณคลิกจุดเดิมสองครั้ง |
| ปลายทั้งสองเป็นจุดเดียวกัน | ใน {{ui:เพิ่มตามกริด}} จุด "From" และ "To" เป็นจุดเดียวกัน |
| เพิ่มเส้นกริดทางซ้ายเพื่อวางชิ้นส่วน | โมเดลไม่มีเส้นกริดในทิศทางหนึ่ง |
| ไม่รู้จักโปรไฟล์ "…" | โปรไฟล์ไม่อยู่ในแคตาล็อกหรือในโปรไฟล์กำหนดเองของโมเดล เลือกจากรายการ |
| พิมพ์ตัวเลข | ช่องตัวเลขว่างหรือมีข้อความ |

## การเชื่อมต่อสร้างไม่ได้

### "คานนี้ไม่ได้สิ้นสุดบนแนวเสา"

แผ่นปลายต้องให้ปลายคานอยู่บนแนวเสาแนวตั้งพอดี ระหว่างด้านล่างและด้านบนของเสา (ภายใน 1 mm) ตรวจ {{ui:ปลาย (x, y, z mm)}} ของคานและตำแหน่งของเสา

### "คานนี้ชนเอวของเสาหรือทำมุม"

หรือในแท็บ {{ui:ปัญหา}}: "คานที่เข้ากับเอวของเสายังไม่ได้สร้าง: หมุนเสา 90° หรือใช้การเชื่อมต่ออื่น"

คานเข้ากับเอวของเสา เลือกเสาแล้วตั้ง {{ui:การหมุน (°)}} เป็น 90 จากนั้นลองใหม่ การต่อแบบเฉียงยังไม่ได้สร้าง

### "แผ่นปลายสร้างได้เฉพาะคานระดับ (คานนี้ลาดเอียง)"

ปลายทั้งสองของคานต้องอยู่ที่ความสูงเดียวกัน

### "แผ่นปลายต้องการคานตั้งตรง (การหมุน 0)"

ตั้ง {{ui:การหมุน (°)}} ของคานกลับเป็น 0

### "แผ่นปลายต้องการคานหน้าตัด I" / "แผ่นปลายต้องการเสาหน้าตัด I"

มีเพียงหน้าตัด I (W, IPE, HEA, HEB หรือ I กำหนดเอง) เท่านั้นที่รับแผ่นปลายได้

### "ปลายคานไม่อยู่บนแนวเสาอีกต่อไป"

คุณย้ายคานหรือเสาหลังจากเพิ่มการเชื่อมต่อ ให้ย้ายกลับ หรือลบการเชื่อมต่อ

### "การเชื่อมต่อตัดชิ้นส่วนนี้จนเหลือศูนย์"

การเชื่อมต่อที่ปลายทั้งสองตัดชิ้นส่วนให้สั้นกว่าความยาวของมัน เช่น คานสั้นมากระหว่างเสาลึกสองต้น ตรวจปลายของชิ้นส่วนและความหนาของแผ่น

### "ไม่มีจุดต่ออื่นแบบนี้ … ที่ยังไม่มีการเชื่อมต่อ"

{{ui:คล้ายกัน}} จะคัดลอกไปยังเฉพาะจุดต่อที่มีหน้าตัดคานเดียวกัน หน้าตัดเสาเดียวกัน และชนิดการเชื่อมต่อเดียวกัน คือคานเข้าปีก ที่ยังไม่มีการเชื่อมต่อเท่านั้น

### "ปลายทั้งสองมีการเชื่อมต่ออยู่แล้ว" / "เสาต้นนี้มีแผ่นฐานอยู่แล้ว"

เลือกการเชื่อมต่อที่มีอยู่เพื่อเปลี่ยนแปลง หรือลบก่อน

## คำเตือนในแท็บปัญหา

คำเตือนไม่หยุดการเชื่อมต่อหรือฐานรากไม่ให้สร้าง แต่ขอให้คุณตรวจสอบ คำเตือนเรื่องขอบและระยะห่างใช้ค่าต่ำสุดจากตาราง 3.3 ของ EN 1993-1-8 (ขอบ 1.2 × รู ระยะห่าง 2.2 × รู เกจ 2.4 × รู) หากโครงการของคุณใช้กฎอื่น คำเตือนอาจไม่ใช้ได้ DetailCraft ไม่ได้ออกแบบการเชื่อมต่อ

"รูอยู่นอกปลายของชิ้นส่วน" หมายความว่าค่า x ของรูน้อยกว่า 0 หรือมากกว่าความยาวที่ตัด จำไว้ว่า x วัดจากจุดเริ่มตัด หลังจากที่การเชื่อมต่อตัดชิ้นส่วนให้สั้นลงแล้ว

## ฐานรากเปลี่ยนแปลงไม่ได้

| ข้อความ | ควรทำอย่างไร |
|---|---|
| ระยะหุ้มไม่เหลือที่ให้เหล็กเส้นในฐานรากนี้ | ทำฐานรากให้ใหญ่ขึ้นหรือลดระยะหุ้ม |
| ฐานรากตื้นเกินไปสำหรับเหล็กเส้นสองชั้นภายในระยะหุ้ม | ทำให้ลึกขึ้นหรือลดระยะหุ้ม |
| เหล็กเสาเริ่มต้นไม่พอดีในฐานรากด้วยระยะหุ้ม 75 mm | เหล็กเสาน้อยลง ระยะห่างแคบลง หรือฐานรากใหญ่ขึ้น |
| ระยะห่างเหล็กเส้นต้องอยู่ระหว่าง 50–1000 mm | พิมพ์ระยะห่างในช่วงนั้น |
| ความยาวต้องอยู่ระหว่าง 300–50000 mm | ขนาดฐานรากมีขีดจำกัด: ความยาวและความกว้าง 300 ถึง 50000 ความลึก 150 ถึง 10000 |

## กริดและระดับถูกปฏิเสธ

| ข้อความ | ควรทำอย่างไร |
|---|---|
| กริดแบบตัวเลข: ให้ระยะห่างหนึ่งค่าระหว่างเส้นแต่ละคู่ (4) | นับช่องว่าง: เส้นห้าเส้นต้องมีสี่ระยะห่าง |
| กริดแบบตัวอักษร: ระยะห่างต้องเป็น mm บวก | ห้ามเป็นศูนย์ ค่าลบ หรือข้อความ |
| กริดแบบตัวเลข: ป้ายกำกับกริดต้องไม่ซ้ำกัน | มีสองเส้นที่มีป้ายเดียวกัน |
| สูงสุด 60 เส้นกริดในแต่ละทิศทาง | แบ่งโมเดล |
| เก็บระดับไว้อย่างน้อยหนึ่งระดับ | คุณลบทุกแถวของระดับ |
| ทุกระดับต้องมีชื่อ / มีสองระดับชื่อ "…" | ตั้งชื่อแต่ละระดับให้ต่างกัน |

## เปิดไฟล์ไม่สำเร็จ

| ข้อความ | สาเหตุ |
|---|---|
| DetailCraft เปิดโมเดลของตัวเอง (.detailcraft.json) การนำเข้า IFC ยังไม่ได้สร้าง | ไฟล์ไม่ใช่ไฟล์ `.json` |
| นี่ไม่ใช่โมเดล DetailCraft (ไม่ใช่ JSON) | ไฟล์เสียหายหรือเป็น JSON อื่น |
| นี่ไม่ใช่โมเดล DetailCraft | ไฟล์ JSON จากโปรแกรมอื่น |
| โมเดลนี้บันทึกโดย DetailCraft ที่ใหม่กว่า (รูปแบบ 2) | เปิดด้วย DetailCraft ใหม่ที่บันทึกไฟล์นั้น |
| ไฟล์นี้ใหญ่เกินไปสำหรับโมเดล DetailCraft | เกิน 50 MB |

เมื่อไฟล์เปิดพร้อมคำเตือน เช่น "มี 2 ชิ้นส่วนไม่ถูกต้องและถูกตัดออก" ส่วนที่เหลือของโมเดลยังใช้ได้ อย่าบันทึกทับไฟล์เดิมจนกว่าคุณจะตรวจสิ่งที่ถูกตัดออกแล้ว

## การส่งออก

| ข้อความ | สาเหตุ |
|---|---|
| ยังไม่มีอะไรให้ส่งออก | {{ui:IFC}} กับโมเดลที่ว่างเปล่า |
| ไม่มีชิ้นส่วนหน้าตัด I หรือแผ่นให้เขียนไฟล์ NC | มีเพียงช่อง มุม หรือท่อในโมเดล |
| ยังไม่ได้เขียน (รองรับเฉพาะหน้าตัด I และแผ่นเท่านั้น): … | เครื่องหมายเหล่านั้นไม่ใช่หน้าตัด I หรือแผ่น ส่วนที่เหลือถูกเขียนแล้ว |
| ไม่มีฐานราก จึงไม่มีเหล็กเส้นให้จัดตาราง | {{ui:การดัด}} กับไม่มีฐานราก |
| … อักขระนอกฟอนต์ PDF แสดงเป็น "?" | ชื่อโมเดลหรือเกรดมีอักขระที่ฟอนต์ PDF ไม่มี |

{{ui:แบบขยาย}} เป็นสีเทาและกดไม่ได้: โมเดลยังไม่มีชิ้นส่วน

## ดาวน์โหลดไม่ปรากฏ

ทุกการบันทึกและการส่งออกเป็นการดาวน์โหลดของเบราว์เซอร์ ตรวจรายการดาวน์โหลดของเบราว์เซอร์ หากเบราว์เซอร์ถามก่อนดาวน์โหลดหลายไฟล์ หรือบล็อกการดาวน์โหลดจากเว็บไซต์นี้ ให้อนุญาต ใน Safari ให้ดูปุ่มดาวน์โหลดบนแถบเครื่องมือ

## ปุ่มคีย์บอร์ดไม่ทำงาน

- เคอร์เซอร์อยู่ในช่องข้อความหรือตัวเลข คีย์เครื่องมือและ {{key:Delete}} จะถูกละเว้นตรงนั้นเพื่อให้พิมพ์ได้ กด {{key:Tab}} หรือคลิกมุมมอง
- มีกล่องโต้ตอบเปิดอยู่: ปิดก่อน
- เบราว์เซอร์รับคีย์บอร์ดอยู่ (เช่น แถบที่อยู่): คลิกภายใน DetailCraft
- {{key:Ctrl+Shift+F}} ใช้ Control แม้บน Mac

## ปัญหาการใช้งานออฟไลน์

ปุ่ม {{ui:บันทึกสำหรับออฟไลน์}} ในแถบแอปจะแสดงสถานะของสำเนาออฟไลน์ วิธีการบันทึก: [การทำงานออฟไลน์](common:offline)

| ปุ่มแสดง | หมายความว่า | ควรทำอย่างไร |
|---|---|---|
| {{ui:บันทึกสำหรับออฟไลน์}} | ยังไม่มีสำเนาออฟไลน์ในเบราว์เซอร์นี้ | เลือกขณะออนไลน์ |
| กำลังบันทึก 5 จาก 20 | กำลังบันทึกอยู่ | รอให้ขึ้น {{ui:พร้อมใช้ออฟไลน์}} และเปิดแท็บค้างไว้ |

## งานที่ยังไม่ได้บันทึก

หากเบราว์เซอร์ถามว่าจะออกจากหน้าหรือไม่ แสดงว่า DetailCraft มีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก เลือกอยู่ต่อ แล้วกด {{key:Mod+S}} DetailCraft กู้โมเดลคืนไม่ได้หลังจากปิดแท็บ

## ยังติดขัดอยู่
