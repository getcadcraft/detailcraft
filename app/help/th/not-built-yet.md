DetailCraft เป็นเวอร์ชันเริ่มต้น หน้านี้แสดงสิ่งที่ยังทำไม่ได้ เพื่อให้คุณวางแผนรอบข้อจำกัดได้ ไม่มีสิ่งใดในหน้านี้เป็นคำสัญญาเรื่องวันที่

## การเชื่อมต่อ

DetailCraft สร้างการเชื่อมต่อได้หกแบบ: แผ่นยึดค้ำยัน (gusset) (ดู [แผ่นยึดค้ำยัน](topic:brace-gussets)); การต่อด้วยสลักเกลียวระหว่างชิ้นสองชิ้นของ I-shape เดียวกัน (ดู [การต่อ](topic:splices)); รอยต่อตัดมุม (mitre) ระหว่าง I-shape สองชิ้นที่มาบรรจบกันเป็นมุม ตัดอย่างเดียว หรือพร้อมแผ่นปลายยึดด้วยสลักเกลียว (ดู [รอยต่อตัดมุม (mitre)](topic:mitres)); แผ่นปลายยึดด้วยสลักเกลียวแบบเรียบหรือยื่น จากคาน I-shape ที่วางตรงในระดับ ไปยังปีกหรือเอวของเสา I-shape; แผ่นเฉือน (shear tab) จากคาน (มุมฉาก เอียง หรือลาดเอียง) ไปยังปีกหรือเอวของเสา; และแผ่นฐานเสาพร้อมเหล็กยึดฐานสี่เส้น

| ยังไม่มี | วิธีทำแทนในตอนนี้ |
|---|---|
| แผ่นปลายที่เอียงหรือลาดเอียง | ใช้ [แผ่นเฉือน (shear tab)](topic:shear-tabs) ซึ่งรองรับคานเอียงและลาดเอียง |
| มุมยึด (clip angle); แผ่นเติมรอยต่อและการต่อระหว่างขนาดต่างกัน; แผ่นยึดมุมที่เชื่อมกับคานและเสา; แผ่นยึดชัมเฟอร์ | เขียนรายละเอียดในซอฟต์แวร์อื่น หรือเพิ่มแผ่นและรูด้วยมือเป็นชิ้นแยก ดู [การต่อ](topic:splices), [แผ่นยึดค้ำยัน](topic:brace-gussets) |
| แผ่นเสริมแข็งแบบชัมเฟอร์หรือเรียวของแผ่นฐาน; รูกราวต์; ช่องฐานรากสำหรับ shear lug | แผ่นเสริมแข็งสี่เหลี่ยม ดู [แผ่นฐาน](topic:base-plates) |
| ฮันช์ (haunch); รอยตัดมุมที่เชื่อมแบบชนกัน; แผ่นเสริมแข็งที่อยู่ในแนวเดียวกับปีกของชิ้นส่วนอีกด้าน | [รอยตัดมุม](topic:mitres) พร้อมแผ่นปลายและแผ่นเสริมเอว หรือรอยตัดมุมธรรมดา เพิ่มแผ่นอื่นด้วยมือเป็นชิ้นแยก |
| การตรวจการออกแบบการเชื่อมต่อ (ความแข็งแรง) | ตรวจการเชื่อมต่อด้วยการคำนวณของวิศวกรคุณ DetailCraft เตือนเฉพาะระยะขอบและระยะห่าง |
| รูยาว (slotted) | รูกลมเท่านั้น |

## การวิเคราะห์

| ยังไม่มี | วิธีทำแทนในตอนนี้ |
|---|---|
| การตรวจการออกแบบนอกเหนือจาก I-shape เหล็ก: ท่อ มุม ช่อง รูปร่างเชื่อม ชิ้นส่วนเพรียวหรือ class 4 การบิด การเชื่อมต่อ; คอนกรีต: ความชะลูดจากการโยก การบิด รายละเอียดแผ่นดินไหว พื้นและผนัง | แท็บ {{ui:Analysis}} ตรวจ I-shape เหล็กตาม AISC 360 หรือ EN 1993-1-1 ([ตรวจชิ้นส่วนเหล็กตามมาตรฐานการออกแบบ](topic:design-checks)) ส่วนที่เหลือจะถูกทำเครื่องหมายว่า "ยังไม่ได้ตรวจ" และวิศวกรควรตรวจทั้งหมด |
| การวิเคราะห์การโก่งเดาะ การสั่น | ลำดับที่สอง (second order) เป็น P-Delta เท่านั้น (ยืดหยุ่น) ไม่มีการวิเคราะห์การโก่งเดาะ (modal, response spectrum, time history และ pushover อยู่ในแท็บการวิเคราะห์) |
| การตรวจการออกแบบที่วิศวกรตรวจทานแล้ว | จนกว่าจะถึงตอนนั้น ผลเป็นเพียงตัวช่วย ตรวจชิ้นส่วนสองหรือสามชิ้นด้วยมือหรือในซอฟต์แวร์ของวิศวกรคุณก่อนนำไปใช้ |
| การคำนวณน้ำหนักพื้น ลม และหิมะจากพื้นที่ให้โดยอัตโนมัติ | ใส่น้ำหนักบนชิ้นส่วนด้วยมือ เป็น kN/m หรือ kN |
| ระยะชดเชยของชิ้นส่วน จุดต่อที่ไม่ตรงศูนย์ ค้ำยันรับแรงดึงอย่างเดียว แผ่นและฐานรากในโครงสร้าง | ชิ้นส่วนถูกวิเคราะห์บนเส้นทำงาน ค้ำยันรับทั้งแรงดึงและแรงอัด |

| เหล็กเมตริกนอกเหนือจาก BS 4449 H8–H40 (เช่น CSA 10M–35M) | ชื่อ ASTM soft-metric #10–#36 หรือเหล็ก BS |

## แพลตฟอร์ม

- DetailCraft ออกแบบมาสำหรับหน้าจอเดสก์ท็อป แล็ปท็อป หรือแท็บเล็ต ใช้บนโทรศัพท์ได้ด้วย: โมเดลยังอยู่บนหน้าจอ และรายงานเปิดเป็นแผ่นจากแถบด้านล่าง แต่พื้นที่ของพาเนลมีน้อย
- การใช้งานออฟไลน์ต้องบันทึก DetailCraft สำหรับออฟไลน์ก่อน ด้วย {{ui:Save for offline}} ในแถบแอป เมื่อแสดง {{ui:Offline ready}} ทุกอย่างในเวอร์ชันนี้ทำงานได้โดยไม่มีการเชื่อมต่อ ดู [ทำงานแบบออฟไลน์](common:offline)

หากข้อจำกัดข้อใดขัดขวางงานของคุณ แจ้งให้เราทราบผ่าน[หน้าสนับสนุน](https://getcadcraft.com/support) ซึ่งช่วยให้เราตัดสินใจว่าจะสร้างอะไรต่อไป
