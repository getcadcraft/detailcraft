วิธีเขียนปุ่มในคู่มือนี้: [ปุ่ม เมาส์ และทัชแพด](common:keys) บน Mac {{key:Mod}} คือปุ่ม Command ที่อื่นคือ Ctrl

## เครื่องมือ

ใช้ได้เมื่อเคอร์เซอร์ไม่อยู่ในช่องข้อความหรือช่องตัวเลข

| ปุ่ม | ทำอะไร |
|---|---|
| {{key:V}} | {{ui:เลือก}} |
| {{key:B}} | {{ui:คาน}} |
| {{key:C}} | {{ui:เสา}} |
| {{key:R}} | {{ui:ค้ำยัน}} |
| {{key:P}} | {{ui:แผ่น}} |
| {{key:F}} | {{ui:ฐานราก}} |
| {{key:S}} | {{ui:บันได}} |
| {{key:M}} | ย้ายที่เลือกโดยชี้จุดตัดกริดสองจุด ([เลือกด้วยหน้าต่าง ย้าย หมุน สะท้อน และเปลี่ยนหลายรายการ](topic:select-and-change)) |
| {{key:Esc}} | ปล่อยหน้าต่างเลือกที่กำลังลาก หรือส่งชิ้นส่วนที่ลากกลับไปที่เดิม ยกเลิกการย้าย จุดแรกของคาน ค้ำยัน หรือแผ่น หรือการวาง กดอีกครั้งเพื่อกลับไป {{ui:เลือก}} ใน {{ui:เลือก}} ให้ล้างที่เลือก เมื่อเมนู {{ui:เพิ่มเติม}} เปิดอยู่ ให้ปิดเมนู |
| {{key:Delete}} หรือ {{key:Backspace}} | ลบที่เลือก (ทุกอย่างที่เลือก ในขั้นเลิกทำขั้นเดียว) |

## ไฟล์และการแก้ไข

| ปุ่ม | ทำอะไร |
|---|---|
| {{key:Mod+S}} | บันทึกโมเดล (ดาวน์โหลด) ทำงานได้แม้กำลังพิมพ์ในช่อง |
| {{key:Mod+O}} | เปิดโมเดล ทำงานได้แม้กำลังพิมพ์ในช่อง |
| {{key:Mod+Z}} | เลิกทำ (นอกช่องข้อความ; ในช่องข้อความจะเลิกทำการพิมพ์) |
| {{key:Mod+Y}} หรือ {{key:Mod+Shift+Z}} | ทำซ้ำ |

## คัดลอกและวาง

ใช้ได้เมื่อเคอร์เซอร์ไม่อยู่ในช่องข้อความหรือช่องตัวเลข (ตรงนั้นจะคัดลอก วาง และเลือกข้อความตามปกติ) การวาง ตัด ทำสำเนา หรือลบแต่ละครั้งเป็นหนึ่งขั้นเลิกทำ เพิ่มเติม: [คัดลอก วาง และทำสำเนา](topic:copy-paste)

| ปุ่ม | ทำอะไร |
|---|---|
| {{key:Mod+C}} | {{ui:คัดลอก}} ชิ้นโครงสร้างและฐานรากที่เลือก (พร้อมรู คอป และการเชื่อมต่อ) |
| {{key:Mod+X}} | {{ui:ตัด}}: คัดลอกที่เลือกแล้วลบ |
| {{key:Mod+V}} | {{ui:วาง}}: สำเนาจะตามตัวชี้ คลิกจุดตัดกริดเพื่อวางที่นั่น |
| {{key:Mod+Shift+V}} | {{ui:วางที่เดิม}}: ที่พิกัดที่คัดลอกมา |
| {{key:Mod+D}} | {{ui:ทำสำเนา}}: ทำสำเนาทันที เลื่อนตามค่าออฟเซ็ตใน[การตั้งค่า DetailCraft](topic:settings) |
| {{key:Mod+A}} | {{ui:เลือกทั้งหมด}}: ทุกชิ้นโครงสร้าง การเชื่อมต่อ และฐานราก |
| {{key:Esc}} | {{ui:ยกเลิกการเลือก}} |

หากเลือกข้อความในหน้า (เช่นในตารางรายงาน) และไม่มีอะไรในโมเดล {{key:Mod+C}} จะคัดลอกข้อความตามปกติ

{{ui:ใหม่}}, {{ui:ตัวอย่าง}} และการส่งออกไม่มีปุ่มลัด ใช้แถบเครื่องมือแทน

ปุ่มเหล่านี้ไม่ทำงานเมื่อมีกล่องโต้ตอบ (ตัวอย่างแบบขยายหรือคำถาม) เปิดอยู่

## ช่องและพาเนล

| ปุ่ม | ทำอะไร |
|---|---|
| {{key:Enter}} หรือ {{key:Tab}} | นำค่าที่พิมพ์ไปใช้ (การเปลี่ยนแปลงแต่ละครั้งเป็นหนึ่งขั้นเลิกทำ) |
| {{key:Enter}} ในช่องของ {{ui:กริด}}, {{ui:ระดับ}}, {{ui:หน้าตัดที่กำหนดเอง}}, รู หรือคอป | เหมือนกับการเลือกปุ่มของฟอร์มนั้น |
| {{key:Left}} {{key:Right}} | เลื่อนระหว่างแท็บ {{ui:ปัญหา}}, {{ui:รายการวัสดุ}} และ {{ui:ตารางการดัด}} เมื่อแท็บมีโฟกัส |
| {{key:Esc}} | ปิดตัวอย่างแบบขยายหรือกล่องโต้ตอบคำถาม (เหมือน {{ui:ยกเลิก}}) |

## หน้าจอและความช่วยเหลือ

| ปุ่ม | ทำอะไร |
|---|---|
| {{key:Ctrl+Shift+F}} | วนระหว่างโหมดปกติ เต็มหน้าจอ และเต็มหน้าจอโดยซ่อนแถบ ใช้ Control บนทุกเครื่อง รวมถึง Mac |
| {{key:Mod+,}} | เปิด {{ui:การตั้งค่า}} ([การตั้งค่า DetailCraft](topic:settings)) |
| {{key:Esc}} | ออกจากโหมดเต็มหน้าจอ |
| {{key:F1}} | เปิดคู่มือนี้ |

## เมาส์

| การทำงาน | ใน 3D | ใน {{ui:ผัง}} และ {{ui:รูปด้าน}} |
|---|---|---|
| คลิก | เลือกชิ้นส่วน หรือวางที่จุดตัดที่ใกล้ที่สุดเมื่อเปิดเครื่องมือวาง (หรือวางตรงนั้นขณะวาง) | เหมือนกัน |
| {{key:Shift}}, {{key:Ctrl}} หรือ {{key:Mod}} แล้วคลิก | เพิ่มชิ้นส่วนเข้าที่เลือก หรือเอาออก | เหมือนกัน |
| กดบนชิ้นส่วนที่เลือกแล้วลาก | ย้ายที่เลือกข้ามระดับ ถือ {{key:Mod}} ไว้เพื่อย้ายขึ้นและลง | ย้ายที่เลือก (ในรูปด้าน: ไปตามแนวและขึ้นลง) |
| ลากด้วยปุ่มซ้าย | หมุนโมเดล เมื่อใช้ {{ui:เลือก}}: หน้าต่างเลือก (ไปทางขวา: อยู่ภายในทั้งหมด; ไปทางซ้าย: แตะ) ขณะวาง: แพน | เมื่อใช้ {{ui:เลือก}}: หน้าต่างเลือก (ไปทางขวา: อยู่ภายในทั้งหมด; ไปทางซ้าย: แตะ) ขณะวาง: แพน |
| {{key:Shift}} แล้วลากด้วยปุ่มซ้าย | เมื่อใช้ {{ui:เลือก}}: หน้าต่างเลือก เพิ่มเข้าที่เลือก ขณะวาง: แพน | เมื่อใช้ {{ui:เลือก}}: หน้าต่างเลือก เพิ่มเข้าที่เลือก |
| {{key:Ctrl}} หรือ {{key:Mod}} แล้วลากด้วยปุ่มซ้าย | แพน | ไม่มี |
| ลากด้วยปุ่มขวา | แพน | แพน |
| ล้อ | ซูมเข้าหาจุดกึ่งกลางของมุมมอง | ซูม |
| ลากด้วยปุ่มกลาง | ซูม | เมื่อใช้ {{ui:เลือก}}: แพน มิฉะนั้นซูม |
| วางไฟล์ `.detailcraft.json` ลงในแอป | เปิดไฟล์ | เปิดไฟล์ |

การคลิกจะนับเมื่อตัวชี้เคลื่อนที่น้อยกว่าประมาณ 5 พิกเซลระหว่างกดและปล่อย การเคลื่อนที่ที่ยาวกว่านั้นเป็นการลาก

## ทัชแพด

| การทำงาน | ผล |
|---|---|
| ปัดสองนิ้วขึ้นหรือลง หรือหยิก | ซูม |
| กดแล้วลาก | หมุน (3D) หรือแพน ({{ui:ผัง}} และ {{ui:รูปด้าน}}) |
| {{key:Shift}} แล้วกดและลาก | แพนใน 3D |
| คลิกสองนิ้ว | คลิกขวา (ไม่มีเมนูในมุมมอง) |

## สัมผัส

บนแท็บเล็ตหรือหน้าจอสัมผัส:

| การทำงาน | ผล |
|---|---|
| แตะ | เลือกชิ้นส่วน หรือวางที่จุดตัดกริดที่ใกล้ที่สุดเมื่อเปิดเครื่องมือวาง (การแตะในระยะประมาณความกว้างของนิ้วนับเป็นการแตะ) |
| กดค้างที่ชิ้นส่วน | เพิ่มเข้าที่เลือก หรือเอาออก (สิ่งที่ {{key:Shift}}+คลิกทำด้วยเมาส์) |
| นิ้วเดียวบนชิ้นส่วนที่เลือก แล้วลาก | ย้ายที่เลือก โดยดูดเข้าจุดตัดกริด |
| นิ้วเดียวที่อื่น | หมุนโมเดล (3D) หรือแพน ({{ui:ผัง}} และ {{ui:รูปด้าน}}) |
| สองนิ้ว | หยิกเพื่อซูม เลื่อนไปด้วยกันเพื่อแพน |

ปุ่ม รายการ และช่องจะใหญ่ขึ้นเมื่อหน้าจอรองรับการสัมผัสอย่างเดียว หน้าต่างเลือกต้องใช้เมาส์ เมื่อใช้นิ้ว ให้แตะและกดค้าง

## ปุ่มที่เบราว์เซอร์เก็บไว้

ทางลัดบางอย่างเป็นของเบราว์เซอร์ และไม่มีหน้าเว็บใดใช้ได้ เช่น {{key:Mod+W}} (ปิดแท็บ) {{key:Mod+T}} (แท็บใหม่) และ {{key:Mod+N}} (หน้าต่างใหม่) หาก {{key:Mod+Y}} เปิดประวัติของเบราว์เซอร์แทนการทำซ้ำ ให้ใช้ {{key:Mod+Shift+Z}}

ทางลัดจะไปถึง DetailCraft ก็ต่อเมื่อหน้าเว็บมีคีย์บอร์ดอยู่ หากปุ่มไม่ทำงาน หรือเบราว์เซอร์ทำงานแทน ให้คลิกส่วนว่างของหน้าต่าง DetailCraft ก่อน (เช่นหลังพิมพ์ในแถบที่อยู่)

## คำสั่งย้ายอยู่ที่ไหน

ไม่มีคำสั่งย้าย: เลือกชิ้นส่วนแล้วลากข้ามระดับ (ถือ {{key:Mod}} ไว้เพื่อลากขึ้นและลง) หรือแก้ไข {{ui:เริ่ม}} และ {{ui:สิ้นสุด}} ใน {{ui:คุณสมบัติ}}
