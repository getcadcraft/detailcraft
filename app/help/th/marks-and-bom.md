DetailCraft กำหนดเครื่องหมายให้โมเดลเอง ไม่มีคำสั่งกำหนดหมายเลขและไม่ต้องรันอะไร หลังทุกการเปลี่ยนแปลง DetailCraft จะคำนวณว่าชิ้นส่วนใดคือเหล็กชิ้นเดียวกัน และให้เครื่องหมายเดียวกัน

## เครื่องหมายแสดงที่ไหนบ้าง

- รายการ {{ui:เครื่องหมายชิ้นส่วน}} ในพาเนล {{ui:โมเดล}}: แต่ละเครื่องหมายพร้อมหน้าตัด ความยาว และจำนวน คลิกหนึ่งรายการเพื่อเลือกชิ้นส่วนแรกที่มีเครื่องหมายนั้น
- พาเนล {{ui:คุณสมบัติ}} ของสมาชิกที่เลือก (และรายการ **เครื่องหมายชิ้นส่วน** ในพาเนลซ้าย): {{ui:เครื่องหมายชิ้นส่วน}} และ {{ui:ชุดประกอบ}} หัวข้อพาเนลจะแสดงเครื่องหมายด้วย เช่น "คาน b1"
- แท็บ {{ui:รายการวัสดุ}} ไฟล์ CSV ชื่อไฟล์ NC แบบขยาย และการส่งออก IFC (เป็นป้ายของแต่ละองค์ประกอบ)

## เครื่องหมายชิ้นส่วนกำหนดอย่างไร

- **เครื่องหมายชิ้นส่วน:** c สำหรับเสา b สำหรับคาน br สำหรับค้ำยัน st สำหรับลำตงบันได p สำหรับแผ่น (รวมแผ่นปลายและแผ่นฐาน) แล้วตามด้วยตัวเลข เช่น c1, c2, b1, p1 … เมื่อชิ้นส่วนอยู่มากกว่าหนึ่งเฟส หมายเลขเฟสจะมาก่อน เช่น 2-b1
- **เครื่องหมายชุดประกอบ:** C, B, BR หรือ P ชุดประกอบคือสมาชิกหลักและแผ่นที่เชื่อมติดกับมัน เช่น คานพร้อมแผ่นปลายทั้งสองข้าง หรือเสาพร้อมแผ่นฐาน
- ชิ้นส่วนสองชิ้นจะมีเครื่องหมายเดียวกันเมื่อมีหน้าตัด วัสดุ และความยาวตัดเท่ากัน และมีรูกับการตัดมุมเหมือนกัน ทั้งหมดภายใน 1 mm แม้ชิ้นหนึ่งจะหมุนกลับหัวหรือกลับด้านเมื่อเทียบกับอีกชิ้น
- การกำหนดหมายเลขเรียงเสาก่อน แล้วคาน ค้ำยัน และแผ่น ภายในแต่ละกลุ่มเรียงตามชื่อหน้าตัด แล้วยาวที่สุดก่อน

กฎทั้งหมด รวมถึงการหมุนที่นับสำหรับรางและเหล็กฉาก: [กฎเครื่องหมาย](topic:mark-rules)

:::warning
เครื่องหมายคำนวณใหม่ทุกครั้งหลังการเปลี่ยนแปลง ดังนั้นอาจกำหนดหมายเลขใหม่ได้ การเพิ่มชิ้นส่วน การเปลี่ยนหน้าตัด หรือการเพิ่มรู อาจทำให้ b3 กลายเป็น b4 ให้ถือว่าเครื่องหมายเป็นค่าสุดท้ายเมื่อโมเดลเสร็จแล้วเท่านั้น และทำ BOM ไฟล์ NC และแบบขยายจากโมเดลที่บันทึกแล้วชุดเดียวกัน
:::

## อ่านรายการวัสดุ

เปิดแท็บ {{ui:รายการวัสดุ}} ที่ด้านล่าง มีสามตาราง

**ชิ้นส่วน** พร้อมน้ำหนักเหล็กรวมในหัวข้อ:

| คอลัมน์ | ความหมาย |
|---|---|
| เครื่องหมายชิ้นส่วน | คลิกเพื่อเลือกชิ้นส่วนแรกที่มีเครื่องหมายนี้ |
| ประเภท | คาน เสา ค้ำยัน ลำตงบันได หรือแผ่น |
| หน้าตัด | เช่น W16x26 หรือ PL20x180 |
| วัสดุ | เกรดที่คุณตั้งไว้ |
| ความยาว (mm) | ความยาวตัดหลังการต่อ |
| จำนวน | จำนวนชิ้น |
| น้ำหนักต่อหน่วย (kg) | มวลของหน้าตัดต่อเมตร × ความยาว |
| น้ำหนักรวม (kg) | น้ำหนักต่อหน่วย × จำนวน |

แถวสุดท้ายให้จำนวนและน้ำหนักรวม

**ชุดประกอบ:** แต่ละเครื่องหมายชุดประกอบ ชิ้นส่วนหลัก ชิ้นส่วนทั้งหมด (เช่น "b1 + p1 + p1") จำนวน น้ำหนักต่อหน่วย และน้ำหนักรวม

**สลักเกลียวและสลักยึด:** จัดกลุ่มตามชนิด เส้นผ่านศูนย์กลาง ความยาว และเกรด พร้อมจำนวน

:::note
น้ำหนักเป็นน้ำหนักรวม รูและการตัดมุมไม่ได้หักออก สลักเกลียว น็อต แหวนรอง และแนวเชื่อมไม่ได้รวมอยู่ในน้ำหนักเหล็ก
:::

## ดาวน์โหลด

เลือก {{ui:ดาวน์โหลด CSV}} ในแท็บ หรือ {{ui:BOM}} ในกลุ่ม {{ui:ผลลัพธ์}} ไฟล์ `<name> BOM.csv` เก็บตารางทั้งสามต่อกัน แต่ละตารางมีหัวข้อของตัวเอง และคั่นด้วยบรรทัดว่าง เปิดได้ด้วยโปรแกรมสเปรดชีตใดก็ได้

## ตรวจก่อนส่ง

1. เปิดแท็บ {{ui:ปัญหา}} แล้วแก้ทุกบรรทัด การต่อที่สร้างไม่ได้จะไม่เพิ่มแผ่น รู หรือสลักเกลียว ทำให้ BOM ขาด
2. มองหาเครื่องหมายที่คุณไม่คาดคิด คานสองชิ้นที่คุณคิดว่าเหมือนกันแต่มีเครื่องหมายต่างกัน มักต่างกันที่รู การตัดมุม หรือความยาวตัด ให้เลือกแต่ละชิ้นแล้วเปรียบเทียบ
3. บันทึกโมเดล แล้วส่งออกทุกอย่างจากสถานะที่บันทึกนั้น
