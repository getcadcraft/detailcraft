## Kopyalama və yapışdırma

Bunlar kursor mətn və ya rəqəm sahəsində olmadıqda işləyir (orada mətni adi qaydada kopyalayır, yapışdırır və seçirsiniz). Hər yapışdırma, kəsmə, surət çıxarma və ya silmə bir geri qaytarma addımıdır. Ətraflı: [Kopyalama, yapışdırma və surət çıxarma](topic:copy-paste).

| Düymə | Nə edir |
|---|---|
| {{key:Mod+C}} | {{ui:Kopyala}} seçilmiş elementləri və bünövrələri (deşikləri, kəsikləri və birləşmələri ilə birlikdə) |
| {{key:Mod+X}} | {{ui:Kəs}}: seçimi kopyalayın, sonra silin |
| {{key:Mod+V}} | {{ui:Yapışdır}}: surət göstəricini izləyir; onu yerləşdirmək üçün şəbəkə kəsişməsinə klik edin |
| {{key:Mod+Shift+V}} | {{ui:Yerində yapışdır}}: kopyalandığı koordinatlarda |
| {{key:Mod+D}} | {{ui:Surət çıxar}}: dərhal surət, [DetailCraft parametrlərində](topic:settings) göstərilən ofset qədər köçürülmüş |
| {{key:Mod+A}} | {{ui:Hamısını seç}}: hər element, birləşmə və bünövrə |
| {{key:Esc}} | {{ui:Heç nəyi seçmə}} |

Səhifədə mətn seçmisinizsə (məsələn hesabat cədvəlində) və modeldə heç nə seçilməyibsə, {{key:Mod+C}} mətni adi qaydada kopyalayır.

{{ui:Yeni}}, {{ui:Nümunə}} və ixrac əməliyyatlarının düymələri yoxdur; alətlər panelindən istifadə edin.

Dialoq (istehsal çertyojunun önizləməsi və ya sual) açıq olduqda bu düymələrin heç biri işləmir.

## Siçan

| Əməliyyat | 3D-də | Planda və Fasadda |
|---|---|---|
| Klik | Detalı seçin, ya da yerləşdirmə aləti aktiv olduqda ən yaxın kəsişmədə yerləşdirin (surət yapışdırarkən də orada yapışdırın) | Eyni |
| {{key:Shift}}, {{key:Ctrl}} və ya {{key:Mod}} və klik | Detalı seçimə əlavə edin və ya seçimdən çıxarın | Eyni |
| Seçilmiş detalın üstünə basın və sürükləyin | Seçimi səviyyə boyunca köçürün; {{key:Mod}} basılı olduqda yuxarı və aşağı | Seçimi köçürün (fasadda: boyunca, yuxarı və aşağı) |
| Sol düymə ilə sürükləyin | Modeli fırladın | {{ui:Seç}} ilə: seçim pəncərəsi (sağa: tamamilə daxildə; sola: toxunan). Yerləşdirərkən: sürüşdürün |
| {{key:Shift}} və sol düymə ilə sürükləyin | {{ui:Seç}} ilə: seçimə əlavə olunan seçim pəncərəsi. Yerləşdirərkən: sürüşdürün | {{ui:Seç}} ilə: seçimə əlavə olunan seçim pəncərəsi |
| {{key:Ctrl}} və ya {{key:Mod}} və sol düymə ilə sürükləyin | Sürüşdürün | Heç nə |
| Sağ düymə ilə sürükləyin | Sürüşdürün | Sürüşdürün |
| Təkər | Miqyası görünüşün ortasına doğru dəyişin | Miqyas |
| Orta düymə ilə sürükləyin | Miqyas | {{ui:Seç}} ilə: sürüşdürün. Əks halda miqyas |
| `.detailcraft.json` faylını tətbiqə atın | Açın | Açın |

Klik yalnız göstərici basılma və buraxılma arasında təxminən 5 piksel hərəkət etdikdə sayılır; daha uzun hərəkət sürükləmədir.

## Toxunuş

Planşet və ya toxunuş ekranında:

| Əməliyyat | Nə edir |
|---|---|
| Toxunma | Detalı seçin, ya da yerləşdirmə aləti aktiv olduqda ən yaxın şəbəkə kəsişmədə yerləşdirin (ona təxminən bir barmaq enində toxunma sayılır) |
| Detalın üstündə uzun basma | Seçimə əlavə edin və ya seçimdən çıxarın ({{key:Shift}}+klikin siçanla etdiyi kimi) |
| Seçilmiş detalın üstündə bir barmaq, sonra sürükləmə | Seçimi köçürün, şəbəkə kəsişmələrinə yapışdırın |
| Başqa yerdə bir barmaq | Modeli fırladın (3D) və ya sürüşdürün (Plan və Fasad) |
| İki barmaq | Miqyas üçün sıxın, birlikdə hərəkət etdirin isə sürüşdürün |

Ekran yalnız toxunuşludursa düymələr, siyahılar və sahələr daha böyük olur. Seçim pəncərələri siçan tələb edir; barmaqlarla toxunun və uzun basın.

## Brauzerin saxladığı düymələr

Bəzi qısayollar brauzerə aiddir və heç bir səhifə onları istifadə edə bilməz, məsələn {{key:Mod+W}} (sekməni bağla), {{key:Mod+T}} (yeni sekmə) və {{key:Mod+N}} (yeni pəncərə). Əgər {{key:Mod+Y}} təkrarlamaq əvəzinə brauzerin tarixçəsini açırsa, {{key:Mod+Shift+Z}} istifadə edin.

Qısayollar DetailCraft-a yalnız səhifədə klaviatura fokusu olduqda çatır. Əgər düymə heç nə etmirsə və ya onu brauzer icra edirsə, əvvəlcə DetailCraft pəncərəsinin boş hissəsinə klik edin (məsələn ünvan sətirinə yazdıqdan sonra).

## Köçürmə harada yerləşir

Köçürmə əmri yoxdur: detalı seçin və səviyyə boyunca sürükləyin ({{key:Mod}} basıb yuxarı və aşağı sürükləyin), ya da {{ui:Başlanğıc}} və {{ui:Son}} dəyərlərini {{ui:Xüsusiyyətlər}} panelində redaktə edin.
