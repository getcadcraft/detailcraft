Негізгі пластина қосылысы бағанның астына пластина қояды, бағанды пластина қалыңдығына қысқартады, екеуін дәнекерлейді және пластинадағы тесіктер арқылы төрт анкерлік шпилька қосады.

:::warning
Өлшемдер бастапқы мәндер, жобалау емес. DetailCraft тіреу қысымын, шпилька беріктігін және бетонға енуін тексермейді.
:::

## Негізгі пластина қосу

1. {{ui:Таңдау}} ({{key:V}}) құралын таңдап, бағанды басыңыз. Ол тік болуы керек.
2. {{ui:Қосу}} тобындағы {{ui:Негіз пластинасы}} немесе {{ui:Қасиеттер}} панеліндегі {{ui:Негізгі пластина қосу}} таңдаңыз.
3. Күй жолағында «Төрт анкерлік шпилькасы бар негізгі пластина қосылды.» деп жазылады. Жаңа қосылыс таңдалады.

Бағанда бір ғана негізгі пластина болуы мүмкін. Оның пластинасы бар болса, күй жолағында «Бұл бағанда негізгі пластина бар.» деп жазылады.

## Өзгерту

Негізгі пластинаны таңдаңыз (пластинаны немесе шпилькасын басыңыз). {{ui:Пластина, болттар және дәнекерлеу (мм)}} астында:

| Параметр | Әдепкі мән | Не істейді |
|---|---|---|
| Пластина қалыңдығы | 25 | Баған осы мөлшерге қысқартылады |
| Пластина ұзындығы | 450 | Бағанның терендігі бойынша |
| Пластина ені | 400 | Баған бойынша көлденең |
| Шпилька диаметрі | 20 | Анкерлік шпильканың өлшемі |
| Тесік диаметрі | 33 | Пластинадағы тесік |
| Болт маркасы | F1554 Gr 36 | Шпилька маркасы, мәтін түрінде |
| Шпилька аралығы (терендік бойынша) | 350 | Шпилька центрлері арасында, пластина ұзындығы бойынша |
| Шпилька аралығы (көлденең) | 300 | Шпилька центрлері арасында, көлденең |
| Шпилька пластинадан шығыңқылығы | 100 | Пластина үстінен шпилька ұшына дейін |
| Шпилька пластина астынан енуі | 450 | Пластина астынан бетонға дейін |
| Бұрыштық дәнекерлеу өлшемі | 8 | Баған негізінің бойымен барлық жағынан |
| Пластина материалы | A36 | Мәтін |
| Құю саңылауы | 0 | Бетонның үстіңгі жағы мен пластина астының арасы |
| Қабырғалар | Жоқ | «Жоқ», 2 (қабырғаға параллель) немесе 4 (сонымен қатар оған перпендикуляр) таңдаңыз; төменді қараңыз |
| Қабырға қалыңдығы, биіктігі | 12, 150 | |
| Ығысу тірегінің терендігі | 0 | Тіреу пластина астына қаншаға дейін түседі; 0 = тірек жоқ |
| Ығысу тірегінің қалыңдығы, ені | 25, 150 | |
| Пластина шайбалары | Жоқ | Әр шпилькада, немесе жоқ |
| Шайба өлшемі, қалыңдығы | 0, 0 | 0 = шпилька үшін AISC Design Guide 1-ден ең аз мән |

Шпилька ұзындығы = бетонға енуі + құю саңылауы + пластина қалыңдығы + шығыңқылығы. Әдепкі мәндерде бұл 575 мм.

## Негіз бөлшектері: құю, қабырғалар, ығысу тірегі, шайбалар

Төртеуі де жаңа негізгі пластинада, сондай-ақ DetailCraft 0.4 нұсқасынан бұрын жасалған модельдердегі негізгі пластиналарда өшірулі.

- **Құю саңылауы.** Пластина бетонның үстінен осы қашықтықта орналасады, ал шпилькалар сонша ұзарады. AISC Design Guide 1 (2.10) бітірілген еденде 1 in., іргетас немесе тірек бағанда 1½–2 in. ұсынады; үлкен пластиналар мен ығысу тірегі бар пластиналар үшін одан да көп.
- **Қабырғалар.** Бағанға және пластинаға дәнекерленген тік пластиналар, баған бетінен пластина шетіне дейін, тіктөртбұрыш түрінде (әзірге қиғаштау немесе конустау жоқ). **2** қабырғасы қапталдағы бағанның қабырғасымен бір түзуде, әр фланецтен тыс тұрады; **4** қосымша екеуін қабырғаға перпендикуляр, фланецтер арасында, пластина қырларына дейін қосады. Құбырлы бағанда олар әр бет ортасында тұрады. Әрқайсысы бағанға және пластинаға екі жағынан дәнекерленеді.
- **Ығысу тірегі.** Негізгі пластина астында, баған терендігі бойынша, ортасында барлық жағынан дәнекерленген пластина. DetailCraft оның терендігі құю саңылауынан артық болмаса ескертеді. Іргетастағы ойықты қиып алмайды, сондықтан [қақтығысты тексеру](topic:clash-check) тіректі және іргетасты осы себепті алып тастайды.
- **Пластина шайбалары.** Әр шпилькаға негізгі пластинаға қойылған квадрат пластина шайба, бағанның жинағында бос (бағанмен бірге жеткізіледі, дәнекерленбейді: Design Guide 1, 2.6). Өлшемі мен қалыңдығы 0 болғанда DetailCraft шпилька үшін AISC Design Guide 1, 2-басылым, 2.3 кестесінен ең аз шайбаны алады; метрлік шпилька келесі дюймдік өлшемді алады (M20 шпилькасы 7/8 in. жолын алады: 2½ in. × 5/16 in.). Қасиеттер панелі қолданылған өлшемді көрсетеді. Шайбаның тесігі шпилька диаметрі + 1/16 in.: бұл DetailCraft таңдауы, кестеде мұндай мән берілмеген. Шпильканың шығыңқылығы шайба қалыңдығы + шпилька диаметрінен аз болғанда (шайба мен гайка үшін жеткіліксіз), DetailCraft ескертеді.

Design Guide 1-дің 2.3 кестесі пластинадағы шпилька тесігін де ұсынады: ¾ in. шпилька үшін 1-5/16 in., ⅞ in. үшін 1-9/16 in., 1 in. үшін 1-13/16 in. DetailCraft тесік өлшеміңізді өзгертпейді.

Шпилька тесіктері пластина шетіне тесік диаметрінің 1.2 × мәнінен жақын болғанда, шпилькалар баған контурының ішіне түскенде немесе пластина бағаннан кіші болғанда да ескертулер шығады.

## Негізгі пластинаны ұқсас бағандарға көшіру

1. Негізгі пластинаны таңдаңыз.
2. {{ui:Ұқсастарға қолдану (n)}} құралын таңдаңыз, немесе {{ui:Қосу}} тобының {{ui:Тағы}} мәзіріндегі {{ui:Ұқсас}} тармағын таңдаңыз.
3. Бірдей профильді, негізгі пластинасы жоқ және басқа бағанға тірелмеген әр тік баған көшірме алады.

## Негізгі пластиналар мен іргетастар

Негізгі пластинаға іргетас керек емес, ал іргетас үстіндегі негізгі пластинаны білмейді: анкерлік шпилькалар іргетас арматурасына байланбайды. Іргетастарды {{ui:Іргетас}} арқылы орналастырыңыз; [арматурамен іргетастарды орналастыру](topic:footings-and-rebar) бөлімін қараңыз.
