IFCのエクスポートは、モデル全体を1つのIFC4ファイルとして書き出します。このファイルは、BIMソフトウェアおよびIFCビューアーで開けます。

## エクスポート

1. {{ui:出力}}グループの{{ui:IFC}}を選びます。
2. ブラウザーが`<name>.ifc`をダウンロードします。ステータスバーに、含まれた内容が表示されます。例: 「IFC4をエクスポートしました: 25個の部材、88個の締結具、7個のフーチング、132本の鉄筋」。

モデルに部材、フーチング、鉄筋がない場合、ステータスバーに「まだエクスポートするものがありません。」と表示されます。

## ファイルに含まれるもの

| DetailCraftでの項目 | IFCファイルでの表現 |
|---|---|
| 各レベル | 建築物の階(IfcBuildingStorey)。1つのプロジェクト、敷地、建物の下に配置 |
| 通り芯 | 軸と符号を持つIfcGrid |
| 柱、梁、ブレース | IfcColumn、IfcBeam、IfcMember(ブレース)。それぞれ標準断面形状の押し出しで、実寸法を持つ |
| プレート、エンドプレート、ベースプレート | IfcPlate |
| 穴と切欠き | 部材から切り抜かれた開口(IfcOpeningElement) |
| 部材と溶接されたプレート | アセンブリ符号が付いたアセンブリ(IfcElementAssembly) |
| ボルトとアンカーボルト | 径と長さを持つIfcMechanicalFastener |
| フーチング | IfcFooting(独立フーチング)。材料としてコンクリートの記述を持つ |
| 各鉄筋 | 鉄筋符号、径、断面積、長さを持つIfcReinforcingBar。実際の中心線に沿って掃引され、曲げ部には実際の円弧がある |

各部材のタグは、その部材符号です。各要素には、符号、断面形状、重量を含む「DetailCraft」プロパティセットも含まれます。各要素は、その最下点以下にある最も高い階に配置されます。材料は等級ごとにグループ化されます。

## 再エクスポート用の安定したID

各要素のIFC ID(GlobalId)は、モデル名と、モデル内での要素自身のIDから算出されます。同じモデルを2回エクスポートするとIDは一致するため、バージョンを比較するソフトウェアで変更点を判別できます。

:::warning
モデル名を変更すると、すべてのIDが変わります。プロジェクトの発行ごとに、モデル名は同じままにしてください。
:::

## 確認

DetailCraftのIFCファイルは、テストスイート内の独立したIFCリーダーで読み戻して検証されています。プログラムによってIFCの読み方は異なるため、ファイルを頼りにする前に、チームが使用しているソフトウェアで開いて確認してください。CadCraftのBimCraftアプリでもIFCファイルを開けます。

## まだ対応していない機能

- IFCファイルからの接合、フーチング、鉄筋の読み込み。{{ui:IFC を読み込み}}は、梁、柱、部材、プレート、通り芯、レベル、穴、切欠き、ボルトを読み込み、対象外の項目を一覧表示します。
- 解析モデルまたは構造解析のデータ。
- IFC4のリファレンスビュー以外のもの。

## インポート

{{ui:ファイル}}グループの{{ui:IFC を読み込み}}(またはビューに`.ifc`ファイルをドロップ)で、IFC2X3またはIFC4ファイルから新しいモデルを作成します:

- **梁、柱、部材(ブレース)、プレート**のうち、本体がDetailCraftで認識できる1つの押し出し断面である要素。カタログの断面に一致させるか、カスタム断面として保持します。**通り芯**と**レベル**は、ファイルの通り芯と階から読み込まれます。
- **穴:** 取り込まれた部材の面に直角な、すべての円形の開口(取り込まれた部材に空洞を作るIfcOpeningElement)。H形鋼または溝形鋼のウェブまたはフランジ、鋼管の壁、プレート、山形鋼の脚が対象です。鋼管の両方の壁を貫通する穴は、1回だけ取り込まれます。
- **切欠き:** H形鋼または溝形鋼の一端から全幅にわたる長方形の開口で、上端から下方向、または下端から上方向に設けられます。
- **ボルト:** すべてのIfcMechanicalFastenerまたはIfcFastenerを、径、長さ、等級、種類(ボルトまたはアンカーボルト)とともに、**単独のボルト**として取り込みます。単独のボルトはビュー、部品表、IFCエクスポートに表示され、部材を移動しても位置は変わりません。何も選択されていない状態の{{ui:プロパティ}}パネルでは、単独のボルトの数が表示され、接合を代わりに追加する場合のために{{ui:単独のボルトを取り除く}}があります。

報告書には、それ以外の項目が種類ごとに、取り込まれなかった理由とともに一覧表示されます。壁とスラブ、フーチングと鉄筋、スロット付きの穴、丸形鋼管の穴、接合部(IFCファイルにはプレートとボルトは含まれますが、それらを生成したルールは含まれません)。
