質量は、公称断面積に 7850 kg/m³ を掛けたものです。半径と端部の突出長さは、BS 8666:2020 の最小寸法表の最小値です (旧来の直径は 2r です)。BS の鉄筋を使うフーチングには、フックの脚長として P を、切断長さには下記の BS 8666 の式を用います。設定で欧州の鋼材を選ぶと、新しいフーチングは C30/37 のコンクリートで、H16 の配筋層と H20 の差し筋から始まります。

## フック

ASTM の鉄筋: 標準の 90° フックは ACI 318-19 の表 25.3.1 によります。内側の曲げ直径は、#3 から #8 までは 6 db、#9 から #11 までは 8 db で、曲げの先に 12 db の直線部分を延長します。外法で測ったフックの脚長は、曲げ直径の半分 + db + 12 db です。

配筋層の鉄筋のフックが、かぶりの内側のフーチングの深さに収まらない場合、DetailCraft は脚長を収まるように短くし、警告を一覧に示します。

## 形状

DetailCraft は 3 種類の形状を保持します。加工帳では、これらを DetailCraft のコード、ACI 315 の型、または BS 8666 の形状コードで表示します。[DetailCraft の設定](topic:settings) ({{ui:鉄筋}}) で **加工帳の形状コード** を選択してください。

| コード | 形状 | 寸法 |
|---|---|---|
| S | 直線 | A = 長さ |
| L | 90° 曲げ 1 回 | A = 主脚、B = フックの脚、いずれも外法 |
| U | 同じ側の 90° 曲げ 2 回 | A = 中央部、B と C = 両脚、いずれも外法 |

{{ui:端部フック}} がオンの配筋層の鉄筋は U、オフの場合は S です。{{ui:下端のフック}} がオンの差し筋は L、オフの場合は S です。

| DetailCraft | BS 8666:2020 | ACI 315-99 (図 10) |
|---|---|---|
| S | 00、L = A | 型番なし |
| L | 11、L = A + B − 0.5r − d | 型番なし: 図には片側だけフックのある鉄筋がありません |
| U | 21、A と C が脚、B が中央、L = A + B + C − r − 2d | 型 2、フック A と G、直線 B |

BS 8666 または ACI 315 のコードを使う場合、加工帳の A、B、C の列は、その規格の記号に従います (U の中央部は B です)。

## 切断長さ

BS 4449 の鉄筋では、切断長さは鉄筋の形状コードに対応する BS 8666 の式 (上記) で求めます。ASTM の鉄筋では、鉄筋の中心線の正確な長さです。すなわち、直線部分と、曲げ部分を曲げ直径の半分に鉄筋径の半分を加えた半径の円弧として加えたものです。曲げ代の表から求めるわけではないため、それを使う加工帳とは数 mm の差が出ることがあります。

## 配置

- 下端の配筋層: L 方向の鉄筋が下段、B 方向の鉄筋がその上に載ります。各組は、かぶりの内側でフーチング全体に均等に配置され、指定した間隔以下で、少なくとも 2 本になります。
- 差し筋: 指定した間隔で L 方向および B 方向に並べた鉄筋の格子です。フーチングの中心に置かれ、配筋層の上に立ち、指定した突出長さだけ上端より上に突き出します。各フックは外側を向きます。

## チェック

| チェック項目 | 規則 | 結果 |
|---|---|---|
| 鉄筋の配置スペース | 両側のかぶりを除いた残りに鉄筋が収まる | 満たさない場合は作成できません |
| 2 層の深さ | 深さから 2 つのかぶりを引いた残りに両方の配筋層が収まる | 満たさない場合は作成できません |
| 差し筋の収まり | 差し筋の格子がかぶりの内側に収まる | 満たさない場合は作成できません |
| あき | 25.4 mm と db のうち大きい方以上 (ACI 318-19 25.2.1; 骨材の寸法は確認しない) | 警告 |
| フックの深さ | フックの脚がかぶりの内側の深さに収まる | 警告、脚長を短縮 |
| 差し筋のフック | フックがかぶりの外へ出ない | 警告 |

## 加工帳の列

{{ui:加工帳}} タブとその CSV には次の列があります: 鉄筋符号、サイズ、形状、A (mm)、B (mm)、C (mm)、本数、切断長さ (mm)、総延長 (m)、kg/m、1 本あたりの重量 (kg)、総重量 (kg)、用途。最終行には、本数、長さ、重量の合計が入ります。
