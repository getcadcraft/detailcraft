## 学べること

AI アシスタント（または利用者が作成したスクリプト）に DetailCraft を操作させる方法と、その操作範囲を決める方法を説明します。

DetailCraft には**独自の AI は含まれておらず**、どこにも情報を送信しません。アシスタントは利用者側で用意します。Model Context Protocol（MCP）に対応したプログラムであれば使用できます。DetailCraft はアシスタントにツールを提供するだけで、どのツールを使わせるかは利用者が選択します。

## 有効にする

1. {{ui:Settings}}（アプリバーの歯車、または {{key:Mod+,}}）を開き、{{ui:DetailCraft}} タブに移動します。
2. {{ui:Assistants}} で、**AI アシスタントとスクリプトに DetailCraft の使用を許可する** にチェックを入れます。初期状態ではオフです。
3. 許可する操作を選択します: **読み取り** は初期状態でオンです。**編集**、**保存**、**書き出し** は、必要なときだけオンにします。

チェックを入れていない権限のツールは、アシスタントに提供されません。アシスタントがそれでも要求した場合、DetailCraft は要求を拒否し、アクティビティログに記録します。スイッチをオフにすると、すべての接続が直ちに終了します。

## アシスタントを接続する

アシスタントは、このコンピューター上の **CadCraft Studio** を経由して接続します。Studio は、このコンピューターからのみアクセスできる小さなサーバーを起動します。このサーバーは、Studio の起動ごとに作成されるトークンで保護されます。Studio で {{ui:Connect an assistant}} を選択し、アドレスとトークンをアシスタントにコピーしてください（貼り付けに必要な正確な設定は Studio に表示されます）。トークンは決して共有しないでください。

:::note
ブラウザーのタブでは、アシスタント用の接続を開くことはできません。ブラウザー版のアプリでは、このコンピューター上の CadCraft Studio を使用するまで、スイッチは効果がありません。
:::

## 操作の主導権

- **すべての変更は1回の元に戻す操作として記録され**、アシスタントによる変更であることがラベルに表示されます（例: "Assistant: add beam"、"Assistant: add gussets"）。{{key:Mod+Z}} を押すと、アシスタントの最後の変更がまとめて元に戻ります。アシスタント自身の `undo` は、アシスタント自身の操作のみを元に戻し、利用者の変更は、明示的に要求された場合を除き元に戻しません。
- **利用者の操作が優先されます。** 部材の配置中、部材の移動中、または貼り付けの最中は、DetailCraft はアシスタントの変更を拒否し、再試行するよう通知します。
- **接続中かどうかがわかります。** 接続中は、アプリバーのボタンにアシスタント名が表示されます。そのボタンをクリックすると、許可されている操作を確認したり、**接続解除** を実行したりできます。
- **アクティビティ。** {{ui:Settings}} › {{ui:DetailCraft}} › {{ui:Assistants}} › {{ui:Activity}} に、すべての呼び出しが、日時、ツール、完了か拒否かとともに一覧表示されます。{{ui:Save the log}} でコピーを保存できます。

## アシスタントが要求できる内容

すべての長さはミリメートルです。座標は `[x, y, z]` の形式で、z 軸が上向きです（モデルと同様）。

| ツール | 権限 | 内容 |
|---|---|---|
| `app_info`, `model_describe` | 読み取り | 開いているモデル: 通り芯、レベル、フェーズ、種類と断面形状ごとの部材、接合、基礎、階段、部品、鋼材重量、問題 |
| `parts_list` | 読み取り | 部材符号、断面形状、材質、切断長、本数、重量、フェーズ、アセンブリ符号。種類、断面形状、符号、またはフェーズで絞り込み |
| `problems_list` | 読み取り | {{ui:Problems}} タブに表示される一覧。それぞれの対象を含みます |
| `clash_check` | 読み取り | [干渉チェック](topic:clash-check)。許容差とフェーズを含みます |
| `selection_get` | 読み取り | 利用者が選択している内容 |
| `selection_set` | 編集 | 部材、接合、基礎、階段（ID または部材符号で指定）を選択して利用者に表示します。何も変更しません |
| `member_add` | 編集 | 2 点間の梁、柱、ブレース、または板 |
| `connection_add` | 編集 | 指定した部材同士が接する箇所への、エンドプレート、せん断タブ、ベースプレート、継手、またはガセット。{{ui:Connect}} ボタンと同じ動作 |
| `undo` | 編集 | アシスタントの最後の操作を元に戻す |
| `model_save` | 保存 | DetailCraft 自体の保存 |
| `model_export` | 書き出し | IFC、NC ファイル、BOM、加工帳、KISS ファイル、または切断リスト。{{ui:Output}} ボタンと同じ動作 |
| `usd_export` | 書き出し | 鋼構造モデルを USD（.usda、.usdc、.usdz）として書き出し。{{ui:Output}} › {{ui:USD}} と同じ（[鋼構造モデルを USD として書き出す](topic:usd) を参照）。Studio では、許可したフォルダーにファイルを書き出せます |

## うまく動かない場合

- **アシスタントに DetailCraft のツールが表示されない:** このウィンドウでスイッチがオンになっていること、およびこのウィンドウが Studio で開かれていることを確認してください。
- **「編集の権限が必要です」（または保存、書き出し）:** {{ui:Assistants}} でその権限をオンにしてから、もう一度依頼してください。
- **「利用者が部材を配置中です」:** 作業を終えるか（または {{key:Esc}} を押す）、その後アシスタントに再試行させてください。
- **「401」または「token」のエラー:** トークンが変更されました（Studio を再起動したか、{{ui:新しいトークン}} を実行した）。新しいトークンを、アシスタントの設定にコピーしてください。
