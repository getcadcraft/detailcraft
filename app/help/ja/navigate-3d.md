ビューには3つのモードがあり、その上にあるビューバーで選択します: {{ui:3D}}、{{ui:平面}}、{{ui:立面}}。マウスボタンの動作は、3Dと平面・立面で異なるため、両方の表を確認してください。

## 3Dでの操作

:::mouse
| 目的 | 操作 |
|---|---|
| モデルの周りを回転 | 左ボタンでドラッグ |
| パン | 右ボタンでドラッグ、または {{key:Shift}} を押しながら左ボタンでドラッグ |
| ズーム | ホイールを回す、または中ボタン（ホイールを押した状態）で上下にドラッグ |
| パーツを選択 | クリック（数ピクセル未満の移動のクリック） |
| モデル全体を表示 | ビューバー右端の全体表示ボタン |
:::

:::touch
| 目的 | 操作 |
|---|---|
| モデルの周りを回転 | 1本指でドラッグ |
| パン | 2本指でドラッグ |
| ズーム | 2本指でピンチ |
| パーツを選択 | タップ |
| モデル全体を表示 | ビューバー右端の全体表示ボタン |
:::

右上（ビューバーの下）にあるViewCubeは、モデルとともに回転します。面、辺、角をクリックすると、その方向から表示されます。ドラッグして回転させることもできます。ホームボタンをクリックすると、初期の表示に戻ります。詳細は[ViewCube](topic:view-cube)を参照してください。

モデルはビューの中央を中心に回転し、ホイールはポインターではなくビューの中央に向かってズームします。ある角を詳しく見るには、まずその角を中央にパンしてから、ズームしてください。

## 平面と立面での操作

これらのビューはモデルを正面から見る表示で、回転はできません。

:::mouse
| 目的 | 操作 |
|---|---|
| パン | 左ボタンまたは右ボタンでドラッグ |
| ズーム | ホイールを回す、または中ボタンで上下にドラッグ |
| パーツを選択 | クリック |
:::

:::touch
| 目的 | 操作 |
|---|---|
| パン | 1本指でドラッグ |
| ズーム | 2本指でピンチ（2本指でドラッグしてもパンします） |
| パーツを選択 | タップ |
:::

## Macのトラックパッド

:::mac
- **ズーム:** 2本指で上下にスワイプ、またはピンチします。どちらもズームとして処理されます。
- **回転（3D）:** トラックパッドを押して1本指でドラッグします。タップでクリックする設定の場合は、**システム設定、アクセシビリティ、ポインターコントロール、トラックパッドオプション**でドラッグを有効にしていれば、ダブルタップしてドラッグすることもできます。
- **パン（3D）:** {{key:Shift}} を押しながらドラッグします。ドラッグ中に {{key:Ctrl}} または {{key:Mod}} を押してもパンします。2本指でのクリックは右クリックですが、トラックパッドでそのままドラッグするのは扱いにくい場合があります。
- **パン（平面と立面）:** そのままドラッグします。
- Magic Mouseには中ボタンがありません。パンには {{key:Shift}} を押しながらのドラッグを、ズームには表面でのスワイプを使ってください。
:::

マウスなしで右クリックやパンを行う詳細は、[キー、マウス、トラックパッド](common:keys)を参照してください。

## 平面と立面で配置を簡単にする

{{ui:3D}}では、異なるレベルの交点が画面上で重なって見えることがあり、クリックは最も近い点に反応します。{{ui:平面}}と{{ui:立面}}では、表示中のレベルまたは通り芯の点だけを選択できます。

1. {{ui:平面}}を選び、ボタンの横の一覧でレベルを選択します。ビューはそのレベルを見下ろす表示になり、その上1.5 mを超えるものは切り取られて非表示になります。
2. または{{ui:立面}}を選び、英字の通り芯（"通り芯 A"、"通り芯 B" …）を選択します。ビューはその通り芯を正面から見る表示になり、そこから1 m以内の鋼材のみが表示されます。

立面は英字の通り芯でのみ使用できます。数字の通り芯の線（AからBまで続く架構など）で作業するには、{{ui:3D}}を使うか、{{ui:通り芯で追加}}フォームに入力して配置します。詳細は[柱、梁、ブレースを配置する](topic:place-members#place-by-grid-without-clicking)を参照してください。

## 選択

- パーツをクリックして選択します。ハイライトの色に変わり、{{ui:プロパティ}}パネルに表示されます。
- 何もない場所をクリックするか、{{key:Esc}} を押すと、選択が解除されます。
- 鋼材がコンクリートより優先されます。透過表示のフーチング内の柱をクリックすると、柱が選択されます。フーチングを選択するには、柱から離れた位置、またはその鉄筋をクリックします。
- ボルトまたはエンドプレートをクリックすると、その接合部が選択されます。
- 平面と立面では、切り取られたパーツはクリックできません。
- {{key:Shift}}（または {{key:Ctrl}}、{{key:Mod}}）を押しながらクリックすると、パーツを選択に追加、または選択から外せます。{{key:Mod+A}} ですべてを選択します。現時点では、窓選択（ボックスをドラッグする選択）はありません。複数のパーツでできることは、[コピー、貼り付け、複製](topic:copy-paste)を参照してください。

一覧からも選択できます。左側の{{ui:部材符号}}のマーク、{{ui:部品表}}タブの部材符号、または{{ui:問題}}の行の横にある{{ui:選択}}をクリックします。

## ビューが正しく見えない場合

- モデルが見当たらない場合は、全体表示ボタンを選んでください。
- ビューが空白またはグレーで、WebGLに関するメッセージが表示される場合は、[トラブルシューティング](topic:troubleshooting#the-3d-view-is-missing)を参照してください。
- 3Dビューがなくても、クリック以外のすべての機能は動作します。パネル、帳票、書き出しはすべて実行でき、{{ui:通り芯で追加}}で入力により部材を配置できます。
