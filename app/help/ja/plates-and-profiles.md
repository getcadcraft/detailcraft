## プレートを配置する

プレートは梁と同じように配置します。2つの交点の間に、幅を横方向、厚さを上方向にして配置されます。

1. {{ui:配置}} グループで {{ui:プレート}} を選ぶか、{{key:P}} を押します。
2. {{ui:プロパティ}} パネルで、{{ui:厚さ (mm)}} と {{ui:幅 (mm)}} を設定します。初期設定は、A36 の 20 x 200 です。
3. 必要に応じて {{ui:材質}} と {{ui:回転角 (°)}} を設定します。回転角 90 でプレートを縦に立てます。
4. 2つの交点をクリックするか、{{ui:通り芯で追加}} フォームを使います。

プレートの断面名は `PL<thickness>x<width>` と書かれます。例: PL20x200。長さは、2点間の距離です。

配置済みのプレートの寸法を変えるには、選択して {{ui:厚さ (mm)}} または {{ui:幅 (mm)}} を変更します。

配置したプレートは独自の部材です(部材符号 p、アセンブリ P)。接続によって作成されたエンドプレートとベースプレートもプレートですが、変更は接続を通じて行います。[エンドプレート](topic:end-plates) を参照してください。

## カスタム断面を追加する

必要な断面がカタログにない場合は、寸法から作成します。カスタム断面はモデルに属し、モデルと一緒に保存されます。すべての新しいモデルで使うには、下記の「新しいモデル用に断面を保存」で説明している マイプロファイル に保存してください。

1. {{ui:モデル}} パネル(左側)で、{{ui:カスタム断面}} を開きます。
2. {{ui:名前}} を入力します(例: `W8x18-custom` または `RHS 120x80x5`)。カタログ名や、プレート名に似た名前にはできません。
3. {{ui:形状}} を選びます: {{ui:H形鋼}}、{{ui:溝形鋼}}、{{ui:等辺山形鋼}}、{{ui:角形鋼管}}、{{ui:丸形鋼管}}、または {{ui:平鋼}}。
4. 表示された寸法をすべてミリメートルで入力します:

| 形状 | 寸法 |
|---|---|
| H形鋼 | せい d、フランジ幅 bf、ウェブ厚 tw、フランジ厚 tf、フィレット半径 r(0 も可) |
| 溝形鋼 | せい d、フランジ幅 bf、ウェブ厚 tw、フランジ厚 tf(角は直角) |
| 等辺山形鋼 | 幅 b(各脚)、厚さ t |
| 角形鋼管 | 高さ h、幅 b、厚さ t(外側の角の半径 2t) |
| 丸形鋼管 | 直径 D、厚さ t |
| 平鋼 | 幅 b、厚さ t |

5. {{ui:マイプロファイルに保存}} のチェックをオンのままにすると、すべての新しいモデルに追加されます(下記参照)。オフにすると、このモデルだけに保存されます。
6. {{ui:断面を追加}} を選びます。

ステータスバーに「断面 "…" を追加しました。すべての断面一覧の「カスタム」の下にあります。」と表示されます。断面は、フォームの下の一覧に表示され、すべての {{ui:断面形状}} 一覧の末尾にも表示されます。

DetailCraft は、その形状が成立するかを確認します。次のようなメッセージが表示される場合があります: 「ウェブとフランジがせいと幅の内側に収まりません。」「フィレット半径がフランジに対して大きすぎます。」「肉厚が厚すぎます。」数値を修正して、もう一度 {{ui:断面を追加}} を選んでください。

### カスタム断面の扱い

- メートルあたりの質量は、断面積 × 7850 kg/m³ で計算されます(カタログの断面は公表された質量を使います)。
- カスタム H形鋼は、カタログの H形鋼と同様に、穴、切欠き、エンドプレート、NC ファイル、製作図を作成できます。
- カスタムの平鋼はプレートとして扱われます。
- カスタムの溝形鋼と鋼管は穴を作成できます。山形鋼と丸形鋼管はまだできません。

追加したカスタム断面は、モデルから編集や削除ができません(間違えた場合は、すぐに {{key:Mod+Z}} を使ってください)。修正した断面には、新しい名前を付けてください。

## 新しいモデル用に断面を保存する

フォームの下の {{ui:マイプロファイル}} は、あなた自身のカスタム断面の一覧です。この一覧は、モデルファイルやアカウントではなく、このブラウザーとこのコンピューターに保存されます。

- {{ui:マイプロファイルに保存}} をオンにして追加した断面は、一覧に入ります。DetailCraft の起動時に開くモデルを含め、新しいモデルはすべて、この一覧の断面をその断面一覧に含んだ状態で始まります。
- モデルにはあるが一覧にない断面には、その横に {{ui:保存}} ボタンが表示されます。
- 一覧にない断面を持たないモデル(古いファイルなど)では、{{ui:ここで使用}} を選ぶと断面を追加できます。
- {{ui:削除}} は断面を一覧から取り除きます。すでにその断面を使っているモデルは、独自のコピーを保持します。
- 開いたモデルは、そのファイルに保存された断面を保持します。ファイルを開いても一覧は変わりません。
- 寸法が異なる同名の断面が一覧にある場合は、追加を拒否されます。新しい断面には別の名前を付けてください。
- ブラウザーのサイトデータを消去したり、別のブラウザーやコンピューターを使ったりすると、一覧は空の状態から始まります。プライベートウィンドウでは保持できず、アプリにその旨が表示されます。
