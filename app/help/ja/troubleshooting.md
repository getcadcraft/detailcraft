ほとんどの拒否理由は、画面下部のステータスバーか、{{ui:Problems}} タブに説明されています。まずそちらを確認してください。以下のメッセージは、DetailCraft に表示される文言のまま引用しています。

## 3D ビューが表示されない

**「このブラウザーで 3D グラフィックス（WebGL）を開始できませんでした。モデル、レポート、書き出しは引き続き使用できます。」**

ブラウザーで WebGL を開始できませんでした。WebGL は、DetailCraft が 3D グラフィックスの描画に使う機能です。

1. ブラウザーを最新バージョンに更新します。
2. ハードウェア アクセラレーションを有効にし、ブラウザーを再起動します（下記参照）。
3. グラフィックスドライバーを更新するか、別のブラウザーをお試しください。リモートデスクトップや仮想マシンには、WebGL がない場合が多くあります。
4. その間も作業は続けられます。{{ui:Add by grid}} フォームで部材を配置し、レポートを確認し、書き出すことができます。WebGL が必要なのは、ビュー内をクリックする操作だけです。

:::chromium
ハードウェア アクセラレーションを有効にするには、**設定**、**システム** を開き、**利用可能な場合はグラフィック アクセラレーションを使用する** をオンにしてから、再起動します。
:::

:::firefox
ハードウェア アクセラレーションを有効にするには、**設定**、**全般**、**パフォーマンス** を開きます。**推奨のパフォーマンス設定を使用する** をオフにし、**利用可能な場合はハードウェア アクセラレーションを使用する** をオンにします。Firefox を再起動してください。
:::

:::safari
Safari では WebGL が既定でオンになっています。表示されない場合は macOS を更新し、拡張機能で WebGL がブロックされていないか確認してください。
:::

詳しくは [ブラウザーとコンピューター](common:browsers) を参照してください。

## ビュー内のクリックが反応しない

- **クリック位置の近くに交点がありません。** 配置ツールはグリッドの交点にのみスナップします。どの点からも離れた場所をクリックしても、何も起こりません。点が点灯するまで近づけてください。
- **ツールが {{ui:Select}} で、何もない場所をクリックしました。** これにより選択が解除されます。
- **ドラッグしました。** 押してから離すまでの間に数ピクセル以上動いた場合はドラッグとみなされ、ビューが回転またはパンされます。
- **部材が切り取られています。** {{ui:Plan}} と {{ui:Elevation}} では、切断面の外側の鋼材は非表示になり、クリックできません。{{ui:3D}} に切り替えてください。
- **交点の高さが違います。** {{ui:3D}} では、複数のレベルの交点が画面上で重なることがあります。その場合、クリックは最も近い交点を選択します。{{ui:Plan}} または {{ui:Elevation}} を使用してください。

| メッセージ | 対処法 |
|---|---|
| 柱が到達できるレベルが、レベル 2 より上にありません。先にレベルを追加してください。 | {{ui:Levels}} でレベルを追加するか、低いレベルをクリックします |
| 他方の端部には、別の交点を指定してください。 | 同じ点を2回クリックしました |
| 両端が同じ点です。 | {{ui:Add by grid}} で、「開始」と「終了」の指定が同じ点です |
| 部材を配置するには、左側で通り芯を追加してください。 | モデルに、ある方向の通り芯がありません |
| 不明な断面 "…" | 断面がカタログまたはモデルのユーザー定義断面に含まれていません。一覧から選択してください |
| 数値を入力してください。 | 数値欄が空欄か、文字が入力されています |

## 接合部が作成できない

### 「この梁は柱の通り芯上で終わっていません。」

端板を作成するには、梁の端部が、縦方向の柱の通り芯上に、下端と上端の間で正確に位置している必要があります（1mm 以内）。梁の {{ui:Ends (x, y, z mm)}} と柱の位置を確認してください。

### 「この梁は柱のウェブに接するか、斜めに接しています」

または {{ui:Problems}} で: 「柱のウェブに取り付く梁の接合は、まだ作成されていません: 柱を 90° 回転させるか、別の接合を使用してください。」

梁が柱のウェブに取り付いています。柱を選択し、{{ui:Rotation (°)}} を 90 に設定してから、もう一度お試しください。斜めの接合は、まだ作成されていません。

### 「端板は水平の梁にのみ作成されます（この梁は傾斜しています）。」

梁の両端の高さが同じである必要があります。

### 「端板には梁が直立している必要があります（回転 0）。」

梁の {{ui:Rotation (°)}} を 0 に戻してください。

### 「端板には I 形の梁が必要です。」 / 「端板には I 形の柱が必要です。」

端板を使用できるのは I 形（W、IPE、HEA、HEB、またはユーザー定義の I 形）のみです。

### 「梁の端部は、もう柱の通り芯上にありません。」

接合を追加した後に、梁または柱を移動しました。元に戻すか、接合を削除してください。

### 「接合により、この部材の長さがゼロになりました。」

両端の接合が、部材の長さを超えて部材を切り詰めています。たとえば、深い柱の間にある非常に短い梁の場合です。部材の端部と添え板の厚さを確認してください。

### 「このような他の接合部のうち、接合がないものはありません…」

{{ui:Similar}} は、同じ梁の断面、同じ柱の断面、同じ種類の接合（梁をフランジに接合）を持ち、まだ接合が設定されていない接合部にのみコピーします。

### 「両端には既に接合があります。」 / 「この柱には既にベースプレートがあります。」

既存の接合を選択して変更するか、先に削除してください。

## 問題タブの警告

警告は、接合部や基礎の作成を停止しません。確認を求めるものです。縁端とピッチの警告は、EN 1993-1-8 の Table 3.3 の最小値を使用します（縁端 1.2 × 穴径、ピッチ 2.2 × 穴径、ゲージ 2.4 × 穴径）。プロジェクトで別の基準を使用している場合、警告が当てはまらないことがあります。DetailCraft は接合部の設計を行いません。

「部材の端から外れた穴があります」は、穴の x が 0 未満、または切断長を超えることを意味します。x は、接合によって部材が切り詰められた後の切断開始位置からの値であることに注意してください。

## 基礎の変更が拒否されます

| メッセージ | 対処法 |
|---|---|
| このかぶりでは、この基礎に鉄筋を配置するスペースがありません。 | 基礎を大きくするか、かぶりを小さくしてください |
| この基礎は、かぶりの内側に 2 層の鉄筋を配置するには浅すぎます。 | 基礎を深くするか、かぶりを小さくしてください |
| 75mm のかぶりでは、差し筋が基礎内に収まりません。 | 差し筋の本数を減らすか、間隔を狭くするか、基礎を大きくしてください |
| 鉄筋の間隔は 50〜1000mm でなければなりません。 | その範囲内の間隔を入力してください |
| 長さは 300〜50000mm でなければなりません。 | 基礎の寸法には上限と下限があります: 長さと幅は 300〜50000mm、深さは 150〜10000mm です |

## 通り芯とレベルの変更が拒否されます

| メッセージ | 対処法 |
|---|---|
| 番号付きの通り芯: 隣り合う線の間ごとに 1 つの間隔を指定してください（4）。 | 間隔の数を数えてください。5 本の線には 4 つの間隔が必要です |
| 英字の通り芯: 間隔は正のミリメートル値でなければなりません。 | 0、負の値、文字は使用できません |
| 番号付きの通り芯: 通り芯の符号は互いに異なる必要があります。 | 同じ符号の線が 2 本あります |
| 各方向の通り芯は最大 60 本までです。 | モデルを分割してください |
| レベルは最低 1 つ残してください。 | すべてのレベルの行を削除しました |
| 各レベルには名前が必要です。 / 2 つのレベルが "…" という名前になっています。 | 各レベルに異なる名前を付けてください |

## ファイルを開けない

| メッセージ | 原因 |
|---|---|
| DetailCraft が開くのは、独自のモデル（.detailcraft.json）です。IFC の読み込みは、まだ作成されていません。 | ファイルが `.json` ファイルではありません |
| これは DetailCraft のモデルではありません（JSON ではありません）。 | ファイルが破損しているか、別の JSON ファイルです |
| これは DetailCraft のモデルではありません。 | 他のプログラムの JSON ファイルです |
| このモデルは、新しいバージョンの DetailCraft（形式 2）で保存されています。 | 保存に使用した新しい DetailCraft で開いてください |
| そのファイルは、DetailCraft のモデルとしては大きすぎます。 | 50MB を超えています |

「2本の部材が無効なため除外されました。」のような警告付きでファイルが開いた場合、モデルの残りの部分は問題ありません。除外された内容を確認するまで、元のファイルを上書き保存しないでください。

## 書き出し

| メッセージ | 原因 |
|---|---|
| まだ書き出すものがありません。 | モデルが空の状態で {{ui:IFC}} を実行した場合 |
| NC ファイルを作成できる I 形または板の部材がありません。 | モデルにあるのは溝形鋼、山形鋼、鋼管のみです |
| 書き出されませんでした（現時点では I 形と板のみ）: … | これらの符号は I 形または板ではありません。それ以外は書き出されました |
| 基礎がないため、加工帳に記載する鉄筋がありません。 | 基礎がない状態で {{ui:Bending}} を実行した場合 |
| PDF フォントにない … 文字は「?」として出力されます。 | モデル名または強度区分に、PDF フォントにない文字が含まれています |

{{ui:Shop drawing}} がグレー表示になっている場合: モデルにまだ部材がありません。

## ダウンロードが表示されない

保存と書き出しは、すべてブラウザーのダウンロードとして行われます。ブラウザーのダウンロードの一覧を確認してください。複数のファイルをダウンロードする前にブラウザーが確認を求める場合、またはこのサイトからのダウンロードがブロックされている場合は、許可してください。Safari では、ツールバーのダウンロードボタンを確認してください。

## キーが機能しない

- テキスト欄または数値欄にカーソルがある場合、入力できるように、ツールキーと {{key:Delete}} は無視されます。{{key:Tab}} を押すか、ビューをクリックしてください。
- ダイアログが開いています。先に閉じてください。
- ブラウザーがキーボードを使用しています（例: アドレスバー）。DetailCraft の内側をクリックしてください。
- {{key:Ctrl+Shift+F}} は、Mac でも Control キーを使います。

## オフライン時の問題

アプリバーの {{ui:Save for offline}} ボタンに、オフライン用コピーの状態が表示されます。保存の仕組みについては、[オフライン作業](common:offline) を参照してください。

| ボタンの表示 | 意味 | 対処法 |
|---|---|---|
| {{ui:Save for offline}} | このブラウザーには、まだオフライン用コピーがありません | オンラインのときに選択してください |
| 20件中5件を保存中 | 保存が進行中です | {{ui:Offline ready}} と表示されるまで待ち、タブを開いたままにしてください |
| {{ui:Offline ready}} | DetailCraft、その 3D ビュー、すべての書き出し、およびこのヘルプは、接続がなくても使用できます | 何もする必要はありません。クリックすると {{ui:Save again (get the newest version)}} または {{ui:Remove the offline copy}} を選択できます |
| {{ui:Could not save}} | 一部のファイルがダウンロードできませんでした | 接続を確認し、クリックして再試行してください |
| {{ui:Offline not available}} | このウィンドウではオフライン用コピーを保存できません。プライベートウィンドウや一部の管理対象コンピューターではブロックされます | 通常のウィンドウを使用するか、オンラインで作業してください |

オフラインで、ボタンに {{ui:Offline ready}} と表示されていない場合は、ページを再読み込みしたりタブを閉じたりしないでください。読み込み済みの内容は引き続き使用できます。{{key:Mod+S}} でモデルを保存し、オンラインに戻るまで待ってください。

## 保存されていない変更

ブラウザーがページを離れるかどうか確認する場合、DetailCraft には保存されていない変更があります。ページに留まり、その後 {{key:Mod+S}} を押してください。タブを閉じた後は、DetailCraft でモデルを復元できません。

## まだ解決しない場合

行った操作と正確なメッセージをメモし、[サポートページ](https://getcadcraft.com/support) からお知らせください。
