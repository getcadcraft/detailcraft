各 `.nc1` ファイルは、部材符号を1つ表します。行の終わりは CR LF です。テキスト項目には ASCII 文字だけを使い、それ以外の文字は "?" に置き換えられます。2行目はコメントで、`** DetailCraft <mark>.nc1` です。

## ヘッダー(ST)

| 項目 | H形鋼、溝形鋼 | 山形鋼 | 角形 HSS | 丸形 HSS | プレート |
|---|---|---|---|---|---|
| 注文 | モデル名 | ← | ← | ← | ← |
| 図面、部材 | 部材符号 | ← | ← | ← | ← |
| フェーズ | 部材のフェーズ、または 1 | ← | ← | ← | ← |
| 鋼材の品質 | 材質の等級 | ← | ← | ← | ← |
| 数量 | この部材符号の部材の数 | ← | ← | ← | ← |
| 断面 | 断面名(例: W16x26) | ← | ← | ← | `PL<t>*<width>` |
| 断面コード | I または U(溝形鋼) | L | M | RO | B |
| 長さ | 切断長さ | ← | ← | ← | 長さ |
| 高さ | せい d | 脚 | 高さ | 直径 | プレート幅 |
| フランジ幅 | bf | 脚 | 幅 | 直径 | 0 |
| フランジ厚 | tf | t | 肉厚 t | 肉厚 t | 0 |
| ウェブ厚 | tw | t | 肉厚 t | 肉厚 t | プレート厚 |
| 半径 | フィレット半径(AISC の溝形鋼は 0) | 0 | 外側の角の半径 | 0 | 0 |
| メートルあたりの質量 | kg/m | kg/m | kg/m | kg/m | kg/m² |
| メートルあたりの塗装面積 | 外周、m²/m | ← | ← | ← | 2(両面、m²/m²) |
| のこぎりの角度(4項目) | 0(直角) | ← | ← | ← | ← |
| テキスト項目(4) | `-` | ← | ← | ← | ← |

プレートは規格の「板」の列に従います。規格には丸形鋼管の列がないため、DetailCraft は直径を高さとフランジ幅の両方に、肉厚を両方の厚さに書き込みます。

## 外側の輪郭(AK)

- **H形鋼と溝形鋼:** ウェブ(v)。切欠きごとに矩形の切り欠きがあります。各フランジ(o と u)は、切欠きがフランジ以上の深さを持つ端で短くなります。
- **角形 HSS:** 両側の壁(v と h)は切欠き分を切り欠き、上下の壁(o と u)もあります。
- **山形鋼:** 脚ごとに1つの矩形(v と u)。山形鋼の切欠きは書き込まれず、そのような部材は書き込まれないものとして一覧されます。[ガセットプレート](topic:brace-gussets) にボルト締めされた山形鋼のブレースは、ボルト締めされる脚に穴があります。部材の u に沿う脚は v、部材の v に沿う脚は u です。
- **丸形 HSS:** v に1つの矩形。管を正面から見た形(長さ × 直径)です。
- **プレート:** 面 v に1つの矩形。

各輪郭は閉じており(最初の点を最後に繰り返します)、反時計回りです。

## 穴(BO)

穴ごとに1行: 面、x、y、直径、深さ 0(貫通)。入力した穴と接続によって作られた穴は、すべて含まれます。角形 HSS の両側の壁を貫く穴は2回書き込まれ、1回は v、もう1回は h です。

## 面と座標

各断面は、規格の断面位置の図(DSTV 1998、7ページ)に描かれているとおりに配置されます。x は部材に沿い、Y は横方向、Z は背面から上向き、原点は外側の角です。DetailCraft は図に合わせて部材を鏡像にすることはありません。

| 面 | H形鋼 | 溝形鋼 | 山形鋼 | 角形 HSS | プレート |
|---|---|---|---|---|---|
| v | ウェブ、正面 | ウェブ、先端側から見た面 | 部材の u に沿う脚 | −u 側の側壁 | プレートの面 |
| h | | | | +u 側の側壁 | |
| o | 上フランジ | **下**フランジ | | 上の壁 | |
| u | 下フランジ | **上**フランジ | 部材の v に沿う脚 | 下の壁 | |

- **x** は、切断の開始位置から部材に沿って進みます。
- **H形鋼と角形 HSS:** ウェブまたは側壁の y は、断面の下側から測ります。フランジ、または上下の壁の y は、背面側(部材の +u 側)の縁から測ります。
- **溝形鋼:** 規格の図のとおり、先端を上に向けて背を下にして置きます。そのため、ウェブの y は上フランジの外側から下向きに測り、上フランジは面 u、下フランジは面 o です。フランジの y は、ウェブの背面から先端に向かって測ります。
- **山形鋼:** 各脚の y は背から測ります。
- **プレート:** y はプレートの −u 側の縁から測ります。

切断の前に、お使いの機械のソフトウェアが溝形鋼の面をどう読み取るかを確認してください。一部のプログラムは溝形鋼の上下を逆にします。

## 書き込まれないもの

開先、内側の輪郭、けがき(SI)、直角以外ののこぎり角度、長穴、丸形鋼管の穴(DetailCraft には作成されません)、そして山形鋼および丸形鋼管の切欠き。
