0.8.1 と比べた DetailCraft 0.9 の変更点です。0.9 では、英国の鋼材サイズ、部材ごとの施工図を一度にまとめて作成する機能、骨組用に拡大した{{ui:解析}}タブ、共同作業中に互いのカーソルを表示する機能が加わりました。

## 新機能

### 英国の鋼材と施工図

- **英国の鋼材サイズ。** 断面リストに、Steel for Life Blue Book の 976 サイズが加わりました: UB、UC、PFC、EA、UEA、CHS、SHS、RHS です。冷間成形の中空断面は別にしてあり、名前は CF で始まります。名前はファミリーを先頭にして書きます(UB305x165x40、SHS100x100x5.0 など)。図面での書き方(305x165x40 UB、L100x100x10、SHS100x5)で入力しても使えます。[断面カタログ](topic:profile-catalog)を参照してください。
- **不等辺山形鋼。** UEA 山形鋼は、IFC の入出力と NC ファイルの両方で両脚の寸法を保持します。鏡像にすると、部材の両端が入れ替わります。
- **すべての施工図を一度に。** 何も選択しない状態で、{{ui:出力}}グループの{{ui:施工図}}を選びます。ウィンドウにはすべての部材符号が一覧表示され、どれでもプレビューできます。{{ui:すべてダウンロード}}を押すと、部材符号ごとに1ページ、「シート 3 / 42」のようなタイトルの付いた PDF が1つ保存されます。{{ui:PDF をダウンロード}}は、今見ている1シートを保存します。溝形鋼、山形鋼、中空断面にもシートが作成されるようになりました。[施工図の作成](topic:shop-drawings)を参照してください。
- **マイプロファイル。** カスタム断面を、新しいモデルすべてで使えるように保存できるようになりました。カスタム断面フォームで{{ui:マイプロファイルに保存}}にチェックを入れたままにします。その下にある{{ui:マイプロファイル}}の一覧には{{ui:保存}}、{{ui:ここで使用}}、{{ui:削除}}があります。一覧はこのブラウザーに保存され(最大 200 件)、アカウントには保存されません。[板と断面](topic:plates-and-profiles)を参照してください。

### 解析

- **2次の効果（P-Delta）。** {{ui:解析}}タブの{{ui:実行}}の横にある{{ui:2次の効果 (P-Delta)}}にチェックを入れると、軸力がたわんだ骨組に作用します。板と剛床は1次のままで、その旨の警告が表示されます。[断面力、反力、たわみ](topic:frame-analysis)を参照してください。
- **固有振動数。** 結果の下にある{{ui:有限要素: 固有振動数}}ブロックは、同じモデルの最も低いモードを求め、周期と有効モード質量を表示します。モデル上でモードを表示することもできます。[断面力、反力、たわみ](topic:frame-analysis)を参照してください。
- **風荷重と地震の敷地。** {{ui:解析}}タブに3つの新しいブロックがあります: {{ui:風荷重(ASCE 7方向別手法)}}、{{ui:地震の敷地と構造形式(ASCE 7)}}、{{ui:ASCE 7荷重の組合せ}}。[風荷重、地震の敷地、ASCE 7 の組合せ](topic:wind-seismic-combinations)を参照してください。

### 共同作業

- **カーソルと名前。** ライブセッションでは、各参加者のポインターが名前と色とともにモデル内に描かれ、選択したものには枠が付きます。
- **参加者をフォロー。** セッションで{{ui:参加者}}を開き、名前の{{ui:フォロー}}を選ぶと、表示がその人の表示に合わせて動きます。ホストは{{ui:全員にフォローを依頼}}を選べます。[ライブセッションで参加者をフォローする](topic:follow-in-live)を参照してください。

### すべてのアプリ

- ツールチップは Bootstrap のツールチップになりました。開始時のヒントカードには閉じるボタンが付き、タブが収まらないときは横にスクロールします。ブラウザーのタブ名には、開いている文書名に続けて DetailCraft と CadCraft が表示されます。

## 修正

- 新しいモデルを開始すると、カスタム断面が失われることがありました。
- 施工図のセットに、溝形鋼、山形鋼、中空断面が含まれていませんでした。

## 制限事項

- 風、地震、有限要素のブロックは確認の補助です。結果は技術者が確認するもので、規準の確認ではありません。USGS の検索は、実際のサービスではなく代わりのもので試験しました。
- 有限要素と P-Delta は、手計算と閉形式の解と照合しました。実際の建物では試していません。座屈解析は作成されていません。
- 英国の鋼材サイズは、まだ英国のファブリケーターが試していません。不等辺山形鋼の NC ファイルは、実機ではまだ動作していません。
- 施工図のセットは PDF のみです。
- 英語以外の言語は機械翻訳の下書きです。
- Windows インストーラーはコード署名されていません(詳細情報、続けて実行)。macOS のディスクイメージは公証されていません(右クリックして開く)。

以前の変更は、このページの下にある 0.8 と 0.8.1 の注記にあります。

## 以前: 0.8 と 0.8.1

0.8（2026年11月1日）と 0.8.1（2026年11月2日）での変更点を、0.7 と比べて説明します。0.7 では鋼材部材を確認しました。0.8 では、リフトの計画、接合の提案、基礎と鉄筋の確認を行い、木造と軽量鉄骨の壁、床、屋根の骨組を作成します。

### 新機能

**建方**

- **建方計画とムービー。** {{ui:建方}}タブで、クレーンを記述します(設置位置、最も高いフック、荷重表にない玉掛け具など)。その荷重表の行を入力します。DetailCraft は、モデルを1つの組立体ずつ、フェーズの順、段ごとにリフトします。各リフトを、その半径での荷重表と設定した余裕に対して確認します。{{ui:ムービーを保存}}は、オフラインでどのブラウザーでも再生できる HTML ファイルを1つ書き出します(スマートフォンでも可)。荷重表を超える、範囲外、または高すぎるリフトは{{ui:問題}}に表示されます。これは入力した数値からの計画であり、リフト計画ではありません。[建方計画とムービー](topic:erection-movie)を参照してください。

**接合部**

- **接合のオートパイロット。** {{ui:オートパイロット}}タブは、接合部のない各接合点を確認し、形状から接合を提案します。ベースプレート、せん断タブ、モーメント梁として指定した梁のエンドプレート、継手、ガセットプレートです。等分布荷重または片端のせん断力を与えると、ボルト本数はボルトの設計強度に従って決まります。{{ui:すべて追加}}を押すと、提案を1回の元に戻す操作として追加されます。これらは確認が必要な開始値であり、接合部の設計ではありません。
- **施工性の確認。** {{ui:問題}}には、レンチが届かないボルト、ソケットに対して近すぎるボルト、サイズ制限を超えるすみ肉溶接、水がたまる中空断面が表示されます。溶接のアクセス性は新しい確認です。トーチが届かない全周すみ肉溶接は、妨げになる部材と影響を受ける溶接の割合とともに一覧表示されます。[施工性の確認](topic:constructability)を参照してください。

**基礎と鉄筋**

- **基礎の確認。** {{ui:基礎}}タブは、入力した地盤の上で、フーチング、連続フーチング、マットを確認します。使用荷重による支持力、滑動、転倒。荷重係数を掛けた荷重による曲げ、せん断、パンチング、定着、最小鉄筋量(ACI 318-19)です。縁や角に近い柱は、フーチングの縁で切り取られた断面で確認します。沈下は地盤の変形係数から求め、柔らかい版は地盤反力係数に基づくばねで解きます。杭群と擁壁にはそれぞれ専用のパネルがあります。柱の荷重は手入力するか、{{ui:解析}}から取り込めます。[基礎の確認](topic:foundation-checks)を参照してください。
- **鉄筋の混雑マップ。** {{ui:混雑}}タブは、各フーチングを上から見た熱マップを描きます。コンクリートが下まで入るには鉄筋の間隔が狭すぎる箇所を、最小あきの規定と、入力した場合は骨材の最大寸法とバイブレーターのヘッドと比較して示します。[鉄筋の混雑マップ](topic:rebar-congestion)を参照してください。

**フレーミングと供給**

- **木造と軽量鉄骨の骨組。** {{ui:フレーミング}}タブは、壁、床、屋根のパネルを、すべての部材、加工リスト、購入する材料、縮尺付きの施工図とともに作成します。{{ui:部材として配置}}で部材をモデルに配置し、{{ui:PDFシート}}で各パネルのシートを1枚ずつ保存します。断面、間隔、まぐさは入力します。DetailCraft は、それが荷重を支えるかどうかは確認しません。[木造と軽量鉄骨のフレーミングパネル](topic:framing-panels)を参照してください。
- **サプライヤーの在庫とリードタイム。** {{ui:供給}}タブは、サプライヤーの在庫リスト(CSV)を読み込み、加工リストが購入する断面ごとに、在庫が十分かどうかと待ち時間を表示します。不足分と納期の遅れは{{ui:問題}}に表示されます。発注は行われません。[サプライヤーの在庫とリードタイム](topic:supplier-stock)を参照してください。

**解析と設計**

- **最初に壊れるのは?** {{ui:解析}}タブのボタンは、支配する強度の組合せ、最も弱い部材、最初の部材が限界に達するまでに荷重をどこまで増やせるか、そしてボルトのせん断強度がわかっている場合の最も弱いエンドプレートまたはせん断タブを求めます。まず組合せと設計規準が必要です。支圧、ブロックせん断、溶接、てこ作用(プライング)は確認しません。接続したアシスタントからも同じ内容を依頼できます。
- **ライブ。** {{ui:ライブ: 編集のたびに解き直す}}にチェックを入れると、編集のたびに骨組を解き直します。
- **コンクリートなど。** 非移動骨組の細長い柱は、拡大モーメントについて設計されます(ACI 318-19 6.6.4.5)。耐震の周期は、レイリー法により解析から求めることができます。板で作られたスラブには、モーメントと一方向せん断から各層に必要な鋼材が与えられます。[コンクリート部材の確認と地震荷重の作成](topic:concrete-and-seismic)を参照してください。
- **技術者が確認する項目。** 基礎、コンクリート、「最初に壊れるのは?」の結果は補助です。風荷重は作成されていません。

**すべてのアプリ**

- **言語。** ヘルプは 54 言語で提供されています。英語以外は、ネイティブの話者が確認するまで機械翻訳の下書きです。10 言語が新たに加わりました(リトアニア語、ラトビア語、ボスニア語、マラーティー語、テルグ語、アルバニア語、アフリカーンス語、フィリピノ語、スワヒリ語、ウズベク語)。
- **ツールバーの行数。** {{ui:設定}} › {{ui:全般}} › {{ui:ツールバーの行数}} で、折り返し、2 行、または 1 行を選びます。すでに収まっているバーはそのままで、ほかのバーは横にスクロールします。
- **プロパティグリッド。** フーチングの欄は共通のグリッドを使います。折りたたみ可能なカテゴリーと、コンパクトな密度です。2*450 のような入力式も引き続き使えます。
- **入力デバイス。** タッチパッド、ペン、3D マウス、コントローラー、MIDI でアプリを操作できます。[3D での操作](topic:navigate-3d)を参照してください。
- **問題パネル。** 上記の新しい確認の警告は、従来と同じ{{ui:問題}}パネルに表示されます。
- **AI アシスタントを接続。** 自分のアシスタントを CadCraft Studio 経由で接続すると、8 つのアプリすべてで動作し、許可した内容だけが見えます。ワンクリック接続、ホスト型コネクター、Studio での独自の API キーは今後の予定です。[DetailCraft で AI アシスタントを使う](topic:use-with-ai-assistants)を参照してください。

### 0.8.1 で修正

- **Studio での言語。** Studio とパッケージ版では、実行中に言語を切り替えられるようになりました。以前は英語のみでした。すべてのプラットフォームでは未検証です。言語が切り替わらない場合はお知らせください。
- **交差選択。** 0.8.1 のインストーラーには、0.8 の Web 版ですでに正しかった交差窓による選択の動作が含まれています。古いインストーラーには含まれていませんでした。
- **縦向きのタブレット。** 余った格子の高さはキャンバスに割り当てられ、シートのレイアウトは 760 px 以下で切り替わります。

### このバージョンにまだ含まれないもの

- **NC を機械へ送る**機能は、まだリリースされていません。
- **風荷重**はコンクリート向けには作成されていません。コンクリートと基礎の確認は、技術者が確認するためのものです。
- **コード署名。** Windows インストーラーと macOS の .dmg は署名されていないため、Windows は警告を表示する場合があり、macOS では右クリックして開く操作が必要です。

以前の変更は[0.7 の新機能](topic:whats-new-0-7)にあります。
