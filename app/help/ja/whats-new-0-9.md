これは DetailCraft 0.8.1 と比べて 0.9 で変わった内容です。0.9 では英国の鋼材断面、全部材の施工図を一度に作成する機能、フレーム用の大きくなった {{ui:Analysis}} タブ、そして共同作業時に互いのカーソルを見られる機能が加わりました。

## 新機能

### 英国の鋼材と施工図

- **英国の鋼材断面。** 断面一覧には、Steel for Life Blue Book の 976 種類の寸法が含まれるようになりました。対象は UB、UC、PFC、EA、UEA、CHS、SHS、RHS です。冷間成形の中空断面は（名称が CF で始まるものとして）分けて扱われます。名称は UB305x165x40 や SHS100x100x5.0 のように、断面の種類を先頭に書かれます。図面での表記のまま、305x165x40 UB、L100x100x10、SHS100x5 のように入力しても認識されます。詳しくは [断面カタログ](topic:profile-catalog) を参照してください。
- **不等辺山形鋼。** UEA 山形鋼は、IFC の入出力と NC ファイルを通じて両脚の寸法を保持し、鏡像にすると部材の両端が入れ替わります。
- **すべての施工図を一度に。** 何も選択していない状態で、{{ui:Output}} グループの {{ui:Shop drawing}} を選びます。ウィンドウにはすべての部材符号が一覧表示され、任意の符号をプレビューできます。{{ui:Download all}} を選ぶと、符号ごとに 1 ページの PDF が 1 つ保存されます。各ページには「Sheet 3 of 42」（シート 3 / 42）のようなタイトルが付きます。{{ui:Download this sheet}} は、今見ているシートだけを保存します。溝形鋼、山形鋼、中空断面にもシートが作成されるようになりました。詳しくは [施工図の作成](topic:shop-drawings) を参照してください。
- **マイプロファイル。** ユーザー定義断面を、新しいモデルすべてで使えるように保存できます。ユーザー定義断面のフォームで {{ui:Keep in My profiles}}（マイプロファイルに保存）をオンのままにします。その下の {{ui:My profiles}} 一覧には {{ui:Keep}}、{{ui:Use here}}、{{ui:Remove}} があります。一覧はお使いのアカウントではなく、このブラウザーに保存されます（最大 200 件）。詳しくは [鋼板と断面](topic:plates-and-profiles) を参照してください。

### 解析

- **2次効果（P-Delta）。** {{ui:Analysis}} タブの「実行」の横にある {{ui:Second order (P-Delta)}} をオンにすると、軸力がたわんだフレームに作用します。鋼板と剛床は一次のままで、その旨の警告が表示されます。詳しくは [断面力、反力、たわみ](topic:frame-analysis) を参照してください。
- **固有振動数。** 結果の下にある {{ui:Finite elements: natural frequencies}} ブロックは、同じモデルの最も低い次数の振動モードを、周期と有効モーダル質量とともに求め、モデル上にモードを表示します。詳しくは [断面力、反力、たわみ](topic:frame-analysis) を参照してください。
- **風荷重と地震の敷地。** {{ui:Analysis}} タブに 3 つの新しいブロックがあります。{{ui:Wind loads (ASCE 7 directional procedure)}}、{{ui:Seismic site and system (ASCE 7)}}、{{ui:ASCE 7 load combinations}} です。詳しくは [風、地震の敷地、ASCE 7 の組合せ](topic:wind-seismic-combinations) を参照してください。

### 共同作業

- **カーソルと名前。** Live セッションでは、各参加者のポインターが名前と色とともにモデル内に表示され、選択したものには枠が付きます。
- **参加者をフォロー。** セッションで {{ui:People}} を開き、名前の {{ui:Follow}} を選ぶと、あなたの表示が相手の表示に合わせて動きます。ホストは {{ui:Ask everyone to follow me}}（全員にフォローを依頼）を選べます。詳しくは [ライブセッションで参加者をフォロー](topic:follow-in-live) を参照してください。

### すべてのアプリ

- ツールチップは Bootstrap のツールチップになりました。開始時のヒントカードには閉じるボタンがあり、タブ列は収まらないときに横にスクロールします。ブラウザーのタブ名には、開いている文書の名前に続けて DetailCraft と CadCraft が表示されます。

## 修正済み

- 新しいモデルを開始すると、ユーザー定義断面が失われていました。
- 溝形鋼、山形鋼、中空断面が施工図のセットに含まれていませんでした。

## 制限事項

- 風荷重、地震、有限要素のブロックは確認を補助するためのツールです。結果は技術者が確認するもので、規準のチェックではありません。USGS の検索は、実際のサービスではなく代替のもので試験されました。
- 有限要素と P-Delta は、手計算と閉形式の解と照合されましたが、実際の建物では検証されていません。座屈解析は未対応です。
- 英国の鋼材製作者による試用はまだありません。不等辺山形鋼の NC ファイルは、実機ではまだ動作確認されていません。
- 施工図のセットは PDF のみです。
- 英語以外の言語は機械翻訳のドラフトです。
- Windows のインストーラーはコード署名されていません（詳細情報、次に実行）。macOS のディスクイメージは公証されていません（右クリック、次に開く）。

## 以前: 0.8と0.8.1

これは DetailCraft 0.7 と比べて、0.8（2026年11月1日）と 0.8.1（2026年11月2日）で変わった内容です。0.7 では鋼部材をチェックしました。0.8 では建方の計画、接合部の提案、基礎と鉄筋のチェック、そして木材と軽量鉄骨の壁、床、屋根のフレーミングを行います。

### 新機能

**建方**

- **建方計画とムービー。** {{ui:Erection}} タブで、クレーンを記述します（設置位置、最も高いフック、荷重表にない玉掛け具など）。そして、その荷重表の行を入力します。DetailCraft は、フェーズの順序と階ごとに、アセンブリを 1 つずつ吊り上げ、各吊り上げを、その作業半径での荷重表と、設定した余裕に対してチェックします。{{ui:Save movie}} は、オフラインで任意のブラウザー（スマートフォンでも可）で再生できる HTML ファイルを 1 つ書き出します。荷重表を超えるもの、範囲外のもの、高すぎるものは {{ui:Problems}} に表示されます。これはあなたの数値に基づく計画であり、正式な吊り上げ計画ではありません。詳しくは [建方計画とムービー](topic:erection-movie) を参照してください。

**接合**

- **接合の自動提案。** {{ui:Autopilot}} タブは、接合が未設定のすべての接合部を調べ、断面形状から接合を提案します。対象は、ベースプレート、せん断プレート、モーメント梁として指定した梁の端板、継手、ガセットです。等分布荷重または片端のせん断力を与えると、ボルト本数はボルトの設計強度に従って決まります。{{ui:Add them all}} は、提案すべてを 1 回の元に戻す操作として追加します。これらは確認用の初期値であり、接合の設計ではありません。
- **施工性のチェック。** {{ui:Problems}} は、レンチが届かないボルト、ソケットに対して近すぎるボルト、サイズ制限を超えた隅肉溶接、水がたまる中空断面を示します。溶接のアクセスは新しい機能です。溶接トーチが届かない全周の隅肉溶接は、妨げになっている部材と影響を受ける溶接の割合とともに一覧表示されます。詳しくは [施工性のチェック](topic:constructability) を参照してください。

**基礎と鉄筋**

- **基礎のチェック。** {{ui:Foundation}} タブは、入力した地盤上のフーチング、複合フーチング、マットをチェックします。使用荷重による支持力、滑動、転倒、そして設計荷重による曲げ、せん断、パンチング、定着長、最小鉄筋（ACI 318-19）です。縁や隅に近い柱は、フーチングの縁で切り取られた断面でチェックされます。沈下は地盤の弾性係数から求められ、柔らかいマットは地盤反力係数に基づくばね上で解かれます。杭群と擁壁には独自のパネルがあります。柱荷重は手入力するか、{{ui:Analysis}} から取得できます。詳しくは [基礎のチェック](topic:foundation-checks) を参照してください。
- **鉄筋の混雑マップ。** {{ui:Congestion}} タブは、各フーチングを上から見た熱マップを描きます。鉄筋がコンクリートを下まで通すための空間を十分残さない箇所を、最小あき寸法の規則と、入力された場合は最大骨材寸法と振動機のヘッドに照らして示します。詳しくは [鉄筋の混雑マップ](topic:rebar-congestion) を参照してください。

**フレーミングと供給**

- **木材と軽量鉄骨のフレーミング。** {{ui:Framing}} タブは、壁、床、屋根のパネルをすべての部材とともにフレーミングし、切断リスト、購入する在庫、縮尺付きの施工図を作成します。{{ui:Place as members}} は部材をモデルに配置し、{{ui:PDF sheets}} は各パネルのシートを 1 枚ずつ保存します。断面寸法、間隔、まぐさはあなたが決めるもので、DetailCraft は荷重を支えられるかどうかを確認しません。詳しくは [木材と軽量鉄骨のフレーミングパネル](topic:framing-panels) を参照してください。
- **サプライヤーの在庫とリードタイム。** {{ui:Supply}} タブは、サプライヤーの在庫リスト（CSV）を読み込み、切断リストが購入する各断面について、在庫が十分かどうかと待ち時間を表示します。不足や遅れる断面は {{ui:Problems}} に表示されます。発注は行われません。詳しくは [サプライヤーの在庫とリードタイム](topic:supplier-stock) を参照してください。

**解析と設計**

- **何が最初に壊れるか？** {{ui:Analysis}} タブのボタンは、支配する強度の組合せ、最も弱い部材、最初の部材が限界に達するまでに荷重をどれだけ増やせるかを求めます。さらに、ボルトのせん断強度が分かっている場合は、最も弱い端板またはせん断プレートも求めます。先に組合せと設計規準の設定が必要です。支圧、ブロックせん断、溶接、こじりはチェックされません。接続したアシスタントも同じ内容を依頼できます。
- **ライブ。** {{ui:Live: solve again after each edit}} をオンにすると、編集のたびにフレームが解き直されます。
- **コンクリートなど。** 非移動フレームの細長い柱は、拡大モーメント（ACI 318-19 6.6.4.5）に基づいて設計されます。耐震の周期は、レイリー法によって解析から求められます。鋼板で作られたスラブは、各層に必要な鋼材を曲げモーメントと一方向せん断から得ます。詳しくは [コンクリート部材のチェックと地震荷重の作成](topic:concrete-and-seismic) を参照してください。
- **技術者による確認が必要です。** 基礎、コンクリート、「何が最初に壊れるか？」の結果は補助ツールです。風荷重はまだ未対応です。

**すべてのアプリ**

- **言語。** ヘルプは 54 の言語で提供されています。英語以外はネイティブ話者が確認するまで機械翻訳のドラフトです。新しく 10 の言語が加わりました（リトアニア語、ラトビア語、ボスニア語、マラーティー語、テルグ語、アルバニア語、アフリカーンス語、フィリピン語、スワヒリ語、ウズベク語）。
- **ツールバーの行数。** {{ui:Settings}} › {{ui:General}} › {{ui:Toolbar rows}} で、折り返し、2 行、1 行のいずれかを選べます。すでに収まっているバーは変わらず、それ以外は横にスクロールします。
- **プロパティグリッド。** 基礎の入力欄は共通のグリッドを使います。折りたためるカテゴリと、コンパクトな密度が使えます。2*450 のような入力での計算も引き続き使えます。
- **入力デバイス。** トラックパッド、ペン、3D マウス、コントローラー、MIDI でアプリを操作できます。詳しくは [3D でのナビゲート](topic:navigate-3d) を参照してください。
- **問題パネル。** 上記の新しいチェックの警告は、これまでと同じ {{ui:Problems}} パネルに表示されます。
- **お使いの AI を接続。** CadCraft Studio に接続したお使いのアシスタントは、8 つのアプリすべてで動作し、許可した内容しか見えません。ワンクリックでの接続、ホストされたコネクター、Studio での独自の API キーはまだ準備中です。詳しくは [DetailCraft を AI アシスタントと使う](topic:use-with-ai-assistants) を参照してください。

### 0.8.1 で修正

- **Studio の言語。** Studio とパッケージ版は、実行中に言語を切り替えられるようになりました。以前は英語のみでした。すべてのプラットフォームではまだ試験されていません。言語が変わらない場合はお知らせください。
- **窓選択。** 0.8.1 のインストーラーには、0.8 の Web 版ですでに正しく動いていた窓による選択の動作が含まれています。古いインストーラーにはこの動作がありませんでした。
- **縦向きのタブレット。** 余ったグリッドの高さはキャンバスに割り当てられ、シートのレイアウトは 760 px 以下から始まります。

### このバージョンではまだ対応していないこと

- **NC を機械に送信する機能**は、まだリリースされていません。
- **コンクリートの風荷重**は未対応です。コンクリートと基礎のチェックは、技術者による確認が必要です。
- **コード署名。** Windows のインストーラーと macOS の .dmg は署名されていないため、Windows では警告が表示されることがあり、macOS では右クリックして開くよう求められます。
