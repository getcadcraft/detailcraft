このトピックは直方体の独立フーチングについてです。梁、柱、スラブ、壁は[鉄筋コンクリートの詳細](topic:reinforced-concrete)にあります。各フーチングには両方向の下端筋が入り、必要に応じてフーチングから立ち上がる差し筋を設けられます。鉄筋は米国サイズの #3 から #11 までです。

## フーチングを配置

1. {{ui:平面}}を選択し、フーチングの天端のレベルを指定します。
2. {{ui:配置}}グループの{{ui:フーチング}}を選択するか、{{key:F}}キーを押します。
3. {{ui:プロパティ}}パネルでフーチングを設定します（下記参照）。既定値のままでもかまいません。
4. 通り芯の交点をクリックします。フーチングはその交点を中心に配置され、天端がレベルに一致します。ステータスバーには、たとえば「A/1の下にフーチング2000 x 2000 x 600を配置しました。」と表示されます。

パネル下部の{{ui:通り芯で追加}}フォームを使うこともできます。

フーチングは透過表示され、内部の鉄筋が見えるようになっています。鉄筋は中実のチューブとして描かれます。

## フーチングの設定

| 項目 | 既定値 | 補足 |
|---|---|---|
| 長さ L (mm) | 2000 | x 方向。300 から 50000 |
| 幅 B (mm) | 2000 | y 方向。300 から 50000 |
| 深さ H (mm) | 600 | 150 から 10000 |
| コンクリート | 4000 psi | 文字列。IFC の書き出しに含まれます |

**下端筋**

| 項目 | 既定値 | 補足 |
|---|---|---|
| 長手方向の鉄筋 | #5 | L 方向に配置される鉄筋。下段 |
| 間隔 (mm) | 250 | 許容される最大間隔。鉄筋はこの間隔以下で均等に配置されます |
| 短手方向の鉄筋 | #5 | B 方向に配置される鉄筋。長手方向の鉄筋の上に置かれます |
| 間隔 (mm) | 250 | 上記と同じ |
| かぶり (mm) | 75 | すべての面の有効なかぶり |
| 端部フック | オン | 下端筋の両端を標準の 90° フック（形状 U）に曲げ上げます。オフにすると直線の鉄筋（形状 S）になります |

**差し筋**

| 項目 | 既定値 | 補足 |
|---|---|---|
| 差し筋 | オン | 差し筋のないフーチングではオフにします |
| 鉄筋 | #6 | |
| L 方向 / B 方向の本数 | 2 / 2 | フーチングの中心に配置される鉄筋の格子 |
| L 方向 / B 方向の間隔 | 250 / 250 | 鉄筋の中心間の距離 |
| 天端からの突出長さ | 600 | フーチングの天端から鉄筋が立ち上がる長さ |
| 下端のフック | オン | 外側を向いた 90° フックで、下端筋の上に載ります（形状 L） |

項目の下には、長手方向の鉄筋のフックの脚長が表示されます。たとえば「#5のフック脚長: 254 mm 外法」。

## 配置済みのフーチングを変更

フーチングを選択します（柱から離れたコンクリート部分、または鉄筋のいずれかをクリックします）。同じ項目に加えて、{{ui:中心 x}}、{{ui:中心 y}}、{{ui:上端 z}}、{{ui:回転角 (°)}}が表示されます。その下の表には、このフーチングの鉄筋を符号、本数、長さとともに一覧表示し、コンクリートの体積を m³ 単位で示します。

変更は保持される前に検査されます。作成できない変更は受け付けられず、ステータスバーに理由が表示されます。たとえば「かぶりのため、このフーチングには鉄筋を配置できません。」「フーチングが浅く、かぶりの内側に鉄筋を2段配置できません。」「差し筋が、かぶり75 mmでフーチングの内側に収まりません。」

作成できるものの、確認が必要な変更は、フーチングの下と{{ui:問題}}タブに一覧表示されます:

- 「#11の鉄筋を59.6 mm間隔で配置すると、有効な隙間が35.8 mm未満になります (ACI 318-19 25.2.1)。」鉄筋間の有効な隙間は、鉄筋径以上かつ25.4 mm以上である必要があります。
- 「#5のフックには254 mmの深さが必要ですが、かぶりの内側には150 mmしか収まりません。」そのためフックの脚は収まるように短くなり、標準のフックではなくなります。
- 「差し筋のフックがかぶりに入り込んでいます。」
- 「差し筋の間隔が、最小の有効な間隔より狭くなっています。」

## 鉄筋符号と加工帳

同じ鉄筋（サイズ、形状、寸法がミリ単位まで同一のもの）は、すべてのフーチングで同じ鉄筋符号を共有します。符号は `<鉄筋番号>F<n>` の形式で付けられます。たとえば #5 の鉄筋には 5F1、5F2、最初の #6 の鉄筋には 6F1 のように付きます。サイズ、コンクリート、下端筋、差し筋が同じフーチングは、同じフーチング符号を共有します: F1、F2 …

1. 下部の{{ui:加工帳}}タブを開きます。各行が 1 つの鉄筋符号に対応し、サイズ、形状、寸法 A、B、C、本数、切断長さ、合計長さ、1 mあたりの質量、それぞれの重量、合計重量、鉄筋の用途を示します。
2. タブ内の{{ui:CSV をダウンロード}}を選択するか、{{ui:出力}}グループの{{ui:その他}}メニューから{{ui:加工帳}}を選択して、`<name> bending schedule.csv` を取得します。

形状は DetailCraft 独自のコードであり、規格のものではありません。S は直線、L は 1 回曲げ、U は 2 回曲げです。寸法は外法で示されます。切断長さは、曲げ部分を通る正確な中心線の長さです。[鉄筋リファレンス](topic:rebar-reference)を参照してください。

## DetailCraft がチェックしない項目

- 定着長さと重ね継手長さ、および差し筋が上部の柱に対して十分な長さかどうか。
- 最小の有効間隔ルールのうち骨材寸法に関する部分（配合は DetailCraft に分からないため）。
- 上部の柱やベースプレートに関するすべての事項。フーチングと鉄骨は別々に扱われます。
