エンドプレート接合は、梁の端部にプレートを溶接し、柱のフランジまたはウェブにボルトで留めます。DetailCraft はプレートを配置し、梁を切り戻し、プレートと柱フランジに対応する孔を開け、ボルトと溶接を追加して、縁端距離と間隔をチェックします。

:::warning
DetailCraft は接合部を設計しません。設定は変更するための初期値であり、強度はチェックされません。縁端と間隔の警告は EN 1993-1-8 表 3.3 の最小値を使用しますが、お使いの規準とは異なる場合があります。
:::

## 接続できるもの

- **水平**な梁（両端が同じ高さ）で、鉛直（回転 0）、I 形断面のもの。
- 鉛直な I 形断面の柱の**フランジ**または**ウェブ**に、直角に接続するもの。
- 梁端は柱の通り芯上にあり、柱の下端と上端の間になければなりません。

斜めや傾斜した梁、および I 形以外の断面は、理由とともに拒否されます。その場合は [シアタブ](topic:shear-tabs) を使ってください。ウェブに接続する場合、プレートと梁フランジは柱フランジの間に収まる必要があります。収まらない場合、DetailCraft が警告します。

:::tip
回転 0 では、柱のフランジは番号付きの通り芯の方向（x）を向きます。A から B へ走る梁はウェブに接続し、ウェブにエンドプレートが付きます。
:::

## 梁にエンドプレートを追加

1. {{ui:選択}}（{{key:V}}）を選び、梁をクリックします。
2. {{ui:接合}} グループの {{ui:エンドプレート}}、または {{ui:プロパティ}} パネルの {{ui:エンドプレートを追加}} を選びます。
3. 柱フランジまたはウェブに直角に接する梁の自由端ごとに、プレートが付きます。ステータスバーには「エンドプレートを2個追加しました。1つ選択するとプレート、ボルト、溶接を変更できます。{{ui:同様に適用}} で同様の接合部にコピーされます。」と表示されます。
4. 最初に追加されたエンドプレートが選択され、その設定が {{ui:プロパティ}} パネルに表示されます。

何も起こらない場合は、ステータスバーを確認してください:

- 「この梁は柱の通り芯上で終わっていません。エンドプレートは、梁端が鉛直な柱に接する箇所に配置されます。」
- 「この梁は柱に斜めに接する、または傾斜しています。エンドプレートは直角で水平な接合部用です。シアタブを使用してください。」
- 「両端にはすでに接合部があります。」

## プレート、ボルト、溶接を変更

エンドプレート（またはそのボルトの1つ）をクリックして接合部を選択します。{{ui:プレート、ボルト、溶接 (mm)}} の下で:

| 設定 | 初期値 | 内容 |
|---|---|---|
| プレート厚さ | 20 | プレートの厚さ。梁がフランジを越えて切り戻される長さにも影響します |
| プレート幅 | 180 | 接合部を横切る幅 |
| 梁の上への突出 | 0 | 上フランジより上。0 より大きいと延長エンドプレートになります |
| 梁の下への突出 | 0 | 下フランジより下 |
| ボルト径 | 20 | 呼びボルトのサイズ |
| 孔径 | 22 | プレートと柱フランジの逃げ孔 |
| ボルトの強度区分 | A325 | テキスト。部材表に表示されます |
| ボルトの列数 | 4 | 2本1組の列数。プレート高さの中央に配置されます |
| 列ピッチ | 75 | 列間の鉛直間隔 |
| ゲージ | 100 | 1列の2本のボルトの水平間隔 |
| ボルト長さの余裕 | 30 | ナット、座金、ねじ部のため、把握長さに加算されます。下記参照 |
| すみ肉溶接サイズ | 8 | 梁端の全周 |
| プレートの材質 | A36 | テキスト |

新しい値を入力し、{{key:Enter}} または {{key:Tab}} を押します。プレート、孔、ボルト、梁の切断長さがすぐに更新されます。各変更は1回の元に戻す操作になります。

設定の下には、接合部が作るものが表示されます:

- {{ui:ボルト}}: 例「8 × 20 × 70 A325（把握長さ 36.2）」。
- {{ui:溶接}}: サイズ、位置、長さ。
- {{ui:プレート}}: サイズと部材符号。

### 数値の求め方

- 梁は、柱の奥行きの半分（ウェブの場合はウェブ厚の半分）にプレート厚を加えた分だけ切り戻されるため、プレートが面に収まります。
- プレートの高さは、梁の高さに上下の突出を加えたものです。
- ボルト長さ = 把握長さ（プレート厚 + 柱フランジまたはウェブ厚）+ 余裕、次の 5 mm の倍数に切り上げ。
- 表示される溶接長さは、梁断面の周長です。

### 警告

接合部は引き続き作成されますが、次の警告が接合部の下と {{ui:問題}} タブに表示されます:

- ボルトの列またはボルトが、孔径の 1.2 倍より近くでプレートの縁に寄っている。
- 列ピッチが孔径の 2.2 倍未満、またはゲージが孔径の 2.4 倍未満。
- 孔が柱のウェブやそのフィレットに入る、または柱フランジからはみ出す。
- プレートが柱フランジより広い、またはウェブ上の場合にフランジ間の幅より広い。梁フランジがその間に収まらない。
- ボルトの列が梁フランジに近すぎる、またはゲージが梁ウェブとその溶接に対して狭すぎる。

## 同様のすべての接合部にコピー

1. 設定した接合部を選択します。
2. {{ui:プロパティ}} パネルの {{ui:同様に適用 (n)}}、または {{ui:接合}} グループの {{ui:その他}} メニューの {{ui:同様に適用}} を選びます。括弧内の数字は、接合を受け取る接合部の数です。
3. 同じ梁断面と柱断面で、同じ種類の面に梁が接続し、まだ接合部がないすべての接合部に、同じ設定のコピーが作られます。ステータスバーに件数が表示されます。

コピーは独立しているため、後で1つを変更しても他には影響しません。すでに接合部がある箇所は変更されません。それらを置き換えたい場合は、先に削除してください。

## 移動と削除

接合部は、モデルが変更されるたびに設定から作り直されます。そのため、梁や柱を移動または寸法変更すると、エンドプレートも一緒に移動します。変更によって接合部が合わなくなった場合でも、接合部はモデルに残り、{{ui:問題}} タブに理由が表示されます（例:「梁端がもはや柱の通り芯上にありません。」）。

接合部を削除するには、選択して {{key:Delete}} を押します。梁または柱を削除すると、その接合部も削除されます。
