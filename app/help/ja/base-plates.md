ベースプレート接合は、柱の下にプレートを配置し、柱をプレートの厚さの分だけ短く切断して両者を溶接し、プレートの穴を通す4本のアンカーボルトを追加します。

:::warning
寸法は開始値であり、設計ではありません。DetailCraftは支圧、アンカーボルトの強度、埋込み長さを確認しません。
:::

## ベースプレートを追加する

1. {{ui:選択}}({{key:V}})を選び、柱をクリックします。柱は鉛直である必要があります。
2. {{ui:接合}}グループの{{ui:ベースプレート}}、または{{ui:プロパティ}}パネルの{{ui:ベースプレートを追加}}を選びます。
3. ステータスバーに「ベースプレートを4本のアンカーボルトとともに追加しました。」と表示されます。新しい接合が選択されます。

柱に設定できるベースプレートは1つです。すでにある場合、ステータスバーに「この柱にはすでにベースプレートがあります。」と表示されます。

## 変更する

ベースプレートを選択します(プレートまたはアンカーボルトをクリック)。{{ui:プレート、ボルト、溶接 (mm)}}の下で次の項目を設定します。

| 設定 | 既定値 | 内容 |
|---|---|---|
| プレート厚さ | 25 | 柱はこの分だけ短くなります |
| プレートの長さ | 450 | 柱の奥行方向 |
| プレートの幅 | 400 | 柱の幅方向 |
| アンカーボルトの径 | 20 | アンカーボルトの寸法 |
| 穴径 | 33 | プレートの穴 |
| ボルトの等級 | F1554 Gr 36 | アンカーボルトの等級(テキスト) |
| アンカーボルト間隔(奥行方向) | 350 | プレートの長さ方向における、アンカーボルトの中心間 |
| アンカーボルト間隔(幅方向) | 300 | 幅方向における、アンカーボルトの中心間 |
| プレート上面からのアンカーボルト突出し | 100 | プレート上面からアンカーボルトの先端まで |
| プレート下面からのアンカーボルト埋込み | 450 | プレート下面からコンクリート内へ |
| すみ肉溶接のサイズ | 8 | 柱脚の全周 |
| プレートの材質 | A36 | テキスト |
| グラウトの隙間 | 0 | コンクリート上面とプレート下面の間の隙間 |
| スチフナー | なし | 「なし」、2(ウェブと同一線上)、4(さらにウェブと直交)から選択します。下記を参照 |
| スチフナーの厚さ、高さ | 12, 150 | |
| シアキーの深さ | 0 | シアキーがプレートの下へ伸びる長さ。0 = シアキーなし |
| シアキーの厚さ、幅 | 25, 150 | |
| プレート座金 | なし | すべてのアンカーボルトに付けるか、なし |
| 座金のサイズ、厚さ | 0, 0 | 0 = アンカーボルトに対するAISC Design Guide 1の最小値 |

アンカーボルトの長さ = 埋込み長さ + グラウトの隙間 + プレート厚さ + 突出し長さ です。既定値では575 mmになります。

## ベースの詳細: グラウト、スチフナー、シアキー、座金

4つすべては新しいベースプレートでは無効です。DetailCraft 0.4より前に作成されたモデルのベースプレートでも無効です。

- **グラウトの隙間。** プレートはコンクリート上面からこの距離だけ上に配置され、アンカーボルトはその分長くなります。AISC Design Guide 1 (2.10)では、仕上げ床では1 in.、フーチングまたは柱脚台では1½〜2 in.を推奨しています。大型のプレートやシアキーを持つプレートでは、さらに大きくします。
- **スチフナー。** 柱とプレートに溶接された鉛直のプレートで、柱の面からプレートの端まで、長方形として作成されます(面取りやテーパーはまだありません)。**2**は各フランジの外側で、ウェブと同一線上に配置されます。**4**では、さらにウェブと直交する2枚が、フランジの間に入り、プレートの側面まで伸びます。鋼管柱では各面の中央に配置されます。各スチフナーは両側で柱とプレートに溶接されます。
- **シアキー。** ベースプレートの下に全周溶接され、柱の奥行方向に揃えて中央に配置されたプレートです。グラウトの隙間以下の深さの場合、DetailCraftが警告します。フーチングにポケットは切り込みません。そのため、[干渉チェック](topic:clash-check)では、シアキーとフーチングを対象から除外します。
- **プレート座金。** 各アンカーボルトに付く角形のプレート座金で、ベースプレートの上に置かれ、柱のアセンブリ内で単独部材として一覧されます(柱とともに出荷され、溶接はされません。Design Guide 1, 2.6)。サイズと厚さが0の場合、DetailCraftはアンカーボルトに対して AISC Design Guide 1, 2nd ed., Table 2.3 の最小座金を使用します。メートル法のアンカーボルトでは、次のインチサイズを使用します(M20のアンカーボルトでは7/8 in.の行を使い、2½ in. × 5/16 in.になります)。使用されたサイズはプロパティパネルに表示されます。座金の穴径はアンカーボルト径 + 1/16 in.です。これはDetailCraftの選択で、表では指定されていません。アンカーボルトの突出しが座金とナットに足りない可能性がある場合(突出し長さ < 座金の厚さ + アンカーボルト径)、DetailCraftが警告します。

Design Guide 1、Table 2.3では、プレートのアンカーボルト穴も推奨しています。¾ in.のアンカーボルトでは1-5/16 in.、⅞ in.では1-9/16 in.、1 in.では1-13/16 in.です。DetailCraftは穴径を変更しません。

次の場合にも警告が表示されます。アンカーボルトの穴がプレート端から穴径の1.2倍より近い場合、アンカーボルトが柱の外形の内側に入る場合、またはプレートが柱より小さい場合です。

## 同様の柱にコピーする

1. ベースプレートを選択します。
2. {{ui:同様に適用(n)}}を選ぶか、{{ui:接合}}グループの{{ui:その他}}メニューから{{ui:同様に適用}}を選びます。
3. 同じ断面形状で、ベースプレートがなく、別の柱の上に載っていない鉛直のすべての柱に、コピーが作成されます。

## ベースプレートとフーチング

ベースプレートにはフーチングは不要で、フーチングは上のベースプレートを認識しません。アンカーボルトはフーチングの鉄筋とは結合されません。フーチングは{{ui:フーチング}}で配置します。[鉄筋付きでフーチングを配置](topic:footings-and-rebar)を参照してください。
