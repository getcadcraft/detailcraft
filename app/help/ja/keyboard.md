このヘルプでのキーの書き方: [キー、マウス、トラックパッド](common:keys)。Macでは{{key:Mod}}がCommandキーで、それ以外ではCtrlキーです。

## ツール

これらは、カーソルが文字欄や数値欄にないときに機能します。

| キー | 操作 |
|---|---|
| {{key:V}} | {{ui:選択}} |
| {{key:B}} | {{ui:梁}} |
| {{key:C}} | {{ui:柱}} |
| {{key:R}} | {{ui:ブレース}} |
| {{key:P}} | {{ui:プレート}} |
| {{key:F}} | {{ui:フーチング}} |
| {{key:S}} | {{ui:階段}} |
| {{key:M}} | 通り芯の交点を2つ指定して選択範囲を移動します（[窓選択、移動、回転、鏡像、多数の変更](topic:select-and-change)） |
| {{key:Esc}} | ドラッグ中の選択窓を解除します。ドラッグ中のパーツを元の位置に戻します。移動、梁・ブレース・プレートの1点目、貼り付けを取り消します。もう一度押すと{{ui:選択}}に戻ります。{{ui:選択}}中は選択を解除します。{{ui:その他}}メニューが開いているときは、それを閉じます |
| {{key:Delete}} または {{key:Backspace}} | 選択を削除します（すべて1回の元に戻す操作で取り消せます） |

## ファイルと編集

| キー | 操作 |
|---|---|
| {{key:Mod+S}} | モデルを保存します（ダウンロード）。文字欄に入力中でも機能します |
| {{key:Mod+O}} | モデルを開きます。文字欄に入力中でも機能します |
| {{key:Mod+Z}} | 元に戻す（文字欄の外）。文字欄の中では入力内容を元に戻します |
| {{key:Mod+Y}} または {{key:Mod+Shift+Z}} | やり直し |

## コピーと貼り付け

これらは、カーソルが文字欄や数値欄にないときに機能します（その場合は、通常どおり文字をコピー、貼り付け、選択します）。貼り付け、切り取り、複製、削除は、それぞれ1回の元に戻す操作になります。詳細: [コピー、貼り付け、複製](topic:copy-paste)

| キー | 操作 |
|---|---|
| {{key:Mod+C}} | {{ui:コピー}}選択した部材とフーチングをコピーします（穴、切欠き、接合を含みます） |
| {{key:Mod+X}} | {{ui:切り取り}}: 選択をコピーしてから削除します |
| {{key:Mod+V}} | {{ui:貼り付け}}: コピーがポインターに追従します。通り芯の交点をクリックして配置します |
| {{key:Mod+Shift+V}} | {{ui:同じ位置に貼り付け}}: コピー元の座標に貼り付けます |
| {{key:Mod+D}} | {{ui:複製}}: すぐにコピーを作成し、[DetailCraftの設定](topic:settings)で指定したオフセット分ずらします |
| {{key:Mod+A}} | {{ui:すべて選択}}: すべての部材、接合、フーチング |
| {{key:Esc}} | {{ui:選択解除}} |

ページ上の文字（たとえば報告書の表）を選択していて、モデル内では何も選択していない場合は、{{key:Mod+C}}は通常どおり文字をコピーします。

{{ui:新規}}、{{ui:サンプル}}、書き出しにはキーがありません。ツールバーを使用してください。

ダイアログ（施工図のプレビューや確認）が開いている間は、これらのキーはいずれも機能しません。

## 欄とパネル

| キー | 操作 |
|---|---|
| {{key:Enter}} または {{key:Tab}} | 入力した値を適用します（変更はそれぞれ1回の元に戻す操作になります） |
| {{ui:通り芯}}、{{ui:レベル}}、{{ui:カスタム断面}}、穴または切欠きの欄での {{key:Enter}} | そのフォームのボタンを選ぶ操作と同じ |
| {{key:Left}} {{key:Right}} | タブにフォーカスがあるとき、{{ui:問題}}、{{ui:部品表}}、{{ui:加工帳}}タブの間を移動します |
| {{key:Esc}} | 施工図のプレビューまたは確認ダイアログを閉じます（{{ui:キャンセル}}と同じ） |

## 画面とヘルプ

| キー | 操作 |
|---|---|
| {{key:Ctrl+Shift+F}} | 通常表示、全画面表示、バーを隠した全画面表示の順に切り替えます。すべてのコンピューターでCtrlを使います。Macも含みます |
| {{key:Mod+,}} | {{ui:設定}}を開きます（[DetailCraftの設定](topic:settings)） |
| {{key:Esc}} | 全画面表示を終了します |
| {{key:F1}} | このヘルプを開きます |

## マウス

| 操作 | 3D | 平面と立面 |
|---|---|---|
| クリック | パーツを選択します。配置ツールがオンのときは、最も近い交点に配置します（貼り付け中は、そこに貼り付けます） | 同じ |
| {{key:Shift}}、{{key:Ctrl}}、または {{key:Mod}} を押しながらクリック | パーツを選択に追加、または選択から外します | 同じ |
| 選択したパーツを押してドラッグ | 選択を同じレベル内で移動します。{{key:Mod}} を押しながらの場合は上下に移動します | 選択を移動します（立面では、その方向と上下に移動します） |
| 左ボタンでドラッグ | モデルを回転します | {{ui:選択}}中: 選択窓（右へ: 完全に内側にあるもの、左へ: 触れているもの）。配置中: パン |
| {{key:Shift}} を押しながら左ボタンでドラッグ | {{ui:選択}}中: 選択窓で、選択に追加します。配置中: パン | {{ui:選択}}中: 選択窓で、選択に追加します |
| {{key:Ctrl}} または {{key:Mod}} を押しながら左ボタンでドラッグ | パン | 何もしません |
| 右ボタンでドラッグ | パン | パン |
| ホイール | ビューの中央に向かってズーム | ズーム |
| 中ボタンでドラッグ | ズーム | {{ui:選択}}中: パン。それ以外はズーム |
| `.detailcraft.json` ファイルをアプリにドロップ | 開きます | 開きます |

クリックとみなされるのは、押してから離すまでにポインターの移動が約5ピクセル未満の場合だけです。それより長く動かした場合はドラッグになります。

## トラックパッド

| 操作 | 機能 |
|---|---|
| 2本指で上下にスワイプ、またはピンチ | ズーム |
| 押してドラッグ | 回転（3D）またはパン（平面と立面） |
| {{key:Shift}} を押しながら押してドラッグ | 3Dでパン |
| 2本指でクリック | 右クリック（ビュー内にメニューはありません） |

## タッチ

タブレットまたはタッチスクリーンの場合:

| 操作 | 機能 |
|---|---|
| タップ | パーツを選択します。配置ツールがオンのときは、最も近い通り芯の交点に配置します（指1本分程度の範囲内のタップも対象になります） |
| パーツを長押し | 選択に追加、または選択から外します（マウスで {{key:Shift}}+クリックしたときと同じ） |
| 選択したパーツを1本指で押してドラッグ | 選択を移動します。通り芯の交点にスナップします |
| ほかの場所を1本指で | モデルを回転（3D）またはパン（平面と立面） |
| 2本指 | ピンチでズーム、2本指をそろえて動かすとパン |

画面がタッチ専用の場合、ボタン、一覧、欄は大きく表示されます。選択窓にはマウスが必要です。指の場合は、タップと長押しを使ってください。

## ブラウザーが使うキー

一部のショートカットはブラウザーのもので、どのページでも使用できません。たとえば {{key:Mod+W}}（タブを閉じる）、{{key:Mod+T}}（新しいタブ）、{{key:Mod+N}}（新しいウィンドウ）です。{{key:Mod+Y}} でやり直しではなくブラウザーの履歴が開く場合は、{{key:Mod+Shift+Z}} を使用してください。

ショートカットがDetailCraftに届くのは、ページがキーボード入力を受け付けている場合だけです。キーが何もしない場合、またはブラウザーが代わりに動作する場合は、まずDetailCraftのウィンドウの空いている部分をクリックしてください（たとえばアドレスバーに入力した後など）。

## 移動の場所

移動コマンドはありません。パーツを選択して同じレベル内でドラッグするか（{{key:Mod}} を押しながらドラッグすると上下に移動します）、{{ui:プロパティ}}で {{ui:始点}} と {{ui:終点}} を編集してください。
