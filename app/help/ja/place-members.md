部材は通り芯の交点に配置します。柱は1つの交点に、梁とブレースは2つの交点の間に配置します。先に[通り芯とレベル](topic:grids-and-levels) を設定してください。

## ツールとそのオプションを選ぶ

1. {{ui:配置}} グループで {{ui:柱}}({{key:C}})、{{ui:梁}}({{key:B}})、または {{ui:ブレース}}({{key:R}}) を選びます。
2. 右側の {{ui:プロパティ}} パネルが「柱を配置」(または梁、ブレースを配置)に変わり、次に配置する部材のオプションが表示されます:
   - {{ui:断面形状}}: 一覧から選びます。断面はカタログごとにグループ化されています(W 形鋼、溝形鋼、山形鋼、HSS、IPE、HEA、HEB、UB、UC、PFC、EA、UEA、SHS、RHS、CHS、およびあなたのカスタム断面)。[断面カタログ](topic:profile-catalog) を参照してください。
   - {{ui:材質}}: A992、A36、A572 Gr 50、A500 Gr C、S235、S275、S355 から選びます。
   - {{ui:位置}}: 2点の間の線に対して断面をどこに置くか: {{ui:鉄骨の上端を通り芯上に}}、{{ui:通り芯の中央に}}、または {{ui:鉄骨の下端を通り芯上に}}。
   - {{ui:回転角 (°)}}: 部材自身の軸まわりに断面を回転させます。
   - {{ui:上端}}(柱のみ): {{ui:直上のレベル}}、またはレベル名。
3. オプションの下の {{ui:断面形状}} ボックスには、選んだ断面の寸法、断面積、メートルあたりの質量、およびその断面が属するカタログが表示されます。

初期設定は、柱が A992 の W12x50(中央)、梁が A992 の W16x26(鉄骨の上端を通り芯上に)、ブレースが A500 Gr C の HSS6x6x1/4(中央)です。オプションは、変更するまで保持されます。

## クリックして配置する

### 柱

1. {{ui:平面}} を選び、柱が始まるレベルを選びます。
2. {{ui:柱}} を選びます。
3. ポインターを交点の近くに動かします。最も近い点が点灯し、ステータスバーにその名前が表示されます。
4. クリックします。柱はそのレベルから、次の上のレベル(または {{ui:上端}} のレベル)まで伸びます。ステータスバーには、たとえば「A/1 の柱 W12x50、レベル1からレベル2まで」のように表示されます。
5. クリックを続けると、さらに配置できます。終了するには {{key:Esc}} を押します。

クリックしたレベルより上にレベルがない場合、ステータスバーに「柱が到達できる、レベル2より上のレベルがありません。先にレベルを追加してください。」と表示されます。

### 梁

1. {{ui:平面}} を選び、梁のレベルを選びます。
2. {{ui:梁}} を選びます。
3. 最初の交点をクリックします。ステータスバーに「A/1、レベル2から開始。次に反対側の端をクリックしてください(Esc でキャンセル)。」と表示されます。破線がポインターに追従します。
4. 2番目の交点をクリックします。梁が表示されます。
5. 続けてクリックすると次の梁を開始します。または {{key:Esc}} を押します。

最初のクリックの後で {{key:Esc}} を押すと、その点だけがキャンセルされます。2回目の {{key:Esc}} で、ツールを終了します。

### ブレース

ブレースは異なるレベルの2つの交点の間に配置されるため、{{ui:立面}} で行うのが最も簡単です。

1. {{ui:立面}} を選び、ブレースがある英字の通り芯を選びます。
2. {{ui:ブレース}} を選びます。
3. 下端、次に上端をクリックします。

立面は英字の通り芯にのみ存在します。数字の通り芯に沿った架構のブレース(A から B まで)には、{{ui:3D}} または下記の {{ui:通り芯で追加}} フォームを使用してください。

:::touch
タッチスクリーンでは、交点の近くをタップしてください。タップは、短い距離内で最も近い点を選びます。近くに点がない場合は何もしません。タップの前にハイライトは表示されません。そのため、タップごとにステータスバーのメッセージを確認してください。1本指でドラッグすると、配置ではなくビューの回転またはパンになります。
:::

## クリックせずに通り芯で配置する

配置ツールにはすべて、{{ui:プロパティ}} パネルの下部に {{ui:通り芯で追加}} フォームがあります。キーボードだけで操作でき、3D ビューは必要ありません。

1. ツールを選びます(例: {{ui:梁}})。
2. {{ui:通り芯で追加}} で、{{ui:開始の通り芯 (英字)}}、{{ui:開始の通り芯 (数字)}}、{{ui:開始のレベル}} を選びます。
3. {{ui:終了の通り芯 (英字)}}、{{ui:終了の通り芯 (数字)}}、{{ui:終了のレベル}} を選びます。
4. {{ui:追加}} を選びます。

柱またはフーチングの場合、フォームの点は1つだけです。{{ui:通り芯 (英字)}}、{{ui:通り芯 (数字)}}、{{ui:レベル}} です。

## 配置後に部材を変更する

1. {{key:Esc}} を押す(または {{ui:選択}}、{{key:V}} を選ぶ)、次に部材をクリックします。
2. {{ui:プロパティ}} パネルで、{{ui:名前}}、{{ui:断面形状}}、{{ui:材質}}、{{ui:位置}}、または {{ui:回転角 (°)}} を変更します。
3. 部材を移動するには、{{ui:端点 (x, y, z mm)}} の下にある {{ui:始点}} または {{ui:終点}} の x、y、z を編集します。各端の通り芯名は下に表示され、通り芯上にない場合は座標が表示されます。

変更はそれぞれ、元に戻す1回分です。項目の下には、部材の {{ui:部材符号}}、{{ui:アセンブリ}}、{{ui:切断長さ}}、{{ui:重量}}(総重量。穴と切欠きは差し引かれません)、および断面の出典カタログが表示されます。

部材はまだドラッグや配列複写ができません。同じ部材を作るには、コピーして貼り付けるか、複製({{key:Mod+D}})してください。[コピー、貼り付け、複製](topic:copy-paste) を参照してください。

## 部材を削除する

部材を選択して {{key:Delete}} または {{key:Backspace}} を押すか、{{ui:削除}} を選びます。その部材に接続されたものも削除されます。{{key:Mod+Z}} で、すべて元に戻せます。

## 知っておくと良いこと

- **柱の向き。** {{ui:回転角 (°)}} が 0 の場合、柱のフランジは x 方向、つまり隣接する番号付き通り芯の方向を向きます。通り芯1から2への梁はフランジに取り付き、A から B への梁はウェブに取り付きます。エンドプレートはフランジにのみ取り付けられるため、梁が A から B に向かう場合は、それらの柱の回転角を 90 にしてください。
- **レベルの梁は、初期設定の {{ui:鉄骨の上端を通り芯上に}} を使うと、レベルの下に垂れ下がります。** レベルが部材の中心線の場合は、{{ui:通り芯の中央に}} を選んでください。
- **柱はレベルからレベルまで伸びます。** 2階をまたぐ柱は、{{ui:上端}} を上のレベルに設定してください。
- **傾斜した梁**は配置できます(異なるレベルの端点を選びます)が、その上にエンドプレートはまだ作成されません。
