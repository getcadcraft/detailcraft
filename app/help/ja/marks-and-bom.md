DetailCraftはモデルに自動で符号を付けます。番号付けのコマンドはなく、実行するものもありません。変更するたびに、どの部材が同じ鋼材であるかを判定し、1つの符号を付けます。

## 符号の表示場所

- {{ui:モデル}}パネルの{{ui:部材符号}}一覧: 各符号と、断面形状、長さ、個数。符号をクリックすると、その符号を持つ最初の部材が選択されます。
- 選択した部材の{{ui:プロパティ}}パネル(および左パネルの**部材符号**一覧): {{ui:部材符号}}と{{ui:アセンブリ}}。パネルの見出しにも符号が表示されます(例: 「梁 b1」)。
- {{ui:部品表}}タブ、CSV、NCファイル名、施工図、IFCエクスポート(各要素のタグとして)。

## 部材の符号の付け方

- **部材符号:** 柱はc、梁はb、ブレースはbr、階段の側桁はst、プレート(エンドプレートとベースプレートを含む)はpです。その後に番号を付けます: c1、c2、b1、p1 … 部材が複数のフェーズにある場合、フェーズ番号が先頭に付きます。例: 2-b1。
- **アセンブリ符号:** C、B、BR、またはPです。アセンブリは主部材と、それに溶接されたプレートで構成されます。例えば、両端にエンドプレートを持つ梁、またはベースプレートを持つ柱です。
- 2つの部材は、断面形状、材質、切断長さ、穴と切欠きが同じで、すべて1 mm以内の場合に同じ符号を持ちます。一方が他方に対して端を入れ替えたり上下逆にしたりしている場合も含みます。
- 番号は柱を先頭に、次に梁、ブレース、プレートの順に付けられます。それぞれの中では、断面名順、次に長い順です。

溝形鋼と山形鋼について、どの回転を同一とみなすかを含む完全な規則は、[符号の規則](topic:mark-rules)を参照してください。

:::warning
符号は変更のたびに新しく算出されるため、番号が振り直される場合があります。部材の追加、断面形状の変更、穴の追加により、b3がb4に変わることがあります。符号を確定とみなすのは、モデルが完成してからにし、部品表、NCファイル、施工図は同じ保存済みモデルから作成してください。
:::

## 部品表を読む

下部の{{ui:部品表}}タブを開きます。3つの表があります。

**部材**(見出しに鋼材の合計重量を表示):

| 列 | 意味 |
|---|---|
| 部材符号 | クリックすると、この符号を持つ最初の部材を選択します |
| 種類 | 梁、柱、ブレース、側桁、プレート |
| 断面形状 | 例: W16x26 または PL20x180 |
| 材質 | 設定した等級 |
| 長さ (mm) | 接合後の切断長さ |
| 個数 | 数量 |
| 単位重量 (kg) | 1 mあたりの断面質量 × 長さ |
| 合計重量 (kg) | 単位重量 × 個数 |

最後の行に、合計個数と合計重量が表示されます。

**アセンブリ:** 各アセンブリ符号、主部材、すべての構成部材(例: 「b1 + p1 + p1」)、個数、単位重量、合計重量。

**ボルトとアンカーボルト:** 種類、径、長さ、等級ごとにグループ化され、個数を表示します。

:::note
重量は総重量です。穴と切欠きは差し引かれません。ボルト、ナット、座金、溶接は鋼材重量に含まれません。
:::

## ダウンロード

タブの{{ui:CSV をダウンロード}}、または{{ui:出力}}グループの{{ui:部材表}}を選びます。ファイル`<name> BOM.csv`には3つの表が順番に、それぞれの見出しの下に、空行を挟んで含まれます。任意の表計算ソフトで開けます。

## 送付前の確認

1. {{ui:問題}}タブを開き、すべての行を解消します。作成できなかった接合にはプレート、穴、ボルトが追加されないため、部品表が不足します。
2. 想定していない符号がないか確認します。同じだと思われる2本の梁に異なる符号が付いている場合、通常は穴、切欠き、切断長さのいずれかが異なります。それぞれを選択して比較してください。
3. モデルを保存してから、その保存済みの状態からすべてのエクスポートを行います。
