Tekla Structures で詳細設計をしている場合、DetailCraft の大部分はなじみのあるものに見えるでしょう。通り芯、レベル、カタログの断面、部材と組立品、接合、番号付け、NC ファイル、IFC などです。規模はかなり異なります。Tekla Structures は本格的な生産システムであり、DetailCraft は小規模で新しいブラウザーアプリで、いくつかの作業を最初から最後まで行います。このページでは、今までの操作がどこで引き継げ、どこで引き継げないかを説明します。

:::tip
Tekla Structures のリボンに慣れている場合は、{{ui:設定}} › {{ui:DetailCraft}} › {{ui:メニュー、キー、マウス}} で {{ui:鉄骨リボン}} のメニュースタイルを選んでください。モデリング、詳細設計、編集、図面、製作、表示の各タブが表示され、中ボタンでパンします。AutoCAD から移行して、コマンドを入力するのが好みの場合は、{{ui:製図クラシック}} でコマンドラインが追加されます（BEAM、COLUMN、ENDPLATE、ZOOM …）。[メニュー、キー、マウス](topic:menus-keys-and-mouse) を参照してください。
:::

## 早見表

| 今までの操作 | DetailCraft では |
|---|---|
| 座標付きのグリッドダイアログで通り芯を作成 | {{ui:通り芯}}（左パネル）: 通り芯の間隔とラベル。絶対座標ではありません。番号付きの通り芯は一方向に、英字の通り芯はもう一方向に伸びます |
| Z 座標の通り芯としてのレベル | 独立した {{ui:レベル}} の一覧。行ごとに名前と標高を設定し、{{ui:レベルを適用}} で適用します |
| スナップを使って任意の点を指定 | クリックは通り芯の交点にのみスナップします。通り芯以外の点は、部材の {{ui:端点 (x, y, z mm)}} に入力します |
| 柱、梁、プレートのコマンド | {{ui:柱}} ({{key:C}})、{{ui:梁}} ({{key:B}})、{{ui:ブレース}} ({{key:R}})、{{ui:プレート}} ({{key:P}})、{{ui:フーチング}} ({{key:F}}) |
| 部品のプロパティダイアログ（部品をダブルクリック） | 1回クリックします。右側の {{ui:プロパティ}} パネルは常に有効です。ダイアログや「変更」「適用」ボタンはありません |
| 平面上の位置、回転、奥行きの設定 | {{ui:位置}}（鋼材の上面、中央、または線上の下端）と {{ui:回転角 (°)}}。個別の水平オフセットはありません |
| 断面カタログ | 公開されている 2,311 の固定断面（AISC W、S、C、L、HSS、Pipe、ヨーロッパの IPE、HEA、HEB、UPN、英国の UB、UC、PFC、EA、UEA、SHS、RHS、CHS、冷間成形中空断面）に加え、パラメトリックなプレートと、独自の {{ui:カスタム断面}} |
| 材料カタログ | 一覧に7つの等級: A992、A36、A572 Gr 50、A500 Gr C、S235、S275、S355 |
| 接合部品とそのダイアログの適用 | 梁を選択し、{{ui:エンドプレート}} を選びます。設定は {{ui:プロパティ}} パネルに表示されます。接合は2種類のみです（柱フランジへのエンドプレート、ベースプレート） |
| 自動接合、または接合を類似の接合にコピー | 接合を選択し、{{ui:同様に適用 (n)}} を選びます |
| 連番と開始番号による番号付け | 番号付けのコマンドはありません。符号は変更のたびに自動で更新されます。接頭辞は固定で、c、b、br、p と C、B、BR、P です |
| ボルトと穴のダイアログ | 穴は面と位置で入力します。ボルトは接合部からのみ作成されます |
| 切断、フィット、多角形切断ツール | コープ（上部または下部、どちらかの端部）はI形鋼のみです。接合部の切り戻しは自動です |
| レポートとテンプレート | 下部のタブに3つの固定レポートと、CSV ダウンロード |
| 図面の作成と図面一覧 | 部材符号ごとに1つの製作図を、すべて一度に作成します。プレビューしてから、1つの PDF またはシートごとにダウンロードします。何も保存・編集されません |
| NC ファイルの書き出し | {{ui:NC ファイル}}: 部材符号ごとに1つの DSTV ファイル。I形鋼とプレートのみで、ZIP にまとめられます |
| IFC 書き出し | {{ui:IFC}}: 鉄筋を含むモデル全体の IFC4 |
| 任意のコンクリート部品の鉄筋 | 鉄筋は矩形のパッドフーチングのみ。米国の鉄筋サイズ、下端筋と差し筋付き |
| プロジェクトフォルダーに保存、マルチユーザー | ダウンロードする `.detailcraft.json` ファイル1つ。単一ユーザーで、お使いのコンピューター上で動作します |
| 元に戻す履歴 | {{key:Mod+Z}} と {{key:Mod+Y}}。最大200ステップ。別のモデルを開くか開始するまで保持されます |

## 操作が混乱しやすい違い

### 符号は自動で変わる

番号付けの手順はありません。符号は変更のたびに再計算されるため、常に最新ですが、番号が振り直されることもあります。柱を追加すると、昨日の c3 が c4 になることがあります。古い符号を保持する「番号付けの履歴」はありません。モデルを完成させてから、保存済みの1つのファイルから部品表、NC ファイル、製作図をまとめて出力してください。

### 中ボタンはズームで、パンはしない

3D ビューでは、左ドラッグで回転、右ドラッグでパン、ホイールでズームします。中ボタンのドラッグでもズームします。{{key:Shift}} を押しながら左ドラッグすると、パンもできます。ホイールはポインターではなく、ビューの中心に向かってズームします。回転の中心を指定する機能はありません。モデルはビューの中央を中心に回転します。[3D ビューの移動](topic:navigate-3d) を参照してください。

### 柱は既定で一方向を向く

回転 0 のとき、柱のフランジは番号付き通り芯の方向に沿って向きます。英字の通り芯の間を走る梁は柱のウェブに取り付き、その場合はエンドプレートが拒否されます（「柱のウェブに取り付く梁はまだ作成されていません」）。接合を追加する前に、それらの柱を 90° 回転させてください。

### 立面は英字の通り芯のみ

{{ui:立面}} は英字の通り芯に沿ってのみ見ます。番号付きの通り芯に沿ったビュー、保存済みのビュー、作業面はありません。番号付きの通り芯上のフレームには {{ui:3D}} または {{ui:通り芯で追加}} を使ってください。

### 選択、コピー、移動

{{key:Shift}} + クリックまたは {{key:Mod+A}} で複数の部品を選択し、コピー、切り取り、貼り付け（通り芯の交点、入力したオフセット位置、または同じ位置）、複製ができます。接合も含まれます（[コピー、貼り付け、複製](topic:copy-paste)）。窓選択、選択フィルター、移動、鏡像、配列はありません。プロパティは {{ui:プロパティ}} パネルで部材ごとに変更します。

### 通り芯は部材を引きずらない

通り芯の間隔を変更しても、部材の座標は変わりません。通り芯線とともに動く部材はありません。鋼材を配置する前に通り芯を変更するか、後から各部材の端点座標を編集してください。

### 接合は設計されない

2種類の接合は、入力された数値に基づいてプレート、穴、ボルト、溶接を配置します。設計チェックは一切なく、端距離と間隔の警告のみです（EN 1993-1-8 表 3.3 より）。

### 3D ビューでは穴は切り欠かれない

穴は濃い色の栓として表示されます。穴は NC ファイル、製作図、IFC ファイルでは実際の穴になります。コープはビュー上で切り欠かれます。

### 重量は総重量

鋼材の重量では穴やコープは差し引かれず、ボルトの重量も含まれません。

### ミリメートルのみ

AISC 形鋼でも、すべての値はミリメートルで入力・表示されます。断面名は公開されている形式を保持します（W12x50、HSS6x6x1/4）。

### 管理する図面はない

図面一覧、図面エディター、一般配置図、組立図はありません。製作図は、要求したときに作成され、ダウンロードされます。変更するには、モデルを変更してから作り直してください。

### ブラウザーで動作する

保存するとファイルがダウンロードされます。ブラウザーが独自に使うキーボードショートカットは使えません。モデルはコンピューターの外に出ることはありません。[ファイルの送信先](common:your-files) を参照してください。

## 現在のソフトウェアで引き続き行うこと

現在、DetailCraft は小規模なフレーム、アイデアの確認、教育、単純な梁と柱の作業の NC ファイルと製作図の作成に適しています。複雑な接合、一般配置図、架設図、マルチユーザーのプロジェクト、そして [未作成の機能](topic:not-built-yet) に記載されているものは、現在お使いのソフトウェアで引き続き行ってください。
