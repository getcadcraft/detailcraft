DetailCraft は初期ビルドです。このページでは、まだできないことを示しますので、計画に組み込んでください。ここに示す内容は、いつ提供されるかを約束するものではありません。

## モデリング

| 未対応 | 代わりに今できること |
|---|---|

| 選択フィルター(梁のみ、断面1種のみ) | 窓選択でドラッグし、その後 {{key:Shift}}+クリックで部材を選択から外す |
| 選択範囲の配列複写、傾いた軸まわりの回転、傾いた面での鏡像 | オフセット位置にコピーして貼り付けるか、{{ui:複製}} を使う。回転と鏡像は平面上で使えます([窓選択、移動、回転、鏡像、一括変更](topic:select-and-change)) |
| クリック時に通り芯から外れた点 | 通り芯上に配置してから、端点の座標を入力する |
| 番号付きの通り芯に沿った立面、保存されたビュー、作業平面 | {{ui:3D}} を使うか、{{ui:通り芯で追加}} を使う |

| インチ・ポンド法での入力 | ミリメートルで入力してください(1インチ = 25.4 mm) |
| カスタム断面の編集や削除 | 修正した断面を新しい名前で追加する |

## 接続

DetailCraft は6種類の接続を作成します。ブレースのガセットプレート([ブレースのガセットプレート](topic:brace-gussets) を参照)。1本の H形鋼の2つの部分をつなぐボルト締めの継手([継手](topic:splices) を参照)。角度をもって接する2本の H形鋼の留め継ぎ(切断のみ、またはボルト締めのエンドプレート付き。[留め継ぎ](topic:mitres) を参照)。水平で鉛直な H形鋼の梁から、H形鋼の柱のフランジまたはウェブへの、面一または延長されたボルト締めのエンドプレート。梁(直角、斜め、または傾斜)から柱のフランジまたはウェブへのせん断タブ。そして、4本のアンカーボルトを持つ柱のベースプレートです。

| 未対応 | 代わりに今できること |
|---|---|
| 斜めまたは傾斜したエンドプレート | 斜めおよび傾斜した梁に対応する[せん断タブ](topic:shear-tabs)を使う |
| クリップアングル、詰め板付きの継手や異なる寸法どうしの継手、梁と柱に溶接するコーナーガセット、面取りしたガセット | 他のソフトウェアで詳細化するか、プレートと穴を単独の部材として手作業で追加してください。[継手](topic:splices)、[ブレースのガセットプレート](topic:brace-gussets) を参照 |
| 面取りまたはテーパーのベーススチフナー、グラウト孔、せん断キーのためのフーチングのポケット | 矩形のスチフナー。[ベースプレート](topic:base-plates) を参照 |
| ハンチ、突き合わせ溶接による溶接留め継ぎ、他方の部材のフランジと一直線のスチフナー | エンドプレートとウェブスチフナー付きの[留め継ぎ](topic:mitres)、または単純な留め切断。その他のプレートは単独の部材として手作業で追加 |
| 接続部の設計照査(強度) | 接続部はエンジニアの計算で確認してください。DetailCraft は縁端距離と間隔について警告するだけです |
| 長穴 | 丸穴のみ |

## 解析

| 未対応 | 代わりに今できること |
|---|---|
| 鋼製 H形鋼以外の設計照査: 鋼管、山形鋼、溝形鋼、溶接形鋼、細長い部材またはクラス4の部材、ねじり、接続部。コンクリート: 横移動の細長比、ねじり、耐震詳細、スラブと壁 | {{ui:解析}} タブは、鋼製 H形鋼を AISC 360 または EN 1993-1-1 で照査します([設計規準による鋼部材の照査](topic:design-checks))。それ以外は「未照査」と表示されます。すべてエンジニアが確認してください |
| 座屈解析、振動 | 二次解析は P-Delta のみ(弾性)です。座屈解析はありません(固有値解析、応答スペクトル、時刻歴、プッシュオーバーは {{ui:解析}} タブにあります) |
| エンジニアが確認済みの設計照査 | それまでは補助としてご利用ください。頼る前に、2〜3の部材を手計算またはエンジニア自身のソフトウェアで確認してください |
| 面積から自動作成される床、風、雪の荷重 | 部材に荷重を手作業で、kN/m または kN で入力する |
| 部材のオフセット、偏心接合、引張専用のブレース、架構内のプレートとフーチング | 部材は作業線上で解析されます。ブレースは引張と圧縮の両方を負担します |

| 構造設計プログラム独自のファイルの読み込み | そのプログラムから IFC を書き出してください。IfcReinforcingBar は鉄筋として読み込まれます([IFC ファイルからの鉄筋](topic:reinforced-concrete#bars-from-an-ifc-file)) |

| BS 4449 H8–H40 以外のメートル法鉄筋(例: CSA 10M–35M) | ASTM のソフトメトリック呼称 #10–#36、または BS の鉄筋 |

| USD 書き出しのボルト穴、ボルト、溶接、フーチング | IFC、NC、部品表の出力に含まれます。[鉄骨モデルを USD で書き出す](topic:usd) を参照 |
| IFC ファイルからの接続、フーチング、長穴または矩形の穴、丸形鋼管の穴の読み込み | {{ui:IFC を読み込み}} は、梁、柱、部材、プレート、通り芯、レベル、丸穴、切欠き、ボルト、鉄筋を読み込みます。読み込めなかったものは、そのレポートに一覧されます |
| カスタムのレポートレイアウト | 3つの CSV ファイル |

## 対応プラットフォーム

- DetailCraft は、デスクトップ、ノートパソコン、タブレットの画面向けに作られています。スマートフォンでも使えます。モデル表示は維持され、レポートは下部のバーからシートとして開きますが、パネルの表示領域は狭くなります。
- オフラインで使うには、まずアプリバーの {{ui:オフライン用に保存}} で DetailCraft をオフライン用に保存してください。{{ui:オフライン対応済み}} と表示されたら、このビルドのすべての機能が接続なしで使えます。[オフラインでの作業](common:offline) を参照してください。

これらの制限が作業の妨げになる場合は、[サポートページ](https://getcadcraft.com/support) からお知らせください。今後何を作るかを決める際の参考にします。
