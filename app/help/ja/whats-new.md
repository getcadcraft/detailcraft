これは DetailCraft 0.8(2026年11月1日)と 0.8.1(2026年11月2日)の変更点です。0.7 と比較しています。0.7 は鋼材部材を確認するものでした。0.8 は揚重を計画し、接合を提案し、基礎と鉄筋を確認し、木造と軽量鉄骨の壁、床、屋根の枠組みを作成します。

## 新機能

### 建方

- **建方計画とムービー。** {{ui:建方}} タブで、クレーンの設置位置、最大フック高さ、荷重表に含まれない玉掛け具などを入力し、荷重表の各行を入力します。DetailCraft はアセンブリを 1 つずつ、フェーズの順、段ごとに吊り上げ、各吊りを、その作業半径での荷重表と設定した余裕と照合します。{{ui:ムービーを保存}} は、オフラインでどのブラウザー(スマートフォンを含む)でも再生できる HTML ファイルを 1 つ書き出します。荷重表を超える、荷重表の範囲外である、または高すぎる吊りは {{ui:問題}} に表示されます。これは入力された数値に基づく計画であり、揚重計画ではありません。[建方計画とムービー](topic:erection-movie) を参照してください。

### 接合

- **接合オートパイロット。** {{ui:オートパイロット}} タブは、接合のないすべての接合部を確認し、形状から接合を提案します。対象はベースプレート、シアタブ、モーメント梁としてマークした梁のエンドプレート、継手、ガセットです。等分布荷重、または片端のせん断力を入力すると、ボルト本数はボルトの設計強度に従って算出されます。{{ui:すべて追加}} を選ぶと、提案がすべて 1 回の元に戻す操作として追加されます。これらは確認用の初期値であり、接合設計ではありません。
- **施工性チェック。** {{ui:問題}} に、レンチが届かないボルト、ソケットに対して近すぎるボルト、サイズ制限を超える隅肉溶接、水がたまる中空断面が表示されます。溶接アクセスは新しい項目です。溶接トーチが届かない全周隅肉溶接は、邪魔になる部材と影響を受ける溶接の割合とともに一覧に表示されます。[施工性チェック](topic:constructability) を参照してください。

### 基礎と鉄筋

- **基礎チェック。** {{ui:基礎}} タブでは、入力した地盤条件に対して、フーチング、複合フーチング、マット基礎を確認します。使用荷重による支持力、滑動、転倒。割増し荷重による曲げ、せん断、押抜きせん断、定着、最小鉄筋量(ACI 318-19)。縁や隅に近い柱は、フーチングの縁で切り取られた断面で確認されます。沈下は地盤の弾性係数から求め、たわみ性のあるマットは地盤反力係数に基づくばねで解きます。杭群と擁壁には、それぞれ専用のパネルがあります。柱荷重は入力するか、{{ui:解析}} から取得できます。[基礎チェック](topic:foundation-checks) を参照してください。
- **鉄筋の混雑マップ。** {{ui:混雑}} タブは、各フーチングを上から見た熱マップを描きます。鉄筋が多すぎてコンクリートが下まで入りにくい箇所を、最小あき寸法の規定と照合して示します。最大骨材寸法とバイブレーターヘッドを入力した場合は、それらも考慮されます。[鉄筋の混雑マップ](topic:rebar-congestion) を参照してください。

### 枠組みと供給

- **木造と軽量鉄骨の枠組み。** {{ui:枠組み}} タブは、壁、床、屋根のパネルを、すべての部材、切断リスト、購入する材料、縮尺付きの施工図とともに作成します。{{ui:部材として配置}} で部材をモデルに配置し、{{ui:PDFシート}} で各パネルのシートを 1 枚ずつ保存します。寸法、間隔、まぐさは利用者が指定します。DetailCraft は、それらが荷重を支えられるかは確認しません。[木造と軽量鉄骨の枠組みパネル](topic:framing-panels) を参照してください。
- **サプライヤーの在庫とリードタイム。** {{ui:供給}} タブは、サプライヤーの在庫一覧(CSV)を読み込み、切断リストが購入する断面ごとに、在庫が十分かどうか、入荷までどれくらい待つかを表示します。在庫不足と入荷遅れの断面は {{ui:問題}} に表示されます。発注は行われません。[サプライヤーの在庫とリードタイム](topic:supplier-stock) を参照してください。

### 解析と設計

- **最初に壊れる箇所は？** {{ui:解析}} タブのボタンは、支配的な強度の組合せ、最も弱い部材、最初の部材が限界に達するまで荷重をどれだけ増やせるか、そしてボルトのせん断強度が分かっている場合は最も弱いエンドプレートまたはシアタブを求めます。組合せと設計基準を先に設定する必要があります。支圧、ブロックせん断、溶接、てこ作用は確認されません。接続されたアシスタントにも同じ内容を尋ねられます。
- **ライブ。** {{ui:ライブ: 編集のたびに解き直す}} にチェックを入れると、編集のたびに骨組みが解き直されます。
- **コンクリートなど。** 非横移動骨組の細長い柱は、増大モーメント(ACI 318-19 6.6.4.5)に対して設計されます。地震周期は、解析結果からレイリー法で求めることができます。板で構成されたスラブは、モーメントと一方向せん断から、各層に必要な鉄筋を求めます。[コンクリート部材の確認と地震荷重の作成](topic:concrete-and-seismic) を参照してください。
- **技術者による確認が必要です。** 基礎、コンクリートの確認、「最初に壊れる箇所」の結果は参考情報です。風荷重はまだ作成されていません。

### すべてのアプリ共通

- **言語。** ヘルプは 54 言語で提供されています。英語以外は、ネイティブスピーカーが確認するまでは機械翻訳の下書きです。10 言語は新規に追加されました(リトアニア語、ラトビア語、ボスニア語、マラーティー語、テルグ語、アルバニア語、アフリカーンス語、フィリピン語、スワヒリ語、ウズベク語)。
- **ツールバーの行数。** {{ui:設定}} › {{ui:全般}} › {{ui:ツールバーの行数}} で、折り返し、2 行、1 行のいずれかを選べます。すでに収まっているバーはそのままで、それ以外のバーは横にスクロールします。
- **プロパティグリッド。** 基礎の項目は共通のグリッドを使います。カテゴリを折りたためるほか、密度をコンパクトにできます。2*450 のような計算式の入力も引き続き使えます。
- **入力デバイス。** トラックパッド、ペン、3D マウス、コントローラー、MIDI でアプリを操作できます。[3D での操作](topic:navigate-3d) を参照してください。
- **問題パネル。** 新しいチェックの警告は、これまでと同じ {{ui:問題}} パネルに表示されます。
- **AI の接続。** 利用者が用意するアシスタントは、CadCraft Studio を通じて接続でき、8 つのアプリすべてで動作します。アシスタントが参照するのは、許可された内容のみです。ワンクリック接続、ホスト型コネクター、Studio での独自 API キーの設定はまだ提供されていません。[DetailCraft で AI アシスタントを使う](topic:use-with-ai-assistants) を参照してください。

## 0.8.1 で修正

- **Studio の言語。** Studio とパッケージ版は、実行中に言語を切り替えられるようになりました。以前は英語のみでした。すべてのプラットフォームでの動作は未検証です。言語が切り替わらない場合は、その旨を報告してください。
- **交差選択。** 0.8.1 のインストーラーには、0.8 の Web ビルドで既に正しく動作している窓選択の動作が含まれています。古いインストーラーには含まれていませんでした。
- **縦向きのタブレット。** 余ったグリッドの高さはキャンバスに割り当てられ、シートのレイアウトは 760 px 以下で切り替わります。

## まだ提供されていない機能

- **機械への NC 送信**はまだリリースされていません。
- **コンクリート用の風荷重**はまだ作成されていません。コンクリートと基礎の確認は、技術者による確認が必要です。
- **コード署名。** Windows インストーラーと macOS の .dmg は署名されていないため、Windows では警告が表示される場合があります。macOS では、右クリックしてから「開く」を選ぶ必要があります。

以前の変更は [0.7 の新機能](topic:whats-new-0-7) にあります。
