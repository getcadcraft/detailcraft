Հենահարթակային միացումը դնում է թիթեղ սյան տակ, կրճատում է սյունը թիթեղի հաստությամբ, եռակցում է երկուսը և ավելացնում չորս խարսխային ձող՝ թիթեղի անցքերով։

:::warning
Չափերը սկզբնական արժեքներ են, ոչ թե նախագիծ։ DetailCraft-ը չի ստուգում հենման դիմադրությունը, ձողերի ամրությունը և խորությամբ ամրացումը։
:::

## Հենահարթակի ավելացում

1. Ընտրեք {{ui:Ընտրել}} ({{key:V}}) և սեղմեք սյան վրա։ Այն պետք է լինի ուղղահայաց։
2. Ընտրեք {{ui:Հենահարթակ}} {{ui:Միացում}} խմբում կամ {{ui:Ավելացնել հիմքի թիթեղ}} {{ui:Հատկություններ}} վահանակում։
3. Կարգավիճակի գոտին ասում է՝ «Հենահարթակը ավելացված է չորս խարսխային ձողով»։ Նոր միացումը ընտրված է։

Սյունը կարող է ունենալ մեկ հենահարթակ։ Եթե արդեն ունի, կարգավիճակի գոտին ասում է՝ «Այս սյունն արդեն ունի հենահարթակ»։

## Փոխել այն

Ընտրեք հենահարթակը (սեղմեք թիթեղի կամ ձողի վրա)։ {{ui:Թիթեղ, հեղույսներ և եռակցում (mm)}} բաժնում՝

| Կարգավորում | Լռելյայն | Ինչ է անում |
|---|---|---|
| Թիթեղի հաստությունը | 25 | Սյունը կրճատվում է այսքանով |
| Թիթեղի երկարությունը | 450 | Սյան խորության երկայնքով |
| Թիթեղի լայնությունը | 400 | Սյան լայնքով |
| Ձողի տրամագիծը | 20 | Խարսխային ձողի չափը |
| Անցքի տրամագիծը | 33 | Անցքը թիթեղում |
| Հեղույսի դասը | F1554 Gr 36 | Ձողի դասը, որպես տեքստ |
| Ձողերի քայլը (խորության երկայնքով) | 350 | Ձողերի կենտրոնների միջև, թիթեղի երկարության երկայնքով |
| Ձողերի քայլը (լայնքով) | 300 | Ձողերի կենտրոնների միջև, լայնքով |
| Ձողի դուրսցցվածքը թիթեղից վերև | 100 | Թիթեղի վերևից մինչև ձողի վերևը |
| Ձողի խորությունը թիթեղից ներքև | 450 | Թիթեղի ներքևից ներս՝ բետոնի մեջ |
| Եռակցման կարի չափը | 8 | Ամբողջ շրջագծով սյան հիմքի շուրջ |
| Թիթեղի նյութը | A36 | Տեքստ |
| Ցեմենտաշաղախի բացվածք | 0 | Բետոնի վերևի և թիթեղի ներքևի միջև տարածություն |
| Կոշտացուցիչներ | Ոչ | Ընտրեք Ոչ, 2 (միջնապատի գծով) կամ 4 (նաև դրան ուղղահայաց)․ տե՛ս ստորև |
| Կոշտացուցչի հաստություն, բարձրություն | 12, 150 | |
| Սահքի ականջի խորություն | 0 | Որքան ցած է հասնում ականջը թիթեղից․ 0 = առանց ականջի |
| Սահքի ականջի հաստություն, լայնություն | 25, 150 | |
| Թիթեղե լվացարաններ | Ոչ | Յուրաքանչյուր ձողի վրա կամ առանց |
| Լվացարանի չափ, հաստություն | 0, 0 | 0 = նվազագույնը AISC Design Guide 1-ից ձողի համար |

Ձողի երկարությունը = խորությամբ ամրացում + ցեմենտաշաղախի բացվածք + թիթեղի հաստություն + դուրսցցվածք։ Լռելյայն արժեքներով դա 575 mm է։

## Հիմքի մանրամասները՝ ցեմենտաշաղախ, կոշտացուցիչներ, սահքի ականջ, լվացարաններ

Չորսն էլ անջատված են նոր հենահարթակի վրա, և DetailCraft 0.4-ից առաջ ստեղծված մոդելների հենահարթակների վրա։

- **Ցեմենտաշաղախի բացվածք.** Թիթեղը գտնվում է այս հեռավորության վրա բետոնի վերևից, և ձողերը նույն չափով երկարում են։ AISC Design Guide 1 (2.10)-ը առաջարկում է 1 in. ավարտված հատակի վրա և 1½–2 in. հիմքի կամ պոստի վրա․ ավելի շատ՝ մեծ թիթեղների և սահքի ականջով թիթեղների համար։
- **Կոշտացուցիչներ.** Ուղղահայաց թիթեղներ, որոնք եռակցված են սյանը և թիթեղին, սյան երեսից մինչև թիթեղի եզրը, որպես ուղղանկյուններ (դեռ չկա անկյունագիծ կամ նեղացում)։ **2**-ը կանգնում է միջնապատի գծով, թևերից դուրս․ **4**-ը ավելացնում է երկուսը միջնապատին ուղղահայաց, թևերի միջև, մինչև թիթեղի կողմերը։ Խողովակային սյան վրա դրանք կանգնում են յուրաքանչյուր նիստի մեջտեղում։ Յուրաքանչյուրը եռակցված է սյանը և թիթեղին երկու կողմից։
- **Սահքի ականջ.** Թիթեղ, որը շրջանաձև եռակցված է հենահարթակի տակ, սյան խորության գծով, կենտրոնացված։ DetailCraft-ը զգուշացնում է, եթե այն ավելի խորը չէ, քան ցեմենտաշաղախի բացվածքը։ Այն չի կտրում խորշը հիմքում․ այդ պատճառով [բախումների ստուգումը](topic:clash-check) բաց է թողնում ականջը և հիմքը։
- **Թիթեղե լվացարաններ.** Քառակուսի թիթեղե լվացարան յուրաքանչյուր ձողի վրա, հենված հենահարթակի վրա, սյան հավաքվածքում թվարկված որպես ազատ (առաքված սյան հետ, ոչ եռակցված․ տե՛ս Design Guide 1, 2.6)։ Չափը և հաստությունը 0 լինելիս DetailCraft-ը վերցնում է նվազագույն լվացարանը AISC Design Guide 1-ի, 2-րդ հրատ., Աղյուսակ 2.3-ից ձողի համար․ մետրային ձողը ստանում է հաջորդ ինչ-չափի շարքը (M20 ձողը ստանում է 7/8 in. շարքը՝ 2½ in. × 5/16 in.)։ Հատկությունների վահանակը ցույց է տալիս օգտագործված չափը։ Լվացարանի անցքը ձողի տրամագիծ + 1/16 in. է․ դա DetailCraft-ի ընտրությունն է, աղյուսակը այն չի տալիս։ DetailCraft-ը զգուշացնում է, եթե ձողերը կարող են չցցվել բավարար չափով՝ լվացարանի և ընկուզի համար (դուրսցցվածքը փոքր է լվացարանի հաստություն + ձողի տրամագիծ)։

Design Guide 1-ի Աղյուսակ 2.3-ը նաև առաջարկում է ձողի անցքը թիթեղում․ ¾ in. ձողի համար՝ 1-5/16 in., ⅞ in.-ի համար՝ 1-9/16 in., 1 in.-ի համար՝ 1-13/16 in.։ DetailCraft-ը չի փոխում ձեր անցքի չափը։

Զգուշացումներ են երևում նաև, երբ ձողերի անցքերը թիթեղի եզրին ավելի մոտ են, քան 1.2 × անցքի տրամագիծը, երբ ձողերը ընկնում են սյան ուրվագծի ներսում, կամ երբ թիթեղը ավելի փոքր է, քան սյունը։

## Պատճենել նմանատիպ սյուներին

1. Ընտրեք հենահարթակը։
2. Ընտրեք {{ui:Կիրառել նմանների վրա (n)}}, կամ {{ui:Նման}}՝ {{ui:Միացում}} խմբի {{ui:Ավելին}} ցանկում։
3. Յուրաքանչյուր ուղղահայաց սյուն, որը նույն պրոֆիլն ունի, չունի հենահարթակ և չի կանգնում մեկ այլ սյան վրա, ստանում է պատճեն։

## Հենահարթակներ և հիմքեր

Հենահարթակին հիմք պետք չէ, և հիմքը չգիտի իր վերևի հենահարթակի մասին․ խարսխային ձողերը չեն կապվում հիմքի ձողերին։ Հիմքերը տեղադրեք {{ui:Հիմք}} գործիքով․ տե՛ս [Հիմքերի տեղադրում արմատուրայով](topic:footings-and-rebar)։
