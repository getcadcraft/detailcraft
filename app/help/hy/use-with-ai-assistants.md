## Ինչ կսովորեք

Ինչպես թույլ տալ AI օգնականին (կամ ձեր գրած սցենարին) աշխատել DetailCraft-ի հետ և ինչպես որոշել, թե ինչին կարող է դիպչել։

DetailCraft-ը **սեփական AI չունի** և ոչինչ ոչ մի տեղ չի ուղարկում։ Դուք բերում եք օգնականը. ցանկացած ծրագիր, որը խոսում է Model Context Protocol (MCP)-ով։ DetailCraft-ը նրան տալիս է միայն գործիքներ, և դուք ընտրում եք, թե որոնք։

## Միացնել

1. Բացեք {{ui:Settings}} (հավելվածի գոտու փոցխը կամ {{key:Mod+,}}) և գնացեք {{ui:DetailCraft}} ներդիր։
2. {{ui:Assistants}}-ի տակ նշեք **Թույլ տալ AI օգնականներին և սցենարներին օգտագործել DetailCraft-ը**։ Այն անջատված է, մինչև դա չանեք։
3. Ընտրեք, թե ինչ կարող է անել. **Read**-ը սկզբից նշված է. նշեք **Edit**, **Save** կամ **Export**-ը միայն երբ դրանք անհրաժեշտ են։

Ձեր չնշած թույլտվություններից դուրս գործիքները օգնականին չեն առաջարկվում, և եթե նա այնուամենայնիվ խնդրի դրանցից մեկը, DetailCraft-ը մերժում է այն և գրանցում գործունեության մատյանում։ Անջատիչը անջատելը անմիջապես ավարտում է բոլոր միացումները։

## Միացնել օգնականը

Օգնականները միանում են ձեր համակարգչի **CadCraft Studio**-ի միջոցով. Studio-ն գործարկում է փոքր սերվեր, որին միայն այս համակարգիչը կարող է հասնել, պաշտպանված յուրաքանչյուր գործարկման ժամանակ իր ստեղծած թոքենով։ Studio-ում ընտրեք {{ui:Connect an assistant}} և պատճենեք հասցեն և թոքենը ձեր օգնականի մեջ (Studio-ն ցույց է տալիս ճիշտ կարգավորումները, որոնք պետք է տեղադրել)։ Երբեք մի տարածեք թոքենը։

:::note
Բրաուզերի ներդիրը չի կարող բացել միացում օգնականի համար. բրաուզերի հավելվածներում անջատիչը ոչ մի ազդեցություն չունի, մինչև չօգտագործեք CadCraft Studio ձեր համակարգչի վրա։
:::

## Դուք մնում եք վերահսկողության տակ

- **Յուրաքանչյուր փոփոխություն մեկ հետարկելու քայլ է**, պիտակավորված որպես օգնականինը (օրինակ՝ "Օգնական՝ ավելացնել գերան", "Օգնական՝ ավելացնել անկյունակներ")։ {{key:Mod+Z}}-ը հետ է վերցնում օգնականի վերջին փոփոխությունը ամբողջությամբ։ Օգնականի սեփական `undo`-ն հետ է վերցնում միայն իր քայլերը, երբեք ձերը, եթե հստակ չի խնդրում դա։
- **Այն սպասում է ձեզ։** Երբ դուք տեղադրում եք տարր, տեղափոխում մասեր կամ տեղադրում, DetailCraft-ը մերժում է օգնականի փոփոխությունները և ասում, որ նորից փորձի։
- **Դուք գիտեք, երբ որևէ բան է միացված։** Հավելվածի գոտում կոճակը անվանում է օգնականին, երբ այն միացված է. սեղմեք այն տեսնելու համար, թե ինչ կարող է անել, կամ **Disconnect** անելու համար։
- **Գործունեություն։** {{ui:Settings}} › {{ui:DetailCraft}} › {{ui:Assistants}} › {{ui:Activity}}-ն թվարկում է յուրաքանչյուր կանչ՝ ժամանակը, գործիքը, կատարվել է թե մերժվել։ {{ui:Save the log}}-ը պահում է պատճենը։

## Ինչ կարող է խնդրել օգնականը

Բոլոր երկարությունները միլիմետրերով են, կետերը `[x, y, z]` ձևով, z-ը վերև, ինչպես մոդելում։

| Գործիք | Թույլտվություն | Ինչ է անում |
|---|---|---|
| `app_info`, `model_describe` | Read | Բաց մոդելը. ցանցեր, մակարդակներ, փուլեր, մասեր ըստ տեսակի և պրոֆիլի, միացումներ, հիմքեր, աստիճանավանդակներ, մասեր, պողպատի կշիռ, խնդիրներ |
| `parts_list` | Read | Մասերի նշաններ՝ պրոֆիլով, նյութով, կտրման երկարությամբ, քանակով, կշիռով, փուլով և հավաքման նշաններով. ըստ տեսակի, պրոֆիլի, նշանի կամ փուլի |
| `problems_list` | Read | Ինչ որ թվարկում է {{ui:Problems}} ներդիրը, յուրաքանչյուրը իր առարկայով |
| `clash_check` | Read | [Բախումների ստուգումը](topic:clash-check), իր շեղումով և փուլերով |
| `selection_get` | Read | Ինչ եք ընտրել |
| `selection_set` | Edit | Ընտրում է մասեր, միացումներ, հիմքեր կամ աստիճանավանդակներ (ըստ id-ի կամ մասի նշանի)՝ ձեզ ցույց տալու համար. ոչինչ չի փոխում |
| `member_add` | Edit | Գերան, սյուն, հակակապ կամ թիթեղ երկու կետի միջև |
| `connection_add` | Edit | Ծայրային թիթեղներ, սահքի ներդիրներ, հիմքի թիթեղներ, հոդակցումներ կամ անկյունակներ, որտեղ տրված մասերը հանդիպում են, ինչպես անում են {{ui:Connect}} կոճակները |
| `undo` | Edit | Հետ է վերցնում օգնականի վերջին քայլերը |
| `model_save` | Save | DetailCraft-ի սեփական Save-ը |
| `model_export` | Export | IFC, NC ֆայլեր, BOM, ծռման գրաֆիկ, KISS ֆայլ կամ կտրման ցանկ, ինչպես ստեղծում են {{ui:Output}} կոճակները |
| `usd_export` | Export | Պողպատե մոդելը որպես USD (.usda, .usdc կամ .usdz), ինչպես այն գրում է {{ui:Output}} › {{ui:USD}} (տես [Պողպատե մոդելի արտահանում USD ձևաչափով](topic:usd)). Studio-ում այն կարող է ֆայլը գրել ձեր թույլատրած թղթապանակում |

## Եթե ինչ-որ բան չի աշխատում

- **Օգնականը DetailCraft-ի գործիքներ չի տեսնում.** ստուգեք, որ անջատիչը միացված է այս պատուհանում, և որ պատուհանը բաց է Studio-ում։
- **"needs the edit permission"** (կամ save, export). Նշեք այն {{ui:Assistants}}-ի տակ, ապա նորից խնդրեք։
- **"The person is placing a member":** ավարտեք այն, ինչ անում եք (կամ սեղմեք {{key:Esc}}), ապա թույլ տվեք օգնականին նորից փորձել։
- **"401" կամ "token" սխալներ.** թոքենը փոխվել է (Studio-ն վերագործարկվել է, կամ {{ui:New token}}). Պատճենեք նորը օգնականի կարգավորումներում։
