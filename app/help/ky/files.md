DetailCraft'та өз файлы бар: модель, жана беш экспорт. Ар бир сактоо жана ар бир экспорт — жүктөө. Эч нерсе жөнөтүлбөйт жана серверде эч нерсе сакталбайт.

## Модель файлы

DetailCraft моделі `<name>.detailcraft.json` катары сакталат, мында `<name>` — {{ui:Model}} панелиндеги модель аты. Анда торлор, деңгээлдер, элементтер (тешиктери жана кесилиштери менен), туташуулар жана алардын жөндөөлөрү, фундаменттер жана сиздин атайын профилдериңиз бар.

Бөлүктөр, белгилер, болттор, ширетүүлөр жана арматуралар сакталбайт: DetailCraft аларды модельден ар ачылганда кайра эсептейт. Ошондуктан модель файлы кичине.

### Сактоо

1. {{ui:Model}} панелинин үстүндөгү {{ui:Name}} талаасына ат жазыңыз.
2. {{ui:File}} тобундагы {{ui:Save}} баскычын тандаңыз же {{key:Mod+S}} басыңыз.
3. Браузер `<name>.detailcraft.json` файлын жүктөйт. Абал тилкесинде "Сакталды … (жүктөлдү)" деп жазылат, ал эми браузер өтмөгүнүн аталышынын башындагы чекит жок болот.

Ар бир сактоо — жаңы жүктөө. Браузер ачылган файлды үстүнөн жазбайт; анын жөндөөлөрүнө жараша атына сан кошот, мисалы `Frame (1).detailcraft.json`, же кайда сактоону сурайт. Өз версияларыңызды жүктөлгөн файлдардын атын өзгөртүп сактаңыз.

:::chromium
Chrome жана Edge файлдарды Downloads папкасына сактайт, эгерде браузердин жүктөө жөндөөлөрүндө **Ask where to save each file before downloading** иштетилбесе. Ар жолу папканы жана файл атын тандагыңыз келсе, аны иштетиңиз.
:::

:::firefox
Firefox файлдарды Downloads папкасына сактайт, же **Always ask you where to save files** жөндөөсү иштетилсе, ар жолу сурайт.
:::

:::safari
Safari файлдарды Downloads папкасына сактайт. Папканы өзгөртүү үчүн **Safari, Settings, General, File download location** ачыңыз.
:::

### Ачуу

1. {{ui:File}} тобундагы {{ui:Open}} баскычын тандаңыз же {{key:Mod+O}} басыңыз.
2. `.detailcraft.json` файлын тандаңыз.

Же файлды {{pick:mac=Finder|windows=File Explorer|linux=файл менеджериңиз}} ичинен сүйрөп, көрүнүшкө таштаңыз. Сүйрөп жатканда көрүнүштө "Ачуу үчүн DetailCraft моделин таштаңыз" деп жазылат.

Ачык моделде сакталбаган өзгөртүүлөр болсо, DetailCraft адегенде сурайт: {{ui:Cancel}}, {{ui:Discard changes}} же {{ui:Save first}}.

DetailCraft файлдын ар бир талаасын колдонуудан мурун текшерет. Колдонууга жарамсыз нерсе алынып салынат, ал эми абал тилкесинде эмне экени айтылат, мисалы "2 элемент жараксыз болуп, алынып салынды." DetailCraft'тын жаңыраак версиясы менен сакталган модель жарым-жартылай туура ачылбай, билдирүү менен четке кагылат.

### Эмне ачылат

Өз модель файлдары (`.json`, 50 MB чейин) жана IFC файлдары (`.ifc`, IFC2X3 же IFC4, 200 MB чейин). IFC файлы ачылганда же {{ui:Import IFC}} менен киргизилгенде, анын балкалары, колонналары, элементтери, пластиналары, торлору жана деңгээлдери менен жаңы модель түзүлөт; тешиктер жана кесилиштер ошолорго кесилет, ал эми болттору эркин болттор катары киргизилет. Кайсы нерселер алынып салынганы жөнүндө отчет берилет. Кененирээк: [IFC экспорту](topic:ifc-export#import). DWG, DXF же башка детализация программасынын моделин али ачпайт; аракет кылганда "DetailCraft өз моделдерин (.detailcraft.json) жана IFC файлдарын (.ifc) ачат." деген билдирүү чыгат.

## Жоголгон иш, акыркы файлдар, иш үстөлүндөгү колдонмо

- Сакталбаган өзгөртүүлөрү бар моделде DetailCraft ушул браузерде көчүрмөсүн сактайт. Өтмөк же браузер сактоодон мурун токтосо, DetailCraft кийинки ачылганда **Ишиңизди калыбына келтиребизби?** деп сурайт: көчүрмөсүн калыбына келтириңиз же аны жокко чыгарыңыз. Кененирээк: [Ишти калыбына келтирүү](common:recover).
- Браузер уруксат бергенде, ачкан моделдер башкы экранда тизмеленет; аларды кайра ачуу үчүн бирин басыңыз.
- Иш үстөлүндөгү колдонмодо {{ui:Save}} моделди ачкан файлга кайра жазат (браузерде көчүрмөсүн жүктөйт), ал эми DetailCraft моделин же IFC файлын эки жолу басканда ал DetailCraft'та ачылат.

## Экспорттор

Бардык экспорттор модель атын колдонот. Аларды {{ui:Output}} тобунан тандаңыз.

| Баскыч | Файл | Ичинде эмне бар |
|---|---|---|
| {{ui:IFC}} | `<name>.ifc` | IFC4: кабаттар, торлор, ар бир болот бөлүгү тешиктери жана кесилиштери менен профилдик экструзия катары, жыйнактар, болттор жана анкер стержендер, фундаменттер жана ар бир арматура. Кененирээк: [IFC экспорттоо](topic:ifc-export). |
| {{ui:NC files}} | `<name> NC.zip` | Ар бир бөлүк белгиси үчүн бир DSTV `.nc1` файлы. Кененирээк: [NC файлдарын цехке жөнөтүү](topic:nc-export). |
| {{ui:BOM}} | `<name> BOM.csv` | Бир файлда үч таблица: бөлүктөр, жыйнактар, жана болттор менен анкер стержендер. Кененирээк: [Белгилер жана материалдардын ведомосту](topic:marks-and-bom). |
| {{ui:Bending}} | `<name> bending schedule.csv` | Фундаменттердеги ар бир арматура белгиси. Кененирээк: [Фундаменттер жана арматура](topic:footings-and-rebar). |
| {{ui:Shop drawing}} | `<name> <mark>.pdf` | `<name> Shop drawings.pdf` файлында бөлүк белгисине бир барак; {{ui:Download this sheet}} көрсөтүлүп турган баракты берет (башка өлчөм тандабасаңыз, A3). Кененирээк: [Цех чиймелерин жасоо](topic:shop-drawings). |
| {{ui:Drawings}} | `<name> drawings.pdf`, `<name> <sheet>.pdf`; `<name> <sheet>.dwg` же `.dxf`, бир нечеси `<name> drawings DWG.zip` (же `DXF.zip`) ичинде | Планы, фасадлар жана жыйнак чиймелери тандаган барак өлчөмүндө; DWG жана DXF толук өлчөмдө, 1 бирдик = кагазда 1 мм. Кененирээк: [Жалпы орношу жана жыйнак чиймелери](topic:drawings). |

### CSV файлдары боюнча эскертүүлөр

- Алар байт тартибинин белгиси менен башталат, ошондо электрондук таблица программалары тамгаланган белгилерди туура окушат.
- `=`, `+`, `-` же `@` менен башталган катакча (жөнөкөй сан эмес) биринчи апостроф алат, ошондо электрондук таблица аны формула катары иштетпейт.
- Узундуктар миллиметрде, салмактар килограммда.

### PDF боюнча эскертүүлөр

PDFтеги текст стандарттык Helvetica шрифтин колдонот. Шрифтте жок белгилер (Батыш Европа топтомунан тышкары) "?" болуп басылат, ал эми абал тилкеси алардын санын айтат.

## Бирдиктер

DetailCraft бардык жерде миллиметр менен иштейт: торлор, деңгээлдер, координаталар, профилдер, тешиктер жана ар бир экспорт. Профилдердин аттары жарыяланган формасында калат (W12x50 — АКШ белгилөөсү, анын өлчөмдөрү мм менен көрсөтүлсө да). Импералдык бирдиктерде киргизүү али жок.

## Онлайн жана оффлайн

Ачуу, сактоо жана экспорттоо баары браузеринизде болот, ошондуктан DetailCraft жүктөлгөндөн кийин байланыш бар же жок болсо дагы бирдей иштейт.

Кийинчерек байланышсыз DetailCraft'ты иштетүү үчүн, онлайн турганыңызда иш тактасындагы {{ui:Save for offline}} баскычын тандаңыз. Баскыч санап турат ("Сакталууда: 3 / 20") жана андан кийин {{ui:Offline ready}} деп жазылат. Сакталган көчүрмөгө 3D графика китепканасы (болжол менен 2.6 MB) жана бул жардам кирет, ошондуктан сакталгандан кийин 3D көрүнүш, ар бир экспорт жана жардам оффлайнда иштейт. Чоо-жай жана байланышты талап кылган нерселер: [Оффлайнда иштөө](common:offline).

:::offline
Сиз оффлайнсыз. Иш тактасында {{ui:Offline ready}} көрүнсө, ачуу, сактоо жана экспорттоо адаттагыдай иштейт. Көрүнбөсө, бул өтмөктү ачык калтырыңыз, байланыш калыбына келмейинче аны кайра жүктөбөңүз жана модельиңизди азыр сактаңыз.
:::

Булутка сактоо али жок, иш үстөлүнүн версиялары да али жок. `.detailcraft.json` файлдарыңызды башка иш файлдарыңыздай резервдеңиз. Кененирээк: [Файлдарыңыз кайда барат](common:your-files).

## Сакталбаган иш

DetailCraft моделди ачык өтмөктө гана сактайт. Сакталбаган өзгөртүүлөр менен өтмөктү жапсаңыз же кайра жүктөсөңүз, браузер баракты таштоону сурайт; текст браузердики. {{key:Mod+S}} менен тез-тез сактаңыз.
