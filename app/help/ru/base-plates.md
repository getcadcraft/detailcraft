Соединение с опорной плитой устанавливает пластину под колонной, укорачивает колонну на толщину пластины, приваривает их друг к другу и добавляет четыре анкерных болта, проходящих через отверстия в пластине.

:::warning
Размеры являются исходными значениями, а не проектом. DetailCraft не проверяет опирание, прочность анкерных болтов и заделку.
:::

## Добавление опорной плиты

1. Выберите {{ui:Выбор}} ({{key:V}}) и щелкните колонну. Она должна быть вертикальной.
2. Выберите {{ui:Опорная плита}} в группе {{ui:Соединения}} или {{ui:Добавить опорную плиту}} на панели {{ui:Свойства}}.
3. В строке состояния появится сообщение «Опорная плита добавлена с четырьмя анкерными болтами.» Новое соединение будет выбрано.

У колонны может быть одна опорная плита. Если она уже есть, в строке состояния появится сообщение «У этой колонны уже есть опорная плита».

## Изменение

Выберите опорную плиту (щелкните пластину или болт). В разделе {{ui:Пластина, болты и шов (mm)}}:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| Толщина пластины | 25 | Колонна укорачивается на эту величину |
| Длина пластины | 450 | Вдоль глубины колонны |
| Ширина пластины | 400 | Поперек колонны |
| Диаметр анкерного болта | 20 | Размер анкерного болта |
| Диаметр отверстия | 33 | Отверстие в пластине |
| Класс болта | F1554 Gr 36 | Класс анкерного болта, как текст |
| Шаг анкерных болтов (вдоль глубины) | 350 | Между осями анкерных болтов, вдоль длины пластины |
| Шаг анкерных болтов (поперек) | 300 | Между осями анкерных болтов, поперек |
| Выступ анкерного болта над плитой | 100 | От верха пластины до верха болта |
| Заделка анкерного болта под плитой | 450 | От низа пластины вниз в бетон |
| Размер углового шва | 8 | По всему периметру основания колонны |
| Материал пластины | A36 | Текст |
| Зазор под подливку | 0 | Расстояние между верхом бетона и низом пластины |
| Ребра жесткости | Нет | Выберите «Нет», 2 (по линии стенки) или 4 (также перпендикулярно ей); см. ниже |
| Толщина, высота ребра жесткости | 12, 150 | |
| Глубина срезного упора | 0 | На сколько упор уходит под плиту; 0 = без упора |
| Толщина, ширина срезного упора | 25, 150 | |
| Пластинчатые шайбы | Нет | На каждом болте или ни на одном |
| Размер, толщина шайбы | 0, 0 | 0 = минимум по AISC Design Guide 1 для болта |

Длина анкерного болта = заделка + зазор под подливку + толщина пластины + выступ. При значениях по умолчанию это 575 mm.

## Детали основания: подливка, ребра жесткости, срезной упор, шайбы

Все четыре элемента выключены на новой опорной плите и на опорных плитах из моделей, созданных до DetailCraft 0.4.

- **Зазор под подливку.** Пластина располагается на такое расстояние над верхом бетона, и анкерные болты становятся длиннее на эту величину. AISC Design Guide 1 (2.10) рекомендует 1 in. для чистового пола и от 1½ до 2 in. для фундамента или пилона; больше — для крупных пластин и пластин со срезным упором.
- **Ребра жесткости.** Вертикальные пластины, приваренные к колонне и пластине, от грани колонны до края пластины, в виде прямоугольников (фасок и сужений пока нет). **2** стоят по линии стенки, за каждой полкой; **4** добавляют еще два ребра перпендикулярно стенке, между полками, до краев пластины. На трубчатой колонне они стоят посередине каждой грани. Каждое приварено к колонне и пластине с обеих сторон.
- **Срезной упор.** Пластина, приваренная по всему контуру под опорной плитой, по линии глубины колонны, по центру. DetailCraft выдает предупреждение, если упор не глубже зазора под подливку. Карман в фундаменте он не вырезает; поэтому [проверка коллизий](topic:clash-check) не учитывает упор и фундамент.
- **Пластинчатые шайбы.** Квадратная пластинчатая шайба на каждом болте, опирается на опорную плиту, указана в сборке колонны как свободная деталь (поставляется с колонной, не приварена: Design Guide 1, 2.6). При размере и толщине 0 DetailCraft берет минимальную шайбу из AISC Design Guide 1, 2nd ed., Table 2.3 для болта; метрический болт получает ближайший больший дюймовый размер (для M20 — строку 7/8 in.: 2½ in. × 5/16 in.). В панели свойств показан использованный размер. Отверстие шайбы равно диаметру болта + 1/16 in.: это выбор DetailCraft, в таблице его нет. DetailCraft выдает предупреждение, если болты могут выступать недостаточно для шайбы и гайки (выступ меньше толщины шайбы + диаметра болта).

Design Guide 1, таблица 2.3, также рекомендует отверстие под болт в пластине: 1-5/16 in. для болта ¾ in., 1-9/16 in. для ⅞ in., 1-13/16 in. для 1 in. DetailCraft не меняет размер вашего отверстия.

Предупреждения также появляются, если отверстия под болты ближе к краю пластины, чем 1.2 × диаметр отверстия, если болты попадают внутрь контура колонны или если пластина меньше колонны.

## Копирование на подобные колонны

1. Выберите опорную плиту.
2. Выберите {{ui:Применить к подобным (n)}} или {{ui:Подобные}} в меню {{ui:Ещё}} группы {{ui:Соединения}}.
3. Копия создается для каждой вертикальной колонны с тем же профилем, у которой нет опорной плиты и которая не стоит на другой колонне.

## Опорные плиты и фундаменты

Опорной плите фундамент не нужен, а фундамент не знает об опорной плите над ним: анкерные болты не связаны со стержнями фундамента. Размещайте фундаменты командой {{ui:Фундамент}}; см. [Размещение фундаментов с арматурой](topic:footings-and-rebar).
