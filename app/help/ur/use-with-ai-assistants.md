## آپ کیا سیکھیں گے

AI اسسٹنٹ (یا آپ کی لکھی ہوئی اسکرپٹ) کے ساتھ DetailCraft کیسے کام کروائیں، اور یہ کیسے طے کریں کہ وہ کیا چھو سکتا ہے۔

DetailCraft کا **اپنا کوئی AI نہیں** ہے اور وہ کہیں کچھ نہیں بھیجتا۔ اسسٹنٹ آپ لاتے ہیں: کوئی بھی پروگرام جو Model Context Protocol (MCP) بولتا ہو۔ DetailCraft اسے صرف ٹولز دیتا ہے، اور کون سے، یہ آپ چنتے ہیں۔

## اسے آن کریں

1. {{ui:ترتیبات}} کھولیں (ایپ بار کا گیئر، یا {{key:Mod+,}}) اور {{ui:DetailCraft}} ٹیب پر جائیں۔
2. {{ui:اسسٹنٹس}} کے تحت **اے آئی اسسٹنٹس اور اسکرپٹس کو DetailCraft استعمال کرنے دیں** پر نشان لگائیں۔ جب تک آپ ایسا نہ کریں، یہ بند رہتا ہے۔
3. چنیں کہ وہ کیا کر سکتا ہے: **Read** شروع میں نشان زد ہے؛ **Edit**، **Save** یا **Export** صرف تب نشان لگائیں جب ضرورت ہو۔

جن ٹولز کی اجازت آپ نے نشان زد نہیں کی وہ اسسٹنٹ کو پیش نہیں کیے جاتے، اور اگر وہ پھر بھی ایک مانگے تو DetailCraft انکار کرتا ہے اور اسے سرگرمی کے لاگ میں لکھتا ہے۔ سوئچ بند کرنے سے ہر کنکشن ایک ساتھ ختم ہو جاتا ہے۔

## اپنا اسسٹنٹ جوڑیں

اسسٹنٹس آپ کے کمپیوٹر پر **CadCraft Studio** کے ذریعے جڑتے ہیں: Studio ایک چھوٹا سرور چلاتا ہے جس تک صرف یہ کمپیوٹر پہنچ سکتا ہے، اور جو ہر بار شروع ہونے پر بنائے گئے ٹوکن سے محفوظ ہوتا ہے۔ Studio میں {{ui:اسسٹنٹ جوڑیں}} چنیں اور پتہ اور ٹوکن اپنے اسسٹنٹ میں کاپی کریں (Studio ٹھیک سیٹنگز دکھاتا ہے جو چسپاں کرنی ہیں)۔ ٹوکن کبھی شیئر نہ کریں۔

:::note
براؤزر ٹیب اسسٹنٹ کے لیے کنکشن نہیں کھول سکتا: براؤزر ایپس میں سوئچ اس وقت تک اثر نہیں کرتا جب تک آپ اپنے کمپیوٹر پر CadCraft Studio استعمال نہ کریں۔
:::

## آپ کنٹرول میں رہتے ہیں

- **ہر تبدیلی ایک undo قدم ہے**، جس پر اسسٹنٹ کا لیبل ہوتا ہے (مثلاً "اسسٹنٹ: بیم شامل کریں"، "اسسٹنٹ: گسٹس شامل کریں")۔ {{key:Mod+Z}} اسسٹنٹ کی آخری تبدیلی پوری طرح واپس لے لیتا ہے۔ اسسٹنٹ کا اپنا `undo` صرف اس کے اپنے قدم واپس لیتا ہے، آپ کے نہیں، جب تک وہ واضح طور پر نہ مانگے۔
- **وہ انتظار کرتا ہے۔** جب آپ ممبر رکھ رہے ہوں، پرزے منتقل کر رہے ہوں یا چسپاں کر رہے ہوں، DetailCraft اسسٹنٹ کی تبدیلیاں انکار کرتا ہے اور اسے دوبارہ کوشش کرنے کو کہتا ہے۔
- **آپ جانتے ہیں کہ کوئی جڑا ہوا ہے۔** ایپ بار کا ایک بٹن جڑے ہوئے اسسٹنٹ کا نام لیتا ہے؛ اس پر کلک کریں تاکہ دیکھیں وہ کیا کر سکتا ہے، یا اسے **منقطع کریں**۔
- **سرگرمی۔** {{ui:ترتیبات}} › {{ui:DetailCraft}} › {{ui:اسسٹنٹس}} › {{ui:سرگرمی}} ہر کال دکھاتا ہے: کب، کون سا ٹول، اور مکمل ہوئی یا انکار۔ {{ui:لاگ محفوظ کریں}} اس کی ایک کاپی رکھتا ہے۔

## اسسٹنٹ کیا مانگ سکتا ہے

تمام لمبائیاں ملی میٹر میں ہیں، پوائنٹس `[x, y, z]` میں، z اوپر، ماڈل کی طرح۔

| ٹول | اجازت | کیا کرتا ہے |
|---|---|---|
| `app_info`، `model_describe` | Read | کھلا ماڈل: گرڈز، لیولز، فیزز، قسم اور پروفائل کے لحاظ سے ممبرز، کنکشنز، فوٹنگز، سیڑھیاں، پرزے، اسٹیل کا وزن، مسائل |
| `parts_list` | Read | پارٹ مارکس، پروفائل، میٹیریل، کٹ لمبائی، تعداد، وزن، فیز اور اسمبلی مارکس؛ قسم، پروفائل، مارک یا فیز کے لحاظ سے |
| `problems_list` | Read | {{ui:مسائل}} ٹیب میں جو فہرست ہے، ہر ایک اس کے بارے میں بتاتا ہوا |
| `clash_check` | Read | [کلیش چیک](topic:clash-check)، اس کی ٹالرنس اور فیزز کے ساتھ |
| `selection_get` | Read | آپ نے جو منتخب کیا ہے |
| `selection_set` | Edit | ممبرز، کنکشنز، فوٹنگز یا سیڑھیاں منتخب کرتا ہے (id یا پارٹ مارک سے) تاکہ آپ کو دکھائے؛ کچھ نہیں بدلتا |
| `member_add` | Edit | دو نقطوں کے درمیان ایک بیم، کالم، بریس یا پلیٹ |
| `connection_add` | Edit | اینڈ پلیٹس، شیئر ٹیبز، بیس پلیٹس، اسپلائسز یا گسٹس وہاں جہاں دیے گئے ممبرز ملتے ہیں، جیسے {{ui:جوڑیں}} بٹن کرتے ہیں |
| `undo` | Edit | اسسٹنٹ کے آخری قدم واپس لیتا ہے |
| `model_save` | Save | DetailCraft کا اپنا محفوظ کرنا |
| `model_export` | Export | IFC، NC فائلیں، BOM، بینڈنگ شیڈول، KISS فائل یا کٹنگ لسٹ، جیسے {{ui:آؤٹ پٹ}} بٹن بناتے ہیں |
| `usd_export` | Export | مکمل اسٹیل ماڈل بطور USD (.usda، .usdc یا .usdz)، جیسے {{ui:آؤٹ پٹ}} › {{ui:USD}} لکھتا ہے (دیکھیں [اسٹیل ماڈل کو USD کے طور پر ایکسپورٹ کریں](topic:usd))؛ Studio میں یہ اس فولڈر میں فائل لکھ سکتا ہے جس کی آپ نے اجازت دی ہو |

## اگر کچھ کام نہ کرے

- **اسسٹنٹ کو DetailCraft کے ٹولز نظر نہیں آتے:** چیک کریں کہ اس ونڈو میں سوئچ آن ہے، اور یہ ونڈو Studio میں کھلی ہے۔
- **"ایڈٹ کی اجازت درکار ہے"** (یا محفوظ کرنے، ایکسپورٹ کرنے کی): اسے {{ui:اسسٹنٹس}} کے تحت نشان زد کریں، پھر دوبارہ پوچھیں۔
- **"صارف ممبر رکھ رہا ہے":** جو کام کر رہے ہیں وہ ختم کریں (یا {{key:Esc}} دبائیں)، پھر اسسٹنٹ کو دوبارہ کوشش کرنے دیں۔
- **"401" یا "token" کی غلطیاں:** ٹوکن بدل گیا ہے (Studio دوبارہ شروع ہوا، یا {{ui:نیا ٹوکن}})۔ نیا ٹوکن اسسٹنٹ کی سیٹنگز میں کاپی کریں۔
