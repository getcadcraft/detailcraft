## तुम्ही काय शिकाल

AI सहाय्यक (किंवा तुम्ही लिहिलेली स्क्रिप्ट) DetailCraft सोबत कसे काम करू शकते, आणि त्याला काय स्पर्श करण्याची परवानगी द्यायची ते कसे ठरवायचे.

DetailCraft स्वतःचे **AI नाही** आणि कुठेही काहीही पाठवत नाही. सहाय्यक तुम्ही आणता: Model Context Protocol (MCP) बोलणारा कोणताही प्रोग्राम. DetailCraft त्याला फक्त साधने देते, आणि कोणती हे तुम्ही निवडता.

## सुरू करा

1. {{ui:Settings}} उघडा (अ‍ॅप बारमधील गियर, किंवा {{key:Mod+,}}) आणि {{ui:DetailCraft}} टॅबवर जा.
2. {{ui:Assistants}} खाली, **AI सहाय्यक आणि स्क्रिप्टना DetailCraft वापरू द्या** टिक करा. तुम्ही तसे करेपर्यंत ते बंद असते.
3. त्याला काय करता येईल ते निवडा: **वाचा** सुरुवातीला टिक केलेले असते; **संपादित करा**, **जतन करा** किंवा **निर्यात करा** फक्त गरज असेल तेव्हाच टिक करा.

तुम्ही टिक केलेल्या परवानग्यांबाहेरची साधने सहाय्यकाला दिली जात नाहीत, आणि त्याने तरीही एखादे मागितल्यास, DetailCraft ते नाकारते आणि क्रियाकलाप लॉगमध्ये नोंदवते. स्विच बंद केल्यास सर्व जोडण्या एकाच वेळी संपतात.

## सहाय्यक जोडा

सहाय्यक तुमच्या संगणकावरील **CadCraft Studio** द्वारे जोडले जातात: Studio एक छोटा सर्व्हर चालवते, जो फक्त हा संगणक गाठू शकतो, आणि तो प्रत्येक वेळी सुरू होताना बनवलेल्या टोकनने संरक्षित असतो. Studio मध्ये {{ui:Connect an assistant}} निवडा आणि पत्ता व टोकन तुमच्या सहाय्यकात कॉपी करा (Studio नेमकी पेस्ट करायची सेटिंग्ज दाखवते). टोकन कधीही शेअर करू नका.

:::note
ब्राउझर टॅब सहाय्यकासाठी कनेक्शन उघडू शकत नाही: ब्राउझर अ‍ॅप्समध्ये तुम्ही तुमच्या संगणकावरील CadCraft Studio वापरेपर्यंत स्विचचा काही परिणाम होत नाही.
:::

## तुम्ही नियंत्रणात राहता

- **प्रत्येक बदल एक पूर्ववत करण्याची पायरी आहे**, जी सहाय्यकाची म्हणून लेबल केलेली असते (उदाहरणार्थ "Assistant: add beam", "Assistant: add gussets"). {{key:Mod+Z}} सहाय्यकाचा शेवटचा बदल संपूर्णपणे मागे घेते. सहाय्यकाचा स्वतःचा `undo` फक्त त्याच्या स्वतःच्या पायऱ्या मागे घेतो, तुमच्या कधीच नाही, जोपर्यंत तो स्पष्टपणे तसे विचारत नाही.
- **ते तुमची वाट पाहते.** तुम्ही सदस्य ठेवत असताना, भाग हलवत असताना किंवा पेस्ट करत असताना, DetailCraft सहाय्यकाचे बदल नाकारते आणि त्याला पुन्हा प्रयत्न करण्यास सांगते.
- **जोडलेला असताना तुम्हाला कळते.** अ‍ॅप बारमधील एक बटण जोडलेल्या सहाय्यकाचे नाव दाखवते; तो काय करू शकतो ते पाहण्यासाठी किंवा त्याला **डिस्कनेक्ट** करण्यासाठी त्यावर क्लिक करा.
- **क्रियाकलाप.** {{ui:Settings}} › {{ui:DetailCraft}} › {{ui:Assistants}} › {{ui:Activity}} प्रत्येक कॉल दाखवते: केव्हा, कोणते साधन, आणि पूर्ण झाले की नाकारले. {{ui:Save the log}} एक प्रत ठेवते.

सर्व लांबी मिलीमीटरमध्ये आहेत, बिंदू `[x, y, z]` आहेत, z वर, मॉडेलप्रमाणे.

| साधन | परवानगी | काय करते |
|---|---|---|
| `app_info`, `model_describe` | वाचा | उघडलेले मॉडेल: ग्रिड, लेव्हल, टप्पे, प्रकार आणि प्रोफाइलनुसार सदस्य, जोडण्या, फूटिंग, जिने, भाग, स्टीलचे वजन, समस्या |
| `parts_list` | वाचा | भाग खुणा प्रोफाइल, मटेरियल, कापलेल्या लांबीसह, संख्या, वजन, टप्पा आणि असेंब्ली खुणा; प्रकार, प्रोफाइल, खूण किंवा टप्प्यानुसार |
| `problems_list` | वाचा | {{ui:Problems}} टॅब जे दाखवते, प्रत्येक त्याबद्दलच्या माहितीसह |
| `clash_check` | वाचा | [क्लॅश तपासणी](topic:clash-check), तिच्या सहनशीलतेसह आणि टप्प्यांसह |
| `selection_get` | वाचा | तुम्ही काय निवडले आहे |
| `selection_set` | संपादित करा | तुम्हाला दाखवण्यासाठी सदस्य, जोडण्या, फूटिंग किंवा जिने निवडते (id किंवा भाग खुणेनुसार); काहीही बदलत नाही |
| `member_add` | संपादित करा | दोन बिंदूंमधील बीम, स्तंभ, ब्रेस किंवा प्लेट |
| `connection_add` | संपादित करा | दिलेल्या सदस्यांची भेट होते तिथे एंड प्लेट्स, शिअर टॅब, बेस प्लेट्स, स्प्लाइस किंवा गसेट, {{ui:Connect}} बटणे करतात तसे |
| `undo` | संपादित करा | सहाय्यकाच्या शेवटच्या पायऱ्या मागे घेते |
| `model_save` | जतन करा | DetailCraft चे स्वतःचे जतन |
| `model_export` | निर्यात करा | IFC, NC फाइल्स, BOM, वाकवण्याचे शेड्यूल, KISS फाइल किंवा कटिंग यादी, {{ui:Output}} बटणे बनवतात तसे |
| `usd_export` | निर्यात करा | स्टील मॉडेल USD म्हणून (.usda, .usdc किंवा .usdz), {{ui:Output}} › {{ui:USD}} लिहिते तसे (पहा [स्टील मॉडेल USD म्हणून निर्यात करा](topic:usd)); Studio मध्ये ते तुम्ही परवानगी दिलेल्या फोल्डरमध्ये फाइल लिहू शकते |

## काही काम न केल्यास

- **सहाय्यकाला DetailCraft ची साधने दिसत नाहीत:** या विंडोमध्ये स्विच चालू आहे आणि विंडो Studio मध्ये उघडी आहे ते तपासा.
- **"needs the edit permission"** (किंवा जतन, निर्यात): {{ui:Assistants}} खाली ती परवानगी टिक करा, मग पुन्हा विचारा.
- **"The person is placing a member":** तुम्ही जे करत आहात ते पूर्ण करा (किंवा {{key:Esc}} दाबा), मग सहाय्यकाला पुन्हा प्रयत्न करू द्या.
- **"401" किंवा "token" त्रुटी:** टोकन बदलले आहे (Studio पुन्हा सुरू झाले, किंवा {{ui:New token}}). नवीन टोकन सहाय्यकाच्या सेटिंग्जमध्ये कॉपी करा.
