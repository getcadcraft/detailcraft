இந்த உதவியில் விசைகள் எவ்வாறு எழுதப்படுகின்றன: [விசைகள், சுட்டிகள் மற்றும் டிராக்பேட்கள்](common:keys). Mac இல் {{key:Mod}} என்பது Command விசை; மற்ற இடங்களில் Ctrl ஆகும்.

## நகலெடு மற்றும் ஒட்டு

இவை கர்சர் உரை அல்லது எண் புலத்தில் இல்லாதபோது வேலை செய்யும் (அங்கே வழக்கம்போல் உங்கள் உரையை நகலெடுக்கும், ஒட்டும், தேர்ந்தெடுக்கும்). ஒவ்வொரு ஒட்டு, வெட்டு, நகலாக்கு அல்லது நீக்கமும் ஒரு செயல்தவிர் படியாகும். மேலும்: [நகலெடு, ஒட்டு மற்றும் நகலாக்கு](topic:copy-paste).

| விசை | செயல் |
|---|---|
| {{key:Mod+C}} | தேர்ந்தெடுத்த உறுப்புகளையும் அடித்தளங்களையும் {{ui:நகலெடு}} (அவற்றின் துளைகள், கோப் வெட்டுகள் மற்றும் இணைப்புகளுடன்) |
| {{key:Mod+X}} | {{ui:வெட்டு}}: தேர்வை நகலெடுத்து, பின் அதை நீக்கு |
| {{key:Mod+V}} | {{ui:ஒட்டு}}: நகல் சுட்டியைப் பின்தொடரும்; அதற்கு ஒரு கட்ட வெட்டுப்புள்ளியைக் கிளிக் செய்யவும் |
| {{key:Mod+Shift+V}} | {{ui:அதே இடத்தில் ஒட்டு}}: எந்த ஆயங்களிலிருந்து நகலெடுக்கப்பட்டதோ அதே ஆயங்களில் |
| {{key:Mod+D}} | {{ui:நகலாக்கு}}: உடனடியாக ஒரு நகல், [DetailCraft அமைப்புகளில்](topic:settings) உள்ள இடைவெளி அளவால் நகர்த்தப்பட்டது |
| {{key:Mod+A}} | {{ui:அனைத்தையும் தேர்ந்தெடு}}: ஒவ்வொரு உறுப்பு, இணைப்பு மற்றும் அடித்தளம் |
| {{key:Esc}} | {{ui:தேர்வை நீக்கு}} |

பக்கத்தில் (எடுத்துக்காட்டாக அறிக்கை அட்டவணையில்) உரையைத் தேர்ந்தெடுத்து மாதிரியில் எதுவும் தேர்ந்தெடுக்கப்படவில்லை என்றால், {{key:Mod+C}} வழக்கம்போல் உரையை நகலெடுக்கும்.

{{ui:புதிய}}, {{ui:மாதிரி}} மற்றும் ஏற்றுமதிகளுக்கு விசைகள் இல்லை; கருவிப்பட்டையைப் பயன்படுத்தவும்.

உரையாடல் பெட்டி (தயாரிப்பு வரைபட முன்னோட்டம் அல்லது ஒரு கேள்வி) திறந்திருக்கும்போது இந்த விசைகள் எதுவும் வேலை செய்யாது.

## தொடுதல்

டேப்லெட் அல்லது தொடுதிரையில்:

| செயல் | செய்வது |
|---|---|
| தட்டு | ஒரு பாகத்தைத் தேர்ந்தெடு, அல்லது வைக்கும் கருவி இயக்கத்தில் இருந்தால் அருகிலுள்ள கட்ட வெட்டுப்புள்ளியில் வை (அதற்கு சுமார் ஒரு விரல் அகலத்திற்குள் தட்டுவது கணக்கிடப்படும்) |
| பாகத்தில் நீண்ட அழுத்தம் | தேர்வில் சேர், அல்லது நீக்கு (சுட்டியில் {{key:Shift}}+கிளிக் செய்வது போல) |
| தேர்ந்தெடுத்த பாகத்தில் ஒரு விரல், பின் இழு | தேர்வை நகர்த்து; கட்ட வெட்டுப்புள்ளிகளில் ஒட்டிக்கொள்ளும் |
| வேறு இடத்தில் ஒரு விரல் | சுழற்று (3D) அல்லது நகர்த்து (தளவரைபடம் மற்றும் முகப்புத் தோற்றம்) |
| இரண்டு விரல்கள் | கிள்ளி பெரிதாக்கு; ஒன்றாக நகர்த்தினால் நகர்த்து (பான்) |

தொடுதல் மட்டுமே உள்ள திரையில் பொத்தான்கள், பட்டியல்கள் மற்றும் புலங்கள் பெரியதாக இருக்கும். தேர்வுச் சாளரங்களுக்கு சுட்டி தேவை; விரல்களால், தட்டு மற்றும் நீண்ட அழுத்தம்.

## உலாவி வைத்திருக்கும் விசைகள்

சில குறுக்குவழிகள் உலாவிக்குரியவை; எந்தப் பக்கமும் அவற்றைப் பயன்படுத்த முடியாது, எடுத்துக்காட்டாக {{key:Mod+W}} (தாவலை மூடு), {{key:Mod+T}} (புதிய தாவல்) மற்றும் {{key:Mod+N}} (புதிய சாளரம்). மீண்டும்செய்வதற்குப் பதிலாக {{key:Mod+Y}} உங்கள் உலாவியின் வரலாற்றைத் திறந்தால், {{key:Mod+Shift+Z}} ஐப் பயன்படுத்தவும்.

பக்கத்திடம் விசைப்பலகை இருக்கும்போது மட்டுமே குறுக்குவழிகள் DetailCraft ஐ அடையும். ஒரு விசை எதுவும் செய்யாவிட்டால், அல்லது அதற்குப் பதிலாக உலாவி செயல்பட்டால், முதலில் DetailCraft சாளரத்தின் காலியான பகுதியைக் கிளிக் செய்யவும் (எடுத்துக்காட்டாக முகவரிப் பட்டியில் தட்டச்சு செய்த பிறகு).

## நகர்த்து எங்கே உள்ளது

நகர்த்து கட்டளை இல்லை: ஒரு பாகத்தைத் தேர்ந்தெடுத்து மட்டத்தின் குறுக்கே இழுக்கவும் ({{key:Mod}} அழுத்தி மேலும் கீழும் இழுக்கவும்), அல்லது {{ui:பண்புகள்}} இல் அதன் {{ui:தொடக்கம்}} மற்றும் {{ui:முடிவு}} ஐத் திருத்தவும்.
