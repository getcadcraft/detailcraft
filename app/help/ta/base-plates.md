அடித்தகடு இணைப்பு தூணின் கீழ் ஒரு தகட்டை வைக்கிறது, தகட்டின் தடிமன் அளவுக்குத் தூணைக் குறைக்கிறது, இரண்டையும் பற்றவைக்கிறது, தகட்டில் உள்ள துளைகள் வழியாக நான்கு நங்கூரக் கம்பிகளைச் சேர்க்கிறது.

:::warning
அளவுகள் தொடக்க மதிப்புகள் மட்டுமே, வடிவமைப்பு அல்ல. DetailCraft தாங்குதிறன், கம்பியின் வலிமை அல்லது புதைவை சரிபார்ப்பதில்லை.
:::

## அடித்தகடு சேர்

1. ஒரு தூணைச் சொடுக்கும் முன் {{ui:தேர்ந்தெடு}} ({{key:V}}) கருவியைத் தேர்ந்தெடுக்கவும். அது செங்குத்தாக இருக்க வேண்டும்.
2. {{ui:இணை}} குழுவில் உள்ள {{ui:அடித்தகடு}} ஐத் தேர்ந்தெடுக்கவும், அல்லது {{ui:பண்புகள்}} பலகத்தில் உள்ள {{ui:அடித்தகடு சேர்}} ஐத் தேர்ந்தெடுக்கவும்.
3. "நான்கு நங்கூரக் கம்பிகளுடன் அடித்தகடு சேர்க்கப்பட்டது." என்று நிலைப்பட்டை சொல்லும். புதிய இணைப்பு தேர்ந்தெடுக்கப்பட்டிருக்கும்.

ஒரு தூணில் ஒரு அடித்தகடு மட்டுமே இருக்கலாம். ஏற்கெனவே ஒன்று இருந்தால், நிலைப்பட்டை "இந்தத் தூணில் ஏற்கெனவே ஓர் அடித்தகடு உள்ளது." என்று சொல்லும்.

## அதை மாற்று

அடித்தகடைத் தேர்ந்தெடுக்கவும் (தகட்டையோ கம்பியையோ சொடுக்கவும்). {{ui:தகடு, போல்ட்கள், பற்றவைப்பு (mm)}} என்பதன் கீழ்:

| அமைப்பு | இயல்புநிலை | என்ன செய்கிறது |
|---|---|---|
| தகடு தடிமன் | 25 | தூண் இத்தனை அளவு குறைக்கப்படும் |
| தகடு நீளம் | 450 | தூணின் ஆழத்தின் வழியே |
| தகடு அகலம் | 400 | தூணின் குறுக்கே |
| கம்பி விட்டம் | 20 | நங்கூரக் கம்பியின் அளவு |
| துளை விட்டம் | 33 | தகட்டில் உள்ள துளை |
| போல்ட் தரம் | F1554 Gr 36 | கம்பியின் தரம், உரையாக |
| கம்பி இடைவெளி (ஆழத்தின் வழியே) | 350 | கம்பி மையங்களுக்கு இடையே, தகட்டின் நீளத்தின் வழியே |
| கம்பி இடைவெளி (குறுக்கே) | 300 | கம்பி மையங்களுக்கு இடையே, குறுக்கே |
| தகட்டுக்கு மேல் கம்பி நீட்சி | 100 | தகட்டின் மேற்பகுதியிலிருந்து கம்பியின் மேற்பகுதி வரை |
| தகட்டுக்குக் கீழ் கம்பி புதைவு | 450 | தகட்டின் அடியிலிருந்து கான்கிரீட்டுக்குள் கீழே |
| ஃபில்லெட் பற்றவைப்பு அளவு | 8 | தூண் அடியைச் சுற்றிலும் |
| தகடு பொருள் | A36 | உரை |
| க்ரௌட் இடைவெளி | 0 | கான்கிரீட்டின் மேற்பகுதிக்கும் தகட்டின் அடிப்பகுதிக்கும் இடையிலான இடம் |
| வலுவூட்டிகள் | இல்லை | இல்லை, 2 (வலைக்கு நேராக) அல்லது 4 (அதற்குச் செங்குத்தாகவும்) ஆகியவற்றில் ஒன்றைத் தேர்ந்தெடுக்கவும்; கீழே காண்க |
| வலுவூட்டி தடிமன், உயரம் | 12, 150 | |

| ஷியர் லக் தடிமன், அகலம் | 25, 150 | |

கம்பி நீளம் = புதைவு + க்ரௌட் இடைவெளி + தகடு தடிமன் + நீட்சி. இயல்புநிலை மதிப்புகளில் அது 575 mm.

## அடித்தள விவரங்கள்: க்ரௌட், வலுவூட்டிகள், ஷியர் லக், வாஷர்கள்

நான்கும் புதிய அடித்தகடில் அணைக்கப்பட்டிருக்கும், DetailCraft 0.4-க்கு முன் உருவாக்கப்பட்ட மாதிரிகளின் அடித்தகடுகளிலும் அவ்வாறே இருக்கும்.

- **க்ரௌட் இடைவெளி.** தகடு கான்கிரீட்டின் மேற்பகுதிக்கு மேலே இத்தனை தூரத்தில் அமரும், கம்பிகள் அதே அளவு நீளமாகும். AISC Design Guide 1 (2.10) முடிக்கப்பட்ட தரையில் 1 in. என்றும், தனி அடித்தளம் அல்லது தூணடியில் 1½ முதல் 2 in. வரை என்றும் பரிந்துரைக்கிறது; பெரிய தகடுகளுக்கும் ஷியர் லக் உள்ள தகடுகளுக்கும் அதிகம்.
- **வலுவூட்டிகள்.** தூணுடனும் தகட்டுடனும் பற்றவைக்கப்பட்ட செங்குத்துத் தகடுகள், தூணின் முகத்திலிருந்து தகட்டின் விளிம்பு வரை, செவ்வகங்களாக (இன்னும் சாய்வோ ஓரச் சீவலோ இல்லை). **2** வலைக்கு நேராக, ஒவ்வொரு விளிம்புக்கும் அப்பால் நிற்கும்; **4** வலைக்குச் செங்குத்தாக, விளிம்புகளுக்கு இடையே, தகட்டின் பக்கங்கள் வரை இரண்டு கூடுதலாகச் சேர்க்கும். குழாய்த் தூணில் அவை ஒவ்வொரு முகத்தின் நடுவிலும் நிற்கும். ஒவ்வொன்றும் இருபக்கங்களிலும் தூணுடனும் தகட்டுடனும் பற்றவைக்கப்படும்.
- **ஷியர் லக்.** அடித்தகடுக்குக் கீழே சுற்றிலும் பற்றவைக்கப்பட்ட ஒரு தகடு, தூணின் ஆழத்தின் வழியே, நடுவில் அமைந்தது. க்ரௌட் இடைவெளியை விட ஆழம் குறைவாக இருந்தால் DetailCraft எச்சரிக்கும். அது தனி அடித்தளத்தில் குழியை வெட்டாது; அதனால்தான் [மோதல் சரிபார்ப்பு](topic:clash-check) லக்கையும் தனி அடித்தளத்தையும் விட்டுவிடுகிறது.
- **தகடு வாஷர்கள்.** ஒவ்வொரு கம்பியிலும் ஒரு சதுர தகடு வாஷர், அடித்தகடின் மேல் அமர்ந்து, தூணின் அசெம்பிளியில் தனித்தது என்று பட்டியலிடப்படும் (தூணுடன் அனுப்பப்படும், பற்றவைக்கப்படாது: Design Guide 1, 2.6). அளவும் தடிமனும் 0 ஆக இருந்தால், DetailCraft கம்பிக்கான AISC Design Guide 1, 2nd ed., Table 2.3 இலிருந்து குறைந்தபட்ச வாஷரை எடுக்கும்; மெட்ரிக் கம்பி அடுத்த அங்குல அளவை எடுக்கும் (M20 கம்பிக்கு 7/8 in. வரிசை கிடைக்கும்: 2½ in. × 5/16 in.). பண்புகள் பலகம் பயன்படுத்தப்பட்ட அளவைக் காட்டும். வாஷரின் துளை கம்பி விட்டம் + 1/16 in. ஆகும்: அது DetailCraft-இன் தேர்வு, அட்டவணை ஒன்றைக் கொடுக்கவில்லை. வாஷருக்கும் நட்டுக்கும் போதுமான அளவு கம்பி நீட்டாமல் போகலாம் என்றால் (நீட்சி வாஷர் தடிமன் + கம்பி விட்டத்தை விடக் குறைவு) DetailCraft எச்சரிக்கும்.

AISC Design Guide 1-இன் அட்டவணை 2.3 தகட்டில் கம்பித் துளையையும் பரிந்துரைக்கிறது: ¾ in. கம்பிக்கு 1-5/16 in., ⅞ in. கம்பிக்கு 1-9/16 in., 1 in. கம்பிக்கு 1-13/16 in். DetailCraft உங்கள் துளை அளவை மாற்றாது.

கம்பித் துளைகள் தகட்டு விளிம்புக்கு துளை விட்டத்தின் 1.2 மடங்கை விட நெருக்கமாக இருந்தாலோ, கம்பிகள் தூணின் வெளிப்புறக் கோட்டுக்குள் விழுந்தாலோ, அல்லது தகடு தூணை விடச் சிறியதாக இருந்தாலோ எச்சரிக்கைகள் தோன்றும்.

## ஒத்த தூண்களுக்கு நகலெடு

1. அடித்தகடைத் தேர்ந்தெடுக்கவும்.
2. {{ui:ஒத்தவற்றுக்குப் பயன்படுத்து (n)}} ஐத் தேர்ந்தெடுக்கவும், அல்லது {{ui:இணை}} குழுவின் {{ui:மேலும்}} பட்டியலில் உள்ள {{ui:ஒத்தவை}} ஐத் தேர்ந்தெடுக்கவும்.
3. ஒரே வெட்டுவடிவம் கொண்டதும், அடித்தகடு இல்லாததும், வேறு தூணின் மேல் நிற்காததுமான ஒவ்வொரு செங்குத்துத் தூணுக்கும் ஒரு நகல் கிடைக்கும்.

## அடித்தகடுகளும் தனி அடித்தளங்களும்

அடித்தகடுக்குத் தனி அடித்தளம் தேவையில்லை, தனி அடித்தளத்துக்கு மேலுள்ள அடித்தகடு பற்றித் தெரியாது: நங்கூரக் கம்பிகள் தனி அடித்தளத்தின் கம்பிகளுடன் பிணைக்கப்படுவதில்லை. {{ui:தனி அடித்தளம்}} மூலம் தனி அடித்தளங்களை வைக்கவும்; பார்க்க [வலுவூட்டுக் கம்பியுடன் தனி அடித்தளங்களை வை](topic:footings-and-rebar).
