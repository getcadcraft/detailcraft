## நீங்கள் கற்றுக்கொள்வது

AI உதவியாளர் (அல்லது நீங்கள் எழுதிய ஸ்கிரிப்ட்) DetailCraft உடன் எப்படி வேலை செய்யலாம், அது எதைத் தொடலாம் என்பதை எப்படி முடிவு செய்வது.

DetailCraft க்கு **சொந்த AI இல்லை** மேலும் எங்கும் எதுவும் அனுப்பாது. உதவியாளரை நீங்களே கொண்டுவருகிறீர்கள்: Model Context Protocol (MCP) பேசும் எந்த நிரலும். DetailCraft அதற்குக் கருவிகளை மட்டும் வழங்குகிறது; எவற்றை வழங்குவது என்பதை நீங்கள் தேர்ந்தெடுக்கிறீர்கள்.

## இதை இயக்கவும்

1. {{ui:அமைப்புகள்}} ஐத் திறக்கவும் (ஆப் பட்டியில் உள்ள கியர், அல்லது {{key:Mod+,}}) மற்றும் {{ui:DetailCraft}} தாவலுக்குச் செல்லவும்.
2. {{ui:உதவியாளர்கள்}} கீழ், **AI உதவியாளர்களும் ஸ்கிரிப்டுகளும் DetailCraft ஐப் பயன்படுத்த அனுமதி** என்பதைத் தேர்வு செய்யவும். அதுவரை அது அணைக்கப்பட்டிருக்கும்.
3. அது என்ன செய்யலாம் என்பதைத் தேர்வு செய்யவும்: **வாசி** தொடக்கத்தில் தேர்வாகியிருக்கும்; **திருத்து**, **சேமி** அல்லது **ஏற்றுமதி** ஆகியவற்றை உங்களுக்குத் தேவைப்படும்போது மட்டும் தேர்வு செய்யவும்.

நீங்கள் தேர்வு செய்யாத அனுமதிகளுக்கு வெளியேயுள்ள கருவிகள் உதவியாளருக்கு வழங்கப்படாது; அது எப்படியும் ஒன்றைக் கேட்டால், DetailCraft மறுத்து அதைச் செயல்பாட்டுப் பதிவில் எழுதும். சுவிட்சை அணைத்தால் ஒரே நேரத்தில் எல்லா இணைப்புகளும் முடிவுக்கு வரும்.

## உங்கள் உதவியாளரை இணைக்கவும்

உதவியாளர்கள் உங்கள் கணினியில் உள்ள **CadCraft Studio** வழியாக இணைகிறார்கள்: Studio இந்தக் கணினி மட்டுமே அடையக்கூடிய ஒரு சிறிய சேவையகத்தை இயக்குகிறது, ஒவ்வொரு முறை தொடங்கும்போதும் அது உருவாக்கும் ஒரு டோக்கனால் பாதுகாக்கப்படுகிறது. Studio இல், {{ui:உதவியாளரை இணை}} ஐத் தேர்ந்தெடுத்து முகவரி மற்றும் டோக்கனை உங்கள் உதவியாளரில் நகலெடுக்கவும் (ஒட்ட வேண்டிய சரியான அமைப்புகளை Studio காட்டும்). டோக்கனை ஒருபோதும் பகிர வேண்டாம்.

:::note
உலாவி தாவல் உதவியாளருக்கான இணைப்பைத் திறக்க முடியாது: உலாவிப் பயன்பாடுகளில், உங்கள் கணினியில் CadCraft Studio ஐப் பயன்படுத்தும் வரை சுவிட்சுக்கு எந்த விளைவும் இருக்காது.
:::

## நீங்கள் பொறுப்பில் இருக்கிறீர்கள்

- **ஒவ்வொரு மாற்றமும் ஒரே செயல்தவிர் படி**, அது உதவியாளருடையது என்று பெயரிடப்பட்டிருக்கும் (எடுத்துக்காட்டாக "உதவியாளர்: உத்திரம் சேர்", "உதவியாளர்: கஸ்ஸெட்டுகள் சேர்"). {{key:Mod+Z}} உதவியாளரின் கடைசி மாற்றத்தை முழுமையாகத் திரும்பப் பெறும். உதவியாளரின் சொந்த `undo` அதன் சொந்தப் படிகளை மட்டுமே திரும்பப் பெறும், உங்களுடையதை அல்ல, அது அதை வெளிப்படையாகக் கேட்காத வரை.
- **அது உங்களுக்காகக் காத்திருக்கிறது.** நீங்கள் ஓர் உறுப்பை வைக்கும்போது, பாகங்களை நகர்த்தும்போது அல்லது ஒட்டும்போது, DetailCraft உதவியாளரின் மாற்றங்களை மறுத்து மீண்டும் முயற்சிக்கச் சொல்கிறது.
- **அது இணைக்கப்பட்டிருக்கும்போது நீங்கள் அறிவீர்கள்.** இணைக்கப்பட்டிருக்கும்போது ஆப் பட்டியில் உள்ள பொத்தான் உதவியாளரின் பெயரைக் காட்டும்; அது என்ன செய்ய அனுமதிக்கப்பட்டுள்ளது என்று பார்க்கவோ, அல்லது **துண்டிக்கவோ** அதைச் சொடுக்கவும்.
- **செயல்பாடு.** {{ui:அமைப்புகள்}} › {{ui:DetailCraft}} › {{ui:உதவியாளர்கள்}} › {{ui:செயல்பாடு}} ஒவ்வொரு அழைப்பையும் பட்டியலிடுகிறது: எப்போது, எந்தக் கருவி, முடிந்ததா அல்லது மறுக்கப்பட்டதா. {{ui:பதிவைச் சேமி}} அதன் நகலை வைத்திருக்கும்.

## உதவியாளர் என்ன கேட்கலாம்

எல்லா நீளங்களும் மில்லிமீட்டரில்; புள்ளிகள் `[x, y, z]`, z மேல்நோக்கி, மாதிரியில் உள்ளபடி.

| கருவி | அனுமதி | அது என்ன செய்கிறது |
|---|---|---|
| `app_info`, `model_describe` | வாசி | திறந்துள்ள மாதிரி: கட்டக் கோடுகள், மட்டங்கள், கட்டம் வாரியாக, வகை மற்றும் வெட்டுவடிவம் வாரியான உறுப்புகள், இணைப்புகள், அடித்தளங்கள், படிக்கட்டுகள், பாகங்கள், எஃகு எடை, சிக்கல்கள் |
| `parts_list` | வாசி | பாகக் குறிகள், வெட்டு நீளம், எண்ணிக்கை, எடை, கட்டம் மற்றும் அசெம்பிளி குறிகளுடன்; வகை, வெட்டுவடிவம், குறி அல்லது கட்டம் வாரியாக |
| `problems_list` | வாசி | {{ui:சிக்கல்கள்}} தாவல் பட்டியலிடுவது, ஒவ்வொன்றும் எதைப் பற்றியது என்பதுடன் |
| `clash_check` | வாசி | [மோதல் சரிபார்ப்பு](topic:clash-check), அதன் சகிப்புத்தன்மை மற்றும் கட்டங்களுடன் |
| `selection_get` | வாசி | நீங்கள் தேர்ந்தெடுத்தது |
| `selection_set` | திருத்து | உறுப்புகள், இணைப்புகள், அடித்தளங்கள் அல்லது படிக்கட்டுகளைத் (id அல்லது பகுதிக் குறி மூலம்) உங்களுக்குக் காட்ட தேர்ந்தெடுக்கும்; எதையும் மாற்றாது |
| `member_add` | திருத்து | இரண்டு புள்ளிகளுக்கு இடையே ஒரு கற்றை, தூண், மூலைவிட்டம் அல்லது தகடு |
| `connection_add` | திருத்து | உறுப்புகள் சந்திக்கும் இடங்களில் முனைத் தகடுகள், வெட்டுத் தாவல்கள், அடித்தகடுகள், இணைப்புகள் அல்லது கஸ்ஸெட்டுகள், {{ui:இணை}} பொத்தான்கள் செய்வது போலவே |
| `undo` | திருத்து | உதவியாளரின் கடைசிப் படிகளைத் திரும்பப் பெறுகிறது |
| `model_save` | சேமி | DetailCraft இன் சொந்த சேமிப்பு |
| `model_export` | ஏற்றுமதி | IFC, NC கோப்புகள், BOM, வளைவு அட்டவணை, KISS கோப்பு அல்லது வெட்டுப் பட்டியல், {{ui:வெளியீடு}} பொத்தான்கள் உருவாக்குவது போல |
| `usd_export` | ஏற்றுமதி | எஃகு மாதிரியை USD ஆக (.usda, .usdc அல்லது .usdz), {{ui:வெளியீடு}} › {{ui:USD}} எழுதுவது போல (பார்க்கவும் [எஃகு மாதிரியை USD ஆக ஏற்றுமதி செய்](topic:usd)); Studio இல் நீங்கள் அனுமதித்த கோப்புறைக்கு கோப்பை எழுதலாம் |

## ஏதேனும் வேலை செய்யவில்லை என்றால்

- **உதவியாளருக்கு DetailCraft கருவிகள் தெரியவில்லை:** இந்தச் சாளரத்தில் சுவிட்ச் இயக்கத்தில் உள்ளதா, மற்றும் Studio இல் சாளரம் திறந்துள்ளதா என்பதைச் சரிபார்க்கவும்.
- **"திருத்த அனுமதி தேவை"** (அல்லது சேமி, ஏற்றுமதி): {{ui:உதவியாளர்கள்}} இன் கீழ் அதைத் தேர்வு செய்யவும், பின் மீண்டும் கேட்கவும்.
- **"பயனர் ஓர் உறுப்பை வைத்துக்கொண்டிருக்கிறார்":** நீங்கள் செய்துகொண்டிருப்பதை முடிக்கவும் (அல்லது {{key:Esc}} ஐ அழுத்தவும்), பின் உதவியாளரை மீண்டும் முயற்சிக்க அனுமதிக்கவும்.
- **"401" அல்லது "token" பிழைகள்:** டோக்கன் மாறிவிட்டது (Studio மறுதொடக்கம் செய்யப்பட்டது, அல்லது {{ui:புதிய டோக்கன்}}). புதிய டோக்கனை உதவியாளரின் அமைப்புகளில் நகலெடுக்கவும்.

## இதையும் காண்க

- [AI உதவியாளர்களுக்கான செய்முறைகள்](common:assistants-recipes): செயல்பட்ட எடுத்துக்காட்டுகள், ஒவ்வொன்றும் அழைக்கும் கருவிகளுடன்.
