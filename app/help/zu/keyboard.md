## Kopisha namathisela

Lezi zisebenza lapho ikhesa lingekho ensimini yombhalo noma yenombolo (lapho zikopisha, zinamathisele futhi zikhethe umbhalo wakho njengokuvamile). Ukunamathisela ngakunye, ukusika, ukuphinda noma ukususa ngakunye kuyinyathelo elilodwa lokuHlehlisa. Okwengeziwe: [Kopisha, namathisela futhi uphinde](topic:copy-paste).

| Ukhiye | Yenza |
|---|---|
| {{key:Mod+C}} | {{ui:Kopisha}} izitho nezisekelo ezikhethiwe (namaholo, ama-cope nezixhumanisi zazo) |
| {{key:Mod+X}} | {{ui:Sika}}: kopisha ukukhethwa, bese usisusa |
| {{key:Mod+V}} | {{ui:Namathisela}}: ikopi ilandela isikhombi; chofoza ukuhlangana kwegridi ukuze uyibeke lapho |
| {{key:Mod+Shift+V}} | {{ui:Namathisela endaweni}}: ezixhumanisweni ayakhopishwa kuzo |
| {{key:Mod+D}} | {{ui:Phinda}}: ikopi ngokushesha, ihanjiswe ngokuhlukaniswa okusezilungiselelweni ze-[DetailCraft](topic:settings) |
| {{key:Mod+A}} | {{ui:Khetha konke}}: wonke amalungu, ixhumanisi nesisekelo |
| {{key:Esc}} | {{ui:Khetha lutho}} |

Uma ukhethe umbhalo ekhasini (ethebhuleni lombiko, nje) futhi akukho okukhethiwe kumodeli, {{key:Mod+C}} ikopisha umbhalo, njengokuvamile.

{{ui:Okusha}}, {{ui:Isampula}} nokuthumela akunakhiye; sebenzisa ibha yamathuluzi.

Akukho kulezi okhiye okwenza lutho lapho kuvuliwe ingxoxo (ukubuka kuqala komdwebo wokukhiqiza noma umbuzo).

## Imouse

| Isenzo | Ku-3D | Ku-Ipulani nokubukeka kohlangothi |
|---|---|---|
| Chofoza | Khetha ingxenye, noma beka ngegridi eseduze uma ithuluzi lokubeka livuliwe (noma namathisele lapho ukhethe ukunamathisela) | Okufanayo |
| {{key:Shift}}, {{key:Ctrl}} noma {{key:Mod}} nokuchofoza | Engeza ingxenye ekukhethweni, noma uyisuse | Okufanayo |
| Cindezela ingxenye ekhethiwe bese uhudula | Hambisa ukukhethwa phakathi kwezinga; ngokubamba {{key:Mod}}, phezulu nasezansi | Hambisa ukukhethwa (ekubukeni kohlangothi: ngasemgqeni, phezulu nasezansi) |
| Hudula ngenkinobho yesobunxele | Phendulela imodeli | Ngo-{{ui:Khetha}}: iwindi lokukhetha (ngakwesokudla: kuphelele ngaphakathi; ngakwesokunxele: kuthinta). Lapho ubeka: shelelisa |
| {{key:Shift}} nokuhudula ngenkinobho yesobunxele | Ngo-{{ui:Khetha}}: iwindi lokukhetha, elengezwa ekukhethweni. Lapho ubeka: shelelisa | Ngo-{{ui:Khetha}}: iwindi lokukhetha, elengezwa ekukhethweni |
| {{key:Ctrl}} noma {{key:Mod}} nokuhudula ngenkinobho yesobunxele | Shelelisa | Akukho |
| Hudula ngenkinobho yesokudla | Shelelisa | Shelelisa |
| Hudula ngenkinobho ephakathi | Sondeza | Ngo-{{ui:Khetha}}: shelelisa. Kwezinye: sondeza |
| Ivili | Sondeza maqondana nephakathi kokubuka | Sondeza |
| Lahla ifayela le-`.detailcraft.json` ku-app | Vula kona | Vula kona |

Ukuchofoza kubalwa kuphela uma isikhombi sinyakaza ngaphansi kwamapikseli angu-5 cishe phakathi kokucindezela nokukhipha; ukunyakaza okude kuyisihudulo.

## Trackpad

| Isenzo | Yenza |
|---|---|
| Ukuswayipha ngeminwe emibili phezulu noma phansi, noma ukukhama | Sondeza |
| Cindezela futhi uhudule | Phendulela (3D) noma shelelisa (Ipulani nokubukeka kohlangothi) |
| {{key:Shift}} nokucindezela nokuhudula | Shelelisa ku-3D |
| Ukuchofoza ngeminwe emibili | Chofoza ngesokudla (akukho imenyu ekubukeni) |

## Ukuthinta

Kuthebhulethi noma kuskrini esithintwayo:

| Isenzo | Yenza |
|---|---|
| Thinta | Khetha ingxenye, noma beka endaweni yegridi eseduze uma ithuluzi lokubeka livuliwe (ukuthinta okungaphakathi kobubanzi bomunwe owodwa cishe kubalwa) |
| Cindezela isikhathi eside ingxenye | Engeza ekukhethweni, noma uyisuse (lokho okwenziwa yi-{{key:Shift}}+ukuchofoza ngemouse) |
| Umunwe owodwa ngengxenye ekhethiwe, bese uhudula | Hambisa ukukhethwa, ukuqondanisa ezindaweni zegridi |
| Umunwe owodwa kwenye indawo | Phendulela imodeli (3D) noma shelelisa (Ipulani nokubukeka kohlangothi) |
| Iminwe emibili | Khama ukusondeza; hambisa ndawonye ukushelelisa |

Izinkinobho, izinhlu nezinkundla zinkulu uma iskrini sithintwa kuphela. Iwindi lokukhetha ludinga imouse; ngeminwe, thinta futhi cindezela isikhathi eside.

## Okhiye ibhrawuzi abagcinayo

Ezinye izinqamuleli zibhrawuzi, futhi akukho khasi elingazisebenzisa, njengo-{{key:Mod+W}} (vala ithebhu), {{key:Mod+T}} (ithebhu entsha) kanye no-{{key:Mod+N}} (iwindi elisha). Uma {{key:Mod+Y}} ivula umlando webhrawuzi esikhundleni sokuphinda wenze, sebenzisa {{key:Mod+Shift+Z}}.

Izinqamuleli zifika ku-DetailCraft kuphela uma ikhasi linekhibhodi. Uma ukhiye ungenzi lutho, noma ibhrawuzi liyawenza, chofoza kuqala endaweni engenalutho yewindi le-DetailCraft (njengemva kokubhala ku-ibha yekheli).

## Lapho kukhona ukuhambisa

Akukho umyalo othi Hambisa: khetha ingxenye bese uyihudula phakathi kwezinga (bamba {{key:Mod}} ukuhudula phezulu nasezansi), noma uhlele i-{{ui:Ukuqala}} ne-{{ui:Ukuphela}} ku-{{ui:Izakhiwo}}.
