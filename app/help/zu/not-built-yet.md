I-DetailCraft iyinguqulo yokuqala. Leli khasi lidweba lokho okungakenzi okwamanje, ukuze ukwazi ukuhlela ngakho. Akukho lapha isithembiso sosuku.

## Ukumodela

| Akukakwenziwa | Esikhundleni, namuhla |
|---|---|
| Ukuhudula uhlangothi olulodwa lwesakhi (ukulolonga) | Hlela {{ui:Ukuqala}} noma {{ui:Ukuphela}} ngaphansi kwe-{{ui:Imiphetho (x, y, z mm)}} epaneli {{ui:Izakhiwo}} |
| Isihlungi sokukhetha (amabhimu kuphela, iphrofayili eyodwa kuphela) | Hudula iwindi, bese {{key:Shift}}+chofoza ukuze uphume izingxenye |
| Ukuhlela okukhethiwe ngesethi; ukujikeleza ngaphezu kwe-eksisi ethambekile; ukubonisa endizeni ethambekile | Kopisha unamathisele ngokuthile, noma {{ui:Phinda}} kona; ukujikeleza nokubonisa kusebenza epulanini ([Khetha ngewindi, hambisa, jikeleza, bonisa, guqula okuningi](topic:select-and-change)) |
| Amaphoyinti angaphandle kwegridi lapho uchofoza | Beka egridini, bese uthayipha izixhumanisi zokuphela |
| Ukubukeka kohlangothi ngemigqa yegridi enombolo; izibuko ezigciniwe; izindiza zokusebenza | Sebenzisa {{ui:3D}}, noma {{ui:Engeza ngegridi}} |
| Izimbobo ezidwetshwe njengokusika okuqinisekile kwi-3D | Izimbobo zibonakala njengamaplagi amnyama; ziyiqiniso kukho konke ukukhishwa |
| Ama-cope agobile noma aphambanayo, ezinye izinqumo nezifakelo | Ama-cope asikwele kuma-I-shape kuphela |

| Ukufakwa kwe-imperial | Thayipha amamilimitha (25.4 ngeyintshi) |
| Ukuhlela noma ukususa iphrofayili yezifiso | Engeza iphrofayili elungisiwe ngegama elisha |

## Uxhumano

I-DetailCraft yakha uxhumano olu-séyisi: i-gusset yeshiyi (bona [Ama-gusset eshiyi](topic:brace-gussets)); ukuhlanganisa okubotshwe phakathi kwezingcezu ezimbili ze-I-shape eyodwa (bona [Ukuhlanganisa](topic:splices)); i-mitre phakathi kwama-I-shape amabili ahlangana ngengeli, esikiwe kuphela noma nama-end plate abotshiwe (bona [Izixhumanisi ze-mitre](topic:mitres)); i-end plate ebotshiwe egxilile noma eneleyo esuka ebhimini elimile nelinqamile lizinga elilodwa lifike efulenjini noma ewebini lensika ye-I-shape; i-shear tab esuka ebhimini (esikwele, esibhekile noma esithambekile) ifike efulenjini noma ewebini lensika; nepuleti lesisekelo lensika elinezinti ezine zokubambelela.

| Akukakwenziwa | Esikhundleni, namuhla |
|---|---|
| Ama-end plate abhekile noma athambekile | Sebenzisa [ama-shear tab](topic:shear-tabs), athatha amabhimu abhekile nathambekile |
| Ama-clip angle; amapuleti okugcwalisa ama-splice nama-splice phakathi kwezinhlobo ezihlukile; ama-corner gusset ashiselwe ebhimini nasensikeni, ama-gusset anecile | Yiqoqe kwesinye isofthiwe, noma engeza amapuleti nezimbobo ngesandla njengezingxenye ezikhululekile; bona [Ukuhlanganisa](topic:splices), [Ama-gusset eshiyi](topic:brace-gussets) |
| Ama-stiffener anecile noma abhoxekile; izimbobo ze-grout; umgodi wesisekelo se-shear lug | Ama-stiffener anxande; bona [Amapuleti esisekelo](topic:base-plates) |
| Ama-haunch; ama-mitre ashiselwe ngeweld yokuhlangana; ama-stiffener ahambisana namaflenji wenye ingxenye | I-[mitre](topic:mitres) enama-end plate nama-stiffener ewebini, noma ukusika okuqondile kwe-mitre; engeza amanye amapuleti ngesandla njengezingxenye ezikhululekile |
| Ukuhlolwa kokwakheka koxhumano (amandla) | Hlola uxhumano ngokubalwa kwenjiniyela yakho; i-DetailCraft ixwayisa kuphela ngebanga lomphetho nokuhlukaniswa |
| Izimbobo ezinde | Izimbobo ezijikelezayo kuphela |

## Ukuhlaziya

| Akukakwenziwa | Esikhundleni, namuhla |
|---|---|
| Ukuhlolwa kokwakheka ngaphezu kwama-I-shape ensimbi: amatyubhu, ama-engeli, amachaneli, izakhiwo ezishiselwe, izingxenye ezincane noma ze-class 4, ukuphenduka, uxhumano; kukhonkrithi: ukuqina kokuntuleka kwesikhundla (sway), ukuphenduka, ukwakhiwa kokuzamazama, amasilebu nezindonga | Ithebhu ethi {{ui:Ukuhlaziya}} ihlola ama-I-shape ensimbi ngokwe-AISC 360 noma i-EN 1993-1-1 ([Hlola izingxenye zensimbi ngekhodi yokwakha](topic:design-checks)); okunye ikushiya kumakwe ngokuthi "akuhlolwanga"; injiniyela iyibuyekeza yonke |
| Ukuhlaziywa kokuphenduka, ukudlidliza | Okwesibili yi-P-Delta kuphela (elastic); akukho ukuhlaziywa kokuphenduka (modal, response spectrum, time history kanye ne-pushover zisethebhu {{ui:Ukuhlaziya}}) |
| Ukuhlolwa kokwakheka okubuyekezwe injiniyela | Kuze kube yilapho kubuyekezwa, zisiza kuphela: hlola izingxenye ezimbili noma ezintathu ngesandla noma kusofthiwe yenjiniyela yakho ngaphambi kokuthembela kuzo |
| Imithwalo yendawo, yomoya nochoba eyenziwe ngezindawo | Beka imithwalo ezingxenyeni ngesandla, nge-kN/m noma nge-kN |
| Ukubekwa kwezingxenye ngokuphambuka, uxhumano olungaphakathi, amashesi okuqina kuphela, amapuleti nezisekelo esakhiweni | Izingxenye ziyahlaziywa ngemigqa yazo yokusebenza; amashesi athwala ukuqina nokucindezeleka |

## Amaplatifomu

- I-DetailCraft yenzelwe isikrini sedeskithophu, selaphu noma sethebulethi. Iyasebenza nakufoni: imodeli igcina isikrini nezinkundla, nemibiko ivulwa njengamashidi ebhala engaphansi, kodwa kunendawo encane yezinkundla.
- Ukusebenza ngaphandle kwe-inthanethi kudinga ukuthi i-DetailCraft ilondolozwe ukuze isebenze ngaphandle kwe-inthanethi kuqala, nge-{{ui:Londoloza ngaphandle kwe-inthanethi}} ebhareni yohlelo; uma ifunda {{ui:Ilungele ukusetshenziswa ngaphandle kwe-inthanethi}}, konke kulolu hlobo kusebenza ngaphandle kokuxhumeka. Bona [Ukusebenza ngaphandle kwe-inthanethi](common:offline).

Uma enye yalezi zinto ivimbela umsebenzi wakho, sitshele ngekhasi lokusekela [ikhasi losekelo](https://getcadcraft.com/support); liyasisiza ekuthatheni isinqumo sokuthi yini okufanele sikhe ngayo okulandelayo.
