DetailCraft 有一种自己的文件，即模型，以及五种导出。每次保存和每次导出都是一次下载。不会上传任何内容，服务器上也不保留任何内容。

## 模型文件

DetailCraft 模型保存为 `<name>.detailcraft.json`，其中 `<name>` 是{{ui:模型}}面板中的模型名称。它包含轴网、标高、构件（连同其孔和切角）、节点及其设置、基础以及你的自定义截面。

零件、编号、螺栓、焊缝和钢筋不会存储：DetailCraft 每次打开时都会根据模型重新计算它们。因此模型文件很小。

### 保存

1. 在{{ui:模型}}面板顶部的{{ui:名称}}字段中输入名称。
2. 选择{{ui:文件}}组中的{{ui:保存}}，或按{{key:Mod+S}}。
3. 浏览器下载 `<name>.detailcraft.json`。状态栏显示“已保存……（已下载）”，浏览器标签页标题开头的圆点消失。

每次保存都是一次新的下载。浏览器不会覆盖你打开的文件；根据其设置，它会给名称加上编号，例如 `Frame (1).detailcraft.json`，或询问保存位置。请通过重命名下载的文件来保留你自己的版本。

:::chromium
Chrome 和 Edge 保存到“下载”文件夹，除非在浏览器的下载设置中开启了**下载前询问每个文件的保存位置**。如果想每次都选择文件夹和文件名，请开启它。
:::

:::firefox
Firefox 保存到“下载”文件夹，如果其设置中开启了**总是询问保存文件的位置**，则每次都会询问。
:::

:::safari
Safari 保存到“下载”文件夹。要更改文件夹，请打开 **Safari，设置，通用，文件下载位置**。
:::

### 打开

1. 选择{{ui:文件}}组中的{{ui:打开}}，或按{{key:Mod+O}}。
2. 选取一个 `.detailcraft.json` 文件。

或者从{{pick:mac=访达|windows=文件资源管理器|linux=文件管理器}}中拖动该文件并放到视图上。拖动时视图显示“放下 DetailCraft 模型即可打开”。

如果打开的模型有未保存的更改，DetailCraft 会先询问：{{ui:取消}}、{{ui:放弃更改}}或{{ui:先保存}}。

DetailCraft 在使用文件之前会检查文件的每个字段。无法使用的内容会被省略，状态栏会说明是什么，例如“2 个构件无效，已被省略。”由更新版本 DetailCraft 保存的模型会被拒绝并给出提示，而不是只打开一半。

### 可以打开什么

它自己的模型文件（`.json`，最大 50 MB）和 IFC 文件（`.ifc`，IFC2X3 或 IFC4，最大 200 MB）。打开的 IFC 文件，或用{{ui:导入IFC}}带入的 IFC 文件，会成为一个新模型，包含其梁、柱、构件、钢板、轴网和标高，其上切出的孔和切角，以及作为独立螺栓的螺栓；报告会列出被省略的内容。参见 [IFC 导出](topic:ifc-export#import)。它暂时不能打开DWG、DXF或任何其他深化程序的模型；尝试时会显示“DetailCraft 可打开自己的模型 (.detailcraft.json) 和 IFC 文件 (.ifc)。”

## 丢失的工作、最近文件、桌面应用

- 当模型有你尚未保存的更改时，DetailCraft 会在此浏览器中保留一份副本。如果标签页或浏览器在你保存之前停止，下次打开 DetailCraft 时它会询问**要恢复你的工作吗？**：恢复该副本，或放弃。参见[恢复你的工作](common:recover)。
- 在浏览器允许 DetailCraft 再次打开它们时，你最近打开的模型会列在起始屏幕上；单击其中一个即可重新打开。
- 在桌面应用中，{{ui:保存}}会把模型写回你打开的文件（在浏览器中则下载一份副本），双击 DetailCraft 模型或 IFC 文件会在 DetailCraft 中打开。

## 导出

所有导出都使用模型名称。请在{{ui:输出}}组中选择它们。

| 按钮 | 文件 | 内容 |
|---|---|---|
| {{ui:IFC}} | `<name>.ifc` | IFC4：楼层、轴网、每个钢零件（作为带孔和切角的截面拉伸体）、装配体、螺栓和锚栓、基础以及每根钢筋。参见[导出 IFC](topic:ifc-export)。 |
| {{ui:NC文件}} | `<name> NC.zip` | 每个零件编号一个 DSTV `.nc1` 文件。参见[向车间发送 NC 文件](topic:nc-export)。 |
| {{ui:BOM}} | `<name> BOM.csv` | 一个文件中的三张表：零件、装配体，以及螺栓和锚栓。参见[编号和材料清单](topic:marks-and-bom)。 |
| {{ui:钢筋弯曲}} | `<name> bending schedule.csv` | 基础中的每个钢筋编号。参见[基础和钢筋](topic:footings-and-rebar)。 |
| {{ui:加工详图}} | `<name> <mark>.pdf` | 所选零件（工字形截面和钢板）的一张图纸（默认A3，除非你选了其他尺寸）。参见[制作加工详图](topic:shop-drawings)。 |
| {{ui:图纸}} | `<name> drawings.pdf`、`<name> <sheet>.pdf`；`<name> <sheet>.dwg` 或 `.dxf`，多张时为 `<name> drawings DWG.zip`（或 `DXF.zip`） | 按你选择的图纸尺寸给出的平面图、立面图和装配图；DWG和DXF为实际大小，纸上 1 个单位 = 1 mm。参见[总体布置图和装配图](topic:drawings)。 |

### 关于 CSV 文件的说明

- 它们以字节顺序标记开头，使电子表格程序能正确读取带重音的字符。
- 以 `=`、`+`、`-` 或 `@` 开头（且不是纯数字）的单元格会加上前导撇号，因此电子表格永远不会把它当作公式运行。
- 长度单位为毫米，重量单位为千克。

### 关于 PDF 的说明

PDF 中的文字使用标准的 Helvetica 字体。它没有的字符（西欧字符集之外）会打印为“?”，状态栏会告诉你有多少个。

## 单位

DetailCraft 全程以毫米为单位：轴网、标高、坐标、截面、孔以及每种导出。截面名称保持其公布的形式（W12x50 是美国的标示，即使其尺寸以 mm 显示）。目前还没有英制输入。

## 在线和离线

打开、保存和导出都在你的浏览器中进行，因此 DetailCraft 加载完成后，无论是否联网，它们的工作方式都相同。

要以后在没有网络连接时使用 DetailCraft，请在联网时选择应用栏中的{{ui:保存以供离线使用}}。按钮会计数（“正在保存3/20”），然后显示{{ui:离线可用}}。保存的副本包含三维图形库（约 2.6 MB）和本帮助，因此保存后，三维视图、所有导出和帮助都可以离线使用。详情，以及哪些功能仍需要网络连接：[离线工作](common:offline)。

:::offline
你处于离线状态。如果应用栏显示{{ui:离线可用}}，则打开、保存和导出照常工作。如果没有，请保持此标签页打开，在重新联网之前不要重新加载它，并立即保存你的模型。
:::

云端保存尚不可用，也还没有桌面版本。请像备份其他工作文件一样备份你的 `.detailcraft.json` 文件。更多内容参见[文件去向](common:your-files)。

## 未保存的工作

DetailCraft 只在打开的标签页中保留模型。如果你带着未保存的更改关闭或重新加载标签页，浏览器会询问是否离开该页面；其措辞是浏览器自己的。请经常用{{key:Mod+S}}保存。
