端板连接是将钢板焊接到梁端，并用螺栓与柱翼缘或腹板相连。DetailCraft会放置钢板，将梁端切短，在钢板和柱翼缘上钻出相配的孔，添加螺栓和焊缝，并检查边距和间距。

:::warning
DetailCraft不设计连接。设置值仅为初始值，可以修改；系统不校核强度。边距和间距警告采用EN 1993-1-8表3.3的最小值，这可能与所遵循的规则不同。
:::

## 可连接的情形

- **水平**梁（两端高度相同），竖直（旋转角为0），截面为工字形。
- 与**竖直**工字形柱的翼缘或腹板相连，且与柱垂直。
- 梁端必须位于柱的轴线上，且介于柱底与柱顶之间。

斜向或倾斜的梁以及非工字形截面会被拒绝，并说明原因：此类情形请使用[剪力板](topic:shear-tabs)。在腹板上连接时，钢板和梁翼缘必须能够放入柱翼缘之间；若不能，DetailCraft会发出警告。

:::tip
旋转角为0时，柱的翼缘沿编号轴线方向（x）布置。从A到B的梁与柱腹板相交，并会在腹板上获得端板。
:::

## 为梁添加端板

1. 选择{{ui:选择}}（{{key:V}}），然后单击梁。
2. 在{{ui:连接}}组中选择{{ui:端板}}，或在{{ui:特性}}面板中选择{{ui:添加端板}}。
3. 梁的每个自由端，若与柱翼缘或腹板垂直相交，都会获得一块端板。状态栏会显示“已添加2个端板。选择其中一个可修改其钢板、螺栓和焊缝；“相同节点”可将其复制到相似节点。”
4. 第一个新增的端板会被选中，其设置显示在{{ui:特性}}面板中。

若没有任何变化，请查看状态栏：

- “此梁未终止于柱轴线上。端板设置在梁端与竖直柱相交处。”
- “此梁与柱以斜角相交，或为倾斜：端板仅适用于垂直且水平的节点。请使用剪力板。”
- “两端均已有连接。”

## 修改钢板、螺栓和焊缝

单击端板（或其中一个螺栓）即可选中该连接。在{{ui:钢板、螺栓和焊缝（mm）}}下：

| 设置 | 默认值 | 作用 |
|---|---|---|
| 钢板厚度 | 20 | 钢板的厚度；也决定梁端超出柱翼缘被切去的距离 |
| 钢板宽度 | 180 | 横跨节点的宽度 |
| 梁上方延伸 | 0 | 超出上翼缘的长度；大于0时形成加长端板 |
| 梁下方延伸 | 0 | 超出下翼缘的长度 |
| 螺栓直径 | 20 | 公称螺栓尺寸 |
| 孔径 | 22 | 钢板和柱翼缘上的间隙孔 |
| 螺栓等级 | A325 | 文本；列入材料清单 |
| 螺栓排数 | 4 | 每排两个螺栓，以钢板高度为中心对称布置 |
| 排距 | 75 | 各排之间的竖向间距 |
| 线距 | 100 | 同一排两个螺栓之间的水平间距 |
| 螺栓长度余量 | 30 | 为螺母、垫圈和螺纹增加的长度，见下文 |
| 角焊缝尺寸 | 8 | 梁端周边全部焊接 |
| 钢板材料 | A36 | 文本 |

输入新值后按{{key:Enter}}或{{key:Tab}}。钢板、孔、螺栓以及梁的切割长度会立即更新。每次修改都是一个撤销步骤。

在设置下方会显示该连接所生成的内容：

- {{ui:螺栓}}：例如“8 × 20 × 70 A325（夹紧长度36.2）”。
- {{ui:焊缝}}：尺寸、位置及长度。
- {{ui:钢板}}：其尺寸及零件编号。

### 数值计算方式

- 梁被切短的长度为柱深的一半（若在腹板上，则为腹板厚度的一半）加上钢板厚度，使钢板位于柱面上。
- 钢板高度为梁高加上两侧的延伸量。
- 螺栓长度 = 夹紧长度（钢板厚度 + 柱翼缘或腹板厚度）+ 余量，向上取整至下一个5 mm的倍数。
- 显示的焊缝长度为梁截面的周长。

### 警告

连接仍会生成，但以下情况会显示在其下方及{{ui:问题}}选项卡中：

- 螺栓排或螺栓距钢板边缘小于1.2 × 孔径。
- 排距小于2.2 × 孔径，或线距小于2.4 × 孔径。
- 孔延伸至柱腹板或其圆角处，或超出柱翼缘。
- 钢板宽于柱翼缘，或（在腹板上时）宽于翼缘之间的空间；梁翼缘无法放入其间。
- 螺栓排过于靠近梁翼缘，或线距过小，以致梁腹板及其焊缝无法容纳。

## 复制到所有相似节点

1. 选择已设置好的连接。
2. 在{{ui:特性}}面板中选择{{ui:应用到相似节点（n）}}，或在{{ui:连接}}组的{{ui:更多}}菜单中选择{{ui:相同节点}}。括号中的数字为将获得该连接的节点数。
3. 梁截面和柱截面相同、梁连接至相同类型面、且尚无连接的每个节点，都会获得一份具有相同设置的副本。状态栏会显示数量。

副本彼此独立：之后修改其中一个不会影响其他副本。已有连接的节点保持不变；若希望替换，请先删除它们。

## 移动与删除

每次模型变化时，连接都会根据其设置重新生成，因此移动或调整梁或柱的同时也会带动其端板。若某次变化使节点不再适用，连接仍保留在模型中，{{ui:问题}}选项卡会说明原因，例如“梁端已不在柱轴线上。”

要删除连接，请选中它并按{{key:Delete}}。删除梁或柱时，其连接也会一并删除。
