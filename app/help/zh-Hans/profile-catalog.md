DetailCraft 内置 2,311 种规格，每种都取自公布的表格，并通过应用的测试检查：由尺寸算出的面积必须与公布的面积一致，公布的重量必须等于该面积乘以钢的密度。钢板和自定义截面则根据其尺寸生成。

## 命名

- **美国截面** 按 AISC 手册的格式书写，x 为小写：W12x50、C10x15.3、L4x4x1/2、HSS6x6x1/4、HSS6.625x0.280。输入时不区分大小写。
- **管材** 按 AISC 数据库的写法：Pipe4STD、Pipe4XS、Pipe4XXS（分别为标准、加厚、特加厚）。
- **欧洲截面** 按 EN 10365 书写：IPE200、HEA240、HEB300、UPN200（中间无空格）。
- **英国截面** 先写系列，再写 Blue Book 中的规格：UB305x165x40、UC203x203x46、PFC200x90x30、EA100x100x10.0、UEA150x90x10.0、SHS100x100x5.0、RHS200x100x8.0、CHS88.9x5.0。冷成型空心截面以 CF 开头：CFSHS100x100x5.0。按图纸中常见的写法输入同样有效：305x165x40 UB、L100x100x10、SHS100x5。
- **钢板** 的名称为 `PL<thickness>x<width>`，单位为毫米：PL20x200 表示厚 20 mm、宽 200 mm。使用{{ui:钢板}}工具可选择任意尺寸。
- **自定义截面** 可使用任意名称，只要不与目录名称相同，也不与钢板名称相似。

在{{ui:截面}}列表中，每组的标题会注明其来源，例如“W型钢 — AISC Shapes Database v16.0”。

## 来源

| 组别 | 来源 | 说明 |
|---|---|---|
| W 型钢、S 型钢、槽钢（C）、角钢（L）、HSS、管材 | AISC Shapes Database v16.0 | 尺寸由英寸精确换算为毫米；每米质量由公布的 lb/ft 换算 |
| IPE、HEA、HEB、UPN | EN 10365:2017 | 按公布值使用毫米和 kg/m |
| UB、UC、PFC、EA、UEA、SHS、RHS、CHS、CFSHS、CFRHS、CFCHS | Steel for Life Blue Book（英国），表 v18（BS EN 10365、BS EN 10056-1、BS EN 10210-2、BS EN 10219-2） | 按公布值使用毫米和 kg/m |
| 钢板 | 参数化 | 质量由面积 × 7850 kg/m³ 计算 |
| 自定义 | 自定义截面的尺寸 | 质量由面积 × 7850 kg/m³ 计算 |

截面的绘制方式：

- **W 型钢：** AISC 数据库未给出圆角半径，因此 DetailCraft 按 r = kdes − tf 绘制圆角。
- **S 型钢和槽钢（C、UPN）：** 翼缘平行，采用公布的平均厚度，角部为直角（实际翼缘为斜面）。
- **角钢：** 直角。
- **矩形 HSS：** 采用设计壁厚（名义值的 0.93 倍，符合 AISC 360-22 B4.2 的规定），外角半径为该壁厚的两倍。
- **圆形 HSS 和管材：** 设计壁厚（名义值的 0.93 倍）。
- **IPE、HEA、HEB、UB、UC：** 采用公布的根部圆角半径。
- **PFC、EA、UEA：** 直角（公布的质量和面积仍包含圆角）。
- **SHS、RHS、CHS：** 名义壁厚。热加工角部：外侧 1.5 t，内侧 t。冷成型：壁厚 6 mm 及以下时外侧 2 t、内侧 t；10 mm 及以下时为 2.5 t 和 1.5 t；超过 10 mm 时为 3 t 和 2 t。

## 各截面可做的操作

| 截面 | 开孔 | 切角 | 端板和底板 | NC 文件 | 加工详图 |
|---|---|---|---|---|---|
| 工字形（W、S、IPE、HEA、HEB、UB、UC、自定义工字形） | 腹板、上翼缘、下翼缘 | 是 | 端板：梁和柱。底板：是 | 是 | 是 |
| 槽钢（C、UPN、PFC） | 腹板、上翼缘、下翼缘 | 否 | 仅底板 | 是 | 是 |
| 矩形 HSS、SHS、RHS | 侧壁（腹板）、顶部、底部 | 否 | 仅底板 | 是 | 是 |
| 圆形 HSS、管材、CHS | 暂不支持 | 否 | 仅底板 | 是 | 是 |
| 角钢（L、EA、UEA） | 暂不支持 | 否 | 仅底板 | 是 | 是 |
| 钢板和自定义扁钢 | 钢板面 | 否 | 否 | 是 | 是 |

对于矩形管，在“腹板”面上的孔会穿过两侧壁。各 NC 文件所包含的内容参见[NC文件字段](topic:nc1-fields)。

## 需要其他规格？

可将其添加为[自定义截面](topic:plates-and-profiles#add-a-custom-profile)。应用中尚无法编辑内置列表。
