每个 `.nc1` 文件描述一个构件编号。每行以 CR LF 结尾。文本字段仅使用纯 ASCII 字符，其他字符以 "?" 代替。第二行为注释：`** DetailCraft <mark>.nc1`。

## 文件头（ST）

| 字段 | 工字形、槽钢 | 角钢 | 矩形 HSS | 圆形 HSS | 钢板 |
|---|---|---|---|---|---|
| 订单 | 模型名称 | ← | ← | ← | ← |
| 图号、件号 | 构件编号 | ← | ← | ← | ← |
| 阶段 | 构件所在的阶段，或 1 | ← | ← | ← | ← |
| 钢材等级 | 材料牌号 | ← | ← | ← | ← |
| 数量 | 具有该编号的构件数 | ← | ← | ← | ← |
| 型材 | 型材名称，例如 W16x26 | ← | ← | ← | `PL<t>*<width>` |
| 型材代码 | I 或 U（槽钢） | L | M | RO | B |
| 长度 | 下料长度 | ← | ← | ← | 长度 |
| 高度 | 深度 d | 肢 | 高度 | 直径 | 钢板宽度 |
| 翼缘宽度 | bf | 肢 | 宽度 | 直径 | 0 |
| 翼缘厚度 | tf | t | 壁厚 t | 壁厚 t | 0 |
| 腹板厚度 | tw | t | 壁厚 t | 壁厚 t | 钢板厚度 |
| 半径 | 圆角半径（AISC 槽钢为 0） | 0 | 外角半径 | 0 | 0 |
| 每米重量 | kg/m | kg/m | kg/m | kg/m | kg/m² |
| 每米涂装面积 | 外周长，m²/m | ← | ← | ← | 2（两面，m²/m²） |
| 锯切角（4 个字段） | 0（直角） | ← | ← | ← | ← |
| 文本字段（4 个） | `-` | ← | ← | ← | ← |

钢板按标准中“钢板”一列执行。标准中没有圆管一栏：DetailCraft 将直径同时写入高度和翼缘宽度，并将壁厚同时写入两个厚度字段。

## 外轮廓（AK）

- **工字形和槽钢：** 腹板（v），每个切角处带矩形缺口；每个翼缘（o 和 u），若切角深度不小于翼缘宽度，则在该端缩短。
- **矩形 HSS：** 两侧壁（v 和 h），切角处开缺口；以及顶壁和底壁（o 和 u）。
- **角钢：** 每肢一个矩形（v 和 u）。角钢上的切角不写入：此类构件列为未写入。通过[节点板](topic:brace-gussets)用螺栓连接的角钢支撑，其孔位于被螺栓连接的肢上：沿构件 u 方向的肢为 v，沿构件 v 方向的肢为 u。
- **圆形 HSS：** 在 v 面上一个矩形，即从正面看到的管（长 × 直径）。
- **钢板：** 在面 v 上一个矩形。

每个轮廓都是闭合的（首点在末尾重复），并沿逆时针方向绘制。

## 孔（BO）

每个孔一行：面、x、y、直径、深度 0（贯通）。包括所有孔，既有手动输入的孔，也有连接生成的孔。穿过矩形 HSS 侧壁的孔会写入两次，一次在 v 面，一次在 h 面。

## 面和坐标

每个型材都按标准中型材位置图（DSTV 1998，第 7 页）的方式放置：x 沿构件方向，Y 横跨，Z 从背面向上，零点位于外角处。DetailCraft 从不为了符合图示而镜像构件。

| 面 | 工字形 | 槽钢 | 角钢 | 矩形 HSS | 钢板 |
|---|---|---|---|---|---|
| v | 腹板，正面 | 腹板，从翼缘外伸端一侧看 | 沿构件 u 方向的肢 | 位于 −u 的侧壁 | 钢板面 |
| h | | | | 位于 +u 的侧壁 | |
| o | 上翼缘 | **下**翼缘 | | 顶壁 | |
| u | 下翼缘 | **上**翼缘 | 沿构件 v 方向的肢 | 底壁 | |

- **x** 沿构件从其切割起点开始。
- **工字形和矩形 HSS：** 腹板或侧壁上的 y 从型材底面开始测量；翼缘、顶壁或底壁上的 y 从其背侧边缘（构件的 +u 侧）开始测量。
- **槽钢：** 槽钢按标准图示背放，外伸端朝上。因此腹板上的 y 从上翼缘外侧向下计算，上翼缘为面 u，下翼缘为面 o；翼缘上的 y 从腹板背面朝外伸端方向计算。
- **角钢：** 每肢上的 y 从肢根开始测量。
- **钢板：** y 从钢板的 −u 边缘开始测量。

切割前请检查机床软件如何读取槽钢的面：有些程序会把槽钢上下颠倒。

## 未写入的内容

坡口、内轮廓、标记（SI）、非直角的锯切角、长圆孔、圆管上的孔（DetailCraft 没有此类孔），以及角钢和圆管上的切角。
