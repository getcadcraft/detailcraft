## 学习内容

本文介绍如何让 AI 助手（或自行编写的脚本）与 DetailCraft 协同工作，以及如何决定其可以修改的内容。

DetailCraft **自身不含 AI**，也不会向任何地方发送内容。需自备助手：任何支持模型上下文协议（MCP）的程序均可。DetailCraft 只提供工具，开放哪些工具由用户选择。

## 开启

1. 打开{{ui:设置}}（应用栏中的齿轮，或{{key:Mod+,}}），进入{{ui:DetailCraft}}选项卡。
2. 在{{ui:助手}}下，勾选**允许 AI 助手和脚本使用 DetailCraft**。在勾选之前此功能处于关闭状态。
3. 选择其可执行的操作：**读取**默认已勾选；仅在需要时勾选**编辑**、**保存**或**导出**。

未勾选权限对应的工具不会提供给助手；如果助手仍然请求此类工具，DetailCraft 会拒绝并将其记录在活动日志中。关闭此开关会立即断开所有连接。

## 连接助手

助手通过本机的 **CadCraft Studio** 连接：Studio 运行一个仅本机可访问的小型服务器，并使用每次启动时生成的令牌进行保护。在 Studio 中，选择{{ui:连接助手}}，然后将地址和令牌复制到助手中（Studio 会显示需粘贴的具体设置）。切勿分享令牌。

:::note
浏览器标签页无法为助手建立连接：在浏览器版本中，此开关在使用本机的 CadCraft Studio 之前不起作用。
:::

## 始终由用户掌控

- **每项更改均为一步撤销**，并标注为助手所做（例如“助手：添加梁”“助手：添加节点板”）。{{key:Mod+Z}}会将助手的最近一次更改整体撤销。助手自身的 `undo` 仅撤销其自己的步骤，不会撤销用户的操作，除非其明确要求这样做。
- **它会等待用户操作。** 在放置构件、移动零件或粘贴时，DetailCraft 会拒绝助手的更改，并提示其稍后重试。
- **用户可以知道是否已连接。** 应用栏中的按钮会在助手连接时显示其名称；点击它可查看助手的权限，或**断开连接**。
- **活动。** 在{{ui:设置}}中依次进入{{ui:DetailCraft}}、{{ui:助手}}、{{ui:活动}}，可查看每次调用：时间、工具、已完成或被拒绝。{{ui:保存日志}}会保存一份副本。

## 助手可请求的操作

所有长度单位为毫米，点以 `[x, y, z]` 表示，z 轴向上，与模型中一致。

| 工具 | 权限 | 功能 |
|---|---|---|
| `app_info`, `model_describe` | 读取 | 当前打开模型的内容：轴网、标高、阶段、按类型和型材分类的构件、节点、基础、楼梯、零件、钢材重量、问题 |
| `parts_list` | 读取 | 零件编号及型材、材料、切割长度、数量、重量、阶段和装配体编号；可按类型、型材、编号或阶段筛选 |
| `problems_list` | 读取 | {{ui:问题}}选项卡中列出的内容，每项附带其说明 |
| `clash_check` | 读取 | [碰撞检查](topic:clash-check)，包括其容差和阶段 |
| `selection_get` | 读取 | 用户当前选中的内容 |
| `selection_set` | 编辑 | 选中构件、节点、基础或楼梯（按 id 或零件编号），以便向用户展示；不作任何更改 |
| `member_add` | 编辑 | 在两点之间添加梁、柱、支撑或板件 |
| `connection_add` | 编辑 | 在给定构件相交处添加端板、剪切连接板、底板、拼接或节点板，与{{ui:连接}}按钮的作用相同 |
| `undo` | 编辑 | 撤销助手的最近步骤 |
| `model_save` | 保存 | DetailCraft 自身的保存 |
| `model_export` | 导出 | IFC、NC 文件、BOM、钢筋弯曲表、KISS 文件或切割清单，与{{ui:输出}}按钮生成的内容相同 |
| `usd_export` | 导出 | 钢结构模型的 USD（.usda、.usdc 或 .usdz），与{{ui:输出}}中的{{ui:USD}}写出的内容相同（见[将钢结构模型导出为 USD](topic:usd)）；在 Studio 中可将文件写入用户允许的文件夹 |

## 如果无法正常工作

- **助手看不到 DetailCraft 工具：** 请检查此窗口中的开关是否已开启，以及该窗口是否在 Studio 中打开。
- **“需要编辑权限”**（或保存、导出）：请在{{ui:助手}}下勾选相应权限，然后重新请求。
- **“用户正在放置构件”：** 请完成当前操作（或按{{key:Esc}}），然后让助手重试。
- **“401”或“token”错误：** 令牌已更改（Studio 重新启动，或点击了{{ui:新令牌}}）。请将新令牌复制到助手的设置中。
