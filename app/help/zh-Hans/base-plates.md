底板连接在柱下设置一块钢板，将柱子截短钢板厚度，两者焊接在一起，并在钢板上的孔中加设四根锚栓。

:::warning
尺寸仅为初始值，不是设计结果。DetailCraft 不校核承压、锚栓强度或埋深。
:::

## 添加底板

1. 使用{{ui:选择}}（{{key:V}}），点击一根柱子。柱子必须竖直。
2. 在{{ui:连接}}组中选择{{ui:底板}}，或在{{ui:特性}}面板中选择{{ui:添加底板}}。
3. 状态栏显示“已添加带四根锚栓的底板。”新建的连接处于选中状态。

一根柱子只能有一块底板。若已有底板，状态栏显示“该柱已有底板。”

## 修改底板

选中底板（点击钢板或锚栓）。在{{ui:钢板、螺栓和焊缝（mm）}}下：

| 设置 | 默认值 | 作用 |
|---|---|---|
| 钢板厚度 | 25 | 柱子按此长度截短 |
| 钢板长度 | 450 | 沿柱截面深度方向 |
| 钢板宽度 | 400 | 沿柱宽方向 |
| 锚栓直径 | 20 | 锚栓规格 |
| 孔径 | 33 | 钢板上的孔 |
| 螺栓等级 | F1554 Gr 36 | 锚栓等级（文字） |
| 锚栓间距（沿截面深度） | 350 | 锚栓中心之间的距离，沿钢板长度方向 |
| 锚栓间距（横向） | 300 | 锚栓中心之间的距离，横向 |
| 锚栓伸出钢板高度 | 100 | 从钢板顶面到锚栓顶端 |
| 锚栓埋入深度 | 450 | 从钢板底面向下伸入混凝土 |
| 角焊缝尺寸 | 8 | 柱脚周边焊缝 |
| 钢板材料 | A36 | 文字 |
| 灌浆间隙 | 0 | 混凝土顶面与钢板底面之间的间距 |
| 加劲肋 | 无 | 选择无、2（与腹板共线）或 4（另外还与腹板垂直）；见下文 |
| 加劲肋厚度、高度 | 12, 150 | |
| 抗剪键深度 | 0 | 抗剪键伸到钢板下方的距离；0 = 无抗剪键 |
| 抗剪键厚度、宽度 | 25, 150 | |
| 垫板 | 无 | 每根锚栓均设置，或不设置 |
| 垫板尺寸、厚度 | 0, 0 | 0 = 按 AISC Design Guide 1 取该锚栓的最小垫板 |

锚栓长度 = 埋入深度 + 灌浆间隙 + 钢板厚度 + 伸出高度。按默认值计算为 575 mm。

## 底板细部：灌浆、加劲肋、抗剪键、垫板

以上四项在新建底板上均为关闭状态，DetailCraft 0.4 之前版本模型中的底板也是如此。

- **灌浆间隙。** 钢板位于混凝土顶面以上此距离，锚栓相应加长。AISC Design Guide 1（2.10）建议：楼面完成面上取 1 in.，独立基础或墩上取 1½ 至 2 in.；大型钢板及带抗剪键的钢板应取更大值。
- **加劲肋。** 竖向板件，与柱和钢板焊接，从柱面伸至钢板边缘，为矩形（尚不支持切角或锥形）。**2** 与腹板共线，位于各翼缘外侧；**4** 另外在腹板两侧、翼缘之间各增加一块与腹板垂直的加劲肋，伸至钢板两侧。在钢管柱上，加劲肋位于每个面的中部。每块加劲肋两侧均与柱和钢板焊接。
- **抗剪键。** 焊接在底板下方的板件，四周施焊，沿柱截面深度方向居中布置。若其深度不大于灌浆间隙，DetailCraft 会发出警告。它不会在基础中开出凹槽，因此[碰撞检查](topic:clash-check)会将抗剪键与基础排除在外。
- **垫板。** 每根锚栓上设一块方形垫板，置于底板上，并在柱的部件中列为散件（随柱发运，不焊接；见 Design Guide 1，2.6）。尺寸和厚度为 0 时，DetailCraft 按 AISC Design Guide 1 第 2 版表 2.3 取该锚栓的最小垫板；公制锚栓取上一档英制尺寸（M20 锚栓取 7/8 in. 一行：2½ in. × 5/16 in.）。特性面板会显示所用尺寸。垫板孔径 = 锚栓直径 + 1/16 in.，这是 DetailCraft 的选择，表中未给出。当锚栓伸出长度不足以容纳垫板与螺母（伸出长度小于垫板厚度 + 锚栓直径）时，DetailCraft 会发出警告。

表 2.3 同时给出了钢板上锚栓孔的建议：¾ in. 锚栓为 1-5/16 in.，⅞ in. 为 1-9/16 in.，1 in. 为 1-13/16 in.。DetailCraft 不会更改你设定的孔径。

当锚栓孔距钢板边缘小于 1.2 × 孔径、锚栓位于柱轮廓以内，或钢板小于柱截面时，同样会出现警告。

## 复制到相似的柱

1. 选中底板。
2. 选择{{ui:应用到相似 (n)}}，或在{{ui:连接}}组的{{ui:更多}}菜单中选择{{ui:相同节点}}。
3. 凡截面相同、没有底板且不支承在其他柱上的竖直柱，都会获得一份副本。

## 底板与基础

底板不需要基础，基础也不“知道”其上方的底板：锚栓不与基础钢筋绑扎。使用{{ui:基础}}放置基础；见[放置带钢筋的基础](topic:footings-and-rebar)。
