大多数拒绝操作的原因会显示在屏幕底部的状态栏中，或{{ui:问题}}选项卡中。请先查看这些信息。以下消息按 DetailCraft 的显示原样引用。

## 3D 视图缺失

**“此浏览器无法启动 3D 图形（WebGL）。模型、报告和导出仍可使用。”**

浏览器无法启动 DetailCraft 用于绘制 3D 图形的 WebGL。

1. 将浏览器更新至最新版本。
2. 开启硬件加速并重新启动浏览器（见下文）。
3. 更新显卡驱动程序，或尝试其他浏览器。远程桌面和虚拟机通常不支持 WebGL。
4. 在此期间仍可继续工作：可使用{{ui:按轴线添加}}表单放置构件、查看报告并导出。只有在视图中点击操作才需要 WebGL。

:::chromium
要开启硬件加速，请在**设置**中打开**系统**，启用**在可用时使用图形加速**，然后重新启动浏览器。
:::

:::firefox
要开启硬件加速，请在**设置**中打开**常规**下的**性能**，取消勾选**使用推荐的性能设置**，并勾选**在可用时使用硬件加速**。重新启动 Firefox。
:::

:::safari
Safari 默认启用 WebGL。如果视图仍无法启动，请更新 macOS，并检查是否有扩展程序阻止了它。
:::

更多信息见[浏览器与计算机](common:browsers)。

## 点击视图无反应

- **点击附近没有交点。** 放置工具只会吸附到轴网交点。在所有圆点之外点击无效。请靠近，直到圆点亮起。
- **当前工具为{{ui:选择}}，且点击了空白处。** 这会清除选择。
- **发生了拖动。** 按下与松开之间的位移超过几个像素即视为拖动：这会旋转或平移视图。
- **构件被剖切遮挡。** 在{{ui:平面}}和{{ui:立面}}中，剖切范围之外的钢构件会被隐藏，无法点击。请切换到{{ui:3D}}。
- **交点位于错误的标高。** 在{{ui:3D}}中，多个标高的交点可能在屏幕上重叠；点击时会选中最近的那个。请使用{{ui:平面}}或{{ui:立面}}。

## 放置消息

| 消息 | 处理方法 |
|---|---|
| 柱子无法到达 Level 2 以上，因为上方没有标高。请先添加标高。 | 在{{ui:标高}}中添加标高，或点击较低的标高 |
| 请为另一端选择不同的交点。 | 两次点击了同一点 |
| 两端为同一点。 | 在{{ui:按轴线添加}}中，“起点”和“终点”选择的是同一点 |
| 请在左侧添加轴线以放置构件。 | 模型在某个方向上没有轴线 |
| 未知型材“…” | 该型材不在型材库或模型的自定义型材中。请从列表中选择 |
| 请输入数字。 | 数字输入框为空或包含文字 |

## 节点无法生成

### “此梁未止于柱线。”

端板要求梁端恰好位于竖向柱的轴线上，且位于柱底与柱顶之间（误差 1 mm 以内）。请检查梁的{{ui:端点（x、y、z mm）}}和柱的位置。

### “此梁与柱腹板相交，或成一定角度”

或在{{ui:问题}}中显示：“与柱腹板相交的梁尚未实现：请将柱旋转 90° 或使用其他节点。”

梁与柱腹板相交。选中柱，将{{ui:旋转（°）}}设为 90，然后重试。斜交节点尚未实现。

### “端板仅适用于水平梁（此梁倾斜）。”

梁两端必须处于相同高度。

### “端板要求梁直立（旋转为 0）。”

将梁的{{ui:旋转（°）}}设回 0。

### “端板要求工字形梁。” / “端板要求工字形柱。”

只有工字形（W、IPE、HEA、HEB 或自定义工字形）可使用端板。

### “梁端已不在柱线上。”

在添加节点后移动了梁或柱。请将其移回，或删除该节点。

### “节点将此构件切割至长度为零。”

两端的节点切除的长度超过了构件自身长度，例如两根较深的柱之间的一根很短的梁。请检查构件端部和板厚。

### “没有其他未设置节点的类似节点……”

{{ui:相同节点}}仅复制到梁型材、柱型材和节点类型相同、且尚无节点的节点，即梁连接到翼缘的节点。

### “两端已有节点。” / “此柱已有底板。”

选中现有节点进行修改，或先将其删除。

## 问题选项卡中的警告

警告不会阻止节点或基础的生成，仅提示需要检查。边距和间距的警告采用 EN 1993-1-8 表 3.3 的最小值（边距为 1.2 × 孔径，间距为 2.2 × 孔径，线距为 2.4 × 孔径）。如果项目采用其他规则，该警告可能不适用；DetailCraft 不对节点进行设计。

“孔位于构件端部之外”表示孔的 x 小于 0，或大于切割长度。请注意 x 从切割起点算起，即节点切除构件端部之后。

## 基础修改被拒绝

| 消息 | 处理方法 |
|---|---|
| 此基础中保护层留出的空间不足以放置钢筋。 | 加大基础或减小保护层 |
| 基础深度不足以在保护层内容纳两层钢筋。 | 加深基础或减小保护层 |
| 插筋在 75 mm 保护层内无法放入基础。 | 减少插筋数量、缩小间距，或加大基础 |
| 钢筋间距必须为 50–1000 mm。 | 输入该范围内的间距 |
| 长度必须为 300–50000 mm。 | 基础尺寸有限制：长度和宽度为 300 至 50000，深度为 150 至 10000 |

## 轴网和标高被拒绝

| 消息 | 处理方法 |
|---|---|
| 编号轴网：每对轴线之间须给出一个间距（4）。 | 数一数间隔：五条轴线需要四个间距 |
| 字母轴网：间距必须为正的毫米数。 | 不能为零、负数或文字 |
| 编号轴网：轴网编号不能重复。 | 两条轴线的编号相同 |
| 每个方向最多 60 条轴线。 | 请拆分模型 |
| 至少保留一个标高。 | 已删除所有标高行 |
| 每个标高都需要名称。/ 两个标高名为“…”。 | 为每个标高指定不同的名称 |

## 打开文件失败

| 消息 | 原因 |
|---|---|
| DetailCraft 只能打开其自身的模型（.detailcraft.json）。IFC 导入尚未实现。 | 文件不是 `.json` 文件 |
| 这不是 DetailCraft 模型（不是 JSON）。 | 文件已损坏，或是其他 JSON 文件 |
| 这不是 DetailCraft 模型。 | 来自其他程序的 JSON 文件 |
| 此模型由更新版本的 DetailCraft（格式 2）保存。 | 请用保存它的更新版 DetailCraft 打开 |
| 该文件过大，不能作为 DetailCraft 模型。 | 超过 50 MB |

当文件打开时出现警告，例如“2 个构件无效，已被剔除。”，模型的其余部分正常。在检查被剔除的内容之前，请勿覆盖原文件。

## 导出

| 消息 | 原因 |
|---|---|
| 尚无可导出内容。 | 模型为空时使用{{ui:IFC}} |
| 没有可写入 NC 文件的工字形或板件零件。 | 模型中只有槽钢、角钢或管材 |
| 未写入（目前仅支持工字形和板件）：… | 这些编号的构件不是工字形或板件；其余已写入 |
| 没有基础，因此没有可统计的钢筋。 | 在没有基础时使用{{ui:钢筋弯曲}} |
| … 个字符超出 PDF 字体范围，已以“?”打印。 | 模型名称或等级中包含 PDF 字体缺少的字符 |

{{ui:加工详图}}呈灰色不可用：模型中尚无零件。

## 下载未出现

每次保存和导出都是浏览器下载。请检查浏览器的下载列表。如果浏览器在下载多个文件前询问，或阻止来自本站的下载，请允许。在 Safari 中，请查看工具栏上的下载按钮。

## 按键无效

- 光标位于文本或数字输入框中：此时工具快捷键和{{key:Delete}}会被忽略，以便输入。按{{key:Tab}}或点击视图即可。
- 对话框已打开：请先关闭。
- 浏览器占用了键盘（例如地址栏）：请点击 DetailCraft 内部。
- {{key:Ctrl+Shift+F}} 在 Mac 上也使用 Control 键。

## 离线问题

应用栏中的{{ui:保存以供离线使用}}按钮显示离线副本的状态。保存方式见[离线工作](common:offline)。

| 按钮显示 | 含义 | 处理方法 |
|---|---|---|
| {{ui:保存以供离线使用}} | 此浏览器中尚无离线副本 | 在联网时选择 |
| 正在保存 5 / 20 | 正在保存 | 等待显示{{ui:离线可用}}；保持标签页打开 |
| {{ui:离线可用}} | DetailCraft、其 3D 视图、所有导出以及本帮助在无连接时均可使用 | 无需操作。点击可选择{{ui:重新保存（获取最新版本）}}或{{ui:移除离线副本}} |
| {{ui:无法保存}} | 部分文件未能下载 | 检查网络连接，然后点击重试 |
| {{ui:无法离线使用}} | 此窗口无法保存离线副本：隐私窗口和部分受管理的计算机会阻止该功能 | 使用普通窗口，或在线工作 |

若处于离线状态且按钮未显示{{ui:离线可用}}，请勿重新加载或关闭标签页：已加载的内容仍可继续使用。使用{{key:Mod+S}}保存模型，待恢复联网后再继续。

## 未保存的工作

如果浏览器询问是否离开页面，说明 DetailCraft 有未保存的更改。请选择留在页面，然后按{{key:Mod+S}}。关闭标签页后，DetailCraft 无法恢复模型。

## 仍未解决

请记录操作步骤和完整消息，并通过[支持页面](https://getcadcraft.com/support)告知我们。
