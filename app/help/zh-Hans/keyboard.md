本帮助中按键的写法见：[按键、鼠标和触控板](common:keys)。在 Mac 上，{{key:Mod}} 为 Command 键；其他系统上为 Ctrl。

## 工具

这些快捷键在光标不在文本或数字输入框中时生效。

| 按键 | 作用 |
|---|---|
| {{key:V}} | {{ui:选择}} |
| {{key:B}} | {{ui:梁}} |
| {{key:C}} | {{ui:柱}} |
| {{key:R}} | {{ui:支撑}} |
| {{key:P}} | {{ui:钢板}} |
| {{key:F}} | {{ui:基础}} |
| {{key:S}} | {{ui:楼梯}} |
| {{key:M}} | 通过选取两个轴线交点来移动所选内容（[按窗口选择、移动、旋转、镜像和批量修改](topic:select-and-change)） |
| {{key:Esc}} | 放弃正在拖动的选择窗口，或将拖动的构件放回原位；取消移动、梁、支撑或钢板的第一个点，或取消粘贴；再按一次则返回{{ui:选择}}；在{{ui:选择}}中，清除选择。若{{ui:更多}}菜单已打开，则将其关闭 |
| {{key:Delete}} 或 {{key:Backspace}} | 删除所选内容（所选的全部对象，计为一步撤销） |

## 文件和编辑

| 按键 | 作用 |
|---|---|
| {{key:Mod+S}} | 保存模型（下载）。即使正在输入框中输入也有效 |
| {{key:Mod+O}} | 打开模型。即使正在输入框中输入也有效 |
| {{key:Mod+Z}} | 撤销（在文本框外有效；在文本框内则撤销你的输入） |
| {{key:Mod+Y}} 或 {{key:Mod+Shift+Z}} | 重做 |

## 复制和粘贴

这些快捷键在光标不在文本或数字输入框中时生效（在输入框中，它们会像平常一样复制、粘贴和选择文字）。每次粘贴、剪切、创建副本或删除都计为一步撤销。更多内容：[复制、粘贴和创建副本](topic:copy-paste)。

| 按键 | 作用 |
|---|---|
| {{key:Mod+C}} | {{ui:复制}}所选的构件和基础（连同其孔洞、切角和连接） |
| {{key:Mod+X}} | {{ui:剪切}}：复制所选内容，然后将其删除 |
| {{key:Mod+V}} | {{ui:粘贴}}：副本跟随指针；点击一个轴线交点即可放置 |
| {{key:Mod+Shift+V}} | {{ui:原位粘贴}}：粘贴到复制时的坐标处 |
| {{key:Mod+D}} | {{ui:创建副本}}：立即创建副本，并按 [DetailCraft 设置](topic:settings) 中的偏移量移动 |
| {{key:Mod+A}} | {{ui:全选}}：所有构件、连接和基础 |
| {{key:Esc}} | {{ui:取消选择}} |

如果你在页面上选中了文字（例如报表表格中的文字），而模型中没有选中任何内容，则 {{key:Mod+C}} 会像平常一样复制文字。

{{ui:新建}}、{{ui:示例}}和各类导出没有快捷键；请使用工具栏。

若有对话框（加工详图预览或询问框）处于打开状态，这些快捷键均不起作用。

## 输入框和面板

| 按键 | 作用 |
|---|---|
| {{key:Enter}} 或 {{key:Tab}} | 应用输入的值（每次更改计为一步撤销） |
| 在 {{ui:轴网}}、{{ui:标高}}、{{ui:自定义截面}}、孔洞或切角输入框中按 {{key:Enter}} | 与选择该表单的按钮相同 |
| {{key:Left}} {{key:Right}} | 当某个标签页获得焦点时，在{{ui:问题}}、{{ui:材料清单}}和{{ui:钢筋表}}标签页之间切换 |
| {{key:Esc}} | 关闭加工详图预览或询问对话框（与{{ui:取消}}相同） |

## 鼠标

| 操作 | 在 3D 中 | 在平面和立面中 |
|---|---|---|
| 单击 | 选择构件；若放置工具已开启，则在最近的交点处放置（粘贴时则粘贴到该处） | 相同 |
| {{key:Shift}}、{{key:Ctrl}} 或 {{key:Mod}} 并单击 | 将构件加入选择，或将其移出选择 | 相同 |
| 在已选构件上按下并拖动 | 在楼层之间移动所选内容；按住 {{key:Mod}} 时可上下移动 | 移动所选内容（在立面中：沿立面方向并上下移动） |
| 用左键拖动 | 旋转模型 | 使用{{ui:选择}}时：拖出选择窗口（向右：完全位于窗口内；向左：与窗口接触）。放置时：平移 |
| {{key:Shift}} 并用左键拖动 | 使用{{ui:选择}}时：拖出选择窗口，并加入选择。放置时：平移 | 使用{{ui:选择}}时：拖出选择窗口，并加入选择 |
| {{key:Ctrl}} 或 {{key:Mod}} 并用左键拖动 | 平移 | 无 |
| 用右键拖动 | 平移 | 平移 |
| 滚轮 | 朝视图中心缩放 | 缩放 |
| 用中键拖动 | 缩放 | 使用{{ui:选择}}时：平移。否则：缩放 |
| 将 `.detailcraft.json` 文件拖放到应用上 | 打开该文件 | 打开该文件 |

仅当按下与松开之间指针移动不超过约 5 像素时，才计为一次单击；移动距离更长则视为拖动。

## 触控板

| 操作 | 作用 |
|---|---|
| 双指上下滑动或捏合 | 缩放 |
| 按下并拖动 | 旋转（3D）或平移（平面和立面） |
| {{key:Shift}} 并按下拖动 | 在 3D 中平移 |
| 双指点击 | 右键单击（视图中没有菜单） |

## 触摸

在平板或触摸屏上：

| 操作 | 作用 |
|---|---|
| 点按 | 选择构件；若放置工具已开启，则在最近的轴线交点处放置（点按距离手指约一个指宽以内的交点也有效） |
| 长按构件 | 将其加入选择，或移出选择（相当于鼠标的 {{key:Shift}}+单击） |
| 一个手指按在已选构件上，然后拖动 | 移动所选内容，并吸附到轴线交点 |
| 一个手指按在其他位置 | 旋转模型（3D）或平移（平面和立面） |
| 两个手指 | 捏合缩放，同时移动则平移 |

在仅使用触摸的屏幕上，按钮、列表和输入框会更大。选择窗口需要鼠标；使用手指时，请点按和长按。

## 浏览器保留的快捷键

某些快捷键属于浏览器，任何页面都无法使用，例如 {{key:Mod+W}}（关闭标签页）、{{key:Mod+T}}（新建标签页）和 {{key:Mod+N}}（新建窗口）。如果 {{key:Mod+Y}} 打开的是浏览器历史记录而不是重做，请改用 {{key:Mod+Shift+Z}}。

只有当页面获得键盘焦点时，快捷键才会传给 DetailCraft。如果某个按键没有反应，或被浏览器响应，请先点击 DetailCraft 窗口中一块空白的构件区域（例如在地址栏中输入之后）。

## 移动命令的位置

没有移动命令：选择构件并将其拖动到楼层之间（按住 {{key:Mod}} 可上下拖动），或在{{ui:特性}}中编辑其{{ui:起点}}和{{ui:终点}}。
