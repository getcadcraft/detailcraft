DetailCraft 是早期版本。本页列出它尚未实现的功能，以便提前规划。以下内容均不承诺任何上线日期。

## 建模

| 尚未实现 | 目前的替代做法 |
|---|---|
| 拖动构件的一端（拉伸构件） | 在{{ui:特性}}面板的{{ui:端点（x、y、z mm）}}下编辑{{ui:起点}}或{{ui:终点}} |
| 选择过滤器（仅梁、仅某一型材） | 框选，然后按住{{key:Shift}}并单击，将部分构件移出选择 |
| 阵列选择对象；绕倾斜轴旋转；在倾斜平面中镜像 | 偏移复制并粘贴，或使用{{ui:创建副本}}；旋转和镜像在平面中可用（[框选、移动、旋转、镜像及批量修改](topic:select-and-change)） |
| 单击时点不在网格上 | 将点放在网格上，然后输入终点坐标 |
| 沿编号轴线的立面；已保存的视图；工作平面 | 使用{{ui:3D}}，或使用{{ui:按轴线添加}} |
| 三维视图中以真实切口显示的孔 | 孔以深色塞子显示；在所有导出中均为真实的孔 |
| 圆角或斜切的切角、其他切割和配件 | 仅支持工字形上的直角切角 |
| 为角钢和圆管添加孔 | 角钢孔仅由[支撑节点板](topic:brace-gussets)生成 |
| 英制输入 | 输入毫米（每英寸 25.4 mm） |
| 编辑或删除自定义截面 | 添加一个修正后的截面，并使用新名称 |

## 楼梯

| 尚未实现 | 目前的替代做法 |
|---|---|
| 扶手、休息平台、踢脚板、格栅踏面、螺旋楼梯和双跑楼梯 | 仅支持直跑楼梯；参见[楼梯](topic:stairs) |
| 楼板处的斜梁端部切割 | 直角切割斜梁；在车间软件中切割 |

## 连接

DetailCraft 可建立六种连接：支撑节点板（参见[支撑节点板](topic:brace-gussets)）；同一工字形两段之间的螺栓拼接（参见[拼接](topic:splices)）；两根以一定角度相交的工字形之间的斜接，可仅切割，也可带螺栓端板（参见[斜接节点](topic:mitres)）；由水平、竖向工字形梁连接到工字形柱翼缘或腹板的平齐或加长螺栓端板；梁（方形、斜交或倾斜）连接到柱翼缘或腹板的剪力板；以及带四根锚栓的柱底板。

| 尚未实现 | 目前的替代做法 |
|---|---|
| 斜交或倾斜的端板 | 使用[剪力板](topic:shear-tabs)，它支持斜交和倾斜的梁 |
| 连接角钢；拼接填板，以及不同尺寸之间的拼接；焊接于梁和柱上的角部节点板、切角节点板 | 在其他软件中细化，或将板和孔作为独立构件手动添加；参见[拼接](topic:splices)、[支撑节点板](topic:brace-gussets) |
| 削角或锥形的底板加劲肋；灌浆孔；剪力键的基础凹槽 | 矩形加劲肋；参见[柱底板](topic:base-plates) |
| 腋托；带对接焊的焊接斜接；与另一构件翼缘不对齐的加劲肋 | 带端板和腹板加劲肋的[斜接节点](topic:mitres)，或普通斜切；其他板件可作为独立构件手动添加 |
| 连接设计校核（强度） | 用工程师的计算校核连接；DetailCraft 仅对边距和间距发出警告 |
| 长圆孔 | 仅圆孔 |

## 分析

| 尚未实现 | 目前的替代做法 |
|---|---|
| 钢工字形以外的设计校核：管材、角钢、槽钢、焊接截面、细长或第 4 类构件、扭转、连接；混凝土：侧移细长比、扭转、抗震构造、楼板和墙 | {{ui:分析}}选项卡按 AISC 360 或 EN 1993-1-1 校核钢工字形（[按设计规范校核钢构件](topic:design-checks)）；其余内容标记为“未校核”；所有结果均需工程师审核 |
| 屈曲分析、振动 | 二阶分析仅为 P-Delta（弹性）；无屈曲分析（模态、反应谱、时程和推覆分析位于{{ui:分析}}选项卡中） |
| 工程师已审核的设计校核 | 在此之前它们仅作为辅助参考：依赖结果前，请手算或用工程师自己的软件校核两三根构件 |
| 按面积自动生成的楼面、风和雪荷载 | 按 kN/m 或 kN 手动施加于构件上 |
| 框架中的构件偏心、偏心节点、仅受拉的支撑、钢板和基础 | 构件按其工作线分析；支撑承受拉力和压力 |

## 钢筋

| 尚未实现 | 目前的替代做法 |
|---|---|
| 圆柱、螺旋箍筋、倾斜或弯曲的梁、非矩形楼板、非直线墙 | 矩形梁、柱、楼板和墙（[钢筋混凝土细化](topic:reinforced-concrete)） |
| 弯折后搭接的钢筋、错开搭接、在任意指定位置设置的搭接 | 等间距搭接，所有钢筋在同一截面搭接（ACI Class B，EN α6 = 1.5） |
| 洞口处的角部钢筋、冲切抗剪钢筋、抗震构造（ACI 318-19 第 18 章） | 洞口每侧的加强筋；其余部分需自行核查 |
| 读取结构设计程序自身的文件 | 从该程序导出 IFC：其中的 IfcReinforcingBar 将作为钢筋导入（[来自 IFC 文件的钢筋](topic:reinforced-concrete#bars-from-an-ifc-file)） |
| 超出直筋、单弯和 U 形之外的形状代码；ACI 315 中直筋和单钩筋以外的类型 | 三种形状分别以 BS 8666 00、11、21 或 ACI Type 2 输出；参见[钢筋参考](topic:rebar-reference) |
| 除 BS 4449 H8–H40 外的公制钢筋（例如 CSA 10M–35M） | ASTM 软公制名称 #10–#36，或 BS 钢筋 |

## 图纸与导出

| 尚未实现 | 目前的替代做法 |
|---|---|
| 竖向图纸、A0 以及自定义尺寸的图纸；斜交轴网上的总布置视图 | 横向 A4至A1 以及 ANSI B至D（[总布置图和装配图](topic:drawings)）；如需以其他尺寸打印，请缩放 PDF |
| 在应用内编辑图纸 | 修改模型后重新生成图纸；可在 MarkupCraft 等 PDF 应用中批注 PDF |
| 带标注对象的 DWG 图纸，或在模型空间以全尺寸显示模型、图纸作为布局 | 每张图纸为全尺寸的 DWG 或 DXF，尺寸以线条和数字表示（[总布置图和装配图](topic:drawings#download)） |
| NC 文件中的圆管孔、角钢和圆管上的切角 | 未写入；参见[NC文件字段](topic:nc1-fields) |
| NC 文件中的坡口、标记和内轮廓 | 目前没有替代做法 |
| USD 导出中的螺栓孔、螺栓、焊缝和基础 | 它们包含在 IFC、NC 和材料清单输出中；参见[将钢结构模型导出为 USD](topic:usd) |
| 从 IFC 文件导入连接、基础、长圆孔或矩形孔以及圆管孔 | {{ui:导入IFC}}可导入梁、柱、构件、钢板、轴网、标高、圆孔、切角、螺栓和钢筋，其报告会列出未导入的内容 |
| 自定义报告布局 | 三个 CSV 文件 |

## 协作与保存

| 尚未实现 | 目前的替代做法 |
|---|---|
| 计算机之间的云保存与同步 | 保存 `.detailcraft.json` 文件，并像其他文件一样共享。云保存暂不可用 |
| Live TeamWork 会话中他人的光标和“正在编辑”标签；网格、标高和阶段逐项合并 | 修改仍会合并（网格、标高和阶段整体替换，后一次修改生效）；参见[实时协作共同细化一个结构](topic:work-live) |
| 通过互联网访问 Live TeamWork 会话的邀请链接 | 在同一网络中使用短代码加入 |

## 平台

- DetailCraft 面向台式机、笔记本和平板电脑屏幕设计。它也可在手机上使用：模型保留屏幕，面板和报告以浮层形式从底部栏打开，但面板的空间很小。
- 离线使用前需先在应用栏中使用{{ui:保存以供离线使用}}，将 DetailCraft 保存为离线可用；显示{{ui:离线可用}}后，本版本中的所有功能均可在无连接状态下使用。参见[离线使用](common:offline)。

如果其中某项限制妨碍了工作，请通过[支持页面](https://getcadcraft.com/support)告诉我们；这有助于我们决定下一步开发什么。
