视图有三种模式，可在其上方的视图栏中选择：{{ui:3D}}、{{ui:平面}}和{{ui:立面}}。鼠标按键在 3D 中与在平面和立面中的作用不同，请阅读两张表格。

## 在 3D 中

:::mouse
| 目的 | 操作 |
|---|---|
| 绕模型旋转 | 用左键拖动 |
| 平移 | 用右键拖动，或按住 {{key:Shift}} 并用左键拖动 |
| 缩放 | 转动滚轮，或按住中键（按下滚轮）上下拖动 |
| 选择构件 | 点击它（移动距离很小的点击） |
| 查看整个模型 | 视图栏右端的{{ui:适合}}按钮 |
:::

:::touch
| 目的 | 操作 |
|---|---|
| 绕模型旋转 | 用一根手指拖动 |
| 平移 | 用两根手指拖动 |
| 缩放 | 用两根手指捏合 |
| 选择构件 | 点按它 |
| 查看整个模型 | 视图栏右端的{{ui:适合}}按钮 |
:::

位于右上角（视图栏下方）的视图立方体会随模型一起转动：点击某个面、边或角即可从该方向观察，拖动可旋转，或点击其主页按钮返回初始视图。参见[视图立方体](topic:view-cube)。

模型围绕视图中心旋转，滚轮则朝视图中心缩放，而不是朝指针方向。要仔细查看某个角，请先将其平移到视图中心，然后再缩放。

## 在平面和立面中

这些视图正对模型，无法旋转。

:::mouse
| 目的 | 操作 |
|---|---|
| 平移 | 用左键或右键拖动 |
| 缩放 | 转动滚轮，或按住中键上下拖动 |
| 选择构件 | 点击它 |
:::

:::touch
| 目的 | 操作 |
|---|---|
| 平移 | 用一根手指拖动 |
| 缩放 | 用两根手指捏合（拖动两根手指也可平移） |
| 选择构件 | 点按它 |
:::

## 在 Mac 触控板上

:::mac
- **缩放：** 用两根手指上下滑动，或捏合。两者都会以缩放的方式传递到视图。
- **旋转 (3D)：** 按下触控板并用一根手指拖动。如果你使用轻触点击，只要在**系统设置、辅助功能、指针控制、触控板选项**中开启了拖移，双击并拖动也可使用。
- **平移 (3D)：** 按住 {{key:Shift}} 并拖动。按住 {{key:Ctrl}} 或 {{key:Mod}} 拖动同样可以平移。双指点击为右键单击，但在触控板上配合拖动比较别扭。
- **平移（平面和立面）：** 直接拖动即可。
- Magic Mouse 没有中键：请使用 {{key:Shift}} 拖动来平移，并在其表面滑动来缩放。
:::

有关不使用鼠标时的右键和平移，参见：[按键、鼠标和触控板](common:keys)。

## 平面和立面让放置更容易

在 {{ui:3D}} 中，不同楼层的交点在屏幕上可能重叠，点击会选中最近的点。在{{ui:平面}}和{{ui:立面}}中，只能选取你所看的楼层或轴线上的点。

1. 选择{{ui:平面}}，然后在按钮旁边的列表中选择一个楼层。视图将俯视该楼层；高出该楼层1.5 m以上的部分将被剪除。
2. 或选择{{ui:立面}}，然后选择一条字母轴线（"A轴"、"B轴" …）。视图将正对该轴线；仅显示距其1 m以内的钢构件。

立面仅能位于字母轴线上。若要处理一组数字轴线（从A至B的框架），请使用 {{ui:3D}}，或在{{ui:按轴线添加}}表单中通过输入进行放置。参见[放置柱、梁和支撑](topic:place-members#place-by-grid-without-clicking)。

## 选择

- 点击构件即可选中。其高亮颜色会改变，并且{{ui:特性}}面板会显示该构件。
- 点击空白处，或按 {{key:Esc}}，可清除选择。
- 钢构件优先于混凝土：在透明基础内点击柱子，会选中柱子。若要选中基础，请在远离柱子的位置点击基础，或点击其钢筋。
- 点击螺栓或端板会选中其连接。
- 在平面和立面中，被剪除的构件无法被点击。
- 按住 {{key:Shift}}（或 {{key:Ctrl}}，或 {{key:Mod}}）并点击，可将构件加入选择或移出选择；{{key:Mod+A}} 选择全部。尚未实现窗口（拖框）选择。多选后可进行的操作见：[复制、粘贴和创建副本](topic:copy-paste)。

也可以从列表中选择：点击左侧{{ui:零件编号}}中的编号、{{ui:材料清单}}标签页中的构件编号，或{{ui:问题}}中某一行旁边的{{ui:选择}}。

## 视图显示异常时

- 模型不见了？选择{{ui:适合}}按钮。
- 视图为空白或灰色，并显示有关 WebGL 的消息：参见[故障排除](topic:troubleshooting#the-3d-view-is-missing)。
- 没有 3D 视图时，除了在视图中点击之外，其他功能仍然正常：面板、报告和导出都可运行，并且{{ui:按轴线添加}}可通过输入来放置构件。
