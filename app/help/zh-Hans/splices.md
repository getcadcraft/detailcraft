螺栓拼接用于将同一工字形截面的两段端对端连接：每个翼缘外侧各有一块盖板，腹板两侧各有一块拼接板，螺栓穿过两段构件将其固定。DetailCraft 会将两段构件切割至间隙尺寸，放置四块拼接板，在拼接板和两段构件上钻孔，添加螺栓，并对边距、间距和配合情况发出警告。

## 适用范围

- 两根梁，或两段柱节段，截面为**同一工字形型材**，端对端且在同一直线上相接：端部间距不超过 50 mm，两段构件平行且位于同一直线上（误差 1 mm 以内）。两段构件的绘制方向不限。
- 水平、倾斜或竖直的构件均可。
- 深度或翼缘宽度不同的两段构件会被拒绝，槽钢、角钢和管材同样不可用。

## 添加拼接

1. 绘制两段构件，使其端对端相接。若要拆分已绘制的构件，请将其重新绘制为两段。
2. 选中其中一段（或两段），在{{ui:连接}}组的{{ui:更多}}菜单中选择{{ui:拼接}}。
3. 所选构件的每个与同一型材其他构件相接的自由节点都会生成拼接。状态栏会显示数量。

选中拼接（点击其任一拼接板）后，可在右侧面板中修改其设置。{{ui:应用到相同节点 (n)}}会将其复制到同一型材构件之间的每个其他自由节点。

## 设置（mm）

| 设置项 | 默认值 | 作用 |
|---|---|---|
| 端部间隙 | 10 | 每段构件各切去一半 |
| 螺栓直径、孔径、等级、长度余量 | 20, 22, A325, 30 | 同端板 |
| 翼缘板厚度 | 12 | 板宽与翼缘相同 |
| 翼缘螺栓行数（每侧） | 3 | 节点两侧每侧翼缘上的螺栓行数 |
| 翼缘螺栓间距 | 75 | 沿构件方向 |
| 翼缘螺栓线距 | 0 | 两条螺栓线之间的距离；0 = 翼缘宽度减 80 |
| 翼缘端距 | 40 | 构件端部至第一颗螺栓，以及最后一颗螺栓至板端 |
| 腹板板厚度 | 8 | 腹板两侧各一块 |
| 腹板螺栓行数 | 3 | 沿腹板向上，居中布置 |
| 腹板螺栓列数（每侧） | 2 | 节点两侧，沿构件方向 |
| 腹板螺栓间距（沿腹板 / 沿构件） | 75, 75 | |
| 腹板端距 | 40 | 同翼缘 |
| 腹板板高 | 0 | 0 = 圆角之间的净腹板高度减去上下各 10 |
| 板材材料 | A36 | 文本 |

板长由螺栓决定：翼缘板 = 间隙 + 2 ×（2 × 端距 +（行数 − 1）× 间距）；腹板板的长度同理，按其列数计算。按默认值，翼缘板长 470。

## 注意事项

- 拼接板归属于两段构件中**先绘制**的那一段（其属性中称为“第一段”）：它们显示在该段的装配图中，并随该段一同发运，采用螺栓连接而非焊接。第二段的装配图仅显示其孔位。
- 翼缘螺栓夹紧翼缘及其拼接板；腹板螺栓夹紧腹板及两块腹板板。螺栓长度单独列在属性中。
- 警告采用与其他节点相同的 EN 1993-1-8 最小值（端距和边距为 1.2 × 孔径，沿构件方向间距为 2.2 × 孔径，线距为 2.4 × 孔径），另外还包括：腹板板高超过腹板净高，以及翼缘螺栓离腹板过近而与圆角冲突。
- DetailCraft 不对拼接进行设计（不做强度校核），也不会为厚度不同的构件制作填充板。
- 同时复制两段构件会一并复制其拼接；删除任一段都会删除拼接。
