本主题介绍矩形独立基础。梁、柱、楼板和墙见[钢筋混凝土详图](topic:reinforced-concrete)。每个基础在两个方向都设有底部钢筋网，如需要，还可设置向上伸出的插筋。钢筋规格为美国制 #3 至 #11。

## 放置基础

1. 选择{{ui:平面}}，并拾取基础顶面所在的标高。
2. 在{{ui:放置}}组中选择{{ui:基础}}，或按{{key:F}}。
3. 在{{ui:特性}}面板中设置基础（见下文），或保留默认值。
4. 点击一个轴网交点，基础以该点为中心放置，顶面位于标高处。状态栏会显示例如“基础 2000 x 2000 x 600，位于 A/1 下方。”

也可以使用面板底部的{{ui:按轴线添加}}表单。

基础以透明方式绘制，便于查看其中的钢筋；钢筋以实心管状显示。

## 基础设置

| 字段 | 默认值 | 说明 |
|---|---|---|
| 长度 L（mm） | 2000 | 沿x方向；300至50000 |
| 宽度 B（mm） | 2000 | 沿y方向；300至50000 |
| 深度 H（mm） | 600 | 150至10000 |
| 混凝土 | 4000 psi | 文本，导出IFC时会写入 |

**底部钢筋网**

| 字段 | 默认值 | 说明 |
|---|---|---|
| 长向钢筋 | #5 | 沿 L 方向的钢筋，位于下层 |
| 间距（mm） | 250 | 允许的最大间距；钢筋按此间距或更小间距均匀布置 |
| 短向钢筋 | #5 | 沿 B 方向的钢筋，铺设在长向钢筋上方 |
| 间距（mm） | 250 | 同上 |
| 保护层（mm） | 75 | 各面的净保护层 |
| 端部弯钩 | 开 | 将每根网片钢筋两端弯成标准90°弯钩（形状 U）；关闭则为直筋（形状 S） |

**插筋**

| 字段 | 默认值 | 说明 |
|---|---|---|
| 插筋 | 开 | 不需要插筋的基础请关闭 |
| 钢筋 | #6 | |
| 沿L方向根数 / 沿B方向根数 | 2 / 2 | 钢筋呈网格布置，以基础中心对称 |
| 沿L方向间距 / 沿B方向间距 | 250 / 250 | 钢筋中心之间的距离 |
| 顶面以上伸出长度 | 600 | 钢筋伸出基础顶面的高度 |
| 底部弯钩 | 开 | 90°弯钩向外，支承在钢筋网上（形状 L） |

字段下方，DetailCraft 会显示长向钢筋的弯钩段长度，例如“#5 弯钩段：外皮至外皮 254 mm。”

## 修改已放置的基础

选择基础（点击远离柱的混凝土部分，或点击其中一根钢筋）。此时会显示相同的字段，另外还有{{ui:中心x}}、{{ui:中心y}}、{{ui:顶面z}}和{{ui:旋转（°）}}。其下方的表格列出该基础的钢筋，包括编号、根数和长度，以及混凝土体积（立方米）。

每项修改在保留前都会进行检查。无法施工的修改会被拒绝，状态栏会说明原因，例如“保护层不足，基础内无法容纳钢筋。”、“基础高度不足以在保护层内布置两层钢筋。”或“插筋在 75 mm 保护层下无法放入基础内。”

可以施工但需要复核的修改会列在基础下方以及{{ui:问题}}选项卡中：

- “#11 钢筋间距 59.6 mm，净距小于 35.8 mm（ACI 318-19 25.2.1）。” 钢筋之间的净距至少应为钢筋直径，且不小于 25.4 mm。
- “#5 弯钩需要 254 mm 的高度，保护层内只有 150 mm。” 此时弯钩段会被截短以适应，因此不再是标准弯钩。
- “插筋弯钩侵入保护层。”
- “插筋间距小于最小净间距。”

## 钢筋编号与钢筋表

尺寸、形状和各尺寸（精确到毫米）均相同的钢筋，在所有基础中共用同一钢筋编号。编号格式为`<钢筋号>F<n>`：#5 钢筋为 5F1、5F2，第一根 #6 钢筋为 6F1，依此类推。尺寸、混凝土、钢筋网和插筋均相同的基础共用同一基础编号：F1、F2……

1. 打开底部的{{ui:钢筋表}}选项卡。每行为一个钢筋编号：规格、形状、尺寸 A、B 和 C、根数、下料长度、总长度、每米质量、单根重量、总重量，以及钢筋用途。
2. 在该选项卡中选择{{ui:下载CSV}}，或在{{ui:输出}}组的{{ui:更多}}菜单中选择{{ui:钢筋弯曲}}，将得到`<name> bending schedule.csv`。

形状代码为 DetailCraft 自定义，并非任何标准的代码：S 为直筋，L 为单弯，U 为双弯。尺寸为外皮至外皮；下料长度为经过弯折处的准确中心线长度。参见[钢筋参考](topic:rebar-reference)。

## DetailCraft 不检查的内容

- 锚固长度和搭接长度，以及插筋是否足够长以伸入上方的柱。
- 净间距规则中与骨料粒径有关的部分（DetailCraft 不了解混凝土配合比）。
- 上方柱或底板的一切内容：基础与钢结构是分开处理的。
