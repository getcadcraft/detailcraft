如果使用 Tekla Structures 进行深化设计，DetailCraft 的大部分内容都会很熟悉：轴网、标高、目录中的型材、零件与装配体、连接、编号、NC 文件、IFC。两者规模差异很大：Tekla Structures 是完整的生产系统，而 DetailCraft 是一款小型、早期的浏览器应用，可端到端完成少数几项任务。本页说明哪些习惯可以延续，哪些则不能。

:::tip
如果已习惯 Tekla Structures 的功能区，可在{{ui:设置}} › {{ui:DetailCraft}} › {{ui:菜单、按键和鼠标}}中选择{{ui:钢结构功能区}}菜单样式：可使用建模、深化、编辑、图纸、加工和视图选项卡，并且鼠标中键用于平移。如果来自 AutoCAD 并习惯输入命令，则{{ui:经典绘图}}会添加命令行（BEAM、COLUMN、ENDPLATE、ZOOM …）。参见[菜单、按键和鼠标](topic:menus-keys-and-mouse)。
:::

## 快速对照

| 习惯的做法 | 在 DetailCraft 中 |
|---|---|
| 通过轴网对话框以坐标创建轴网 | 左侧面板中的{{ui:轴网}}：通过编号和线间距定义，而非绝对坐标。编号轴线沿一个方向，字母轴线沿另一方向 |
| 以轴网 Z 坐标表示标高 | 独立的{{ui:标高}}列表，每行设置名称和标高，并通过{{ui:应用标高}}应用 |
| 使用捕捉在任意位置拾取点 | 点击仅捕捉到轴网交点。非轴网点需在杆件的{{ui:端点（x、y、z mm）}}中输入 |
| 柱、梁和钢板命令 | {{ui:柱}}({{key:C}})、{{ui:梁}}({{key:B}})、{{ui:支撑}}({{key:R}})、{{ui:钢板}}({{key:P}})、{{ui:基础}}({{key:F}}) |
| 构件属性对话框（双击构件） | 单击即可：右侧的{{ui:特性}}面板始终处于激活状态；没有对话框，也没有“修改”或“应用”按钮 |
| 平面位置、旋转和深度设置 | {{ui:位置}}（钢顶面、居中或底部对齐轴线）和{{ui:旋转（°）}}。没有单独的水平偏移 |
| 型材目录 | 固定列表，包含 2,311 种已公布的截面规格（AISC W、S、C、L、HSS、Pipe；欧洲 IPE、HEA、HEB、UPN；英国 UB、UC、PFC、EA、UEA、SHS、RHS、CHS 及冷弯空心型材），另有参数化钢板，以及自定义的{{ui:自定义截面}}截面 |
| 材料目录 | 列表中共七个等级：A992、A36、A572 Gr 50、A500 Gr C、S235、S275、S355 |
| 应用连接构件及其对话框 | 选择梁，然后选择{{ui:端板}}。设置显示在{{ui:特性}}面板中。仅有两种连接：端板连接至柱翼缘，以及底板 |
| 自动连接，或将节点复制到相似节点 | 选择一个连接，然后选择{{ui:应用到相似项 (n)}} |
| 使用序列和起始编号进行编号 | 无专用命令：每次修改后编号自动更新，前缀固定为 c、b、br、p 及 C、B、BR、P |
| 螺栓和孔洞对话框 | 孔洞按面和位置输入。螺栓只能由连接生成 |
| 切割、配合和多边形切割工具 | 切角（上方或下方，任一端）仅适用于工字形型材。连接处的截短自动完成 |
| 报告和模板 | 底部选项卡中有三份固定报告，以及 CSV 下载 |
| 图纸创建与图纸列表 | 每个零件编号生成一张加工详图，一次性全部生成，预览后可下载为一个 PDF 或逐张下载。不保存也不编辑任何内容 |
| NC 文件导出 | {{ui:NC文件}}：每个零件编号生成一个 DSTV 文件，仅限工字形型材和钢板，并打包为 zip |
| IFC 导出 | {{ui:IFC}}：整个模型的 IFC4，包含钢筋 |
| 任何混凝土构件中的钢筋 | 钢筋仅用于矩形独立基础，采用美制钢筋规格，并包括底部网片和插筋 |
| 模型保存在项目文件夹中，支持多用户 | 下载一个 `.detailcraft.json` 文件。单用户，保存在本地计算机上 |
| 撤销历史 | {{key:Mod+Z}}和{{key:Mod+Y}}，最多 200 步，直至打开或新建另一个模型前均保留 |

## 容易出错的差异

### 编号会自动变化

没有编号步骤。每次修改后都会重新计算编号，因此编号始终为最新，但也可能重新编号：添加一根柱后，原来的 c3 可能变为 c4。没有可以保留旧编号的“编号历史”。完成模型后，请从同一个已保存的文件中一并输出材料清单（BOM）、NC 文件和加工详图。

### 鼠标中键用于缩放，而非平移

在三维视图中：左键拖动旋转，右键拖动平移，滚轮缩放，按住鼠标中键拖动同样缩放。按住{{key:Shift}}并左键拖动也可平移。滚轮朝视图中央缩放，而非朝向指针。没有旋转中心拾取功能：模型绕视图中央旋转。参见[在三维视图中移动](topic:navigate-3d)。

### 柱默认朝向固定

旋转角度为 0 时，柱的翼缘沿编号轴网方向。在字母轴线之间布置的梁会连接到腹板上，此处的端板会被拒绝（“梁连接至柱腹板的情况尚未实现”）。添加连接之前，请将这些柱旋转 90°。

### 立面仅沿字母轴线

{{ui:立面}}仅沿字母轴线观察。没有沿编号轴线的视图、没有已保存的视图，也没有工作平面。对于位于编号轴线上的框架，请使用{{ui:3D}}或{{ui:按轴线添加}}。

### 选择、复制和移动

使用{{key:Shift}}+点击或{{key:Mod+A}}选择多个构件，然后对其进行复制、剪切、粘贴（粘贴到轴网交点、按输入的偏移量粘贴，或原位粘贴）以及创建副本，连接一并包括（[复制、粘贴和创建副本](topic:copy-paste)）。没有窗口选择、没有选择过滤器，也没有移动、镜像或阵列；属性需在{{ui:特性}}面板中逐个构件修改。

### 修改轴网不会带动构件

修改轴网间距时，构件保持其坐标不变；构件不会随轴线移动。请在布置钢结构之前修改轴网，或之后逐个编辑各构件的端点坐标。

### 连接不做设计

两种连接根据所输入的数值布置钢板、孔洞、螺栓和焊缝。没有任何设计校核，仅提供边距和间距警告（依据 EN 1993-1-8 表 3.3）。

### 三维视图中不切割孔洞

孔洞以深色塞子显示。它们在 NC 文件、加工详图和 IFC 文件中为真实孔洞。切角则在视图中切割。

### 重量为毛重

钢材重量未扣除孔洞或切角，也不包括螺栓重量。

### 仅使用毫米

所有数值均以毫米输入和显示，即使是 AISC 型材也是如此。型材名称保留其公布的形式（W12x50、HSS6x6x1/4）。

### 无需管理图纸

没有图纸列表，没有图纸编辑器，也没有总布置图或装配图。加工详图在需要时生成并下载；如需修改，请修改模型后重新生成。

### 在浏览器中运行

保存即下载文件。浏览器自身保留的键盘快捷键无法使用。模型不会离开计算机：参见[文件去向](common:your-files)。

## 在现有软件中继续进行的工作

目前 DetailCraft 适用于小型框架、验证设计思路、教学，或为简单的梁柱工程生成 NC 文件和加工详图。复杂连接、总布置图、安装图、多用户项目，以及[尚未实现的功能](topic:not-built-yet)中列出的所有内容，请继续在现有软件中完成。
