DetailCraft 会自动为模型编号。没有编号命令，也无需运行任何操作：每次修改后，它都会判断哪些零件属于同一根钢件，并为其赋予同一个编号。

## 编号显示位置

- {{ui:模型}}面板中的{{ui:零件编号}}列表：每个编号及其截面、长度和数量。点击某一编号可选中具有该编号的第一个零件。
- 选中构件后，其{{ui:特性}}面板（以及左侧面板中的**零件编号**列表）：{{ui:构件编号}}和{{ui:部件}}。面板标题也会显示编号，例如“梁 b1”。
- {{ui:材料清单}}选项卡、CSV、NC 文件名、加工详图以及 IFC 导出（作为每个构件的标记）。

## 编号规则

- **构件编号：** 柱为 c，梁为 b，支撑为 br，楼梯斜梁为 st，钢板（包括端板和底板）为 p。其后为序号：c1、c2、b1、p1……当零件位于多个阶段时，阶段号置于最前，例如 2-b1。
- **部件编号：** C、B、BR 或 P。部件是主构件及其焊接的钢板，例如带两块端板的梁，或带底板的柱。
- 当两个零件的截面、材料、下料长度以及孔和切角均相同（误差在 1 mm 以内）时，二者共用同一编号，即使其中一个相对另一个调转了两端或上下颠倒。
- 编号顺序为先柱、后梁、支撑和钢板；每类之内，先按截面名称排序，再按由长到短排序。

完整规则，包括槽钢和角钢的哪些调转视为相同，见[编号规则](topic:mark-rules)。

:::warning
每次修改后编号都会重新计算，因此可能重新排号。添加零件、更改截面或添加孔，都可能使 b3 变为 b4。只有在模型完成后才应将编号视为最终结果，并且材料清单、NC 文件和加工详图应基于同一个已保存的模型生成。
:::

## 阅读材料清单

打开底部的{{ui:材料清单}}选项卡，其中包含三张表。

**零件**，标题中给出钢材总重量：

| 列 | 含义 |
|---|---|
| 构件编号 | 点击可选中具有该编号的第一个零件 |
| 类型 | 梁、柱、支撑、斜梁或钢板 |
| 截面 | 例如 W16x26 或 PL20x180 |
| 材料 | 你设定的等级 |
| 长度（mm） | 下料长度，连接处理之后 |
| 数量 | 数量 |
| 单位重量（kg） | 每米截面质量 × 长度 |
| 总重量（kg） | 单位重量 × 数量 |

最后一行给出总数量和总重量。

**部件**：每个部件编号、其主构件、所有组成零件（例如“b1 + p1 + p1”）、数量、单位重量和总重量。

**螺栓和锚栓**：按类型、直径、长度和等级分组，并给出数量。

:::note
重量为毛重：未扣除孔和切角。螺栓、螺母、垫圈和焊缝均不计入钢材重量。
:::

## 下载

在选项卡中选择{{ui:下载CSV}}，或在{{ui:输出}}组中选择{{ui:BOM}}。文件 `<name> BOM.csv` 依次包含三张表，每张表下有其标题，表与表之间空一行。可在任何电子表格程序中打开。

## 发送前检查

1. 打开{{ui:问题}}选项卡，逐条处理所有项。无法建造的连接不会添加钢板、孔或螺栓，因此材料清单会短缺。
2. 检查是否有意外的编号。若你认为相同的两根梁编号不同，通常是孔、切角或下料长度有差异；分别选中并进行比较。
3. 保存模型，然后基于已保存的状态进行所有导出。
