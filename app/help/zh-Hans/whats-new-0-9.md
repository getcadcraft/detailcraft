这是 DetailCraft 0.9 相较于 0.8.1 的变化。0.9 带来英国钢材规格、一次性生成所有构件的加工详图、更大的框架 {{ui:分析}} 选项卡，以及多人协作时查看彼此光标的功能。

## 新增

### 英国钢材与加工详图

- **英国钢材规格。** 型材列表现包含 Steel for Life Blue Book 中的 976 种规格：UB、UC、PFC、EA、UEA、CHS、SHS 和 RHS，冷弯空心型材单独列出（名称以 CF 开头）。名称按型材系列在前书写，例如 UB305x165x40 或 SHS100x100x5.0；按图纸习惯输入也可识别，例如 305x165x40 UB、L100x100x10、SHS100x5。参见[型材目录](topic:profile-catalog)。
- **不等边角钢。** UEA 角钢在 IFC 导入导出和 NC 文件中均保留两条肢，镜像会将构件首尾调换。
- **一次生成所有加工详图。** 在未选择任何对象时，于 {{ui:输出}} 组中选择 {{ui:加工详图}}。窗口会列出所有构件编号，可预览任一编号，{{ui:全部下载}} 会将所有图纸保存为一个 PDF，每个编号一页，标题为“第 3 张，共 42 张”这样的形式。{{ui:下载PDF}} 保存当前所看的那一张。槽钢、角钢和空心型材现在也会生成图纸。参见[生成加工详图](topic:shop-drawings)。
- **我的配置文件。** 自定义截面现在可以保存，供每个新模型使用。在自定义截面表单中保持勾选 {{ui:保存到我的配置文件}}；其下方的 {{ui:我的配置文件}} 列表提供 {{ui:保留}}、{{ui:在此使用}} 和 {{ui:移除}}。该列表保存在当前浏览器中（最多 200 项），而不保存在你的账户中。参见[板件与型材](topic:plates-and-profiles)。

### 分析

- **二阶效应（P-Delta）。** 在 {{ui:分析}} 选项卡中，于运行按钮旁勾选 {{ui:二阶效应（P-Delta）}}，轴力将作用于变形后的框架。板件和刚性楼板仍按一阶计算，并会给出警告。参见[内力、反力和变形](topic:frame-analysis)。
- **固有频率。** 结果下方的 {{ui:有限元：固有频率}} 块会求出同一模型的最低阶振型，给出周期和有效模态质量，并在模型上显示某一振型。参见[内力、反力和变形](topic:frame-analysis)。
- **风荷载与地震场地。** {{ui:分析}} 选项卡中新增三个块：{{ui:风荷载（ASCE 7 方向性方法）}}、{{ui:地震场地与体系（ASCE 7）}} 和 {{ui:ASCE 7 荷载组合}}。参见[风荷载、地震场地与 ASCE 7 组合](topic:wind-seismic-combinations)。

### 协同工作

- **光标与名称。** 在 Live 会话中，每位参与者的指针会以其名称和颜色显示在模型中，其所选对象会显示一个框。
- **跟随参与者。** 在会话中打开 {{ui:参与者}}，在某个名称上选择 {{ui:跟随}}，你的视图就会随其移动。主持人可以选择 {{ui:让所有人跟随我}}。参见[在 Live 会话中跟随参与者](topic:follow-in-live)。

### 所有应用

- 工具提示采用 Bootstrap 工具提示样式，开始提示卡带有关闭按钮，选项卡栏放不下时可横向滚动，浏览器标签页名称显示当前打开的文档，后接 DetailCraft 和 CadCraft。

## 修复

- 开始新模型时，自定义截面会丢失。
- 加工详图图纸集中缺少槽钢、角钢和空心型材。

## 已知限制

- 风荷载、地震和有限元块都是校核辅助工具。结果需由工程师审核；它们不是规范校核。USGS 查询是在替代服务上测试的，并未在正式服务上测试。
- 有限元和 P-Delta 已与手算及闭合解对比验证，未用实际建筑验证。尚未实现屈曲分析。
- 尚无英国加工厂试用英国规格；不等边角钢的 NC 文件尚未在机器上运行。
- 加工详图集仅支持 PDF。
- 英语以外的语言均为机器草稿。
- Windows 安装程序未进行代码签名（点击“更多信息”，然后“仍要运行”）；macOS 磁盘映像未经公证（右键单击，然后选择“打开”）。

更早的变更记录在本页下方的 0.8 和 0.8.1 说明中。

## 更早版本：0.8 和 0.8.1

这是 DetailCraft 0.8（2026年11月1日）和 0.8.1（2026年11月2日）相较于 0.7 的变化。0.7 校核钢构件；0.8 规划吊装、提出连接方案、校核基础和钢筋，并为木结构和轻钢墙体、楼板和屋面进行框架设计。

### 新增

**吊装**

- **吊装方案与动画。** 在 {{ui:吊装}} 选项卡中，描述起重机（所在位置、最高吊钩高度、起重性能表中未包含的吊索具），并输入其起重性能表的各行数据。DetailCraft 会按阶段顺序、逐层吊装模型中的一个组件，并依据起重性能表在相应幅度下校核每次吊装，同时检查你设定的裕量。{{ui:保存动画}} 会生成一个 HTML 文件，可离线在任何浏览器中播放，手机上也可以。超出起重性能表、超出幅度或过高的吊装会列在 {{ui:问题}} 中。这是基于你所给数值的方案，而不是吊装方案。参见[吊装方案与动画](topic:erection-movie)。

**连接**

- **连接自动生成。** {{ui:自动连接}} 选项卡会检查每个没有连接的节点，并根据截面形状提出连接方案：柱脚底板、剪切板、为你标记为弯矩梁的梁提供的端板、拼接板和节点板。给定均布荷载或一端剪力后，螺栓数量将依据螺栓的设计强度确定。{{ui:全部添加}} 会将所有方案作为一次撤销步骤添加。这些方案是供审核的起始值，而非连接设计。
- **可施工性校核。** {{ui:问题}} 中会列出扳手无法触及的螺栓、套筒装不下的过近螺栓、超出焊脚尺寸限值的角焊缝，以及会积水的空心型材。焊接操作空间为新增项：若焊枪无法触及某条周边角焊缝，将列出妨碍的构件以及受影响的焊缝比例。参见[可施工性校核](topic:constructability)。

**基础与钢筋**

- **基础校核。** {{ui:基础}} 选项卡依据你所描述的地基校核独立基础、联合基础和筏板：正常使用荷载下的承载力、滑移和倾覆；设计荷载下的弯曲、受剪、冲切、锚固长度和最小配筋（ACI 318-19）。靠近边缘或角部的柱，将按基础边缘截去的截面进行校核。沉降由地基模量得出；柔性筏板依据基床系数在弹簧上求解；桩群和挡土墙有各自的计算面板。柱荷载可以手动输入，也可取自 {{ui:分析}}。参见[基础校核](topic:foundation-checks)。
- **钢筋拥挤度图。** {{ui:拥挤度}} 选项卡从上方俯视绘制每个基础的热力图，显示钢筋在何处使混凝土难以下落，并对照净间距规定；若你提供了最大骨料粒径和振捣器头尺寸，还会一并考虑。参见[钢筋拥挤度图](topic:rebar-congestion)。

**框架与供货**

- **木结构与轻钢框架。** {{ui:框架}} 选项卡对墙板、楼板和屋面板进行框架设计，给出每一构件、切割清单、需采购的材料，以及按比例绘制的加工详图。{{ui:作为杆件放置}} 会将各构件放入模型，{{ui:PDF 图纸}} 为每块面板保存一张图纸。截面尺寸、间距和过梁均由你确定：DetailCraft 不校核其能否承载荷载。参见[木结构与轻钢框架面板](topic:framing-panels)。
- **供应商库存与交货期。** {{ui:供货}} 选项卡读取供应商的库存清单（CSV），并针对切割清单中需采购的每种截面，显示库存是否充足以及等待时间。缺料和延迟的截面列在 {{ui:问题}} 中。不会下订单。参见[供应商库存与交货期](topic:supplier-stock)。

**分析与设计**

- **先失效的是什么？** 在 {{ui:分析}} 选项卡中，该按钮会找出起控制作用的强度组合、最薄弱的构件，以及荷载可增大到多少时第一根构件达到其限值；若已知螺栓的抗剪强度，还会找出最薄弱的端板或剪切板。它需要先生成组合并选定设计规范。承压、块状剪切、焊缝和撬力尚未校核。连接的 AI 助手也可以提出同样的问题。
- **实时。** 勾选 {{ui:实时：每次编辑后重新求解}}，每次编辑后框架都会重新求解。
- **混凝土等。** 非侧移框架中的细长柱，按其放大弯矩进行设计（ACI 318-19 6.6.4.5）。抗震周期可用 Rayleigh 法从分析结果中取得。由板组成的楼板，会依据各层弯矩求得所需钢筋，并校核单向受剪。参见[混凝土构件校核与地震荷载生成](topic:concrete-and-seismic)。
- **供工程师审核。** 基础、混凝土和“先失效的是什么？”的结果都是辅助工具。风荷载尚未实现。

**所有应用**

- **语言。** 帮助文档提供 54 种语言。英语以外的语言均为机器草稿，待母语人士审阅；其中 10 种为新增（立陶宛语、拉脱维亚语、波斯尼亚语、马拉地语、泰卢固语、阿尔巴尼亚语、南非荷兰语、菲律宾语、斯瓦希里语、乌兹别克语）。
- **工具栏行数。** {{ui:设置}} › {{ui:常规}} › {{ui:工具栏行数}} 可选择换行、2 行或 1 行。已能容纳的工具栏保持不变，其余的可横向滚动。
- **属性网格。** 基础的字段使用共享网格：可折叠的类别和紧凑的密度。键入的算式（如 2*450）仍然有效。
- **输入设备。** 触控板、手写笔、3D 鼠标、手柄和 MIDI 均可操作应用。参见[在 3D 中导航](topic:navigate-3d)。
- **问题面板。** 上述新校核的警告与之前一样显示在同一个 {{ui:问题}} 面板中。
- **连接 AI 助手。** 你自己的助手可通过 CadCraft Studio 连接，适用于全部八个应用，并且只能看到你允许的内容。一键连接、托管连接器以及在 Studio 中使用自有 API 密钥仍在开发中。参见[在 AI 助手中使用 DetailCraft](topic:use-with-ai-assistants)。

### 0.8.1 修复

- **Studio 中的语言。** Studio 和打包版本可以在运行时切换语言；此前仅支持英语。尚未在所有平台上测试：如果语言没有切换，请告知我们。
- **交叉窗口选择。** 0.8.1 安装程序已包含 0.8 网页版中正确的窗口选择行为；较早的安装程序没有。
- **竖屏平板。** 多余的网格高度分配给画布，图纸布局在 760 px 或更小时启用。

### 本版本尚未包含

- **将 NC 发送到机器** 尚未发布。
- **混凝土的风荷载** 尚未实现，混凝土和基础校核需由工程师审核。
- **代码签名。** Windows 安装程序和 macOS .dmg 未签名，因此 Windows 可能会发出警告，macOS 需要右键单击，然后选择“打开”。
