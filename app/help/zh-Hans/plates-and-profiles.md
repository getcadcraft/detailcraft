## 放置钢板

钢板的放置方式与梁相同：它位于两个交点之间，宽度沿水平方向，厚度沿竖直方向。

1. 在{{ui:放置}}组中选择{{ui:钢板}}，或按{{key:P}}。
2. 在{{ui:特性}}面板中设置{{ui:厚度（mm）}}和{{ui:宽度（mm）}}。默认值为 A36 材质的 20 x 200。
3. 如有需要，设置{{ui:材料}}和{{ui:旋转（°）}}。旋转 90 可使钢板竖立。
4. 单击两个交点，或使用{{ui:按轴线添加}}表单。

钢板的型材名称写作 `PL<thickness>x<width>`，例如 PL20x200。其长度为两点之间的距离。

要调整已放置钢板的尺寸，请选中它并修改{{ui:厚度（mm）}}或{{ui:宽度（mm）}}。

手动放置的钢板为独立构件（构件编号 p，装配编号 P）。连接生成的端板和底板也是钢板，但需通过其所属的连接进行修改；参见[端板](topic:end-plates)。

## 添加自定义截面

目录中没有所需截面时，可根据其尺寸创建。自定义截面属于模型，并随模型一起保存。若要在每个新模型中使用它，请将其保存到{{ui:我的配置文件}}中，见下文“为新模型保留截面”。

1. 在左侧{{ui:模型}}面板中，打开{{ui:自定义截面}}。
2. 输入{{ui:名称}}，例如 `W8x18-custom` 或 `RHS 120x80x5`。该名称不能与目录名称相同，也不能与钢板名称相似。
3. 选择{{ui:形状}}：{{ui:工字形}}、{{ui:槽钢}}、{{ui:等边角钢}}、{{ui:矩形钢管}}、{{ui:圆钢管}}或{{ui:扁钢}}。
4. 填写出现的尺寸，单位均为毫米：

| 形状 | 尺寸 |
|---|---|
| 工字形 | 深度 d、翼缘宽度 bf、腹板 tw、翼缘 tf、圆角半径 r（可为 0） |
| 槽钢 | 深度 d、翼缘宽度 bf、腹板 tw、翼缘 tf（直角） |
| 等边角钢 | 肢宽 b（每肢）、厚度 t |
| 矩形钢管 | 高度 h、宽度 b、厚度 t（外角半径 2t） |
| 圆钢管 | 直径 D、厚度 t |
| 扁钢 | 宽度 b、厚度 t |

5. 保持{{ui:在我的配置文件中保留}}勾选，使其出现在每个新模型中（见下文）；取消勾选则仅保留在本模型中。
6. 选择{{ui:添加截面}}。

状态栏会显示“已添加截面 "…"；它位于所有截面列表的“自定义”下。”它会出现在表单下方的列表中，以及每个{{ui:截面}}列表的末尾。

DetailCraft 会检查截面是否可行，并可能显示如下消息：“腹板和翼缘超出了深度和宽度范围。”“圆角半径对翼缘而言过大。”或“壁厚过大。”修正数值后，再次选择{{ui:添加截面}}。

### 自定义截面的特性

- 每米质量 = 面积 × 7850 kg/m³（目录截面使用公布的重量）。
- 自定义工字形可像目录工字形一样开孔、切角、添加端板，并生成 NC 文件和加工详图。
- 自定义扁钢的行为与钢板相同。
- 自定义槽钢和管材可以开孔；角钢和圆管暂不支持。

添加后，无法在模型中编辑或删除自定义截面（若操作有误，立即使用{{key:Mod+Z}}即可撤销）。修正后的截面请使用新名称。

## 为新模型保留截面

{{ui:我的配置文件}}位于表单下方，是您个人的自定义截面列表。它保存在本浏览器中，即本台计算机上，而不在模型文件中，也不在账户中。

- 勾选{{ui:在我的配置文件中保留}}添加的截面会进入列表。每个新模型（包括启动 DetailCraft 时打开的模型）的截面列表中都会包含这些截面。
- 已在模型中但不在列表中的截面，旁边有{{ui:保留}}按钮。
- 在不含某个自定义截面的模型中（例如旧文件），选择{{ui:在此使用}}即可将其添加到该模型中。
- {{ui:移除}}会将截面从列表中删除。已使用该截面的模型会保留其自身的副本。
- 打开的模型会保留其文件中保存的截面。打开文件不会改变列表。
- 若列表中已有同名但尺寸不同的截面，新截面会被拒绝：请另取名称。
- 清除浏览器的网站数据，或使用其他浏览器或计算机，都会从空列表开始。无痕窗口无法保留该列表；应用会对此作出提示。
