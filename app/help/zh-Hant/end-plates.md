端板連接是將板焊接於梁端，並以螺栓鎖至柱翼緣或腹板。DetailCraft 會配置端板、將梁切除至適當長度、在端板與柱翼緣上鑽出對應的孔、加入螺栓與焊接，並檢查邊距與間距。

:::warning
DetailCraft 不設計連接。設定值僅為起始值，可自行變更；不會檢核強度。邊距與間距警告採用 EN 1993-1-8 表 3.3 的最小值，這可能與所依循的規則不同。
:::

## 可連接的對象

- **水平**梁（兩端高度相同），直立（旋轉為 0），斷面為 I 形。
- 連入**垂直** I 形柱的**翼緣**或**腹板**，且與柱正交。
- 梁端必須位於柱的軸線上，介於柱底與柱頂之間。

斜交或傾斜的梁以及非 I 形斷面會被拒絕並附上原因：這些情況請使用[剪力板](topic:shear-tabs)。在腹板上，板與梁翼緣必須能容納於柱翼緣之間；若不能，DetailCraft 會發出警告。

:::tip
在旋轉為 0 時，柱的翼緣面向編號格線方向（x）。由 A 至 B 的梁會接合於腹板，並在腹板上取得端板。
:::

## 為梁加入端板

1. 選擇 {{ui:選取}}（{{key:V}}），然後點選梁。
2. 在 {{ui:連接}} 群組中選擇 {{ui:端板}}，或在 {{ui:屬性}} 面板中選擇 {{ui:新增端板}}。
3. 梁上每個與柱翼緣或腹板正交相接的自由端都會獲得一塊板。狀態列會顯示「已新增 2 個端板。選取其中一個以變更其板、螺栓與焊接；相似會將其複製到相似的接頭。」
4. 第一個新端板會被選取，其設定會顯示於 {{ui:屬性}} 面板中。

若沒有任何反應，請閱讀狀態列：

- 「此梁未終止於柱軸線上。端板會配置於梁端與垂直柱相接之處。」
- 「此梁與柱以角度相交或傾斜：端板僅適用於正交、水平的接頭。請使用剪力板。」
- 「兩端已有連接。」

## 變更板、螺栓與焊接

點選端板（或其中一顆螺栓）以選取連接。在 {{ui:板、螺栓與焊縫（mm）}} 下：

| 設定 | 預設 | 作用 |
|---|---|---|
| 板厚 | 20 | 板的厚度；也是梁在翼緣之外被切除的距離 |
| 板寬 | 180 | 橫跨接頭的寬度 |
| 梁上方延伸 | 0 | 超出上翼緣的長度；大於 0 即成為延伸端板 |
| 梁下方延伸 | 0 | 超出下翼緣的長度 |
| 螺栓直徑 | 20 | 公稱螺栓尺寸 |
| 孔徑 | 22 | 板與柱翼緣上的餘隙孔 |
| 螺栓等級 | A325 | 文字；列印於材料表中 |
| 螺栓列數 | 4 | 每列兩顆螺栓，以板高居中 |
| 列距 | 75 | 各列之間的垂直間距 |
| 栓距 | 100 | 同列兩顆螺栓之間的水平間距 |
| 螺栓長度餘量 | 30 | 加於握持長度上，供螺帽、墊圈與螺紋使用；見下文 |
| 角焊尺寸 | 8 | 梁端四周全周 |
| 板材料 | A36 | 文字 |

輸入新值後按 {{key:Enter}} 或 {{key:Tab}}。板、孔、螺栓與梁的切割長度會立即更新。每次變更為一個復原步驟。

設定下方會顯示連接所產生的內容：

- {{ui:螺栓}}：例如「8 × 20 × 70 A325（握持 36.2）」。
- {{ui:焊縫}}：尺寸、位置與其長度。
- {{ui:板}}：其尺寸與零件編號。

### 數值如何計算

- 梁會依柱深度之半（於腹板上為腹板厚度之半）加上板厚而切除，使板貼於柱面。
- 板高為梁深加上兩側延伸。
- 螺栓長度 = 握持（板厚 + 柱翼緣或腹板厚度）+ 餘量，無條件進位至下一個 5 mm。
- 所示焊縫長度為梁斷面的周長。

### 警告

連接仍會建立，但以下警告會顯示於其下方及 {{ui:問題}} 索引標籤中：

- 螺栓列或螺栓距板邊小於孔徑的 1.2 倍。
- 列距小於孔徑的 2.2 倍，或栓距小於孔徑的 2.4 倍。
- 孔延伸至柱腹板或其圓角處，或超出柱翼緣之外。
- 板寬大於柱翼緣，或（於腹板上）大於兩翼緣之間的空間；梁翼緣無法容納於其間。
- 螺栓列過於靠近梁翼緣，或栓距對梁腹板及其焊縫而言過密。

## 複製到每個相似的接頭

1. 選取已設定好的連接。
2. 在 {{ui:屬性}} 面板中選擇 {{ui:套用到相似項目 (n)}}，或在 {{ui:連接}} 群組的 {{ui:更多}} 功能表中選擇 {{ui:相似}}。括號中的數字為將會獲得連接的接頭數量。
3. 每個梁斷面與柱斷面相同、梁以相同類型的面相接，且尚無連接的接頭，都會獲得一份具有相同設定的副本。狀態列會顯示數量。

副本彼此獨立：之後變更其中一個不會改變其他的。已有連接的接頭保持不變；若要取代，請先刪除這些連接。

## 移動與刪除

連接會在每次模型變更時依其設定重新建立，因此移動或調整梁或柱的大小時，其端板會隨之移動。若變更使接頭不再適用，連接仍會保留在模型中，而 {{ui:問題}} 索引標籤會說明原因，例如「梁端已不在柱軸線上。」

若要刪除連接，請選取它並按 {{key:Delete}}。刪除梁或柱時，其連接也會一併刪除。
