DetailCraft 有一種自己的檔案，即模型，以及五種匯出內容。每次儲存和每次匯出都是下載。不會上傳任何內容，也不會在伺服器上保留任何內容。

## 模型檔案

DetailCraft 模型儲存為 `<name>.detailcraft.json`，其中 `<name>` 是 {{ui:模型}} 面板中的模型名稱。它包含格線、樓層、構件（含孔與切角）、接頭及其設定、基腳，以及自訂斷面。

零件、編號、螺栓、銲接與鋼筋不會儲存：DetailCraft 每次開啟時都會從模型重新算出。這就是模型檔案很小的原因。

### 儲存

1. 在 {{ui:模型}} 面板頂端的 {{ui:名稱}} 欄位輸入名稱。
2. 在 {{ui:檔案}} 群組中選擇 {{ui:儲存}}，或按 {{key:Mod+S}}。
3. 瀏覽器會下載 `<name>.detailcraft.json`。狀態列顯示「已儲存……（已下載）」，瀏覽器分頁標題開頭的圓點也會消失。

每次儲存都是新的下載。瀏覽器不會覆寫已開啟的檔案；依其設定，它會在名稱後加上數字，例如 `Frame (1).detailcraft.json`，或詢問儲存位置。若要保留各自的版本，請將下載的檔案重新命名。

:::chromium
Chrome 與 Edge 會儲存到「下載」資料夾，除非瀏覽器的下載設定中開啟了**下載前先詢問每個檔案的儲存位置**。若想每次選擇資料夾與檔名，請開啟它。
:::

:::firefox
Firefox 會儲存到「下載」資料夾；若其設定中開啟了**一律詢問儲存檔案的位置**，則每次都會詢問。
:::

:::safari
Safari 會儲存到「下載」資料夾。若要變更資料夾，請開啟 **Safari、設定、一般、檔案下載位置**。
:::

### 開啟

1. 在 {{ui:檔案}} 群組中選擇 {{ui:開啟}}，或按 {{key:Mod+O}}。
2. 選取 `.detailcraft.json` 檔案。

或從{{pick:mac=Finder|windows=檔案總管|linux=檔案管理員}}拖曳檔案，放到檢視上。拖曳時，檢視會顯示「放開以開啟 DetailCraft 模型」。

若已開啟的模型有尚未儲存的變更，DetailCraft 會先詢問：{{ui:取消}}、{{ui:捨棄變更}} 或 {{ui:先儲存}}。

DetailCraft 在使用檔案之前會檢查每個欄位。無法使用的內容會被省略，狀態列會說明內容，例如「有 2 個構件無效，已略去。」由較新版 DetailCraft 儲存的模型會被拒絕並顯示訊息，而不是只開啟一部分。

### 可開啟的內容

它自己的模型檔案（`.json`，最大 50 MB）以及 IFC 檔案（`.ifc`，IFC2X3 或 IFC4，最大 200 MB）。IFC 檔案不論是開啟或以 {{ui:匯入 IFC}} 帶入，都會成為由其樑、柱、構件、板、格線與樓層組成的新模型，其上的孔與切角會被切出，螺栓則成為獨立的螺栓；報告會列出被略去的內容。參閱 [IFC 匯出](topic:ifc-export#import)。它尚不能開啟 DWG、DXF，或任何其他詳圖程式的模型；嘗試時會顯示「DetailCraft 可開啟自己的模型（.detailcraft.json）和 IFC 檔案（.ifc）。」

## 遺失的作業、最近的檔案、桌面應用程式

- 模型有尚未儲存的變更時，DetailCraft 會在此瀏覽器中保留一份副本。若分頁或瀏覽器在儲存前停止，下次開啟 DetailCraft 時會詢問**要復原尚未儲存的內容嗎？**：復原該副本，或捨棄。參閱[復原尚未儲存的內容](common:recover)。
- 最近開啟的模型，在瀏覽器允許 DetailCraft 再次開啟它們時，會列在起始畫面上；按一下即可重新開啟。
- 在桌面應用程式中，{{ui:儲存}} 會將模型寫回已開啟的檔案（在瀏覽器中則下載副本），按兩下 DetailCraft 模型或 IFC 檔案則會在 DetailCraft 中開啟。

## 匯出

所有匯出都使用模型名稱。請在 {{ui:輸出}} 群組中選擇。

| 按鈕 | 檔案 | 內容 |
|---|---|---|
| {{ui:IFC}} | `<name>.ifc` | IFC4：樓層、格線、每個鋼構零件（以含其孔與切角的斷面拉伸表示）、組件、螺栓與錨栓、基腳，以及每根鋼筋。參閱[匯出 IFC](topic:ifc-export)。 |
| {{ui:NC 檔}} | `<name> NC.zip` | 每個零件編號一個 DSTV `.nc1` 檔案。參閱[將 NC 檔案送到工廠](topic:nc-export)。 |
| {{ui:材料表}} | `<name> BOM.csv` | 一個檔案中有三張表：零件、組件，以及螺栓與錨栓。參閱[編號與材料清單](topic:marks-and-bom)。 |
| {{ui:彎折}} | `<name> bending schedule.csv` | 基腳中的每個鋼筋編號。參閱[基腳與鋼筋](topic:footings-and-rebar)。 |
| {{ui:加工圖}} | `<name> <mark>.pdf` | 所選零件（I 型鋼與板）的一張圖紙（除非選擇其他尺寸，否則為 A3）。參閱[製作施工圖](topic:shop-drawings)。 |
| {{ui:圖紙}} | `<name> drawings.pdf`、`<name> <sheet>.pdf`；`<name> <sheet>.dwg` 或 `.dxf`，多張時為 `<name> drawings DWG.zip`（或 `DXF.zip`） | 所選圖紙尺寸的平面圖、立面圖與組件圖；DWG 與 DXF 為實際大小，紙上 1 單位 = 1 mm。參閱[總平面配置與組件圖](topic:drawings)。 |

### CSV 檔案的注意事項

- 檔案開頭有位元組順序標記，使試算表程式能正確讀取帶重音符號的字元。
- 以 `=`、`+`、`-` 或 `@` 開頭（且不是一般數字）的儲存格，前面會加上撇號，因此試算表絕不會把它當作公式執行。
- 長度為公釐，重量為公斤。

### PDF 的注意事項

PDF 中的文字使用標準的 Helvetica 字型。其沒有的字元（西歐字元集之外）會印成「?」，狀態列會說明有多少個。

## 單位

DetailCraft 全程使用公釐：格線、樓層、座標、斷面、孔，以及每種匯出內容。斷面名稱保留其公開的形式（W12x50 是美國的標示，即使其尺寸以 mm 顯示）。目前尚無英制輸入。

## 線上與離線

開啟、儲存與匯出都在瀏覽器中進行，因此 DetailCraft 載入後，有無連線的運作方式相同。

若之後要在沒有連線時使用 DetailCraft，請在線上時於應用程式列選擇 {{ui:儲存供離線使用}}。按鈕會向上計數（「正在儲存 20 個中的 3 個」），然後顯示 {{ui:可離線使用}}。儲存的副本包含 3D 圖形程式庫（約 2.6 MB）與本說明，因此儲存之後，3D 檢視、每種匯出內容與說明都能離線使用。詳情，以及哪些仍需要連線：[離線工作](common:offline)。

:::offline
目前離線。應用程式列顯示 {{ui:可離線使用}} 時，開啟、儲存與匯出如常運作。若沒有，請保持此分頁開啟，在重新上線之前不要重新載入，並立即儲存模型。
:::

雲端儲存尚未提供，桌面版也尚未推出。請像備份其他工作檔案一樣備份 `.detailcraft.json` 檔案。更多資訊請參閱[檔案的去向](common:your-files)。

## 尚未儲存的作業

DetailCraft 只將模型保留在開啟的分頁中。若在有尚未儲存的變更時關閉或重新載入分頁，瀏覽器會詢問是否離開頁面；其措辭屬於瀏覽器本身。請經常以 {{key:Mod+S}} 儲存。
