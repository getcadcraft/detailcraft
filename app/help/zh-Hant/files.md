DetailCraft 只有一種自有檔案，也就是模型，另有五種匯出。每次儲存與每次匯出都是下載。不會上傳任何內容，伺服器上也不保存任何內容。

## 模型檔

DetailCraft 模型會儲存為 `<name>.detailcraft.json`，其中 `<name>` 是 {{ui:模型}} 面板中的模型名稱。檔案內含格線、樓層、構件（含其孔洞與切角）、連接及其設定、基腳，以及自訂斷面。

零件、零件編號、螺栓、銲接與鋼筋不會儲存：DetailCraft 每次開啟時都會依模型重新算出。這就是模型檔很小的原因。

### 儲存

1. 在 {{ui:模型}} 面板頂端的 {{ui:名稱}} 欄位中輸入名稱。
2. 在 {{ui:檔案}} 群組中選擇 {{ui:儲存}}，或按 {{key:Mod+S}}。
3. 瀏覽器會下載 `<name>.detailcraft.json`。狀態列會顯示「已儲存 …（已下載）」，瀏覽器索引標籤標題開頭的圓點也會消失。

每次儲存都會產生新的下載。瀏覽器不會覆寫開啟的檔案；依其設定，它可能會在檔名後加上編號（例如 `Frame (1).detailcraft.json`），或詢問要儲存到哪裡。若要保留多個版本，請在下載後重新命名。

:::chromium
Chrome 與 Edge 會儲存到下載資料夾，除非瀏覽器的下載設定中已開啟 **下載前詢問每個檔案的儲存位置**。若要每次自行選擇資料夾與檔案名稱，請開啟此選項。
:::

:::firefox
Firefox 會儲存到下載資料夾；若其設定中已開啟 **每次都詢問儲存檔案的位置**，則會每次詢問。
:::

:::safari
Safari 會儲存到下載資料夾。若要變更資料夾，請開啟 **Safari、設定、一般、檔案下載位置**。
:::

### 開啟

1. 在 {{ui:檔案}} 群組中選擇 {{ui:開啟}}，或按 {{key:Mod+O}}。
2. 選取一個 `.detailcraft.json` 檔案。

也可以將檔案從 {{pick:mac=Finder|windows=File Explorer|linux=檔案管理程式}} 拖曳到檢視區中放開。拖曳時，檢視區會顯示「拖放 DetailCraft 模型即可開啟」。

若開啟中的模型有尚未儲存的變更，DetailCraft 會先詢問：{{ui:取消}}、{{ui:捨棄變更}}或{{ui:先儲存}}。

DetailCraft 在使用檔案中的每個欄位之前都會先檢查。無法使用的內容會被略過，狀態列會說明原因，例如「2 個構件無效，已略過。」由較新版 DetailCraft 儲存的模型會被拒絕並顯示訊息，而不會半對半錯地開啟。

### 可開啟的檔案

可開啟 DetailCraft 自有的模型檔（`.json`，最大 50 MB）與 IFC 檔（`.ifc`，IFC2X3 或 IFC4，最大 200 MB）。IFC 檔無論是直接開啟或透過 {{ui:匯入 IFC}} 匯入，都會成為一個新模型，包含其樑、柱、構件、鋼板、格線與樓層，並附上切好的孔洞與切角，其螺栓則成為獨立螺栓；報告會列出被略過的項目。請參閱 [IFC 匯出](topic:ifc-export#import)。目前尚無法開啟 DWG、DXF 或其他細部設計程式的模型；嘗試開啟時會顯示「DetailCraft 可開啟自有模型（.detailcraft.json）與 IFC 檔（.ifc）。」

## 遺失的工作、最近檔案與桌面應用程式

- 模型有未儲存的變更時，DetailCraft 會在此瀏覽器中保留一份副本。若分頁或瀏覽器在儲存前停止運作，下次開啟 DetailCraft 時會詢問 **復原尚未儲存的內容？**：可復原副本，或放棄。請參閱 [復原尚未儲存的內容](common:recover)。
- 瀏覽器允許 DetailCraft 再次開啟檔案時，最近開啟過的模型會列在起始畫面上；按一下即可重新開啟。
- 在桌面應用程式中，{{ui:儲存}} 會將模型寫回開啟的檔案（在瀏覽器中則是下載一份副本），而在 DetailCraft 模型或 IFC 檔上按兩下，即可在 DetailCraft 中開啟。

## 匯出

所有匯出都使用模型名稱。請在 {{ui:輸出}} 群組中選擇。

| 按鈕 | 檔案 | 內容 |
|---|---|---|
| {{ui:IFC}} | `<name>.ifc` | IFC4：樓層、格線、每個鋼構件以斷面擠出的實體（含孔洞與切角）、組合件、螺栓與錨栓、基腳，以及每根鋼筋。請參閱 [匯出 IFC](topic:ifc-export)。 |
| {{ui:NC 檔}} | `<name> NC.zip` | 每個零件編號一個 DSTV `.nc1` 檔。請參閱 [將 NC 檔送至加工廠](topic:nc-export)。 |
| {{ui:材料表}} | `<name> BOM.csv` | 同一檔案中的三個表格：零件、組合件，以及螺栓與錨栓。請參閱 [編號與材料清單](topic:marks-and-bom)。 |
| {{ui:彎折}} | `<name> bending schedule.csv` | 基腳中的每個鋼筋編號。請參閱 [基腳與鋼筋](topic:footings-and-rebar)。 |
| {{ui:加工圖}} | `<name> <mark>.pdf` | `<name> Shop drawings.pdf` 含每個零件編號一張圖紙；{{ui:下載 PDF}} 會下載目前顯示的那一張（除非另外選擇其他尺寸，否則為 A3）。請參閱 [製作加工圖](topic:shop-drawings)。 |
| {{ui:圖紙}} | `<name> drawings.pdf`、`<name> <sheet>.pdf`；`<name> <sheet>.dwg` 或 `.dxf`，多個會放在 `<name> drawings DWG.zip`（或 `DXF.zip`）中 | 所選圖紙尺寸上的平面、立面與組合圖；DWG 與 DXF 為實際大小，圖紙上 1 單位 = 1 mm。請參閱 [一般配置與組合圖](topic:drawings)。 |

### CSV 檔說明

- 檔案開頭含有位元組順序標記，讓試算表程式能正確讀取帶重音的字元。
- 開頭為 `=`、`+`、`-` 或 `@`（且不是純數字）的儲存格會加上前置撇號，讓試算表永遠不會將其當成公式執行。
- 長度單位為毫米，重量單位為公斤。

### PDF 說明

PDF 中的文字使用標準 Helvetica 字型。它不具備的字元（西歐字集以外）會印成「?」，狀態列會顯示數量。

## 單位

DetailCraft 全程使用毫米：格線、樓層、座標、斷面、孔洞及所有匯出皆然。斷面名稱保留其已發佈的形式（W12x50 是美制規格，即使其尺寸以 mm 顯示）。目前尚無英制輸入。

## 線上與離線

開啟、儲存與匯出都在瀏覽器中進行，因此只要 DetailCraft 已載入，無論有無連線，運作方式都相同。

若之後要在無連線的情況下使用 DetailCraft，請在連線時於應用程式列中選擇 {{ui:儲存供離線使用}}。按鈕會計數（「正在儲存 3 / 20」），然後顯示 {{ui:可離線使用}}。已儲存的副本包含 3D 圖形程式庫（約 2.6 MB）與本說明，因此儲存後，3D 檢視、所有匯出與本說明都能離線使用。細節與仍需連線的功能請見：[離線使用](common:offline)。

:::offline
目前離線。若應用程式列顯示 {{ui:可離線使用}}，開啟、儲存與匯出都會照常運作。若未顯示，請保持此分頁開啟，在恢復連線前不要重新載入，並立即儲存模型。
:::

雲端儲存尚未提供，也尚無桌面版建置。請像備份其他工作檔案一樣備份 `.detailcraft.json` 檔。更多說明請見：[檔案存放位置](common:your-files)。

## 未儲存的工作

DetailCraft 只將模型保存在開啟的分頁中。若在有未儲存的變更時關閉或重新載入分頁，瀏覽器會詢問是否離開頁面；其文字由瀏覽器自行提供。請經常按 {{key:Mod+S}} 儲存。
