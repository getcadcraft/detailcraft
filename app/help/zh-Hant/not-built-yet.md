DetailCraft是早期版本。本頁列出尚未提供的功能，方便你事先規劃。此處的內容都不是日期承諾。

## 建模

| 尚未提供 | 目前的替代做法 |
|---|---|
| 拖曳構件的一端（拉伸） | 在{{ui:屬性}}面板中，於{{ui:端部（x、y、z mm）}}下編輯{{ui:起點}}或{{ui:終點}} |
| 選取篩選（只選樑、只選一種斷面） | 拖曳出視窗選取，再按{{key:Shift}}+點選以移出零件 |
| 陣列選取物件；繞傾斜軸旋轉；在傾斜平面上鏡像 | 偏移一段距離後複製貼上，或使用{{ui:製作副本}}；旋轉與鏡像可在平面上使用（[以視窗選取、移動、旋轉、鏡像與批次變更](topic:select-and-change)） |
| 點擊時取得格線以外的點 | 將點放在格線上，然後輸入終點座標 |
| 沿數字格線的立面；已儲存的視圖；工作平面 | 使用{{ui:3D}}，或使用{{ui:依格線新增}} |
| 在3D視圖中以實際切除方式繪製孔 | 孔以深色塞子顯示；所有匯出中皆為實際的孔 |
| 圓角或斜角切角、其他切割與配件 | 僅工字型可使用直角切角 |
| 在角鋼與圓管上手動新增孔 | 角鋼的孔只能來自[斜撐接合板](topic:brace-gussets) |
| 英制輸入 | 以 mm 輸入（每英吋 25.4 mm） |
| 編輯或移除自訂斷面 | 以新名稱新增已修正的斷面 |

## 樓梯

| 尚未提供 | 目前的替代做法 |
|---|---|
| 扶手、平台、踢腳板、格柵踏板、螺旋與折返式樓梯 | 僅支援直跑樓梯；參見[樓梯](topic:stairs) |
| 斜梁端部與樓板的切割 | 以直角切割斜梁，於加工軟體中自行切割 |

## 接合

DetailCraft可建立六種接合：[斜撐接合板](topic:brace-gussets)；兩段同一工字型之間的螺栓[接頭](topic:splices)；兩個工字型以角度相交的[斜接](topic:mitres)，僅切割或加螺栓端板；從水平、直立的工字型樑到工字型柱翼板或腹板的齊平或延伸螺栓端板；從樑（正交、斜交或傾斜）到柱翼板或腹板的剪力板；以及具有四根錨栓的柱底板。

| 尚未提供 | 目前的替代做法 |
|---|---|
| 斜交或傾斜的端板 | 使用[剪力板](topic:shear-tabs)，可用於斜交與傾斜的樑 |
| 夾角鋼；接頭填充板與不同尺寸之間的接頭；焊接於樑與柱的角隅接合板，斜切接合板 | 在其他軟體中細部設計，或以零散零件的形式手動加入板件與孔；見[接頭](topic:splices)、[斜撐接合板](topic:brace-gussets) |
| 斜切或漸縮的底部加勁板；灌漿孔；剪力榫的基礎凹槽 | 矩形加勁板；見[底板](topic:base-plates) |
| 托臂；以對接焊接的焊接斜接；與另一構件翼板成一直線的加勁板 | 附有端板與腹板加勁板的[斜接](topic:mitres)，或單純的斜接切割；其他板件以零散零件手動加入 |
| 接合的設計檢核（強度） | 以工程師的計算檢核接合；DetailCraft僅警告邊距與間距 |
| 長孔 | 僅圓孔 |

## 分析

| 尚未提供 | 目前的替代做法 |
|---|---|
| 鋼工字型以外的設計檢核：管材、角鋼、槽鋼、焊接斷面、細長或第4類零件、扭轉、接合；混凝土：側移細長比、扭轉、耐震細部、樓板與牆 | {{ui:分析}}索引標籤依AISC 360或EN 1993-1-1檢核鋼工字型（[依設計規範檢核鋼構件](topic:design-checks)）；其餘項目標示為「未檢核」；全部皆須由工程師審閱 |
| 挫屈分析、振動 | 二階分析僅限P-Delta（彈性）；不進行挫屈分析（模態、反應譜、時程與推覆分析位於{{ui:分析}}索引標籤中） |
| 經工程師審閱的設計檢核 | 在此之前僅供參考：依賴結果前，先以手算或工程師自有軟體檢核兩到三根構件 |
| 依面積自動產生的樓板、風力與雪載 | 以kN/m或kN手動將載重加在構件上 |
| 構件偏位、偏心接合、僅受拉斜撐，以及框架中的板與基礎 | 構件依其工作線進行分析；斜撐承受拉力與壓力 |

## 鋼筋

| 尚未提供 | 目前的替代做法 |
|---|---|
| 圓柱、螺旋箍筋、傾斜或彎曲的樑、非矩形樓板、非直線牆 | 矩形樑、柱、樓板與牆（[細部設計鋼筋混凝土](topic:reinforced-concrete)） |
| 彎折成搭接的鋼筋、交錯搭接、可任意指定位置的搭接 | 等間距搭接，所有鋼筋在同一斷面搭接（ACI Class B，EN α6 = 1.5） |
| 開口處角筋、沖剪補強筋、耐震細部（ACI 318-19第18章） | 開口兩側的加強筋；其餘部分需自行檢查 |
| 讀取結構設計程式自有的檔案 | 從該程式匯出IFC：其IfcReinforcingBar會以鋼筋匯入（[來自IFC檔的鋼筋](topic:reinforced-concrete#bars-from-an-ifc-file)） |
| 直線、單彎與U形以外的形狀代碼；直線與單鉤鋼筋的ACI 315類型 | 三種形狀分別印為BS 8666 00、11、21或ACI Type 2；見[鋼筋參考](topic:rebar-reference) |
| BS 4449 H8–H40以外的公制鋼筋（例如CSA 10M–35M） | ASTM軟公制名稱#10–#36，或BS鋼筋 |

## 圖面與匯出

| 尚未提供 | 目前的替代做法 |
|---|---|
| 直式圖紙、A0，以及自訂尺寸的圖紙；斜交格線上的一般配置視圖 | 橫向A4至A1與ANSI B至D（[一般配置與組合圖](topic:drawings)）；縮放PDF後即可在其他尺寸列印 |
| 單一零件加工圖上的銲接符號；角焊以外的符號 | 組合圖帶有角焊符號；加工圖以文字標示銲接 |
| 在應用程式中編輯圖面 | 變更模型並重新製作圖面；以PDF應用程式（例如MarkupCraft）標記PDF |
| 以含標註物件的DWG輸出圖面，或以實際尺寸在模型空間中呈現模型並以圖紙作為配置 | 每張圖紙皆為該圖紙的全尺寸DWG或DXF，標註以線段與數字呈現（[一般配置與組合圖](topic:drawings#download)） |
| NC檔中圓管上的孔、角鋼與圓管上的切角 | 不寫出；見[NC檔欄位](topic:nc1-fields) |
| NC檔中的斜切、標記與內輪廓 | 目前無 |
| USD匯出中的螺栓孔、螺栓、銲接與基礎 | 這些內容位於IFC、NC與BOM輸出中；見[將鋼構模型匯出為USD](topic:usd) |
| 從IFC檔匯入接合、基礎、長孔或矩形孔，以及圓管上的孔 | {{ui:匯入 IFC}}可匯入樑、柱、構件、板、格線、樓層、圓孔、切角、螺栓與鋼筋，其報告會列出未匯入的項目 |
| 自訂報告版面 | 三個CSV檔 |

## 協作與儲存

| 尚未提供 | 目前的替代做法 |
|---|---|
| 電腦之間的雲端儲存與同步 | 將`.detailcraft.json`檔案儲存，並像其他檔案一樣分享。目前尚不提供雲端儲存 |
| Live TeamWork工作階段中其他人的游標與「正在編輯」標籤；格線、樓層與階段逐項合併 | 編輯仍會合併（格線、樓層與階段整組套用，較晚的變更優先）；見[即時共同細部設計一座結構](topic:work-live) |
| 透過網際網路的Live TeamWork工作階段邀請連結 | 在同一網路上以短代碼加入 |

## 平台

- DetailCraft專為桌上型電腦、筆記型電腦或平板螢幕設計。手機也可使用：模型保留畫面，面板與報告會從底部的列以頁面方式開啟，但面板的空間很有限。
- 離線使用前，需先在應用程式列中以{{ui:儲存供離線使用}}將DetailCraft儲存為可離線使用；一旦顯示{{ui:可離線使用}}，本版本的所有功能皆可在沒有連線的情況下運作。見[離線工作](common:offline)。

如果其中一項限制阻礙你的工作，請透過[支援頁面](https://getcadcraft.com/support)告訴我們；這有助於決定接下來要開發的項目。
