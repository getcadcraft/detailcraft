檢視下方的{{ui:混凝土}}索引標籤會詳列混凝土樑、柱、樓板與牆的鋼筋。你提供尺寸與鋼筋；DetailCraft 會配置每根鋼筋、為其編號，依其所據條文檢核搭接、錨定、保護層與間距，並將其繪出。

:::warning
DetailCraft 只詳列你提供的鋼筋，不進行設計。所有結果皆供工程師檢核。
:::

## 開啟混凝土索引標籤

選擇檢視下方的{{ui:混凝土}}索引標籤。在功能區版面中，{{ui:混凝土}}位於{{ui:建模}}索引標籤中，與{{ui:基腳}}相鄰。若使用製圖樣式的指令列，請輸入 {{cmd:CONCRETE}}。

## 依格線新增元素

混凝土元素會配置於模型的格線與標高上，因此請先設定格線與標高（左側面板）。

1. 在{{ui:依格線新增}}中，選擇{{ui:元素}}：{{ui:混凝土樑}}、{{ui:混凝土柱}}、{{ui:樓板}}或{{ui:牆}}。
2. 選取格線與標高：
   - 樑從一個格線交點延伸至另一個，其頂部位於標高上；
   - 柱位於一個交點上，從一個標高至另一個標高；
   - 樓板填滿兩條數字格線與兩條字母格線之間的矩形，其頂部位於標高上；
   - 牆沿其中心線從一個交點延伸至另一個，並從一個標高至另一個標高。
3. 輸入尺寸並選擇{{ui:新增}}。元素會被選取，其欄位會在{{ui:屬性}}面板中開啟。

每個元素一開始的鋼筋皆為起始值，並非設計值：請改為工程師的設計值。

## 變更鋼筋

選取元素（在檢視中，或在{{ui:混凝土}}索引標籤中選取其名稱）。{{ui:屬性}}面板會顯示：

| 元素 | 可設定項目 |
|---|---|
| 樑 | 寬度、深度、淨保護層；頂部與底部鋼筋（尺寸、數量、兩端為直線或 90° 彎鉤）；側面鋼筋；箍筋（尺寸、135° 或 90° 彎鉤、第一道箍筋距支承面的距離、端部區段長度與間距、中段間距）；支承長度；搭接長度 |
| 柱 | 寬度、深度、旋轉、保護層；各面的縱向鋼筋；繫筋（同箍筋）；鋼筋在頂部的處理方式（與上方的柱搭接、彎入樓板，或終止） |
| 樓板 | 厚度、尺寸、頂部、保護層；底層與頂層鋼筋網的各向鋼筋（尺寸與間距）；繞邊緣的 U 形筋；補強筋；開口 |
| 牆 | 厚度、保護層、單層或雙層、水平與垂直鋼筋、端部的 U 形筋、垂直鋼筋是否向上搭接、補強筋、開口 |

每次變更為一個復原步驟。無法建構的變更會被拒絕，狀態列會說明原因，例如「開口無法放入含保護層的元素內。」

箍筋與繫筋為封閉式，兩個彎鉤位於同一個角落。樑的鋼筋在兩端延伸進入混凝土柱，至柱的遠側面扣除保護層為止；若該處沒有柱，請輸入{{ui:起點支承長度(mm)}}與終點的支承長度。

## 搭接與錨定

長於{{ui:原料鋼筋長度(mm)}}（起始值為 12000）的鋼筋會被切成等長的數段，並以搭接連接。{{ui:搭接與錨定}}表列出每個搭接與每個錨定：所需長度、所據條文與其條件，以及詳圖所提供的長度。

- 搭接長度為 0 表示「依需要」：即規範所給的長度，無條件進位至 25 mm。
- 輸入你自己的搭接長度即可改用該值。若其短於所需長度，即為問題（見下文），並會在表中標示 *。
- 錨定自支承面量至鋼筋在支承內的末端。若樑的支承未知，則會說明此情況，而不進行檢核。
- 立於基腳上的柱，會與基腳的續接鋼筋搭接；立於另一根柱上的柱，則與該柱的鋼筋搭接：此搭接同樣會被檢核。

**ACI 318-19**（SI）：受拉直鋼筋 25.4.2.3（表，含 ψt、ψe、ψg、λ）、標準彎鉤 25.4.3.1（除非另有已知值，否則採用 ψr 1.6 與 ψo 1.25）、受壓鋼筋 25.4.9.2、受拉搭接 25.5.2.1（B 類，或設定中的 A 類）、受壓搭接 25.5.5.1。

**EN 1992-1-1**：錨定 8.4.4，其 fbd 取自 8.4.2（良好或不良黏結），搭接 8.7.3，於同一斷面搭接的每根鋼筋皆採用 α6。γc、γs 與 αct 以建議值為起始值；請設定你的國家附錄值。

## 檢核項目

所有未通過的檢核，會列於殼層的問題面板（來源為{{ui:鋼筋檢核}}），也會列於元素的{{ui:檢查}}清單中：

| 檢核 | ACI 318-19 | EN 1992-1-1 |
|---|---|---|
| 保護層 | 表 20.5.1.3.1，依暴露等級 | 黏結最小值，表 4.2（耐久性保護層由你提供） |
| 鋼筋淨間距 | 25.2.1（樑、樓板、牆）、25.2.3（柱） | 8.2 (2) |
| 箍筋間距 | 9.7.6.2.2 | 9.2.2 (6) |
| 樑最小鋼筋量 | 9.6.1.2 | 9.2.1.1 (1) |
| 深度超過 900 mm 之樑的側面鋼筋 | 9.7.2.3 | 未檢核 |
| 柱鋼筋比、鋼筋根數 | 10.6.1.1、10.7.3.1 | 9.5.2 |
| 繫筋：間距、尺寸、橫向繫筋 | 25.7.2.1、25.7.2.2、25.7.2.3 | 9.5.3 (1)、(3)、(4) |
| 樓板間距、最小鋼筋量 | 7.7.2.3、24.4.3.2 | 9.3.1.1 |
| 牆間距、最小鋼筋量、雙層 | 11.7.2.1、11.7.3.1、11.6.1、11.7.2.3 | 9.6.2、9.6.3 |
| 搭接、錨定 | 如上 | 如上 |

骨材粒徑未知，因此淨間距檢核不計入骨材粒徑。

## 開口、補強筋與邊緣鋼筋

在選取的樓板或牆下選擇{{ui:新增開口}}，並設定其位置與尺寸。被開口切斷的鋼筋會止於距其邊緣一個保護層處。補強筋會加在每一側、位於同一層，承載被切斷鋼筋一半的面積，並延伸超過開口一個錨定長度。這是 DetailCraft 的起始規則，並非規範條文：請將{{ui:補強筋}}改為工程師的設定。不會加入角隅鋼筋。

樓板自由邊緣與牆端周圍的 U 形筋，其兩側段長度為一個搭接長度。

## 鋼筋編號與彎折表

相同的鋼筋共用一個編號：基腳保留 F 編號（5F1），樑為 B、柱為 C、樓板為 S、牆為 W（7B1、8C1、4S2）。{{ui:彎折表}}索引標籤及其 CSV 現在會列出結構中的每根鋼筋，基腳排在最前。{{ui:輸出}} › {{ui:更多}} › {{ui:彎折}}可下載該檔案。

## 加工圖

選擇{{ui:輸出}} › {{ui:更多}} › {{ui:鋼筋圖紙}}、{{ui:混凝土}}索引標籤中的{{ui:鋼筋圖紙}}，或某個元素旁的{{ui:加工圖}}。每個元素會產生一張圖紙，包含立面（樓板則為平面）、標示每根鋼筋及其編號、箍筋或繫筋區段與搭接尺寸，以及中央的剖面；其後的鋼筋加工表會列出每個編號，並附有其形狀草圖、尺寸、數量、下料長度與重量。

圖紙每次都會依模型重新產生，且在視窗開啟期間，每次變更後也會重新產生：標題欄會載明模型參照。可輸出{{ui:將此圖紙輸出為 PDF}}或{{ui:將所有圖紙輸出為 PDF}}。

## 來自 IFC 檔案的鋼筋

{{ui:檔案}} › {{ui:匯入 IFC}}現在可讀取 IfcReinforcingBar：沿其中心線掃掠的圓盤，會還原為直段與彎曲段，並帶有其直徑、編號與所屬元素。鋼筋會依讀取時的樣貌保留（不會轉換為樑或樓板的規則），顯示於檢視中，列於彎折表，並會隨 IFC 匯出重新寫出。匯入報告會說明讀取了多少根鋼筋、其尺寸為何、分屬於多少個元素，以及哪些項目被略過及其原因。

該檔案中含有鋼筋或材料為混凝土的樑、柱、樓板或牆，不會被視為鋼構件；報告中會說明此情況。DetailCraft 自身的 IFC 匯出會帶有每個混凝土元素的定義，因此匯入後會還原為該元素，其鋼筋亦會依此重新產生。

:::note
讀取結構設計程式自身的檔案（非 IFC）尚未實作：請從該程式匯出 IFC。
:::

## IFC 匯出

混凝土樑、柱、樓板（含開口）與牆會匯出為 IfcBeam、IfcColumn、IfcSlab 與 IfcWall，每個元素的鋼筋則以 IfcReinforcingBar 匯出並歸屬於該元素（主筋、箍筋與繫筋的綁紮筋、邊緣鋼筋）；每根鋼筋皆為沿其中心線掃掠的圓盤，彎曲處為真實圓弧，並帶有其編號與下料長度。
