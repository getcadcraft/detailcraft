IFC 匯出會將整個模型寫成單一 IFC4 檔，可由 BIM 軟體與 IFC 檢視器開啟。

## 匯出

1. 在{{ui:輸出}}群組中選擇{{ui:IFC}}。
2. 瀏覽器會下載 `<name>.ifc`。狀態列會說明匯出的內容，例如「IFC4 已匯出：25個零件、88個緊固件、7個基腳、132根鋼筋。」

若模型中沒有零件、基腳或鋼筋，狀態列會顯示「尚無可匯出的內容。」

## 檔案內容

| DetailCraft 中 | IFC 檔中 |
|---|---|
| 每個樓層 | 建築樓層（IfcBuildingStorey），隸屬於一個專案、基地與建築物之下 |
| 軸線 | 一個 IfcGrid，含其軸線與標籤 |
| 柱、樑、斜撐 | IfcColumn、IfcBeam、IfcMember（斜撐），每個皆為標準斷面形狀的擠出體，具有實際尺寸 |
| 板、端板、底板 | IfcPlate |
| 孔與切角 | 從零件切除的開口（IfcOpeningElement） |
| 構件及其焊接的板 | 組合件（IfcElementAssembly），以組合件標記標示 |
| 螺栓與錨栓 | IfcMechanicalFastener，含直徑與長度 |
| 基腳 | IfcFooting（獨立基腳），以混凝土文字作為其材料 |
| 每根鋼筋 | IfcReinforcingBar，含其鋼筋編號、直徑、面積與長度，沿其真實中心線掃掠，並在彎折處為真實圓弧 |

每個零件的標籤為其零件編號。每個元素也帶有名為「DetailCraft」的屬性集，包含其標記、斷面與重量。每個元素位於其最低點所在或之下的最高樓層。材料依等級分組。

## 重新匯出時的穩定識別碼

每個元素的 IFC 識別碼（GlobalId）由模型名稱與該元素在模型中的自身識別碼計算而得。匯出同一模型兩次，識別碼會相同，因此比較版本的軟體能辨識出何者有變更。

:::warning
更改模型名稱會使每個識別碼改變。在同一專案的各次發行之間，請保持模型名稱相同。
:::

## 檢查

DetailCraft 的 IFC 檔會由其測試套件中的一個獨立 IFC 讀取器讀回。各程式讀取 IFC 的方式不同，因此在依賴檔案之前，請先在團隊使用的軟體中開啟。CadCraft 的 BimCraft 應用程式也可開啟 IFC 檔。

## 尚未支援

- 從 IFC 檔匯入接頭、基腳與鋼筋。{{ui:匯入 IFC}}會匯入樑、柱、構件、板、軸線、樓層、孔、切角與螺栓，並列出其略過的內容。
- 分析或結構分析資料。
- IFC4 參考檢視以外的任何內容。

## 匯入

{{ui:匯入 IFC}}位於{{ui:檔案}}群組中（或將 `.ifc` 檔拖曳至檢視區上），可由 IFC2X3 或 IFC4 檔建立新模型：

- **樑、柱、構件（斜撐）與板**，其實體為 DetailCraft 所認得的單一擠出斷面，會比對至目錄，或保留為自訂斷面；**軸線**與**樓層**取自檔案中的軸線與樓層。
- **孔：**每個垂直於已匯入零件某一面的圓形開口（IfcOpeningElement 穿過該零件）：工字形或槽形的腹板或翼緣、方管的壁、板，或角鋼的肢。穿過方管兩壁的孔只匯入一次。
- **切角：**一個矩形開口，從一端佔滿工字形或槽形的全寬，由上方向下或由下方向上。
- **螺栓：**每個 IfcMechanicalFastener 或 IfcFastener，含其直徑、長度、等級與種類（螺栓或錨栓），作為**散裝螺栓**匯入。散裝螺栓會顯示於檢視、材料清單與 IFC 匯出中，移動構件時會留在原位。{{ui:屬性}}面板在未選取任何物件時會計算其數量，並提供{{ui:移除散裝螺栓}}，供改為新增接頭時使用。

報告會依類別列出其他所有內容，並說明略過的原因：牆與樓板、基腳與鋼筋、開槽孔、圓管上的孔、接頭（IFC 檔帶有其板與螺栓，但不含產生它們的規則）。
