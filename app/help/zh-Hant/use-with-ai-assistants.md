## 本主題內容

如何讓AI助理（或自行撰寫的指令稿）與DetailCraft協同運作，以及如何決定它可以變更的範圍。

DetailCraft**本身沒有AI**，也不會傳送任何資料。助理需自行準備：任何支援模型內容協定（MCP）的程式皆可。DetailCraft只提供工具，由使用者決定提供哪些。

## 啟用

1. 開啟{{ui:設定}}（應用程式列中的齒輪圖示，或{{key:Mod+,}}），然後切換至{{ui:DetailCraft}}索引標籤。
2. 在{{ui:助理}}下勾選**允許AI助理與指令稿使用DetailCraft**。在勾選之前，此功能為關閉狀態。
3. 選擇其可執行的操作：**讀取**預設已勾選；只在需要時才勾選**編輯**、**儲存**或**匯出**。

未勾選之權限範圍以外的工具不會提供給助理；即使助理仍要求使用，DetailCraft也會拒絕並將其記錄於活動紀錄中。關閉此開關會立即中斷所有連接。

## 連接助理

助理透過電腦上的**CadCraft Studio**連接：Studio會執行一個僅此電腦可連線的小型伺服器，並以每次啟動時產生的權杖加以保護。在Studio中，選擇{{ui:連接助理}}，並將位址與權杖複製到助理中（Studio會顯示應貼上的確切設定）。切勿分享權杖。

:::note
瀏覽器分頁無法為助理開啟連接：在瀏覽器版應用程式中，此開關在使用電腦上的CadCraft Studio之前不會生效。
:::

## 保持掌控

- **每項變更都是一個復原步驟**，並標示為助理所做（例如"Assistant: add beam"、"Assistant: add gussets"）。{{key:Mod+Z}}會將助理的最後一項變更整體復原。助理自身的`undo`只會復原它自己的步驟，除非明確要求，否則不會復原使用者的變更。
- **它會等待使用者。**在放置構件、移動零件或貼上時，DetailCraft會拒絕助理的變更，並告知其重新嘗試。
- **連接時會有提示。**應用程式列中的按鈕會在助理連接時顯示其名稱；點選可查看其可執行的操作，或**中斷連接**。
- **活動。**{{ui:設定}} › {{ui:DetailCraft}} › {{ui:助理}} › {{ui:活動}}會列出每次呼叫：時間、使用的工具、完成或遭拒。{{ui:儲存紀錄}}可保留一份副本。

## 助理可要求的操作

所有長度皆以毫米為單位，點座標為`[x, y, z]`，Z軸朝上，與模型一致。

| 工具 | 權限 | 功能 |
|---|---|---|
| `app_info`、`model_describe` | 讀取 | 目前開啟的模型：格線、樓層、階段、依類型與斷面分列的構件、接頭、基礎、樓梯、零件、鋼材重量、問題 |
| `parts_list` | 讀取 | 零件編號，含斷面、材料、切割長度、數量、重量、階段與組合件編號；可依類型、斷面、編號或階段篩選 |
| `problems_list` | 讀取 | {{ui:問題}}索引標籤所列的內容，每項並附上其說明 |
| `clash_check` | 讀取 | [衝突檢查](topic:clash-check)，含其容差與階段 |
| `selection_get` | 讀取 | 目前選取的內容 |
| `selection_set` | 編輯 | 選取構件、接頭、基礎或樓梯（依id或零件編號），以便顯示給使用者；不會變更任何內容 |
| `member_add` | 編輯 | 兩點之間的梁、柱、斜撐或板件 |
| `connection_add` | 編輯 | 在指定構件相交處加入端板、剪力板、底板、接合或接合板，與{{ui:連接}}按鈕的作用相同 |
| `undo` | 編輯 | 復原助理的最後幾個步驟 |
| `model_save` | 儲存 | DetailCraft自身的儲存功能 |
| `model_export` | 匯出 | IFC、NC檔、BOM、鋼筋加工表、KISS檔或下料表，與{{ui:輸出}}按鈕產生的內容相同 |
| `usd_export` | 匯出 | 將鋼結構模型匯出為USD（.usda、.usdc或.usdz），與{{ui:輸出}} › {{ui:USD}}的輸出方式相同（見[將鋼結構模型匯出為USD](topic:usd)）；在Studio中，可將檔案寫入已允許的資料夾 |

## 若無法運作

- **助理看不到任何DetailCraft工具：**檢查此視窗中的開關是否已開啟，以及此視窗是否已在Studio中開啟。
- **「需要編輯權限」**（或儲存、匯出）：在{{ui:助理}}下勾選該權限，然後再次要求。
- **「使用者正在放置構件」：**完成目前的操作（或按{{key:Esc}}），然後再讓助理重試。
- **「401」或「token」錯誤：**權杖已變更（Studio已重新啟動，或{{ui:新權杖}}）。將新的權杖複製到助理的設定中。
