如何在本說明中標示按鍵：[按鍵、滑鼠與觸控板](common:keys)。在 Mac 上，{{key:Mod}} 為 Command 鍵；其他系統則為 Ctrl。

## 工具

這些操作在游標不在文字或數字欄位中時有效。

| 按鍵 | 功能 |
|---|---|
| {{key:V}} | {{ui:選取}} |
| {{key:B}} | {{ui:樑}} |
| {{key:C}} | {{ui:柱}} |
| {{key:R}} | {{ui:斜撐}} |
| {{key:P}} | {{ui:板}} |
| {{key:F}} | {{ui:基腳}} |
| {{key:S}} | {{ui:樓梯}} |
| {{key:M}} | 依選取兩個格線交點，移動選取範圍（[以視窗選取、移動、旋轉、鏡射、批次變更](topic:select-and-change)） |
| {{key:Esc}} | 放掉拖曳中的選取視窗，或將拖曳中的零件放回原位；取消移動、樑、斜撐或板的第一點，或取消貼上；再按一次可回到 {{ui:選取}}；在 {{ui:選取}} 中，清除選取。開啟 {{ui:更多}} 功能表時，則關閉該功能表 |
| {{key:Delete}} 或 {{key:Backspace}} | 刪除選取的物件（所有已選取項目，為一個復原步驟） |

## 檔案與編輯

| 按鍵 | 功能 |
|---|---|
| {{key:Mod+S}} | 儲存模型（下載）。即使正在欄位中輸入也有效 |
| {{key:Mod+O}} | 開啟模型。即使正在欄位中輸入也有效 |
| {{key:Mod+Z}} | 復原（在文字欄位外有效；在文字欄位內則復原輸入內容） |
| {{key:Mod+Y}} 或 {{key:Mod+Shift+Z}} | 取消復原 |

## 複製與貼上

這些操作在游標不在文字或數字欄位中時有效（在欄位中則照常複製、貼上與選取文字）。每次貼上、剪下、製作副本或刪除都是一個復原步驟。更多說明：[複製、貼上與製作副本](topic:copy-paste)。

| 按鍵 | 功能 |
|---|---|
| {{key:Mod+C}} | {{ui:複製}} 已選取的構件與基腳（連同其開孔、切角與連接） |
| {{key:Mod+X}} | {{ui:剪下}}：複製選取範圍，然後刪除 |
| {{key:Mod+V}} | {{ui:貼上}}：複本跟隨指標移動；點選格線交點即可放置 |
| {{key:Mod+Shift+V}} | {{ui:就地貼上}}：貼到複製時的座標位置 |
| {{key:Mod+D}} | {{ui:製作副本}}：立即建立副本，並依 [DetailCraft 設定](topic:settings) 中的位移量移動 |
| {{key:Mod+A}} | {{ui:全選}}：所有構件、連接與基腳 |
| {{key:Esc}} | {{ui:取消全選}} |

若頁面上選取了文字（例如報表表格），而模型中沒有任何選取項目，{{key:Mod+C}} 會照常複製文字。

{{ui:新增}}、{{ui:範例}} 及各項匯出沒有快速鍵；請使用工具列。

當對話方塊（施工圖預覽或提示）開啟時，這些按鍵都不會作用。

| {{key:Esc}} | 關閉施工圖預覽或提示對話方塊（與 {{ui:取消}} 相同） |

## 滑鼠

| 動作 | 在 3D 中 | 在平面與立面中 |
|---|---|---|
| 點選 | 選取構件；放置工具開啟時，放在最近的交點（貼上時也貼在該處） | 相同 |
| {{key:Shift}}、{{key:Ctrl}} 或 {{key:Mod}} 加點選 | 將構件加入選取，或取消選取 | 相同 |
| 在已選取的構件上按下並拖曳 | 在樓層間移動選取範圍；按住 {{key:Mod}} 時可上下移動 | 移動選取範圍（在立面中：沿立面移動，並可上下移動） |
| 以左鍵拖曳 | 轉動模型 | 使用 {{ui:選取}} 時：選取視窗（向右拖曳：完全包含在內；向左拖曳：接觸即選取）。放置時：平移 |
| {{key:Shift}} 加左鍵拖曳 | 使用 {{ui:選取}} 時：加入選取的選取視窗。放置時：平移 | 使用 {{ui:選取}} 時：加入選取的選取視窗 |
| {{key:Ctrl}} 或 {{key:Mod}} 加左鍵拖曳 | 平移 | 無 |
| 以右鍵拖曳 | 平移 | 平移 |
| 滾輪 | 以視圖中央為中心縮放 | 縮放 |
| 以中鍵拖曳 | 縮放 | 使用 {{ui:選取}} 時：平移。否則縮放 |
| 將 `.detailcraft.json` 檔拖放到應用程式上 | 開啟該檔 | 開啟該檔 |

只有在按下與放開之間指標移動不到約 5 像素時，才算點選；移動較長距離則為拖曳。

## 觸控板

| 動作 | 功能 |
|---|---|
| 雙指上下滑動或捏合 | 縮放 |
| 按下並拖曳 | 轉動（3D）或平移（平面與立面） |
| {{key:Shift}} 加按下並拖曳 | 在 3D 中平移 |
| 雙指點按 | 按右鍵（視圖中沒有功能表） |

## 觸控

在平板或觸控螢幕上：

| 動作 | 功能 |
|---|---|
| 點按 | 選取構件；放置工具開啟時，放在最近的格線交點（距離約一指寬內的點按也算） |
| 長按構件 | 加入選取，或取消選取（相當於滑鼠的 {{key:Shift}} 加點選） |
| 單指按住已選取的構件後拖曳 | 移動選取範圍，並貼齊到格線交點 |
| 單指在其他位置 | 轉動模型（3D）或平移（平面與立面） |
| 雙指 | 捏合縮放，一起移動則平移 |

僅觸控螢幕時，按鈕、清單與欄位會放大。選取視窗需要使用滑鼠；以手指操作時，請使用點按與長按。

## 瀏覽器保留的快速鍵

某些快速鍵屬於瀏覽器，任何網頁都無法使用，例如 {{key:Mod+W}}（關閉分頁）、{{key:Mod+T}}（新增分頁）與 {{key:Mod+N}}（新增視窗）。如果 {{key:Mod+Y}} 開啟的是瀏覽器紀錄而非取消復原，請改用 {{key:Mod+Shift+Z}}。

快速鍵只有在網頁取得鍵盤焦點時才會傳到 DetailCraft。如果按鍵沒有作用，或瀏覽器執行了其他動作，請先在 DetailCraft 視窗中點選一個空白的構件處（例如在網址列輸入文字後）。

## 移動功能的位置

沒有獨立的移動指令：請選取構件後在樓層間拖曳（按住 {{key:Mod}} 可上下拖曳），或在 {{ui:屬性}} 中編輯其 {{ui:起點}} 與 {{ui:終點}}。
