底板接頭會在柱下放置一塊板，將柱截短板厚的長度，再把兩者焊接在一起，並在板上的孔中加入四根錨栓。

:::warning
尺寸僅為起始值，並非設計。DetailCraft 不檢查承壓、錨栓強度或埋置深度。
:::

## 新增底板

1. 選擇{{ui:選取}}（{{key:V}}），然後按一下柱。該柱必須為垂直。
2. 在{{ui:連接}}群組中選擇{{ui:底板}}，或在{{ui:屬性}}面板中選擇{{ui:新增底板}}。
3. 狀態列顯示「已新增底板與四根錨栓。」新增的接頭會被選取。

一根柱只能有一塊底板。若該柱已有底板，狀態列會顯示「此柱已有底板。」

## 變更設定

選取底板（按一下板或錨栓）。在{{ui:板、螺栓與焊縫（mm）}}下：

| 設定 | 預設 | 作用 |
|---|---|---|
| 板厚 | 25 | 柱會因此縮短這麼多 |
| 板長 | 450 | 沿柱深方向 |
| 板寬 | 400 | 垂直柱深方向 |
| 錨栓直徑 | 20 | 錨栓尺寸 |
| 孔徑 | 33 | 板上的孔 |
| 螺栓等級 | F1554 Gr 36 | 錨栓等級，為文字 |
| 錨栓間距（沿深度） | 350 | 錨栓中心之間的距離，沿板長方向 |
| 錨栓間距（垂直） | 300 | 錨栓中心之間的距離，垂直方向 |
| 錨栓伸出板面高度 | 100 | 從板頂到錨栓頂端 |
| 錨栓埋入板下深度 | 450 | 從板底向下伸入混凝土的長度 |
| 填角焊尺寸 | 8 | 環繞柱底一圈 |
| 板材料 | A36 | 文字 |
| 灌漿間隙 | 0 | 混凝土頂面與板底之間的距離 |
| 加勁板 | 無 | 選擇無、2（與腹板同線）或 4（另加與其垂直）；見下方 |
| 加勁板厚度、高度 | 12, 150 | |
| 剪力榫深度 | 0 | 榫頭伸出板底的距離；0 = 無榫 |
| 剪力榫厚度、寬度 | 25, 150 | |
| 板墊圈 | 無 | 每根錨栓都加，或都不加 |
| 墊圈尺寸、厚度 | 0, 0 | 0 = 採用 AISC Design Guide 1 對該錨栓的最小值 |

錨栓長度 = 埋入深度 + 灌漿間隙 + 板厚 + 伸出高度。以預設值計算為 575 mm。

## 底板的細部：灌漿、加勁板、剪力榫、墊圈

四者在新底板上皆為關閉，DetailCraft 0.4 之前的模型中的底板也一樣。

- **灌漿間隙。**板位於混凝土頂面上方此距離，錨栓會相應加長。AISC Design Guide 1 (2.10) 建議在完成的樓板上為 1 in.，在基腳或墩座上為 1½ 至 2 in.；大型板與帶剪力榫的板應取更大值。
- **加勁板。**焊接於柱與板之間的垂直板，從柱面向外延伸到板邊，為矩形（尚不支援斜角或錐度）。**2** 片與腹板同線，位於各翼緣之外；**4** 再加兩片與腹板垂直，位於翼緣之間，延伸到板邊。在方管柱上，加勁板位於各面的中央。每片兩側都焊於柱與板。
- **剪力榫。**焊於底板下方四周的板，沿柱深方向置中。若其深度不大於灌漿間隙，DetailCraft 會發出警告。它不會在基腳上切出凹槽；因此[衝突檢查](topic:clash-check)會排除榫頭與基腳。
- **板墊圈。**每根錨栓上一片方形板墊圈，放在底板上，列於柱的組合件中，為散裝（隨柱出貨，不焊接；Design Guide 1，2.6）。尺寸與厚度為 0 時，DetailCraft 採用 AISC Design Guide 1 第 2 版表 2.3 中該錨栓的最小墊圈；公制錨栓取次一英吋尺寸（M20 錨栓用 7/8 in. 列：2½ in. × 5/16 in.）。屬性面板會顯示所用尺寸。墊圈孔徑為錨栓直徑加 1/16 in.：此為 DetailCraft 的選擇，表中未給定。若錨栓伸出長度不足以容納墊圈與螺帽（伸出長度小於墊圈厚度加錨栓直徑），DetailCraft 會發出警告。

Design Guide 1，表 2.3 也建議板上的錨栓孔：¾ in. 錨栓用 1-5/16 in.，⅞ in. 用 1-9/16 in.，1 in. 用 1-13/16 in.。DetailCraft 不會更改孔徑設定。

當錨栓孔與板邊距離小於 1.2 × 孔徑、錨栓位於柱輪廓之內，或板小於柱時，也會出現警告。

## 複製到相似的柱

1. 選取底板。
2. 選擇{{ui:套用至相似 (n)}}，或{{ui:連接}}群組的{{ui:更多}}功能表中的{{ui:相似}}。
3. 每根沒有底板、且不站在其他柱上、斷面相同的垂直柱，都會獲得一份複本。

## 底板與基腳

底板不需要基腳，而基腳也不會感知上方的底板：錨栓不會與基腳的鋼筋相連。使用{{ui:基腳}}放置基腳；請見[以鋼筋放置基腳](topic:footings-and-rebar)。
