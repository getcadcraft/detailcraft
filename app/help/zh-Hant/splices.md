螺栓接合是將同一 I 型斷面的兩段首尾相接：每個翼板外側各一片覆板，腹板兩側各一片接合板，並以螺栓穿過兩段鎖合。DetailCraft會將兩段裁短至間隙範圍，放置四片板件，在板件與兩段上鑽孔，加入螺栓，並對邊距、間距與配合發出警告。

## 適用情況

- 兩根梁或兩段柱，斷面為**相同的 I 型斷面**，並且**首尾相接、位於同一直線上**：端部間距不超過50 mm，兩段彼此平行且位於同一直線上（誤差1 mm以內）。兩段的繪製方向可任意。
- 水平、斜向或垂直的段件皆可使用。
- 深度或翼板寬度不同的兩段會被拒絕，槽鋼、角鋼與管材也不支援。

## 新增接合

1. 繪製兩段，使其首尾相接。若要分割已繪製的構件，將其重新繪製為兩段。
2. 選取其中一段（或兩段），然後在{{ui:連接}}群組的{{ui:更多}}功能表中選擇{{ui:接合}}。
3. 所選各段與同一斷面其他段之間的每個自由接頭都會加入接合。狀態列會顯示數量。

選取接合（點選其中一片板件）即可在右側面板變更其設定。{{ui:套用至相似（n）}}會將接合複製到同一斷面各段之間的其他自由接頭。

## 設定（mm）

| 設定 | 預設值 | 功能 |
|---|---|---|
| 端部間隙 | 10 | 每段各裁短其一半 |
| 螺栓直徑、孔徑、等級、長度餘量 | 20、22、A325、30 | 與端板相同 |
| 翼板覆板厚度 | 12 | 板寬與翼板相同 |
| 翼板螺栓列數（每側） | 3 | 接頭每側橫跨翼板的列數 |
| 翼板螺栓間距 | 75 | 沿構件方向 |
| 翼板螺栓線距 | 0 | 兩條螺栓線之間的距離；0 = 翼板寬度減80 |
| 翼板端距 | 40 | 構件端部至第一顆螺栓，以及最後一顆螺栓至板端 |
| 腹板覆板厚度 | 8 | 腹板兩側各一片 |
| 腹板螺栓列數 | 3 | 沿腹板向上，置中排列 |
| 腹板螺栓行數（每側） | 2 | 沿構件方向，位於接頭每側 |
| 腹板螺栓間距（沿腹板向上 / 沿構件方向） | 75、75 | |
| 腹板端距 | 40 | 與翼板相同 |
| 腹板覆板高度 | 0 | 0 = 圓角之間的淨腹板高度，上下各減10 |
| 板材材質 | A36 | 文字欄位 |

板長由螺栓決定：翼板覆板長度 = 間隙 + 2 ×（2 × 端距 +（列數 − 1）× 間距）；腹板覆板依其行數以同樣方式計算。以預設值計算，翼板覆板長470。

## 注意事項

- 板件屬於兩段中**先繪製的那一段**（其屬性稱為第一段）：板件會顯示在該段的組合圖上，並隨該段一同出貨，以螺栓而非銲接固定。第二段的組合圖只顯示其孔位。
- 翼板螺栓夾緊翼板及其覆板；腹板螺栓夾緊腹板及兩片腹板覆板。螺栓長度另列於屬性中。
- 警告採用與其他接頭相同的 EN 1993-1-8 最小值（端距與邊距為1.2 × 孔徑，沿構件方向的間距為2.2 × 孔徑，橫向的線距為2.4 × 孔徑），另包括腹板覆板深於淨腹板高度，以及翼板螺栓因圓角而離腹板過近的情況。
- DetailCraft不設計接合（不進行強度檢核），也不會為厚度不同的兩段製作填補板。
- 同時複製兩段時會一併複製其接合；刪除任一段都會刪除接合。
