以下為 DetailCraft 0.9 相較於 0.8.1 的變更。0.9 新增英國鋼材尺寸、一次為每個構件產生加工圖、構架用的更大{{ui:分析}}索引標籤，以及協作時檢視彼此游標的功能。

## 新增功能

### 英國鋼材與加工圖

- **英國鋼材尺寸。** 斷面清單現包含 976 個尺寸，取自 Steel for Life Blue Book：UB、UC、PFC、EA、UEA、CHS、SHS 與 RHS，冷成型中空斷面另行分開（名稱以 CF 開頭）。名稱以系列在前書寫，例如 UB305x165x40 或 SHS100x100x5.0；也可依圖說的寫法輸入，例如 305x165x40 UB、L100x100x10、SHS100x5。請見[斷面目錄](topic:profile-catalog)。
- **不等邊角鋼。** UEA 角鋼在透過 IFC 匯入與匯出及 NC 檔時，會保留兩側肢長；鏡射會使構件前後端對調。
- **一次產生所有加工圖。** 在未選取任何物件時，於{{ui:輸出}}群組中選擇{{ui:加工圖}}。視窗會列出每個構件編號，可預覽其中任一項，而{{ui:全部下載}}會儲存為一份 PDF，每個構件編號一頁，各頁標題為「第 3 張，共 42 張」。{{ui:下載 PDF}}則儲存目前所檢視的那一張。槽鋼、角鋼與中空斷面現在也會產生圖紙。請見[製作加工圖](topic:shop-drawings)。
- **我的設定檔。** 自訂設定檔現可保留，供每個新模型使用。在自訂設定檔表單中，保持勾選{{ui:保留於我的設定檔}}；其下的{{ui:我的設定檔}}清單有{{ui:保留}}、{{ui:在此使用}}與{{ui:移除}}。此清單保存於此瀏覽器（最多 200 個），而非你的帳戶。請見[鋼板與設定檔](topic:plates-and-profiles)。

### 分析

- **二階（P-Delta）。** 在{{ui:分析}}索引標籤中，於執行旁勾選{{ui:二階（P-Delta）}}，軸力即作用於變形後的構架。鋼板與剛性樓板仍維持一階，並顯示警告。請見[內力、反力與撓度](topic:frame-analysis)。
- **自然頻率。** 結果下方的{{ui:有限元素：自然頻率}}區塊會求出同一模型的最低振態，包含週期與有效模態質量，並可在模型上顯示某一振態。請見[內力、反力與撓度](topic:frame-analysis)。
- **風載與地震場址。** {{ui:分析}}索引標籤新增三個區塊：{{ui:風力載重（ASCE 7方向性程序）}}、{{ui:地震場址與系統（ASCE 7）}}與{{ui:ASCE 7載重組合}}。請見[風載、地震場址與 ASCE 7 組合](topic:wind-seismic-combinations)。

### 協作

- **游標與名稱。** 在Live工作階段中，每位參與者的指標會以其名稱與顏色繪於模型中，而其所選取的物件會加上方框。
- **跟隨參與者。** 在工作階段中開啟{{ui:參與者}}，並在名稱上選擇{{ui:跟隨}}；你的檢視會隨其移動。主持人可選擇{{ui:要求所有人跟隨我}}。請見[在Live工作階段中跟隨參與者](topic:follow-in-live)。

### 所有應用程式

- 工具提示為 Bootstrap 工具提示；起始提示卡新增關閉按鈕；索引標籤列放不下時可橫向捲動；瀏覽器索引標籤名稱會顯示開啟中的文件，後接 DetailCraft 與 CadCraft。

## 已修正

- 開始新模型時，自訂設定檔會遺失。
- 加工圖集中缺少槽鋼、角鋼與中空斷面。

## 限制說明

- 風載、地震與有限元素區塊為檢核輔助工具。結果需由工程師審查；它們並非規範檢核。USGS 查詢係以替代來源測試，並非於正式線上服務上測試。
- 有限元素與 P-Delta 係以手算與封閉解答進行檢核，未以實際建築物測試。挫屈分析尚未實作。
- 尚無英國加工廠試用英國鋼材尺寸，不等邊角鋼的 NC 檔也尚未在機器上執行。
- 加工圖集僅提供 PDF。
- 英文以外的語言為機器翻譯草稿。
- Windows 安裝程式未經程式碼簽署（請選擇「其他資訊」，再選擇「仍要執行」）；macOS 磁碟映像未經公證（請按右鍵，然後選擇「開啟」）。

較早的變更請見本頁下方的 0.8 與 0.8.1 說明。

## 較早版本：0.8 與 0.8.1

以下為 DetailCraft 0.8（2026年11月1日）與 0.8.1（2026年11月2日）相較於 0.7 的變更。0.7 檢核鋼構件；0.8 規劃吊裝、建議接頭、檢核基礎與鋼筋，並建立木構造與輕型鋼架的牆、樓板與屋頂骨架。

### 新增功能

**吊裝**

- **吊裝計畫與影片。** 在{{ui:吊裝}}索引標籤中，描述起重機（其位置、最高吊鉤，以及不在載重表內的吊掛具），並輸入其載重表的各列數值。DetailCraft 會依階段順序、逐層一次吊裝一個組件，並依各吊次的作業半徑對照載重表，以及你所設定的餘裕檢核每次吊裝。{{ui:儲存影片}}會寫出一個 HTML 檔，可在任何瀏覽器離線播放，手機亦可。超出載重表、超出作業範圍或過高的吊次會列於{{ui:問題}}中。這是依你所輸入數值產生的計畫，並非吊裝計畫。請見[吊裝計畫與影片](topic:erection-movie)。

**連接**

- **連接自動導航。** {{ui:自動導航}}索引標籤會檢視每個沒有連接的接點，並依斷面建議一個連接：底板、剪力板、端板（針對你標記為彎矩樑的樑）、接頭與接合板。輸入均布載重或一端剪力，螺栓數量即依螺栓的設計強度計算。{{ui:全部新增}}會將建議項目一次加入，作為單一復原步驟。這些是供檢閱的起始值，並非連接設計。
- **可施工性檢核。** {{ui:問題}}會列出扳手無法觸及的螺栓、與套筒距離過近的螺栓、角銲尺寸超出限制的銲接，以及會積水的中空斷面。新增銲接可及性：銲槍無法觸及的全周角銲，會列出阻礙的構件及受影響的銲接比例。請見[可施工性檢核](topic:constructability)。

**基礎與鋼筋**

- **基礎檢核。** {{ui:基礎}}索引標籤依你所描述的土壤，檢核基腳、聯合基腳與筏基：由使用載重計算的承壓、滑動與傾覆；由載重係數載重計算的彎矩、剪力、穿剪、握裹長度與最小鋼筋量（ACI 318-19）。靠近邊緣或角落的柱，會以基腳邊緣截去的斷面進行檢核。沉陷由土壤的模數求得，撓性筏基則依地床反力係數以彈簧求解，樁群與擋土牆各自有獨立的面板。柱載重可輸入，亦可取自{{ui:分析}}。請見[基礎檢核](topic:foundation-checks)。
- **鋼筋擁擠度圖。** {{ui:擁擠度}}索引標籤以俯視角度，為每個基腳繪製熱力圖：顯示鋼筋留給混凝土下流的空間不足之處，並以淨間距規定檢核；若你輸入最大骨材粒徑與震動機頭，亦一併納入。請見[鋼筋擁擠度圖](topic:rebar-congestion)。

**骨架與供應**

- **木構造與輕型鋼架骨架。** {{ui:骨架}}索引標籤為牆、樓板與屋頂面板建立所有構件的骨架、切割清單、待購材料，以及按比例繪製的加工圖。{{ui:放置為構件}}會將各構件放入模型，{{ui:PDF 圖紙}}則為每個面板儲存一張圖紙。尺寸、間距與過梁皆由你決定：DetailCraft 不會檢核其是否足以承載。請見[木構造與輕型鋼架骨架面板](topic:framing-panels)。
- **供應商庫存與交期。** {{ui:供應}}索引標籤讀取供應商的庫存清單（CSV），並針對切割清單所需購買的每個斷面，顯示庫存是否足夠以及等待時間。數量不足與延遲的斷面會列於{{ui:問題}}中。不會下單。請見[供應商庫存與交期](topic:supplier-stock)。

**分析與設計**

- **何者先破壞？** 在{{ui:分析}}索引標籤中，此按鈕會找出主控的強度組合、最弱的構件、載重在第一根構件達到其上限前可增加的幅度，以及在其螺栓剪力強度已知時，最弱的端板或剪力板。須先具備組合與設計規範。不檢核承壓、塊狀剪斷、銲接與撬曲。你所連接的助理亦可提出相同要求。
- **Live。** 勾選{{ui:即時：每次編輯後重新求解}}，每次編輯後構架都會重新求解。
- **混凝土及其他。** 無側移構架中的細長柱，依其放大彎矩設計（ACI 318-19 6.6.4.5）。地震週期可依瑞利（Rayleigh）法由分析求得。由鋼板構成的樓板，依各層所需鋼筋由其彎矩與單向剪力求得。請見[檢核混凝土構件與建立地震載重](topic:concrete-and-seismic)。
- **由工程師檢視。** 基礎、混凝土與「何者先破壞？」的結果皆為輔助工具。風載尚未實作。

**所有應用程式**

- **語言。** 說明提供 54 種語言。在母語人士審閱前，英文以外的語言皆為機器翻譯草稿；其中十種為新增（立陶宛語、拉脫維亞語、波士尼亞語、馬拉地語、泰盧固語、阿爾巴尼亞語、南非荷蘭語、菲律賓語、史瓦希里語、烏茲別克語）。
- **工具列列數。** {{ui:設定}} › {{ui:一般}} › {{ui:工具列列數}}可選擇換行、2 列或 1 列。已能放下的工具列維持原狀；其餘的可橫向捲動。
- **屬性格線。** 基腳的欄位使用共用格線：可摺疊的分類與緊湊的密度。輸入的算術運算式（例如 2*450）仍可運作。
- **輸入裝置。** 觸控板、觸控筆、3D 滑鼠、控制器與 MIDI 皆可操作應用程式。請見[在3D中導覽](topic:navigate-3d)。
- **問題面板。** 上述新增檢核的警告會顯示在與先前相同的{{ui:問題}}面板中。
- **連接你的 AI。** 你自己的助理透過 CadCraft Studio 連接，可用於全部八個應用程式，且僅能看到你允許的內容。一鍵連接、代管連接器，以及在 Studio 中使用你自己的 API 金鑰，尚待推出。請見[在DetailCraft中使用 AI 助理](topic:use-with-ai-assistants)。

### 0.8.1 已修正

- **Studio 中的語言。** Studio 與封裝版本可於執行時切換語言；先前僅有英文。尚未在所有平台上測試：若語言未變更，請告知我們。
- **交叉視窗選取。** 0.8.1 安裝程式已包含 0.8 網頁版中正確的視窗選取行為；較舊的安裝程式則未包含。
- **直向平板。** 多餘的格線高度會分配給繪圖區，而圖紙版面於 760 px 或更小時啟用。

### 本版本尚未提供

- **將 NC 送至機器**尚未釋出。
- 混凝土的**風載**尚未實作，而混凝土與基礎檢核由工程師審查。
- **程式碼簽署。** Windows 安裝程式與 macOS .dmg 未經簽署，因此 Windows 可能會發出警告，而 macOS 需要按右鍵，然後選擇「開啟」。

較早的變更請見[0.7 新功能](topic:whats-new-0-7)。
