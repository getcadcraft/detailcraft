DetailCraft內建2,311種尺寸，每一種皆取自已發佈的表格，並由應用程式的測試檢核：由尺寸算出的面積必須與發佈面積相符，且發佈的重量必須等於該面積乘以鋼材密度。鋼板與自訂斷面由其尺寸產生。

## 命名

- **美製型鋼**依AISC Manual的印法書寫，x為小寫：W12x50、C10x15.3、L4x4x1/2、HSS6x6x1/4、HSS6.625x0.280。輸入時不區分大小寫。
- **鋼管**依AISC資料庫的寫法：Pipe4STD、Pipe4XS、Pipe4XXS（標準、加厚、特加厚）。
- **歐規型鋼**依EN 10365的寫法：IPE200、HEA240、HEB300、UPN200（中間無空格）。
- **英規型鋼**先寫系列名稱，再接Blue Book的尺寸：UB305x165x40、UC203x203x46、PFC200x90x30、EA100x100x10.0、UEA150x90x10.0、SHS100x100x5.0、RHS200x100x8.0、CHS88.9x5.0。冷成形中空型鋼以CF開頭：CFSHS100x100x5.0。依圖面常見寫法輸入也可行：305x165x40 UB、L100x100x10、SHS100x5。
- **鋼板**為`PL<厚度>x<寬度>`，單位為毫米：PL20x200表示厚20 mm、寬200 mm。任何尺寸皆可在{{ui:板}}工具中使用。
- **自訂斷面**可使用任何名稱，只要不是目錄名稱，且不類似鋼板名稱即可。

在{{ui:斷面}}清單中，每個群組的標題會註明其來源，例如「W shapes — AISC Shapes Database v16.0」。

## 來源

| 群組 | 來源 | 說明 |
|---|---|---|
| W shapes、S shapes、槽鋼（C）、角鋼（L）、HSS、Pipe | AISC Shapes Database v16.0 | 尺寸由英吋精確換算為毫米；每公尺質量由發佈的lb/ft換算 |
| IPE、HEA、HEB、UPN | EN 10365:2017 | 毫米與kg/m依發佈值 |
| UB、UC、PFC、EA、UEA、SHS、RHS、CHS、CFSHS、CFRHS、CFCHS | Steel for Life Blue Book (UK), table v18 (BS EN 10365, BS EN 10056-1, BS EN 10210-2, BS EN 10219-2) | 毫米與kg/m依發佈值 |
| 鋼板 | 參數化 | 質量 = 面積 × 7850 kg/m³ |
| 自訂 | 自行輸入的尺寸 | 質量 = 面積 × 7850 kg/m³ |

型鋼的繪製方式：

- **W shapes：** AISC資料庫未提供圓角半徑，因此DetailCraft將圓角繪為r = kdes − tf。
- **S shapes與槽鋼（C、UPN）：** 翼板為平行，採發佈的平均厚度，直角轉角（實際翼板為斜面）。
- **角鋼：** 直角轉角。
- **矩形HSS：** 設計壁厚（0.93 × 標稱值，依AISC 360-22 B4.2允許），外角半徑為其兩倍。
- **圓形HSS與Pipe：** 設計壁厚（0.93 × 標稱值）。
- **IPE、HEA、HEB、UB、UC：** 採發佈的根部半徑。
- **PFC、EA、UEA：** 直角轉角（發佈的質量與面積仍包含圓角）。
- **SHS、RHS、CHS：** 標稱壁厚。熱加工轉角：外圓角1.5 t、內圓角t。冷成形：壁厚至6 mm時外圓角2 t、內圓角t；至10 mm時為2.5 t與1.5 t；超過10 mm時為3 t與2 t。

## 各斷面可做的事

| 斷面 | 孔 | 切角 | 端板與底板 | NC檔 | 加工圖 |
|---|---|---|---|---|---|
| 工字型（W、S、IPE、HEA、HEB、UB、UC、自訂工字型） | 腹板、上翼板、下翼板 | 是 | 端板：樑與柱。底板：是 | 是 | 是 |
| 槽鋼（C、UPN、PFC） | 腹板、上翼板、下翼板 | 否 | 僅底板 | 是 | 是 |
| 矩形HSS、SHS、RHS | 側壁（腹板）、上、下 | 否 | 僅底板 | 是 | 是 |
| 圓形HSS、Pipe、CHS | 尚未支援 | 否 | 僅底板 | 是 | 是 |
| 角鋼（L、EA、UEA） | 尚未支援 | 否 | 僅底板 | 是 | 是 |
| 鋼板與自訂扁鋼 | 板面 | 否 | 否 | 是 | 是 |

對於矩形管，「腹板」面上的孔會貫穿兩側壁。各NC檔所包含的內容見[NC檔欄位](topic:nc1-fields)。

## 需要其他尺寸嗎？

將其新增為[自訂斷面](topic:plates-and-profiles#add-a-custom-profile)即可。內建清單目前無法在應用程式中編輯。
