本主題說明矩形獨立基腳。梁、柱、樓板與牆請見[鋼筋混凝土細部](topic:reinforced-concrete)。每個基腳在兩個方向各有底層網片，如需要，也可加上向上伸出的續接鋼筋。鋼筋使用美制編號 #3 至 #11。

## 放置基腳

1. 選擇{{ui:平面}}，並指定基腳頂面所在的樓層。
2. 在{{ui:放置}}群組中選擇{{ui:基腳}}，或按{{key:F}}鍵。
3. 在{{ui:屬性}}面板中設定基腳（見下文），或保留預設值。
4. 點選格線交點。基腳會以該點為中心放置，頂面位於該樓層。狀態列會顯示例如「基腳 2000 x 2000 x 600，位於 A/1 下方。」

也可以使用面板底部的{{ui:依格線新增}}表單。

基腳以透視方式繪製，方便看見其中的鋼筋；鋼筋以實心管線顯示。

## 基腳設定

| 欄位 | 預設 | 說明 |
|---|---|---|
| 長度 L（mm） | 2000 | 沿 x 方向；300 至 50000 |
| 寬度 B（mm） | 2000 | 沿 y 方向；300 至 50000 |
| 深度 H（mm） | 600 | 150 至 10000 |
| 混凝土 | 4000 psi | 文字；會寫入 IFC 匯出檔 |

**底層網片**

| 欄位 | 預設 | 說明 |
|---|---|---|
| 長向鋼筋 | #5 | 沿 L 方向配置的鋼筋，位於下層 |
| 間距（mm） | 250 | 允許的最大間距；鋼筋會以此間距或更密均勻配置 |
| 短向鋼筋 | #5 | 沿 B 方向配置，置於長向鋼筋之上 |
| 間距（mm） | 250 | 同上 |
| 保護層（mm） | 75 | 每個面的淨保護層 |
| 端部彎鉤 | 開啟 | 將每根網片鋼筋的兩端向上彎成標準 90° 彎鉤（形狀 U）；關閉則為直鋼筋（形狀 S） |

**續接鋼筋**

| 欄位 | 預設 | 說明 |
|---|---|---|
| 續接鋼筋 | 開啟 | 關閉可用於不設續接鋼筋的基腳 |
| 鋼筋 | #6 | |
| 沿 L 的鋼筋數 / 沿 B 的鋼筋數 | 2 / 2 | 以基腳為中心排列成一組鋼筋 |
| 沿 L 的間距 / 沿 B 的間距 | 250 / 250 | 鋼筋中心之間的距離 |
| 頂面以上伸出長度 | 600 | 鋼筋自基腳頂面向上伸出的長度 |
| 底部彎鉤 | 開啟 | 向外的 90° 彎鉤，置於網片上（形狀 L） |

在欄位下方，DetailCraft 會顯示長向鋼筋的鉤腳長度，例如「#5 的鉤腳長度：254 mm，外緣至外緣。」

## 修改已放置的基腳

選取基腳（點選遠離柱的混凝土，或點選其中一根鋼筋）。除了上述欄位外，還會出現{{ui:中心 x}}、{{ui:中心 y}}、{{ui:頂部 z}}與{{ui:旋轉（°）}}。其下方的表格會列出此基腳的鋼筋、編號、數量與長度，以及混凝土體積（立方公尺）。

每項變更在保留前都會先檢查。無法施工的變更會被拒絕，狀態列會說明原因，例如「保護層不留給此基腳任何鋼筋的空間。」、「基腳深度不足以在保護層內配置兩層鋼筋。」或「在 75 mm 保護層下，續接鋼筋無法放入此基腳內。」

可以施工但需要檢視的變更，會列在基腳下方，也會列在{{ui:問題}}索引標籤中：

- 「#11 鋼筋間距 59.6 mm，淨距小於 35.8 mm（ACI 318-19 25.2.1）。」鋼筋之間的淨距至少須等於鋼筋直徑，且至少 25.4 mm。
- 「#5 彎鉤需要 254 mm 的深度；保護層內只容得下 150 mm。」此時鉤腳會截短以符合空間，因此不再是標準彎鉤。
- 「續接彎鉤伸入保護層。」
- 「續接鋼筋之間的距離小於最小淨間距。」

## 鋼筋編號與鋼筋加工表

所有基腳中，尺寸、形狀與各段尺寸完全相同（精確到毫米）的鋼筋，共用同一個鋼筋編號。編號格式為`<鋼筋號碼>F<n>`，例如 5F1、5F2 代表 #5 鋼筋，6F1 代表第一根 #6 鋼筋，依此類推。尺寸、混凝土、網片與續接鋼筋皆相同的基腳，共用同一個基腳編號：F1、F2……

1. 開啟底部的{{ui:彎折表}}索引標籤。每列代表一個鋼筋編號：尺寸、形狀、尺寸 A、B、C、數量、切割長度、總長度、每公尺重量、每根重量、總重量，以及此鋼筋的用途。
2. 在索引標籤中選擇{{ui:下載 CSV}}，或在{{ui:輸出}}群組的{{ui:更多}}功能表中選擇{{ui:彎折}}，即可下載`<name> bending schedule.csv`。

形狀為 DetailCraft 自訂的代碼，並非任何標準：S 為直鋼筋，L 為一次彎折，U 為兩次彎折。尺寸為外緣至外緣；切割長度為經過彎折處的精確中心線長度。請見[鋼筋參考](topic:rebar-reference)。

## DetailCraft 不檢核的項目

- 伸展長度與搭接長度，以及續接鋼筋是否足以延伸到上方的柱。
- 淨間距規則中關於骨材粒徑的部分（DetailCraft 不知道混凝土配比）。
- 上方柱或底板的任何事項：基腳與鋼材是分開的。
