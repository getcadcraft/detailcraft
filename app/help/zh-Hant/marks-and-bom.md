DetailCraft 會自行為模型加上標記。沒有編號指令，也無需執行任何動作：每次變更後，它都會判斷哪些零件為同一件鋼材，並賦予其一個標記。

## 標記顯示位置

- {{ui:模型}}面板中的{{ui:零件編號}}清單：每個標記附其斷面、長度與數量。按一下某個標記即可選取第一個具有該標記的零件。
- 所選構件的{{ui:屬性}}面板（以及左側面板中的**零件編號**清單）：{{ui:零件編號}}與{{ui:組合件}}。面板標題也會顯示標記，例如「樑 b1」。
- {{ui:材料清單}}索引標籤、CSV、NC 檔名稱、加工圖，以及 IFC 匯出（作為每個元素的標籤）。

## 零件如何標記

- **零件編號：**c 為柱、b 為樑、br 為斜撐、st 為樓梯斜梁、p 為板（包括端板與底板）。再加上數字：c1、c2、b1、p1 …。當零件分布於一個以上的階段時，階段編號置於最前，例如 2-b1。
- **組合件標記：**C、B、BR 或 P。組合件由一根主構件及焊接於其上的板組成，例如樑加上其兩端板，或柱加上其底板。
- 兩個零件若斷面、材料與切割長度相同，且孔與切角皆在 1 mm 之內，即共用一個標記，即使其中一個相對另一個調轉頭尾或上下翻轉。
- 編號順序為先柱，再樑、斜撐與板；在每類之內，依斷面名稱，由最長者開始。

完整規則，包括對槽形與角鋼而言哪些翻轉算數：[標記規則](topic:mark-rules)。

:::warning
每次變更後標記都會重新計算，因此可能重新編號。新增零件、變更斷面或新增孔，都可能使 b3 變為 b4。只有在模型完成後才將標記視為定稿，並從同一已儲存的模型製作材料清單、NC 檔與加工圖。
:::

## 閱讀材料清單

在底部開啟{{ui:材料清單}}索引標籤。它有三個表格。

**零件**，標題中含鋼材總重：

| 欄 | 意義 |
|---|---|
| 零件編號 | 按一下即選取第一個具有此標記的零件 |
| 類型 | 樑、柱、斜撐、樓梯斜梁或板 |
| 斷面 | 例如 W16x26 或 PL20x180 |
| 材料 | 所設定的等級 |
| 長度 (mm) | 連接後的切割長度 |
| 數量 | 件數 |
| 單位重 (kg) | 斷面每公尺質量 × 長度 |
| 總重 (kg) | 單位重 × 數量 |

最後一列為總數量與總重。

**組合件：**每個組合件標記、其主零件、所有零件（例如「b1 + p1 + p1」）、數量、單位重與總重。

**螺栓與錨栓：**依種類、直徑、長度與等級分組，附數量。

:::note
重量為毛重：孔與切角不予扣除。螺栓、螺帽、墊圈與焊縫不計入鋼材重量。
:::

## 下載

在索引標籤中選擇{{ui:下載 CSV}}，或在{{ui:輸出}}群組中選擇{{ui:材料表}}。檔案 `<name> BOM.csv` 依序包含三個表格，每個表格下有其標題，表格之間以空白行分隔。可在任何試算表程式中開啟。

## 送出前檢查

1. 開啟{{ui:問題}}索引標籤，清除每一行。無法建立的連接不會新增板、孔或螺栓，因此材料清單會短缺。
2. 留意非預期的標記。若應該相同的兩根樑卻有不同標記，通常是因為孔、切角或切割長度不同；請分別選取並比較。
3. 儲存模型，然後從已儲存的狀態進行所有匯出。
