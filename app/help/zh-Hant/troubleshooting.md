大多數拒絕操作的原因，都會顯示在畫面底部的狀態列，或{{ui:問題}}索引標籤中。應先查看這些內容。以下訊息均依DetailCraft的顯示方式引用。

## 3D檢視遺失

**「此瀏覽器無法啟動3D圖形（WebGL）。模型、報告與匯出仍可使用。」**

瀏覽器無法啟動WebGL，即DetailCraft繪製3D圖形所使用的技術。

1. 將瀏覽器更新至最新版本。
2. 開啟硬體加速並重新啟動瀏覽器（見下文）。
3. 更新顯示卡驅動程式，或改用其他瀏覽器。遠端桌面與虛擬機器通常不支援WebGL。
4. 同時仍可繼續工作：使用{{ui:依格線新增}}表單放置構件、查看報告並匯出。只有在檢視中點選時才需要WebGL。

:::chromium
要開啟硬體加速，請開啟**設定、系統**，並開啟**可用時使用圖形加速功能**，然後重新啟動瀏覽器。
:::

:::firefox
要開啟硬體加速，請開啟**設定、一般、效能**，取消勾選**使用建議的效能設定**，並勾選**可用時使用硬體加速**。重新啟動Firefox。
:::

:::safari
Safari預設已開啟WebGL。若檢視仍無法啟動，應更新macOS，並確認沒有擴充功能阻擋它。
:::

更多資訊請見[瀏覽器與電腦](common:browsers)。

## 在檢視中點選無反應

- **點選處附近沒有交點。**放置工具只會吸附至格線交點。若點選位置遠離所有圓點，則不會有任何反應。移近至圓點亮起為止。
- **目前工具為{{ui:選取}}，且點選了空白處。**這會清除選取。
- **曾經拖曳。**按下與放開之間的距離超過數個像素即視為拖曳：會旋轉或平移檢視。
- **零件已被剖切掉。**在{{ui:平面}}與{{ui:立面}}中，剖切範圍以外的鋼材會被隱藏，無法點選。切換至{{ui:3D}}。
- **交點位於錯誤的樓層。**在{{ui:3D}}中，多個樓層的交點可能在畫面上重疊；點選會取最近的一個。改用{{ui:平面}}或{{ui:立面}}。

## 放置訊息

| 訊息 | 處理方式 |
|---|---|
| 柱無法到達Level 2以上，因為沒有更高的樓層。先新增樓層。 | 在{{ui:樓層}}中新增樓層，或點選較低的樓層 |
| 為另一端選取不同的交點。 | 兩次點選了同一點 |
| 兩端為同一點。 | 在{{ui:依格線新增}}中，"From"與"To"的選點相同 |
| 在左側新增格線，才能放置構件。 | 模型在某一方向沒有格線 |
| 未知的斷面"…" | 該斷面不在目錄或模型的自訂斷面中。從清單中選擇一種。 |
| 輸入數字。 | 數字欄位為空白，或含有文字 |

## 接頭無法建立

### 「此梁的端部不在柱線上。」

端板要求梁的端部恰好位於垂直柱的線上，且介於柱的底部與頂部之間（誤差1 mm以內）。檢查梁的{{ui:端部（x、y、z mm）}}與柱的位置。

### 「此梁接入柱腹板或以斜角相接」

或在{{ui:問題}}中顯示：「接入柱腹板的梁尚未實作：將柱旋轉90°或改用其他接頭。」

梁接入柱腹板。選取柱並將{{ui:旋轉（°）}}設為90，然後再試一次。斜向接頭尚未實作。

### 「端板僅適用於水平梁（此梁為斜向）。」

梁的兩端必須位於相同高度。

### 「端板要求梁直立（旋轉為0）。」

將梁的{{ui:旋轉（°）}}重新設為0。

### 「端板需要I型梁。」／「端板需要I型柱。」

只有I型斷面（W、IPE、HEA、HEB或自訂I型）可使用端板。

### 「梁端已不在柱線上。」

在加入接頭後移動了梁或柱。將其移回，或刪除接頭。

### 「接頭已將此構件全部切除。」

兩端的接頭切除的長度超過構件長度，例如兩根深柱之間的極短梁。檢查構件端部與板厚。

### 「沒有其他類似、尚未有接頭的接頭…」

{{ui:相似}}只會複製到梁斷面、柱斷面與接頭類型相同（梁接入翼板），且尚未有接頭的接頭。

### 「兩端已有接頭。」／「此柱已有底板。」

選取既有接頭即可變更，或先將其刪除。

## 問題索引標籤中的警告

警告不會阻止接頭或基礎建立，僅提示需要檢查。邊距與間距警告採用EN 1993-1-8表3.3的最小值（邊距1.2 × 孔徑、間距2.2 × 孔徑、線距2.4 × 孔徑）。若專案採用其他規範，警告可能不適用；DetailCraft不設計接頭。

「孔位於零件端部之外」表示孔的x小於0，或大於切割長度。需注意x是從切割起點算起，並且是在接頭將零件裁短之後計算。

## 基礎變更遭拒

| 訊息 | 處理方式 |
|---|---|
| 保護層使此基礎無空間容納鋼筋。 | 加大基礎，或減小保護層 |
| 基礎深度不足以在保護層內容納兩層鋼筋。 | 加深基礎，或減小保護層 |
| 在保護層75 mm下，續接鋼筋無法放入基礎內。 | 減少續接鋼筋數量、縮小間距，或加大基礎 |
| 鋼筋間距必須為50–1000 mm。 | 輸入該範圍內的間距 |
| 長度必須為300–50000 mm。 | 基礎尺寸有其限制：長度與寬度為300至50000，深度為150至10000 |

## 格線與樓層遭拒

| 訊息 | 處理方式 |
|---|---|
| 編號格線：每兩條線之間需給定一個間距（4）。 | 計算間隔數：五條線需要四個間距 |
| 字母格線：間距必須為正的毫米值。 | 不可為零、負值或文字 |
| 編號格線：格線標籤必須不同。 | 兩條線有相同的標籤 |
| 每個方向最多60條格線。 | 將模型拆分 |
| 至少保留一個樓層。 | 所有樓層列都已被刪除 |
| 每個樓層都需要名稱。／兩個樓層名為「…」。 | 為每個樓層指定不同的名稱 |

## 開啟檔案失敗

| 訊息 | 原因 |
|---|---|
| DetailCraft只開啟自有模型（.detailcraft.json）。IFC匯入尚未實作。 | 該檔案不是`.json`檔 |
| 這不是DetailCraft模型（不是JSON）。 | 檔案已損壞，或為其他JSON檔案 |
| 這不是DetailCraft模型。 | 來自其他程式的JSON檔案 |
| 此模型由較新版本的DetailCraft（格式2）儲存。 | 以儲存它的較新版DetailCraft開啟 |
| 該檔案過大，無法作為DetailCraft模型。 | 超過50 MB |

檔案開啟時若出現類似「2個構件無效，已略過。」的警告，其餘模型仍然正常。在檢查被略過的內容前，不要覆寫原檔。

## 匯出

| 訊息 | 原因 |
|---|---|
| 尚無可匯出的內容。 | 模型為空時的{{ui:IFC}} |
| 沒有可寫入NC檔的I型或板件零件。 | 模型中只有槽鋼、角鋼或管材 |
| 未寫入（目前僅支援I型與板件）：… | 這些零件編號不是I型或板件；其餘已寫入。 |
| 沒有基礎，因此沒有可排程的鋼筋。 | 沒有基礎時的{{ui:彎折}} |
| …個字元不在PDF字型內，已列印為「?」。 | 模型名稱或等級含有PDF字型缺少的字元 |

模型尚無零件時，{{ui:加工圖}}會呈灰色停用。

## 下載不會出現

每次儲存與匯出都是瀏覽器下載。檢查瀏覽器的下載清單。若瀏覽器在下載多個檔案前要求確認，或封鎖此網站的下載，請允許。在Safari中，檢查工具列上的下載按鈕。

## 按鍵無反應

- 游標位於文字或數字欄位中：此時工具按鍵與{{key:Delete}}鍵會被忽略，以便輸入。按{{key:Tab}}鍵或點選檢視。
- 開啟了對話方塊：先關閉對話方塊。
- 瀏覽器持有鍵盤焦點（例如網址列）：點選DetailCraft內部。
- {{key:Ctrl+Shift+F}}即使在Mac上也使用Control鍵。

## 離線問題

應用程式列中的{{ui:儲存供離線使用}}按鈕會顯示離線副本的狀態。儲存方式請見[離線工作](common:offline)。

| 按鈕顯示 | 意義 | 處理方式 |
|---|---|---|
| {{ui:儲存供離線使用}} | 此瀏覽器尚無離線副本 | 於線上時點選此按鈕 |
| 正在儲存（5 / 20） | 儲存進行中 | 等待{{ui:可離線使用}}出現；保持分頁開啟 |
| {{ui:可離線使用}} | DetailCraft、其3D檢視、所有匯出與本說明都可在無連線時使用 | 無需處理。點選可執行{{ui:重新儲存（取得最新版本）}}或{{ui:移除離線副本}} |
| {{ui:無法儲存}} | 部分檔案未能下載 | 檢查網路連線，然後點選以重試 |
| {{ui:無法離線使用}} | 此視窗無法保留離線副本：私密視窗與部分受管理的電腦會封鎖此功能 | 使用一般視窗，或改為線上工作 |

若目前離線，且按鈕未顯示{{ui:可離線使用}}，不要重新載入或關閉分頁：已載入的內容仍可繼續使用。以{{key:Mod+S}}儲存模型，並等待恢復線上連線。

## 尚未儲存的工作

若瀏覽器詢問是否離開頁面，表示DetailCraft有尚未儲存的變更。選擇留在頁面，然後按{{key:Mod+S}}。關閉分頁後，DetailCraft無法復原模型。
