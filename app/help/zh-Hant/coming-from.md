如果你使用 Tekla Structures 進行細部設計，DetailCraft 的大部分功能都會讓你感到熟悉：格線、標高、來自目錄的斷面、零件與組合件、接頭、編號、NC 檔、IFC。規模則相差很大：Tekla Structures 是完整的生產系統，而 DetailCraft 是一款小型、早期的瀏覽器應用程式，能端到端完成少數工作。本頁說明你的習慣哪些可以沿用，哪些則不能。

:::tip
如果你習慣 Tekla Structures 的功能區，請在 {{ui:設定}} › {{ui:DetailCraft}} › {{ui:功能表、快速鍵與滑鼠}} 中選擇 {{ui:鋼構功能區}} 功能表樣式：提供建模、細部設計、編輯、圖面、加工與檢視等索引標籤，且中鍵可平移。若你來自 AutoCAD 並習慣輸入指令，{{ui:經典繪圖}} 會加入指令列（BEAM、COLUMN、ENDPLATE、ZOOM …）。參見 [功能表、快速鍵與滑鼠](topic:menus-keys-and-mouse)。
:::

## 快速對照

| 你習慣的 | 在 DetailCraft 中 |
|---|---|
| 在格線對話方塊中以座標建立格線 | 左側面板中的 {{ui:格線}}：以標示與各線之間的間距設定，而非絕對座標。編號的線朝一個方向，字母的線朝另一個方向 |
| 將標高視為格線的 Z 座標 | 獨立的 {{ui:樓層}} 清單，每列有名稱與高程，並以 {{ui:套用樓層}} 套用 |
| 以捕捉在任意位置取點 | 按一下只會捕捉到格線交點。不在格線上的點需輸入到構件的 {{ui:端部（x、y、z mm）}} 中 |
| 柱、樑與板的指令 | {{ui:柱}}（{{key:C}}）、{{ui:樑}}（{{key:B}}）、{{ui:斜撐}}（{{key:R}}）、{{ui:板}}（{{key:P}}）、{{ui:基腳}}（{{key:F}}） |
| 零件屬性對話方塊（連按兩下零件） | 按一下即可：右側的 {{ui:屬性}} 面板隨時可用；沒有對話方塊，也沒有「修改」或「套用」按鈕 |
| 平面上的位置、旋轉與深度設定 | {{ui:位置}}（鋼料頂部、置中或位於線的底部）與 {{ui:旋轉（°）}}。沒有獨立的水平偏移 |
| 斷面目錄 | 固定清單，共 2,311 種已公布的尺寸（AISC W、S、C、L、HSS、Pipe；歐規 IPE、HEA、HEB、UPN；英規 UB、UC、PFC、EA、UEA、SHS、RHS、CHS，以及冷彎中空斷面），另有參數化的板與你自己的 {{ui:自訂斷面}} |
| 材料目錄 | 清單中有七種等級：A992、A36、A572 Gr 50、A500 Gr C、S235、S275、S355 |
| 套用接頭元件及其對話方塊 | 選取樑，然後選擇 {{ui:端板}}。設定會出現在 {{ui:屬性}} 面板中。只有兩種接頭（端板連接柱翼緣、底板） |
| 自動接頭，或將接頭複製到相似接頭 | 選取接頭，然後選擇 {{ui:套用到相似項 (n)}} |
| 以系列與起始編號編號 | 沒有指令：編號會在每次變更後自動更新，前置字元固定為 c、b、br、p，以及 C、B、BR、P |
| 螺栓與孔洞對話方塊 | 孔洞依面與位置輸入。螺栓只能由接頭產生 |
| 切割、配合與多邊形切割工具 | 扣口（頂部或底部，位於任一端）僅適用於 I 形斷面。接頭的切短為自動 |
| 報表與範本 | 底部索引標籤中有三種固定報表，以及 CSV 下載 |
| 圖面建立與圖面清單 | 每個構件標記對應一張加工圖，全部一次建立，先預覽，再以一個 PDF 或逐張圖紙下載。不會保存或編輯 |
| NC 檔匯出 | {{ui:NC 檔}}：每個構件標記一個 DSTV 檔，僅限 I 形與板，並壓縮成 zip |
| IFC 匯出 | {{ui:IFC}}：整個模型的 IFC4，包含鋼筋 |
| 任何混凝土構件中的鋼筋 | 鋼筋僅適用於矩形墊式基腳，採美規鋼筋尺寸，含底層網與續接鋼筋 |
| 儲存於專案資料夾、多人使用 | 一個你下載的 `.detailcraft.json` 檔案。單人使用，在你的電腦上 |
| 復原紀錄 | {{key:Mod+Z}} 與 {{key:Mod+Y}}，最多 200 步，直到你開啟或開始另一個模型為止保留 |

## 容易讓人出錯的差異

### 編號會自動變動

沒有編號步驟。編號會在每次變更後重新計算，因此永遠是最新的，但也可能重新編號：新增一根柱後，昨天的 c3 可能變成 c4。沒有可保留舊編號的「編號紀錄」。完成模型後，再從同一個已儲存的檔案一併產出材料清單、NC 檔與加工圖。

### 中鍵是縮放，不是平移

在 3D 視圖中：左鍵拖曳旋轉，右鍵拖曳平移，滾輪縮放，而以中鍵拖曳同樣會縮放。按住 {{key:Shift}} 同時左鍵拖曳，也可以平移。滾輪會朝視圖的中央縮放，而非朝指標。沒有選取旋轉中心的功能：模型會繞著視圖中央旋轉。參見 [在 3D 視圖中移動](topic:navigate-3d)。

### 預設時柱面朝向固定

在旋轉角度為 0 時，柱的翼緣沿著編號格線的方向。跨在字母格線之間的樑會接到柱的腹板上，而此處的端板會被拒絕（「接到柱腹板的樑尚未實作」）。在加入接頭之前，請先將這些柱旋轉 90°。

### 立面只能沿字母格線

{{ui:立面}} 只沿字母格線方向觀看。沒有沿編號格線的視圖，也沒有儲存的視圖與工作平面。若要建立編號格線上的框架，請使用 {{ui:3D}} 或 {{ui:依格線新增}}。

### 選取、複製與移動

以 {{key:Shift}}+點按或 {{key:Mod+A}} 選取多個零件，然後複製、剪下、貼上（在格線交點、在輸入的偏移量處，或原位貼上），並建立副本，接頭一併包含（[複製、貼上與建立副本](topic:copy-paste)）。沒有視窗選取、沒有選取篩選、沒有移動、鏡像或陣列，且屬性須在 {{ui:屬性}} 面板中逐一構件修改。

### 格線不會連帶移動構件

變更格線間距時，構件會保持其座標；沒有任何東西會隨格線移動。請先變更格線再放置鋼構，或之後逐一編輯每個構件的端點座標。

### 接頭不經設計

兩種接頭依你所給的數值放置板、孔、螺栓與焊接。沒有任何形式的設計檢查，只有邊距與間距的警告（來自 EN 1993-1-8 表 3.3）。

### 3D 視圖中不會切出孔

孔以深色的塞子顯示。它們在 NC 檔、加工圖與 IFC 檔中是真正的孔。扣口會在視圖中切出。

### 重量為毛重

鋼料重量不會扣除孔或扣口，螺栓重量也不計入。

### 只使用毫米

所有數值都以毫米輸入與顯示，即使是 AISC 斷面亦然。斷面名稱保留其公布的形式（W12x50、HSS6x6x1/4）。

### 不需管理圖面

沒有圖面清單、沒有圖面編輯器，也沒有總體配置圖或組合圖。加工圖是在你要求時建立並下載的；若要變更，請修改模型後重新建立。

### 在瀏覽器中執行

儲存會下載一個檔案。瀏覽器自己保留的快速鍵無法使用。你的模型絕不會離開你的電腦：參見 [檔案的去向](common:your-files)。

## 目前仍應繼續使用你現有的軟體

目前 DetailCraft 適合小型框架、驗證想法、教學，或為簡單的樑柱工作產出 NC 檔與加工圖。複雜接頭、總體配置圖、安裝圖、多人專案，以及 [尚未實作的功能](topic:not-built-yet) 中列出的任何項目，請仍在你目前使用的軟體中處理。
