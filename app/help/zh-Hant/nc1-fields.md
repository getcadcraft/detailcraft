每個`.nc1`檔描述一個零件編號。每行以CR LF結尾。文字欄位僅使用純ASCII；其他字元會變為"?"。第二行為註解，格式為`** DetailCraft <mark>.nc1`。

## 表頭（ST）

| 欄位 | 工字型、槽鋼 | 角鋼 | 矩形HSS | 圓形HSS | 鋼板 |
|---|---|---|---|---|---|
| 訂單 | 模型名稱 | ← | ← | ← | ← |
| 圖號、件號 | 零件編號 | ← | ← | ← | ← |
| 階段 | 零件的階段，或1 | ← | ← | ← | ← |
| 鋼材品質 | 材料等級 | ← | ← | ← | ← |
| 數量 | 具有此編號的零件數 | ← | ← | ← | ← |
| 斷面 | 斷面名稱，例如W16x26 | ← | ← | ← | `PL<t>*<width>` |
| 斷面代碼 | I或U（槽鋼） | L | M | RO | B |
| 長度 | 下料長度 | ← | ← | ← | 長度 |
| 高度 | 深度d | 肢 | 高度 | 直徑 | 板寬 |
| 翼板寬度 | bf | 肢 | 寬度 | 直徑 | 0 |
| 翼板厚度 | tf | t | 壁厚t | 壁厚t | 0 |
| 腹板厚度 | tw | t | 壁厚t | 壁厚t | 板厚 |
| 半徑 | 圓角半徑（AISC槽鋼為0） | 0 | 外角半徑 | 0 | 0 |
| 每公尺重量 | kg/m | kg/m | kg/m | kg/m | kg/m² |
| 每公尺塗裝面積 | 外周長，m²/m | ← | ← | ← | 2（兩面，m²/m²） |
| 鋸切角度（4個欄位） | 0（直角） | ← | ← | ← | ← |
| 文字欄位（4個） | `-` | ← | ← | ← | ← |

鋼板依標準的「板材用」欄位。標準中沒有圓管的欄位：DetailCraft將直徑寫為高度與翼板寬度，並將壁厚寫為兩個厚度欄位。

## 外輪廓（AK）

- **工字型與槽鋼：** 腹板（v），每個切角處有一個矩形缺口；每條翼板（o與u）在切角深度不小於翼板時，於該端縮短。
- **矩形HSS：** 兩側壁（v與h）為切角挖去缺口，以及上、下壁（o與u）。
- **角鋼：** 每肢一個矩形（v與u）。角鋼上的切角不會寫入：此類零件會列為未寫出。以螺栓接於[接合板](topic:brace-gussets)的角鋼斜撐，其孔位於被螺栓接的肢上：沿零件u方向的肢為v，沿零件v方向的肢為u。
- **圓形HSS：** v面一個矩形，即從正面看管材（長度 × 直徑）。
- **鋼板：** 面v上一個矩形。

每個輪廓皆封閉（起點在結尾重複一次），並以逆時針方向繪製。

## 孔（BO）

每個孔一行：面、x、y、直徑、深度0（貫穿）。所有孔皆包括在內，包括手動輸入的孔與接合產生的孔。貫穿矩形HSS側壁的孔會寫入兩次，一次在v面、一次在h面。

## 面與座標

每個斷面依標準的斷面位置圖式放置（DSTV 1998，第7頁）：x沿零件方向，Y橫跨，Z由背面向上，零點位於外角。DetailCraft從不為了符合圖式而鏡射零件。

| 面 | 工字型 | 槽鋼 | 角鋼 | 矩形HSS | 鋼板 |
|---|---|---|---|---|---|
| v | 腹板，正面 | 腹板，從翼緣端側看 | 沿零件u方向的肢 | −u側壁 | 板面 |
| h | | | | +u側壁 | |
| o | 上翼板 | **下**翼板 | | 上壁 | |
| u | 下翼板 | **上**翼板 | 沿零件v方向的肢 | 下壁 | |

- **x**沿零件方向，從其切割起點算起。
- **工字型與矩形HSS：** 腹板或側壁上的y從斷面底面量起；翼板或上、下壁上的y從其背面側邊緣量起（零件的+u側）。
- **槽鋼**平放於背面、翼緣端朝上，如標準圖式所示。因此腹板上的y從上翼板外側向下延伸，上翼板為u面，下翼板為o面，翼板上的y從腹板背面朝翼緣端延伸。
- **角鋼：** 每肢上的y從肢根量起。
- **鋼板：** y從鋼板的−u邊緣量起。

切割前，確認機器軟體如何讀取槽鋼的面：有些程式會將槽鋼上下翻轉。

## 未寫出的內容

斜切、內輪廓、標記（SI）、非直角的鋸切角度、長孔、圓管上的孔（DetailCraft沒有此功能），以及角鋼與圓管上的切角。
