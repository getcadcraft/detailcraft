대부분의 거부 사유는 화면 아래의 상태 표시줄이나 {{ui:문제}} 탭에 설명되어 있습니다. 먼저 이 메시지들을 확인하는 것이 좋습니다. 아래 메시지는 DetailCraft에 표시되는 그대로 인용했습니다.

## 3D 화면이 보이지 않음

**"이 브라우저에서 3D 그래픽(WebGL)을 시작할 수 없습니다. 모델, 보고서 및 내보내기는 계속 작동합니다."**

브라우저가 DetailCraft가 3D 그래픽을 그리는 데 쓰는 WebGL을 시작하지 못했습니다.

1. 브라우저를 최신 버전으로 업데이트합니다.
2. 하드웨어 가속을 켜고 브라우저를 다시 시작합니다(아래 참고).
3. 그래픽 드라이버를 업데이트하거나 다른 브라우저를 사용합니다. 원격 데스크톱과 가상 머신에는 WebGL이 없는 경우가 많습니다.
4. 그동안에도 작업할 수 있습니다. {{ui:축선으로 추가}} 양식으로 부재를 배치하고, 보고서를 읽고, 내보낼 수 있습니다. WebGL이 필요한 것은 화면을 클릭하는 작업뿐입니다.

:::chromium
하드웨어 가속을 켜려면 **설정, 시스템**을 열고 **가능한 경우 그래픽 가속 사용**을 켠 뒤 다시 실행합니다.
:::

:::firefox
하드웨어 가속을 켜려면 **설정, 일반, 성능**을 열고 **권장 성능 설정 사용**의 선택을 해제한 뒤 **가능한 경우 하드웨어 가속 사용**을 선택합니다. Firefox를 다시 시작합니다.
:::

:::safari
Safari는 WebGL이 기본으로 켜져 있습니다. 그래도 화면이 시작되지 않으면 macOS를 업데이트하고, 어떤 확장 프로그램도 WebGL을 차단하지 않는지 확인합니다.
:::

자세한 내용은 [브라우저와 컴퓨터](common:browsers)를 참고합니다.

## 화면을 클릭해도 반응이 없음

- **클릭 근처에 교점이 없음.** 배치 도구는 그리드 교점에만 맞춰집니다. 모든 점에서 떨어진 곳을 클릭하면 아무 일도 일어나지 않습니다. 점에 불이 켜질 때까지 가까이 이동합니다.
- **도구가 {{ui:선택}}이고 빈 공간을 클릭함.** 선택이 해제됩니다.
- **드래그함.** 몇 픽셀 이상 떨어진 위치에서 누르고 떼면 드래그로 간주되며, 뷰가 회전하거나 이동합니다.
- **부재가 잘려 있음.** {{ui:평면}}과 {{ui:입면}}에서는 절단 면 바깥의 강재가 숨겨져 있어 클릭할 수 없습니다. {{ui:3D}}로 전환합니다.
- **교점의 높이가 잘못됨.** {{ui:3D}}에서는 여러 층의 교점이 화면에서 겹칠 수 있으며, 클릭하면 가장 가까운 교점이 선택됩니다. {{ui:평면}} 또는 {{ui:입면}}을 사용합니다.

## 배치 메시지

| 메시지 | 대처 방법 |
|---|---|
| 기둥이 닿을 Level 2 위의 층이 없습니다. 먼저 층을 추가해야 합니다. | {{ui:레벨}}에서 층을 추가하거나, 더 낮은 층을 클릭합니다 |
| 다른 끝에는 다른 교점을 선택해야 합니다. | 같은 점을 두 번 클릭했습니다 |
| 두 끝이 같은 점입니다. | {{ui:축선으로 추가}} 양식에서 "From"과 "To" 선택이 같습니다 |
| 부재를 배치하려면 왼쪽에 축선을 추가해야 합니다. | 모델에 한 방향의 축선이 없습니다 |
| 알 수 없는 프로파일 "…" | 프로파일이 카탈로그 또는 모델의 사용자 프로파일에 없습니다. 목록에서 선택합니다 |
| 숫자를 입력해야 합니다. | 숫자 입력란이 비어 있거나 텍스트가 들어 있습니다 |

## 접합이 만들어지지 않음

### "이 보는 기둥 축선에서 끝나지 않습니다."

단부 판은 보의 끝이 수직 기둥의 축선 위에 정확히 있어야 하며, 기둥의 아래 끝과 위 끝 사이에 있어야 합니다(1 mm 이내). 보의 {{ui:끝 (x, y, z mm)}}과 기둥의 위치를 확인합니다.

### "이 보는 기둥 웨브에 닿거나 비스듬히 만납니다"

또는 {{ui:문제}}에서: "기둥 웨브에 맞닿는 보는 아직 만들지 않았습니다. 기둥을 90° 돌리거나 다른 접합을 사용하십시오."

보가 기둥 웨브에 맞닿습니다. 기둥을 선택하고 {{ui:회전 (°)}}을 90으로 설정한 뒤 다시 시도합니다. 비스듬한 접합은 아직 만들지 않습니다.

### "단부 판은 수평 보에만 만들어집니다(이 보는 경사져 있습니다)."

보의 양 끝이 같은 높이에 있어야 합니다.

### "단부 판에는 보가 똑바로 세워져 있어야 합니다(회전 0)."

보의 {{ui:회전 (°)}}을 다시 0으로 설정합니다.

### "단부 판에는 I형 보가 필요합니다." / "단부 판에는 I형 기둥이 필요합니다."

I형(W, IPE, HEA, HEB 또는 사용자 정의 I형)만 단부 판을 사용할 수 있습니다.

### "보의 끝이 더 이상 기둥 축선에 있지 않습니다."

접합을 추가한 뒤 보나 기둥을 이동했습니다. 다시 옮기거나 접합을 삭제합니다.

### "접합이 이 부재를 모두 잘라냈습니다."

양 끝의 접합이 부재를 길이보다 더 많이 잘라냅니다. 예를 들어 깊은 두 기둥 사이의 매우 짧은 보가 여기에 해당합니다. 부재의 끝과 판 두께를 확인합니다.

### "이와 같은 다른 접합 중 연결이 없는 것은 없습니다 …"

{{ui:유사 적용}}은 보 프로파일, 기둥 프로파일과 접합 종류(플랜지에 맞닿는 보 끝)가 같고, 아직 접합이 없는 접합부에만 복사합니다.

### "양 끝에 이미 접합이 있습니다." / "이 기둥에는 이미 밑판이 있습니다."

기존 접합을 선택해 변경하거나, 먼저 삭제합니다.

## 문제 탭의 경고

경고는 접합이나 기초가 만들어지는 것을 막지 않습니다. 확인을 요청할 뿐입니다. 가장자리와 간격 경고는 EN 1993-1-8 표 3.3의 최소값을 사용합니다(가장자리 1.2 × 구멍, 간격 2.2 × 구멍, 게이지 2.4 × 구멍). 프로젝트가 다른 기준을 사용한다면 경고가 적용되지 않을 수 있습니다. DetailCraft는 접합을 설계하지 않습니다.

"a hole is off the end of the part"는 구멍의 x가 0보다 작거나 절단 길이보다 크다는 뜻입니다. x는 접합이 부재를 잘라낸 뒤의 절단 시작점에서부터 잰 값이라는 점을 기억합니다.

## 기초 변경이 거부됨

| 메시지 | 대처 방법 |
|---|---|
| 피복 두께 때문에 이 기초에는 철근을 넣을 공간이 없습니다. | 기초를 키우거나 피복 두께를 줄입니다 |
| 피복 안쪽에 철근 두 층을 넣기에는 기초가 너무 얕습니다. | 기초를 더 깊게 하거나 피복 두께를 줄입니다 |
| 75 mm 피복으로는 시작 철근이 기초 안에 들어가지 않습니다. | 시작 철근 수를 줄이거나, 간격을 좁히거나, 기초를 키웁니다 |
| 철근 간격은 50–1000 mm여야 합니다. | 그 범위의 간격을 입력합니다 |
| 길이는 300–50000 mm여야 합니다. | 기초 크기에는 한계가 있습니다. 길이와 폭은 300~50000, 깊이는 150~10000입니다 |

## 축선과 레벨이 거부됨

| 메시지 | 대처 방법 |
|---|---|
| 번호 축선: 선 사이마다 간격을 하나씩 입력해야 합니다 (4). | 간격 수를 셉니다. 선이 다섯 개면 간격은 넷입니다 |
| 문자 축선: 간격은 양의 밀리미터여야 합니다. | 0, 음수 또는 텍스트는 안 됩니다 |
| 번호 축선: 축선 표시는 서로 달라야 합니다. | 두 선의 표시가 같습니다 |
| 각 방향의 축선은 최대 60개입니다. | 모델을 나눕니다 |
| 최소한 하나의 레벨은 유지해야 합니다. | 모든 레벨 행을 삭제했습니다 |
| 각 레벨에는 이름이 있어야 합니다. / 두 레벨의 이름이 "…"입니다. | 레벨마다 서로 다른 이름을 붙입니다 |

## 파일 열기에 실패함

| 메시지 | 원인 |
|---|---|
| DetailCraft는 자체 모델(.detailcraft.json)을 엽니다. IFC 가져오기는 아직 만들지 않았습니다. | 파일이 `.json` 파일이 아닙니다 |
| 이것은 DetailCraft 모델이 아닙니다(JSON이 아님). | 파일이 손상되었거나 다른 JSON 파일입니다 |
| 이것은 DetailCraft 모델이 아닙니다. | 다른 프로그램의 JSON 파일입니다 |
| 이 모델은 더 최신 DetailCraft(형식 2)로 저장되었습니다. | 저장한 최신 DetailCraft에서 엽니다 |
| 이 파일은 DetailCraft 모델로 보기에 너무 큽니다. | 50 MB를 넘습니다 |

"부재 2개가 올바르지 않아 제외했습니다."와 같은 경고와 함께 파일이 열리는 경우, 나머지 모델은 정상입니다. 제외된 항목을 확인하기 전까지는 원본 파일을 덮어쓰지 마십시오.

## 내보내기

| 메시지 | 원인 |
|---|---|
| 내보낼 항목이 아직 없습니다. | 모델이 비어 있는 상태에서 {{ui:IFC}} |
| NC 파일을 만들 I형 또는 판 부품이 없습니다. | 모델에 채널, 앵글 또는 튜브만 있습니다 |
| 기록하지 않음(지금까지는 I형과 판만 가능): … | 해당 마크는 I형이나 판이 아닙니다. 나머지는 기록되었습니다 |
| 기초가 없어서 일람할 철근이 없습니다. | 기초 없이 {{ui:벤딩}} |
| PDF 글꼴 밖의 문자 …개는 "?"로 인쇄되었습니다. | 모델 이름이나 등급에 PDF 글꼴에 없는 문자가 있습니다 |

{{ui:제작도}}가 비활성화되어 있으면 모델에 아직 부품이 없습니다.

## 다운로드가 나타나지 않음

모든 저장과 내보내기는 브라우저 다운로드로 처리됩니다. 브라우저의 다운로드 목록을 확인합니다. 브라우저가 여러 파일을 다운로드하기 전에 묻거나 이 사이트의 다운로드를 차단하면 허용합니다. Safari에서는 도구 모음의 다운로드 버튼을 확인합니다.

## 키가 작동하지 않음

- 커서가 텍스트 또는 숫자 입력란에 있으면 도구 키와 {{key:Delete}}는 무시됩니다. 입력할 수 있도록 하기 위해서입니다. {{key:Tab}}을 누르거나 화면을 클릭합니다.
- 대화상자가 열려 있으면 먼저 닫습니다.
- 브라우저가 키보드를 가지고 있으면(예: 주소 표시줄), DetailCraft 안을 클릭합니다.
- {{key:Ctrl+Shift+F}}는 Mac에서도 Control 키를 사용합니다.

## 오프라인 문제

앱 바의 {{ui:오프라인용 저장}} 버튼은 오프라인 복사본의 상태를 보여 줍니다. 저장 방식은 [오프라인 작업](common:offline)을 참고합니다.

| 버튼 표시 | 의미 | 대처 방법 |
|---|---|---|
| {{ui:오프라인용 저장}} | 이 브라우저에는 아직 오프라인 복사본이 없습니다 | 온라인 상태에서 선택합니다 |
| 20개 중 5개 저장 중 | 저장이 진행 중입니다 | {{ui:오프라인 사용 준비됨}}이 표시될 때까지 기다리고, 탭을 열어 둡니다 |
| {{ui:오프라인 사용 준비됨}} | DetailCraft, 3D 화면, 모든 내보내기와 이 도움말을 연결 없이 사용할 수 있습니다 | 없음. 클릭하면 {{ui:다시 저장 (최신 버전 받기)}} 또는 {{ui:오프라인 사본 제거}}를 선택할 수 있습니다 |
| {{ui:저장하지 못했습니다}} | 일부 파일을 내려받지 못했습니다 | 연결을 확인하고 클릭해서 다시 시도합니다 |
| {{ui:오프라인 사용 불가}} | 이 창은 오프라인 복사본을 보관할 수 없습니다. 비공개 창과 일부 관리되는 컴퓨터가 이를 차단합니다 | 일반 창을 사용하거나 온라인으로 작업합니다 |

오프라인 상태인데 버튼이 {{ui:오프라인 사용 준비됨}}으로 표시되지 않으면, 페이지를 새로 고치거나 탭을 닫지 않습니다. 이미 불러온 내용은 계속 작동합니다. {{key:Mod+S}}로 모델을 저장하고 다시 온라인이 될 때까지 기다립니다.

## 저장하지 않은 작업

브라우저가 페이지를 떠날지 묻는다면, DetailCraft에 저장되지 않은 변경 사항이 있다는 뜻입니다. 머무르기를 선택한 뒤 {{key:Mod+S}}를 누릅니다. 탭을 닫은 뒤에는 DetailCraft가 모델을 복구할 수 없습니다.

## 여전히 해결되지 않음

수행한 작업과 정확한 메시지를 기록한 뒤, [지원 페이지](https://getcadcraft.com/support)를 통해 알려 주시기 바랍니다.
