Tekla Structures로 상세 설계를 한다면 DetailCraft의 대부분이 익숙할 것입니다. 축선, 레벨, 카탈로그의 단면, 부품과 조립품, 접합, 번호 매기기, NC 파일, IFC가 그렇습니다. 규모는 많이 다릅니다. Tekla Structures는 완전한 생산 시스템이고, DetailCraft는 작고 초기 단계의 브라우저 앱으로 몇 가지 작업을 처음부터 끝까지 수행합니다. 이 페이지는 익숙한 습관이 어디까지 이어지고 어디서 이어지지 않는지를 알려 줍니다.

:::tip
Tekla Structures의 리본에 손이 익었다면 {{ui:설정}} › {{ui:DetailCraft}} › {{ui:메뉴, 키, 마우스}}에서 {{ui:강재 리본}} 메뉴 스타일을 고르십시오. 모델링, 상세 설계, 편집, 도면, 제작, 보기 탭이 나오고 가운데 버튼은 초점을 이동합니다. AutoCAD에서 넘어왔고 명령을 입력하는 것을 좋아한다면 {{ui:제도 클래식}}이 명령행(BEAM, COLUMN, ENDPLATE, ZOOM …)을 추가합니다. [메뉴, 키, 마우스](topic:menus-keys-and-mouse)를 참조하십시오.
:::

## 빠른 대응표

| 익숙한 것 | DetailCraft에서 |
|---|---|
| 좌표를 입력하는 그리드 대화상자로 그리드 만들기 | 왼쪽 패널의 {{ui:축선}}: 절대 좌표가 아니라 레이블과 선 사이의 간격. 번호 선은 한 방향, 문자 선은 다른 방향으로 뻗습니다 |
| 그리드 Z 좌표로서의 레벨 | 별도의 {{ui:레벨}} 목록. 행마다 이름과 높이를 정하고 {{ui:레벨 적용}}으로 적용 |
| 스냅으로 아무 곳이나 점 찍기 | 클릭은 그리드 교차점에만 스냅됩니다. 그리드 밖의 점은 부재의 {{ui:끝 (x, y, z mm)}}에 입력합니다 |
| 기둥, 보, 플레이트 명령 | {{ui:기둥}}({{key:C}}), {{ui:보}}({{key:B}}), {{ui:브레이스}}({{key:R}}), {{ui:플레이트}}({{key:P}}), {{ui:기초}}({{key:F}}) |
| 부품 속성 대화상자(부품을 더블 클릭) | 한 번 클릭하면 오른쪽의 {{ui:속성}} 패널이 항상 실시간으로 나타납니다. 대화상자도, 수정이나 적용 버튼도 없습니다 |
| 평면 위의 위치, 회전, 깊이 설정 | {{ui:위치}}(강재 윗면, 가운데 또는 선 위 아래)와 {{ui:회전 (°)}}. 별도의 수평 간격 띄우기는 없습니다 |
| 단면 카탈로그 | 2,311개 공개 규격의 고정 목록(AISC W, S, C, L, HSS, Pipe. 유럽 IPE, HEA, HEB, UPN. 영국 UB, UC, PFC, EA, UEA, SHS, RHS, CHS 및 냉간 성형 중공 단면), 매개변수 플레이트, 그리고 사용자의 {{ui:사용자 단면}} |
| 재료 카탈로그 | 목록의 일곱 등급: A992, A36, A572 Gr 50, A500 Gr C, S235, S275, S355 |
| 접합 구성요소와 그 대화상자 적용 | 보를 선택하고 {{ui:엔드 플레이트}} 명령을 선택합니다. 설정은 {{ui:속성}} 패널에 나타납니다. 접합은 두 가지만 있습니다(기둥 플랜지에 대한 엔드 플레이트, 베이스 플레이트) |
| 자동 접합, 또는 접합을 비슷한 접합에 복사 | 접합을 선택하고 {{ui:유사 항목에 적용 (n)}} 명령을 선택합니다 |
| 계열과 시작 번호를 가진 번호 매기기 | 명령 없음. 표시는 모든 변경 뒤 저절로 갱신되며, 접두사 c, b, br, p 및 C, B, BR, P는 고정입니다 |
| 볼트와 구멍 대화상자 | 구멍은 면과 위치로 입력합니다. 볼트는 접합에서만 생깁니다 |
| 자르기, 맞춤, 다각형 자르기 도구 | 코프(위 또는 아래, 어느 끝이든)는 I형강에만 있습니다. 접합의 절단 축소는 자동입니다 |
| 보고서와 템플릿 | 아래쪽 탭에 있는 고정된 보고서 세 개와 CSV 다운로드 |
| 도면 작성과 도면 목록 | 부재 표시마다 제작도 한 장을 만들며, 모두 한꺼번에 만듭니다. 미리 본 뒤 PDF 한 개로 또는 시트별로 다운로드합니다. 아무것도 보관되거나 편집되지 않습니다 |
| NC 파일 내보내기 | {{ui:NC 파일}}: 부재 표시마다 DSTV 파일 하나, I형강과 플레이트만, 압축 파일로 묶음 |
| IFC 내보내기 | {{ui:IFC}}: 철근을 포함한 전체 모델의 IFC4 |
| 모든 콘크리트 부재의 철근 | 철근은 직사각형 패드 기초에만 있으며, 미국식 철근 규격을 쓰고, 아래 매트와 시작 철근이 있습니다 |
| 프로젝트 폴더에 저장되는 모델, 다중 사용자 | 다운로드하는 `.detailcraft.json` 파일 하나. 단일 사용자이며 사용자의 컴퓨터에서 실행 |
| 실행 취소 기록 | {{key:Mod+Z}}와 {{key:Mod+Y}}, 최대 200단계. 다른 모델을 열거나 시작할 때까지 유지 |

## 사람을 헷갈리게 하는 차이점

### 표시가 저절로 바뀝니다

번호를 매기는 단계는 없습니다. 표시는 모든 변경 뒤에 다시 계산되므로 항상 최신이지만, 다시 번호가 매겨질 수도 있습니다. 기둥을 추가하면 어제의 c3이 이제 c4가 될 수 있습니다. 옛 표시를 보관하는 "번호 기록"은 없습니다. 모델을 마친 뒤 저장된 파일 하나에서 부품표(BOM), NC 파일, 제작도를 함께 발행하십시오.

### 가운데 마우스 버튼은 확대하며, 초점을 이동하지 않습니다

3D 뷰에서 왼쪽 드래그는 회전, 오른쪽 드래그는 초점 이동, 휠은 확대/축소, 가운데 버튼 드래그도 확대/축소입니다. {{key:Shift}}를 누른 채 왼쪽 드래그하면 초점도 이동합니다. 휠은 포인터가 아니라 뷰의 가운데를 향해 확대합니다. 회전 중심을 고르는 기능은 없으며, 모델은 뷰의 가운데를 중심으로 회전합니다. [3D 뷰에서 이동하기](topic:navigate-3d)를 참조하십시오.

### 기둥은 기본적으로 한 방향을 향합니다

회전 0에서 기둥의 플랜지는 번호 그리드 방향을 따릅니다. 문자 축선 사이를 달리는 보는 웨브에 붙으며, 그곳에서는 엔드 플레이트가 거부됩니다("기둥 웨브에 붙는 보는 아직 만들지 않았습니다"). 접합을 추가하기 전에 그런 기둥을 90° 회전시키십시오.

### 입면은 문자 축선에서만 봅니다

{{ui:입면}} 뷰는 문자 축선을 따라서만 봅니다. 번호 축선을 따라 보는 뷰, 저장된 뷰, 작업 평면은 없습니다. 번호 축선의 골조에는 {{ui:3D}} 또는 {{ui:축선으로 추가}}를 사용하십시오.

### 선택, 복사, 이동

{{key:Shift}}+클릭 또는 {{key:Mod+A}}로 여러 부품을 선택한 뒤 복사, 잘라내기, 붙여넣기(그리드 교차점에, 입력한 간격에, 또는 제자리에)와 복제를 할 수 있습니다. 접합도 포함됩니다([복사, 붙여넣기, 복제](topic:copy-paste)). 창 선택, 선택 필터, 이동, 대칭, 배열은 없으며, 속성은 {{ui:속성}} 패널에서 부재 하나씩 바꿉니다.

### 그리드를 옮겨도 부재는 따라 움직이지 않습니다

그리드 간격을 바꿔도 부재는 자기 좌표를 유지합니다. 그리드 선과 함께 움직이는 것은 없습니다. 강재를 배치하기 전에 그리드를 바꾸거나, 나중에 부재마다 끝 좌표를 편집하십시오.

### 접합은 설계되지 않습니다

두 접합은 입력한 숫자에 따라 플레이트, 구멍, 볼트, 용접을 배치합니다. 어떤 설계 검사도 없으며, 가장자리와 간격에 대한 경고만 있습니다(EN 1993-1-8 표 3.3).

### 3D 뷰에서는 구멍이 잘리지 않습니다

구멍은 어두운 마개로 보입니다. 구멍은 NC 파일, 제작도, IFC 파일에서는 실제 구멍입니다. 코프는 뷰에서 잘립니다.

### 중량은 총량입니다

강재 중량은 구멍이나 코프를 빼지 않으며, 볼트 중량은 포함되지 않습니다.

### 밀리미터만 사용합니다

AISC 단면이라도 모든 값은 밀리미터로 입력되고 표시됩니다. 단면 이름은 공개된 형식을 유지합니다(W12x50, HSS6x6x1/4).

### 관리할 도면이 없습니다

도면 목록, 도면 편집기, 일반 배치 도면이나 조립 도면은 없습니다. 제작도는 요청할 때 만들어 다운로드합니다. 바꾸려면 모델을 바꾸고 다시 만드십시오.

### 브라우저에서 실행됩니다

저장하면 파일이 다운로드됩니다. 브라우저가 자체적으로 쓰는 단축키는 사용할 수 없습니다. 모델은 사용자의 컴퓨터를 떠나지 않습니다. [파일이 어디로 가는지](common:your-files)를 참조하십시오.

## 지금 소프트웨어에서 계속할 일

현재 DetailCraft는 작은 골조, 아이디어 확인, 교육, 또는 단순한 보와 기둥 작업의 NC 파일과 제작도 생산에 알맞습니다. 복잡한 접합, 일반 배치 도면, 설치 도면, 다중 사용자 프로젝트, 그리고 [아직 만들지 않은 기능](topic:not-built-yet)에 나열된 모든 것은 지금 사용하는 소프트웨어에 남겨 두십시오.
