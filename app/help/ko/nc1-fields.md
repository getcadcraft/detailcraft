각 `.nc1` 파일은 부재 마크 하나를 설명합니다. 줄은 CR LF로 끝납니다. 텍스트 필드는 일반 ASCII를 사용하며, 다른 문자는 "?"로 바뀝니다. 둘째 줄은 주석으로, `** DetailCraft <mark>.nc1`입니다.

## 머리글 (ST)

| 필드 | I형강, 채널 | 앵글 | 사각 HSS | 원형 HSS | 플레이트 |
|---|---|---|---|---|---|
| 주문 | 모델 이름 | ← | ← | ← | ← |
| 도면, 조각 | 부재 마크 | ← | ← | ← | ← |
| 단계 | 부재의 단계, 또는 1 | ← | ← | ← | ← |
| 강재 품질 | 재질 등급 | ← | ← | ← | ← |
| 수량 | 이 마크를 가진 부재 수 | ← | ← | ← | ← |
| 단면 | 단면 이름, 예: W16x26 | ← | ← | ← | `PL<t>*<width>` |
| 단면 코드 | I 또는 U (채널) | L | M | RO | B |
| 길이 | 절단 길이 | ← | ← | ← | 길이 |
| 높이 | 깊이 d | 다리 | 높이 | 지름 | 플레이트 너비 |
| 플랜지 너비 | bf | 다리 | 너비 | 지름 | 0 |
| 플랜지 두께 | tf | t | 벽 두께 t | 벽 두께 t | 0 |
| 웨브 두께 | tw | t | 벽 두께 t | 벽 두께 t | 플레이트 두께 |
| 반지름 | 필렛 반지름 (AISC 채널은 0) | 0 | 바깥 모서리 반지름 | 0 | 0 |
| 미터당 중량 | kg/m | kg/m | kg/m | kg/m | kg/m² |
| 미터당 도장 면적 | 바깥 둘레, m²/m | ← | ← | ← | 2 (양면, m²/m²) |
| 톱 각도 (4개 필드) | 0 (직각) | ← | ← | ← | ← |
| 텍스트 필드 (4개) | `-` | ← | ← | ← | ← |

플레이트는 표준의 "판재용" 열을 따릅니다. 표준에는 원형 튜브 열이 없으므로, DetailCraft는 지름을 높이와 플랜지 너비로, 벽 두께를 두 두께 모두에 씁니다.

## 바깥 윤곽 (AK)

- **I형강과 채널:** 웨브(v), 코프마다 직사각형 노치. 각 플랜지(o와 u)는 코프가 플랜지 이상으로 깊은 끝에서 짧아집니다.
- **사각 HSS:** 양쪽 측벽(v와 h)은 코프에 맞춰 노치되며, 상단과 하단 벽(o와 u)도 있습니다.
- **앵글:** 날개마다 직사각형 하나(v와 u). 앵글의 코프는 기록되지 않으며, 그런 부재는 기록되지 않음으로 나열됩니다. 앵글 브레이스가 [거셋](topic:brace-gussets)에 볼트로 연결되면, 구멍은 볼트로 체결되는 날개에 있습니다: 부재의 u를 따라가는 날개는 v, v를 따라가는 날개는 u.
- **원형 HSS:** 튜브를 앞에서 본 모습으로, v에 직사각형 하나(길이 × 지름).
- **플레이트:** 면 v에 직사각형 하나.

각 윤곽은 닫혀 있으며(첫 점을 끝에 반복), 반시계 방향으로 진행합니다.

## 구멍 (BO)

구멍마다 한 줄: 면, x, y, 지름, 깊이 0(관통). 직접 입력한 구멍과 연결이 만든 구멍을 모두 포함합니다. 사각 HSS의 측벽을 관통하는 구멍은 두 번 기록됩니다. 한 번은 v에, 한 번은 h에.

## 면과 좌표

각 단면은 표준의 단면 위치 그림(DSTV 1998, 7쪽)에 그려진 대로 배치됩니다: x는 부재를 따라, Y는 폭 방향으로, Z는 뒷면에서 위쪽으로, 원점은 바깥 모서리에 둡니다. DetailCraft는 그림에 맞추려고 부재를 뒤집지 않습니다.

| 면 | I형강 | 채널 | 앵글 | 사각 HSS | 플레이트 |
|---|---|---|---|---|---|
| v | 웨브, 앞 | 웨브, 플랜지 끝 쪽에서 본 면 | 부재의 u를 따라가는 날개 | 측벽 −u | 플레이트 면 |
| h | | | | 측벽 +u | |
| o | 상부 플랜지 | **하부** 플랜지 | | 상단 벽 | |
| u | 하부 플랜지 | **상부** 플랜지 | 부재의 v를 따라가는 날개 | 하단 벽 | |

- **x**는 절단 시작점에서 부재를 따라 진행합니다.
- **I형강과 사각 HSS:** 웨브나 측벽의 y는 단면 하부에서부터 잽니다. 플랜지나 상하 벽의 y는 뒷면 쪽(부재의 +u 쪽) 모서리에서부터 잽니다.
- **채널:** 그림처럼 등을 대고 플랜지 끝이 위로 향하게 눕습니다. 따라서 웨브의 y는 상부 플랜지 바깥쪽에서 아래로 진행하고, 상부 플랜지는 면 u, 하부 플랜지는 면 o입니다. 플랜지의 y는 웨브 뒤쪽에서 플랜지 끝 쪽으로 진행합니다.
- **앵글:** 각 날개의 y는 뒤꿈치에서 잽니다.
- **플레이트:** y는 플레이트의 −u 모서리에서 잽니다.

절단하기 전에 기계 소프트웨어가 채널의 면을 어떻게 읽는지 확인하십시오: 일부 프로그램은 채널을 위아래 반대로 돌립니다.

## 기록되지 않음

베벨, 내부 윤곽, 표시(SI), 직각이 아닌 톱 각도, 장공, 원형 튜브의 구멍(DetailCraft에는 없음), 그리고 앵글과 원형 튜브의 코프.
