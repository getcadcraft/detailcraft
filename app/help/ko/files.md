DetailCraft에는 고유한 파일이 모델 하나뿐이며, 내보내기는 다섯 가지입니다. 모든 저장과 내보내기는 다운로드입니다. 아무것도 업로드되지 않고 서버에 보관되지 않습니다.

## 모델 파일

DetailCraft 모델은 `<이름>.detailcraft.json`으로 저장됩니다. `<이름>`은 {{ui:모델}} 패널의 모델 이름입니다. 파일에는 축선, 레벨, 부재(구멍과 코프 포함), 접합과 그 설정, 기초, 사용자 단면이 들어 있습니다.

파트, 마크, 볼트, 용접, 철근은 저장되지 않습니다. DetailCraft는 모델을 열 때마다 이것들을 모델에서 다시 계산합니다. 그래서 모델 파일은 작습니다.

### 저장

1. {{ui:모델}} 패널 맨 위의 {{ui:이름}} 입력란에 이름을 입력합니다.
2. {{ui:파일}} 그룹에서 {{ui:저장}}을 선택하거나 {{key:Mod+S}}를 누릅니다.
3. 브라우저가 `<이름>.detailcraft.json`을 다운로드합니다. 상태 표시줄에 "Saved … (downloaded)"가 표시되고, 브라우저 탭 제목 앞의 점이 사라집니다.

저장할 때마다 새 다운로드가 됩니다. 브라우저는 열어 둔 파일을 덮어쓰지 않습니다. 설정에 따라 `Frame (1).detailcraft.json`처럼 이름에 번호를 붙이거나 저장 위치를 묻습니다. 버전을 따로 관리하려면 다운로드한 파일의 이름을 바꾸십시오.

:::chromium
Chrome과 Edge는 브라우저 다운로드 설정에서 **Ask where to save each file before downloading**을 켜지 않았다면 다운로드 폴더에 저장합니다. 매번 폴더와 파일 이름을 직접 고르려면 이 설정을 켜십시오.
:::

:::firefox
Firefox는 다운로드 폴더에 저장하며, 설정에서 **Always ask you where to save files**를 켜 두었다면 매번 묻습니다.
:::

:::safari
Safari는 다운로드 폴더에 저장합니다. 폴더를 바꾸려면 **Safari, Settings, General, File download location**을 여십시오.
:::

### 열기

1. {{ui:파일}} 그룹에서 {{ui:열기}}를 선택하거나 {{key:Mod+O}}를 누릅니다.
2. `.detailcraft.json` 파일을 고릅니다.

또는 {{pick:mac=Finder|windows=파일 탐색기|linux=파일 관리자}}에서 파일을 끌어 뷰에 놓습니다. 끄는 동안 뷰에 "Drop a DetailCraft model to open it"이라고 표시됩니다.

열려 있는 모델에 저장하지 않은 변경 사항이 있으면 DetailCraft가 먼저 묻습니다. {{ui:취소}}, {{ui:변경 사항 버리기}}, {{ui:먼저 저장}} 중에서 고르십시오.

DetailCraft는 파일을 사용하기 전에 모든 필드를 검사합니다. 사용할 수 없는 항목은 제외되고, 상태 표시줄에 그 내용이 표시됩니다. 예: "2 members were not valid and left out." 더 새로운 DetailCraft에서 저장한 모델은 반쯤만 맞게 열지 않고 메시지와 함께 거부됩니다.

### 열 수 있는 파일

자체 모델 파일(`.json`, 최대 50 MB)과 IFC 파일(`.ifc`, IFC2X3 또는 IFC4, 최대 200 MB)을 열 수 있습니다. IFC 파일은 직접 열거나 {{ui:IFC 가져오기}}로 가져오면 보, 기둥, 부재, 플레이트, 축선, 레벨로 이루어진 새 모델이 됩니다. 구멍과 코프는 부재에 반영되고, 볼트는 개별 볼트로 들어옵니다. 제외된 항목은 보고서에 나열됩니다. [IFC 내보내기](topic:ifc-export#import)를 참조하십시오. DWG, DXF나 다른 상세 설계 프로그램의 모델은 아직 열 수 없으며, 시도하면 "DetailCraft opens its own models (.detailcraft.json) and IFC files (.ifc)."가 표시됩니다.

## 잃어버린 작업, 최근 파일, 데스크톱 앱

- 모델에 저장하지 않은 변경 사항이 있는 동안 DetailCraft는 이 브라우저에 사본을 보관합니다. 저장하기 전에 탭이나 브라우저가 중단되면 다음에 DetailCraft를 열 때 **Recover your work?**라고 묻습니다. 사본을 복구하거나 버릴 수 있습니다. [작업 복구](common:recover)를 참조하십시오.
- 최근에 연 모델은 브라우저가 DetailCraft의 재열기를 허용하는 경우 시작 화면에 나열됩니다. 모델을 클릭하면 다시 열립니다.
- 데스크톱 앱에서는 {{ui:저장}}이 열었던 파일에 모델을 다시 씁니다(브라우저에서는 사본을 다운로드합니다). DetailCraft 모델이나 IFC 파일을 더블클릭하면 DetailCraft에서 열립니다.

## 내보내기

모든 내보내기는 모델 이름을 사용합니다. {{ui:출력}} 그룹에서 선택합니다.

| 버튼 | 파일 | 내용 |
|---|---|---|
| {{ui:IFC}} | `<이름>.ifc` | IFC4: 층, 축선, 구멍과 코프를 포함한 단면 돌출 형태의 모든 강재 파트, 어셈블리, 볼트와 앵커 로드, 기초, 모든 철근. [IFC 내보내기](topic:ifc-export)를 참조하십시오. |
| {{ui:NC 파일}} | `<이름> NC.zip` | 파트 마크당 DSTV `.nc1` 파일 하나. [NC 파일을 공장에 보내기](topic:nc-export)를 참조하십시오. |
| {{ui:BOM}} | `<이름> BOM.csv` | 한 파일에 표 세 개: 파트, 어셈블리, 볼트와 앵커 로드. [마크와 자재 명세서](topic:marks-and-bom)를 참조하십시오. |
| {{ui:벤딩}} | `<이름> bending schedule.csv` | 기초에 있는 모든 철근 마크. [기초와 철근](topic:footings-and-rebar)을 참조하십시오. |
| {{ui:제작도}} | `<이름> <마크>.pdf` | 선택한 파트(I형강과 플레이트) 한 장의 시트(다른 크기를 고르지 않았다면 A3). [제작도 만들기](topic:shop-drawings)를 참조하십시오. |
| {{ui:도면}} | `<이름> drawings.pdf`, `<이름> <시트>.pdf`; `<이름> <시트>.dwg` 또는 `.dxf`, 여러 개는 `<이름> drawings DWG.zip`(또는 `DXF.zip`) | 선택한 시트 크기의 평면도, 입면도, 어셈블리 도면. DWG와 DXF는 실척이며 용지 1 단위 = 1 mm입니다. [일반 배치도와 어셈블리 도면](topic:drawings)을 참조하십시오. |

### CSV 파일 참고 사항

- 스프레드시트 프로그램이 악센트 문자를 올바르게 읽도록 바이트 순서 표시(BOM)로 시작합니다.
- `=`, `+`, `-`, `@`로 시작하는 셀(단순 숫자는 제외)에는 앞에 아포스트로피가 붙어, 스프레드시트가 수식으로 실행하지 않습니다.
- 길이는 밀리미터, 중량은 킬로그램입니다.

### PDF 참고 사항

PDF의 문자는 표준 Helvetica 글꼴을 사용합니다. 이 글꼴에 없는 문자(서유럽 문자 집합 밖)는 "?"로 인쇄되고, 상태 표시줄에 그 개수가 표시됩니다.

## 단위

DetailCraft는 축선, 레벨, 좌표, 단면, 구멍, 모든 내보내기에서 밀리미터로 작업합니다. 단면 이름은 발표된 형식을 그대로 유지합니다(W12x50은 치수를 mm로 표시하더라도 미국 규격 명칭입니다). 야드파운드법 입력은 아직 없습니다.

## 온라인과 오프라인

열기, 저장, 내보내기는 모두 브라우저에서 이루어지므로, DetailCraft를 한 번 불러온 뒤에는 연결 여부와 관계없이 똑같이 동작합니다.

나중에 연결 없이 DetailCraft를 사용하려면 온라인일 때 앱 바에서 {{ui:오프라인용 저장}}을 선택하십시오. 버튼에 진행 상황이 표시되고("Saving 3 of 20") 이어서 {{ui:오프라인 사용 준비됨}}으로 바뀝니다. 저장된 사본에는 3D 그래픽 라이브러리(약 2.6 MB)와 이 도움말이 들어 있으므로, 저장하고 나면 3D 뷰, 모든 내보내기, 도움말이 오프라인에서 동작합니다. 자세한 내용과 여전히 연결이 필요한 기능은 [오프라인 작업](common:offline)을 참조하십시오.

:::offline
오프라인 상태입니다. 앱 바에 {{ui:오프라인 사용 준비됨}}이 표시되면 열기, 저장, 내보내기가 평소처럼 동작합니다. 표시되지 않으면 이 탭을 열어 둔 채로 다시 온라인이 될 때까지 새로 고치지 말고 지금 모델을 저장하십시오.
:::

클라우드 저장은 아직 지원하지 않으며, 데스크톱 빌드도 아직 없습니다. `.detailcraft.json` 파일은 다른 작업 파일과 같은 방식으로 백업하십시오. 자세한 내용은 [파일이 저장되는 위치](common:your-files)를 참조하십시오.

## 저장하지 않은 작업

DetailCraft는 모델을 열려 있는 탭에만 보관합니다. 저장하지 않은 변경 사항이 있는 상태에서 탭을 닫거나 새로 고치면 브라우저가 페이지를 떠날지 묻습니다. 이 문구는 브라우저 자체의 것입니다. {{key:Mod+S}}로 자주 저장하십시오.
