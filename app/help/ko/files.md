DetailCraft에는 고유 파일인 모델 하나와 내보내기 다섯 가지가 있습니다. 모든 저장과 내보내기는 다운로드입니다. 아무것도 업로드되지 않으며, 서버에 보관되는 것도 없습니다.

## 모델 파일

DetailCraft 모델은 `<name>.detailcraft.json`으로 저장됩니다. 여기서 `<name>`은 {{ui:Model}} 패널에 있는 모델 이름입니다. 이 파일에는 축선, 레벨, 구멍과 코프가 있는 부재, 접합부와 그 설정, 기초, 사용자 단면이 들어 있습니다.

부품, 부재 마크, 볼트, 용접 및 철근은 저장되지 않습니다. DetailCraft가 파일을 열 때마다 모델에서 다시 계산하기 때문입니다. 그래서 모델 파일이 작습니다.

### 저장

1. {{ui:Model}} 패널 위쪽의 {{ui:Name}} 입력란에 이름을 입력합니다.
2. {{ui:File}} 그룹의 {{ui:Save}}을 선택하거나 {{key:Mod+S}} 키를 누릅니다.
3. 브라우저가 `<name>.detailcraft.json`을 다운로드합니다. 상태 표시줄에 "저장됨 … (다운로드됨)"이 표시되고, 브라우저 탭 제목 앞의 점이 사라집니다.

저장할 때마다 새 다운로드가 됩니다. 브라우저는 열었던 파일을 덮어쓰지 않습니다. 설정에 따라 `Frame (1).detailcraft.json`처럼 이름 뒤에 번호를 붙이거나 저장 위치를 묻습니다. 버전을 따로 보관하려면 다운로드한 파일의 이름을 바꿔 보관합니다.

:::chromium
Chrome과 Edge는 브라우저의 다운로드 설정에서 **각 파일을 다운로드하기 전에 저장 위치 묻기**가 켜져 있지 않으면 다운로드 폴더에 저장합니다. 파일을 저장할 때마다 폴더와 파일 이름을 고르려면 이 옵션을 켜면 됩니다.
:::

:::firefox
Firefox는 다운로드 폴더에 저장하며, 설정에서 **파일을 저장할 위치를 항상 묻기**가 켜져 있으면 매번 묻습니다.
:::

:::safari
Safari는 다운로드 폴더에 저장합니다. 폴더를 바꾸려면 **Safari, 설정, 일반, 파일 다운로드 위치**를 엽니다.
:::

### 열기

1. {{ui:File}} 그룹의 {{ui:Open}}를 선택하거나 {{key:Mod+O}} 키를 누릅니다.
2. `.detailcraft.json` 파일을 고릅니다.

또는 {{pick:mac=Finder|windows=파일 탐색기|linux=사용 중인 파일 관리자}}에서 파일을 끌어 뷰에 놓습니다. 끌어 놓는 동안 뷰에 "DetailCraft 모델을 놓아 열기"라는 메시지가 나타납니다.

열려 있는 모델에 저장되지 않은 변경 사항이 있으면 DetailCraft가 먼저 묻습니다: {{ui:Cancel}}, {{ui:Discard changes}} 또는 {{ui:Save first}}.

DetailCraft는 파일을 사용하기 전에 모든 항목을 확인합니다. 사용할 수 없는 항목은 제외되며, 상태 표시줄에 그 내용이 표시됩니다. 예: "부재 2개가 올바르지 않아 제외되었습니다." 최신 DetailCraft 버전으로 저장된 모델은 절반만 열리는 대신 메시지와 함께 열기가 거부됩니다.

### 열 수 있는 파일

DetailCraft 자체 모델 파일(`.json`, 최대 50 MB)과 IFC 파일(`.ifc`, IFC2X3 또는 IFC4, 최대 200 MB)입니다. IFC 파일은 열거나 {{ui:Import IFC}} 명령으로 가져오면, 보, 기둥, 부재, 플레이트, 축선, 레벨을 가진 새 모델이 됩니다. 구멍과 코프는 잘려서 반영되고, 볼트는 독립 볼트가 됩니다. 제외된 항목은 보고서에 나열됩니다. 참조: [IFC 내보내기](topic:ifc-export#import). 아직 DWG, DXF 또는 다른 상세 설계 프로그램의 모델은 열 수 없습니다. 시도하면 "DetailCraft는 자체 모델(.detailcraft.json)과 IFC 파일(.ifc)만 엽니다."라는 메시지가 표시됩니다.

## 손실된 작업, 최근 파일, 데스크톱 앱

- 모델에 저장하지 않은 변경 사항이 있는 동안 DetailCraft는 이 브라우저에 사본을 보관합니다. 저장하기 전에 탭이나 브라우저가 멈추면, 다음에 DetailCraft를 열 때 **작업을 복구할까요?**라고 묻습니다. 사본을 복구하거나 버릴 수 있습니다. 참조: [작업 복구](common:recover).
- 최근에 연 모델은 브라우저가 다시 열기를 허용하면 시작 화면에 나열됩니다. 하나를 클릭하면 다시 열립니다.
- 데스크톱 앱에서는 {{ui:Save}} 명령이 열었던 파일에 모델을 다시 씁니다(브라우저에서는 사본을 다운로드합니다). DetailCraft 모델이나 IFC 파일을 두 번 클릭하면 DetailCraft에서 열립니다.

## 내보내기

모든 내보내기는 모델 이름을 사용합니다. {{ui:Output}} 그룹에서 선택합니다.

| 버튼 | 파일 | 포함 내용 |
|---|---|---|
| {{ui:IFC}} | `<name>.ifc` | IFC4: 층, 축선, 모든 강재 부품(구멍과 코프가 반영된 단면 돌출), 어셈블리, 볼트와 앵커 로드, 기초와 모든 철근. 참조: [IFC 내보내기](topic:ifc-export). |
| {{ui:NC files}} | `<name> NC.zip` | 부재 마크마다 DSTV `.nc1` 파일 하나. 참조: [NC 파일을 제작소로 보내기](topic:nc-export). |
| {{ui:BOM}} | `<name> BOM.csv` | 파일 하나에 표 세 개: 부품, 어셈블리, 볼트와 앵커 로드. 참조: [마크와 자재 명세서](topic:marks-and-bom). |
| {{ui:Bending}} | `<name> bending schedule.csv` | 기초에 있는 모든 철근 마크. 참조: [기초와 철근](topic:footings-and-rebar). |
| {{ui:Shop drawing}} | `<name> <mark>.pdf` | `<name> Shop drawings.pdf`에는 부재 마크마다 시트 한 장이 들어 있습니다. {{ui:PDF 다운로드}}는 현재 보이는 시트 하나를 저장합니다(다른 크기를 고르지 않았다면 A3). 참조: [제작도 만들기](topic:shop-drawings). |
| {{ui:Drawings}} | `<name> drawings.pdf`, `<name> <sheet>.pdf`; `<name> <sheet>.dwg` 또는 `.dxf`, 여러 개는 `<name> drawings DWG.zip`(또는 `DXF.zip`)에 포함 | 선택한 시트 크기의 평면도, 입면도, 어셈블리 도면. DWG와 DXF는 실제 크기이며, 용지에서 1 단위 = 1 mm입니다. 참조: [일반 배치도와 어셈블리 도면](topic:drawings). |

### CSV 파일 참고 사항

- 파일 앞에 바이트 순서 표시가 있어 스프레드시트 프로그램이 악센트 문자를 올바르게 읽습니다.
- 시작 문자가 `=`, `+`, `-` 또는 `@`인 셀(단순 숫자가 아닌 경우)에는 앞에 아포스트로피가 붙습니다. 스프레드시트가 이를 수식으로 실행하지 않도록 하기 위해서입니다.
- 길이는 밀리미터, 무게는 킬로그램 단위입니다.

### PDF 참고 사항

PDF의 텍스트는 표준 Helvetica 글꼴을 사용합니다. 글꼴에 없는 문자(서유럽 문자 집합 밖)는 "?"로 인쇄되며, 상태 표시줄에 그 개수가 표시됩니다.

## 단위

DetailCraft는 전체적으로 밀리미터를 사용합니다. 축선, 레벨, 좌표, 단면, 구멍 및 모든 내보내기가 해당됩니다. 단면 이름은 공개된 형식을 그대로 유지합니다(W12x50은 치수가 mm로 표시되더라도 미국 규격 명칭입니다). 아직 야드파운드법 입력은 없습니다.

## 온라인과 오프라인

열기, 저장, 내보내기는 모두 브라우저에서 이루어집니다. 따라서 DetailCraft가 로드된 후에는 연결 여부와 관계없이 같은 방식으로 작동합니다.

나중에 연결 없이 DetailCraft를 쓰려면 온라인 상태에서 {{ui:Save for offline}}을 선택합니다. 버튼은 "저장 중 3 / 20"처럼 숫자를 세며 진행되다가 {{ui:Offline ready}} 상태로 바뀝니다. 저장된 사본에는 3D 그래픽 라이브러리(약 2.6 MB)와 이 도움말이 포함되므로, 저장되면 3D 뷰, 모든 내보내기, 도움말이 모두 오프라인에서 작동합니다. 자세한 내용과 여전히 연결이 필요한 항목: [오프라인에서 작업하기](common:offline).

:::offline
현재 오프라인 상태입니다. 앱 바에 {{ui:Offline ready}} 상태가 나타나면 열기, 저장, 내보내기가 평소처럼 작동합니다. 나타나지 않으면 이 탭을 열어 두고, 온라인 상태로 돌아갈 때까지 새로 고치지 말고, 지금 모델을 저장하십시오.
:::

클라우드 저장은 아직 사용할 수 없으며, 데스크톱 빌드도 아직 없습니다. 다른 작업 파일을 백업하듯이 `.detailcraft.json` 파일도 백업합니다. 자세한 내용: [파일이 저장되는 위치](common:your-files).

## 저장되지 않은 작업

DetailCraft는 모델을 열린 탭에만 보관합니다. 저장되지 않은 변경 사항이 있는 상태에서 탭을 닫거나 새로 고치면, 브라우저가 페이지를 떠날지 묻습니다. 이 문구는 브라우저 고유의 문구입니다. {{key:Mod+S}} 키로 자주 저장합니다.
