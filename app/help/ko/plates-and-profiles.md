## 플레이트 배치

플레이트는 보처럼 배치합니다. 두 교차점 사이에 놓이며, 너비는 가로로, 두께는 위쪽으로 향합니다.

1. {{ui:Place}} 그룹에서 {{ui:Plate}}를 선택하거나 {{key:P}}를 누릅니다.
2. {{ui:Properties}} 패널에서 {{ui:Thickness (mm)}}와 {{ui:Width (mm)}}를 설정합니다. 기본값은 A36의 20 x 200입니다.
3. 필요하면 {{ui:Material}}과 {{ui:Rotation (°)}}를 설정합니다. 회전 90은 플레이트를 옆으로 세웁니다.
4. 두 교차점을 클릭하거나 {{ui:Add by grid}} 양식을 사용합니다.

배치된 플레이트의 단면 이름은 `PL<thickness>x<width>` 형식으로 쓰며, 예: PL20x200. 길이는 두 점 사이의 거리입니다.

배치된 플레이트의 크기를 바꾸려면 선택한 다음 {{ui:Thickness (mm)}} 또는 {{ui:Width (mm)}}를 변경합니다.

직접 배치한 플레이트는 독립된 부재입니다(마크 p, 조립품 P). 연결이 만든 엔드 플레이트와 베이스 플레이트도 플레이트이지만, 연결을 통해 바꿉니다. [엔드 플레이트](topic:end-plates)를 참조하십시오.

## 사용자 단면 추가

카탈로그에 필요한 단면이 없으면 치수로 직접 만드십시오. 사용자 단면은 모델에 속하며 모델과 함께 저장됩니다. 모든 새 모델에서 쓰려면 아래 "새 모델을 위해 단면 보관"에 설명된 대로 {{ui:My profiles}}에 보관하십시오.

1. 왼쪽 {{ui:Model}} 패널에서 {{ui:Custom profile}}을 엽니다.
2. {{ui:Name}}을 입력합니다. 예: `W8x18-custom` 또는 `RHS 120x80x5`. 카탈로그 이름이거나 플레이트 이름처럼 보이면 안 됩니다.
3. {{ui:Shape}}을 고릅니다: {{ui:I-shape}}, {{ui:Channel}}, {{ui:Equal angle}}, {{ui:Rectangular tube}}, {{ui:Round tube}} 또는 {{ui:Flat bar}}.
4. 나타나는 치수를 모두 밀리미터로 입력합니다:

| 형상 | 치수 |
|---|---|
| I형강 | 깊이 d, 플랜지 너비 bf, 웨브 tw, 플랜지 tf, 필렛 반지름 r (0 가능) |
| 채널 | 깊이 d, 플랜지 너비 bf, 웨브 tw, 플랜지 tf (직각 모서리) |
| 등변 앵글 | 너비 b(각 날개), 두께 t |
| 각형 튜브 | 높이 h, 너비 b, 두께 t (바깥 모서리 반지름 2t) |
| 원형 튜브 | 지름 D, 두께 t |
| 평철 | 너비 b, 두께 t |

5. 모든 새 모델에 두려면 {{ui:Keep in My profiles}}을 체크한 상태로 두고(아래 참조), 이 모델에만 두려면 체크를 해제합니다.
6. {{ui:Add profile}}를 선택합니다.

상태 표시줄에 "단면 "…" 추가됨. 사용자 항목 아래 모든 단면 목록에 있습니다."라고 표시됩니다. 단면은 이 양식 아래의 목록에 나타나며, 모든 {{ui:Profile}} 목록의 끝에도 나타납니다.

DetailCraft는 그 형상이 실제로 존재할 수 있는지 확인합니다. "웨브와 플랜지가 깊이와 너비 안에 들어가지 않습니다.", "플랜지에 비해 필렛 반지름이 너무 큽니다." 또는 "벽이 너무 두껍습니다." 같은 메시지가 나타날 수 있습니다. 숫자를 고친 다음 {{ui:Add profile}}를 다시 선택하십시오.

### 사용자 단면이 얻는 것

- 면적 × 7850 kg/m³로 미터당 질량을 구합니다(카탈로그 크기는 공표된 중량을 사용합니다).
- 사용자 I형강은 카탈로그 I형강처럼 구멍, 코프, 엔드 플레이트, NC 파일, 제작도를 가집니다.
- 사용자 평철은 플레이트처럼 작동합니다.
- 사용자 채널과 튜브는 구멍을 가질 수 있습니다. 앵글과 원형 튜브는 아직 구멍을 가질 수 없습니다.

단면을 추가한 뒤에는 모델에서 편집하거나 제거할 수 없습니다. 실수했다면 즉시 {{key:Mod+Z}}를 사용하십시오. 수정한 단면에는 새 이름을 붙이십시오.

## 새 모델을 위해 단면 보관

양식 아래에 있는 {{ui:My profiles}} 목록은 사용자 단면을 담은 목록입니다. 이 목록은 이 브라우저와 이 컴퓨터에 저장되며, 모델 파일이나 계정에는 저장되지 않습니다.

- {{ui:Keep in My profiles}}을 체크한 채로 추가한 단면은 목록에 들어갑니다. DetailCraft가 시작할 때 여는 모델을 포함해 모든 새 모델은 목록의 모든 단면으로 시작합니다.
- 모델에 이미 있지만 목록에 없는 단면에는 옆에 {{ui:Keep}} 버튼이 있습니다.
- 내 단면이 없는 모델(예: 오래된 파일)에서는 {{ui:Use here}} 버튼을 선택하여 추가합니다.
- {{ui:Remove}}는 목록에서 단면을 뺍니다. 이미 그 단면을 쓰고 있는 모델은 자체 복사본을 유지합니다.
- 열린 모델은 파일에 저장된 단면을 유지합니다. 파일을 여는 것은 목록을 바꾸지 않습니다.
- 목록에 다른 치수로 이미 있는 이름은 추가가 거부됩니다. 새 단면에는 다른 이름을 붙이십시오.
- 브라우저의 사이트 데이터를 지우거나 다른 브라우저나 컴퓨터를 쓰면 빈 목록으로 시작합니다. 비공개 창에서는 목록을 유지할 수 없으며, 앱이 이를 알려 줍니다.
