## 이 문서에서 배울 내용

AI 어시스턴트(또는 직접 작성한 스크립트)가 DetailCraft와 함께 작동하도록 하는 방법과, 어시스턴트가 무엇을 건드릴 수 있는지 결정하는 방법입니다.

DetailCraft에는 **자체 AI가 없으며** 아무것도 어디에도 보내지 않습니다. Model Context Protocol(MCP)을 사용하는 프로그램은 직접 준비해야 합니다. DetailCraft는 도구만 제공하며, 어떤 도구를 줄지는 사용자가 선택합니다.

## 켜기

1. 설정({{ui:설정}}, 앱 바의 톱니바퀴 또는 {{key:Mod+,}})을 열고 {{ui:DetailCraft}} 탭으로 이동합니다.
2. {{ui:어시스턴트}} 아래에서 **AI 어시스턴트와 스크립트가 DetailCraft를 사용하도록 허용**을 선택합니다. 선택하기 전까지는 꺼져 있습니다.
3. 허용할 작업을 고릅니다. **읽기**는 처음부터 선택되어 있습니다. **편집**, **저장** 또는 **내보내기**는 필요할 때만 선택합니다.

선택한 권한 밖의 도구는 어시스턴트에게 제공되지 않습니다. 그래도 어시스턴트가 요청하면 DetailCraft가 거부하고 활동 기록에 남깁니다. 스위치를 끄면 모든 연결이 즉시 끝납니다.

## 어시스턴트 연결

어시스턴트는 사용자의 컴퓨터에서 **CadCraft Studio**를 통해 연결합니다. Studio는 이 컴퓨터만 접근할 수 있는 작은 서버를 실행하며, 시작할 때마다 새로 만드는 토큰으로 보호됩니다. Studio에서 {{ui:어시스턴트 연결}}을 선택하고 주소와 토큰을 어시스턴트에 복사합니다. Studio에 붙여넣을 정확한 설정이 표시됩니다. 토큰은 절대 공유하지 마십시오.

:::note
브라우저 탭은 어시스턴트를 위한 연결을 열 수 없습니다. 브라우저 앱에서는 컴퓨터의 CadCraft Studio를 사용하기 전까지 스위치가 아무 효과가 없습니다.
:::

## 사용자가 주도권을 가집니다

- **모든 변경은 실행 취소 한 단계입니다.** 어시스턴트의 변경으로 표시됩니다(예: "어시스턴트: 보 추가", "어시스턴트: 거셋 추가"). {{key:Mod+Z}}는 어시스턴트의 마지막 변경 전체를 되돌립니다. 어시스턴트의 `undo`는 어시스턴트 자신의 단계만 되돌리며, 사용자의 변경은 명시적으로 요청하지 않는 한 되돌리지 않습니다.
- **사용자를 기다립니다.** 부재를 배치하거나, 부품을 옮기거나, 붙여넣는 동안에는 DetailCraft가 어시스턴트의 변경을 거부하고 다시 시도하라고 알립니다.
- **연결 여부를 알 수 있습니다.** 연결되어 있는 동안 앱 바의 버튼에 어시스턴트 이름이 표시됩니다. 클릭하면 어시스턴트가 할 수 있는 작업을 확인하거나 **연결 해제**할 수 있습니다.
- **활동.** {{ui:설정}} › {{ui:DetailCraft}} › {{ui:어시스턴트}} › {{ui:활동}}에 모든 호출이 나열됩니다(시각, 도구, 완료 또는 거부). {{ui:기록 저장}}으로 사본을 보관합니다.

## 어시스턴트가 요청할 수 있는 항목

모든 길이는 밀리미터이며, 점은 모델과 같이 z가 위를 향하는 `[x, y, z]`입니다.

| 도구 | 권한 | 역할 |
|---|---|---|
| `app_info`, `model_describe` | 읽기 | 열린 모델: 그리드, 레벨, 단계, 종류와 프로파일별 부재, 접합, 기초, 계단, 부품, 강재 무게, 문제 |
| `parts_list` | 읽기 | 프로파일, 재료, 절단 길이, 개수, 무게, 단계와 조립 마크가 포함된 부품 마크; 종류, 프로파일, 마크 또는 단계별 |
| `problems_list` | 읽기 | {{ui:문제}} 탭에 나열된 항목과 각 항목의 내용 |
| `clash_check` | 읽기 | [간섭 검사](topic:clash-check), 허용 오차와 단계 포함 |
| `selection_get` | 읽기 | 사용자가 선택한 항목 |
| `selection_set` | 편집 | 부재, 접합, 기초 또는 계단을(id 또는 부품 마크로) 선택해 사용자에게 보여 줍니다. 아무것도 바꾸지 않습니다 |
| `member_add` | 편집 | 두 점 사이의 보, 기둥, 가새 또는 판 |
| `connection_add` | 편집 | 주어진 부재가 만나는 곳에 단부 판, 전단 탭, 밑판, 이음 또는 거셋을 만듭니다. {{ui:접합}} 버튼과 같은 방식입니다 |
| `undo` | 편집 | 어시스턴트의 마지막 단계를 되돌립니다 |
| `model_save` | 저장 | DetailCraft 자체 저장 |
| `model_export` | 내보내기 | IFC, NC 파일, 부품표, 벤딩 일람표, KISS 파일 또는 절단 목록을 {{ui:출력}} 버튼으로 만드는 것과 같이 내보냅니다 |
| `usd_export` | 내보내기 | 강재 모델을 USD(.usda, .usdc 또는 .usdz)로 내보냅니다. {{ui:출력}} › {{ui:USD}}가 쓰는 방식과 같습니다([강재 모델을 USD로 내보내기](topic:usd) 참고). Studio에서는 허용한 폴더에 파일을 쓸 수 있습니다 |

## 문제가 생길 때

- **어시스턴트에 DetailCraft 도구가 보이지 않음:** 이 창에서 스위치가 켜져 있는지, 그리고 이 창이 Studio에서 열려 있는지 확인합니다.
- **"편집 권한이 필요합니다"**(또는 저장, 내보내기): {{ui:어시스턴트}} 아래에서 해당 권한을 선택한 뒤 다시 요청합니다.
- **"사용자가 부재를 배치하는 중입니다":** 하고 있는 작업을 마치거나({{key:Esc}}를 누른 뒤), 어시스턴트가 다시 시도하도록 합니다.
- **"401" 또는 "token" 오류:** 토큰이 바뀌었습니다(Studio가 다시 시작되었거나 {{ui:새 토큰}}을 만들었습니다). 새 토큰을 어시스턴트 설정에 복사합니다.
