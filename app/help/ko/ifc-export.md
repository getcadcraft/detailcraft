IFC 내보내기는 모델 전체를 BIM 소프트웨어와 IFC 뷰어에서 열 수 있는 IFC4 파일 하나로 씁니다.

## 내보내기

1. {{ui:출력}} 그룹의 {{ui:IFC}}를 선택합니다.
2. 브라우저가 `<name>.ifc`를 다운로드합니다. 상태 표시줄에 무엇이 들어갔는지 표시됩니다. 예: "IFC4 내보내기 완료: 부재 25개, 체결구 88개, 기초 7개, 철근 132개."

모델에 부재, 기초, 철근이 없으면 상태 표시줄에 "내보낼 항목이 아직 없습니다."라고 표시됩니다.

## 파일에 들어가는 내용

| DetailCraft의 항목 | IFC 파일의 항목 |
|---|---|
| 각 층 | 하나의 프로젝트, 부지, 건물 아래의 건물 층(IfcBuildingStorey) |
| 그리드 | 축과 레이블이 있는 IfcGrid |
| 기둥, 보, 브레이스 | IfcColumn, IfcBeam, IfcMember(브레이스). 각각 표준 단면 형상의 돌출이며 실제 치수를 가짐 |
| 플레이트, 끝 플레이트, 베이스 플레이트 | IfcPlate |
| 구멍과 코프 | 부재에서 잘라 낸 개구부(IfcOpeningElement) |
| 부재와 용접된 플레이트 | 조립 마크를 단 조립품(IfcElementAssembly) |
| 볼트와 앵커 로드 | 지름과 길이가 있는 IfcMechanicalFastener |
| 기초 | 재료가 콘크리트인 IfcFooting(패드 기초) |
| 각 철근 | 철근 마크, 지름, 면적, 길이가 있는 IfcReinforcingBar. 실제 중심선을 따라 굽힘부의 실제 호와 함께 스윕됨 |

각 부재의 태그는 그 부재 마크입니다. 각 요소에는 마크, 단면, 중량이 들어 있는 "DetailCraft" 속성 세트도 있습니다. 각 요소는 자신의 가장 낮은 지점과 같거나 그보다 낮은 가장 높은 층에 놓입니다. 재료는 등급별로 묶입니다.

## 다시 내보낼 때 고정된 ID

모든 요소의 IFC ID(GlobalId)는 모델 이름과 모델 안에서 요소 자신의 ID로부터 계산됩니다. 같은 모델을 두 번 내보내면 ID가 일치하므로, 버전을 비교하는 소프트웨어가 무엇이 바뀌었는지 알 수 있습니다.

:::warning
모델 이름을 바꾸면 모든 ID가 바뀝니다. 프로젝트의 발행본 사이에서는 모델 이름을 같게 유지하십시오.
:::

## 확인

DetailCraft의 IFC 파일은 테스트 스위트의 독립 IFC 리더로 다시 읽어 검증합니다. 프로그램마다 IFC를 해석하는 방식이 다르므로, 의존하기 전에 팀이 쓰는 소프트웨어에서 파일을 여십시오. CadCraft의 BimCraft 앱도 IFC 파일을 엽니다.

## 아직 지원하지 않음

- IFC 파일에서 접합, 기초, 철근 가져오기. {{ui:IFC 가져오기}}는 보, 기둥, 부재, 플레이트, 그리드, 층, 구멍, 코프, 볼트를 가져오며, 가져오지 않은 항목을 목록으로 보여 줍니다.
- 해석 또는 구조 해석 데이터.
- IFC4 참조 뷰 이외의 것.

## 가져오기

{{ui:파일}} 그룹의 {{ui:IFC 가져오기}}(또는 `.ifc` 파일을 뷰에 끌어 놓기)는 IFC2X3 또는 IFC4 파일로 새 모델을 만듭니다.

- **보, 기둥, 부재(브레이스), 플레이트**: 본체가 DetailCraft가 아는 돌출된 단면 하나인 경우 카탈로그와 맞추거나 사용자 정의 단면으로 유지합니다. **그리드**와 **층**은 파일의 그리드와 층에서 만듭니다.
- **구멍**: 가져온 부재의 면에 수직인 원형 개구부(IfcOpeningElement)가 부재를 관통하는 모든 경우. 대상은 I형강이나 채널의 웨브 또는 플랜지, 튜브의 벽, 플레이트, 앵글의 다리입니다. 튜브의 양쪽 벽을 관통하는 구멍은 한 번만 가져옵니다.
- **코프**: I형강이나 채널의 전체 폭을 한쪽 끝에서, 위에서 아래로 또는 아래에서 위로 차지하는 직사각형 개구부.
- **볼트**: 모든 IfcMechanicalFastener 또는 IfcFastener를 지름, 길이, 등급, 종류(볼트 또는 앵커 로드)와 함께 **느슨한 볼트**로 가져옵니다. 느슨한 볼트는 뷰, 자재 명세서, IFC 내보내기에 표시되고, 부재를 옮겨도 제자리에 남습니다. 아무것도 선택하지 않은 상태의 {{ui:속성}} 패널은 이를 세며, 접합을 대신 추가할 때 쓰도록 {{ui:느슨한 볼트 제거}} 버튼이 있습니다.

보고서에는 나머지 모든 항목이 클래스별로 나열되며, 제외된 이유가 함께 표시됩니다. 벽과 슬래브, 기초와 철근, 슬롯 구멍, 둥근 튜브의 구멍, 접합(IFC 파일은 접합의 플레이트와 볼트는 담지만 그것을 만든 규칙은 담지 않음)이 여기에 해당합니다.
