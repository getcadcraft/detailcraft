DetailCraft는 초기 빌드입니다. 이 페이지는 아직 할 수 없는 기능을 나열하므로 작업을 계획하는 데 참고할 수 있습니다. 여기 나온 내용은 출시 날짜에 대한 약속이 아닙니다.

## 모델링

| 아직 미지원 | 대신 지금 할 수 있는 방법 |
|---|---|
| 부재의 한쪽 끝을 드래그하여 늘이기(스트레칭) | {{ui:Properties}} 패널의 {{ui:Ends (x, y, z mm)}} 아래에서 {{ui:Start}} 또는 {{ui:End}} 값을 편집합니다 |
| 선택 필터(보만, 단면 하나만) | 윈도우를 드래그하여 선택한 다음, {{key:Shift}}+클릭으로 부재를 제외합니다 |
| 선택 항목 배열, 경사 축 회전, 경사 평면 대칭 | 오프셋 위치에 복사하여 붙여넣거나 {{ui:Duplicate}}를 사용합니다. 회전과 대칭은 평면에서 작동합니다 ([윈도우로 선택, 이동, 회전, 대칭, 여러 개 변경](topic:select-and-change)) |
| 클릭할 때 격자에서 벗어난 점 | 격자에 배치한 다음 끝 좌표를 입력합니다 |
| 번호 매겨진 격자선을 따른 입면, 저장된 뷰, 작업 평면 | {{ui:3D}}를 사용하거나 {{ui:Add by grid}}를 사용합니다 |
| 3D 뷰에서 실제 절단으로 그린 구멍 | 구멍은 어두운 마개로 표시되며, 모든 내보내기에서는 실제 구멍입니다 |
| 둥글거나 경사진 코프, 기타 절단 및 피팅 | I형강의 직각 코프만 |
| 앵글과 원형 튜브에 직접 추가하는 구멍 | 앵글 구멍은 [브레이스 거셋](topic:brace-gussets)에서만 생깁니다 |
| 인치 단위 입력 | 밀리미터로 입력합니다 (1인치당 25.4) |
| 사용자 단면 편집 또는 제거 | 수정된 단면을 새 이름으로 추가합니다 |

## 계단

| 아직 미지원 | 대신 지금 할 수 있는 방법 |
|---|---|
| 난간, 참, 토 플레이트, 그레이팅 디딤판, 나선형 및 꺾인 계단 | 직선 계단만 가능합니다. [계단](topic:stairs)을 참조하십시오 |
| 바닥에 맞춘 스트링거 끝 절단 | 직각으로 자른 스트링거를 사용하고, 작업장 소프트웨어에서 자르십시오 |

## 연결

DetailCraft는 여섯 가지 연결을 만듭니다: 브레이스 거셋([브레이스 거셋](topic:brace-gussets) 참조), 두 I형강 조각 사이의 볼트 이음([이음](topic:splices) 참조), 각도로 만나는 두 I형강 사이의 마이터 이음(절단만 하거나 볼트 엔드 플레이트 포함, [마이터 이음](topic:mitres) 참조), 레벨에서 수직으로 선 I형강 보와 I형강 기둥의 플랜지 또는 웨브 사이의 평평하거나 연장된 볼트 엔드 플레이트, 보에서 기둥 플랜지 또는 웨브로 가는 전단 탭(직각, 사교 또는 경사), 그리고 앵커 로드 4개가 있는 기둥 베이스 플레이트.

| 아직 미지원 | 대신 지금 할 수 있는 방법 |
|---|---|
| 사교 또는 경사 엔드 플레이트 | [전단 탭](topic:shear-tabs)을 사용하십시오. 사교 및 경사 보에 쓸 수 있습니다 |
| 클립 앵글, 이음 채움판 및 크기가 다른 이음, 보와 기둥에 용접된 코너 거셋, 모따기 거셋 | 다른 소프트웨어에서 상세 설계하거나, 플레이트와 구멍을 별도 부재로 수작업 추가하십시오. [이음](topic:splices), [브레이스 거셋](topic:brace-gussets)을 참조하십시오 |
| 모따기 또는 테이퍼 베이스 스티프너, 그라우트 구멍, 전단 러그용 기초 포켓 | 직사각형 스티프너를 사용하십시오. [베이스 플레이트](topic:base-plates)를 참조하십시오 |
| 헌치, 맞댐 용접 마이터, 다른 부재의 플랜지와 맞춘 스티프너 | 엔드 플레이트와 웨브 스티프너가 있는 [마이터](topic:mitres) 또는 단순 마이터 절단을 사용하고, 다른 플레이트는 부재로 수작업 추가하십시오 |
| 연결 설계 검토(강도) | 기술자의 계산으로 확인하십시오. DetailCraft는 연단 거리와 간격만 경고합니다 |
| 장공 | 원형 구멍만 가능합니다 |

## 해석

| 아직 미지원 | 대신 지금 할 수 있는 방법 |
|---|---|
| 강재 I형강을 넘어선 설계 검토: 튜브, 앵글, 채널, 용접 형상, 가늘거나 4등급 부재, 비틀림, 연결. 콘크리트: 횡변위 세장비, 비틀림, 내진 상세, 슬래브와 벽 | {{ui:Analysis}} 탭은 강재 I형강을 AISC 360 또는 EN 1993-1-1로 검토합니다([강재 부재를 설계 기준으로 검토](topic:design-checks)). 나머지는 "검토 안 됨"으로 표시되며, 모든 결과는 기술자가 검토해야 합니다 |
| 좌굴 해석, 진동 | 2차 해석은 P-Delta만(탄성) 가능합니다. 좌굴 해석은 없습니다. 모달, 응답 스펙트럼, 시간 이력, 푸시오버는 해석 탭에 있습니다 |
| 기술자가 검토한 설계 검토 | 그때까지는 참고용입니다. 의존하기 전에 부재 두세 개를 직접 계산하거나 기술자의 소프트웨어로 확인하십시오 |
| 면적으로 자동 생성되는 바닥, 바람, 적설 하중 | kN/m 또는 kN 단위로 부재에 하중을 직접 지정하십시오 |
| 프레임의 부재 오프셋, 편심 접합, 인장 전용 브레이스, 프레임 안의 플레이트와 기초 | 부재는 작업선 위에서 해석됩니다. 브레이스는 인장과 압축을 받습니다 |

## 철근

| 아직 미지원 | 대신 지금 할 수 있는 방법 |
|---|---|
| 원형 기둥, 스파이럴, 경사 또는 곡선 보, 직사각형이 아닌 슬래브, 직선이 아닌 벽 | 직사각형 보, 기둥, 슬래브, 벽([철근 콘크리트 상세](topic:reinforced-concrete)) |
| 구부려 겹치는 철근, 엇갈린 겹침, 원하는 위치의 겹침 | 같은 간격의 겹침, 한 단면에서 모든 철근 겹침(ACI 클래스 B, EN α6 = 1.5) |
| 개구부의 모서리 철근, 펀칭 전단 보강근, 내진 상세(ACI 318-19 18장) | 개구부 양쪽의 트리머. 나머지는 직접 확인하십시오 |
| 구조 설계 프로그램 자체 파일 읽기 | 그 프로그램에서 IFC를 내보내십시오. 그 IfcReinforcingBar가 철근으로 가져와집니다([IFC 파일의 철근](topic:reinforced-concrete#bars-from-an-ifc-file)) |
| 직선, 한 번 구부림, U형 이외의 형상 코드, 직선 및 한 갈고리 철근의 ACI 315 유형 | 세 가지 형상은 BS 8666 00, 11, 21 또는 ACI Type 2로 표시됩니다. [철근 참조](topic:rebar-reference)를 참조하십시오 |
| BS 4449 H8–H40 이외의 미터법 철근(예: CSA 10M–35M) | ASTM 소프트 미터법 이름 #10–#36 또는 BS 철근 |

## 도면과 내보내기

| 아직 미지원 | 대신 지금 할 수 있는 방법 |
|---|---|
| 세로 방향 시트, A0, 사용자 지정 크기 시트, 경사 격자의 일반 배치도 | 가로 A4~A1 및 ANSI B~D([일반 배치 및 조립 도면](topic:drawings)). 다른 크기로 인쇄하려면 PDF를 배율 조정하십시오 |
| 단일 부재 제작도의 용접 기호, 필렛 이외의 기호 | 조립 도면에는 필렛 용접 기호가 있으며, 제작도는 용접을 텍스트로 나타냅니다 |
| 앱에서 도면 편집 | 모델을 바꾸고 도면을 다시 만드십시오. MarkupCraft 같은 PDF 앱에서 PDF에 주석을 달 수 있습니다 |
| 치수 객체가 있는 DWG 도면, 또는 모델 공간의 실척 모델과 배치로서의 시트 | 각 시트는 종이 기준의 실척 DWG 또는 DXF이며, 치수는 선과 숫자로 표시됩니다([일반 배치 및 조립 도면](topic:drawings#download)) |
| NC 파일의 원형 튜브 구멍, 앵글과 원형 튜브의 코프 | 기록되지 않습니다. [NC 파일 필드](topic:nc1-fields)를 참조하십시오 |
| NC 파일의 베벨, 표시, 내부 윤곽 | 현재 없음 |
| USD 내보내기의 볼트 구멍, 볼트, 용접, 기초 | IFC, NC, BOM 출력에 있습니다. [USD로 강재 모델 내보내기](topic:usd)를 참조하십시오 |
| IFC 파일에서 연결, 기초, 장공 또는 직사각형 구멍, 원형 튜브의 구멍 가져오기 | {{ui:Import IFC}}는 보, 기둥, 부재, 플레이트, 격자, 레벨, 원형 구멍, 코프, 볼트, 철근을 가져오며, 보고서에 제외된 항목이 나열됩니다 |
| 사용자 보고서 레이아웃 | CSV 파일 세 개 |

## 함께 작업하기와 저장

| 아직 미지원 | 대신 지금 할 수 있는 방법 |
|---|---|
| 클라우드 저장 및 컴퓨터 간 동기화 | `.detailcraft.json` 파일을 저장하고 다른 파일처럼 공유하십시오. 클라우드 저장은 아직 사용할 수 없습니다 |
| Live TeamWork 세션에서 다른 사람의 커서와 "편집 중" 표시, 격자, 레벨, 단계의 항목별 병합 | 편집은 여전히 병합됩니다(격자, 레벨, 단계는 통째로 적용되며 나중 변경이 우선). [실시간으로 한 구조를 함께 상세화](topic:work-live)를 참조하십시오 |
| 인터넷을 통한 Live TeamWork 세션 초대 링크 | 같은 네트워크에서 짧은 코드로 참여하십시오 |

## 플랫폼

- DetailCraft는 데스크톱, 노트북, 태블릿 화면을 위해 만들어졌습니다. 휴대폰에서도 작동합니다: 모델은 화면을 유지하고, 보고서는 하단 막대에서 시트로 열리지만 패널을 놓을 공간이 적습니다.
- 오프라인 사용을 하려면 먼저 DetailCraft를 오프라인용으로 저장해야 합니다. 앱 바의 {{ui:Save for offline}}을 사용하십시오. {{ui:Offline ready}} 상태로 바뀌면 이 빌드의 모든 기능이 연결 없이 작동합니다. [오프라인 작업](common:offline)을 참조하십시오.

이 격차 중 하나가 작업을 막는다면 [지원 페이지](https://getcadcraft.com/support)에서 알려 주십시오. 다음에 무엇을 만들지 정하는 데 도움이 됩니다.
