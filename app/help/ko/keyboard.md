이 도움말의 키 표기 방법: [키, 마우스, 트랙패드](common:keys). Mac에서 {{key:Mod}}는 Command 키이며, 그 밖의 환경에서는 Ctrl입니다.

## 도구

커서가 문자 또는 숫자 입력란에 있지 않을 때 작동합니다.

| 키 | 기능 |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:B}} | {{ui:Beam}} |
| {{key:C}} | {{ui:Column}} |
| {{key:R}} | {{ui:Brace}} |
| {{key:P}} | {{ui:Plate}} |
| {{key:F}} | {{ui:Footing}} |
| {{key:S}} | {{ui:Stair}} |
| {{key:M}} | 축선 교차점 두 개를 지정하여 선택 항목 이동 ([윈도우 선택, 이동, 회전, 대칭, 여러 개 변경](topic:select-and-change)) |
| {{key:Esc}} | 끌고 있는 선택 윈도우를 놓거나, 끌고 있던 부재를 원래 자리로 되돌립니다. 이동, 보·브레이스·플레이트의 첫 점, 또는 붙여넣기를 취소합니다. 다시 누르면 {{ui:Select}} 도구로 돌아갑니다. {{ui:Select}} 상태에서는 선택을 해제합니다. {{ui:More}} 메뉴가 열려 있으면 메뉴를 닫습니다 |
| {{key:Delete}} 또는 {{key:Backspace}} | 선택 항목 삭제(선택한 모든 항목, 실행 취소 한 단계) |

## 파일 및 편집

| 키 | 기능 |
|---|---|
| {{key:Mod+S}} | 모델 저장(다운로드). 입력란에 입력하는 중에도 작동합니다 |
| {{key:Mod+O}} | 모델 열기. 입력란에 입력하는 중에도 작동합니다 |
| {{key:Mod+Z}} | 실행 취소(문자 입력란 밖에서; 입력란 안에서는 입력한 내용을 취소합니다) |
| {{key:Mod+Y}} 또는 {{key:Mod+Shift+Z}} | 다시 실행 |

## 복사 및 붙여넣기

커서가 문자 또는 숫자 입력란에 있지 않을 때 작동합니다(입력란에서는 평소처럼 텍스트를 복사, 붙여넣기, 선택합니다). 붙여넣기, 잘라내기, 복제, 삭제는 각각 실행 취소 한 단계입니다. 자세히: [복사, 붙여넣기 및 복제](topic:copy-paste).

| 키 | 기능 |
|---|---|
| {{key:Mod+C}} | {{ui:Copy}}: 선택한 부재와 기초를 구멍, 코프, 접합과 함께 복사합니다 |
| {{key:Mod+X}} | {{ui:Cut}}: 선택 항목을 복사한 뒤 삭제합니다 |
| {{key:Mod+V}} | {{ui:Paste}}: 복사본이 포인터를 따라갑니다. 복사본을 놓을 축선 교차점을 클릭하십시오 |
| {{key:Mod+Shift+V}} | {{ui:Paste in place}}: 복사한 원래 좌표에 붙여넣습니다 |
| {{key:Mod+D}} | {{ui:Duplicate}}: 즉시 복사본을 만들고, [DetailCraft 설정](topic:settings)에 정한 간격 띄우기 값만큼 이동합니다 |
| {{key:Mod+A}} | {{ui:Select all}}: 모든 부재, 접합, 기초 |
| {{key:Esc}} | {{ui:Select none}} |

페이지에서 텍스트를 선택했고(예: 보고서 표) 모델에서는 아무것도 선택하지 않았다면, {{key:Mod+C}}는 평소처럼 텍스트를 복사합니다.

{{ui:New}}, {{ui:Sample}} 및 내보내기에는 키가 없습니다. 도구 모음을 사용하십시오.

대화상자(제작도 미리 보기 또는 질문)가 열려 있는 동안에는 이 키들이 아무 작업도 하지 않습니다.

## 입력란과 패널

| 키 | 기능 |
|---|---|
| {{key:Enter}} 또는 {{key:Tab}} | 입력한 값 적용(변경 한 번이 실행 취소 한 단계) |
| {{ui:Grids}}, {{ui:Levels}}, {{ui:Custom profile}}, 구멍 또는 코프 입력란에서의 {{key:Enter}} | 해당 양식의 버튼을 선택하는 것과 같습니다 |
| {{key:Left}} {{key:Right}} | 탭에 포커스가 있을 때 {{ui:Problems}}, {{ui:Bill of materials}}, {{ui:Bending schedule}} 탭 사이를 이동합니다 |
| {{key:Esc}} | 제작도 미리 보기 또는 질문 대화상자를 닫습니다({{ui:Cancel}} 버튼과 같은 동작) |

## 화면과 도움말

| 키 | 기능 |
|---|---|
| {{key:Ctrl+Shift+F}} | 기본 화면, 전체 화면, 막대를 숨긴 전체 화면을 차례로 전환합니다. 모든 컴퓨터에서 Ctrl을 사용하며 Mac도 마찬가지입니다 |
| {{key:Mod+,}} | {{ui:Settings}} 열기([DetailCraft 설정](topic:settings)) |
| {{key:Esc}} | 전체 화면 종료 |
| {{key:F1}} | 이 도움말 열기 |

## 마우스

| 동작 | 3D에서 | 평면 및 입면에서 |
|---|---|---|
| 클릭 | 부재 선택, 또는 배치 도구가 켜져 있으면 가장 가까운 축선 교차점에 배치(붙여넣는 중이면 그곳에 붙여넣기) | 같음 |
| {{key:Shift}}, {{key:Ctrl}} 또는 {{key:Mod}} 키를 누른 채 클릭 | 부재를 선택에 추가하거나 선택에서 제외 | 같음 |
| 선택한 부재를 누른 채 끌기 | 선택 항목을 같은 레벨 안에서 이동. {{key:Mod}} 키를 누른 채 끌면 위아래로 이동 | 선택 항목 이동(입면에서는 입면선을 따라, 그리고 위아래로 이동) |
| 왼쪽 버튼으로 끌기 | 모델 회전 | {{ui:Select}} 도구 사용 시: 선택 윈도우(오른쪽으로 끌면 완전히 포함된 항목, 왼쪽으로 끌면 닿은 항목). 배치 중에는 초점 이동 |
| {{key:Shift}} 키를 누른 채 왼쪽 버튼으로 끌기 | {{ui:Select}} 도구 사용 시: 선택 윈도우를 기존 선택에 추가. 배치 중에는 초점 이동 | {{ui:Select}} 도구 사용 시: 선택 윈도우를 기존 선택에 추가 |
| {{key:Ctrl}} 또는 {{key:Mod}} 키를 누른 채 왼쪽 버튼으로 끌기 | 초점 이동 | 없음 |
| 오른쪽 버튼으로 끌기 | 초점 이동 | 초점 이동 |
| 휠 | 뷰 중앙을 향해 줌 | 줌 |
| 가운데 버튼으로 끌기 | 줌 | {{ui:Select}} 도구 사용 시: 초점 이동. 그 밖에는 줌 |
| 앱에 `.detailcraft.json` 파일 놓기 | 열기 | 열기 |

클릭은 누를 때와 뗄 때 사이에 포인터가 약 5픽셀 미만으로 움직인 경우에만 인정됩니다. 그보다 길게 움직이면 끌기입니다.

## 트랙패드

| 동작 | 기능 |
|---|---|
| 두 손가락으로 위아래 스와이프 또는 핀치 | 줌 |
| 누른 채 끌기 | 회전(3D) 또는 초점 이동(평면 및 입면) |
| {{key:Shift}} 키를 누른 채 끌기 | 3D에서 초점 이동 |
| 두 손가락 클릭 | 오른쪽 클릭(뷰에는 메뉴가 없습니다) |

## 터치

태블릿이나 터치 화면에서:

| 동작 | 기능 |
|---|---|
| 탭 | 부재 선택, 또는 배치 도구가 켜져 있으면 가장 가까운 축선 교차점에 배치(손가락 너비 정도 이내를 탭하면 인정) |
| 부재를 길게 누르기 | 부재를 선택에 추가하거나 제외(마우스에서 {{key:Shift}}+클릭과 같은 동작) |
| 선택한 부재에 한 손가락을 대고 끌기 | 선택 항목 이동, 축선 교차점에 스냅 |
| 다른 곳에서 한 손가락 | 모델 회전(3D) 또는 초점 이동(평면 및 입면) |
| 두 손가락 | 핀치하여 줌, 함께 움직여 초점 이동 |

화면이 터치만 지원하는 경우 버튼, 목록, 입력란이 더 커집니다. 선택 윈도우에는 마우스가 필요합니다. 손가락으로는 탭과 길게 누르기를 사용하십시오.

## 브라우저가 사용하는 키

일부 단축키는 브라우저에 속하며 어떤 페이지도 사용할 수 없습니다. 예를 들어 {{key:Mod+W}}(탭 닫기), {{key:Mod+T}}(새 탭), {{key:Mod+N}}(새 창)이 있습니다. {{key:Mod+Y}}가 다시 실행 대신 브라우저 기록을 열면 {{key:Mod+Shift+Z}}를 사용하십시오.

단축키는 페이지가 키보드를 가지고 있을 때만 DetailCraft에 전달됩니다. 키가 아무 작업도 하지 않거나 브라우저가 대신 작동하면, 먼저 DetailCraft 창의 빈 부분을 클릭하십시오(예: 주소 표시줄에 입력한 뒤).

## 이동 명령이 있는 곳

이동 명령은 없습니다. 부재를 선택하여 같은 레벨에서 끌거나({{key:Mod}} 키를 누른 채 끌면 위아래로 이동), {{ui:Properties}}에서 {{ui:Start}} 및 {{ui:End}} 값을 수정하십시오.
