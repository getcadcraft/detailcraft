베이스 플레이트 접합은 기둥 아래에 플레이트를 놓고, 플레이트 두께만큼 기둥을 짧게 자르고, 두 부재를 용접한 다음, 플레이트의 구멍을 통해 앵커 로드 네 개를 추가합니다.

:::warning
크기는 시작값이며 설계가 아닙니다. DetailCraft는 지압, 로드 강도, 매입 깊이를 검사하지 않습니다.
:::

## 베이스 플레이트 추가

1. {{ui:선택}} ({{key:V}}) 도구를 선택하고 기둥을 클릭합니다. 기둥은 수직이어야 합니다.
2. {{ui:접합}} 그룹의 {{ui:베이스 플레이트}} 또는 {{ui:속성}} 패널의 {{ui:베이스 플레이트 추가}}를 선택합니다.
3. 상태 표시줄에 "베이스 플레이트를 앵커 로드 네 개와 함께 추가했습니다."라고 표시됩니다. 새 접합이 선택됩니다.

기둥 하나에는 베이스 플레이트를 하나만 둘 수 있습니다. 이미 있으면 상태 표시줄에 "이 기둥에는 이미 베이스 플레이트가 있습니다."라고 표시됩니다.

## 설정 변경

베이스 플레이트를 선택합니다(플레이트 또는 로드를 클릭). {{ui:플레이트, 볼트, 용접 (mm)}} 아래에서 다음을 설정합니다.

| 설정 | 기본값 | 설명 |
|---|---|---|
| 플레이트 두께 | 25 | 기둥이 이만큼 짧아집니다 |
| 플레이트 길이 | 450 | 기둥 깊이 방향 |
| 플레이트 너비 | 400 | 기둥 폭 방향 |
| 로드 지름 | 20 | 앵커 로드 크기 |
| 구멍 지름 | 33 | 플레이트의 구멍 |
| 볼트 등급 | F1554 Gr 36 | 로드 등급(텍스트) |
| 로드 간격 (깊이 방향) | 350 | 플레이트 길이 방향으로 로드 중심 사이 간격 |
| 로드 간격 (폭 방향) | 300 | 폭 방향으로 로드 중심 사이 간격 |
| 플레이트 위 로드 돌출 | 100 | 플레이트 상단에서 로드 상단까지 |
| 플레이트 아래 로드 매입 | 450 | 플레이트 아랫면에서 콘크리트 안쪽으로 |
| 필렛 용접 크기 | 8 | 기둥 베이스 둘레 전체 |
| 플레이트 재료 | A36 | 텍스트 |
| 그라우트 간격 | 0 | 콘크리트 상단과 플레이트 아랫면 사이 간격 |
| 보강재 | 없음 | 없음, 2개(웨브와 일렬), 4개(웨브와 직각으로 추가) 중에서 선택. 아래 참조 |
| 보강재 두께, 높이 | 12, 150 | |
| 전단 러그 깊이 | 0 | 러그가 플레이트 아래로 내려가는 깊이, 0 = 러그 없음 |
| 전단 러그 두께, 너비 | 25, 150 | |
| 플레이트 와셔 | 없음 | 모든 로드에 적용하거나 없음 |
| 와셔 크기, 두께 | 0, 0 | 0 = 로드에 대한 AISC Design Guide 1의 최소값 |

로드 길이 = 매입 깊이 + 그라우트 간격 + 플레이트 두께 + 돌출. 기본값으로는 575 mm입니다.

## 기초 상세: 그라우트, 보강재, 전단 러그, 와셔

네 가지 모두 새 베이스 플레이트에서는 꺼져 있으며, DetailCraft 0.4 이전 모델의 베이스 플레이트도 마찬가지입니다.

- **그라우트 간격.** 플레이트는 콘크리트 상단에서 이 간격만큼 떨어져 놓이고, 로드는 그만큼 길어집니다. AISC Design Guide 1(2.10)은 마감 바닥에는 1 in., 기초나 필러에는 1½~2 in.를 권장합니다. 큰 플레이트나 전단 러그가 있는 플레이트에는 더 크게 합니다.
- **보강재.** 기둥과 플레이트에 용접된 수직 판으로, 기둥 면에서 플레이트 가장자리까지 직사각형으로 만듭니다(모따기나 테이퍼는 아직 없음). **2**개는 웨브와 일렬로 각 플랜지 바깥에 놓이고, **4**개는 플랜지 사이에서 웨브와 직각으로 두 개를 더해 플레이트 측면까지 나갑니다. 튜브 기둥에서는 각 면의 가운데에 놓입니다. 각 보강재는 양쪽에서 기둥과 플레이트에 용접됩니다.
- **전단 러그.** 베이스 플레이트 아래에 둘레 전체를 용접한 판으로, 기둥 깊이 방향으로 가운데에 맞춥니다. 그라우트 간격보다 깊지 않으면 DetailCraft가 경고합니다. 기초에 포켓을 자르지는 않으므로, [간섭 검사](topic:clash-check)에서는 러그와 기초를 제외합니다.
- **플레이트 와셔.** 각 로드에 베이스 플레이트 위에 놓이는 정사각형 플레이트 와셔입니다. 기둥의 조립품에는 풀린 상태(기둥과 함께 배송하며 용접하지 않음; Design Guide 1, 2.6)로 나열됩니다. 크기와 두께가 0이면 DetailCraft가 AISC Design Guide 1, 2판, 표 2.3에서 그 로드에 맞는 최소 와셔를 가져옵니다. 미터법 로드는 다음 인치 크기 행을 씁니다(M20 로드는 7/8 in. 행: 2½ in. × 5/16 in.). 속성 패널에 사용된 크기가 표시됩니다. 와셔의 구멍은 로드 지름 + 1/16 in.이며, 이는 DetailCraft의 선택입니다. 표에는 값이 없습니다. 로드가 와셔와 너트를 끼울 만큼 튀어나오지 않을 수 있으면(돌출 < 와셔 두께 + 로드 지름) DetailCraft가 경고합니다.

Design Guide 1의 표 2.3은 플레이트의 로드 구멍도 권장합니다. ¾ in. 로드에는 1-5/16 in., ⅞ in. 로드에는 1-9/16 in., 1 in. 로드에는 1-13/16 in.입니다. DetailCraft는 구멍 크기를 바꾸지 않습니다.

다음 경우에도 경고가 표시됩니다. 로드 구멍이 플레이트 가장자리에서 구멍 지름의 1.2배보다 가까울 때, 로드가 기둥 외곽 안쪽에 있을 때, 플레이트가 기둥보다 작을 때입니다.

## 비슷한 기둥에 복사

1. 베이스 플레이트를 선택합니다.
2. {{ui:유사 항목에 적용 (n)}} 또는 {{ui:접합}} 그룹의 {{ui:더보기}} 메뉴에서 {{ui:유사 적용}}을 선택합니다.
3. 단면이 같고, 베이스 플레이트가 없으며, 다른 기둥 위에 서 있지 않은 모든 수직 기둥에 사본이 만들어집니다.

## 베이스 플레이트와 기초

베이스 플레이트에는 기초가 필요하지 않으며, 기초는 그 위의 베이스 플레이트를 알지 못합니다. 앵커 로드는 기초의 철근에 묶이지 않습니다. 기초는 {{ui:기초}} 도구로 배치합니다. [철근이 있는 기초 배치](topic:footings-and-rebar)를 참조하십시오.
