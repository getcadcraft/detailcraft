DetailCraft ໝາຍໂມເດວດ້ວຍຕົນເອງ. ບໍ່ມີຄຳສັ່ງໃສ່ເລກ ແລະ ບໍ່ຕ້ອງເຮັດຫຍັງ: ຫຼັງຈາກທຸກການປ່ຽນແປງ ມັນຈະຄິດວ່າຊິ້ນສ່ວນໃດເປັນເຫຼັກຊິ້ນດຽວກັນ ແລະ ໃຫ້ພວກມັນເຄື່ອງໝາຍດຽວກັນ.

## ເຄື່ອງໝາຍຢູ່ໃສ

- ລາຍການ {{ui:Part marks}} ໃນແຜງ {{ui:Model}}: ແຕ່ລະເຄື່ອງໝາຍພ້ອມໂປຣໄຟລ໌, ຄວາມຍາວ ແລະ ຈຳນວນ. ຄລິກໜຶ່ງອັນເພື່ອເລືອກຊິ້ນສ່ວນທຳອິດທີ່ມີເຄື່ອງໝາຍນັ້ນ.
- ແຜງ {{ui:Properties}} ຂອງຊິ້ນໂຄງທີ່ເລືອກ (ແລະ ລາຍການ **Part marks** ໃນແຜງຊ້າຍ): {{ui:Part mark}} ແລະ {{ui:Assembly}}. ຫົວແຜງຍັງມີເຄື່ອງໝາຍນັ້ນ, ເຊັ່ນ "Beam b1".
- ແຖບ {{ui:Bill of materials}}, CSV, ຊື່ໄຟລ໌ NC, ແບບໂຮງງານ ແລະ ການສົ່ງອອກ IFC (ເປັນປ້າຍຂອງແຕ່ລະອົງປະກອບ).

## ວິທີໝາຍຊິ້ນສ່ວນ

- **ເຄື່ອງໝາຍຊິ້ນສ່ວນ:** c ສຳລັບເສົາ, b ສຳລັບຄານ, br ສຳລັບຄ້ຳຢັນ, st ສຳລັບສະເຕຣນເນີບັນໄດ, p ສຳລັບແຜ່ນ (ລວມທັງແຜ່ນປາຍ ແລະ ແຜ່ນຖານ). ຈາກນັ້ນເປັນເລກ: c1, c2, b1, p1 … ເມື່ອຊິ້ນສ່ວນຢູ່ໃນຫຼາຍໄລຍະ, ເລກໄລຍະຈະມາກ່ອນ, ເຊັ່ນ 2-b1.
- **ເຄື່ອງໝາຍການປະກອບ:** C, B, BR ຫຼື P. ການປະກອບແມ່ນຊິ້ນໂຄງຫຼັກ ແລະ ແຜ່ນທີ່ເຊື່ອມຕິດກັບມັນ, ເຊັ່ນ ຄານກັບແຜ່ນປາຍສອງແຜ່ນ, ຫຼື ເສົາກັບແຜ່ນຖານ.
- ສອງຊິ້ນສ່ວນຈະມີເຄື່ອງໝາຍດຽວກັນເມື່ອມີໂປຣໄຟລ໌, ວັດສະດຸ ແລະ ຄວາມຍາວຕັດດຽວກັນ, ແລະ ມີຮູ ແລະ ການຕັດມຸມດຽວກັນ, ທັງໝົດພາຍໃນ 1 mm, ເຖິງແມ່ນວ່າໜຶ່ງໃນນັ້ນຈະຫັນປາຍຕໍ່ປາຍ ຫຼື ກັບຫົວລົງເມື່ອທຽບກັບອີກອັນ.
- ການໃສ່ເລກເລີ່ມຈາກເສົາກ່ອນ, ຈາກນັ້ນຄານ, ຄ້ຳຢັນ ແລະ ແຜ່ນ; ພາຍໃນແຕ່ລະປະເພດ ຕາມຊື່ໂປຣໄຟລ໌, ຍາວສຸດກ່ອນ.

ກົດເຕັມ, ລວມທັງການຫັນທີ່ນັບສຳລັບເຫຼັກຮ່ອງ ແລະ ເຫຼັກສາກ: [ກົດການໝາຍ](topic:mark-rules).

:::warning
ເຄື່ອງໝາຍຖືກຄິດໄລ່ໃໝ່ຫຼັງທຸກການປ່ຽນແປງ, ສະນັ້ນມັນອາດໃສ່ເລກໃໝ່. ການເພີ່ມຊິ້ນສ່ວນ, ປ່ຽນໂປຣໄຟລ໌ ຫຼື ເພີ່ມຮູ ອາດເຮັດໃຫ້ b3 ກາຍເປັນ b4. ໃຫ້ຖືເຄື່ອງໝາຍເປັນທີ່ສຸດພຽງເມື່ອໂມເດວສຳເລັດແລ້ວ, ແລະ ສ້າງ BOM, ໄຟລ໌ NC ແລະ ແບບໂຮງງານຈາກໂມເດວທີ່ບັນທຶກແລ້ວດຽວກັນ.
:::

## ອ່ານບັນຊີວັດສະດຸ

ເປີດແຖບ {{ui:Bill of materials}} ທີ່ດ້ານລຸ່ມ. ມີສາມຕາຕະລາງ.

**ຊິ້ນສ່ວນ**, ພ້ອມນ້ຳໜັກເຫຼັກທັງໝົດໃນຫົວຕາຕະລາງ:

| ຄໍລຳ | ຄວາມໝາຍ |
|---|---|
| Part mark | ຄລິກເພື່ອເລືອກຊິ້ນສ່ວນທຳອິດທີ່ມີເຄື່ອງໝາຍນີ້ |
| Type | beam, column, brace, stringer ຫຼື plate |
| Profile | ຕົວຢ່າງ W16x26 ຫຼື PL20x180 |
| Material | ເກຣດທີ່ທ່ານຕັ້ງ |
| Length (mm) | ຄວາມຍາວຕັດ, ຫຼັງຈາກການເຊື່ອມຕໍ່ |
| Count | ມີຈັກອັນ |
| Unit weight (kg) | ມວນໂປຣໄຟລ໌ຕໍ່ແມັດ × ຄວາມຍາວ |
| Total weight (kg) | ນ້ຳໜັກຕໍ່ອັນ × ຈຳນວນ |

ແຖວສຸດທ້າຍໃຫ້ຈຳນວນ ແລະ ນ້ຳໜັກລວມ.

**ການປະກອບ:** ແຕ່ລະເຄື່ອງໝາຍການປະກອບ, ຊິ້ນໂຄງຫຼັກຂອງມັນ, ທຸກຊິ້ນສ່ວນຂອງມັນ (ເຊັ່ນ "b1 + p1 + p1"), ຈຳນວນ, ນ້ຳໜັກຕໍ່ອັນ ແລະ ນ້ຳໜັກລວມ.

**ໂບລ ແລະ ແກນຢຶດ:** ຈັດກຸ່ມຕາມປະເພດ, ເສັ້ນຜ່າສູນກາງ, ຄວາມຍາວ ແລະ ເກຣດ, ພ້ອມຈຳນວນ.

:::note
ນ້ຳໜັກເປັນນ້ຳໜັກເຕັມ: ຮູ ແລະ ການຕັດມຸມບໍ່ຖືກຫັກອອກ. ໂບລ, ນັອດ, ແຫວນຮອງ ແລະ ແນວເຊື່ອມບໍ່ຢູ່ໃນນ້ຳໜັກເຫຼັກ.
:::

## ດາວໂຫຼດ

ເລືອກ {{ui:Download CSV}} ໃນແຖບ, ຫຼື {{ui:BOM}} ໃນກຸ່ມ {{ui:Output}}. ໄຟລ໌ `<name> BOM.csv` ມີສາມຕາຕະລາງຕໍ່ກັນ, ແຕ່ລະອັນພາຍໃຕ້ຫົວຂໍ້ຂອງມັນ, ໂດຍມີແຖວຫວ່າງຄັ້ງລະຫວ່າງ. ມັນເປີດໃນໂປຣແກຣມສະເປຣດຊີດໃດກໍໄດ້.

## ກວດກ່ອນສົ່ງ

1. ເປີດແຖບ {{ui:Problems}} ແລະ ແກ້ທຸກແຖວ. ການເຊື່ອມຕໍ່ທີ່ສ້າງບໍ່ໄດ້ຈະບໍ່ເພີ່ມແຜ່ນ, ຮູ ຫຼື ໂບລ, ດັ່ງນັ້ນ BOM ຈະຂາດ.
2. ເບິ່ງເຄື່ອງໝາຍທີ່ທ່ານບໍ່ໄດ້ຄາດໄວ້. ສອງຄານທີ່ທ່ານຄິດວ່າຄືກັນແຕ່ມີເຄື່ອງໝາຍຕ່າງກັນ ມັກຈະຕ່າງກັນດ້ວຍຮູ, ການຕັດມຸມ ຫຼື ຄວາມຍາວຕັດ; ເລືອກແຕ່ລະອັນ ແລະ ປຽບທຽບ.
3. ບັນທຶກໂມເດວ, ແລ້ວສົ່ງອອກທຸກຢ່າງຈາກສະຖານະທີ່ບັນທຶກນັ້ນ.
