## ຂະໜາດເຫຼັກ

ອ້າງອີງຈາກ ASTM A615/A615M ຕາຕະລາງ 1 (ລະບົບນິ້ວ-ປອນ). ມິນລີແມັດ ແລະ kg/m ແມ່ນການແປງທີ່ແນ່ນອນຈາກຄ່າ ນິ້ວ ແລະ lb/ft ທີ່ປະກາດໄວ້. ລາຍການສະແດງແຕ່ລະຂະໜາດເປັນ ເຊັ່ນ "#5 (15.9 mm)".

## ຂໍ

ເຫຼັກ ASTM: ຂໍມາດຕະຖານ 90° ຈາກ ACI 318-19 ຕາຕະລາງ 25.3.1: ເສັ້ນຜ່າສູນການດັດດ້ານໃນ 6 db ສຳລັບ #3 ຫາ #8 ແລະ 8 db ສຳລັບ #9 ຫາ #11, ພ້ອມສ່ວນຊື່ຍືດອອກ 12 db ຫຼັງການດັດ. ຂາຂໍ ວັດແບບນອກຫາ ນອກ ເທົ່າກັບ ເຄິ່ງເສັ້ນຜ່າສູນການດັດ + db + 12 db.

ຖ້າຂໍຂອງເຫຼັກໃນຊັ້ນເຫຼັກບໍ່ພໍດີກັບຄວາມເລິກຂອງຮາກຖານພາຍໃນຊັ້ນປົກຄຸມ, DetailCraft ຈະຫຼຸດຂາໃຫ້ພໍດີ ແລະ ລາຍງານຄຳເຕືອນ.

## ຮູບຮ່າງ

DetailCraft ເກັບສາມຮູບຮ່າງ. ຕາຕະລາງການດັດພິມພວກມັນເປັນລະຫັດຂອງ DetailCraft, ເປັນປະເພດ ACI 315 ຫຼື ເປັນລະຫັດຮູບຮ່າງ BS 8666: ເລືອກ **ລະຫັດຮູບຮ່າງຕາຕະລາງການດັດ** ໃນ [ການຕັ້ງຄ່າ DetailCraft](topic:settings) ({{ui:Rebar}}).

| ລະຫັດ | ຮູບຮ່າງ | ຂະໜາດ |
|---|---|---|
| S | ຊື່ | A = ຄວາມຍາວ |
| L | ການດັດ 90° ດຽວ | A = ຂາຫຼັກ, B = ຂາຂໍ, ທັງສອງນອກຫາ ນອກ |
| U | ການດັດ 90° ສອງເທື່ອດ້ານດຽວກັນ | A = ກາງ, B ແລະ C = ສອງຂາ, ນອກຫາ ນອກ |

ເຫຼັກຊັ້ນທີ່ມີ {{ui:End hooks}} ເປີດຢູ່ແມ່ນ U; ຖ້າບໍ່ເປີດແມ່ນ S. ເຫຼັກລໍຖ້າທີ່ມີ {{ui:Hook at the bottom}} ເປີດຢູ່ແມ່ນ L; ຖ້າບໍ່ເປີດແມ່ນ S.

| DetailCraft | BS 8666:2020 | ACI 315-99 (ຮູບ 10) |
|---|---|---|
| S | 00, L = A | ບໍ່ມີເລກປະເພດ |
| L | 11, L = A + B − 0.5r − d | ບໍ່ມີເລກປະເພດ: ຮູບບໍ່ມີເຫຼັກທີ່ມີຂໍດຽວ |
| U | 21, A ແລະ C ແມ່ນຂາ, B ແມ່ນກາງ: L = A + B + C − r − 2d | ປະເພດ 2, ຂໍ A ແລະ G, B ຊື່ |

ເມື່ອໃຊ້ລະຫັດ BS 8666 ຫຼື ACI 315, ຄໍລຳ A, B ແລະ C ຂອງຕາຕະລາງຈະປະຕິບັດຕາມການຕັ້ງຊື່ຂອງມາດຕະຖານນັ້ນ (ກາງຂອງ U ແມ່ນ B).

## ຄວາມຍາວຕັດ

ສຳລັບເຫຼັກ BS 4449 ຄວາມຍາວຕັດແມ່ນສູດ BS 8666 ຂອງລະຫັດຮູບຮ່າງຂອງເຫຼັກ (ດ້ານເທິງ). ສຳລັບເຫຼັກ ASTM ມັນແມ່ນຄວາມຍາວທີ່ແນ່ນອນຂອງເສັ້ນກາງຂອງເຫຼັກ: ສ່ວນຊື່ບວກກັບການດັດເປັນສ່ວນໂຄ້ງ ທີ່ມີລັດສະໝີເທົ່າກັບເຄິ່ງເສັ້ນຜ່າສູນການດັດບວກເຄິ່ງເສັ້ນຜ່າເຫຼັກ. ມັນບໍ່ໄດ້ຄຳນວນຈາກຕາຕະລາງການຫັກການດັດ ສະນັ້ນອາດຕ່າງຈາກຕາຕະລາງທີ່ໃຊ້ການຫັກດັ່ງກ່າວຢູ່ບາງມິນລີແມັດ.

## ການຈັດວາງ

- ຊັ້ນລຸ່ມ: ເຫຼັກຕາມ L ປະກອບເປັນຊັ້ນລຸ່ມ, ເຫຼັກຕາມ B ວາງທັບເທິງ. ແຕ່ລະຊຸດກະຈາຍເທົ່າໆກັນທົ່ວຮາກຖານພາຍໃນຊັ້ນປົກຄຸມ, ຕາມໄລຍະທີ່ທ່ານໃຫ້ ຫຼື ແຄບກວ່າ, ຢ່າງໜ້ອຍສອງເສັ້ນ.
- ເຫຼັກລໍຖ້າ: ຕາຂ່າຍເຫຼັກຕາມ L ແລະ ຕາມ B ໃນໄລຍະທີ່ທ່ານໃຫ້, ຈັດໃຈກາງຢູ່ເທິງຮາກຖານ, ຢືນເທິງຊັ້ນເຫຼັກ ແລະ ຍື່ນເໜືອດ້ານເທິງຕາມການຍື່ນທີ່ທ່ານໃຫ້. ຂໍແຕ່ລະອັນຊີ້ອອກນອກ.
