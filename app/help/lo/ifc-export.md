ການສົ່ງອອກ IFC ຈະຂຽນທັງໂມເດວເປັນໄຟລ໌ IFC4 ໜຶ່ງໄຟລ໌ ທີ່ຊອບແວ BIM ແລະ ໂປຣແກຣມເບິ່ງ IFC ສາມາດເປີດໄດ້.

## ສົ່ງອອກ

1. ເລືອກ {{ui:IFC}} ໃນກຸ່ມ {{ui:Output}}.
2. ບຣາວເຊີຈະດາວໂຫຼດ `<name>.ifc`. ແຖບສະຖານະຈະບອກວ່າມີຫຍັງບ້າງ, ເຊັ່ນ "ສົ່ງອອກ IFC4 ແລ້ວ: 25 ຊິ້ນສ່ວນ, 88 ຕົວຍຶດ, 7 ຮາກຖານ, 132 ເສັ້ນເຫຼັກເສີມ."

ຖ້າໂມເດວບໍ່ມີຊິ້ນສ່ວນ, ຮາກຖານ ຫຼື ເສັ້ນເຫຼັກເສີມ, ແຖບສະຖານະຈະບອກວ່າ "ຍັງບໍ່ມີຫຍັງໃຫ້ສົ່ງອອກ."

## ມີຫຍັງຢູ່ໃນໄຟລ໌

| ໃນ DetailCraft | ໃນໄຟລ໌ IFC |
|---|---|
| ແຕ່ລະລະດັບ | ຊັ້ນອາຄານ (IfcBuildingStorey), ຢູ່ໃຕ້ໂຄງການ, ໄຊຕ໌ ແລະ ອາຄານໜຶ່ງ |
| ກຣິດ | IfcGrid ພ້ອມແກນ ແລະ ປ້າຍຊື່ |
| ເສົາ, ຄານ, ຄ້ຳຢັນ | IfcColumn, IfcBeam, IfcMember (ຄ້ຳຢັນ), ແຕ່ລະອັນເປັນການອັດຮູບຮ່າງໂປຣໄຟລ໌ມາດຕະຖານພ້ອມຂະໜາດຈິງ |
| ແຜ່ນ, ແຜ່ນປາຍ, ແຜ່ນຖານ | IfcPlate |
| ຮູ ແລະ ການຕັດມຸມ | ຊ່ອງເປີດ (IfcOpeningElement) ທີ່ຕັດອອກຈາກຊິ້ນສ່ວນ |
| ຊິ້ນໂຄງ ແລະ ແຜ່ນທີ່ເຊື່ອມຕິດ | ການປະກອບ (IfcElementAssembly) ທີ່ໝາຍດ້ວຍເຄື່ອງໝາຍການປະກອບ |
| ໂບລ ແລະ ແກນຢຶດ | IfcMechanicalFastener ພ້ອມເສັ້ນຜ່າສູນກາງ ແລະ ຄວາມຍາວ |
| ຮາກຖານ | IfcFooting (ຮາກຖານແຜ່ນ), ໂດຍມີຂໍ້ຄວາມຄອນກຣີດເປັນວັດສະດຸ |
| ແຕ່ລະເສັ້ນເຫຼັກເສີມ | IfcReinforcingBar ພ້ອມເຄື່ອງໝາຍເສັ້ນ, ເສັ້ນຜ່າສູນກາງ, ພື້ນທີ່ ແລະ ຄວາມຍາວ, ຖືກກວາດຕາມເສັ້ນກາງທີ່ແທ້ຈິງ ພ້ອມໂຄ້ງຈິງຢູ່ທີ່ການງໍ |

ປ້າຍຂອງແຕ່ລະຊິ້ນສ່ວນແມ່ນເຄື່ອງໝາຍຊິ້ນສ່ວນຂອງມັນ. ແຕ່ລະອົງປະກອບຍັງມີຊຸດຄຸນສົມບັດ "DetailCraft" ທີ່ມີເຄື່ອງໝາຍ, ໂປຣໄຟລ໌ ແລະ ນ້ຳໜັກ. ແຕ່ລະອົງປະກອບຢູ່ໃນຊັ້ນສູງສຸດທີ່ຢູ່ຕ່ຳກວ່າ ຫຼື ເທົ່າກັບຈຸດຕ່ຳສຸດຂອງມັນ. ວັດສະດຸຖືກຈັດກຸ່ມຕາມເກຣດ.

## ID ທີ່ຄົງທີ່ສຳລັບການສົ່ງອອກຄືນ

ID IFC (GlobalId) ຂອງທຸກອົງປະກອບຖືກຄິດໄລ່ຈາກຊື່ໂມເດວ ແລະ ID ຂອງອົງປະກອບນັ້ນໃນໂມເດວ. ເມື່ອສົ່ງອອກໂມເດວດຽວກັນສອງເທື່ອ ID ຈະກົງກັນ, ດັ່ງນັ້ນຊອບແວທີ່ປຽບທຽບລຸ້ນຕ່າງໆຈະບອກໄດ້ວ່າມີຫຍັງປ່ຽນ.

:::warning
ການປ່ຽນຊື່ໂມເດວຈະປ່ຽນ ID ທັງໝົດ. ໃຫ້ຮັກສາຊື່ໂມເດວໃຫ້ຄືເກົ່າລະຫວ່າງແຕ່ລະລຸ້ນຂອງໂຄງການ.
:::

## ກວດສອບ

ໄຟລ໌ IFC ຂອງ DetailCraft ຖືກອ່ານກັບຄືນໂດຍໂປຣແກຣມອ່ານ IFC ອິດສະຫຼະໃນຊຸດທົດສອບຂອງມັນ. ໂປຣແກຣມຕ່າງກັນອ່ານ IFC ຕ່າງກັນ, ດັ່ງນັ້ນໃຫ້ເປີດໄຟລ໌ໃນຊອບແວທີ່ທີມຂອງທ່ານໃຊ້ກ່ອນທີ່ຈະເຊື່ອໃຈມັນ. ແອັບ BimCraft ຂອງ CadCraft ກໍເປີດໄຟລ໌ IFC ໄດ້ເຊັ່ນກັນ.

## ຍັງບໍ່ມີ

- ການນຳເຂົ້າການເຊື່ອມຕໍ່, ຮາກຖານ ແລະ ເຫຼັກເສີມຈາກໄຟລ໌ IFC. {{ui:Import IFC}} ນຳເຂົ້າຄານ, ເສົາ, ຊິ້ນໂຄງ, ແຜ່ນ, ກຣິດ, ລະດັບ, ຮູ, ການຕັດມຸມ ແລະ ໂບລ, ແລະ ລາຍງານສິ່ງທີ່ມັນບໍ່ໄດ້ນຳເຂົ້າ.
- ຂໍ້ມູນການວິເຄາະ ຫຼື ການວິເຄາະໂຄງສ້າງ.
- ສິ່ງອື່ນນອກຈາກມຸມເບິ່ງອ້າງອີງ IFC4.

## ນຳເຂົ້າ

{{ui:Import IFC}} ໃນກຸ່ມ {{ui:File}} (ຫຼື ລາກໄຟລ໌ `.ifc` ໃສ່ມຸມມອງ) ຈະສ້າງໂມເດວໃໝ່ຈາກໄຟລ໌ IFC2X3 ຫຼື IFC4:

- **ຄານ, ເສົາ, ຊິ້ນໂຄງ (ຄ້ຳຢັນ) ແລະ ແຜ່ນ** ທີ່ຕົວຂອງມັນເປັນໂປຣໄຟລ໌ດຽວທີ່ DetailCraft ຮູ້ຈັກ, ຈັບຄູ່ກັບແຄັດຕາລັອກ ຫຼື ເກັບເປັນໂປຣໄຟລ໌ກຳນົດເອງ; **ກຣິດ** ແລະ **ລະດັບ** ຈາກກຣິດ ແລະ ຊັ້ນໃນໄຟລ໌.
- **ຮູ:** ທຸກຊ່ອງເປີດວົງມົນ (IfcOpeningElement ທີ່ເຈາະຊິ້ນສ່ວນທີ່ນຳເຂົ້າມາ) ທີ່ຕັ້ງສາກກັບໜ້າໃດໜຶ່ງຂອງຊິ້ນສ່ວນ: ເອິງ ຫຼື ປີກຂອງເຫຼັກຮູບ I ຫຼື ຮ່ອງ, ຝາທໍ່, ແຜ່ນ, ຫຼື ດ້ານຂອງເຫຼັກສາກ. ຮູທີ່ຜ່ານຝາທັງສອງຂອງທໍ່ຈະຖືກນຳເຂົ້າພຽງຄັ້ງດຽວ.
- **ການຕັດມຸມ:** ຊ່ອງເປີດສີ່ຫຼ່ຽມທີ່ກິນຄວາມກວ້າງເຕັມຂອງເຫຼັກຮູບ I ຫຼື ຮ່ອງຈາກປາຍໜຶ່ງ, ລົງຈາກດ້ານເທິງ ຫຼື ຂຶ້ນຈາກດ້ານລຸ່ມ.
- **ໂບລ:** ທຸກ IfcMechanicalFastener ຫຼື IfcFastener, ພ້ອມເສັ້ນຜ່າສູນກາງ, ຄວາມຍາວ, ເກຣດ ແລະ ປະເພດ (ໂບລ ຫຼື ແກນຢຶດ), ເປັນ **ໂບລຫຼວມ**. ໂບລຫຼວມຈະສະແດງໃນມຸມມອງ, ບັນຊີວັດສະດຸ ແລະ ການສົ່ງອອກ IFC, ແລະ ຢູ່ບ່ອນເກົ່າເມື່ອທ່ານຍ້າຍຊິ້ນໂຄງ. ແຜງ {{ui:Properties}} ເມື່ອບໍ່ໄດ້ເລືອກຫຍັງ ຈະນັບພວກມັນ ແລະ ມີ {{ui:Remove loose bolts}} ສຳລັບເວລາທີ່ທ່ານເພີ່ມການເຊື່ອມຕໍ່ແທນ.

ລາຍງານຈະລະບຸທຸກຢ່າງອື່ນຕາມຊັ້ນພ້ອມເຫດຜົນທີ່ບໍ່ໄດ້ນຳເຂົ້າ: ຝາ ແລະ ແຜ່ນພື້ນ, ຮາກຖານ ແລະ ເສັ້ນເຫຼັກ, ຮູຍາວ, ຮູໃນທໍ່ວົງມົນ, ການເຊື່ອມຕໍ່ (ໄຟລ໌ IFC ມີແຜ່ນ ແລະ ໂບລຂອງມັນ, ແຕ່ບໍ່ມີກົດທີ່ສ້າງມັນ).
