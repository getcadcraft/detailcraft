## Ang gagawin mo

Gamitin ang parehong kasaysayan ng issue gaya ng iba pang miyembro ng team. Tingnan kung aling mga sheet ang ipinadala sa anong revision, at itala ang nangyayari sa site laban sa issue na kinabibilangan nito.

## Mga hakbang

1. Buksan ang **Mga issue at revision**.
2. Piliin ang **Magbasa ng issue history** at piliin ang file na `.issues.json` na na-save mula sa BimCraft o ibang app. Idadagdag ang mga issue at record nito sa iyo. Walang papalitan.
3. Piliin ang **Magdagdag ng record** para sa site instruction, shop drawing, markup set, linked model o note. Piliin ang issue na kinabibilangan nito at ang status nito. Ang file na pipiliin mo ay itatala ayon sa pangalan, laki at SHA-256; mananatili ang file kung nasaan ito.
4. Ang **Drawing changelog** ay nagpapakita ng isang hilera para sa bawat sheet at isang column para sa bawat issue. Ang revision na nasa bracket ay muling inilabas nang walang pagbabago.
5. Ang **I-download ang changelog (CSV)** ay nagsa-save ng mga issue, ng talahanayan ng sheet at ng mga record. Ang **I-save ang issue history** ay nagsusulat ng file na binabasa ng ibang app.

## Dapat tandaan

- Inilalabas pa rin ang mga sheet mula sa Mga Drawing, isa-isang sheet. Lumalabas dito ang mga issue na iyon: ang mga sheet na na-issue sa iisang petsa na may iisang note ay isang issue.
- Ang mga record at issue na binasa mo ay sine-save sa model file. Ang bawat pagbabago ay isang I-undo na hakbang.
- Ang pagbasa ng parehong file nang dalawang beses ay walang idinadagdag na doble. Kapag magkapareho ang dalawang kopya ng record, ang mas bago ang pinananatili.
