މިއީ DetailCraft 0.8 (1 November 2026) އަދި 0.8.1 (2 November 2026) ގައި 0.7 އާ ހިސާބުން ބަދަލުވި ކަންތައް. 0.7 ސްޓީލް މެމްބަރުތައް ޗެކް ކުރިއެވެ؛ 0.8 ލިފްޓްތައް ޕްލޭން ކުރެއެވެ، ކަނެކްޝަންތައް ޕްރޮޕޯޒް ކުރެއެވެ، ފައުންޑޭޝަންތައް އަދި ރީބާ ޗެކް ކުރެއެވެ، އަދި ލަކުޑި އަދި ލައިޓް-ގޭޖް ވޯލް، ފްލޯ އަދި ރޫފް ފްރޭމް ކުރެއެވެ.

## އާ ކަންތައް

### އެރެކްޝަން

- **އެރެކްޝަން ޕްލޭން އަދި މޫވީ.** {{ui:Erection}} ޓެބުގައި ކްރޭނެއް ޚިޔާލުކުރޭ (އެ ހުންނަ ތަން، އޭގެ އެންމެ މަތީ ހުކް، ޗާޓުގައި ނެތް ރިގިންގ)، އަދި އޭގެ ލޯޑް ޗާޓުގެ ރޯތައް ޓައިޕް ކުރޭ. DetailCraft މޮޑެލް ކޮންމެ އެސެމްބްލީއަކަށް އެއްފަހަރު، ފޭޒް އޯޑަރުން އަދި ޓިއަރ ޓިއަރ އިން ލިފްޓް ކުރައްވައި، ކޮންމެ ލިފްޓެއް ރޭޑިއަސްގައި ޗާޓާއި ތިޔަ ސެޓް ކުރި މާޖިންއާ ޗެކް ކުރެއެވެ. {{ui:Save movie}} ކޮންމެ ބްރައުޒަރުގައި އޮފްލައިން ޕްލޭ ވާ HTML ފައިލެއް ލިޔެއެވެ، ފޯނުގައިވެސް. ޗާޓުން ބޮޑު، ރޭޑިއަސް ކަށަވަރު ނުވާ، ނުވަތަ ކޮންމެހެން ބޮޑު ލިފްޓްތައް {{ui:Problems}} ގައި ފެނޭ. އެއީ ތިޔަ އަދަދުތަކުން ހަދާ ޕްލޭނެއް، ލިފްޓް ޕްލޭނެއް ނޫނެވެ. [އެރެކްޝަން ޕްލޭން އަދި މޫވީ](topic:erection-movie) ބަލާ.

### ކަނެކްޝަންސް

- **ކަނެކްޝަން އޮޓޯޕައިލޓް.** {{ui:Autopilot}} ޓެބް ކަނެކްޝަނެއް ނެތް ކޮންމެ ޖޯންޓަށް ބަލައި، ހެދުމުގެ ޝޭޕްސްގެ މަތިން އެއް ޕްރޮޕޯޒް ކުރެއެވެ: ބޭސް ޕްލޭޓްސް، ޝިއާ ޓެބްސް، މޮމަންޓް ބީމްތަކަށް ކުރެވޭ އެންޑް ޕްލޭޓްސް، ސްޕްލައިސް އަދި ގަސެޓްސް. ޔުނިފޯމް ލޯޑެއް ނުވަތަ ޝިއާ ގޮތަކަށް އެންޑެއް ދީފިނަމަ، ބޯލްޓް އަދަދު ބޯލްޓުގެ ޑިޒައިން ސްޓްރެންތަށް ބަލައެވެ. {{ui:Add them all}} ޕްރޮޕޯޒަލްތައް އެއް އަންޑޫ ސްޓެޕަކަށް އިތުރުކުރެއެވެ. އެއީ ރިވިއު ކުރަން ފަށާ އަގުތަކެއް، ކަނެކްޝަން ޑިޒައިނެއް ނޫން.
- **Constructability ޗެކްސް.** {{ui:Problems}}: ރަންޗަކަށް ނުލިބޭ ބޯލްޓް، ސޮކެޓަށް ގާތް ބޯލްޓް، ސައިޒް ސީމާއަށް ބޭރު fillet welds، އަދި ފެނިގެން ހުންނަ ފާރުތަކުގެ ހޮލޯ ސެކްޝަންތައް. Weld access އާއެކު ވެލްޑަރުގެ ޓޯޗަށް ނުލިބޭ ރައުންޑް-އޮލް fillet weld ލިސްޓު ކުރެވެ، އޭގެ މަގުގައި ހުރި ޕާޓާއި، ވެލްގެ ކޮންމެ ބައިގެ އަސަރު ފެނޭ. [Constructability ޗެކްސް](topic:constructability) ބަލާ.

### ފައުންޑޭޝަން އަދި ރީބާ

- **ފައުންޑޭޝަން ޗެކްސް.** {{ui:Foundation}} ޓެބް ފުޓިންގްސް، ކޮމްބައިންޑް ފުޓިންގްސް އަދި މެޓްސް ޗެކް ކުރެއެވެ، ތިޔަ ސިފަކޮށްދިން ބިމުގެ ސިފަ މަތިން: bearing، sliding އަދި overturning ސަރވިސް ލޯޑްސް ގެންގުޅެ؛ flexure، shear، punching، development އަދި މިނިމަމް ސްޓީލް ފެކްޓަރޑް ލޯޑްސް ގެންގުޅެ (ACI 318-19). ފުޓިންގްގެ ގާތުގައިވާ ކޮލަމެއް އޭގެ ކަނާރަ ކެނޑިފައިވާ ސެކްޝަނާއެކު ޗެކް ކުރެވެ. ސެޓްލްމަންޓް ބިމުގެ މޮޑިއުލަސްން ލިބެއެވެ، ފްލެކްސިބަލް މެޓް ސަބްގްރޭޑް މޮޑިއުލަސް މަތިން ސްޕްރިންގްސް މަތީގައި ސޮލްވް ކުރެވެ، އަދި ޕައިލް ގްރޫޕްސާއި ރިޓެއިނިންގ ވޯލްސް އެކަމަކުންވެސް ތަފާތު ޕެނަލްސް ހުރެއެވެ. ކޮލަމް ލޯޑްސް ޓައިޕް ކުރެވޭ ނުވަތަ {{ui:Analysis}} އިން ނެގެވޭ. [ފައުންޑޭޝަން ޗެކްސް](topic:foundation-checks) ބަލާ.
- **ރީބާ ކޮންގެސްޓަން މެޕް.** {{ui:Congestion}} ޓެބް ކޮންމެ ފުޓިންގެއް މަތީން ފެންނަ ގޮތަށް ހީޓް މެޕެއް ހަދައެވެ: ބާރ ތަން ކޮންކްރީޓް ދާންދޭނެ ކުޑަ ތަން، ކްލިއާ ސްޕޭސިން ރޫލާއި ދެކޮޅު، އަދި ތިޔަ ދިން ނަމަ އެންމެ ބޮޑު އެގްރިގޭޓާއި ވައިބްރޭޓަރ ހެޑް. [ރީބާ ކޮންގެސްޓަން މެޕް](topic:rebar-congestion) ބަލާ.

### ފްރޭމިންގ އަދި ސަޕްލައި

- **ލަކުޑި އަދި ލައިޓް-ގޭޖް ފްރޭމިންގ.** {{ui:Framing}} ޓެބް ވޯލް، ފްލޯ އަދި ރޫފް ޕެނަލްތައް ކޮންމެ ޕީސްއާއެކު، ކަޓް ލިސްޓާއި، ގަންނަ ސްޓޮކާއި، ސްކޭލްގައި ޝޮޕް ޑްރޯއިންގާއެކު ފްރޭމް ކުރެއެވެ. {{ui:Place as members}} ޕީސްތައް މޮޑެލްގައި ބަހައްޓައި، {{ui:PDF sheets}} ކޮންމެ ޕެނަލަށް ޝީޓެއް ސޭވް ކުރެއެވެ. ސައިޒްތާއި ސްޕޭސިންގާއި ހެޑާތައް ތިޔަ ވާސްތާ: DetailCraft ލޯޑް ކެރިވެވޭތޯ ބަލައި ނުވެއެވެ. [ލަކުޑި އަދި ލައިޓް-ގޭޖް ފްރޭމިންގ ޕެނަލްސް](topic:framing-panels) ބަލާ.
- **ސަޕްލައަރ ސްޓޮކް އަދި ލީޑް ޓައިމްސް.** {{ui:Supply}} ޓެބް ސަޕްލައަރުގެ ސްޓޮކް ލިސްޓު (CSV) ކިޔައި، ކަޓް ލިސްޓް ގަންނަ ކޮންމެ ސެކްޝަނަކަށް ސްޓޮކުގައި ފުދޭތޯ އަދި އިންތިޒާރު ކިހާ ދިގުތޯ ދައްކައެވެ. ކުޑަ ވި އަދި ލޭޓް ސެކްޝަންތައް {{ui:Problems}} ގައި. އެއްވެސް އޯޑަރެއް ނުކުރެވެ. [ސަޕްލައަރ ސްޓޮކް އަދި ލީޑް ޓައިމްސް](topic:supplier-stock) ބަލާ.

### އެނަލިސިސް އަދި ޑިޒައިން

- **What breaks first?** {{ui:Analysis}} ޓެބުގައި، ބަޓަން ހޯދާ ކަންތައް: ގަވަރންކުރާ ސްޓްރެންތު ކޮމްބިނޭޝަން، އެންމެ ކުޑަ މެމްބަރު، ކޮންމެ ލިމިޓަށް ފުރަތަމަ މެމްބަރު ރަޗު ވާއިރު ލޯޑްސް ކިހާ ގޮތުން ބޮޑުވެދާނެ، އަދި އެންމެ ކުޑަ އެންޑް ޕްލޭޓް ނުވަތަ ޝިއާ ޓެބް އެ ބޯލްޓުތަކުގެ ޝިއާ ސްޓްރެންތު ޢިލްމުން ދެނެގަންނަ ތަން. އެއަށް ކޮމްބިނޭޝަންތައް އަދި ޑިޒައިން ކޯޑެއް ފުރަތަމަ ބޭނުންވޭ. Bearing، block shear، welds އަދި prying ނުބެލެވެ. ތިޔަ ކަނެކްޓެޑް އެސިސްޓަންޓަށްވެސް އެކަން ސުވާލު ކުރެވޭ.
- **ލައިވް.** {{ui:Live: solve again after each edit}} ޓިކް ކުރާ ހިނދު، ކޮންމެ އެޑިޓަކަށްފަހު ފްރޭމް އަލުން ސޮލްވް ކުރެވެއެވެ.
- **ކޮންކްރީޓް، އިތުރު.** ނޮން-ސްވޭ ފްރޭމުގައި ސްލެންޑަރ ކޮލަމެއް އޭގެ މެގްނިފައިޑް މޮމަންޓަށް ޑިޒައިން ކުރެވެ (ACI 318-19 6.6.4.5). ސީސްމިކް ޕީރިއަޑް އެނަލިސިސުން ރޭލީސް މެތަޑުން ނެގެވޭ. ޕްލޭޓުން ހަދާ ސްލެބަކަށް ކޮންމެ ލޭޔަރަކަށް ބޭނުންވާ ސްޓީލް އޭގެ މޮމަންޓުންނާއި ވަން-ވޭ ޝިއާން ލިބެއެވެ. [ކޮންކްރީޓް މެމްބަރު ޗެކް ކުރުން އަދި ސީސްމިކް ލޯޑްސް ހަދުން](topic:concrete-and-seismic) ބަލާ.
- **އިންޖިނިއަރަށް ޗެކް ކުރުމަށް.** ފައުންޑޭޝަން، ކޮންކްރީޓް އަދި What breaks first ނަތީޖާ ކިޔަވާ ކުޑަ މަދަދުތަކެކެވެ. ވިންޑް ލޯޑްސް ހަދާފައި ނުވެއެވެ.

### ހުރިހާ އެޕްގައި

- **ބަސްތައް.** ހެލްޕް ބަސް 54 ގައި. އިނގިރޭސިއިން ބޭރު ބަސްތައް ވަނީ މެޝިން ޑްރާފްޓް، ބަސްދާ މީހަކު ކިޔަވާ ވަރަށް ކުރީ. ދިހަ އާ: Lithuanian، Latvian، Bosnian، Marathi، Telugu، Albanian، Afrikaans، Filipino، Swahili، Uzbek.
- **ޓޫލްބާ ރޯތައް.** {{ui:Settings}} › {{ui:General}} › {{ui:Toolbar rows}} ގައި wrap، 2 rows ނުވަތަ 1 row ނިންމައި ޗޮއިސް ކުރޭ. ފިޓް ވާ ބާ އޭގެ ހާލުގައި ހުރެގެން، ބާކީ ސްކްރޯލް ކުރެވެ.
- **ޕްރޮޕަރޓީ ގްރިޑް.** ފުޓިންގްގެ ފީލްޑްތައް ޝެއާކުރާ ގްރިޑް ބޭނުން ކުރެއެވެ: ފޯލްޑް ކުރެވޭ ކެޓަގަރީތަކާއި ކޮމްޕެކްޓް ޑެންސިޓީ. ޓައިޕް ކުރާ ހިސާބު، މިސާލަކަށް 2*450، އަދިވެސް މަސައްކަތް ކުރެއެވެ.
- **އިންޕުޓް ޑިވައިސް.** ޓްރެކްޕެޑް، ޕެން، 3D މައުސް، ކޮންޓްރޯލަރ އަދި MIDI އިން އެޕްތައް ހިންގެވޭ. [3D ގައި ހިނގުން](topic:navigate-3d) ބަލާ.
- **Problems ޕެނަލް.** މަތީގައިވާ އާ ޗެކްތަކުގެ އިންޒާރުތައް ކުރިން ފަދައިން އެއް {{ui:Problems}} ޕެނަލުގައި ފެނޭ.
- **ތިޔަ AI ގުޅުން.** ތިޔަ އަމިއްލަ އެސިސްޓަންޓް، CadCraft Studio އާއި ގުޅާފައި، ހުރިހާ އަށެއް އެޕާއެކު މަސައްކަތް ކުރެއެވެ، އަދި ތިޔަ ދޭ ކަންތައް ނޫން ދެކެ ނުވެއެވެ. އެއް ކްލިކް ކަނެކްޓް، ހޯސްޓް ކަނެކްޓަރ އަދި Studio ގައި ތިޔަ އަމިއްލަ API ކީ އަދިވެސް އަންނަން ބާކީއެވެ. [DetailCraft އަކާ AI އެސިސްޓަންޓް ބޭނުން ކުރުން](topic:use-with-ai-assistants) ބަލާ.

## 0.8.1 ގައި ފިކްސް ކުރެވުނު

- **Studio ގައި ބަސްތައް.** Studio އަދި ޕެކްޑް އެޑިޝަންތައް ރަންޓައިމުގައި ބަސް ބަދަލު ކުރެވޭ؛ ކުރީން އިނގިރޭސި އެކަނި އޮތީ. ހުރިހާ ޕްލެޓްފޯމެއްގައި ޓެސްޓް ނުކުރެވިފައެވެ: ބަސް ބަދަލު ނުވެއްޖެނަމަ އަހަރެމެންނަށް ކިޔައިދޭ.
- **ކްރޮސިންގ-ވިންޑޯ ސެލެކްޓް.** 0.8.1 އިންސްޓޯލަރުތަކުގައި 0.8 ވެބް ބިލްޑުގައި ކުރިން ރަނގަޅުވެފައިވާ ވިންޑޯން ޚިޔާރު ކުރާ ގޮތް ވެސް ހިމެނެއެވެ؛ ކުރީގެ އިންސްޓޯލަރެއް ނުހިމެނުނެވެ.
- **ޕޯޓްރެއިޓުގައި ޓެބްލެޓް.** ވާސްތަ ގްރިޑް އުސްމިން ކެންވަހަށް ދެވެ، އަދި ޝީޓް ލޭއައުޓް 760 px ނުވަތަ ކުޑަ ތަނުން ފަށައެވެ.

## މި ވާރޝަނުގައި އަދި ނެތް

- **NC މެޝިނަށް ފޮނުވުން** އަދި ނިކުމެފައި ނެތް.
- **ވިންޑް ލޯޑްސް** ކޮންކްރީޓަށް ނެތް، އަދި ކޮންކްރީޓް އަދި ފައުންޑޭޝަން ޗެކްތައް އިންޖިނިއަރަށް ރިވިއު ކުރުމަށް.
- **ކޯޑް ސައިނިންގ.** Windows އިންސްޓޯލަރުތަކާއި macOS .dmg ސައިން ކޮށްފައެއް ނޫން، އެހެންކަމުން Windows އިންޒާރު ދިނެވިދާނެ، އަދި macOS ރައިޓް-ކްލިކް ކުރުމާ، ދެން ހުޅުވާ ބޭނުންވެއެވެ.
