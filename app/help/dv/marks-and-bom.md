DetailCraft މޮޑެލަށް އިސްވެސް ނިޝާން ލެއްވެއެވެ. ނަމްބަރިންގ ކޮމާންޑެއް ނެތް، އެއްވެސް ކަމެއް ރަން ކުރުމަށް ނެތް: ކޮންމެ ބަދަލަކަށް ފަހު، ކޮން ޕާޓުތައް އެއް ބައި ސްޓީލް ކަން ގުރުގައި ބެލުމާއެކު އެ އެކުންދު އެއް ނިޝާނެއް ދެއެވެ.

## ނިޝާންތައް ފެންނަ ތަން

- {{ui:Model}} ޕެނަލުގެ {{ui:Part marks}} ލިސްޓް: ކޮންމެ ނިޝާނާއެކު އޭގެ ޕްރޮފައިލް، ދިގާއި ގިނަކަން. ނިޝާނެއް ކްލިކްކޮށް އެ ނިޝާނާއެކު ފުރަތަމަ ޕާޓް ޚިޔާރުކުރޭ.
- ޚިޔާރުކުރެވުނު މެމްބަރުގެ {{ui:Properties}} ޕެނަލް (އަދި ގަނޑު ފެނުމުގެ **Part marks** ލިސްޓް): {{ui:Part mark}} އަދި {{ui:Assembly}}. ޕެނަލްގެ ހެޑިންގ ވެސް ނިޝާން ދައްކާ، މިސާލަކަށް "Beam b1".
- {{ui:Bill of materials}} ޓެބް، CSV، NC ފައިލްގެ ނަންތައް، ޝޮޕް ޑްރޯއިންގ އަދި IFC އެކްސްޕޯރޓް (ކޮންމެ އެލިމަންޓުގެ ޓެގްގެ ގޮތުގައި).

## ޕާޓްތައް ކިހިނެއް ނިޝާން ކުރެވޭ

- **Part marks:** c ތަނބުތަކަށް، b ބީމަށް، br ބްރޭސަށް، st ސްޓޭރ ސްޓްރިންގަރަށް، p ޕްލޭޓަށް (އެންޑް ޕްލޭޓް އަދި ބޭސް ޕްލޭޓް ހިމެނިގެން). ދެން އަދަދެއް: c1، c2، b1، p1 … ޕާޓްތައް ފޭހާ ގިނަ ފޭސްތަކުގައި ހުންނާނަމަ، ފޭސް އަދަދު ފުރަތަމަ އަންނާނެއެވެ، މިސާލަކަށް 2-b1.
- **Assembly marks:** C، B، BR ނުވަތަ P. އެސެމްބްލީ އަކީ މެއިން މެމްބަރާއި އޭގައި ވެލްޑްކުރެވުނު ޕްލޭޓުތަކެވެ، މިސާލަކަށް ބީމަކާއި އެންޑް ޕްލޭޓް ދެކެނޑި، ނުވަތަ ތަނބަކާއި ބޭސް ޕްލޭޓް.
- ދެ ޕާޓަކަށް އެއް ނިޝާން ލިބެނީ އެމީހުންގެ ޕްރޮފައިލް، މެޓީރިއަލް އަދި ކަޓް ދިގު އެއްވެސް ކަމަށްވާއިރު، އަދި ހޯލްތަކާއި ކޯޕްސް އެއް ވާއިރު، 1 mm ތެރޭގައި، އެއްޗެއް އެހެންކަމެއް އަނެއް މަތީން ނުވަތަ ދަށުން އަނެއްކާކަށް ހުރިނަމަވެސް.
- ނަމްބަރިންގ ފެށޭނީ ތަނބުތަކުން، ފަހުން ބީމް، ބްރޭސް އަދި ޕްލޭޓް؛ ކޮންމެ ގްރޫޕެއްގައި ޕްރޮފައިލް ނަމުން، ދިގު ފުރަތަމަ.

ފުރިހަމަ ގޮތުން ޓާންސް ކުރުން: [Mark rules](topic:mark-rules)، އެ ގައި ހިމެނޭ ޗެނަލް އަދި އޭންގަލް ސާބިތު ކޮށް ހުރި ގޮތްތައް.

:::warning
ކޮންމެ ބަދަލަކަށް ފަހު ނިޝާންތައް އާއެކު ހިސާބު ކުރެވޭ، އެހެންކަމުން ނަމްބަރު ބަދަލުވެވޭ. ޕާޓެއް އިތުރުކުރުމާއި، ޕްރޮފައިލް ބަދަލުކުރުމާއި، ހޯލް އިތުރުކުރުމުން b3 b4 ވެވޭ. މޮޑެލް ނިންމާތުމަށް ފަހު ނިޝާންތައް ފަހުގެ ގޮތުގައި ހަދާ، އަދި BOM، NC ފައިލްތައް އަދި ޝޮޕް ޑްރޯއިންގ އެއް ސޭވް ކުރެވުނު މޮޑެލްތަކުން ހަދާށެވެ.
:::

## މެޓީރިއަލް ބިލް ކިޔަވާ

ތިރީގައި {{ui:Bill of materials}} ޓެބް ހުޅުވާ. އޭގައި ތިން ޓޭބަލް ހުރި.

**Parts**، ހެޑިންގ ތެރޭގައި ހުރިހާ ސްޓީލް ބަރާއެކު:

| ކޮލަމް | މާނައާ |
|---|---|
| Part mark | މި ނިޝާނާއެކު ފުރަތަމަ ޕާޓް ޚިޔާރުކުރުމަށް ކްލިކްކުރޭ |
| Type | beam، column، brace، stringer ނުވަތަ plate |
| Profile | މިސާލަކަށް W16x26 ނުވަތަ PL20x180 |
| Material | ތިޔަ ސެޓް ކުރި ގްރޭޑް |
| Length (mm) | ކަޓް ދިގު، ކަނެކްޝަންތަކުން ފަހު |
| Count | ކިތަނެއް |
| Unit weight (kg) | ޕްރޮފައިލްގެ ވަޒަންގެ މީޓަރ × ދިގު |
| Total weight (kg) | ޔުނިޓް ވަޒަން × ގިނަކަން |

ފަހު ދަރަނި ގިނަކަން އަދި ވަޒަން ދެއެވެ.

**Assemblies:** ކޮންމެ އެސެމްބްލީ ނިޝާނެއް، އޭގެ މެއިން ޕާޓް، އޭގެ ހުރިހާ ޕާޓް (މިސާލަކަށް "b1 + p1 + p1")، ގިނަކަން، ޔުނިޓް ވަޒަން އަދި ޓޮޓަލް ވަޒަން.

**Bolts and anchor rods:** ބާވަތް، ޑަޔާމީޓަރ، ދިގު އަދި ގްރޭޑް މިންވަރުން ގްރޫޕްކޮށް، ގިނަކަމާއެކު.

:::note
ވަޒަންތައް ގްރޮސް: ހޯލްތަކާއި ކޯޕްސް ނަކަނޑާ. ބޯލްޓް، ނަޓް، ވޮޝާ އަދި ވެލްޑްތައް ސްޓީލް ވަޒަނުގައި ނުހިމެނޭ.
:::

## ޑައުންލޯޑުކުރޭ

ޓެބުގައި {{ui:Download CSV}} ނުވަތަ {{ui:Output}} ގްރޫޕުގެ {{ui:BOM}} ޚިޔާރުކުރޭ. `<name> BOM.csv` ފައިލުގައި ތިން ޓޭބަލް އެކަނި ފަހެ ފަހަރު، ކޮންމެ އެއްގެ ޓައިޓްލް ދަށުން، ކޮންމެ ރޯއާ ގެންގުޅޭ ހުސް ލައިނެއްގައި. އެއް ސްޕްރެޑްޝީޓް ޕްރޮގްރާމްގައި ހުޅުވޭ.

## ފޮނުވާށެކޭ ކުރިން ބަލާ

1. {{ui:Problems}} ޓެބް ހުޅުވައި ހުރިހާ ލައިނެއް ސާފު ކުރޭ. ހަދަން ނޫން ކަނެކްޝަނެއް ނުވަތަ ޕްލޭޓް، ހޯލް އަދި ބޯލްޓް ނުދޭ، އެހެންކަމުން BOM ކުޑަވާނެއެވެ.
2. ހިތައް ނުފޮނި ނިޝާންތައް ބަލާ. ތިޔަ ހިތުން އެއްގޮތް ބީމްތައް އެކި ނިޝާންތަކާއެކު ހުރި ނަމަ، އެއީ އެއް ހޯލް، ކޯޕް ނުވަތަ ކަޓް ދިގުގެ ފަރަގުން: ކޮންމެ ޗާޓް ޚިޔާރުކޮށް ބަރާބަރު ބަލާ.
3. މޮޑެލް ސޭވް ކުރޭ، ދެން އެ ސޭވްކުރި ގޮތުން ހުރިހާ އެކްސްޕޯރޓެއް ހަދާ.
