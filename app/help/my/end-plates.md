အဆုံးပလိတ် ချိတ်ဆက်မှုသည် beam အဆုံးတွင် ပလိတ်ကို ဂဟေဆော်ပြီး ကော်လံ flange သို့မဟုတ် web သို့ bolt ဖြင့် ချိတ်သည်။ DetailCraft သည် ပလိတ်ကို နေရာချ၊ beam ကို နောက်သို့ ဖြတ်၊ ပလိတ်နှင့် ကော်လံ flange တွင် ကိုက်ညီသော အပေါက်များ တူးပြီး၊ bolt နှင့် ဂဟေကို ထည့်ကာ အစွန်းအကွာအဝေးနှင့် အကွာအဝေးကို စစ်ဆေးသည်။

:::warning
DetailCraft သည် ချိတ်ဆက်မှုကို ဒီဇိုင်းမလုပ်ပါ။ ဆက်တင်များသည် သင်ပြောင်းရန် စတင်တန်ဖိုးများ ဖြစ်သည်; ခိုင်ခံ့မှုကို ဘာမျှ မစစ်ပါ။ အစွန်းနှင့် အကွာအဝေး သတိပေးချက်များသည် EN 1993-1-8 Table 3.3 ၏ အနည်းဆုံးတန်ဖိုးများကို သုံးသည်၊ သင်လိုက်နာသော စည်းမျဉ်းများနှင့် ကွဲပြားနိုင်သည်။
:::

## ဘာကို ချိတ်နိုင်သလဲ

- **အဆင့်တူ** beam (ဆုံးဖျားနှစ်ခုလုံး အမြင့်တူ)၊ ထောင်ရပ် (လှည့်ပတ်မှု 0)၊ I-shape ပရိုဖိုင်ဖြင့်။
- **ဒေါင်လိုက်** I-shape ကော်လံ၏ **flange** သို့မဟုတ် **web** ထဲသို့၊ ၎င်းနှင့် ထောင့်မှန်ဖြင့်။
- beam ဆုံးဖျားသည် ကော်လံ၏ မျဉ်းပေါ်တွင်၊ ကော်လံ၏ အောက်ခြေနှင့် အထက်ပိုင်းကြား ရှိရမည်။

ထောင့်စောင်းသော သို့မဟုတ် စောင်းနေသော beam နှင့် I မဟုတ်သော section များကို အကြောင်းပြ၍ ငြင်းပယ်သည်: ထိုအတွက် [shear tabs](topic:shear-tabs) ကို သုံးပါ။ web ပေါ်တွင် ပလိတ်နှင့် beam flange များသည် ကော်လံ flange များကြား ဝင်ရမည်; မဝင်လျှင် DetailCraft က သတိပေးသည်။

:::tip
လှည့်ပတ်မှု 0 တွင် ကော်လံ flange များသည် နံပါတ်ထားသော ဂရစ်ဦးတည်ချက် (x) ဘက်သို့ မျက်နှာမူသည်။ A မှ B သို့ သွားသော beam သည် web ကို တွေ့ပြီး web ပေါ်တွင် အဆုံးပလိတ် ရရှိသည်။
:::

## beam သို့ အဆုံးပလိတ် ထည့်ရန်

1. {{ui:Select}} ({{key:V}}) ကို ရွေးပြီး beam ကို နှိပ်ပါ။
2. {{ui:Connect}} အုပ်စုတွင် {{ui:End plates}} ကို ရွေးပါ၊ သို့မဟုတ် {{ui:Properties}} အကန့်ရှိ {{ui:Add end plates}} ကို ရွေးပါ။
3. ကော်လံ flange သို့မဟုတ် web နှင့် ထောင့်မှန် တွေ့သော beam ၏ လွတ်နေသော ဆုံးဖျားတိုင်းသည် ပလိတ်ရရှိသည်။ status bar က "အဆုံးပလိတ် 2 ခု ထည့်ပြီး။ ပလိတ်၊ bolt နှင့် ဂဟေ ပြောင်းရန် တစ်ခု ရွေးပါ; Similar က ၎င်းနှင့်တူသော ဆက်စပ်နေရာများသို့ ကူးသည်။" ဟု ပြောသည်။
4. ပထမ အဆုံးပလိတ်အသစ်ကို ရွေးထားပြီး ၎င်း၏ ဆက်တင်များသည် {{ui:Properties}} အကန့်တွင် ရှိသည်။

တစ်ခုမှ မဖြစ်လျှင် status bar ကို ဖတ်ပါ-

- "ဤ beam သည် ကော်လံမျဉ်းပေါ်တွင် မဆုံးပါ။ အဆုံးပလိတ်များသည် beam ဆုံးဖျားသည် ဒေါင်လိုက်ကော်လံနှင့် တွေ့သည့်နေရာသို့ သွားသည်။"
- "ဤ beam သည် ကော်လံနှင့် ထောင့်တစ်ခု သို့မဟုတ် စောင်းတွင် တွေ့သည်: အဆုံးပလိတ်များသည် ထောင့်မှန်၊ အဆင့်တူ ဆက်စပ်နေရာများအတွက် တည်ဆောက်ထားသည်။ Shear tabs ကို သုံးပါ။"
- "ဆုံးဖျားနှစ်ခုလုံးတွင် ချိတ်ဆက်မှု ရှိပြီးသား။"

## ပလိတ်၊ bolt နှင့် ဂဟေ ပြောင်းရန်

အဆုံးပလိတ် (သို့မဟုတ် ၎င်း၏ bolt တစ်ခု) ကို နှိပ်ပြီး ချိတ်ဆက်မှုကို ရွေးပါ။ {{ui:Plate, bolts and weld (mm)}} အောက်တွင်-

| ဆက်တင် | မူလတန်ဖိုး | ဘာလုပ်သလဲ |
|---|---|---|
| ပလိတ်အထူ | 20 | ပလိတ်၏ အထူ; beam ကို flange ကျော်၍ ဖြတ်ရမည့် အကွာအဝေးလည်း ဖြစ်သည် |
| ပလိတ်အကျယ် | 180 | ဆက်စပ်နေရာတစ်လျှောက် |
| beam အထက် တိုးချဲ့ | 0 | အပေါ် flange အထက်; 0 ထက်ကြီးလျှင် တိုးချဲ့ အဆုံးပလိတ် ဖြစ်သည် |
| beam အောက် တိုးချဲ့ | 0 | အောက် flange အောက် |
| Bolt အချင်း | 20 | အမည်ခံ bolt အရွယ်အစား |
| အပေါက် အချင်း | 22 | ပလိတ်နှင့် ကော်လံ flange ရှိ သင့် clearance အပေါက် |
| Bolt အဆင့် | A325 | စာသား; ပစ္စည်းစာရင်းတွင် ပုံနှိပ်သည် |
| Bolt အတန်းများ | 4 | bolt နှစ်ခုစီ၏ အတန်း၊ ပလိတ်အမြင့်အလယ်တွင် ဗဟို |
| အတန်း pitch | 75 | အတန်းများကြား ဒေါင်လိုက် အကွာအဝေး |
| Gauge | 100 | အတန်းတစ်ခု၏ bolt နှစ်ခုကြား အလျားလိုက် အကွာအဝေး |
| Bolt အရှည် ခွင့်ပြုချက် | 30 | nut၊ washer နှင့် thread အတွက် grip သို့ ထည့်သည်; အောက်တွင် ကြည့်ပါ |
| Fillet weld အရွယ် | 8 | beam ဆုံးဖျား ပတ်လည်အကုန် |
| ပလိတ်ပစ္စည်း | A36 | စာသား |

တန်ဖိုးအသစ် ရိုက်ထည့်ပြီး {{key:Enter}} သို့မဟုတ် {{key:Tab}} ကို နှိပ်ပါ။ ပလိတ်၊ အပေါက်များ၊ bolt များနှင့် beam ၏ ဖြတ်အရှည် ချက်ချင်း ပြောင်းသည်။ ပြောင်းလဲမှု တစ်ခုစီသည် undo အဆင့်တစ်ခု ဖြစ်သည်။

ဆက်တင်များအောက်တွင် ချိတ်ဆက်မှု ဖြစ်စေသည်များကို တွေ့ရသည်-

- {{ui:Bolts}}: ဥပမာ "8 × 20 × 70 A325 (grip 36.2)"။
- {{ui:Weld}}: အရွယ်အစား၊ ဘယ်နေရာ၊ နှင့် ၎င်း၏ အရှည်။
- {{ui:Plate}}: ၎င်း၏ အရွယ်အစားနှင့် အစိတ်အပိုင်းအမှတ်အသား။

### ဂဏန်းများ တွက်ပုံ

- beam ကို ကော်လံအနက်၏ တစ်ဝက် (web ပေါ်တွင်: web အထူ၏ တစ်ဝက်) နှင့် ပလိတ်အထူ ပေါင်းပြီး နောက်သို့ ဖြတ်သည်၊ ထို့ကြောင့် ပလိတ်သည် မျက်နှာပေါ်တွင် ထိုင်သည်။
- ပလိတ်အမြင့်သည် beam အနက်နှင့် တိုးချဲ့မှု နှစ်ခု ပေါင်းဖြစ်သည်။
- Bolt အရှည် = grip (ပလိတ်အထူ + ကော်လံ flange သို့မဟုတ် web အထူ) + ခွင့်ပြုချက်၊ နောက် 5 mm သို့ အပေါ်သို့ ပြည့်သည်။
- ပြသသော ဂဟေအရှည်သည် beam section ၏ ပတ်လည်အရှည် ဖြစ်သည်။

### သတိပေးချက်များ

ချိတ်ဆက်မှုသည် ဆက်တည်ဆောက်သော်လည်း အောက်ပါများသည် ၎င်းအောက်နှင့် {{ui:Problems}} တဘ်တွင် ပေါ်သည်-

- bolt အတန်းများ သို့မဟုတ် bolt များသည် ပလိတ်အစွန်းနှင့် 1.2 × အပေါက်အချင်းထက် နီးသည်။
- အတန်း pitch သည် 2.2 × အပေါက်အချင်းထက် နည်းသည်၊ သို့မဟုတ် gauge သည် 2.4 × အပေါက်အချင်းထက် နည်းသည်။
- အပေါက်များသည် ကော်လံ web သို့မဟုတ် ၎င်း၏ fillet ထဲ ဝင်သည်၊ သို့မဟုတ် ကော်လံ flange အပြင်ဘက် ထွက်သည်။
- ပလိတ်သည် ကော်လံ flange ထက် ကျယ်သည်၊ သို့မဟုတ် (web ပေါ်တွင်) flange များကြား နေရာထက် ကျယ်သည်; beam flange များ ၎င်းတို့ကြား မဝင်နိုင်ပါ။
- bolt အတန်းသည် beam flange နှင့် နီးလွန်းသည်၊ သို့မဟုတ် gauge သည် beam web နှင့် ၎င်း၏ ဂဟေအတွက် ကျဉ်းလွန်းသည်။

## တူညီသော ဆက်စပ်နေရာတိုင်းသို့ ကူးရန်

1. သင်သတ်မှတ်ထားသော ချိတ်ဆက်မှုကို ရွေးပါ။
2. {{ui:Properties}} အကန့်ရှိ {{ui:Apply to similar (n)}} ကို ရွေးပါ၊ သို့မဟုတ် {{ui:Connect}} အုပ်စု၏ {{ui:More}} မီနူးရှိ {{ui:Similar}} ကို ရွေးပါ။ ကွင်းထဲရှိ နံပါတ်သည် ၎င်းကို ရရှိမည့် ဆက်စပ်နေရာ အရေအတွက် ဖြစ်သည်။
3. beam ပရိုဖိုင်နှင့် ကော်လံပရိုဖိုင် တူညီပြီး၊ beam သည် တူညီသော မျက်နှာအမျိုးအစားသို့ ဝင်သော၊ ချိတ်ဆက်မှု မရှိသေးသော ဆက်စပ်နေရာတိုင်းသည် တူညီသော ဆက်တင်ဖြင့် မိတ္တူရရှိသည်။ status bar က အရေအတွက်ကို ပြောသည်။

မိတ္တူများသည် လွတ်လပ်သည်: နောက်မှ တစ်ခုကို ပြောင်းလျှင် အခြားများ မပြောင်းပါ။ ချိတ်ဆက်မှု ရှိပြီးသား ဆက်စပ်နေရာများကို မထိပါ; အစားထိုးလိုလျှင် ဦးစွာ ဖျက်ပါ။

## ရွှေ့ရန်နှင့် ဖျက်ရန်

ချိတ်ဆက်မှုများသည် မော်ဒယ် ပြောင်းသည့်အခါတိုင်း ၎င်းတို့၏ ဆက်တင်များမှ ပြန်ဖန်တီးသည်၊ ထို့ကြောင့် beam သို့မဟုတ် ကော်လံကို ရွှေ့ခြင်း သို့မဟုတ် အရွယ်ပြောင်းခြင်းသည် အဆုံးပလိတ်များကို ပါလိုက်စေသည်။ ပြောင်းလဲမှုက ဆက်စပ်နေရာ မကိုက်တော့လျှင် ချိတ်ဆက်မှုသည် မော်ဒယ်တွင် ကျန်နေပြီး {{ui:Problems}} တဘ်က အကြောင်းပြသည်၊ ဥပမာ "beam ဆုံးဖျားသည် ကော်လံမျဉ်းပေါ် မရှိတော့ပါ။"

ချိတ်ဆက်မှုကို ဖျက်ရန် ရွေးပြီး {{key:Delete}} ကို နှိပ်ပါ။ beam သို့မဟုတ် ကော်လံကို ဖျက်လျှင် ၎င်း၏ ချိတ်ဆက်မှုများကိုလည်း ဖျက်သည်။
