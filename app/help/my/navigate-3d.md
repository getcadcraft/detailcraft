view တွင် မုဒ် သုံးမျိုးရှိသည်၊ ၎င်းအပေါ်ရှိ view bar တွင် ရွေးသည်: {{ui:3D}}၊ {{ui:အပေါ်ပုံ}} နှင့် {{ui:အမြင်ပုံ}}။ mouse ခလုတ်များသည် 3D တွင် Plan နှင့် Elevation ထက် မတူညီစွာ လုပ်ဆောင်သဖြင့် ဇယား နှစ်ခုလုံးကို ဖတ်ပါ။

## 3D တွင်

:::mouse
| လုပ်ချင်သည် | ဤအတိုင်း လုပ်ပါ |
|---|---|
| model ပတ်လည် လှည့်ရန် | ဘယ်ခလုတ်ဖြင့် ဆွဲပါ |
| pan | ညာခလုတ်ဖြင့် ဆွဲပါ၊ သို့မဟုတ် {{key:Shift}} ကိုင်ပြီး ဘယ်ခလုတ်ဖြင့် ဆွဲပါ |
| zoom | wheel ကို လှည့်ပါ၊ သို့မဟုတ် အလယ်ခလုတ်ဖြင့် အပေါ်အောက် ဆွဲပါ (wheel ကို နှိပ်ထား) |
| အစိတ်အပိုင်း ရွေးရန် | နှိပ်ပါ (pixel အနည်းငယ်ထက် လျော့ရွေ့သော နှိပ်ခြင်း) |
| model တစ်ခုလုံး ကြည့်ရန် | view bar ၏ ညာဘက်အဆုံးရှိ ကိုက်ညီအောင် ခလုတ် |
:::

:::touch
| လုပ်ချင်သည် | ဤအတိုင်း လုပ်ပါ |
|---|---|
| model ပတ်လည် လှည့်ရန် | လက်ချောင်းတစ်ချောင်းဖြင့် ဆွဲပါ |
| pan | လက်ချောင်းနှစ်ချောင်းဖြင့် ဆွဲပါ |
| zoom | လက်ချောင်းနှစ်ချောင်းဖြင့် pinch လုပ်ပါ |
| အစိတ်အပိုင်း ရွေးရန် | တို့ပါ |
| model တစ်ခုလုံး ကြည့်ရန် | view bar ၏ ညာဘက်အဆုံးရှိ ကိုက်ညီအောင် ခလုတ် |
:::

ညာဘက်ထိပ်ရှိ view cube (view bar အောက်) သည် model နှင့်အတူ လှည့်သည်: မျက်နှာ၊ အနားသား သို့မဟုတ် ထောင့်ကို နှိပ်ပြီး ထိုနေရာမှ ကြည့်ပါ၊ ဆွဲပြီး လှည့်ပါ၊ သို့မဟုတ် အိမ်ပုံခလုတ်ကို နှိပ်ပြီး စတင်သည့်နေရာသို့ ပြန်သွားပါ။ [View cube](topic:view-cube) ကို ကြည့်ပါ။

model သည် view ၏ အလယ်ပတ်လည် လှည့်သည်၊ wheel သည် pointer ဆီသို့ မဟုတ်ဘဲ view ၏ အလယ်ဆီသို့ zoom လုပ်သည်။ ထောင့်တစ်ခုကို နီးကပ်ကြည့်ရန် အရင် အလယ်သို့ pan လုပ်ပြီး ထို့နောက် zoom လုပ်ပါ။

| zoom | wheel ကို လှည့်ပါ၊ သို့မဟုတ် အလယ်ခလုတ်ဖြင့် အပေါ်အောက် ဆွဲပါ |
| အစိတ်အပိုင်း ရွေးရန် | နှိပ်ပါ |

| zoom | လက်ချောင်းနှစ်ချောင်းဖြင့် pinch လုပ်ပါ (လက်ချောင်းနှစ်ချောင်း ဆွဲလျှင်လည်း pan ဖြစ်သည်) |
| အစိတ်အပိုင်း ရွေးရန် | တို့ပါ |
:::

## Mac trackpad တွင်

:::mac
- **Zoom:** လက်ချောင်းနှစ်ချောင်းဖြင့် အပေါ် သို့မဟုတ် အောက် swipe လုပ်ပါ၊ သို့မဟုတ် pinch လုပ်ပါ။ နှစ်ခုလုံးသည် view သို့ zooming အဖြစ် ရောက်သည်။
- **လှည့် (3D):** trackpad ကို နှိပ်ပြီး လက်ချောင်းတစ်ချောင်းဖြင့် ဆွဲပါ။ tap to click သုံးလျှင် ဆွဲခြင်းကို **System Settings, Accessibility, Pointer Control, Trackpad Options** တွင် ဖွင့်ထားလျှင် double-tap နှင့် ဆွဲခြင်းလည်း အလုပ်လုပ်သည်။
- **Pan (3D):** {{key:Shift}} ကိုင်ပြီး ဆွဲပါ။ ဆွဲနေစဉ် {{key:Ctrl}} သို့မဟုတ် {{key:Mod}} ကိုင်ထားလျှင်လည်း pan ဖြစ်သည်။ လက်ချောင်းနှစ်ချောင်း နှိပ်ခြင်းသည် right-click ဖြစ်သော်လည်း trackpad ပေါ်တွင် ၎င်းဖြင့် ဆွဲခြင်းမှာ ခက်ခဲသည်။
- **Pan (Plan နှင့် Elevation):** ဆွဲရုံသာ။
- Magic Mouse တွင် အလယ်ခလုတ် မရှိပါ: pan လုပ်ရန် {{key:Shift}} ဆွဲခြင်းကို သုံးပြီး zoom လုပ်ရန် မျက်နှာပြင်ပေါ်တွင် swipe ကို သုံးပါ။
:::

mouse မသုံးဘဲ right-click နှင့် pan လုပ်ခြင်းအကြောင်း နောက်ထပ်: [Keys၊ mice နှင့် trackpads](common:keys)။

## Plan နှင့် Elevation က နေရာချရန် လွယ်ကူစေသည်

3D တွင် အဆင့်မတူသော intersection များသည် မျက်နှာပြင်ပေါ် အပေါ်အောက် ထပ်နေနိုင်ပြီး နှိပ်ခြင်းသည် အနီးဆုံး အစက်ဆီ ရောက်သည်။ Plan နှင့် Elevation တွင် သင်ကြည့်နေသော အဆင့် သို့မဟုတ် grid လိုင်း၏ အစက်များကိုသာ ရွေးနိုင်သည်။

1. {{ui:အပေါ်ပုံ}} ကို ရွေးပြီး ခလုတ်ဘေးရှိ စာရင်းမှ အဆင့်တစ်ခုကို ရွေးပါ။ view သည် ထိုအဆင့်ကို အပေါ်မှ ကြည့်သည်; ၎င်းထက် 1.5 m အထက်ရှိ အရာတိုင်းကို ဖြတ်ထုတ်သည်။
2. သို့မဟုတ် {{ui:အမြင်ပုံ}} ကို ရွေးပြီး အက္ခရာ grid လိုင်းတစ်ခုကို ရွေးပါ ("ဂရစ် A", "ဂရစ် B" …)။ view သည် ထိုလိုင်းကို တိုက်ရိုက်ကြည့်သည်; ၎င်းနှင့် 1 m အတွင်းရှိ သံကိုသာ ပြသသည်။

Elevation များသည် အက္ခရာ grid လိုင်းများပေါ်တွင်သာ ရှိသည်။ နံပါတ်ပေး grid လိုင်းများ (A မှ B အထိ ဖြတ်သော frame) ပေါ်တွင် အလုပ်လုပ်ရန် {{ui:3D}} ကို သုံးပါ၊ သို့မဟုတ် {{ui:ဂရစ်ဖြင့် ထည့်ရန်}} ပုံစံတွင် ရိုက်၍ နေရာချပါ။ [ကော်လံ၊ beam နှင့် brace များ နေရာချခြင်း](topic:place-members#place-by-grid-without-clicking) ကို ကြည့်ပါ။

## ရွေးခြင်း

- အစိတ်အပိုင်းကို ရွေးရန် နှိပ်ပါ။ highlight အရောင်ပြောင်းပြီး {{ui:ဂုဏ်သတ္တိများ}} panel တွင် ပြသည်။
- ရွေးချယ်မှု ရှင်းရန် လွတ်နေသော နေရာကို နှိပ်ပါ၊ သို့မဟုတ် {{key:Esc}} ကို နှိပ်ပါ။
- သံသည် ကွန်ကရစ်ထက် ဦးစားပေးသည်: ကြည့်ထိုးနိုင်သော footing အတွင်းရှိ ကော်လံကို နှိပ်လျှင် ကော်လံကို ရွေးသည်။ footing ကို ရွေးရန် ကော်လံနှင့် ဝေးသော footing သို့မဟုတ် ၎င်း၏ bar တစ်ခုကို နှိပ်ပါ။
- bolt သို့မဟုတ် end plate ကို နှိပ်လျှင် ၎င်း၏ ချိတ်ဆက်မှုကို ရွေးသည်။
- Plan နှင့် Elevation တွင် ဖြတ်ထုတ်ထားသော အစိတ်အပိုင်းများကို နှိပ်၍မရပါ။
- {{key:Shift}} (သို့မဟုတ် {{key:Ctrl}}၊ {{key:Mod}}) ကိုင်ပြီး နှိပ်လျှင် အစိတ်အပိုင်းကို ရွေးချယ်မှုသို့ ထည့်သည် သို့မဟုတ် ဖယ်သည်; {{key:Mod+A}} သည် အားလုံးကို ရွေးသည်။ ဝင်းဒိုး (ဘောက်စ်ဆွဲ) ရွေးချယ်မှု ယခုမရှိသေးပါ။ အများအပြားဖြင့် ဘာလုပ်နိုင်သလဲ: [ကူး၊ ကူးထည့်နှင့် ပွားခြင်း](topic:copy-paste)။

စာရင်းမှလည်း ရွေးနိုင်သည်: ဘယ်ဘက်ရှိ {{ui:အစိတ်အပိုင်း အမှတ်အသားများ}} တွင် mark တစ်ခုကို နှိပ်ပါ၊ {{ui:ပစ္စည်းစာရင်း}} tab တွင် part mark တစ်ခုကို နှိပ်ပါ၊ သို့မဟုတ် {{ui:ပြဿနာများ}} ရှိ လိုင်းတစ်ခုဘေးရှိ {{ui:ရွေးရန်}} ကို နှိပ်ပါ။

## view မှားနေပါက

- model ပျောက်သွားသလား? ကိုက်ညီအောင် ခလုတ်ကို ရွေးပါ။
- view သည် ဗလာ သို့မဟုတ် မီးခိုးရောင် WebGL အကြောင်း မက်ဆေ့ဂျ်ဖြင့်ဖြစ်ပါက: [ပြဿနာဖြေရှင်းခြင်း](topic:troubleshooting#the-3d-view-is-missing) ကို ကြည့်ပါ။
- 3D view မရှိဘဲ ၎င်းအတွင်း နှိပ်ခြင်းမှလွဲ၍ အရာအားလုံး ဆက်အလုပ်လုပ်သည်: panel များ၊ အစီရင်ခံစာများနှင့် ထုတ်ယူမှုများ အားလုံး run ပြီး {{ui:ဂရစ်ဖြင့် ထည့်ရန်}} သည် ရိုက်ထည့်ခြင်းဖြင့် အဖွဲ့ဝင်များ နေရာချသည်။
