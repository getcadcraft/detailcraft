DetailCraft တွင် ကိုယ်ပိုင် ဖိုင်တစ်ခုဖြစ်သည့် မော်ဒယ် တစ်ခုနှင့် ထုတ်ယူမှု ငါးခု ရှိသည်။ သိမ်းခြင်းနှင့် ထုတ်ယူခြင်းတိုင်းမှာ ဒေါင်းလုဒ် ဖြစ်သည်။ ဘာမျှ upload မလုပ်ပါ၊ ဆာဗာတွင်လည်း ဘာမျှ မသိမ်းပါ။

## မော်ဒယ်ဖိုင်

DetailCraft မော်ဒယ်ကို `<name>.detailcraft.json` အဖြစ် သိမ်းသည်။ ဤတွင် `<name>` သည် {{ui:Model}} panel ရှိ မော်ဒယ် အမည် ဖြစ်သည်။ ၎င်းတွင် grid များ၊ level များ၊ အဖွဲ့ဝင်များ (အပေါက်နှင့် cope များပါသည်)၊ ချိတ်ဆက်မှုများနှင့် ၎င်းတို့၏ ဆက်တင်များ၊ အုတ်မြစ်များနှင့် သင်၏ စိတ်ကြိုက် ပရိုဖိုင်များ ပါဝင်သည်။

အစိတ်အပိုင်းများ၊ အမှတ်အသားများ၊ bolt များ၊ weld များနှင့် bar များကို သိမ်းထားခြင်း မရှိပါ။ DetailCraft သည် ဖွင့်တိုင်း မော်ဒယ်မှ ၎င်းတို့ကို ပြန်တွက်ပေးသည်။ ထို့ကြောင့် မော်ဒယ်ဖိုင်သည် သေးငယ်သည်။

### သိမ်းရန်

1. {{ui:Model}} panel ၏ထိပ်ရှိ {{ui:Name}} အကွက်တွင် အမည် ရိုက်ထည့်ပါ။
2. {{ui:File}} အုပ်စုရှိ {{ui:Save}} ကို ရွေးပါ၊ သို့မဟုတ် {{key:Mod+S}} ကို နှိပ်ပါ။
3. Browser က `<name>.detailcraft.json` ကို ဒေါင်းလုဒ် လုပ်သည်။ Status bar တွင် "Saved … (downloaded)" ဟု ပြပြီး browser tab ခေါင်းစဉ်အစရှိ အစက်လေး ပျောက်သွားသည်။

သိမ်းတိုင်း ဒေါင်းလုဒ် အသစ် ဖြစ်သည်။ Browser က သင်ဖွင့်ထားသော ဖိုင်ကို ထပ်မရေးပါ။ ၎င်း၏ ဆက်တင်အလိုက် `Frame (1).detailcraft.json` ကဲ့သို့ နံပါတ် ထည့်သည် သို့မဟုတ် သိမ်းမည့်နေရာ မေးသည်။ ဗားရှင်းကိုယ်ပိုင် ထားလိုပါက ဒေါင်းလုဒ်များကို အမည်ပြောင်း၍ ထားပါ။

:::chromium
Chrome နှင့် Edge သည် browser ၏ ဒေါင်းလုဒ် ဆက်တင်တွင် **Ask where to save each file before downloading** ဖွင့်မထားပါက သင့် Downloads ဖိုင်တွဲသို့ သိမ်းသည်။ ဖိုင်တွဲနှင့် ဖိုင်အမည်ကို အကြိမ်တိုင်း ရွေးလိုပါက ၎င်းကို ဖွင့်ပါ။
:::

:::firefox
Firefox သည် သင့် Downloads ဖိုင်တွဲသို့ သိမ်းသည်။ ဆက်တင်တွင် **Always ask you where to save files** ဖွင့်ထားပါက အကြိမ်တိုင်း မေးသည်။
:::

:::safari
Safari သည် သင့် Downloads ဖိုင်တွဲသို့ သိမ်းသည်။ ဖိုင်တွဲ ပြောင်းလိုပါက **Safari, Settings, General, File download location** ကို ဖွင့်ပါ။
:::

### ဖွင့်ရန်

1. {{ui:File}} အုပ်စုရှိ {{ui:Open}} ကို ရွေးပါ၊ သို့မဟုတ် {{key:Mod+O}} ကို နှိပ်ပါ။
2. `.detailcraft.json` ဖိုင်တစ်ခုကို ရွေးပါ။

သို့မဟုတ် ဖိုင်ကို {{pick:mac=Finder|windows=File Explorer|linux=သင့်ဖိုင်မန်နေဂျာ}} မှ ဆွဲ၍ view ပေါ်သို့ ချလိုက်ပါ။ ဆွဲနေစဉ် view တွင် "Drop a DetailCraft model to open it" ဟု ပြသည်။

ဖွင့်ထားသော မော်ဒယ်တွင် မသိမ်းရသေးသော ပြောင်းလဲမှုများ ရှိပါက DetailCraft က ပထမဆုံး မေးသည်: {{ui:Cancel}}၊ {{ui:Discard changes}} သို့မဟုတ် {{ui:Save first}}။

DetailCraft သည် ဖိုင်၏ field တိုင်းကို အသုံးမပြုမီ စစ်ဆေးသည်။ အသုံးမပြုနိုင်သည်များကို ချန်ထားပြီး status bar တွင် ၎င်း၏ အကြောင်းကို ပြသည်၊ ဥပမာ "2 members were not valid and left out." ပြန်သိမ်းထားသော DetailCraft ဗားရှင်းသစ်ဖြင့် သိမ်းထားသည့် မော်ဒယ်ကို တစ်စိတ်တစ်ပိုင်းမှား၍ မဖွင့်ဘဲ မက်ဆေ့ချ်ဖြင့် ငြင်းပယ်သည်။

### ဖွင့်နိုင်သည့်ဖိုင်များ

ကိုယ်ပိုင် မော်ဒယ်ဖိုင်များ (`.json`၊ 50 MB အထိ) နှင့် IFC ဖိုင်များ (`.ifc`၊ IFC2X3 သို့မဟုတ် IFC4၊ 200 MB အထိ)။ IFC ဖိုင်ကို ဖွင့်သည့်အခါ သို့မဟုတ် {{ui:Import IFC}} ဖြင့် သွင်းသည့်အခါ ၎င်းသည် beam၊ column၊ အဖွဲ့ဝင်၊ plate၊ grid နှင့် level များပါသော မော်ဒယ် အသစ် တစ်ခု ဖြစ်လာသည်။ အပေါက်နှင့် cope များကို ဖြတ်ထားပြီး bolt များကို လွတ်သော bolt များအဖြစ် ထားသည်။ ချန်ထားခဲ့သည်များကို အစီရင်ခံစာတွင် ဖော်ပြသည်။ [IFC export](topic:ifc-export#import) ကို ကြည့်ပါ။ DWG၊ DXF သို့မဟုတ် အခြား detailing program ၏ မော်ဒယ်ကို ယခုအချိန်တွင် မဖွင့်နိုင်သေးပါ။ ကြိုးစားပါက "DetailCraft opens its own models (.detailcraft.json) and IFC files (.ifc)." ဟု ပြသည်။

## ဆုံးရှုံးသွားသော အလုပ်၊ မကြာသေးမီ ဖိုင်များ၊ desktop app

- မော်ဒယ်တွင် သင်မသိမ်းရသေးသော ပြောင်းလဲမှုများ ရှိနေစဉ် DetailCraft သည် ဤ browser တွင် မိတ္တူတစ်ခု သိမ်းထားသည်။ သိမ်းမီ tab သို့မဟုတ် browser ပိတ်သွားပါက နောက်တစ်ကြိမ် DetailCraft ဖွင့်သည့်အခါ **Recover your work?** ဟု မေးသည်: မိတ္တူကို ပြန်ယူရန် သို့မဟုတ် ဖျက်ပစ်ရန်။ [Recover your work](common:recover) ကို ကြည့်ပါ။
- Browser က ခွင့်ပြုပါက မကြာသေးမီက ဖွင့်ထားသော မော်ဒယ်များကို စတင်စခရင်တွင် ဖော်ပြသည်။ တစ်ခုကို နှိပ်၍ ပြန်ဖွင့်ပါ။
- Desktop app တွင် {{ui:Save}} သည် မော်ဒယ်ကို သင်ဖွင့်ထားသော ဖိုင်သို့ ပြန်ရေးသည် (browser တွင်မူ မိတ္တူ ဒေါင်းလုဒ် လုပ်သည်)။ DetailCraft မော်ဒယ် သို့မဟုတ် IFC ဖိုင်ကို နှစ်ချက်နှိပ်ပါက DetailCraft တွင် ဖွင့်သည်။

## ထုတ်ယူမှုများ

ထုတ်ယူမှု အားလုံးသည် မော်ဒယ်အမည်ကို အသုံးပြုသည်။ {{ui:Output}} အုပ်စုတွင် ရွေးပါ။

| ခလုတ် | ဖိုင် | အတွင်းပါသည့်အရာ |
|---|---|---|
| {{ui:IFC}} | `<name>.ifc` | IFC4: storey များ၊ grid များ၊ ရုပ်ပိုင်း ဒြပ်ပစ္စည်း အစိတ်အပိုင်းတိုင်းကို ပရိုဖိုင် extrusion အဖြစ် အပေါက်နှင့် cope များပါ၊ assembly များ၊ bolt နှင့် anchor rod များ၊ အုတ်မြစ်များနှင့် bar အားလုံး။ [Export IFC](topic:ifc-export) ကို ကြည့်ပါ။ |
| {{ui:NC files}} | `<name> NC.zip` | အစိတ်အပိုင်း အမှတ်အသား တစ်ခုစီအတွက် DSTV `.nc1` ဖိုင် တစ်ခု။ [Send NC files to the shop](topic:nc-export) ကို ကြည့်ပါ။ |
| {{ui:BOM}} | `<name> BOM.csv` | ဇယား သုံးခုကို ဖိုင်တစ်ခုတွင်: အစိတ်အပိုင်းများ၊ assembly များ၊ နှင့် bolt နှင့် anchor rod များ။ [Marks and the bill of materials](topic:marks-and-bom) ကို ကြည့်ပါ။ |
| {{ui:Bending}} | `<name> bending schedule.csv` | အုတ်မြစ်များရှိ bar အမှတ်အသား တိုင်းကို။ [Footings and rebar](topic:footings-and-rebar) ကို ကြည့်ပါ။ |
| {{ui:Shop drawing}} | `<name> <mark>.pdf` | `<name> Shop drawings.pdf` တွင် အစိတ်အပိုင်း အမှတ်အသား တစ်ခုစီအတွက် စာမျက်နှာ ပါသည်၊ {{ui:Download this sheet}} က ပြနေသည့်တစ်ခုကို ပေးသည် (အခြားအရွယ် မရွေးပါက A3)။ [Make shop drawings](topic:shop-drawings) ကို ကြည့်ပါ။ |
| {{ui:Drawings}} | `<name> drawings.pdf`၊ `<name> <sheet>.pdf`; `<name> <sheet>.dwg` သို့မဟုတ် `.dxf`၊ အများအပြားကို `<name> drawings DWG.zip` (သို့မဟုတ် `DXF.zip`) တွင် | သင်ရွေးသော စာရွက်အရွယ်အပေါ်တွင် အပေါ်ပုံ၊ အမြင်ပုံနှင့် assembly ပုံဆွဲများ။ DWG နှင့် DXF ကို အပြည့်အစုံ အရွယ်ဖြင့်၊ စက္ကူပေါ်တွင် 1 unit = 1 mm။ [General-arrangement and assembly drawings](topic:drawings) ကို ကြည့်ပါ။ |

### CSV ဖိုင်များအကြောင်း မှတ်ချက်များ

- Spreadsheet program များက အက်ဆင့် ပါသော စာလုံးများကို မှန်ကန်စွာ ဖတ်နိုင်ရန် ဖိုင်စတင်ရာတွင် byte-order mark ပါသည်။
- `=`၊ `+`၊ `-` သို့မဟုတ် `@` ဖြင့် စသော cell (ရိုးရိုး နံပါတ် မဟုတ်သည့်အရာ) တွင် ရှေ့တွင် apostrophe ထည့်ပေးသည်။ ထို့ကြောင့် spreadsheet က ၎င်းကို formula အဖြစ် မ run ပါ။
- အရှည်များသည် millimeter ဖြစ်ပြီး အလemေးချိန်များသည် kilogram ဖြစ်သည်။

### PDF အကြောင်း မှတ်ချက်များ

PDF ရှိ စာသားသည် စံ Helvetica font ကို အသုံးပြုသည်။ ၎င်းတွင် မပါသော စာလုံးများ (Western European အစုအဝေးပြင်ပ) ကို "?" ဟု ပုံနှိပ်ပြီး status bar က မည်မျှရှိသည်ကို ပြသည်။

## ယူနစ်များ

DetailCraft သည် အစအဆုံး millimeter ဖြင့် အလုပ်လုပ်သည်: grid များ၊ level များ၊ ကိုဩဒိနိတ်များ၊ ပရိုဖိုင်များ၊ အပေါက်များနှင့် ထုတ်ယူမှု အားလုံး။ ပရိုဖိုင်အမည်များသည် ထုတ်ပြန်ထားသည့် ပုံစံကို ထိန်းထားသည် (W12x50 သည် ၎င်း၏ အတိုင်းအတာများကို mm ဖြင့် ပြသော်လည်း US သတ်မှတ်ချက် ဖြစ်သည်)။ Imperial input ကို ယခုအချိန်တွင် မရနိုင်သေးပါ။

## အွန်လိုင်းနှင့် အော့ဖ်လိုင်း

ဖွင့်ခြင်း၊ သိမ်းခြင်းနှင့် ထုတ်ယူခြင်း အားလုံးသည် သင့် browser တွင် ဖြစ်သောကြောင့် DetailCraft ဖွင့်ပြီးနောက် ချိတ်ဆက်မှုရှိရှိ မရှိရှိ အတူတူ အလုပ်လုပ်သည်။

ချိတ်ဆက်မှုမရှိဘဲ နောက်ပိုင်း အသုံးပြုလိုပါက အွန်လိုင်းရှိနေစဉ် app bar တွင် {{ui:Save for offline}} ကို ရွေးပါ။ ခလုတ်က "Saving 3 of 20" ဟု ရေတွက်ပြီးနောက် {{ui:Offline ready}} ဟု ဖတ်ရသည်။ သိမ်းထားသော မိတ္တူတွင် 3D graphics library (ခန့်မှန်း 2.6 MB) နှင့် ဤ help ပါဝင်သောကြောင့် သိမ်းပြီးနောက် 3D view၊ ထုတ်ယူမှု အားလုံးနှင့် help အားလုံး အော့ဖ်လိုင်းတွင် အလုပ်လုပ်သည်။ အသေးစိတ်နှင့် ချိတ်ဆက်မှု လိုအပ်သည်များ: [Working offline](common:offline)။

:::offline
သင် အော့ဖ်လိုင်းတွင် ရှိသည်။ App bar တွင် {{ui:Offline ready}} ပြနေပါက ဖွင့်ခြင်း၊ သိမ်းခြင်းနှင့် ထုတ်ယူခြင်း ပုံမှန်အတိုင်း အလုပ်လုပ်သည်။ မပြပါက ဤ tab ကို ဖွင့်ထားပါ၊ အွန်လိုင်းပြန်ရောက်မှ ပြန်မလုပ်ပါနှင့်၊ ယခုပင် မော်ဒယ်ကို သိမ်းပါ။
:::

Cloud သိမ်းခြင်းကို ယခုအချိန်တွင် မရနိုင်သေးပါ၊ desktop build များလည်း မရှိသေးပါ။ သင့် `.detailcraft.json` ဖိုင်များကို အခြား အလုပ်ဖိုင်များကို အရန်ကူးသကဲ့သို့ အရန်ကူးထားပါ။ နောက်ထပ်အချက်အလက်ကို [Where your files go](common:your-files) တွင် ကြည့်ပါ။

## မသိမ်းရသေးသော အလုပ်

DetailCraft သည် ဖွင့်ထားသော tab တွင်သာ မော်ဒယ်ကို သိမ်းထားသည်။ မသိမ်းရသေးဘဲ tab ကို ပိတ်ခြင်း သို့မဟုတ် ပြန်တင်ခြင်း ပြုလုပ်ပါက browser က စာမျက်နှာကို ထွက်ရန် မေးသည်၊ စာသားမှာ browser ကိုယ်တိုင် ဖြစ်သည်။ {{key:Mod+S}} ဖြင့် မကြာခဏ သိမ်းပါ။
