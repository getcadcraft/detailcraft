DetailCraft သည် ကနဦးဗားရှင်းဖြစ်သည်။ ဤစာမျက်နှာတွင် ၎င်း မလုပ်နိုင်သေးသော အရာများကို စာရင်းပြုထားသဖြင့် သင် စီစဉ်နိုင်ပါသည်။ ဤတွင် ရက်စွဲအတွက် ကတိပေးချက် တစ်ခုမျှ မရှိပါ။

## မော်ဒယ်ပြုလုပ်ခြင်း

| ယခုထိ မရှိသေး | ယနေ့ အစားထိုးနည်း |
|---|---|
| အဖွဲ့ဝင်တစ်ဖက်ကို ဆွဲခြင်း (ဆန့်ထုတ်ခြင်း) | {{ui:ဂုဏ်သတ္တိများ}} panel ရှိ {{ui:အဆုံးများ (x, y, z mm)}} အောက်တွင် {{ui:အစ}} သို့မဟုတ် {{ui:အဆုံး}} ကို တည်းဖြတ်ပါ |
| ရွေးချယ်ရေး စစ်ထုတ်မှု (အဘောင်များသာ၊ ပရိုဖိုင်တစ်ခုသာ) | ဝင်းဒိုးတစ်ခု ဆွဲပြီး {{key:Shift}}+click ဖြင့် အစိတ်အပိုင်းများကို ဖယ်ထုတ်ပါ |
| ရွေးချယ်မှုကို array လုပ်ခြင်း၊ စောင်းနေသော ဝင်ရိုးပတ်လည် လှည့်ခြင်း၊ စောင်းနေသော ပြင်ဆင်မှုတွင် ထင်ဟပ်ခြင်း | offset ဖြင့် ကူးပြီး ကူးထည့်ပါ၊ သို့မဟုတ် {{ui:ပွားရန်}}; လှည့်ခြင်းနှင့် ထင်ဟပ်ခြင်းကို plan တွင် အလုပ်လုပ်သည် ([ဝင်းဒိုးဖြင့် ရွေး၊ ရွှေ့၊ လှည့်၊ ထင်ဟပ်၊ အများအပြား ပြောင်း](topic:select-and-change)) |
| နှိပ်နေစဉ် ဂရစ်ပြင်ပ အမှတ်များ | ဂရစ်ပေါ်တွင် ထားပြီး အဆုံးကိုဩဒိနိတ်များကို ရိုက်ထည့်ပါ |
| နံပါတ်ရှိ ဂရစ်မျဉ်းများအတိုင်း အမြင့်ပုံများ၊ သိမ်းထားသော အမြင်များ၊ အလုပ်ပြင်များ | {{ui:3D}} ကို သုံးပါ၊ သို့မဟုတ် {{ui:ဂရစ်ဖြင့် ထည့်ရန်}} |
| 3D view တွင် အပေါက်များကို အမှန်ဖြတ်ချက်အဖြစ် ဆွဲခြင်း | အပေါက်များကို အမည်းရောင် ပလပ်အဖြစ် ပြသည်; ၎င်းတို့သည် export တိုင်းတွင် အမှန်ဖြစ်သည် |
| အဝိုင်း သို့မဟုတ် ထောင့်စောင်း အနားဖြတ်ချက်များ၊ အခြားဖြတ်ချက်များနှင့် ပစ္စည်းတပ်ဆင်ချက်များ | I-shape ပေါ်တွင်သာ စတုရန်း အနားဖြတ်ချက်များ |
| ထောင့်များနှင့် စက်ဝိုင်းပိုက်များသို့ ထည့်သော အပေါက်များ | ထောင့်အပေါက်များသည် [brace gussets](topic:brace-gussets) မှသာ ထွက်သည် |
| Imperial ထည့်သွင်းမှု | မီလီမီတာဖြင့် ရိုက်ပါ (လက်မတစ်ခုလျှင် 25.4) |
| စိတ်ကြိုက်ပရိုဖိုင်ကို ပြင်ခြင်း သို့မဟုတ် ဖယ်ရှားခြင်း | ပြင်ဆင်ထားသော ပရိုဖိုင်ကို အမည်အသစ်ဖြင့် ထည့်ပါ |

## လှေကားများ

| ယခုထိ မရှိသေး | ယနေ့ အစားထိုးနည်း |
|---|---|
| လက်ရန်း၊ ဆင်းရာနေရာ၊ ခြေဖျားပလိတ်၊ ဂရိတ်တင်ခြေလှမ်းများ၊ စက်ဝိုင်းနှင့် dog-leg လှေကားများ | ဖြောင့်သော လှေကားထပ်များသာ; [လှေကားများ](topic:stairs) ကိုကြည့်ပါ |
| ကြမ်းပြင်များနှင့် ထိတွေ့သော stringer အဆုံးဖြတ်ချက်များ | စတုရန်းဖြတ်ထားသော stringer များ; သင့်အလုပ်ရုံဆော့ဖ်ဝဲတွင် ဖြတ်ပါ |

## ချိတ်ဆက်မှုများ

DetailCraft သည် ချိတ်ဆက်မှု ခြောက်မျိုးကို တည်ဆောက်သည်: ထောက်တိုင် gusset ([Brace gussets](topic:brace-gussets) ကိုကြည့်ပါ); I-shape တစ်ခု၏ အပိုင်းနှစ်ခုကြား bolt ဖြင့် ချိတ်ထားသော splice ([Splices](topic:splices) ကိုကြည့်ပါ); ထောင့်တစ်ခုဖြင့် တွေ့ဆုံသော I-shape နှစ်ခုကြား mitre၊ ဖြတ်ရုံသာ သို့မဟုတ် bolt ဖြင့် အဆုံးပလိတ်များဖြင့် ([Mitre joints](topic:mitres) ကိုကြည့်ပါ); အဆင့်တစ်ခုမှ ထောင်ထားသော I-shape ဘောင်ကို I-shape ကော်လံ flange သို့မဟုတ် web သို့ ညီညာ သို့မဟုတ် ရှည်လျားသော bolt ဖြင့် အဆုံးပလိတ်; ဘောင်မှ shear tab (စတုရန်း၊ ထောင့်စောင်း သို့မဟုတ် စောင်း) ကို ကော်လံ flange သို့မဟုတ် web သို့; နှင့် anchor rod လေးခုပါသော ကော်လံ အခြေပလိတ်။

| ယခုထိ မရှိသေး | ယနေ့ အစားထိုးနည်း |
|---|---|
| ထောင့်စောင်း သို့မဟုတ် စောင်းနေသော အဆုံးပလိတ်များ | ထောင့်စောင်းနှင့် စောင်းဘောင်များကို လက်ခံသော [shear tabs](topic:shear-tabs) ကို သုံးပါ |
| Clip ထောင့်များ၊ splice ဖြည့်ပလိတ်များနှင့် မတူညီသောအရွယ်အစားများကြား splice များ၊ ဘောင်နှင့် ကော်လံသို့ ဂဟေဆော်ထားသော ထောင့် gusset များ၊ chamfer gusset များ | အခြားဆော့ဖ်ဝဲတွင် အသေးစိတ်ပြုလုပ်ပါ၊ သို့မဟုတ် ပလိတ်နှင့် အပေါက်များကို လက်ဖြင့် သီးခြားအစိတ်အပိုင်းအဖြစ် ထည့်ပါ; [Splices](topic:splices), [Brace gussets](topic:brace-gussets) ကိုကြည့်ပါ |
| chamfer သို့မဟုတ် ချွန်ထားသော အခြေ stiffener များ၊ ဆေးရည် (grout) အပေါက်များ၊ shear lug အတွက် အုတ်မြစ်အိတ် | စတုဂံ stiffener များ; [Base plates](topic:base-plates) ကိုကြည့်ပါ |
| Haunch များ၊ butt weld ဖြင့် ဂဟေဆော်ထားသော mitre များ၊ အခြားအဖွဲ့ဝင်၏ flange များနှင့် တန်းညီသော stiffener များ | အဆုံးပလိတ်နှင့် web stiffener ပါသော [mitre](topic:mitres) သို့မဟုတ် ရိုးရိုး mitre ဖြတ်; အခြားပလိတ်များကို လက်ဖြင့် သီးခြားအစိတ်အပိုင်းအဖြစ် ထည့်ပါ |
| ချိတ်ဆက်မှု ဒီဇိုင်း စစ်ဆေးချက်များ (အား) | ချိတ်ဆက်မှုများကို သင့်အင်ဂျင်နီယာ တွက်ချက်မှုဖြင့် စစ်ဆေးပါ; DetailCraft သည် အနားအကွာအဝေးနှင့် အကွာအဝေးအတွက်သာ သတိပေးသည် |
| အပေါက်ရှည်များ | စက်ဝိုင်းအပေါက်များသာ |

## ခွဲခြမ်းစိတ်ဖြာမှု

| ယခုထိ မရှိသေး | ယနေ့ အစားထိုးနည်း |
|---|---|
| သံ I-shape အပြင် ဒီဇိုင်း စစ်ဆေးချက်များ: ပိုက်များ၊ ထောင့်များ၊ ချန်နယ်များ၊ ဂဟေဆော်ထားသော ပုံသဏ္ဍာန်များ၊ ပိန်သော သို့မဟုတ် class 4 အစိတ်အပိုင်းများ၊ torsion၊ ချိတ်ဆက်မှုများ; ကွန်ကရစ်: sway slenderness၊ torsion၊ ငလျင်ဒီဇိုင်း၊ slab နှင့် နံရံများ | {{ui:ခွဲခြမ်းစိတ်ဖြာမှု}} tab သည် သံ I-shape များကို AISC 360 သို့မဟုတ် EN 1993-1-1 ဖြင့် စစ်ဆေးသည် ([Check steel members to a design code](topic:design-checks)); ကျန်သည်များကို "မစစ်ဆေးရသေး" ဟု အမှတ်အသားပြုသည်; အင်ဂျင်နီယာက အားလုံးကို သုံးသပ်ပါ |
| Buckling ခွဲခြမ်းစိတ်ဖြာမှု၊ တုန်ခါမှု | ဒုတိယအဆင့်သည် P-Delta (ပြန်ထစ်ခြင်း) သာဖြစ်သည်; buckling ခွဲခြမ်းစိတ်ဖြာမှု မရှိ (modal၊ response spectrum၊ time history နှင့် pushover ကို Analysis tab တွင် ထားသည်) |
| အင်ဂျင်နီယာ သုံးသပ်ပြီးသော ဒီဇိုင်းစစ်ဆေးချက်များ | ထိုအချိန်အထိ ၎င်းတို့သည် အကူအညီသာ ဖြစ်သည်: မှီခိုမီ အဖွဲ့ဝင် နှစ်ခု သို့မဟုတ် သုံးခုကို လက်ဖြင့် သို့မဟုတ် သင့်အင်ဂျင်နီယာ၏ ကိုယ်ပိုင်ဆော့ဖ်ဝဲဖြင့် စစ်ဆေးပါ |
| ဧရိယာများမှ သင့်အတွက် ပြုလုပ်ပေးသော ကြမ်းပြင်၊ လေနှင့် နှင်းဝန်များ | အဖွဲ့ဝင်များပေါ်တွင် ဝန်များကို လက်ဖြင့် kN/m သို့မဟုတ် kN ဖြင့် ထည့်ပါ |
| အဖွဲ့ဝင် offset များ၊ ဗဟိုမဟုတ်သော ဆက်မှုများ၊ ဆွဲအား-သာ ထောက်တိုင်များ၊ ဘောင်ထဲရှိ ပလိတ်နှင့် အုတ်မြစ်များ | အဖွဲ့ဝင်များကို ၎င်းတို့၏ အလုပ်မျဉ်းများပေါ်တွင် ခွဲခြမ်းစိတ်ဖြာသည်; ထောက်တိုင်များသည် ဆွဲအားနှင့် ဖိအားကို ထမ်းသည် |

## သံချောင်း (Rebar)

| ယခုထိ မရှိသေး | ယနေ့ အစားထိုးနည်း |
|---|---|
| စက်ဝိုင်းကော်လံများ၊ spiral များ၊ စောင်း သို့မဟုတ် ကွေးဘောင်များ၊ စတုဂံမဟုတ်သော slab များ၊ ဖြောင့်မနေသော နံရံများ | စတုဂံ ဘောင်၊ ကော်လံ၊ slab နှင့် နံရံများ ([Detail reinforced concrete](topic:reinforced-concrete)) |
| လက်ကွင်းသို့ ကွေးထားသော ချောင်းများ၊ အဆင့်ဆင့် ထပ်ခြင်းများ၊ သင်ရွေးသည့်နေရာတွင် ထပ်ခြင်းများ | တန်းညီ အဆင့်များဖြင့် ထပ်ခြင်း၊ ချောင်းတိုင်းကို အပိုင်းတစ်ခုတည်းတွင် ထပ်ထားသည် (ACI Class B, EN α6 = 1.5) |
| အဖွင့်များ၌ ထောင့်ချောင်းများ၊ punching shear ပြင်းအား သံချောင်း၊ ငလျင်ဒီဇိုင်း (ACI 318-19 chapter 18) | အဖွင့်တစ်ဖက်စီတွင် trimmer များ; ကျန်သည်များကို သင်ကိုယ်တိုင် စစ်ဆေးပါ |
| ဖွဲ့စည်းပုံ ဒီဇိုင်းပရိုဂရမ်၏ ကိုယ်ပိုင်ဖိုင်များကို ဖတ်ခြင်း | ၎င်းမှ IFC ထုတ်ပါ: ၎င်း၏ IfcReinforcingBar များသည် ချောင်းများအဖြစ် ဝင်လာသည် ([Bars from an IFC file](topic:reinforced-concrete#bars-from-an-ifc-file)) |
| ဖြောင့်၊ ကွေးတစ်ခုနှင့် U ကျော်သော ပုံသဏ္ဍာန်ကုဒ်များ; ဖြောင့်နှင့် hook တစ်ခုပါ ချောင်းများအတွက် ACI 315 အမျိုးအစားများ | ပုံသဏ္ဍာန် သုံးမျိုးကို BS 8666 00၊ 11၊ 21 သို့မဟုတ် ACI Type 2 ဖြင့် ပရင့်ထုတ်သည်; [Rebar reference](topic:rebar-reference) ကိုကြည့်ပါ |
| BS 4449 H8–H40 မှလွဲ၍ မက်ထရစ် ချောင်းများ (ဥပမာ CSA 10M–35M) | ASTM soft-metric အမည်များ #10–#36၊ သို့မဟုတ် BS ချောင်းများ |

## Platform များ

- DetailCraft ကို desktop၊ laptop သို့မဟုတ် tablet မျက်နှာပြင်အတွက် ပြုလုပ်ထားသည်။ ဖုန်းပေါ်တွင်လည်း အလုပ်လုပ်သည်: မော်ဒယ်သည် မျက်နှာပြင်ကို ထိန်းထားပြီး panel များနှင့် အစီရင်ခံစာများကို အောက်ခြေဘားမှ စာရွက်များအဖြစ် ဖွင့်သည်၊ သို့သော် panel များအတွက် နေရာနည်းသည်။
- Offline အသုံးပြုရန် DetailCraft ကို ဦးစွာ offline အတွက် သိမ်းရမည်၊ အက်ပ်ဘားရှိ {{ui:အော့ဖ်လိုင်းအတွက် သိမ်းရန်}} ဖြင့်; {{ui:အော့ဖ်လိုင်း အဆင်သင့်}} ဟု ပြသပြီးနောက် ဤဗားရှင်းရှိ အရာအားလုံး ချိတ်ဆက်မှုမရှိဘဲ အလုပ်လုပ်သည်။ [Working offline](common:offline) ကိုကြည့်ပါ။

ဤကွက်လပ်တစ်ခုခုက သင့်အလုပ်ကို ဟန့်တားပါက [support page](https://getcadcraft.com/support) မှတစ်ဆင့် ကျွန်ုပ်တို့ကို အသိပေးပါ; ၎င်းသည် နောက်ဘာကို တည်ဆောက်ရမည်ကို ဆုံးဖြတ်ရန် ကူညီပါသည်။
