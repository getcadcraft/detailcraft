{{ui:ကွန်ကရစ်}} tab သည် view အောက်တွင် ကွန်ကရစ် ထုပ်(ဘီမ်)၊ ကော်လံ၊ ဆလပ်နှင့် နံရံများ၏ သံချောင်များကို အသေးစိတ် ပြသသည်။ သင်က အရွယ်အစားနှင့် သံချောင်များကို ပေးသည်; DetailCraft က သံချောင်တိုင်းကို နေရာချ၊ နံပါတ်ပေး၊ ထပ်ဆက်များ၊ ချိတ်ဆက်မှု၊ cover နှင့် အကွာအဝေးကို ၎င်းတို့ ဆင်းသက်လာသော clause နှင့် နှိုင်းယှဉ်ပြီး စစ်ဆေးကာ ဆွဲပြသည်။

:::warning
DetailCraft က ပေးထားသော သံချောင်များကို အသေးစိတ် ဖော်ပြသည်။ ၎င်းက ဒီဇိုင်း မလုပ်ပါ။ ရလဒ်တိုင်းကို engineer က စစ်ဆေးရန် ဖြစ်သည်။
:::

## ကွန်ကရစ် tab ကို ဖွင့်ခြင်း

View အောက်ရှိ {{ui:ကွန်ကရစ်}} tab ကို ရွေးပါ။ ribbon layout တွင် {{ui:ကွန်ကရစ်}} သည် {{ui:မော်ဒယ်ဖန်တီးခြင်း}} tab တွင် {{ui:အုတ်မြစ်}} ၏ ဘေးတွင် ရှိသည်။ drafting style ၏ command line ဖြင့် {{cmd:CONCRETE}} ဟု ရိုက်ပါ။

## Grid ဖြင့် ဒြပ် ထည့်ခြင်း

ကွန်ကရစ် ဒြပ်များကို မော်ဒယ်၏ grid လိုင်းများနှင့် အဆင့်များပေါ်တွင် နေရာချသည်၊ ထို့ကြောင့် ၎င်းတို့ကို ဦးစွာ သတ်မှတ်ပါ (ဘယ်ဘက် panel)။

1. {{ui:ဂရစ်ဖြင့် ထည့်ရန်}} တွင် {{ui:ဒြပ်}} ကို ရွေးပါ: {{ui:ကွန်ကရစ် ထုပ်(ဘီမ်)}}၊ {{ui:ကွန်ကရစ် ကော်လံ}}၊ {{ui:ဆလပ်}} သို့မဟုတ် {{ui:နံရံ}}။
2. Grid လိုင်းများနှင့် အဆင့်များကို ရွေးပါ:
   - ထုပ်(ဘီမ်) သည် grid intersection တစ်ခုမှ အခြားတစ်ခုသို့ ပြေးပြီး ထိပ်သည် အဆင့်တွင် ရှိသည်;
   - ကော်လံ သည် intersection တွင် ရပ်ပြီး အဆင့်တစ်ခုမှ အခြားတစ်ခုသို့ ရှိသည်;
   - ဆလပ် သည် နံပါတ်ပါ grid လိုင်း နှစ်ခုနှင့် အက္ခရာပါ grid လိုင်း နှစ်ခုကြား စတုဂံကို ဖြည့်ပြီး ထိပ်သည် အဆင့်တွင် ရှိသည်;
   - နံရံ သည် ၎င်း၏ အလယ်မျဉ်တလျှောက် intersection တစ်ခုမှ အခြားတစ်ခုသို့၊ အဆင့်တစ်ခုမှ အခြားတစ်ခုသို့ ရှိသည်။
3. အရွယ်အစားကို ပေးပြီး {{ui:ထည့်ရန်}} ကို ရွေးပါ။ ဒြပ်ကို ရွေးထားပြီး ၎င်း၏ field များသည် {{ui:ဂုဏ်သတ္တိများ}} panel တွင် ဖွင့်သည်။

ဒြပ်တိုင်းသည် စတင်တန်ဖိုး သံချောင်များဖြင့် စတင်သည်၊ ဒီဇိုင်း မဟုတ်ပါ: engineer ၏ တန်ဖိုးများသို့ ပြောင်းပါ။

## သံချောင်များ ပြောင်းခြင်း

ဒြပ်ကို ရွေးပါ (view တွင် သို့မဟုတ် {{ui:ကွန်ကရစ်}} tab ရှိ အမည်ဖြင့်)။ {{ui:ဂုဏ်သတ္တိများ}} panel တွင်:

| ဒြပ် | သတ်မှတ်ရမည့်အရာ |
|---|---|
| ထုပ်(ဘီမ်) | အကျယ်၊ အနက်၊ clear cover၊ အထက်နှင့် အောက် သံချောင်များ (အရွယ်အစား၊ အရေအတွက်၊ အဆုံးများတွင် တည့် သို့မဟုတ် 90° ချိတ်)၊ ဘေးသံချောင်များ၊ stirrup များ (အရွယ်အစား၊ 135° သို့မဟုတ် 90° ချိတ်၊ ပထမတစ်ခု၏ အထောက်အပံ့ မျက်နှာမှ အကွာအဝေး၊ အဆုံးဇုန် အရှည်နှင့် အကွာအဝေး၊ ကြားအကွာအဝေး)၊ အထောက်ခံ အရှည်များ၊ lap အရှည်များ |
| ကော်လံ | အကျယ်၊ ဖြတ်အနက်၊ လည်ပတ်မှု၊ cover၊ မျက်နှာတိုင်းရှိ longitudinal သံချောင်များ၊ stirrup ကဲ့သို့ tie များ၊ အထက်ဘက်တွင် သံချောင်များ ဘာလုပ်မည် (အထက်ကော်လံနှင့် lap၊ ကြမ်းပြင်ထဲ ချိတ်၊ သို့မဟုတ် ရပ်) |
| ဆလပ် | အထူ၊ အရွယ်အစား၊ အထက်၊ covers၊ အောက် mat နှင့် အထက် mat တစ်ဖက်စီ (အရွယ်အစားနှင့် အကွာအဝေး)၊ အစွန်းပတ်လည် U-bar များ၊ {{ui:ထောက်ပံ့သံချောင်များ}}၊ အဖွင့်များ |
| နံရံ | အထူ၊ cover၊ အလွှာ တစ်ခု သို့မဟုတ် နှစ်ခု၊ ဘေးလိုက် (horizontal) နှင့် ဒေါင်လိုက် (vertical) သံချောင်များ၊ အဆုံးရှိ U-bar များ၊ အထက်တွင် lap လုပ်သော ဒေါင်လိုက် သံချောင်များ ရှိ/မရှိ၊ {{ui:ထောက်ပံ့သံချောင်များ}}၊ အဖွင့်များ |

ပြောင်းလဲမှု တစ်ခုစီသည် undo အဆင့်တစ်ခု ဖြစ်သည်။ ဆောက်၍မရသော ပြောင်းလဲမှုကို ငြင်းပယ်ပြီး status bar က အကြောင်းပြသည်၊ ဥပမာ "အဖွင့်သည် cover ဖြင့် ဒြပ်အတွင်း မကိုက်ညီပါ။"

Stirrup နှင့် tie များသည် ပိတ်ထားပြီး ချိတ်နှစ်ခုစလုံး ထောင့်တစ်ခုတွင် ရှိသည်။ ထုပ်(ဘီမ်)၏ သံချောင်များသည် အဆုံးတွင် ကော်လံ၏ ဝေးဘက် မျက်နှာ လျော့ cover အထိ ကွန်ကရစ် ကော်လံထဲ ဝင်သည်; ကော်လံ မရှိသော နေရာတွင် {{ui:အစတွင် ထောက်ခံမှု အရှည် (mm)}} နှင့် အဆုံးအတွက် တန်ဖိုးကို ပေးပါ။

## ထပ်ဆက်များနှင့် ချိတ်ဆက်မှု

{{ui:Stock bar length (mm)}} (အစမှာ 12000) ထက် ပိုရှည်သော သံချောင်များကို အရှည်တူ အပိုင်းများအဖြစ် ဖြတ်ပြီး lap လုပ်သည်။ {{ui:ထပ်ဆက်များနှင့် ချိတ်ဆက်မှု}} ဇယားက lap နှင့် anchorage တိုင်းကို ဖော်ပြသည်: ဘာလိုသလဲ၊ clause နှင့် ၎င်း၏ အခြေအနေများ၊ နှင့် detail တွင် ရှိသည်။

- Lap အရှည် 0 ဆိုသည်မှာ "လိုအပ်သလို" ဖြစ်သည်: code က ပေးသော အရှည်ကို 25 mm သို့ တိုးပြီး ပြည့်စေသည်။
- သင့်ကိုယ်ပိုင် lap အရှည်ကို ရိုက်၍ ထိုအစား သုံးနိုင်သည်။ လိုအပ်သည်ထက် တိုလျှင် ပြဿနာ ဖြစ်သည် (အောက်တွင်ကြည့်ပါ) နှင့် ဇယားတွင် * ဖြင့် အမှတ်အသားပြုသည်။
- Anchorage ကို အထောက်အပံ့ မျက်နှာမှ အထောက်အပံ့အတွင်း သံချောင်အဆုံးအထိ တိုင်းသည်။ သိရှိထားသော အထောက်အပံ့ မရှိသော ထုပ်(ဘီမ်) သည် ထိုသို့ ပြောပြပြီး စစ်ဆေးခြင်း မပြုပါ။
- အုတ်မြစ်ပေါ် ရပ်သော ကော်လံသည် အုတ်မြစ်၏ starter သံချောင်များနှင့် lap လုပ်ပြီး အခြား ကော်လံပေါ်တွင် ထိုကော်လံ၏ သံချောင်များနှင့် lap လုပ်သည်: ၎င်းတို့၏ lap ကိုလည်း စစ်ဆေးသည်။

**ACI 318-19** (SI): ဆွဲအား တည့်သံချောင်များ 25.4.2.3 (ဇယား၊ ψt၊ ψe၊ ψg၊ λ ဖြင့်)၊ စံ ချိတ်များ 25.4.3.1 (မသိလျှင် ψr 1.6 နှင့် ψo 1.25 ယူသည်)၊ ဖိအား သံချောင်များ 25.4.9.2၊ ဆွဲအား lap များ 25.5.2.1 (Class B၊ သို့မဟုတ် ဆက်တင်တွင် Class A)၊ ဖိအား lap များ 25.5.5.1။

**EN 1992-1-1**: anchorage 8.4.4 ဖြင့် fbd ကို 8.4.2 မှ (ကောင်းသော သို့မဟုတ် ညံ့သော bond)၊ lap များ 8.7.3 ဖြင့် α6 ကို အပိုင်းတစ်ခုတည်းတွင် lap လုပ်သော သံချောင်တိုင်းအတွက်။ γc၊ γs နှင့် αct သည် အကြံပြုထားသော တန်ဖိုးများဖြင့် စတင်သည်; သင့် national annex ၏ တန်ဖိုးများကို သတ်မှတ်ပါ။

## အဖွင့်များ၊ ထောက်ပံ့သံချောင်များနှင့် အစွန်းသံချောင်များ

ရွေးထားသော ဆလပ် သို့မဟုတ် နံရံအောက်တွင် {{ui:အဖွင့် ထည့်ရန်}} ကို ရွေးပြီး နေရာနှင့် အရွယ်အစားကို သတ်မှတ်ပါ။ အဖွင့်ကို ဖြတ်သော သံချောင်များသည် ၎င်း၏ အစွန်းမှ cover အထိ ရပ်သည်။ {{ui:ထောက်ပံ့သံချောင်များ}} ကို ဘေးနှစ်ဖက်စလုံးတွင် တူညီသော အလွှာ၌ ထည့်ပြီး ဖြတ်ထားသော သံချောင်များ၏ ဧရိယာ၏ တစ်ဝက်ကို ထမ်းဆောင်ကာ အဖွင့်၏ anchorage အရှည် တစ်ခု ကျော်သည်။ ၎င်းသည် DetailCraft ၏ စတင် စည်းမျဉ်းဖြစ်ပြီး code clause မဟုတ်ပါ: {{ui:ထောက်ပံ့သံချောင်များ}} ကို engineer ၏ တန်ဖိုးများသို့ ပြောင်းပါ။ Corner သံချောင်များ မထည့်ပါ။

U-bar များသည် ဆလပ်၏ လွတ်သော အစွန်းများနှင့် နံရံ၏ အဆုံးများတွင် ပတ်ပြီး ခြေများသည် lap အရှည် တစ်ခုစီ ရှိသည်။

## သံချောင် မှတ်ချက်များနှင့် ကွေးညွှတ်ဇယား

တူညီသော သံချောင်များသည် မှတ်ချက် တစ်ခုကို မျှဝေသည်: အုတ်မြစ်များသည် F မှတ်ချက် (5F1) ကို ထိန်းသည်၊ ထုပ်(ဘီမ်)များ B၊ ကော်လံ C၊ ဆလပ် S နှင့် နံရံ W ရရှိသည် (7B1၊ 8C1၊ 4S2)။ {{ui:ကွေးညွှတ်ဇယား}} tab နှင့် ၎င်း၏ CSV သည် ယခု structure ၏ သံချောင် အားလုံးကို ဖော်ပြသည်၊ အုတ်မြစ်များ ဦးစွာ။ {{ui:Output}} › {{ui:နောက်ထပ်}} › {{ui:ကွေးညွှတ်ရန်}} ဖြင့် ဒေါင်းလုဒ် လုပ်သည်။

## စက်ရုံပုံဆွဲများ

{{ui:Output}} › {{ui:နောက်ထပ်}} › {{ui:ပြင်ဆင်ရေး ပုံဆွဲများ}}၊ ကွန်ကရစ် tab ရှိ {{ui:ပြင်ဆင်ရေး ပုံဆွဲများ}}၊ သို့မဟုတ် ဒြပ်တစ်ခုဘေးရှိ {{ui:စက်ရုံပုံဆွဲ}} ကို ရွေးပါ။ ဒြပ်တစ်ခုစီသည် ဒေါင်လိုက်ပုံ (ဆလပ်အတွက် plan) ပြသော စာရွက်တစ်ခု ရရှိသည်၊ သံချောင်တိုင်းနှင့် ၎င်း၏ မှတ်ချက်၊ stirrup သို့မဟုတ် tie ဇုန်များနှင့် lap များ အတိုင်းအတာပါ၊ နှင့် အလယ်တွင် အပိုင်းဖြတ်တစ်ခု။ ထို့နောက် bar-bending စာရွက်များက မှတ်ချက်တိုင်းကို ၎င်း၏ ပုံသဏ္ဍာန် ပုံကြမ်း၊ အတိုင်းအတာ၊ အရေအတွက်၊ ဖြတ်အလျားနှင့် အလေးချိန်ဖြင့် ဖော်ပြသည်။

စာရွက်များကို ဖွင့်ထားသော window တွင် အချိန်တိုင်း မော်ဒယ်မှ ပြန်ဖန်တီးပြီး ပြောင်းလဲမှု တိုင်းပြီးနောက် ထပ်ဖန်တီးသည်: title block တွင် မော်ဒယ် ref ပါသည်။ {{ui:This sheet as PDF}} သို့မဟုတ် {{ui:All sheets as PDF}} ကို သိမ်းပါ။

## IFC ဖိုင်မှ သံချောင်များ

{{ui:File}} › {{ui:Import IFC}} သည် IfcReinforcingBar ကို ယခု ဖတ်သည်: center line တလျှောက် swept disk ကို တည့်ခြေများနှင့် ကွေးများအဖြစ် ပြန်ထုတ်ပေးပြီး ၎င်း၏ အချင်း၊ မှတ်ချက်နှင့် ၎င်းကို ကိုင်ထားသော ဒြပ်ကို ပါဝင်သည်။ သံချောင်များကို ဖတ်ထားသည့်အတိုင်း ထားသည် (ထုပ်(ဘီမ်)သို့မဟုတ် ဆလပ်စည်းမျဉ်း အဖြစ် မပြောင်းပါ)၊ view တွင် ပြသပြီး ကွေးညွှတ်ဇယားတွင် ဖော်ပြကာ IFC export ဖြင့် ပြန်ရေးသည်။ Import အစီရင်ခံစာက သံချောင် မည်မျှ ဖတ်သည်၊ အရွယ်အစား မည်မျှ၊ ဒြပ် မည်မျှတွင် ပါသည်၊ ဘာ ကျန်ခဲ့ပြီး အကြောင်းရင်းကို ပြောသည်။

ထိုဖိုင်၏ သံချောင် ပါသော သို့မဟုတ် ပစ္စည်းကွန်ကရစ် ဖြစ်သော ထုပ်(ဘီမ်)၊ ကော်လံ၊ ဆလပ် သို့မဟုတ် နံရံကို သံမဏိ ဟု မယူပါ; အစီရင်ခံစာက ထိုသို့ ပြောသည်။ DetailCraft ၏ ကိုယ်ပိုင် IFC export သည် ကွန်ကရစ် ဒြပ်တိုင်း၏ သတ်မှတ်ချက်ကို သယ်ဆောင်သဖြင့် ၎င်းအဖြစ် ပြန်ရောက်ပြီး ၎င်း၏ သံချောင်များကို ထိုမှ ပြန်ဖန်တီးသည်။

:::note
ဖွဲ့စည်းပုံ ဒီဇိုင်း program ၏ ကိုယ်ပိုင် ဖိုင်များ (IFC မဟုတ်သော) ကို ဖတ်ခြင်း မရှိသေးပါ: ၎င်းမှ IFC export လုပ်ပါ။
:::

## IFC export

ကွန်ကရစ် ထုပ်(ဘီမ်)၊ ကော်လံ၊ ဆလပ် (အဖွင့်များပါ) နှင့် နံရံများသည် IfcBeam၊ IfcColumn၊ IfcSlab နှင့် IfcWall အဖြစ် ထွက်သည်၊ သံချောင်တိုင်းကို IfcReinforcingBar (အဓိက သံချောင်များ၊ stirrup နှင့် tie အတွက် ligature များ၊ အစွန်း သံချောင်များ) အဖြစ် ထည့်ပြီး ၎င်းသို့ စုစည်းသည်။ သံချောင်တိုင်းသည် center line တလျှောက် swept disk ဖြစ်ပြီး ကွေးများတွင် အမှန် arc များ၊ မှတ်ချက်နှင့် ဖြတ်အလျား ပါသည်။
