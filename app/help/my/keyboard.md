ဤအကူအညီတွင် key များကို မည်သို့ရေးသားထားသည်ကို [Keys၊ mice နှင့် trackpads](common:keys) တွင် ကြည့်ပါ။ Mac တွင် {{key:Mod}} သည် Command key ဖြစ်ပြီး အခြားနေရာတွင် Ctrl ဖြစ်သည်။

## ကိရိယာများ

cursor သည် စာသား သို့မဟုတ် ဂဏန်းအကွက်ထဲတွင် မရှိသောအခါ ဤအရာများ အလုပ်လုပ်သည်။

| Key | လုပ်ဆောင်ချက် |
|---|---|
| {{key:V}} | {{ui:ရွေးရန်}} |
| {{key:B}} | {{ui:အဘောင်}} |
| {{key:C}} | {{ui:ကော်လံ}} |
| {{key:R}} | {{ui:ထောက်တိုင်}} |
| {{key:P}} | {{ui:ပလိတ်}} |
| {{key:F}} | {{ui:အုတ်မြစ်}} |
| {{key:S}} | {{ui:လှေကား}} |
| {{key:M}} | ဂရစ်ဖြတ်မှတ်နှစ်ခုကို ရွေး၍ ရွေးထားသည်များကို ရွှေ့ရန် ([ဝင်းဒိုးဖြင့် ရွေး၊ ရွှေ့၊ လှည့်၊ ထင်ပုံကူး၊ အများအပြား ပြောင်းခြင်း](topic:select-and-change)) |
| {{key:Esc}} | ဆွဲနေသော ရွေးချယ်ဝင်းဒိုးကို ချရန် သို့မဟုတ် ဆွဲနေသော အစိတ်အပိုင်းများကို နေရာပြန်ထားရန်; ရွှေ့ခြင်း၊ beam၊ brace သို့မဟုတ် plate ၏ ပထမအမှတ်၊ သို့မဟုတ် ကူးထည့်ခြင်းကို ပယ်ဖျက်ရန်; နောက်တစ်ကြိမ် ထပ်နှိပ်လျှင် {{ui:ရွေးရန်}} သို့ ပြန်သွားရန်; {{ui:ရွေးရန်}} တွင် ရွေးချယ်မှုကို ရှင်းရန်။ {{ui:နောက်ထပ်}} menu ဖွင့်ထားလျှင် ပိတ်ရန် |
| {{key:Delete}} သို့မဟုတ် {{key:Backspace}} | ရွေးထားသည်များကို ဖျက်ရန် (ရွေးထားသမျှ၊ ပြန်ဖျက်ရန် တစ်ဆင့်တည်း) |

## ဖိုင်နှင့် တည်းဖြတ်ခြင်း

| Key | လုပ်ဆောင်ချက် |
|---|---|
| {{key:Mod+S}} | model ကို သိမ်းရန် (ဒေါင်းလုဒ်)။ စာရိုက်နေချိန်တွင်ပင် အလုပ်လုပ်သည် |
| {{key:Mod+O}} | model ဖွင့်ရန်။ စာရိုက်နေချိန်တွင်ပင် အလုပ်လုပ်သည် |
| {{key:Mod+Z}} | ပြန်ဖျက်ရန် (စာသားအကွက်များအပြင်တွင်; အတွင်းတွင် ရိုက်ထားသည်ကို ပြန်ဖျက်သည်) |
| {{key:Mod+Y}} သို့မဟုတ် {{key:Mod+Shift+Z}} | ပြန်လုပ်ရန် |

## ကူးခြင်းနှင့် ကူးထည့်ခြင်း

cursor သည် စာသား သို့မဟုတ် ဂဏန်းအကွက်ထဲတွင် မရှိသောအခါ ဤအရာများ အလုပ်လုပ်သည် (ထိုနေရာတွင် ပုံမှန်အတိုင်း စာသားကို ကူး၊ ကူးထည့်၊ ရွေးသည်)။ ကူးထည့်ခြင်း၊ ဖြတ်ခြင်း၊ ပွားခြင်း သို့မဟုတ် ဖျက်ခြင်းတိုင်းသည် ပြန်ဖျက်ရန် တစ်ဆင့်ဖြစ်သည်။ နောက်ထပ်: [ကူး၊ ကူးထည့်နှင့် ပွားခြင်း](topic:copy-paste)။

| Key | လုပ်ဆောင်ချက် |
|---|---|
| {{key:Mod+C}} | {{ui:ကူးရန်}} ရွေးထားသော အဖွဲ့ဝင်များနှင့် footing များ (အပေါက်၊ cope နှင့် ချိတ်ဆက်မှုများနှင့်အတူ) |
| {{key:Mod+X}} | {{ui:ဖြတ်ရန်}}: ရွေးချယ်မှုကို ကူးပြီးနောက် ဖျက်ရန် |
| {{key:Mod+V}} | {{ui:ကူးထည့်ရန်}}: မိတ္တူသည် pointer ကို လိုက်သည်; ထိုနေရာအတွက် grid intersection တစ်ခုကို နှိပ်ပါ |
| {{key:Mod+Shift+V}} | {{ui:နေရာတွင် ကူးထည့်ရန်}}: ကူးခဲ့သော coordinate များတွင် |
| {{key:Mod+D}} | {{ui:ပွားရန်}}: ချက်ချင်း မိတ္တူတစ်ခု၊ [DetailCraft ဆက်တင်များ](topic:settings) ရှိ offset ဖြင့် ရွှေ့ထားသည် |
| {{key:Mod+A}} | {{ui:အားလုံးရွေးရန်}}: အဖွဲ့ဝင်၊ ချိတ်ဆက်မှုနှင့် footing အားလုံး |
| {{key:Esc}} | {{ui:ဘာမှမရွေးရန်}} |

စာမျက်နှာပေါ်ရှိ စာသားကို ရွေးထားပြီး (ဥပမာ အစီရင်ခံစာဇယားတွင်) model တွင် ဘာမှမရွေးထားလျှင် {{key:Mod+C}} သည် ပုံမှန်အတိုင်း စာသားကို ကူးသည်။

{{ui:အသစ်}}၊ {{ui:နမူနာ}} နှင့် ထုတ်ယူမှုများတွင် key မရှိပါ၊ toolbar ကို သုံးပါ။

dialog (shop drawing preview သို့မဟုတ် မေးခွန်း) ဖွင့်ထားစဉ် ဤ key များ မည်သည့်အရာမှ မလုပ်ဆောင်ပါ။

## အကွက်များနှင့် panel များ

| Key | လုပ်ဆောင်ချက် |
|---|---|
| {{key:Enter}} သို့မဟုတ် {{key:Tab}} | ရိုက်ထားသော တန်ဖိုးကို အသုံးပြုရန် (ပြောင်းလဲမှုတိုင်းသည် ပြန်ဖျက်ရန် တစ်ဆင့်) |
| {{ui:ဂရစ်များ}}၊ {{ui:အထပ်များ}}၊ {{ui:စိတ်ကြိုက်ပရိုဖိုင်}}၊ အပေါက် သို့မဟုတ် cope အကွက်တွင် {{key:Enter}} | ထို form ၏ ခလုတ်ကို ရွေးသည်နှင့် အတူတူ |
| {{key:Left}} {{key:Right}} | tab တစ်ခု အာရုံရှိစဉ် {{ui:ပြဿနာများ}}၊ {{ui:ပစ္စည်းစာရင်း}} နှင့် {{ui:ကွေးညွှတ်ဇယား}} tab များကြား ရွှေ့ရန် |
| {{key:Esc}} | shop drawing preview သို့မဟုတ် မေးခွန်း dialog ကို ပိတ်ရန် ({{ui:ပယ်ဖျက်ရန်}} နှင့် အတူတူ) |

## မျက်နှာပြင်နှင့် အကူအညီ

| Key | လုပ်ဆောင်ချက် |
|---|---|
| {{key:Ctrl+Shift+F}} | ပုံမှန်၊ full screen၊ bars ဝှက်ထားသော full screen သို့ လည်ပတ်ရန်။ Mac အပါအဝင် ကွန်ပျူတာတိုင်းတွင် Control |
| {{key:Mod+,}} | {{ui:ဆက်တင်များ}} ကို ဖွင့်ရန် ([DetailCraft ဆက်တင်များ](topic:settings)) |
| {{key:Esc}} | Full screen မှ ထွက်ရန် |
| {{key:F1}} | ဤအကူအညီကို ဖွင့်ရန် |

## Mouse

| လုပ်ဆောင်ချက် | 3D တွင် | အပေါ်ပုံနှင့် အမြင်ပုံတွင် |
|---|---|---|
| နှိပ်ခြင်း | အစိတ်အပိုင်းကို ရွေးရန်၊ သို့မဟုတ် နေရာချသော ကိရိယာဖွင့်ထားစဉ် အနီးဆုံး intersection တွင် နေရာချရန် (ကူးထည့်နေစဉ်လည်း ထိုနေရာတွင် ကူးထည့်ရန်) | အတူတူ |
| {{key:Shift}}၊ {{key:Ctrl}} သို့မဟုတ် {{key:Mod}} ကိုင်ပြီး နှိပ်ခြင်း | ရွေးချယ်မှုသို့ အစိတ်အပိုင်းထည့်ရန် သို့မဟုတ် ဖယ်ရန် | အတူတူ |
| ရွေးထားသော အစိတ်အပိုင်းပေါ် နှိပ်ပြီး ဆွဲခြင်း | ရွေးချယ်မှုကို အဆင့်တစ်လျှောက် ရွှေ့ရန်; {{key:Mod}} ကိုင်ထားလျှင် အပေါ်အောက် | ရွေးချယ်မှုကို ရွှေ့ရန် (elevation တွင် တစ်လျှောက်နှင့် အပေါ်အောက်) |
| ဘယ်ခလုတ်ဖြင့် ဆွဲခြင်း | model ကို လှည့်ရန်။ {{ui:ရွေးရန်}} ဖြင့်: ရွေးချယ်ဝင်းဒိုး (ညာဘက်သို့ ဆွဲလျှင် လုံးဝ အတွင်းရှိသည်များ; ဘယ်ဘက်သို့ ဆွဲလျှင် ထိတွေ့သည်များ)။ နေရာချနေစဉ်: pan | {{ui:ရွေးရန်}} ဖြင့်: ရွေးချယ်ဝင်းဒိုး (ညာဘက်သို့ ဆွဲလျှင် လုံးဝ အတွင်းရှိသည်များ; ဘယ်ဘက်သို့ ဆွဲလျှင် ထိတွေ့သည်များ)။ နေရာချနေစဉ်: pan |
| {{key:Shift}} ကိုင်ပြီး ဘယ်ခလုတ်ဖြင့် ဆွဲခြင်း | {{ui:ရွေးရန်}} ဖြင့်: ရွေးချယ်ဝင်းဒိုး၊ ရွေးချယ်မှုသို့ ထည့်သည်။ နေရာချနေစဉ်: pan | {{ui:ရွေးရန်}} ဖြင့်: ရွေးချယ်ဝင်းဒိုး၊ ရွေးချယ်မှုသို့ ထည့်သည် |
| {{key:Ctrl}} သို့မဟုတ် {{key:Mod}} ကိုင်ပြီး ဘယ်ခလုတ်ဖြင့် ဆွဲခြင်း | pan | ဘာမှမလုပ်ဆောင် |
| ညာခလုတ်ဖြင့် ဆွဲခြင်း | pan | pan |
| Wheel | view ၏ အလယ်သို့ zoom | Zoom |
| အလယ်ခလုတ်ဖြင့် ဆွဲခြင်း | Zoom | {{ui:ရွေးရန်}} ဖြင့်: pan။ အခြားအခါ zoom |
| `.detailcraft.json` ဖိုင်ကို အက်ပ်ပေါ် ချခြင်း | ဖွင့်ရန် | ဖွင့်ရန် |

နှိပ်ခြင်းသည် pointer သည် နှိပ်ချိန်နှင့် လွှတ်ချိန်ကြား pixel ၅ ခန့်ထက် လျော့ရွေ့မှသာ ရေတွက်သည်; ပိုရှည်သော ရွေ့ခြင်းသည် ဆွဲခြင်း ဖြစ်သည်။

## Trackpad

| လုပ်ဆောင်ချက် | လုပ်ဆောင်မှု |
|---|---|
| လက်ချောင်းနှစ်ချောင်းဖြင့် အပေါ်အောက် swipe လုပ်ခြင်း သို့မဟုတ် pinch | Zoom |
| နှိပ်ပြီး ဆွဲခြင်း | 3D တွင် လှည့်ရန် သို့မဟုတ် Plan နှင့် Elevation တွင် pan |
| {{key:Shift}} ကိုင်ပြီး နှိပ်ပြီး ဆွဲခြင်း | 3D တွင် pan |
| လက်ချောင်းနှစ်ချောင်းဖြင့် နှိပ်ခြင်း | Right-click (view တွင် menu မရှိ) |

## Touch

tablet သို့မဟုတ် touch screen တွင်:

| လုပ်ဆောင်ချက် | လုပ်ဆောင်မှု |
|---|---|
| Tap | အစိတ်အပိုင်းကို ရွေးရန်၊ သို့မဟုတ် နေရာချသော ကိရိယာဖွင့်ထားစဉ် အနီးဆုံး grid intersection တွင် နေရာချရန် (အနီးတွင် လက်ချောင်းအနံခန့်အတွင်း tap လုပ်လျှင် ရေတွက်သည်) |
| အစိတ်အပိုင်းပေါ် long press | ရွေးချယ်မှုသို့ ထည့်ရန် သို့မဟုတ် ဖယ်ရန် (mouse ဖြင့် {{key:Shift}}+နှိပ်ခြင်းနှင့် အတူတူ) |
| ရွေးထားသော အစိတ်အပိုင်းပေါ် လက်ချောင်းတစ်ချောင်း၊ ထို့နောက် ဆွဲခြင်း | ရွေးချယ်မှုကို ရွှေ့ရန်၊ grid intersection များပေါ် ကပ်သည် |
| နေရာတခြားတွင် လက်ချောင်းတစ်ချောင် | 3D တွင် model ကို လှည့်ရန်၊ Plan နှင့် Elevation တွင် pan |
| လက်ချောင်းနှစ်ချောင်း | Pinch ဖြင့် zoom၊ အတူရွေ့ခြင်းဖြင့် pan |

touch သက်သက်ဖြစ်သော မျက်နှာပြင်တွင် ခလုတ်များ၊ စာရင်းများနှင့် အကွက်များ ပိုကြီးသည်။ ရွေးချယ်ဝင်းဒိုးများသည် mouse လိုအပ်သည်; လက်ဖြင့် tap နှင့် long-press ကို သုံးပါ။

## browser က ထိန်းထားသော key များ

ဖြတ်လမ်းအချို့မှာ browser ၏ ဖြစ်ပြီး မည်သည့်စာမျက်နှာမျှ အသုံးပြု၍ မရပါ၊ ဥပမာ {{key:Mod+W}} (tab ပိတ်ရန်)၊ {{key:Mod+T}} (tab အသစ်) နှင့် {{key:Mod+N}} (window အသစ်)။ {{key:Mod+Y}} သည် ပြန်လုပ်ရန်အစား browser ၏ သမိုင်းကို ဖွင့်ပါက {{key:Mod+Shift+Z}} ကို သုံးပါ။

ဖြတ်လမ်းများသည် စာမျက်နှာတွင် keyboard ရှိမှသာ DetailCraft သို့ ရောက်သည်။ key တစ်ခု ဘာမှမလုပ်ပါက သို့မဟုတ် browser က ဆောင်ရွက်ပါက DetailCraft ဝင်းဒိုး၏ လွတ်သော နေရာကို အရင်နှိပ်ပါ (ဥပမာ address bar တွင် ရိုက်ပြီးနောက်)။

## ရွှေ့ရန်ကို ဘယ်မှာရှိသလဲ

ရွှေ့ရန် command မရှိပါ: အစိတ်အပိုင်းကို ရွေး၍ အဆင့်တစ်လျှောက် ဆွဲပါ ({{key:Mod}} ကိုင်၍ အပေါ်အောက် ဆွဲပါ)၊ သို့မဟုတ် {{ui:အစ}} နှင့် {{ui:အဆုံး}} ကို {{ui:ဂုဏ်သတ္တိများ}} တွင် တည်းဖြတ်ပါ။
