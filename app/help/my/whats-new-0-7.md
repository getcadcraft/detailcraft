ဤသည်မှာ 0.6 နှင့် နှိုင်းယှဉ်လျှင် DetailCraft 0.7 တွင် ပြောင်းလဲချက်များ ဖြစ်သည်။ 0.6 ၏ frame analysis တွင် ယခု ဒုတိယအဆင့် ရှိလာသည်- သံမဏိအပိုင်းများကို ဒီဇိုင်းကုဒ်ဖြင့် စစ်ဆေးခြင်း။

## အသစ်

### Mitre ဆက်အဆစ်များ (0.7.1)

- **ထောင့်တစ်ခုဖြင့် တွေ့ဆုံသော I-shape နှစ်ခု**၊ ဥပမာ portal ဒူးဆစ် သို့မဟုတ် ထိပ်ကြိုး: နှစ်ခုလုံးကို ရွေးပါ၊ {{ui:Connect}} အုပ်စု၏ {{ui:More}} မီနူးတွင် {{ui:Mitre}} ကို ရွေးပါ၊ ထို့နောက် အဖျားနှစ်ခုလုံးကို ထောင့်ကို နှစ်ပိုင်းခွဲသော အပြင်ပြင်ဖြင့် ဖြတ်ပါမည်။ အတူ bolt ဖြင့် ချိတ်ထားသော အဆုံးပလိတ်များနှင့် web stiffener များသည် Mitre dialog အသစ်တွင် အမှတ်ခြစ်အကွက်များ ဖြစ်သည်၊ နံပါတ်ပါသော အကွက်များသည် သင်ရိုက်နေစဉ် သင့်ဆက်အဆစ်၏ ပုံဆွဲချက်နှင့် ကိုက်ညီသည်။ Mitre သည် အပိုင်းများ ရွေ့သောအခါ လိုက်ပါပြီး ပုံဆွဲများ၊ NC ဖိုင်များ (skew cut)၊ IFC နှင့် ပစ္စည်းစာရင်းတို့တွင် ပါဝင်သည်။ [Mitre ဆက်အဆစ်များ](topic:mitres) ကို ကြည့်ပါ။

### ဒီဇိုင်းစစ်ဆေးမှုများ

- **ကုဒ်မှ ဝန်ပေါင်းစပ်မှုများ။** {{ui:Analysis}} tab တွင် {{ui:Design checks}} block အသစ်တွင် {{ui:Design code}} ရှိသည်: ASCE 7 + AISC 360 (US, LRFD) သို့မဟုတ် EN 1990 + EN 1993-1-1 (Eurocode)။ ဝန်အမှုတစ်ခုစီကို အမျိုးအစား (dead၊ live၊ အမိုး live အသစ်၊ snow၊ wind၊ seismic) ပေးပါ၊ {{ui:Make combinations}} ကို နှိပ်ပါ၊ ထို့နောက် DetailCraft သည် သင့်ဝန်အမှုများအတွက် ကုဒ်၏ ခိုင်ခံ့မှုနှင့် အသုံးပြုမှု ဝန်ပေါင်းစပ်မှုများကို ရေးပေးသည်။ သင်ကိုယ်တိုင် ရိုက်ထားသော ပေါင်းစပ်မှုများ ကျန်ရှိနေမည်။ [ပေါင်းစပ်မှုများ ဖန်တီးခြင်း](topic:design-checks#make-the-combinations) ကို ကြည့်ပါ။
- **National Annex တန်ဖိုးများ။** Eurocode အတွက် ကိန်းဂဏန်းများသည် အကြံပြုတန်ဖိုးများဖြင့် စတင်သည်၊ {{ui:National Annex values}} ဖြင့် သင့်နိုင်ငံ၏ တန်ဖိုးများကို ရိုက်နိုင်ပြီး မော်ဒယ်တွင် သိမ်းဆည်းသည်။ [ပေါင်းစပ်မှုများ ဖန်တီးခြင်း](topic:design-checks#make-the-combinations) ကို ကြည့်ပါ။
- **အပိုင်းများ စစ်ရန်။** {{ui:Check members}} သည် သံမဏိ I-shape တိုင်းကို ဆွဲအား၊ buckling ပါသော ချုံ့အား၊ lateral-torsional buckling ပါသော ကွေးအား၊ shear၊ axial force ပါသော ကွေးအား နှင့် သင်သတ်မှတ်ထားသော {{ui:Deflection limit}} နှင့် နှိုင်းယှဉ်သော deflection တို့ဖြင့် စစ်ဆေးသည်။ ဇယားတွင် အပိုင်းတစ်ခုစီ၏ အသုံးပြုနှုန်း၊ အုပ်ချုပ်သော စစ်ဆေးမှုနှင့် ၎င်း၏ပေါင်းစပ်မှုကို ပြသပြီး၊ အပိုင်းများကို မော်ဒယ်ပေါ်တွင် အရောင်ခြယ်သည် (အပြာ၊ အစိမ်း၊ ဝါညို၊ အနီ၊ မစစ်ရသေးသည်အတွက် မီးခိုးရောင်)။ [အပိုင်းများ စစ်ခြင်း](topic:design-checks#check-the-members) ကို ကြည့်ပါ။
- **အစီရင်ခံစာတွင်။** {{ui:Report (PDF)}} နှင့် {{ui:Report (CSV)}} တို့သည် ကုဒ်ထုတ်ဝေချက်များ၊ ဆက်တင်များ၊ အပိုင်းအလိုက် အသုံးပြုနှုန်းနှင့် အသုံးပြုထားသော ပုဒ်မတိုင်းကို ထည့်သည်။ [အစီရင်ခံစာ](topic:design-checks#the-report) ကို ကြည့်ပါ။
- **အင်ဂျင်နီယာ သုံးသပ်သည်အထိ အကူအညီ။** ၎င်းသည် ပထမအဆင့်အား (first-order) အားကိုသာ အသုံးပြုသည်။ tube၊ angle၊ channel၊ welded shape နှင့် ပါးလွှာသော သို့မဟုတ် class 4 အစိတ်အပိုင်းများကို အကြောင်းရင်းနှင့်အတူ "မစစ်ရသေး" ဟု ဖော်ပြသည်; torsion၊ connection နှင့် concrete များကို မစစ်ပါ။ [မစစ်ရသေးသောအရာ](topic:design-checks#what-is-not-checked) ကို ကြည့်ပါ။

### USD

- **steel မော်ဒယ်ကို USD အဖြစ် ထုတ်ရန်။** {{ui:Output}} အုပ်စုရှိ {{ui:USD}} သည် မော်ဒယ်ကို {{ui:Text (.usda)}}၊ {{ui:Binary (.usdc)}} သို့မဟုတ် {{ui:Package (.usdz)}} အဖြစ် ရေးသည်၊ rendering program များနှင့် scene assembly အတွက် ဖြစ်သည်- assembly တစ်ခုစီတွင် ၎င်း၏ အစိတ်အပိုင်းများ ပါဝင်သည်၊ အစိတ်အပိုင်းတစ်ခုစီသည် ၎င်း၏ section ကို အရှည်လိုက် ဆွဲထားပြီး copes ဖြတ်ထားသည်၊ နှင့် တစ်ခုစီတွင် part mark၊ profile၊ grade၊ အရှည်နှင့် အလေးချိန် ပါဝင်သည်။ Bolt hole၊ bolt၊ weld နှင့် footing များသည် USD mesh များတွင် မပါဝင်ပါ။ [steel မော်ဒယ်ကို USD အဖြစ် ထုတ်ရန်](topic:usd) ကို ကြည့်ပါ။

### AI လက်ထောက်များ

- **လက်ထောက်များအတွက် USD။** CadCraft Studio မှတစ်ဆင့် ချိတ်ဆက်ထားသော သင်၏ကိုယ်ပိုင် လက်ထောက်သည် မော်ဒယ်ကို USD အဖြစ် ထုတ်နိုင်သည် (`usd_export`)၊ Studio တွင် သင်ခွင့်ပြုထားသော ဖိုင်တွဲတစ်ခုသို့ ရေးနိုင်သည်။ [လက်ထောက်က ဘာတောင်းဆိုနိုင်သလဲ](topic:use-with-ai-assistants#what-an-assistant-can-ask-for) ကို ကြည့်ပါ။

## ပြောင်းလဲထားသည်များ

- **Steel ribbon** တွင် ခလုတ်ကြီးနှင့် သေးသော ခလုတ်များ ရှိသည်: {{ui:Modeling}} › {{ui:Members}} တွင် ကြီးသော {{ui:Beam}} နှင့်အတူ သေးသော {{ui:Column}}၊ {{ui:Brace}} နှင့် {{ui:Plate}}; {{ui:Detailing}} › {{ui:Connections}} တွင် ကြီးသော {{ui:End plates}}၊ {{ui:Splice}} နှင့် {{ui:Gusset}} တို့သည် split button တစ်ခုတည်းကို မျှဝေသည်; {{ui:Edit}} › {{ui:Clipboard}} တွင် ကြီးသော {{ui:Paste}}၊ အုပ်စု၏ မြှားနောက်ကွယ်တွင် {{ui:Paste in place}} နှင့် {{ui:Duplicate}} ရှိသည်။ {{ui:Fabrication}} › {{ui:Exchange}} တွင် IFC ဘေးတွင် {{ui:Export USD}} ရှိသည်။ အခြား မီနူးပုံစံများသည် ယခင်အတိုင်း ကြည့်ရသည်။ [မီနူး၊ ကီးနှင့် မောက်စ်](topic:menus-keys-and-mouse#the-three-styles) ကို ကြည့်ပါ။
- [Analyse the frame](topic:frame-analysis) သည် ယခု ဒီဇိုင်းစစ်ဆေးမှုများကို ညွှန်ပြပြီး ၎င်း၏ ပေါင်းစပ်မှုများကို ကုဒ်ဖြင့် ဖန်တီးနိုင်သည်။

## အက်ပ်အားလုံးတွင်

- **ယူနစ်များ။** {{ui:Settings}} › {{ui:General}} › {{ui:Units}} တွင် length၊ area၊ volume၊ angle နှင့် slope အတွက် စာရင်းတစ်ခုစီ ရှိပြီး unit များ၏ အဓိပ္ပာယ်ဖွင့်ဆိုချက်များက ပေးသော တိကျသော အရွယ်အစားများ ပါဝင်သည် (US survey foot သည် ကိုယ်ပိုင် unit ဖြစ်သည်)။ အသုံးမပြုသော unit များကို ပိတ်လိုက်ပါက ၎င်းတို့သည် unit စာရင်းမှ ထွက်သွားသည်; တစ်ခုကို ကြယ်ပွင့်အမှတ်အသားလုပ်ပါက အသစ်အလုပ်များသည် ထို unit ဖြင့် စတင်သည်။ ဖိုင်တစ်ခုသည် ၎င်း၏ကိုယ်ပိုင် unit ကို အမြဲထိန်းသည်။ DetailCraft ၏ ကိုယ်ပိုင် အကွက်များသည် စာရင်းများကို မလိုက်နာသေးပါ၊ ၎င်းတို့၏ အရှည်များကို ယခုအချိန်တွင် မီလီမီတာဖြင့်သာ ရိုက်ထည့်ရသည်။ [ယူနစ်များ၊ ရိုက်ထည့်ထားသော တန်ဖိုးများနှင့် ယူနစ်စာရင်းများ](common:unit-lists) ကို ကြည့်ပါ။
- **နေရာ ပိုကျစ်လစ်ပြီး panel များ သပ်သပ်ရပ်ရပ် သိမ်းနိုင်ခြင်း။** {{ui:Settings}} › {{ui:General}} › {{ui:Layout density}} › {{ui:Compact}} သည် မျက်နှာပြင်ပေါ်တွင် ပိုမို ထည့်နိုင်သည် (touch screen နှင့် ဖုန်းများသည် ၎င်းတို့၏ ခလုတ်ကြီးများကို ဆက်ထားသည်)။ ဘေးဘောင် panel တစ်ခုစီတွင် ပါးလွှာသော ခေါင်းစဉ်ဘား ရှိသည်: ဆွဲ၍ panel ကို dock သို့မဟုတ် float လုပ်ပါ၊ အခြား panel ၏ bar ပေါ်သို့ ချထားပြီး frame တစ်ခုကို tab များအဖြစ် မျှဝေပါ၊ ဘေးသို့ လျောသွားစေရန် pin လုပ်ပါ၊ သို့မဟုတ် ဝှက်ထားပြီး ဘေးမှ ပြန်ခေါ်ပါ။ [panel များကို စီစဉ်ခြင်း](common:arrange-panels#make-the-layout-denser) ကို ကြည့်ပါ။
- **Dialog များ ရွှေ့နိုင်သည်။** dialog ကို ခေါင်းစဉ်ဘားဖြင့် ဆွဲ၍ ပုံဆွဲနေရာမှ ဖယ်ပါ၊ ၎င်းသည် သင်ထားခဲ့သည့်နေရာသို့ ပြန်ရောက်သည်။ ခေါင်းစဉ်ဘားကို နှစ်ချက်နှိပ်လျှင် ၎င်းကို အလယ်တွင် ပြန်ထားသည်။ [dialog ကို ရွှေ့ခြင်း](common:arrange-panels#move-a-dialog) ကို ကြည့်ပါ။
- **AI လက်ထောက်များအတွက် ချက်များ။** လက်ထောက်အတွက် လုပ်ဆောင်ပြီး တောင်းဆိုချက် ဆယ်ခု (ပုံဆွဲ သပ်ရပ်စေခြင်း၊ ပုံစုကို ထုတ်ခြင်း၊ ပုံများ စစ်ဆေးခြင်း၊ မော်ဒယ်ကို မေးခွန်းမေးခြင်း၊ takeoff ကို စုစုပေါင်းတွက်ခြင်း၊ part variant စမ်းခြင်း...)၊ တစ်ခုစီသည် ခေါ်ဆိုသော tool များနှင့် လိုအပ်သော ခွင့်ပြုချက်များနှင့်အတူ ပါဝင်ပြီး ကျွန်ုပ်တို့၏ စမ်းသပ်မှုများဖြင့် ပြန်လည် ပြသသည်။ apps တွင် AI မပါပါ။ [AI လက်ထောက်များအတွက် ချက်များ](common:assistants-recipes) ကို ကြည့်ပါ။
- **ဘာသာစကားများ။** **Português (Portugal)** သည် {{ui:Settings}} › {{ui:General}} › {{ui:Language}} တွင် အသစ်ဖြစ်သည်။ ၎င်း၊ **Português (Brasil)**၊ **Español (México)** နှင့် **Bahasa Indonesia** တို့တွင် ယခု apps ၏ စကားလုံးအားလုံး ရှိပြီး မိခင်ဘာသာစကား သုံးသပ်သူမှ မစစ်ဆေးရသေးသော မူကြမ်းများဖြစ်သည်။ Help topic များသည် အင်္ဂလိပ်ဖြင့်သာ ရှိသည်။
- **CadCraft Studio** သည် update စစ်ဆေးမှု ဘာကြောင့် မအောင်မြင်သလဲ ပြောပြသည် (ဤစနစ်အတွက် ဖိုင် မရှိသေး၊ network မရှိ၊ signature မှား) "Done" ဟု ရိုးရိုးပြခြင်းမပြတော့ဘဲ၊ သင်ပိတ်ထားသော What's new card ကို နောက်ဗားရှင်းအသစ် မရမချင် ပြန်မပြတော့ပါ။

## ဤဗားရှင်းတွင် မရှိသေးသည်များ

- **0.7 ကို code-sign မလုပ်ထားပါ။** Signing နှင့် Microsoft Store package ကို certificate အတည်ပြုချက် မရောက်သေးသောကြောင့် 0.8 သို့ ရွှေ့ထားသည်။ getcadcraft.com/download တွင် ဖိုင်တစ်ခုစီဘေးရှိ SHA-256 ကို စစ်ဆေးပါ။ Windows တွင် SmartScreen က installer ကို ရပ်စေပါက {{ui:More info}} ကို ရွေးပြီး {{ui:Run anyway}} ကို ရွေးပါ။ Mac တွင် ပထမအကြိမ် CadCraft Studio ကို right-click လုပ်ပြီး {{ui:Open}} ကို ရွေးပါ။ CadCraft Studio သည် app store တွင် မရှိသေးပြီး iPad သို့မဟုတ် iPhone build လည်း မရှိသေးပါ။
- {{ui:Units}} ရှိ angle နှင့် slope စာရင်းများကို သိမ်းထားသော်လည်း မည်သည့် box မှ ယခုထိ ဖတ်ခြင်း မရှိသေးပါ။
- **ဒီဇိုင်းစစ်ဆေးမှုများကို အင်ဂျင်နီယာက ယခုထိ သုံးသပ်ခြင်း မရှိသေးပါ။** ကျွန်ုပ်တို့၏ စမ်းသပ်မှုများက ၎င်းတို့ကို ပုံနှိပ်ထားသော ဇယားတန်ဖိုးများနှင့် လက်ဖြင့်တွက်ထားသော ဖော်မြူလာများနှင့် နှိုင်းယှဉ်သည်၊ ဒီဇိုင်းလမ်းညွှန်၏ အလုပ်လုပ်ပြထားသော ဥပမာများနှင့်တော့ မဟုတ်သေးပါ။ သုံးသပ်မှု မရမချင် ၎င်းတို့သည် အကူအညီသာ ဖြစ်သည်- အရေးကြီးသော အပိုင်းများကို လက်ဖြင့် စစ်ဆေးပါ။
- ဒီဇိုင်းစစ်ဆေးမှုများသည် ပထမအဆင့် အား (second-order effect မပါ) ကို အသုံးပြုပြီး I-shape များကိုသာ စစ်သည်။ မတည်ဆောက်ရသေးသည်များ: tube၊ angle၊ channel၊ welded shape၊ AISC အတွက် ပါးလွှာသော သို့မဟုတ် Eurocode အတွက် class 4 အစိတ်အပိုင်းများ၏ bending၊ torsion၊ shear buckling ကို bending နှင့် ပေါင်း၍၊ connection၊ fatigue၊ fire၊ seismic detailing နှင့် concrete။ compression တွင် ပါးလွှာသော အစိတ်အပိုင်းသည် compression စစ်ဆေးမှုများကို ဖယ်ထုတ်ပြီး အပိုင်းသည် "passes, partly checked" ဟု ဖတ်ရသည်။
- Frame analysis သည် ယခုထိ ပထမအဆင့်နှင့် မျဉ်းဖြောင့် (linear) ဖြစ်ပြီး အင်ဂျင်နီယာက လက်တွေ့ အလုပ်တစ်ခုပေါ်တွင် မစမ်းသပ်ရသေးပါ။
- Bolt hole၊ bolt၊ weld နှင့် footing များသည် USD export တွင် မပါဝင်ပါ။
