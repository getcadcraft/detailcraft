`.nc1` ဖိုင်တစ်ခုစီသည် အစိတ်အပိုင် မှတ်ချက်တစ်ခုကို ဖော်ပြသည်။ စာကြောင်းများသည် CR LF ဖြင့် အဆုံးသတ်သည်။ စာသားအကွက်များတွင် ရိုးရိုး ASCII သာ ပါသည်၊ အခြားဇာတ်ကောင်များသည် "?" ဖြစ်သွားသည်။ ဒုတိယစာကြောင်းသည် မှတ်ချက် ဖြစ်ပြီး `** DetailCraft <mark>.nc1` ဖြစ်သည်။

ပလိတ်များသည် စံနှုန်း၏ "ပြားများအတွက်" ကော်လံကို လိုက်နာသည်။ စံနှုန်းတွင် စက်ဝိုင်းပိုက်အတွက် ကော်လံ မရှိပါ: DetailCraft သည် အချင်းကို အမြင့်နှင့် flange အကျယ် နှစ်ခုလုံးအဖြစ်၊ နံရံကို အထူ နှစ်ခုလုံးအဖြစ် ရေးသည်။

## အပြင်ဘက် ကွက်ဆွဲချက် (AK)

- **I-shape နှင့် ချန်နယ်များ:** web (v)၊ အနားဖြတ်ချက်တိုင်းအတွက် စတုဂံအခေါက်ပါသည်; flange တစ်ခုစီ (o နှင့် u)၊ အနားဖြတ်ချက်သည် flange ထက် နက်သောနေရာတွင် အဆုံးတစ်ဖက်တွင် တိုထားသည်။
- **စတုဂံ HSS:** နံရံဘေးနှစ်ဖက် (v နှင့် h)၊ အနားဖြတ်ချက်များအတွက် အခေါက်ပါ၊ နှင့် အပေါ်နှင့် အောက်နံရံများ (o နှင့် u)။
- **ထောင့်များ:** ခြေထောက်တစ်ခုလျှင် စတုဂံတစ်ခု (v နှင့် u)။ ထောင့်များပေါ်ရှိ အနားဖြတ်ချက်များကို မရေးပါ: ထိုအစိတ်အပိုင်းကို မရေးထားသောစာရင်းတွင် ထည့်သည်။ [gusset](topic:brace-gussets) သို့ bolt ဖြင့် ချိတ်ထားသော ထောင့်ထောက်တိုင်တွင် အပေါက်များသည် bolt ချိတ်ထားသော ခြေထောက်ပေါ်တွင် ရှိသည်: အစိတ်အပိုင်း၏ u တလျှောက်ရှိ ခြေထောက်အတွက် v၊ v တလျှောက်ရှိ ခြေထောက်အတွက် u။
- **စက်ဝိုင်း HSS:** v ပေါ်တွင် စတုဂံတစ်ခု၊ ရှေ့မှကြည့်သော ပိုက် (အလျား × အချင်း)။
- **ပလိတ်များ:** မျက်နှာ v ပေါ်တွင် စတုဂံတစ်ခု။

ကွက်ဆွဲချက်တိုင်းသည် ပိတ်ထားသည် (ပထမအမှတ်ကို အဆုံးတွင် ထပ်ထည့်သည်) နှင့် နာရီလက်တံ ပြောင်းပြန်ဘက်သို့ လည်သည်။

## အပေါက်များ (BO)

အပေါက်တစ်ခုလျှင် စာကြောင်းတစ်ကြောင်း: မျက်နှာ၊ x၊ y၊ အချင်း၊ အနက် 0 (ဖောက်ထွင်း)။ အပေါက်အားလုံး ပါဝင်သည်၊ သင်ရိုက်ထည့်ထားသည်များနှင့် ချိတ်ဆက်မှုများက ဖန်တီးသည်များ။ စတုဂံ HSS ၏ နံရံဘေးများကို ဖောက်ထားသော အပေါက်ကို နှစ်ကြိမ် ရေးသည်၊ တစ်ကြိမ် v တွင်နှင့် တစ်ကြိမ် h တွင်။

## မျက်နှာများနှင့် ကိုဩဒိနိတ်များ

ပရိုဖိုင်တစ်ခုစီကို စံနှုန်း၏ ပရိုဖိုင်နေရာဆွဲကွက် (DSTV 1998၊ စာမျက်နှာ 7) က ဆွဲထားသည့်အတိုင်း ထားသည်: x သည် အစိတ်အပိုင်းတလျှောက်၊ Y သည် ဖြတ်ကျော်၊ Z သည် နောက်မျက်နှာမှ အပေါ်သို့၊ သုည အမှတ်သည် အပြင်ထောင့်တွင်။ DetailCraft သည် ပုံနှင့်ကိုက်ညီစေရန် အစိတ်အပိုင်းကို ဘယ်တစ်ခါမှ ထင်ဟပ်မပြုလုပ်ပါ။

| မျက်နှာ | I-shape | ချန်နယ် | ထောင့် | စတုဂံ HSS | ပလိတ် |
|---|---|---|---|---|---|
| v | Web၊ ရှေ့ | Web၊ ဖျားဘက်မှ ကြည့်သည် | အစိတ်အပိုင်း u တလျှောက်ရှိ ခြေထောက် | နံရံဘေး −u တွင် | ပလိတ်မျက်နှာ |
| h | | | | နံရံဘေး +u တွင် | |
| o | အပေါ် flange | **အောက်ခြေ** flange | | အပေါ်နံရံ | |
| u | အောက် flange | **အပေါ်** flange | အစိတ်အပိုင်း v တလျှောက်ရှိ ခြေထောက် | အောက်နံရံ | |

- **x** သည် ဖြတ်စမှ အစိတ်အပိုင်းတလျှောက် သွားသည်။
- **I-shape နှင့် စတုဂံ HSS:** web သို့မဟုတ် နံရံဘေးပေါ်ရှိ y သည် ပရိုဖိုင်၏ အောက်ခြေမှ စတင်; flange သို့မဟုတ် အပေါ်နှင့် အောက်နံရံပေါ်ရှိ y သည် နောက်ဘက် (အစိတ်အပိုင်း၏ +u ဘက်) အစွန်းမှ စတင်သည်။
- **ချန်နယ်များ** သည် စံနှုန်းပုံအတိုင်း ဖျားများ အပေါ်သို့ မှောက်ထားသည်။ ထို့ကြောင့် web ပေါ်ရှိ y သည် အပေါ် flange ၏ အပြင်ဘက်မှ အောက်သို့ သွားသည်၊ အပေါ် flange သည် မျက်နှာ u ဖြစ်ပြီး အောက် flange သည် မျက်နှာ o ဖြစ်သည်၊ flange ပေါ်ရှိ y သည် web နောက်ကျောမှ ဖျားဘက်သို့ သွားသည်။
- **ထောင့်များ:** ခြေထောက်တစ်ခုစီပေါ်ရှိ y သည် ထောင့်ဆုံမှ စတင်သည်။
- **ပလိတ်များ:** y သည် ပလိတ်၏ −u အစွန်းမှ စတင်သည်။

ဖြတ်ခြင်းမပြုမီ သင့်စက်ဆော့ဖ်ဝဲက ချန်နယ်မျက်နှာများကို မည်သို့ဖတ်သည်ကို စစ်ဆေးပါ: ပရိုဂရမ်အချို့က ချန်နယ်များကို အထက်အောက် ပြောင်းလှန်ထားသည်။

## မရေးထားသောအရာများ

ထောင့်ဖြတ် (bevel)၊ အတွင်းပိုင်း ကွက်ဆွဲချက်များ၊ အမှတ်အသားများ (SI)၊ စတုရန်းမဟုတ်သော ဖြတ်ထောင့်များ၊ အပေါက်ရှည်များ၊ စက်ဝိုင်းပိုက်ရှိ အပေါက်များ (DetailCraft တွင် မရှိ)၊ ထောင့်နှင့် စက်ဝိုင်းပိုက်များပေါ်ရှိ အနားဖြတ်ချက်များ။
