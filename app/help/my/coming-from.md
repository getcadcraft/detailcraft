Tekla Structures ဖြင့် detail လုပ်ပါက DetailCraft ၏ အများစုသည် သိသလို ရှိမည်: grid များ၊ level များ၊ catalog မှ ပရိုဖိုင်များ၊ အစိတ်အပိုင်းများနှင့် assembly များ၊ ချိတ်ဆက်မှုများ၊ နံပါတ်ထိုးခြင်း၊ NC ဖိုင်များ၊ IFC။ အရွယ်အစားမှာ အလွန် ကွာခြားသည်: Tekla Structures သည် full production system ဖြစ်ပြီး DetailCraft သည် အကျဉ်း၊ အစောပိုင်း browser app တစ်ခုဖြစ်ကာ အလုပ်အနည်းငယ်ကို အစမှ အဆုံးထိ လုပ်ပေးသည်။ ဤစာမျက်နှာက သင့် အလေ့အကျင့်များ ဘယ်နေရာတွင် ကူးပြောင်းနိုင်ပြီး ဘယ်နေရာတွင် မဟုတ်သလဲ ပြောပြသည်။

:::tip
သင့်လက်က Tekla Structures ribbon ကို သိပါက {{ui:Settings}} › {{ui:DetailCraft}} › {{ui:Menus, keys and mouse}} တွင် {{ui:Steel ribbon}} menu style ကို ရွေးပါ: Modeling၊ Detailing၊ Edit၊ Drawings၊ Fabrication နှင့် View tab များ၊ အလယ် ခလုတ်သည် pan လုပ်သည်။ AutoCAD မှ လာပြီး command ရိုက်ရန် နှစ်သက်ပါက {{ui:Drafting classic}} က command line ထည့်ပေးသည် (BEAM, COLUMN, ENDPLATE, ZOOM …)။ [Menus, keys and mouse](topic:menus-keys-and-mouse) ကို ကြည့်ပါ။
:::

## လူများကို ချော်စေသော ကွာခြားချက်များ

### Mark များ သူ့ဟာသူ ပြောင်းသည်

နံပါတ်ထိုးရန် အဆင့် မရှိပါ။ Mark များကို ပြောင်းလဲမှု တိုင်းနောက်တွင် ပြန်တွက်သဖြင့် အမြဲ ဆိုင်းငံ့ပေမယ့်၊ ၎င်းတို့ ပြန်နံပါတ်ထိုးနိုင်သည်: ကော်လံ ထည့်လိုက်လျှင် မနေ့က c3 သည် c4 ဖြစ်သွားနိုင်သည်။ အဟောင်း mark များကို ထိန်းသိမ်းမည့် "numbering history" မရှိပါ။ မော်ဒယ်ကို ပြီးအောင် လုပ်ပြီး၊ BOM၊ NC ဖိုင်များနှင့် shop drawing များကို သိမ်းထားသော ဖိုင်တစ်ခုတည်းမှ တစ်ပြိုင်တည်း ထုတ်ပါ။

### အလယ် mouse ခလုတ်သည် zoom လုပ်သည်; pan မလုပ်ပါ

3D view တွင်: ဘယ်ဘက် drag သည် လှည့်သည်၊ ညာဘက် drag သည် pan လုပ်သည်၊ wheel သည် zoom လုပ်သည်၊ အလယ်ခလုတ်ဖြင့် drag ရင်းလည်း zoom လုပ်သည်။ {{key:Shift}} ကိုင်ထားပြီး ဘယ်ဘက် drag လုပ်ခြင်းသည်လည်း pan လုပ်သည်။ Wheel သည် pointer သို့ မဟုတ် view ၏ အလယ်သို့ zoom လုပ်သည်။ Rotation-center ရွေးချယ်ခြင်း မရှိ: မော်ဒယ်သည် view ၏ အလယ်ပတ်လည် လှည့်သည်။ [Move around the 3D view](topic:navigate-3d) ကို ကြည့်ပါ။

### ကော်လံများသည် မူလအနေဖြင့် တစ်ဖက်ကို မျက်နှာမူသည်

Rotation 0 တွင် ကော်လံ flange များသည် နံပါတ်ထိုး grid ဦးတည်ချက်တလျှောက် မျက်နှာမူသည်။ အက္ခရာ grid မျဉ်းများကြား ပြေးသော အဘောင်များသည် web ထဲသို့ ဆက်ထားပြီး၊ end plate များကို ထိုနေရာတွင် ငြင်းသည် ("Beams framing into a column web are not built yet")။ ထိုကော်လံများကို 90° လှည့်ပြီးမှ ချိတ်ဆက်မှု ထည့်ပါ။

### Elevation များသည် အက္ခရာ မျဉ်းများပေါ်တွင်သာ

{{ui:Elevation}} သည် အက္ခရာ grid မျဉ်းများတလျှောက်သာ ကြည့်သည်။ နံပါတ် မျဉ်းများတလျှောက် view မရှိပါ၊ သိမ်းထားသော view မရှိ၊ work plane မရှိ။ နံပါတ် မျဉ်းများပေါ်ရှိ frame များအတွက် {{ui:3D}} သို့မဟုတ် {{ui:Add by grid}} ကို သုံးပါ။

### ရွေးချယ်ခြင်း၊ ကူးခြင်းနှင့် ရွှေ့ခြင်း

{{key:Shift}}+နှိပ်ခြင်း သို့မဟုတ် {{key:Mod+A}} ဖြင့် အစိတ်အပိုင်းများစွာကို ရွေးပြီး၊ ကူး၊ ဖြတ်၊ ကပ် (grid လမ်းဆုံ၊ ရိုက်ထားသော offset၊ သို့မဟုတ် နေရာတွင်) နှင့် ပွားပါ၊ ချိတ်ဆက်မှုများ အပါအဝင် ([Copy, paste and duplicate](topic:copy-paste))။ Window ရွေးချယ်ခြင်း၊ select filter၊ ရွှေ့ခြင်း၊ mirror သို့မဟုတ် array မရှိပါ၊ ပစ္စည်း ဂုဏ်သတ္တိများကို {{ui:Properties}} panel တွင် အဖွဲ့ဝင် တစ်ခုချင်းစီ ပြောင်းသည်။

### Grid များသည် အဖွဲ့ဝင်များကို မဆွဲပါ

Grid အကွာအဝေး ပြောင်းလျှင် အဖွဲ့ဝင်များသည် ၎င်းတို့၏ coordinates ကို ထိန်းသည်; grid မျဉ်းများနှင့်အတူ ဘာမျှ မရွေ့ပါ။ သံမဏိ မထားမီ grid ကို ပြင်ပါ၊ သို့မဟုတ် နောက်မှ အဖွဲ့ဝင် တစ်ခုချင်းစီ၏ end coordinates ကို ပြင်ပါ။

### ချိတ်ဆက်မှုများကို ဒီဇိုင်း မလုပ်ပါ

ချိတ်ဆက်မှု နှစ်ခုသည် သင်ပေးသော နံပါတ်များမှ ပလိတ်၊ အပေါက်၊ ဘော့လ်နှင့် ဂဟေများကို နေရာချသည်။ မည်သည့် ဒီဇိုင်း စစ်ဆေးမှုမျှ မရှိပါ၊ ဘေးနှင့် အကွာအဝေး သတိပေးချက်များသာ ရှိသည် (EN 1993-1-8 Table 3.3 မှ)။

### အပေါက်များကို 3D view တွင် မဖြတ်ပါ

အပေါက်များသည် အမှောင် plug များအဖြစ် ပြသည်။ ၎င်းတို့သည် NC ဖိုင်များ၊ shop drawing များနှင့် IFC ဖိုင်တွင် အမှန်တကယ် အပေါက်များ ဖြစ်သည်။ Copes များကို view တွင် ဖြတ်သည်။

### အလေးချိန်များသည် gross ဖြစ်သည်

သံမဏိ အလေးချိန်သည် အပေါက်များ သို့မဟုတ် copes ကို နုတ်ခြင်း မရှိပါ၊ bolt အလေးချိန်လည်း မပါ။

### မီလီမီတာသာ

အရာအားလုံးကို မီလီမီတာဖြင့် ရိုက်ထည့်ပြီး ပြသသည်၊ AISC ပုံသဏ္ဍာန်များအတွက်ပင်။ ပရိုဖိုင် အမည်များသည် ထုတ်ပြန်ထားသော ပုံစံကို ထိန်းသည် (W12x50, HSS6x6x1/4)။

### စီမံရမည့် drawing မရှိ

Drawing စာရင်း၊ drawing editor၊ general arrangement သို့မဟုတ် assembly drawing မရှိပါ။ Shop drawing ကို သင် တောင်းသည့်အခါ ဖန်တီးပြီး ဒေါင်းလုဒ်ဆွဲသည်; ပြင်ရန် မော်ဒယ်ကို ပြင်ပြီး ထပ်ထုတ်ပါ။

### ဘရောက်ဇာတွင် လည်ပတ်သည်

သိမ်းခြင်းသည် ဖိုင် တစ်ခု ဒေါင်းလုဒ်ဆွဲသည်။ ဘရောက်ဇာက သူ့ဘာသာ ထိန်းထားသော keyboard shortcut များကို အသုံးမပြုနိုင်ပါ။ သင့်မော်ဒယ်များသည် သင့်ကွန်ပျူတာမှ ဘယ်တော့မှ မထွက်ပါ: [Where your files go](common:your-files) ကို ကြည့်ပါ။

## သင့်လက်ရှိ ဆော့ဖ်ဝဲတွင် ဆက်လုပ်ရမည့်အရာများ

ယခုအချိန်တွင် DetailCraft သည် သေးငယ်သော frame များ၊ အယူအဆ စစ်ဆေးခြင်း၊ သင်ကြားခြင်း၊ သို့မဟုတ် ရိုးရှင်းသော အဘောင်နှင့် ကော်လံ အလုပ်အတွက် NC ဖိုင်နှင့် shop drawing ထုတ်ခြင်းတို့အတွက် သင့်တော်သည်။ ရှုပ်ထွေးသော ချိတ်ဆက်မှုများ၊ general arrangement drawing များ၊ erection drawing များ၊ multi-user project များနှင့် [What is not built yet](topic:not-built-yet) တွင် စာရင်းပြုထားသည့် အရာတိုင်းကို သင် လက်ရှိ သုံးနေသော ဆော့ဖ်ဝဲတွင် ဆက်ထားပါ။
