IFC ထုတ်ခြင်းသည် မော်ဒယ်တစ်ခုလုံးကို BIM ဆော့ဖ်ဝဲနှင့် IFC ကြည့်ရှုစနစ်များ ဖွင့်နိုင်သော IFC4 ဖိုင် တစ်ခုအဖြစ် ရေးသားသည်။

## ထုတ်ရန်

1. {{ui:Output}} အုပ်စုတွင် {{ui:IFC}} ကို ရွေးပါ။
2. ဘရောက်ဇာက `<name>.ifc` ကို ဒေါင်းလုဒ်ဆွဲသည်။ အခြေအနေဘားက ဘာပါဝင်သည်ကို ပြသသည်၊ ဥပမာ "IFC4 exported: 25 parts, 88 fasteners, 7 footings, 132 bars."

မော်ဒယ်တွင် အစိတ်အပိုင်း၊ အုတ်မြစ် သို့မဟုတ် သံချောင်း မရှိပါက အခြေအနေဘားက "Nothing to export yet." ဟု ပြသသည်။

## ဖိုင်ထဲ ပါဝင်သည်များ

| DetailCraft တွင် | IFC ဖိုင်တွင် |
|---|---|
| အထပ်တိုင်း | အဆောက်အအုံ အထပ် (IfcBuildingStorey)၊ project တစ်ခု၊ site နှင့် building တစ်ခုအောက်တွင် |
| ဂရစ်များ | ၎င်း၏ ဝင်ရိုးများနှင့် အမည်များပါသော IfcGrid |
| ကော်လံ၊ beam၊ brace | IfcColumn၊ IfcBeam၊ IfcMember (brace)၊ တစ်ခုစီသည် စံပရိုဖိုင် ပုံသွင်းမှု ဖြစ်ပြီး အမှန်တကယ် အတိုင်းအတာများ ပါသည် |
| ပလိတ်များ၊ အဆုံးပလိတ်များ၊ အခြေပလိတ်များ | IfcPlate |
| အပေါက်များနှင့် cope များ | အစိတ်အပိုင်းမှ ဖြတ်ထားသော အဖွင့်များ (IfcOpeningElement) |
| အဖွဲ့ဝင်နှင့် ၎င်း၏ ဂဟေပလိတ်များ | တပ်ဆင်မှု အမှတ်အသားဖြင့် မှတ်ထားသော တပ်ဆင်မှု (IfcElementAssembly) |
| ဘော့လ်များနှင့် အင်ကာ ရော့ဒ်များ | အချင်းနှင့် အရှည်ပါသော IfcMechanicalFastener |
| အုတ်မြစ်များ | IfcFooting (pad footing)၊ ကွန်ကရစ် စာသားကို ပစ္စည်းအဖြစ် |
| သံချောင်းတိုင်း | IfcReinforcingBar၊ ၎င်း၏ bar အမှတ်အသား၊ အချင်း၊ ဧရိယာနှင့် အရှည်ပါ၊ ကွေးညွှတ်ရာတွင် အမှန်တကယ် အဝိုင်းများဖြင့် အမှန်တကယ် ဗဟိုမျဉ်းတလျှောက် ဆွဲထား |

အစိတ်အပိုင်းတစ်ခုစီ၏ tag သည် ၎င်း၏ အစိတ်အပိုင်း အမှတ်အသား ဖြစ်သည်။ ဒြပ်စင်တစ်ခုစီတွင် "DetailCraft" property set ပါပြီး ၎င်း၏ အမှတ်အသား၊ ပရိုဖိုင်နှင့် အလေးချိန် ပါသည်။ ဒြပ်စင်တစ်ခုစီသည် ၎င်း၏ အနိမ့်ဆုံးအမှတ် နှင့် ညီသော သို့မဟုတ် အောက်တွင် ရှိသော အမြင့်ဆုံး အထပ်တွင် ထားသည်။ ပစ္စည်းများကို အဆင့်အလိုက် စုထားသည်။

## ပြန်ထုတ်ရာတွင် တည်ငြိမ်သော id များ

ဒြပ်စင်တစ်ခုစီ၏ IFC id (GlobalId) ကို မော်ဒယ်အမည်နှင့် မော်ဒယ်ထဲရှိ ဒြပ်စင်၏ ကိုယ်ပိုင် id မှ တွက်ချက်သည်။ မော်ဒယ်တူတူကို နှစ်ကြိမ် ထုတ်လျှင် id များ ကိုက်ညီသည်၊ ထို့ကြောင့် ဗားရှင်းများ နှိုင်းယှဉ်သော ဆော့ဖ်ဝဲက ပြောင်းလဲမှုကို ပြနိုင်သည်။

:::warning
မော်ဒယ် အမည် ပြောင်းလျှင် id အားလုံး ပြောင်းသွားသည်။ ပရောဂျက် ထုတ်ဝေမှု အကြား မော်ဒယ်အမည်ကို တူညီစွာ ထားပါ။
:::

## စစ်ဆေးရန်

DetailCraft ၏ IFC ဖိုင်များကို ၎င်း၏ စမ်းသပ် အစုတွင် သီးခြား IFC ဖတ်ကိရိယာဖြင့် ပြန်ဖတ်သည်။ ပရိုဂရမ်များသည် IFC ကို ဖတ်ပုံ ကွဲပြားသောကြောင့်၊ ယုံကြည်ခြင်းမပြုမီ သင့်အဖွဲ့ အသုံးပြုသော ဆော့ဖ်ဝဲတွင် ဖိုင်ကို ဖွင့်ကြည့်ပါ။ CadCraft ၏ BimCraft အက်ပ်သည်လည်း IFC ဖိုင်များကို ဖွင့်သည်။

## မရှိသေးသည်များ

- ချိတ်ဆက်မှုများ၊ အုတ်မြစ်များနှင့် သံချောင်းများကို IFC ဖိုင်မှ သွင်းခြင်း။ {{ui:Import IFC}} သည် beam၊ ကော်လံ၊ အဖွဲ့ဝင်၊ ပလိတ်၊ ဂရစ်၊ အထပ်၊ အပေါက်၊ cope နှင့် ဘော့လ်များကို သွင်းပြီး ချန်ထားခဲ့သည်များကို စာရင်းပြုသည်။
- Analytical သို့မဟုတ် ဖွဲ့စည်းပုံ ခွဲခြမ်းစိတ်ဖြာမှု ဒေတာ။
- IFC4 reference view အပြင် မည်သည့်အရာမဆို။

## သွင်းရန်

{{ui:File}} အုပ်စုရှိ {{ui:Import IFC}} (သို့မဟုတ် view ပေါ်သို့ `.ifc` ဖိုင် ချလိုက်ခြင်း) သည် IFC2X3 သို့မဟုတ် IFC4 ဖိုင်မှ မော်ဒယ်အသစ် တစ်ခု ဖန်တီးသည်:

- **Beam၊ ကော်လံ၊ အဖွဲ့ဝင် (brace) နှင့် ပလိတ်များ** ကိုယ်ထည်သည် DetailCraft သိသော ထုတ်ထားသော ပရိုဖိုင် တစ်ခုတည်း ဖြစ်သည့်အရာ၊ ကက်တလော့ဂ်နှင့် ကိုက်ညီလျှင် သို့မဟုတ် စိတ်ကြိုက် ပရိုဖိုင်အဖြစ် ထားသည်; **ဂရစ်များ** နှင့် **အထပ်များ** ကို ဖိုင်၏ ဂရစ်နှင့် အထပ်များမှ။
- **အပေါက်များ:** အစိတ်အပိုင် မျက်နှာတစ်ခုနှင့် ထောင့်မှန်သော စက်ဝိုင်း ဖွင့်ပေါက်အားလုံး (ဝင်လာသော အစိတ်အပိုင်းကို ဖြုတ်သော IfcOpeningElement): I-shape သို့မဟုတ် channel ၏ web သို့မဟုတ် flange များ၊ tube ၏ နံရံများ၊ ပလိတ်၊ angle ၏ ခြေထောက်များ။ tube ၏ နံရံနှစ်ခုလုံးကို ဖြတ်သော အပေါက်တစ်ခုကို တစ်ကြိမ်သာ သွင်းသည်။
- **Cope များ:** I-shape သို့မဟုတ် channel ၏ အကျယ်အပြည့်ကို တစ်ဖက်အစွန်းမှ ယူသော စတုဂံ ဖွင့်ပေါက်၊ အပေါ်မှ အောက်သို့ သို့မဟုတ် အောက်မှ အပေါ်သို့။
- **ဘော့လ်များ:** IfcMechanicalFastener သို့မဟုတ် IfcFastener အားလုံး၊ အချင်း၊ အရှည်၊ အဆင့်နှင့် အမျိုးအစား (ဘော့လ် သို့မဟုတ် အင်ကာ ရော့ဒ်) ပါသည့် **လွတ်သော ဘော့လ်** အဖြစ်။ လွတ်သော ဘော့လ်များသည် view၊ ပစ္စည်းစာရင်းနှင့် IFC ထုတ်ခြင်းတွင် ပေါ်ပြီး အဖွဲ့ဝင်များကို ရွှေ့သည့်အခါ မူလနေရာတွင် ကျန်ခဲ့သည်။ {{ui:Properties}} အကန့်သည် ဘာမှ မရွေးထားသည့်အခါ ၎င်းတို့ကို ရေတွက်ပြီး ချိတ်ဆက်မှုများ အစား ထည့်သည့်အခါအတွက် {{ui:Remove loose bolts}} ရှိသည်။

အစီရင်ခံစာက ကျန်သည့်အရာအားလုံးကို အမျိုးအစားအလိုက် ချန်ထားရသည့် အကြောင်းရင်းနှင့်အတူ စာရင်းပြုသည်: နံရံများနှင့် ကြမ်းပြင်များ၊ အုတ်မြစ်များနှင့် သံချောင်းများ၊ slot အပေါက်များ၊ စက်ဝိုင်း tube များရှိ အပေါက်များ၊ ချိတ်ဆက်မှုများ (IFC ဖိုင်တွင် ၎င်းတို့၏ ပလိတ်နှင့် ဘော့လ်များသာ ပါပြီး ၎င်းတို့ကို ဖန်တီးသည့် စည်းမျဉ်း မပါ)။
