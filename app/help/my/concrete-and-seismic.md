{{ui:Analysis}} tab ရှိ {{ui:Concrete members}} နှင့် {{ui:Seismic loads}} block များသည် ကွန်ကရစ် အဘောင်နှင့် ကော်လံများကို စစ်ဆေးပြီး frame ကြမ်းပြင်များပေါ်ရှိ ငလျင်၏ ဘေးတိုက်အား ပြုလုပ်သည်။ နှစ်ခုစလုံးသည် {{ui:Analysis}} tab ၏ run ကို လိုက်ပြီး မော်ဒယ်နှင့်အတူ သိမ်းထားသည်။

:::warning
ရလဒ်များသည် **အင်ဂျင်နီယာ စစ်ဆေးရန်အတွက်** ဖြစ်သည်: အင်ဂျင်နီယာ တစ်ဦး သုံးသပ်ပြီးမချင်း အကူအညီ သက်သက်သာ ဖြစ်သည်။ ကွန်ကရစ် စစ်ဆေးမှုများသည် first-order force များကို သုံးသည်၊ သို့သော် သင် non-sway ဟု ခေါ်သော frame ရှိ ကော်လံကို ၎င်း၏ magnified moment အတွက် ဒီဇိုင်းလုပ်သည် (sway magnification မရှိ၊ torsion ဒီဇိုင်း မရှိ၊ seismic detailing (ACI chapter 18) မရှိ၊ tie detailing မရှိ)။ Seismic load များတွင် redundancy factor၊ ဒေါင်လိုက် seismic effect၊ torsional amplification နှင့် P-delta effect များ ပါဝင်သည်မဟုတ်ပါ။ လေအား load များကို မတည်ဆောက်ရသေးပါ။
:::

## အဖွဲ့ဝင်များကို ဆွဲရန်

ကွန်ကရစ် အဖွဲ့ဝင်များကို စတုဂံအဖြစ် ဆွဲပါ: ကော်လံအတွက် `PL400x400` နှင့် အဘောင်အတွက် `PL300x600` ကဲ့သို့ {{ui:Plate}} ပရိုဖိုင်သည် အပိုင်းဖြတ်ကို ပေးသည်။ ကော်လံနှင့် အဘောင်များကို အခြား အဖွဲ့ဝင်များကဲ့သို့ နေရာချသည်။

## အပိုင်းဖြတ်များကို သတ်မှတ်ရန်

{{ui:Concrete members}} block သည် အဖွဲ့ဝင်များ သုံးသော အပိုင်းဖြတ် အားလုံးကို စာရင်းပြုသည်။ ကွန်ကရစ် ဖြစ်သော အရာများပေါ်တွင် {{ui:Set up as concrete…}} ကို နှိပ်ပါ။ DetailCraft သည် ဆွဲထားသော ပရိုဖိုင်မှ အကျယ် **b** (အဖွဲ့ဝင်၏ ကိုယ်ပိုင် y ဝင်ရိုးတလျှောက်) နှင့် အနက် **h** (z တလျှောက်) ကို ဖတ်ပြီး၊ အောက်ပါတို့ကို မေးသည်:

- ဘားများ၏ ဗဟိုသို့ **cover**၊ နှင့် အဘောင်အတွက် **top**၊ **bottom** နှင့် **side** ဘားများ (ဘယ်နှစ်ခု နှင့် အချင်းဘယ်လောက်)၊ သို့မဟုတ် ကော်လံအတွက် **column cage** (b တလျှောက်နှင့် h တလျှောက် ဘား၊ အချင်း၊ spiral tie များ);
- **ties**: ခြေများ၊ အချင်းနှင့် အကွာအဝေး;
- အဖွဲ့ဝင်က **ဘာအဖြစ် ဆောင်ရွက်သလဲ**: အဘောင်၊ ကော်လံ၊ သို့မဟုတ် ၎င်း၏ အင်အားမှ ဆုံးဖြတ်သည် (ဒေါင်လိုက် အဖွဲ့ဝင်၊ သို့မဟုတ် 0.10 f′c Ag ထက် ပိုသယ်ဆောင်သော အဖွဲ့ဝင်သည် ကော်လံ ဖြစ်သည်)။

f′c၊ ဘား yield fy နှင့် tie yield fyt (shear အတွက် 420 MPa အထိ ရေတွက်သည်)၊ K နှင့် frame sway သို့မဟုတ် non-sway ဟုတ်မဟုတ်ကို ၎င်းတို့အပေါ် သတ်မှတ်ပါ။ ကွန်ကရစ်အဖြစ် သတ်မှတ်ထားသော အပိုင်းကို ကွန်ကရစ်အဖြစ် ခွဲခြမ်းစိတ်ဖြာသည်: E = 4700 √f′c၊ 2400 kg/m³၊ နှင့် မူလအနေဖြင့် **cracked sections** ဖြင့် (ကော်လံ 0.70 Ig၊ အဘောင် 0.35 Ig; ACI 318-19 Table 6.6.3.1.1(a))။ ၎င်းကို ပိတ်ရန် {{ui:Gross sections}} ကို ရွေးပါ။

## Combination များ ပြုလုပ်ပြီး စစ်ဆေးရန်

Load case များကို ၎င်းတို့၏ အမျိုးအစား ပေးပြီး {{ui:Make combinations}}: ACI 318-19 သည် ASCE 7 ၏ strength combination များကို ယူသည် (§5.3.1)။ {{ui:Check concrete}} ကို နှိပ်ပါက အဖွဲ့ဝင် တိုင်းတွင် utilisation ရမည်၊ steel စစ်ဆေးမှုများကဲ့သို့ မော်ဒယ်ပေါ်တွင် အရောင်ခွဲ: flexure နှင့် အနည်းဆုံး သံ (22.2, 9.6.1.2)၊ tension-controlled strain (9.3.3.1)၊ ties ပါ shear (22.5, 9.6.3)၊ tie အကွာအဝေး၊ နှင့် ကော်လံအတွက် axial load နှင့် moment (22.4၊ နှစ်ဘက် ကွေးညွှတ်မှုအတွက် Bresler နည်းလမ်းနှင့်)။ ဆွဲထားသော အပိုင်းသည် သင်ရိုက်ထည့်ထားသော b × h နှင့် ကွဲပြားသော အဖွဲ့ဝင်ကို *partly checked* ဟု ဖတ်ရမည်၊ ပါးလွှာသော ကော်လံ သို့မဟုတ် threshold ထက် ပိုသော torsion လည်း ထိုနည်းတူ: ထိုအရာများကို ဒီဇိုင်း မလုပ်ပါ။

စွမ်းရည်ထက် ကျော်သော အဖွဲ့ဝင်များကို {{ui:Problems}} တွင် စာရင်းပြုသည်; အကြောင်းပြချက်ဖြင့် လက်ခံပါ၊ သို့မဟုတ် အပိုင်းဖြတ်ကို ပြင်ပါ။

## ကြမ်းပြင်များနှင့် seismic load များ

ကြမ်းပြင်ဆိုသည်မှာ frame ကို rigid slab (**rigid diaphragm**) ဖြင့် ချိတ်ထားသော level ဖြစ်သည်။ {{ui:Seismic loads}} block တွင် {{ui:Find floors}} ကို နှိပ်ပါ: အဘောင် နှစ်ခု သို့မဟုတ် ထို့ထက်ပို တွေ့သော level များကို ယူသည်။ ထို့နောက် ကြမ်းပြင်တစ်ခုစီကို **seismic weight** ပေးပါ၊ ရိုက်ထည့်ခြင်း သို့မဟုတ် ဖတ်ခြင်း: {{ui:Take weights from cases}} သည် သင်ပေးသော factor ဖြင့် case များ၏ ဒေါင်လိုက် load များကို ပေါင်းသည် (dead case သည် 1; storage live case သို့မဟုတ် flat roof ရှိ snow အတွက် 0.25 ထည့်ပါ ASCE 7-22 12.7.2 အတိုင်း)။ Node တစ်ခုစီ၏ ဒေါင်လိုက် load သည် ၎င်းနှင့် တူသို့မဟုတ် အထက် ကြမ်းပြင်သို့ ရောက်သည်၊ ထို့ကြောင့် ကြမ်းပြင်နှစ်ခု ကြား ကော်လံသည် အလေးချိန် တစ်ဝက်ကို ကြမ်းပြင်တစ်ခုစီသို့ ပေးသည်။

Design တန်ဖိုးများကို ဖြည့်ပါ: SDS, SD1, S1, R, Ie, Cd, TL၊ structural system (period အတွက်) နှင့် risk category။ {{ui:Make seismic cases}} သည် မော်ဒယ်အမြင့်မှ period ကို တွက်သည် (12.8.2.1)၊ base shear V = Cs W (12.8.1) ကို တွက်သည်၊ ကြမ်းပြင်များပေါ် အထက်သို့ ခွဲဝေသည် (12.8.3) နှင့် load case လေးခုကို ရေးသည်၊ X နှင့် Y တွင် accidental torsion 5 % တစ်ဖက်စီ (12.8.4.2)။ Storey force များနှင့် storey drift စစ်ဆေးမှု (12.8.6, Table 12.12-1၊ drift Cd δxe / Ie နှင့် 0.020 hsx ကို နှိုင်းယှဉ်) သည် run တစ်ခုပြီးနောက် ပေါ်သည်; ကန့်သတ်ချက်ထက်ကျော်သော drift သည် ပြဿနာတစ်ခု ဖြစ်သည်။ Seismic case များကို combination များထဲ ထည့်ရန် {{ui:Make combinations}} ကို ထပ်နှိပ်ပါ။

**Analysis မှ period။** ခန့်မှန်း period Ta သည် အဆောက်အအုံ အမြင့်မှ ရရှိသည်။ Seismic case များဖြင့် analysis ကို run ပြီးသည့်အခါ {{ui:Take the period from the analysis}} သည် ကြမ်းပြင်တစ်ခုစီ အင်အားအောက်တွင် ဘယ်လောက် ရွေ့သလဲ ဖတ်ပြီး Rayleigh နည်းလမ်းဖြင့် period ကို တွက်သည်၊ T = 2π √(Σ w δ² / (g Σ f δ)), X အတွက် တစ်ကြိမ်နှင့် Y အတွက် တစ်ကြိမ်; seismic case များကို ၎င်းဖြင့် ထပ်ပြုလုပ်သည်။ သုံးသော period သည် Cu·Ta ထက် ဘယ်တော့မှ မများပါ (ASCE 7-22 12.8.2)၊ ထို့ကြောင့် အားနည်းသော မော်ဒယ်က base shear ကို ထိုတန်ဖိုးအောက် မလျှော့နိုင်ပါ။ ဒုတိယ run ပြီးနောက် period ကို ထပ်ယူပါ: အဆင့် တစ်ဆင့် သို့မဟုတ် နှစ်ဆင့်တွင် တည်ငြိမ်သည်။ Ta သို့ ပြန်သွားရန် {{ui:Period from the analysis}} ကို ဖြုတ်ပါ။

**ပါးလွှာသော ကော်လံများ (ACI 318-19 6.6.4.5)။** Non-sway ဟု ခေါ်သော frame အတွက်၊ k·ℓu/r သည် 34 + 12·M1/M2 ထက်ကျော် (အများဆုံး 40) ဖြစ်သော ကော်လံကို magnified moment Mc = δns · M2 အတွက် ဒီဇိုင်းလုပ်သည်: δns = Cm / (1 − Pu / 0.75 Pc), Pc = π² (EI)eff / (k ℓu)² နှင့် (EI)eff = 0.4 Ec Ig / (1 + βdns), နှင့် အနည်းဆုံး moment Pu (15 + 0.03 h)။ βdns (စတင်ရန် 0.6) သည် factored axial load ၏ ဆက်လက်ခံရသော အစိတ်အပိုင်း ဖြစ်သည်: သင့်ကိုယ်ပိုင် ရိုက်ထည့်ပါ။ Pu သည် 0.75 Pc သို့ ရောက်သော ကော်လံသည် ၎င်း၏ စစ်ဆေးမှုဖြင့် ပျက်ကွက်သည်။ Report တွင် ပါးလွှာသော ကော်လံတစ်ခုစီ၏ ကိန်းဂဏန်းများ ပါသည်။ **Sway** frame တွင် ပါးလွှာသော ကော်လံသည် "partly checked" ဖြစ်နေဆဲ: ၎င်း၏ magnification သည် second-order analysis လိုအပ်ပြီး ထိုအရာကို မတည်ဆောက်ရသေးပါ။

**Slab များ။** မော်ဒယ်တွင် ပလိတ်များ ရှိသည့်အခါ {{ui:Slab reinforcement}} block သည် strength combination တိုင်း၏ ပလိတ် moment များကို ယူပြီး Wood–Armer စည်းမျဉ်း (ကွေးညွှတ်မှုနှင့် ကွေ့ခြင်း တစ်ပြိုင်တည်း) ဖြင့် layer တစ်ခုစီက မီတာတစ်ခုလျှင် လိုအပ်သော သံကို တွက်သည်: အောက်နှင့် အပေါ်၊ x နှင့် y တွင်။ Thickness၊ cover နှင့် ဘား ပေးပါ; ဇယားက လိုအပ်သည်နှင့် ပေးထားသည်ကို၊ one-way shear ကို φVc နှင့် ပြသည်၊ လိုအပ်သည်ထက် နည်းသော layer သည် clause အလိုက် ပြဿနာ ဖြစ်သည်။ Deflection၊ ကော်လံများတွင် punching နှင့် ဖွင့်ပေါက်များ၏ trimmer bar များကို မဖုံးလွှမ်းပါ၊ four-node ပလိတ်များဖြင့် support ပေါ်ရှိ moment သည် နှေးကွေးစွာ ကပ်လာသည်။

သင်စာရင်းပြုသော ကြမ်းပြင်တိုင်းသည် analysis တွင် rigid diaphragm ဖြစ်လာပြီး၊ ၎င်း၏ အဘောင်များသည် ကြမ်းပြင် ရွေ့လျားမှုမှ axial force မသယ်ပါ။ CraftScript export သည် ကြမ်းပြင်ပါသော မော်ဒယ်အတွက် မပြုလုပ်ပါ။
