DetailCraft ၏ command များသည် မည်သည့်နည်းဖြင့် ရောက်ရောက် အတူတူပင်ဖြစ်သည်။ **menu style** သည် ၎င်းတို့ မျက်နှာပြင်ပေါ် ဘယ်မှာရှိမလဲ၊ ထိုနေရာတွင် ဘယ်လိုခေါ်မလဲနှင့် ဘယ် key က run မလဲကိုသာ ဆုံးဖြတ်သည်။ {{ui:ဆက်တင်များ}} ({{key:Mod+,}}) › {{ui:DetailCraft}} › {{ui:Menus, keys နှင့် mouse}} တွင် ရွေးပါ; ပြောင်းလဲမှုသည် ချက်ချင်း ဖြစ်ပြီး ဤ browser က မှတ်ထားသည်။

## style သုံးမျိုး

| Style | ရရှိမည့်အရာ |
|---|---|
| {{ui:DetailCraft}} | DetailCraft ၏ကိုယ်ပိုင် toolbar (ဖိုင်, နေရာချရန်, {{ui:ချိတ်ဆက်ရန်}}, {{ui:တည်းဖြတ်ရန်}}, {{ui:ထုတ်ရန်}}) နှင့် single-letter key များ: {{key:V}} ရွေးရန်၊ {{key:B}} အဘောင်၊ {{key:C}} ကော်လံ၊ {{key:R}} ထောက်တိုင်၊ {{key:P}} ပလိတ်၊ {{key:F}} အုတ်မြစ်၊ {{key:S}} လှေကား။ စတင်သော style ဖြစ်သည်။ |
| {{ui:Drafting classic}} | command ရိုက်သူများအတွက်: အသေးစား ribbon ({{ui:ပင်မ}}၊ {{ui:ကြည့်ရှုမှု}}၊ {{ui:ထုတ်ရန်}}) နှင့် command line။ BEAM, COLUMN, BRACE, PLATE, FOOTING, STAIR, ENDPLATE, BASEPLATE, SHEARTAB, SPLICE, GUSSET, U (ပြန်ဖျက်ရန်), ZOOM, PLAN, 3D, DRAWINGS, NC သို့မဟုတ် HELP ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ; ဘာမှမရှိသော {{key:Enter}} သည် နောက်ဆုံး command ကို ပြန်လုပ်သည်၊ {{key:Esc}} က ရှင်းသည်။ နေရာတိုင်းတွင် စာရိုက်လျှင် အက္ခရာများသည် command line သို့ ရောက်သည်။ mouse အလယ်ခလုတ်က pan လုပ်သည်; 3D တွင် {{key:Shift}} နှင့် အလယ်ခလုတ် orbit လုပ်သည်။ |
| {{ui:Steel ribbon}} | steel detailing program များ စီစဉ်သည့်နည်းအတိုင်း tab များ: {{ui:မော်ဒယ်ဖန်တီးခြင်း}} (အဖွဲ့ဝင်များ၊ ကွန်ကရစ်၊ လှေကား), {{ui:အသေးစိတ်ဆွဲခြင်း}} (ချိတ်ဆက်မှုများ), {{ui:တည်းဖြတ်ရန်}}, {{ui:ပုံဆွဲများ}} (ပုံဆွဲများနှင့် အစီရင်ခံစာများ), {{ui:ထုတ်လုပ်ခြင်း}} (NC ဖိုင်များ၊ IFC) နှင့် {{ui:ကြည့်ရှုမှု}}၊ ညာဘက်တွင် {{ui:ဖိုင်}} menu နှင့် အမြန်ခလုတ်များ။ single-letter key များ ဆက်ရှိနေသည်။ mouse အလယ်ခလုတ်က pan; 3D တွင် ဘယ်ခလုတ်က orbit လုပ်သည်။ |

style တိုင်းသည် {{key:Mod+Z}}၊ {{key:Mod+Y}}၊ {{key:Mod+S}}၊ {{key:Mod+O}}၊ {{key:Mod+C}}၊ {{key:Mod+X}}၊ {{key:Mod+V}}၊ {{key:Mod+Shift+V}}၊ {{key:Mod+D}} နှင့် {{key:Mod+A}} ကို ထိန်းသည်။ ribbon များတွင် view bar ၏ {{ui:3D}}၊ {{ui:အပေါ်ပုံ}}၊ {{ui:အမြင်ပုံ}} နှင့် {{ui:ကိုက်ညီအောင်}} လည်း ပါဝင်သည်။

:::tip
DetailCraft ၏ ကိုယ်ပိုင် layout နှင့် ဆိုင်သော်လည်း သင့် style က command အခြားတစ်ခုကို ပေးထားသော key သည် ဘာမှမလုပ်ပါ၊ status line က ထို command ရောက်သွားသည့်နေရာကို ပြောပြသည် ("In My Steel ribbon, Column is Ctrl+Alt+C" › "My Steel ribbon ထဲတွင် ကော်လံသည် Ctrl+Alt+C")။ {{key:Delete}}၊ {{key:Esc}}၊ {{key:Enter}}၊ {{key:Tab}}၊ {{key:Space}} နှင့် မြားခလုတ်များသည် အမြဲ ၎င်းတို့၏ အဓိပ္ပာယ် ဆက်ရှိနေသည်၊ အဖွဲ့ဝင်တစ်ခု တစ်ဝက်ချထားနေစဉ် သို့မဟုတ် ကူးမိတ္တူ pointer ကို လိုက်နေစဉ် အက္ခရာများသည် DetailCraft ၏ဖြစ်သည်။
:::

## ကိုယ်ပိုင်ပြုလုပ်ခြင်း

1. သင်လိုချင်သည်နှင့် အနီးဆုံး style ကို ရွေးပြီး {{ui:စိတ်ကြိုက်ပြင်ရန်…}} ကို နှိပ်ပါ။
2. {{ui:Keys နှင့် menus}} တွင် command တစ်ခုကို ရှာပါ (ရှာဖွေရေးအကွက်က ကူညီသည်)။ {{ui:key ထည့်ရန်}} ကို နှိပ်ပြီး key ကို နှိပ်ပါ၊ သို့မဟုတ် အက္ခရာနှစ်လုံး key အတွက် key နှစ်ခုကို တစ်ဆက်တည်း နှိပ်ပါ။ key တစ်ခုကို နှိပ်လျှင် ဖယ်ထုတ်သည်။
3. ribbon ဖြင့် {{ui:တည်နေရာ}} က command ကို အခြား tab နှင့် panel၊ {{ui:ဖိုင်}} menu သို့မဟုတ် {{ui:Keys သာ}} သို့ ရွှေ့သည်။
4. {{ui:Mouse}} တွင် wheel၊ အပေါ်ပုံနှင့် အမြင်ပုံကို pan လုပ်သော ခလုတ်များနှင့် 3D view တွင် ခလုတ်တစ်ခုစီ ဘာလုပ်မလဲကို သတ်မှတ်ပါ။
5. အမည်ပေးပြီး {{ui:သိမ်းရန်}} ကို နှိပ်ပါ။

built-in style ကို သိမ်းလျှင် ကိုယ်ပိုင် မိတ္တူ ("My Steel ribbon") ဖြစ်သည်; built-in ကို ဘယ်တော့မှ မပြောင်းပါ။ command နှစ်ခုသို့ ပေးထားသော key ကို အနီရောင်ဖြင့် ပြပြီး သိမ်းခင် ပြင်ရမည်။

## Mouse

- **Mouse wheel**: {{ui:အပေါ်သို့ scroll လုပ်လျှင် zoom in}} (စတင်သည့်) သို့မဟုတ် {{ui:အပေါ်သို့ scroll လုပ်လျှင် zoom out}}၊ နှင့် ဘယ်လောက်မြန်မလဲ။ trackpad pinch သည် သင့်လက်ချောင်းများ ရွေ့သည့်အတိုင်း အမြဲ zoom လုပ်သည်။
- **အပေါ်ပုံနှင့် အမြင်ပုံကို pan လုပ်ရန်**: အလယ်ခလုတ်၊ ညာခလုတ် သို့မဟုတ် နှစ်ခုလုံး။ ရွေးရန် tool ဖြင့် ဘယ်ခလုတ်သည် အမြဲ ရွေးချယ်ဝင်းဒိုး ဆွဲသည်။
- **3D view တွင် ဆွဲခြင်း**: {{ui:view တစ်ခုချင်းစီ၏ ကိုယ်ပိုင်}} က DetailCraft ၏ခလုတ်များကို ထိန်းသည် (ဘယ်က orbit၊ အလယ်က zoom၊ ညာက pan)။ သို့မဟုတ် ခလုတ်တစ်ခုစီကို orbit, pan, zoom သို့မဟုတ် ဘာမှမလုပ်ရန် သတ်မှတ်ပါ; orbit သို့မဟုတ် pan လုပ်သော ခလုတ်ဖြင့် {{key:Shift}} သည် နှစ်ခုကို လဲလှယ်သည်။

## သင်နှင့်အတူ ယူဆောင်ခြင်း

{{ui:ထုတ်ယူရန်}} သည် အသုံးပြုနေသော style ကို အသေးစား `.ccinput.json` ဖိုင်အဖြစ် သိမ်းသည်; {{ui:သွင်းရန်…}} က အခြားကွန်ပျူတာ သို့မဟုတ် လုပ်ဖော်ကိုင်ဖက်မှ တစ်ခု ထည့်သည်။ သွင်းသော ဖိုင်သည် DetailCraft ၏ကိုယ်ပိုင် command များကိုသာ ညွှန်ပြနိုင်သည်: အခြားအရာများကို ဖယ်ထုတ်ပြီး status line တွင် ရေတွက်ပြသည်။ {{ui:ဤ style ကို ဖျက်ရန်}} က သင်ကိုယ်တိုင်ဖန်တီးထားသော တစ်ခုကို ဖျက်သည်။

:::note
ဤ ဆက်တင်များသည် ဤ browser တွင် ကျန်ရှိသည်။ style card များအောက်ရှိ {{ui:ဤ style ကို အက်ပ်အားလုံးတွင် အသုံးပြုရန်}} သည် အက်ပ်တိုင်းကို ၎င်းနှင့် ကိုက်ညီသော style (ကိုယ်ပိုင် toolbar၊ ribbon သို့မဟုတ် Drafting classic) ဖြင့် ဖွင့်စေပြီး အက်ပ်တစ်ခုစီတွင် သင်ပြုလုပ်ခဲ့သော ပြောင်းလဲမှုများ ပါဝင်သည်။ DetailCraft တွင် menu-bar style မရှိပါ: အခြားအက်ပ်၏ menu bar ကို အက်ပ်အားလုံးအတွက် ရွေးထားသောအခါ DetailCraft သည် ကိုယ်ပိုင် toolbar ကို ဆက်ထားသည်။
:::
