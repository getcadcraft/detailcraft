## သင်လုပ်မည့်အရာ

IDS (Information Delivery Specification၊ buildingSMART စံနှုန်း) သည် IFC တွင် ပါရမည့်အရာများ၏ စာရင်း ဖြစ်သည်။ DetailCraft သည် သင်ရရှိထားသော IDS နှင့် IFC ကို စစ်ဆေးသည် (ဘယ် {{ui:IFC}} ရေးသလဲ ထိုဖိုင်အတိုင်း)၊ မပြည့်မီသော အစိတ်အပိုင်းတိုင်းကို စာရင်းပြုစုသည်။

## အဆင့်များ

1. မော်ဒယ်ကို ဖွင့်ပါ သို့မဟုတ် ဆွဲပါ။
2. Toolbar ၏ {{ui:Output}} အုပ်စုတွင် {{ui:IDS ဖြင့် စစ်ဆေးရန်…}} ကို နှိပ်ပါ။
3. {{ui:.ids ဖိုင် တင်ရန်…}} ကို နှိပ်ပြီး ဖိုင်ကို ရွေးပါ။ ဘာမျှ မတင်ပါ။
4. ရလဒ်ကို ဖတ်ပါ: specification တစ်ခုစီနှင့် {{ui:အောင်မြင်}} သို့မဟုတ် {{ui:မအောင်မြင်}}၊ ၎င်း လျှောက်သော element အရေအတွက်။
5. Problems ({{key:Ctrl+Shift+M}}) ကို ဖွင့်ပြီး ပျက်ကွက်မှု တစ်ခုကို နှိပ်ပါ: ၎င်းမှ ဆင်းသက်လာသော အဖွဲ့ဝင်၊ ချိတ်ဆက်မှု၊ လှေကားသို့မဟုတ် အုတ်မြစ် ရွေးချယ်သွားပြီး view သည် ၎င်းဆီ ဇူးမ်ဝင်သွားမည်။

## သင်မြင်ရမည့်အရာများ

- Export ထုတ်သော element တစ်ခုစီနှင့် မပြည့်မီသော requirement တစ်ခုစီအတွက် သတိပေးချက် တစ်ခု၊ specification အမည်၊ IDS က တောင်းဆိုသည့်အရာနှင့် export တွင် ရှိသည့်အရာ။
- Problems ရှိ စစ်ဆေးမှု အစီရင်ခံစာသည် IDS ဖြင့် စသည်: ၎င်း၏ ခေါင်းစဉ်၊ ဗားရှင်း၊ ရေးသူနှင့် specification တစ်ခုစီ၏ ရေတွက်မှုများ။

## သိထားသင့်သည်များ

- IDS ကို မော်ဒယ်ဖိုင်တွင် သိမ်းထားသဖြင့် မော်ဒယ်ကို ပြန်ဖွင့်သည့်အခါ ထပ်မံ စစ်ဆေးသည်။ တင်ခြင်း သို့မဟုတ် ဖယ်ရှားခြင်းသည် undo ပြန်လုပ်နိုင်သော အဆင့်တစ်ခု ဖြစ်သည်။
- ပြောင်းလဲမှု တစ်ခုစီကို နောက်ခဏတွင် ထပ်စစ်သည်; မော်ဒယ် ကြီးပါက စစ်ဆေးမှု တစ်ကြိမ်ချင်းစီကြား ပိုကြာသည်။
- Export ၏ GlobalIds များသည် မော်ဒယ်အမည်နှင့် DetailCraft အတွင်းရှိ အစိတ်အပိုင်း နံပါတ်များမှ ရရှိသဖြင့် စစ်ဆေးမှု တစ်ကြိမ်မှ နောက်တစ်ကြိမ်အထိ တည်ငြိမ်နေသည်။ မော်ဒယ်အမည် ပြောင်းလျှင် element အားလုံး GlobalIds အသစ် ရရှိသည်။
- ဂဏန်းများကို SI ယူနစ်ဖြင့် နှိုင်းယှဉ်သည် (export သည် မီလီမီတာဖြစ်ပြီး အလျားများကို ပထမ မီတာသို့ ပြောင်းသည်)။

- IDS ရှိ pattern များကို တန်ဖိုး အပြည့်အစုံအဖြစ် ဖတ်သည်။ အစမှ `^` နှင့် အဆုံးမှ `$` ကိုလည်း IDS ဖိုင် အများစု ဆိုလိုသည့်အတိုင်း "တန်ဖိုး အပြည့်အစုံ" ဟု ယူသည်။
