Shear tab (single plate, fin plate) သည် shop တွင် ကော်လံ၌ ဂဟေထားသော ပလိတ် ဖြစ်သည်; site တွင် အဘောင်၏ web ကို ဒေါင်လိုက် bolt အတန်း တစ်ခုဖြင့် ၎င်းနှင့် bolt ဆွဲသည်။ DetailCraft က tab ကို နေရာချ၊ အဘောင်ကို ကော်လံမှ ရှင်းလင်းစွာ ဖြတ်၊ tab နှင့် အဘောင် web တွင် အပေါက်များ ဖောက်၊ bolt နှင့် ဂဟေ ထည့်ပြီး အစွန်း အကွာအဝေးနှင့် ကိုက်ညီမှုအတွက် သတိပေးသည်။

## အလုပ်လုပ်သော နေရာ

- အဘောင် (I-shape သို့မဟုတ် channel) ၏ အဆုံးသည် **ဒေါင်လိုက်** I-shape ကော်လံ မျဉ်းပေါ်တွင် ရှိပြီး၊ ၎င်း၏ **flange** သို့မဟုတ် **web** နှင့် တွေ့သည်။
- **စတုရန်း၊ plan တွင် ထောင့်ဖြင့်၊ သို့မဟုတ် စောက်စောင်း**: tab သည် အဘောင်၏ web ကို လိုက်ပြီး အဘောင်သည် အနီးဆုံး ထောင့်က ကော်လံအထိ ကွာဟချက် ထိန်းရန် ဖြတ်သည်။ 60° ထက် ပိုတက် သို့မဟုတ် ဆင်းသော အဘောင်ကို ငြင်းပယ်သည်။

## Shear tab များ ထည့်ခြင်း

1. အဘောင်ကို ရွေးပါ။
2. {{ui:ချိတ်ဆက်ရန်}} အုပ်စုတွင် {{ui:နောက်ထပ်}} ကို ဖွင့်ပြီး {{ui:Shear tab များ}} ကို ရွေးပါ (သို့မဟုတ် {{ui:ဂုဏ်သတ္တိများ}} panel တွင် {{ui:Shear tab များ ထည့်ရန်}} ကို ရွေးပါ)။
3. ကော်လံနှင့် တွေ့သော အဘောင်၏ အခမဲ့ အဆုံးတိုင်းသည် tab တစ်ခု ရရှိသည်။ အဘောင် အဆုံးတစ်ခုစီသည် ချိတ်ဆက်မှု တစ်ခုသာ ယူသည်: shear tab သို့မဟုတ် end plate။

Tab ကို ရွေးပါ (နှိပ်သော သို့မဟုတ် bolt) ဖြင့် ဆက်တင်များ ကြည့်ပြီး ပြောင်းပါ။ {{ui:ဆင်တူသည်များသို့ သုံးရန်}} သည် ချိတ်ဆက်မှု မရှိသေးသော ဆင်တူ joint တိုင်းသို့ shear tab အဖြစ် ကူးသည်။

## သိထားသင့်သည်များ

- Tab သည် ကော်လံ၏ တပ်ဆင်မှု၏ အစိတ်အပိုင်း ဖြစ်သည် (shop တွင် ဂဟေထားသော); အဘောင်၏ တပ်ဆင်မှုတွင် အပေါက်များသာ ပါသည်။
- ထောင့်ဖြင့် သို့မဟုတ် စောက်စောင်း အဘောင်ကို ထောင့်မှန်ထက် ပိုနောက်ပြန် ဖြတ်သည် ၎င်း၏ အနီးဆုံး ထောင့်က ကွာဟချက် ထိန်းရန်။ DetailCraft က အဘောင်များကို ထောင့်မှန် ဖြတ်သည်: ဖြတ်သူက အဆုံးကို ကိုက်အောင် ဖြတ်သည်။ Tab ၏ ကော်လံဘက် အစွန်းကိုလည်း ထောင့်မှန် ဆွဲသည်။
- DetailCraft က ခွန်အား မစစ်ပါ။ သတိပေးချက်များက EN 1993-1-8 Table 3.3 အနည်းဆုံး အစွန်း အကွာအဝေးနှင့် pitch များကို အသုံးပြုပြီး tab သည် အဘောင် web ၏ fillet အကြား အနက်ထက် နက်သည် သို့မဟုတ် bolt များသည် အဘောင်၏ ဖြတ်ထားသော အဆုံးနှင့် နီးလွန်းသည် ဟု ပြောသည်။
- [ထိမိမှု စစ်ဆေးခြင်း](topic:clash-check) သည် tab နှင့် ၎င်းချိတ်ဆက်သော အဖွဲ့ဝင်များကို ဖယ်ထားသည်: ၎င်းတို့ တွေ့ရန် ရည်ရွယ်ထားသည်။
