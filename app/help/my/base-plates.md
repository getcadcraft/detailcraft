အခြေပလိတ် ချိတ်ဆက်မှုသည် ကော်လံအောက်တွင် ပလိတ်ကို ထားပေးပြီး ပလိတ်အထူအတိုင်း ကော်လံကို တိုစေကာ နှစ်ခုကို ဂဟေဆက်ပြီး ပလိတ်ရှိ အပေါက်များမှတစ်ဆင့် အင်ကာ ရော့ဒ် လေးချောင်းကို ထည့်ပေးသည်။

:::warning
အရွယ်အစားများသည် စတင်တန်ဖိုးများသာ ဖြစ်ပြီး ဒီဇိုင်း မဟုတ်ပါ။ DetailCraft သည် ဖိအား ခံနိုင်ရည်၊ ရော့ဒ် ခိုင်ခံမှုနှင့် မြှုပ်သွင်းနက်ဝင်မှုကို စစ်ဆေးခြင်း မပြုပါ။
:::

## အခြေပလိတ် ထည့်ရန်

1. {{ui:Select}} ({{key:V}}) ကို ရွေးပြီး ကော်လံတစ်ခုကို နှိပ်ပါ။ ၎င်းသည် ဒေါင်လိုက် ဖြစ်ရပါမည်။
2. {{ui:Connect}} အုပ်စုရှိ {{ui:Base plate}} ကို ရွေးပါ၊ သို့မဟုတ် {{ui:Properties}} အကန့်ရှိ {{ui:Add base plate}} ကို ရွေးပါ။
3. အခြေအနေဘားက "Base plate added with four anchor rods." ဟု ပြသသည်။ ချိတ်ဆက်မှုအသစ်ကို ရွေးထားသည်။

ကော်လံတစ်ခုတွင် အခြေပလိတ် တစ်ခုသာ ရှိနိုင်သည်။ ရှိပြီးသားဆိုလျှင် အခြေအနေဘားက "This column already has a base plate." ဟု ပြသသည်။

## အခြေ အသေးစိတ်: grout၊ ထောက်ပံ့ချက်များ၊ shear lug၊ ဝါရှာများ

လေးခုစလုံးသည် အခြေပလိတ် အသစ်တွင် ပိတ်ထားပြီး DetailCraft 0.4 မတိုင်မီ ပြုလုပ်ထားသော မော်ဒယ်များမှ အခြေပလိတ်များတွင်လည်း ပိတ်ထားသည်။

- **Grout အကွာအဝေး။** ပလိတ်သည် ကွန်ကရစ် အပေါ်ပိုင်းမှ ဤအကွာအဝေးဖြင့် အထက်တွင် ထားပြီး ရော့ဒ်များသည် ထိုအတိုင်း ပိုရှည်လာသည်။ AISC Design Guide 1 (2.10) က ပြီးသား ကြမ်းပြင်တွင် 1 in. နှင့် အုတ်မြစ် သို့မဟုတ် တိုင်တွင် 1½ မှ 2 in. ကို အကြံပြုသည်။ ကြီးမားသော ပလိတ်များနှင့် shear lug ပါသော ပလိတ်များအတွက် ပိုမိုသည်။
- **ထောက်ပံ့ချက်များ။** ကော်လံနှင့် ပလိတ်သို့ ဂဟေဆက်ထားသော ဒေါင်လိုက် ပလိတ်များ၊ ကော်လံ မျက်နှာမှ ပလိတ် အစွန်းအထိ၊ စတုဂံအဖြစ် (ထောင့်ဖြတ် သို့မဟုတ် ပါးလွှာမှု မရှိသေး)။ **2** သည် web နှင့် တန်းညီ၊ flange တစ်ခုစီ၏ အပြင်ဘက်တွင် ရပ်တည်သည်။ **4** သည် web ၏ ထောင့်မှန် နှစ်ခုကို ထပ်ထည့်သည်၊ flange များကြား၊ ပလိတ် ဘေးများအထိ။ ပိုက်ကော်လံတွင် မျက်နှာတစ်ခုစီ၏ အလယ်တွင် ရပ်တည်သည်။ တစ်ခုစီသည် နှစ်ဖက်စလုံးမှ ကော်လံနှင့် ပလိတ်သို့ ဂဟေဆက်ထားသည်။
- **Shear lug။** အခြေပလိတ်အောက်တွင် ပတ်လည် ဂဟေဆက်ထားသော ပလိတ်ဖြစ်ပြီး ကော်လံ အနက်နှင့် တန်းညီ၊ ဗဟိုတွင် ထားသည်။ Grout အကွာအဝေးထက် နက်မနေပါက DetailCraft က သတိပေးသည်။ အုတ်မြစ်ထဲတွင် အိတ်ပေါက် မဖြတ်ပါ၊ ထို့ကြောင့် [ထိုးဝင်မှု စစ်ဆေးခြင်း](topic:clash-check) က lug နှင့် အုတ်မြစ်ကို ထည့်မတွက်ပါ။
- **ပလိတ် ဝါရှာများ။** ရော့ဒ်တိုင်းပေါ်တွင် စတုရန်း ပလိတ် ဝါရှာ တစ်ခု၊ အခြေပလိတ်ပေါ်တွင် ထိုင်ထားပြီး ကော်လံ တပ်ဆင်မှုတွင် လွတ် (ကော်လံနှင့်အတူ ပို့ပြီး ဂဟေမဆက်ပါ: Design Guide 1, 2.6) ဟု စာရင်းပြုသည်။ အရွယ်အစားနှင့် အထူကို 0 ထားလျှင် DetailCraft က AISC Design Guide 1, 2nd ed., Table 2.3 မှ ရော့ဒ်အတွက် အနည်းဆုံး ဝါရှာကို ယူသည်။ metric ရော့ဒ်များက နောက်ဆက်တွဲ inch အရွယ်အစားကို ယူသည် (M20 ရော့ဒ်သည် 7/8 in. အတန်းကို ရရှိသည်: 2½ in. × 5/16 in.)။ ဂုဏ်သတ္တိ အကန့်တွင် အသုံးပြုသော အရွယ်အစားကို ပြသည်။ ဝါရှာ အပေါက်သည် ရော့ဒ် အချင်း + 1/16 in. ဖြစ်သည်: ဤသည် DetailCraft ၏ ရွေးချယ်မှု ဖြစ်ပြီး ဇယားက မပေးပါ။ ရော့ဒ်များသည် ဝါရှာနှင့် nut အတွက် လုံလောက်စွာ ထွက်မနေနိုင်ပါက (ထွက်နေမှု < ဝါရှာ အထူ + ရော့ဒ် အချင်း) DetailCraft က သတိပေးသည်။

Design Guide 1၊ Table 2.3 က ပလိတ်ရှိ ရော့ဒ် အပေါက်ကိုလည်း အကြံပြုသည်: ¾ in. ရော့ဒ်အတွက် 1-5/16 in.၊ ⅞ in. အတွက် 1-9/16 in.၊ 1 in. အတွက် 1-13/16 in.။ DetailCraft သည် သင့်အပေါက် အရွယ်အစားကို မပြောင်းပါ။

ရော့ဒ် အပေါက်များသည် ပလိတ်အစွန်းနှင့် အပေါက် အချင်း 1.2 × ထက် နီးနေပါက၊ ရော့ဒ်များသည် ကော်လံ အပြင်ပိုင်းအတွင်း ကျနေပါက၊ သို့မဟုတ် ပလိတ်သည် ကော်လံထက် သေးငယ်နေပါက သတိပေးချက်များ ပေါ်သည်။

## ဆင်တူ ကော်လံများသို့ ကူးရန်

1. အခြေပလိတ်ကို ရွေးပါ။
2. {{ui:Apply to similar (n)}} ကို ရွေးပါ၊ သို့မဟုတ် {{ui:Connect}} အုပ်စု၏ {{ui:More}} မီနူးရှိ {{ui:Similar}} ကို ရွေးပါ။
3. ပရိုဖိုင် တူညီပြီး အခြေပလိတ် မရှိသော၊ အခြား ကော်လံပေါ်တွင် မရပ်သော ဒေါင်လိုက် ကော်လံတိုင်းသည် ကူးယူမှု ရရှိသည်။

## အခြေပလိတ်များနှင့် အုတ်မြစ်များ

အခြေပလိတ်သည် အုတ်မြစ် လိုအပ်ခြင်း မရှိပါ၊ အုတ်မြစ်သည်လည်း ၎င်းအပေါ်ရှိ အခြေပလိတ်ကို မသိပါ: အင်ကာ ရော့ဒ်များကို အုတ်မြစ်၏ သံချောင်းများနှင့် မချည်ပါ။ အုတ်မြစ်များကို {{ui:Footing}} ဖြင့် ထားပါ၊ [ဘားဖြင့် အုတ်မြစ် ထားခြင်း](topic:footings-and-rebar) ကို ကြည့်ပါ။
