ဤသည်မှာ 0.8.1 နှင့် နှိုင်းယှဉ်လျှင် DetailCraft 0.9 တွင် ပြောင်းလဲချက်များ ဖြစ်သည်။ 0.9 တွင် UK သံမဏိအရွယ်အစားများ၊ အပိုင်းတိုင်းအတွက် စက်ရုံပုံဆွဲတစ်ခုစီကို တစ်ကြိမ်တည်း၊ frame များအတွက် ပိုကြီးသော {{ui:Analysis}} tab နှင့် အတူလုပ်ဆောင်သူများ၏ cursor များကို တွေ့ရှိနိုင်ခြင်း ပါဝင်သည်။

## အသစ်

### UK သံမဏိနှင့် စက်ရုံပုံဆွဲများ

- **UK သံမဏိအရွယ်အစားများ။** profile စာရင်းများတွင် Steel for Life Blue Book မှ အရွယ်အစား 976 ခု ပါဝင်သည်: UB၊ UC၊ PFC၊ EA၊ UEA၊ CHS၊ SHS နှင့် RHS၊ cold-formed hollow section များကို (အမည်များသည် CF ဖြင့် စတင်သည်) သီးခြားထားသည်။ အမည်များကို မိသားစုအရင်ဖြင့် ရေးသည်၊ ဥပမာ UB305x165x40 သို့မဟုတ် SHS100x100x5.0၊ ပုံဆွဲများက ပြောသည့်ပုံစံအတိုင်း ရိုက်ထည့်လည်း အလုပ်လုပ်သည်: 305x165x40 UB၊ L100x100x10၊ SHS100x5။ [Profile catalog](topic:profile-catalog) ကို ကြည့်ပါ။
- **မညီသော ထောင့်များ။** UEA ထောင့်များသည် IFC in နှင့် out တွင်နှင့် NC ဖိုင်များတွင် ခြေထောက်နှစ်ဖက်စလုံးကို ထိန်းထားပြီး mirror က အပိုင်းကို အဆုံးမှ အဆုံးသို့ လှည့်ပေးသည်။
- **စက်ရုံပုံဆွဲအားလုံးတစ်ကြိမ်တည်း။** ဘာမျှ မရွေးဘဲ {{ui:Output}} အုပ်စုရှိ {{ui:Shop drawing}} ကို ရွေးပါ။ ပြတင်းပေါက်သည် အပိုင်းမှတ် (part mark) အားလုံးကို စာရင်းပြုစုပြီး မည်သည်တစ်ခုကိုမဆို အစမ်းကြည့်နိုင်သည်၊ {{ui:Download all}} သည် စာမျက်နှာတစ်ခုစီကို mark တစ်ခုစီအတွက် ပေးပြီး "Sheet 3 of 42" ဟု ခေါင်းစဉ်တပ်ထားသော PDF တစ်ခုတည်းကို သိမ်းသည်။ {{ui:Download this sheet}} က သင်ကြည့်နေသော တစ်ခုတည်းကို သိမ်းသည်။ Channel၊ angle နှင့် hollow section များလည်း ယခု စာရွက်များ ရရှိသည်။ [စက်ရုံပုံဆွဲများ ထုတ်ခြင်း](topic:shop-drawings) ကို ကြည့်ပါ။
- **My profiles။** စိတ်ကြိုက် profile ကို မော်ဒယ်အသစ်တိုင်းအတွက် ယခု သိမ်းထားနိုင်သည်။ Custom profile ပုံစံတွင် {{ui:Keep in My profiles}} ကို အမှတ်ခြစ်ထားပါ၊ ၎င်းအောက်ရှိ {{ui:My profiles}} စာရင်းတွင် {{ui:Keep}}၊ {{ui:Use here}} နှင့် {{ui:Remove}} ရှိသည်။ စာရင်းကို ဤဘရောက်ဇာတွင် သိမ်းထားသည် (200 အထိ)၊ သင့်အကောင့်တွင် မဟုတ်ပါ။ [Plate နှင့် profile များ](topic:plates-and-profiles) ကို ကြည့်ပါ။

### Analysis

- **ဒုတိယအစီအစဉ် (P-Delta)။** {{ui:Analysis}} tab ရှိ Run ဘေးရှိ {{ui:Second order (P-Delta)}} ကို အမှတ်ခြစ်ပါက axial force များသည် ပြောင်းသွားသော frame ပေါ်တွင် လုပ်ဆောင်သည်။ Plate များနှင့် ခိုင်မာသော floor များသည် ပထမအဆင့်တွင် ကျန်ရှိပြီး သတိပေးချက်ဖြင့် ဖြစ်သည်။ [အားများ၊ ဓာတ်ပြန်များနှင့် အကွေးများ](topic:frame-analysis) ကို ကြည့်ပါ။
- **သဘာဝကြိမ်နှုန်းများ။** ရလဒ်များအောက်ရှိ {{ui:Finite elements: natural frequencies}} block သည် တူညီသော မော်ဒယ်၏ အနိမ့်ဆုံး mode များကို ရှာပြီး period နှင့် effective modal mass ဖြင့် mode တစ်ခုကို မော်ဒယ်ပေါ်တွင် ပြသည်။ [အားများ၊ ဓာတ်ပြန်များနှင့် အကွေးများ](topic:frame-analysis) ကို ကြည့်ပါ။
- **လေဝင်ဝန်များနှင့် ငလျင်နေရာ။** {{ui:Analysis}} tab တွင် block သုံးခု အသစ်ရှိသည်: {{ui:Wind loads (ASCE 7 directional procedure)}}၊ {{ui:Seismic site and system (ASCE 7)}} နှင့် {{ui:ASCE 7 load combinations}}။ [လေဝင်၊ ငလျင်နေရာနှင့် ASCE 7 ပေါင်းစပ်မှုများ](topic:wind-seismic-combinations) ကို ကြည့်ပါ။

### တစ်ခုတည်း လုပ်ဆောင်ခြင်း

- **Cursor များနှင့် နာမည်များ။** Live session တွင် လူတိုင်း၏ ညွှန်မှတ်ကို ၎င်းတို့၏ နာမည်နှင့် အရောင်ဖြင့် မော်ဒယ်ပေါ်တွင် ဆွဲပြသည်၊ ၎င်းတို့ ရွေးထားသည်များတွင် ဘောင်တစ်ခု ရှိသည်။
- **လူတစ်ယောက်ကို Follow လုပ်ခြင်း။** session ရှိ {{ui:People}} ကို ဖွင့်ပြီး နာမည်တစ်ခုပေါ်ရှိ {{ui:Follow}} ကို ရွေးပါ; သင့်ကြည့်ရှုမှုသည် ၎င်းတို့နှင့်အတူ ရွေ့သွားမည်။ host က {{ui:Ask everyone to follow me}} ကို ရွေးနိုင်သည်။ [Live session တွင် လူတစ်ယောက်ကို Follow လုပ်ခြင်း](topic:follow-in-live) ကို ကြည့်ပါ။

### အက်ပ်အားလုံးတွင်

- Tooltip များသည် Bootstrap tooltip များဖြစ်ပြီး၊ start tip card တွင် ပိတ်ခလုတ် ရှိသည်၊ tab အစုများသည် မကိုက်ညီသောအခါ ဘေးသို့ scroll လုပ်သည်၊ ဘရောက်ဇာ tab အမည်သည် ဖွင့်ထားသော စာရွက်စာတမ်းနှင့် DetailCraft နှင့် CadCraft ကို ပြသည်။

## ပြင်ဆင်ပြီး

- Model အသစ်တစ်ခု စတင်သောအခါ စိတ်ကြိုက် profile ပျောက်သွားသည်။
- Channel၊ angle နှင့် hollow section များသည် စက်ရုံပုံဆွဲအစုံတွင် မရှိခဲ့ပါ။

## ရိုးသားသော ကန့်သတ်ချက်များ

- လေ၊ ငလျင်နှင့် finite element block များသည် စစ်ဆေးမှု အကူအညီများဖြစ်သည်။ သင့်အင်ဂျင်နီယာက ရလဒ်များကို သုံးသပ်ရမည်; ၎င်းတို့သည် ကုဒ်စစ်ဆေးမှု မဟုတ်ပါ။ USGS ရှာဖွေမှုကို live ဝန်ဆောင်မှုပေါ်တွင် မဟုတ်ဘဲ တုပ ဝန်ဆောင်မှုပေါ်တွင် စမ်းသပ်ခဲ့သည်။
- Finite element နှင့် P-Delta များကို လက်ဖြင့်နှင့် closed-form အဖြေများနှင့် စစ်ဆေးထားသည်၊ အမှန်တကယ် အဆောက်အအုံတစ်ခုတွင် မဟုတ်ပါ။ Buckling analysis မတည်ဆောက်ရသေးပါ။
- UK ဖြတ်လုပ်သူ တစ်ယောက်မျှ UK အရွယ်အစားများကို မစမ်းသပ်ရသေးပါ၊ မညီသော ထောင့်များအတွက် NC ဖိုင်များကို စက်တစ်လုံးပေါ်တွင် မလည်ပတ်ရသေးပါ။
- စက်ရုံပုံဆွဲအစုံသည် PDF သာ ဖြစ်သည်။
- အင်္ဂလိပ်မှတစ်ပါး ဘာသာစကားများသည် စက်မူကြမ်းများ ဖြစ်သည်။
- Windows installer များကို code-sign မလုပ်ထားပါ (More info ထို့နောက် Run anyway); macOS disk image ကို notarize မလုပ်ထားပါ (right-click ထို့နောက် Open)။

ယခင် ပြောင်းလဲမှုများကို ဤစာမျက်နှာ၏ အောက်ပိုင်းရှိ 0.8 နှင့် 0.8.1 မှတ်စုများတွင် တွေ့နိုင်သည်။

## ယခင်: 0.8 နှင့် 0.8.1

ဤသည်မှာ 0.7 နှင့် နှိုင်းယှဉ်လျှင် DetailCraft 0.8 (1 November 2026) နှင့် 0.8.1 (2 November 2026) တွင် ပြောင်းလဲချက်များ ဖြစ်သည်။ 0.7 သည် သံမဏိအပိုင်းများကို စစ်ဆေးခဲ့သည်; 0.8 သည် မ လှုပ်ရှားမှုများကို စီစဉ်၊ ချိတ်ဆက်မှုများကို အကြံပြုကာ အုတ်မြစ်များနှင့် rebar ကို စစ်ဆေးပြီး သစ်သား နှင့် light-gauge နံရံ၊ ကြမ်းပြင်နှင့် အမိုးများကို ဘောင်ဆွဲသည်။

- **ထောင်ခြင်းအစီအစဉ်နှင့် movie။** {{ui:Erection}} tab တွင် crane ကို ဖော်ပြပါ (ဘယ်မှာရပ်သလဲ၊ အမြင့်ဆုံး hook၊ chart တွင် မပါသော rigging)၊ ထို့နောက် ၎င်း၏ load chart ၏ အတန်းများကို ရိုက်ထည့်ပါ။ DetailCraft သည် မော်ဒယ်ကို assembly တစ်ခုချင်းစီ၊ phase အစဉ်လိုက်နှင့် tier တစ်ခုချင်းစီဖြင့် မ လှုပ်ရှားပြီး၊ မ လှုပ်ရှားမှု တစ်ခုစီကို ၎င်း၏ radius တွင် chart နှင့် သင်သတ်မှတ်ထားသော margin နှင့် နှိုင်းယှဉ်သည်။ {{ui:Save movie}} သည် HTML ဖိုင်တစ်ခုကို ရေးသည်၊ ၎င်းသည် ဘရောက်ဇာမှန်သမျှတွင် အော့ဖ်လိုင်းဖြင့် ဖွင့်ရသည်၊ ဖုန်းပေါ်တွင်ပင်။ Chart အပြင်၊ ကျော်လွန်သော သို့မဟုတ် အလွန်မြင့်သော မ လှုပ်ရှားမှုများကို {{ui:Problems}} တွင် ဖော်ပြသည်။ ၎င်းသည် သင်၏ နံပါတ်များမှ ပြုလုပ်ထားသော အစီအစဉ်ဖြစ်ပြီး lift plan မဟုတ်ပါ။ [ထောင်ခြင်းအစီအစဉ်နှင့် movie](topic:erection-movie) ကို ကြည့်ပါ။

- **Connection autopilot။** {{ui:Autopilot}} tab သည် ချိတ်ဆက်မှုမရှိသော ဆက်အဆစ်တိုင်းကို ကြည့်ပြီး ပုံသဏ္ဍာန်များမှ ချိတ်ဆက်မှုတစ်ခုကို အကြံပြုသည်: base plate၊ shear tab၊ moment beam အဖြစ် သင်မှတ်သော beam များအတွက် end plate၊ splice နှင့် gusset။ uniform load သို့မဟုတ် အဆုံးတစ်ဖက် shear ပေးပါက bolt အရေအတွက်သည် bolt ၏ design strength ကို လိုက်သည်။ {{ui:Add them all}} သည် အကြံပြုချက်များကို undo အဆင့်တစ်ခုတည်းအဖြစ် ထည့်သည်။ ၎င်းတို့သည် သုံးသပ်ရန် စတင်တန်ဖိုးများဖြစ်ပြီး connection design မဟုတ်ပါ။
- **Constructability စစ်ဆေးမှုများ။** {{ui:Problems}} တွင် ဓာတ်ကြိုး မရောက်နိုင်သော bolt၊ socket အတွက် အလွန်နီးနေသော bolt များ၊ အရွယ်အစားကန့်သတ်ချက်ပြင်ပ fillet weld များနှင့် ရေကိုင်ထားနိုင်သော hollow section များကို ဖော်ပြသည်။ Weld access သည် အသစ်ဖြစ်သည်: welder ၏ ခေါင်းတွင်းဓာတ်မီး မရောက်နိုင်သော အဝိုင်းပတ် fillet weld ကို ပိတ်ဆို့နေသော အစိတ်အပိုင်းနှင့် ထိခိုက်သော weld ၏ အစိတ်အပိုင်းအပါအဝင် စာရင်းပြုသည်။ [Constructability စစ်ဆေးမှုများ](topic:constructability) ကို ကြည့်ပါ။

**အုတ်မြစ်နှင့် rebar**

- **Foundation စစ်ဆေးမှုများ။** {{ui:Foundation}} tab သည် သင်ဖော်ပြသော မြေပေါ်တွင် footing၊ combined footing နှင့် mat များကို စစ်သည်: service load မှ bearing၊ sliding နှင့် overturning; factored load မှ flexure၊ shear၊ punching၊ development နှင့် အနည်းဆုံး သံ (ACI 318-19)။ အစွန်း သို့မဟုတ် ထောင့်အနီးရှိ ကော်လံကို footing ၏ အစွန်းဖြတ်ထားသော အပိုင်းဖြင့် စစ်သည်။ Settlement ကို မြေ၏ modulus မှ ရသည်၊ flexible mat ကို subgrade modulus မှ spring များပေါ်တွင် ဖြေရှင်းသည်၊ pile group နှင့် retaining wall များတွင် ၎င်းတို့၏ ကိုယ်ပိုင် panel များ ရှိသည်။ ကော်လံ load များကို ရိုက်ထည့်နိုင်ပြီး သို့မဟုတ် {{ui:Analysis}} မှ ယူနိုင်သည်။ [Foundation စစ်ဆေးမှုများ](topic:foundation-checks) ကို ကြည့်ပါ။
- **Rebar congestion map။** {{ui:Congestion}} tab သည် footing တစ်ခုစီကို အပေါ်မှကြည့်သလို heat map ဆွဲသည်: ကွန်ကရစ် ဆင်းနိုင်ရန် အခန်းလွန်ကျဉ်းသော နေရာများကို clear-spacing စည်းမျဉ်းနှင့်၊ သင်ပေးပါက အကြီးဆုံး aggregate နှင့် vibrator head နှင့် နှိုင်းယှဉ်ပြသည်။ [Rebar congestion map](topic:rebar-congestion) ကို ကြည့်ပါ။

**ဘောင်ဆွဲခြင်းနှင့် supply**

- **သစ်သားနှင့် light-gauge ဘောင်ဆွဲခြင်း။** {{ui:Framing}} tab သည် နံရံ၊ ကြမ်းပြင်နှင့် အမိုး panel များကို အစိတ်အပိုင်းအားလုံး၊ cut list၊ ဝယ်ရမည့် stock နှင့် scale အတိုင်း စက်ရုံပုံဆွဲဖြင့် ဘောင်ဆွဲသည်။ {{ui:Place as members}} သည် အပိုင်းများကို မော်ဒယ်ထဲ ထည့်ပြီး {{ui:PDF sheets}} သည် panel တစ်ခုစီအတွက် စာရွက်တစ်ရွက် သိမ်းသည်။ အရွယ်အစား၊ အကွာအဝေးနှင့် header များသည် သင့်ဆုံးဖြတ်ချက်ဖြစ်သည်: DetailCraft သည် ၎င်းတို့က load ကို ထမ်းနိုင်သည်ဟု မစစ်ဆေးပါ။ [သစ်သားနှင့် light-gauge ဘောင်ဆွဲ panel များ](topic:framing-panels) ကို ကြည့်ပါ။
- **Supplier stock နှင့် lead time။** {{ui:Supply}} tab သည် supplier ၏ stock စာရင်း (CSV) ကို ဖတ်ပြီး cut list ဝယ်သော section တစ်ခုစီအတွက် stock လုံလောက်မလုံလောက်နှင့် စောင့်ရမည့်ကာလကို ပြသည်။ လိုအပ်ချက်မပြည့်သော နှင့် နောက်ကျသော section များကို {{ui:Problems}} တွင် ရှိသည်။ ဘာမျှ မမှာယူပါ။ [Supplier stock နှင့် lead time](topic:supplier-stock) ကို ကြည့်ပါ။

**Analysis နှင့် design**

- **ဘာကြိုဆုံးပျက်မလဲ?** {{ui:Analysis}} tab တွင် ခလုတ်သည် အုပ်ချုပ်သော ခိုင်ခံ့မှု ပေါင်းစပ်မှု၊ အားနည်းဆုံး အပိုင်း၊ ပထမအပိုင်းသည် ၎င်း၏ကန့်သတ်ချက်သို့ ရောက်မချင် load များ ဘယ်လောက်တိုးနိုင်သလဲ၊ နှင့် bolt ၏ shear strength သိရှိသော အားနည်းဆုံး end plate သို့မဟုတ် shear tab ကို ရှာသည်။ ပထမ ပေါင်းစပ်မှုများနှင့် design code လိုအပ်သည်။ Bearing၊ block shear၊ weld နှင့် prying များကို မစစ်ပါ။ သင်ချိတ်ဆက်ထားသော လက်ထောက်သည် တူညီသော မေးခွန်းကို မေးနိုင်သည်။
- **Live။** {{ui:Live: solve again after each edit}} ကို အမှတ်ခြစ်ပါက frame ကို တည်းဖြတ်တိုင်း ပြန်ဖြေရှင်းသည်။
- **ကွန်ကရစ်၊ နောက်ထပ်။** Non-sway frame ရှိ ပိန်သော ကော်လံကို ၎င်း၏ magnified moment အတွက် ဒီဇိုင်းလုပ်သည် (ACI 318-19 6.6.4.5)။ ငလျင်ကာလကို Rayleigh နည်းလမ်းဖြင့် analysis မှ ယူနိုင်သည်။ plate များဖြင့် ပြုလုပ်ထားသော slab သည် ၎င်း၏ moment များနှင့် one-way shear မှ layer တစ်ခုစီ လိုအပ်သော သံကို ရသည်။ [ကွန်ကရစ်အစိတ်အပိုင်းများ စစ်ခြင်းနှင့် ငလျင် load များ ပြုလုပ်ခြင်း](topic:concrete-and-seismic) ကို ကြည့်ပါ။
- **အင်ဂျင်နီယာ စစ်ဆေးရန်။** foundation၊ concrete နှင့် What breaks first ရလဒ်များသည် အကူအညီများဖြစ်သည်။ လေဝင်ဝန်များကို မတည်ဆောက်ရသေးပါ။

**အက်ပ်အားလုံးတွင်**

- **ဘာသာစကားများ။** အကူအညီသည် ဘာသာစကား ၅၄ ခုဖြင့် ရှိသည်။ အင်္ဂလိပ်မှတစ်ပါး ဘာသာစကားများသည် မိခင်ဘာသာစကား ဖတ်သူ မရမချင် စက်မူကြမ်းများဖြစ်ပြီး၊ ဆယ်ခုသည် အသစ်ဖြစ်သည် (Lithuanian၊ Latvian၊ Bosnian၊ Marathi၊ Telugu၊ Albanian၊ Afrikaans၊ Filipino၊ Swahili၊ Uzbek)။
- **Toolbar အတန်းများ။** {{ui:Settings}} › {{ui:General}} › {{ui:Toolbar rows}} တွင် wrap၊ အတန်း 2 ခု သို့မဟုတ် အတန်း 1 ခု ရွေးနိုင်သည်။ ကိုက်ညီနေပြီးသား ဘားသည် ယခင်အတိုင်း ရှိနေပြီး အခြားများသည် ဘေးသို့ scroll လုပ်သည်။
- **Property grid။** footing ၏ အကွက်များသည် မျှဝေ grid ကို သုံးသည်: ခေါက်သိမ်းနိုင်သော အမျိုးအစားများနှင့် compact density။ 2*450 ကဲ့သို့ ရိုက်ထည့်သော သင်္ချာ ယခုလည်း အလုပ်လုပ်သည်။
- **Input ကိရိယာများ။** Trackpad၊ pen၊ 3D mouse၊ controller နှင့် MIDI များဖြင့် apps များကို ထိန်းချုပ်နိုင်သည်။ [3D တွင် လှည့်ပတ်ခြင်း](topic:navigate-3d) ကို ကြည့်ပါ။
- **Problems panel။** အထက်ပါ အသစ်စစ်ဆေးမှုများ၏ သတိပေးချက်များသည် ယခင်အတိုင်း တူညီသော {{ui:Problems}} panel တွင် ပေါ်သည်။
- **AI ကို ချိတ်ဆက်ခြင်း။** CadCraft Studio မှတစ်ဆင့် ချိတ်ဆက်ထားသော သင်၏ကိုယ်ပိုင် လက်ထောက်သည် apps ရှစ်ခုလုံးနှင့် အလုပ်လုပ်ပြီး သင်ခွင့်ပြုသည်များကိုသာ မြင်သည်။ တစ်ချက်နှိပ်ချိတ်ဆက်မှု၊ hosted connector နှင့် Studio ရှိ သင့်ကိုယ်ပိုင် API key တို့သည် ကျန်ရှိနေသေးသည်။ [DetailCraft ကို AI လက်ထောက်နှင့် အသုံးပြုခြင်း](topic:use-with-ai-assistants) ကို ကြည့်ပါ။
