## သင်သိရမည့်အရာ

လူများစွာက တစ်ပြိုင်နက် အသေးစိတ်ဆွဲနေချိန်တွင် မော်ဒယ်တစ်ခုအတွက် ဘာဖြစ်သလဲ။ CadCraft Studio သည် Live TeamWork session ကို စတင်သည်နှင့် ဝင်ရောက်သည် (Share၊ Join); ဤစာမျက်နှာသည် မော်ဒယ်ကိုယ်တိုင်အကြောင်း ဖြစ်သည်။

## လူအားလုံး တပြိုင်နက် လုပ်ဆောင်သည်

အဖွဲ့ဝင်များ၊ ချိတ်ဆက်မှုများ၊ footing များ၊ လှေကားများနှင့် bolt များကို ပုံမှန်အတိုင်း ထည့်ပြီး တည်းဖြတ်ပါ။ သင့်ကိုယ်ပိုင် တည်းဖြတ်မှုများ ချက်ချင်း ပေါ်သည်; အခြားသူများ၏ တည်းဖြတ်မှုများသည် ၎င်းတို့ လုပ်ပြီးနောက် ခဏအကြာတွင် ပေါ်လာသည်။

- **လူနှစ်ယောက်က အဖွဲ့ဝင်တစ်ခုကို ပြောင်းသည်:** ဆက်တင် မတူညီလျှင် (တစ်ယောက်က profile၊ အခြားတစ်ယောက်က အဆုံးမှတ်) နှစ်ခုလုံး ထိန်းထားသည်; ဆက်တင်တူလျှင် နောက်ပြောင်းလဲမှုကို ယူသည်။
- **လူတစ်ယောက် ခုနက ဖျက်လိုက်သော အဖွဲ့ဝင်ပေါ်ရှိ ချိတ်ဆက်မှု** ကို ပြန်ဖျက်သည်၊ အခြေအနေဘားက အကြောင်းပြသည်။
- Grid များ၊ level များနှင့် phase များသည် နောက်ဆုံးပြောင်းလဲသူထံ သွားသည်။
- တည်ဆောက်ထားသော ပုံသဏ္ဍာန်၊ piece mark များနှင့် schedule ကို ပြတင်းပေါက်တိုင်းတွင် တူညီသော မော်ဒယ်မှ တွက်ချက်သဖြင့် ကိုက်ညီသည်။

## တစ်ဦးကိုတစ်ဦး မြင်ခြင်း

Session ရှိ လူတိုင်းတွင် ကိုယ်ပိုင်အရောင် ရှိသည်။ လူတစ်ယောက်စီ၏ ညွှန်မှတ်ကို ၎င်းတို့၏ အရောင်ဖြင့် မြား အဖြစ် မြင်ရပြီး ၎င်းတို့၏ နာမည်ကို ဘေးတွင် ရေးထားသည်၊ ၎င်းတို့ ညွှန်ပြနေသော အဖွဲ့ဝင် သို့မဟုတ် plate ပေါ်တွင်ရှိသည်၊ ၎င်းတို့ ရွေးထားသော အဖွဲ့ဝင်၊ ချိတ်ဆက်မှု၊ footing နှင့် လှေကားများ ပတ်လည်တွင် ၎င်းတို့ အရောင်ဖြင့် မျဉ်းတုတ် ဘောင်ရှိသည်။

ညွှန်မှတ်၊ နာမည်နှင့် ရွေးချယ်မှုများသည် session အတွက်သာဖြစ်သည်: ဖိုင်တွင် ဘယ်တော့မှ မသိမ်းပါ၊ မည်သူ့ undo ထဲမှ မဝင်ပါ။ ၎င်းတို့သည် လူတစ်ယောက်စီ ရှိသည့်နေရာသို့ ချောမွေ့စွာ ရွေ့သွားသည်၊ ထို့ကြောင့် နှေးသော ချိတ်ဆက်မှုပေါ်တွင်လည်း ချောမွေ့သည်။

## Undo သည် သင့်ကိုယ်ပိုင် အလုပ်ကို ပြန်ဖျက်သည်

{{key:Mod+Z}} သည် သင့်ကိုယ်ပိုင် နောက်ဆုံး တည်းဖြတ်မှုကို ပြန်ဖျက်ပြီး အခြားသူများ၏ တည်းဖြတ်မှုများကို မထိပါ။ ထိုနောက်ပိုင်း တူညီသောအရာကို တစ်စုံတစ်ယောက် ပြောင်းလဲခဲ့လျှင် ဘာမျှ မပြန်ဖျက်ပါ၊ အခြေအနေဘားက မည်သူဖြစ်သည်ကို ပြောပြသည်။

## ဘရောက်ဇာမှ ဝင်ရောက်ခြင်း

Studio မရှိသော အဖွဲ့သားတစ်ဦးသည် host ၏ ကုဒ်အောက်ရှိ ပုံကို တူညီသော ကွန်ရက်ပေါ်ရှိ ဖုန်း၊ tablet သို့မဟုတ် ကွန်ပျူတာဖြင့် စကင်န်ဖတ်နိုင်သည်။ DetailCraft သည် ဘရောက်ဇာတွင် ဖွင့်ပြီး host က ခွင့်ပြုသည်နှင့် host ၏ မော်ဒယ်ဖြင့် ဖြည့်သွင်းသည်။ Invite link ဖြင့် အခြားကွန်ရက်မှ ဝင်နိုင်သည်: host တွင် app အတွက် Team Cloud Plan နေရာ လိုအပ်ပြီး အခြားသူတိုင်း အခမဲ့ ဝင်သည်၊ link သည် host ၏ session ဖွင့်ထားစဉ်သာ အလုပ်လုပ်သည်။

## Session ပြီးဆုံးသောအခါ

Host သာ မော်ဒယ်ကို သိမ်းသည်။ အခြားသူအားလုံးသည် မသိမ်းရသေးသော မိတ္တူတစ်ခုကို ထိန်းထားရသည်: ထိန်းလိုပါက သိမ်းပါ။
