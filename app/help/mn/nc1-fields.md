Файл бүр `.nc1` нэг элементийн тэмдгийг тодорхойлно. Мөр бүр CR LF-ээр төгсөнө. Текст талбарт зөвхөн энгийн ASCII тэмдэгт бичигдэж, бусад тэмдэгт «?» болно. Хоёр дахь мөр нь тайлбар: `** DetailCraft <mark>.nc1`.

## Толгой хэсэг (ST)

| Талбар | I хэлбэр, суваг | Өнцөгт | Тэгш өнцөгт HSS | Дугуй HSS | Ялтас |
|---|---|---|---|---|---|
| Захиалга | Загварын нэр | ← | ← | ← | ← |
| Зураг, ширхэг | Элементийн тэмдэг | ← | ← | ← | ← |
| Үе шат | Элементийн үе шат, эсвэл 1 | ← | ← | ← | ← |
| Төмрийн чанар | Материалын зэрэг | ← | ← | ← | ← |
| Тоо | Энэ тэмдэгтэй элементийн тоо | ← | ← | ← | ← |
| Профайл | Профайлын нэр, жишээ нь W16x26 | ← | ← | ← | `PL<t>*<width>` |
| Профайлын код | I эсвэл U (суваг) | L | M | RO | B |
| Урт | Тайрах урт | ← | ← | ← | Урт |
| Өндөр | Гүн d | Хөл | Өндөр | Диаметр | Ялтасны өргөн |
| Тавцангийн өргөн | bf | Хөл | Өргөн | Диаметр | 0 |
| Тавцангийн зузаан | tf | t | Ханын t | Ханын t | 0 |
| Ирийн зузаан | tw | t | Ханын t | Ханын t | Ялтасны зузаан |
| Радиус | Булангийн радиус (AISC сувагт 0) | 0 | Гадна булангийн радиус | 0 | 0 |
| Метр тутмын жин | kg/m | kg/m | kg/m | kg/m | kg/m² |
| Метр тутмын будгийн гадаргуу | Гадна периметр, m²/m | ← | ← | ← | 2 (хоёр тал, m²/m²) |
| Хөрөөний өнцөг (4 талбар) | 0 (тэгш өнцөг) | ← | ← | ← | ← |
| Текст талбар (4) | `-` | ← | ← | ← | ← |

Ялтас нь стандартын «хуудсанд зориулсан» баганыг дагадаг. Стандартад дугуй хоолойн багана байхгүй тул DetailCraft диаметрийг өндөр ба тавцангийн өргөн хоёуланд, ханыг хоёр зузаанд нь бичдэг.

## Гадна контур (AK)

- **I хэлбэр ба суваг:** ир (v), огтлолт бүрт тэгш өнцөгт хэрчилттэй; тавцан бүр (o ба u), огтлолтын гүн тавцанд тэнцүү буюу түүнээс их бол тавцан тэр төгсгөлдөө богиносно.
- **Тэгш өнцөгт HSS:** хоёр хажуу хана (v ба h), огтлолтод зориулж хэрчсэн, мөн дээд ба доод хана (o ба u).
- **Өнцөгт:** хөл тус бүрт нэг тэгш өнцөгт (v ба u). Өнцөгт дээрх огтлолтыг бичдэггүй: ийм элемент бичигдээгүй гэж жагсана. [Гуссет](topic:brace-gussets)-д боолтоор бэхэлсэн өнцөгт диагоналын нүхийг боолтоор бэхэлсэн хөл дээр гаргана: элементийн u-ийн дагуух хөлд v, v-ийн дагуух хөлд u.
- **Дугуй HSS:** v дээр нэг тэгш өнцөгт, хоолойг урд талаас харсан (урт × диаметр).
- **Ялтас:** v гадаргуу дээр нэг тэгш өнцөгт.

Контур бүр хаалттай (эхний цэгийг төгсгөлд дахин давтана) бөгөөд цагийн зүүний эсрэг чиглэлд явна.

## Нүх (BO)

Нүх бүр нэг мөрөөр: гадаргуу, x, y, диаметр, гүн 0 (нэвтрүүлсэн). Бүх нүх орно: та оруулсан нүх ба холбоосууд үүсгэсэн нүх. Тэгш өнцөгт HSS-ийн хажуу ханаар дамжсан нүхийг хоёр удаа бичнэ: нэг нь v, нэг нь h дээр.

## Гадаргуу ба координат

Профайл бүр стандартын профайлын байрлалын зурагт зурсан шигээ байрлана (DSTV 1998, х. 7): x элементийн дагуу, Y хөндлөн, Z ард гадаргуунаас дээш, тэг цэг гадна булан дээр. DetailCraft зурагт тохируулахын тулд элементийг хэзээ ч толин тусгалаар эргүүлдэггүй.

| Гадаргуу | I хэлбэр | Суваг | Өнцөгт | Тэгш өнцөгт HSS | Ялтас |
|---|---|---|---|---|---|
| v | Ир, урд тал | Ир, ирмэгийн талаас харсан | Элементийн u-ийн дагуух хөл | Хажуу хана −u дээр | Ялтасны гадаргуу |
| h | | | | Хажуу хана +u дээр | |
| o | Дээд тавцан | **Доод** тавцан | | Дээд хана | |
| u | Доод тавцан | **Дээд** тавцан | Элементийн v-ийн дагуух хөл | Доод хана | |

- **x** элементийн дагуу, тайралтын эхлэлээс явна.
- **I хэлбэр ба тэгш өнцөгт HSS:** ир эсвэл хажуу хана дээрх y профайлын доод талаас; тавцан эсвэл дээд ба доод хана дээрх y ард талын ирмэгээс (элементийн +u тал).
- **Суваг** нуруугаараа хэвтэж, ирмэгүүд дээшээ харсан, стандартын зурагт байгаачлан. Тиймээс ир дээрх y дээд тавцангийн гадна талаас доош явна; дээд тавцан гадаргуу u, доод тавцан гадаргуу o; тавцан дээрх y ирийн ард талаас ирмэг рүү явна.
- **Өнцөгт:** хөл бүр дээрх y булангаас.
- **Ялтас:** y ялтасны −u ирмэгээс.

Огтлохоос өмнө машины програм сувгийн гадаргууг хэрхэн уншихыг шалгана уу: зарим програм сувгийг эсрэгээр эргүүлдэг.

## Бичигдэхгүй зүйлс

Ирмэгийн налуу, дотоод контур, тэмдэглэгээ (SI), тэгш өнцгөөс бусад хөрөөний өнцөг, урт нүх, дугуй хоолойн нүх (DetailCraft-д байхгүй), мөн өнцөгт ба дугуй хоолой дээрх огтлолт.
