Энэ тусламжид товчлуурыг хэрхэн бичсэнийг харна уу: [Гар, хулгана ба тачпад](common:keys). Mac дээр {{key:Mod}} нь Command товч; бусад дээр Ctrl.

## Багаж

Эдгээр нь курсор текст эсвэл тооны талбарт биш байхад ажиллана.

| Товчлуур | Юу хийдэг |
|---|---|
| {{key:V}} | {{ui:Сонгох}} |
| {{key:B}} | {{ui:Дам нуруу}} |
| {{key:C}} | {{ui:Багана}} |
| {{key:R}} | {{ui:Диагональ}} |
| {{key:P}} | {{ui:Ялтас}} |
| {{key:F}} | {{ui:Суурь}} |
| {{key:S}} | {{ui:Шат}} |
| {{key:M}} | Сонгосныг хоёр торын огтлолцлоор нь зөөнө ([Цонхоор сонгох, зөөх, эргүүлэх, толин тусгал, олныг өөрчлөх](topic:select-and-change)) |
| {{key:Esc}} | Чирж буй сонголтын цонхыг буулгах эсвэл чирсэн эд ангиудыг буцаах; зөөлтийг, дам нуруу, диагональ эсвэл ялтасны эхний цэгийг, эсвэл буулгалтыг цуцлах; дахин дарвал {{ui:Сонгох}} руу буцна; {{ui:Сонгох}} горимд сонголтыг арилгана. Нээлттэй {{ui:Нэмэлт}} цэс байвал түүнийг хаана |

## Хуулах ба буулгах

Эдгээр нь курсор текст эсвэл тооны талбарт биш байхад ажиллана (тэнд текстээ хуулах, буулгах, сонгох нь ердийнх шиг). Буулгах, огтлох, хуулбарлах, устгах бүр нэг буцаах алхам. Дэлгэрэнгүй: [Хуулах, буулгах ба хуулбарлах](topic:copy-paste).

| Товчлуур | Юу хийдэг |
|---|---|
| {{key:Mod+C}} | {{ui:Хуулах}}: сонгосон эд анги ба суурийг (нүх, огтлолт, холболттой нь хамт) |
| {{key:Mod+X}} | {{ui:Огтлох}}: сонголтыг хуулж, дараа нь устгана |
| {{key:Mod+V}} | {{ui:Буулгах}}: хуулбар заагчийг дагана; түүнийг тор огтлолцол дээр дарж байрлуулна |
| {{key:Mod+Shift+V}} | {{ui:Байранд нь буулгах}}: хуулсан координатад |
| {{key:Mod+D}} | {{ui:Хуулбарлах}}: тэр даруй хуулбар, [DetailCraft тохиргоо](topic:settings)-д заасан офсетоор зөөгдсөн |
| {{key:Mod+A}} | {{ui:Бүгдийг сонгох}}: бүх эд анги, холболт, суурь |
| {{key:Esc}} | {{ui:Юуг ч сонгохгүй}} |

Хэрэв хуудсан дээр (жишээ нь тайлангийн хүснэгтэд) текст сонгосон бөгөөд загварт юу ч сонгоогүй бол {{key:Mod+C}} ердийнхөөрөө текстийг хуулна.

{{ui:Шинэ}}, {{ui:Жишээ}} ба экспортод товчлуур байхгүй; хэрэгслийн самбарыг ашиглана уу.

Диалог (урьдчилан харах зураг эсвэл асуулт) нээлттэй үед эдгээр товчлуур юу ч хийхгүй.

## Талбар ба самбар

| Товчлуур | Юу хийдэг |
|---|---|
| {{key:Enter}} эсвэл {{key:Tab}} | Бичсэн утгыг хэрэглэнэ (өөрчлөлт бүр нэг буцаах алхам) |
| {{key:Enter}} {{ui:Тор}}, {{ui:Түвшин}}, {{ui:Өөрчилсөн профиль}}, нүх эсвэл огтлолтын талбарт | Тухайн маягтын товчийг сонгохтой адил |
| {{key:Left}} {{key:Right}} | Таб фокустай үед {{ui:Асуудлууд}}, {{ui:Материалын жагсаалт}} ба {{ui:Гулзайлтын хуваарь}} табуудын хооронд шилжүүлнэ |
| {{key:Esc}} | Урьдчилан харах зураг эсвэл асуултын диалогийг хаана ({{ui:Цуцлах}}-тай адил) |

## Хулгана

| Үйлдэл | 3D-д | План ба фасадад |
|---|---|---|
| Дарах | Эд анги сонгох, эсвэл байрлуулах хэрэгсэл асаалттай үед хамгийн ойрын огтлолцолд байрлуулах (буулгах үед ч тэнд) | Адилхан |
| {{key:Shift}}, {{key:Ctrl}} эсвэл {{key:Mod}} дарж дарах | Эд ангийг сонголтод нэмэх эсвэл хасах | Адилхан |
| Сонгосон эд ангийг дарж чирэх | Сонголтыг түвшний дагуу зөөнө; {{key:Mod}} дарсан үед дээш доош | Сонголтыг зөөнө (фасадад: дагуу болон дээш доош) |
| Зүүн товчоор чирэх | Загварыг эргүүлнэ | {{ui:Сонгох}} горимд: сонголтын цонх (баруун тийш: бүрэн дотор; зүүн тийш: хүрсэн). Байрлуулж байхад: харагдац шилжүүлэх |
| {{key:Shift}} дарж зүүн товчоор чирэх | {{ui:Сонгох}} горимд: сонголтын цонх, сонголтод нэмэгдэнэ. Байрлуулж байхад: харагдац шилжүүлэх | {{ui:Сонгох}} горимд: сонголтын цонх, сонголтод нэмэгдэнэ |
| {{key:Ctrl}} эсвэл {{key:Mod}} дарж зүүн товчоор чирэх | Харагдац шилжүүлэх | Юу ч биш |
| Баруун товчоор чирэх | Харагдац шилжүүлэх | Харагдац шилжүүлэх |
| Дугуй | Харагдацын голд чиглүүлэн томруулах | Томруулах |
| Дунд товчоор чирэх | Томруулах | {{ui:Сонгох}} горимд: харагдац шилжүүлэх. Бусад тохиолдолд томруулах |
| `.detailcraft.json` файлыг аппад чирж оруулах | Нээх | Нээх |

Хулганы товчийг дарснаас хойш суллах хүртлээ заагч ойролцоогоор 5 пикселээс бага хөдөлсөн бол дарсан гэж тооцно; илүү их хөдөлбөл чирэлт.

## Тачпад

| Үйлдэл | Юу хийдэг |
|---|---|
| Хоёр хурууг дээш доош шудах, эсвэл хумих | Томруулах |
| Дарж чирэх | Эргүүлэх (3D) эсвэл харагдац шилжүүлэх (План, фасад) |
| {{key:Shift}} дарж, дарж чирэх | 3D-д харагдац шилжүүлэх |
| Хоёр хуруугаар товших | Баруун товч (харагдацад цэс байхгүй) |

## Мэдрэгч

Таблет эсвэл мэдрэгч дэлгэц дээр:

| Үйлдэл | Юу хийдэг |
|---|---|
| Товших | Эд анги сонгох, эсвэл байрлуулах хэрэгсэл асаалттай үед хамгийн ойрын тор огтлолцолд байрлуулах (хурууны өргөнийх ойролцоо зайд товших нь тоологдоно) |
| Эд ангийг удаан дарах | Сонголтод нэмэх эсвэл хасах (хулганаар {{key:Shift}}+дарахтай адил) |
| Сонгосон эд ангийг нэг хуруугаар дарж чирэх | Сонголтыг зөөнө, тор огтлолцол дээр наалдуулан |
| Бусад газар нэг хуруу | Загварыг эргүүлнэ (3D) эсвэл харагдац шилжүүлнэ (План, фасад) |
| Хоёр хуруу | Хумих ба тэлэх замаар томруулна; хамт хөдөлгөвөл харагдац шилжинэ |

Зөвхөн мэдрэгч дэлгэц дээр товчлуур, жагсаалт ба талбарууд илүү том байна. Сонголтын цонх хулгана шаарддаг; хурууны хувьд товших ба удаан дарах.

## Хөтөчийн эзэмшдэг товчлолууд

Зарим товчлол хөтчийнх бөгөөд ямар ч хуудас ашиглаж чадахгүй, жишээ нь {{key:Mod+W}} (табыг хаах), {{key:Mod+T}} (шинэ таб) ба {{key:Mod+N}} (шинэ цонх). Хэрэв {{key:Mod+Y}} дахин хийхийн оронд хөтчийн түүхийг нээвэл {{key:Mod+Shift+Z}}-ийг ашиглана уу.

Товчлол DetailCraft-д зөвхөн хуудсанд гар байгаа үед хүрнэ. Хэрэв товч юу ч хийхгүй, эсвэл хөтөч өөрөө ажиллавал DetailCraft цонхны хоосон хэсгийг эхлээд дарна уу (жишээ нь хаягийн мөрөнд бичсэний дараа).

## Зөөх хаана байдаг вэ

Зөөх гэсэн команд байхгүй: эд ангийг сонгоод түвшний дагуу чирнэ үү ({{key:Mod}} дарж дээш доош чирнэ), эсвэл {{ui:Шинж чанар}} дотор {{ui:Эхлэл}} ба {{ui:Төгсгөл}}-ийг засна уу.
