## Та юу сурах вэ

AI туслах (эсвэл таны бичсэн скрипт) DetailCraft-тай хэрхэн ажиллахыг зөвшөөрөх, мөн түүнд юуг хөндөж болохыг хэрхэн шийдэхийг сурна.

DetailCraft-д **өөрийн AI байхгүй** бөгөөд ямар ч зүйлийг хаашаа ч илгээдэггүй. Туслахаа та өөрөө авчирна: Model Context Protocol (MCP)-ээр ярьдаг ямар ч программ. DetailCraft түүнд зөвхөн хэрэгслүүдийг өгнө, та аль нь вэ гэдгийг сонгоно.

## Асаах

1. {{ui:Тохиргоо}} (аппын баарын араа эсвэл {{key:Mod+,}}) нээгээд **{{ui:DetailCraft}}** таб руу орно.
2. **{{ui:Туслахууд}}** доор **AI туслах болон скриптүүдэд DetailCraft-г ашиглахыг зөвшөөрөх** гэсэн сонголтыг тэмдэглэнэ. Та тэмдэглэх хүртэл унтраалттай байна.
3. Түүнд юу хийхийг зөвшөөрөхөө сонгоно: **Унших** анхдагчаар тэмдэглэгдсэн; **Засах**, **Хадгалах** эсвэл **Экспорт**-ыг зөвхөн хэрэгтэй үед тэмдэглэнэ.

Таны тэмдэглээгүй зөвшөөрлийн хүрээнээс гадуурх хэрэгслүүдийг туслахад санал болгохгүй; туслах тэдгээрийг хүсвэл DetailCraft татгалзаж, үйл ажиллагааны бүртгэлд бичнэ. Унтраалтыг унтраавал бүх холболт нэг дор тасарна.

## Туслахаа холбох

Туслахууд таны компьютер дээрх **CadCraft Studio**-оор холбогдоно: Studio зөвхөн энэ компьютер хүрч чадах жижиг сервер ажиллуулдаг бөгөөд эхлэх бүрт үүсгэдэг токеноор хамгаалагдсан. Studio дотор {{ui:Туслахыг холбох}}-ийг сонгоод хаяг ба токеныг туслахдаа хуулна (Studio яг юу буулгахыг харуулна). Токеныг хэзээ ч бусадтай хуваалцахгүй.

:::note
Хөтөчийн таб туслахад холболт нээж чадахгүй: хөтчийн аппуудад унтраалт нөлөөгүй бөгөөд таны компьютер дээрх CadCraft Studio-г ашиглах хүртэл.
:::

## Та хяналтаа хадгална

- **Өөрчлөлт бүр нэг буцаах алхам** бөгөөд туслахынх гэж тэмдэглэгдэнэ (жишээлбэл "Туслах: дам нэмэх", "Туслах: нэмэлт хавтан нэмэх"). {{key:Mod+Z}} нь туслахын сүүлийн өөрчлөлтийг бүхэлд нь буцаана. Туслахын өөрийн `undo` нь зөвхөн өөрийн алхмуудыг буцаана, таных огт биш, тодорхой хүсэхгүй бол.
- **Тэр таныг хүлээнэ.** Та элемент байрлуулж, хөдөлгөж эсвэл буулгаж байх үед DetailCraft туслахын өөрчлөлтийг татгалзаж, дахин оролдохыг хэлнэ.
- **Холбогдсоныг мэдэх.** Аппын баарын товч холбогдсон үед туслахын нэрийг харуулна; дарж, түүнд юу хийхийг зөвшөөрснийг харах эсвэл **Салгах**-ыг дарна.
- **Үйл ажиллагаа.** {{ui:Тохиргоо}} › {{ui:DetailCraft}} › {{ui:Туслахууд}} › {{ui:Үйл ажиллагаа}} нь дуудлага бүрийг жагсаана: хэзээ, ямар хэрэгсэл, хийгдсэн эсвэл татгалзсан. {{ui:Бүртгэлийг хадгалах}} нь хуулбарыг хадгална.

## Туслах юу хүсч болох вэ

Бүх урт нь миллиметр, цэгүүд `[x, y, z]` (z дээшээ), загварт байгаагаар.

| Хэрэгсэл | Зөвшөөрөл | Юу хийдэг вэ |
|---|---|---|
| `app_info`, `model_describe` | Унших | Нээлттэй загвар: тор, түвшин, үе шат, төрлөөр ба профайлаар элементүүд, холболт, суурь, шат, элемент, ган жин, асуудлууд |
| `parts_list` | Унших | Элементийн тэмдэг, профайл, материал, тайрах урт, тоо, жин, үе шат ба угсралтын тэмдэг; төрлөөр, профайлаар, тэмдгээр эсвэл үе шатаар |
| `problems_list` | Унших | {{ui:Асуудлууд}} табын жагсаалт, тус бүрийн тухай |
| `clash_check` | Унших | [мөргөлдөөний шалгалт](topic:clash-check), түүний хүлцэл ба үе шатууд |
| `selection_get` | Унших | Таны сонгосон зүйлс |
| `selection_set` | Засах | Элемент, холболт, суурь эсвэл шатыг (id эсвэл тэмдгээр) танд харуулахын тулд сонгоно; юу ч өөрчлөхгүй |
| `member_add` | Засах | Хоёр цэгийн хооронд дам, багана, диагональ эсвэл ялтас |
| `connection_add` | Засах | Өгөгдсөн элементүүд уулзах газарт төгсгөлийн ялтас, хажуугийн таб, суурийн ялтас, залгалт эсвэл хавирга, {{ui:Холбох}} товчнуудын адил |
| `undo` | Засах | Туслахын сүүлийн алхмуудыг буцаана |
| `model_save` | Хадгалах | DetailCraft-ийн өөрийн хадгалалт |
| `model_export` | Экспорт | IFC, NC файлууд, BOM, гулзайлтын хуваарь, KISS файл эсвэл тайрах жагсаалт, {{ui:Гаралт}} товчнуудын адил |
| `usd_export` | Экспорт | Ган загварыг USD-ээр (.usda, .usdc эсвэл .usdz), {{ui:Гаралт}} › {{ui:USD}}-ийн адил бичнэ (үзэх: [Ган загварыг USD-ээр экспортлох](topic:usd)); Studio дотор таны зөвшөөрсөн хавтас руу файл бичиж чадна |

## Юу ажиллахгүй бол

- **Туслах DetailCraft хэрэгслүүдийг харахгүй байна:** энэ цонхонд унтраалт асаалттай эсэхийг, мөн цонх Studio-д нээлттэй эсэхийг шалгана уу.
- **"засварлах зөвшөөрөл шаардлагатай"** (эсвэл хадгалах, экспорт): {{ui:Туслахууд}} доор тэмдэглээд дахин асуу.
- **"Хүн дам байрлуулж байна":** хийж байгаагаа дуусга (эсвэл {{key:Esc}} дар), дараа нь туслахыг дахин оролдуул.
- **"401" эсвэл "token" алдаа:** токен өөрчлөгдсөн (Studio дахин эхэлсэн эсвэл {{ui:Шинэ токен}}). Шинэ токеныг туслахын тохиргоонд хуул.
