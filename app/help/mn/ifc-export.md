IFC экспорт нь бүх загварыг нэг IFC4 файл болгон бичнэ. Үүнийг BIM програм болон IFC үзэгч нээж чадна.

## Экспорт

1. {{ui:Гаралт}} бүлгийн {{ui:IFC}}-г сонгоно.
2. Хөтөч `<name>.ifc`-г татна. Төлвийн мөрөнд юу орсныг харуулна, жишээлбэл «IFC4 экспортлогдлоо: 25 эд анги, 88 бэхэлгээ, 7 суурь, 132 арматур.»

Загварт эд анги, суурь эсвэл арматур байхгүй бол төлвийн мөрөнд «Экспортлох зүйл алга.» гэж гарна.

## Файлд юу байдаг вэ

| DetailCraft дотор | IFC файл дотор |
|---|---|
| Давхар бүр | Барилгын давхар (IfcBuildingStorey), нэг төсөл, талбай ба барилгын доор |
| Тор | Тэнхлэг ба шошготой IfcGrid |
| Багана, дам нуруу, тулгуур | IfcColumn, IfcBeam, IfcMember (тулгуур), бүгд стандарт профайлын хэлбэрийн экструзэн бодит хэмжээстэйгээр |
| Ялтас, төгсгөлийн ялтас, суурийн ялтас | IfcPlate |
| Нүх ба тайралт | Эд анги дээрээс огтлогдсон нээлт (IfcOpeningElement) |
| Элемент ба түүний гагнасан ялтсууд | Угсралт (IfcElementAssembly), угсралтын тэмдгээр шошгологдсон |
| Боолт ба анкерийн боолт | Диаметр ба уртын IfcMechanicalFastener |
| Суурь | IfcFooting (үндсэн суурь), бетоны текстыг материал болгож |
| Арматур бүр | IfcReinforcingBar, арматурын тэмдэг, диаметр, талбай ба урттай, бодит төвийн шугамын дагуу, уян хэсгүүдэд бодит нуман хэлбэртэй |

Эд анги бүрийн шошго нь түүний эд ангийн тэмдэг байна. Элемент бүр "DetailCraft" шинж чанарын багцтай байх бөгөөд тэмдэг, профайл, жинтэй. Элемент бүр түүний хамгийн доод цэгээс дээш биш хамгийн дээд давхарт байрлана. Материал зэрэглэлээр бүлэглэгдэнэ.

## Дахин экспортлоход тогтвортой ID

Элемент бүрийн IFC ID (GlobalId) нь загварын нэр ба загвар дахь элементийн өөрийн ID-аас тооцоологдоно. Ижил загварыг хоёр дахин экспортлоход ID тань таарна, тиймээс хувилбарыг харьцуулдаг програм юу өөрчлөгдсөнийг ялгаж чадна.

:::warning
Загварын нэрийг өөрчлөх нь бүх ID-г өөрчилнө. Төслийн хувилбар хооронд загварын нэрийг адилхан байлгана уу.
:::

## Шалгах

DetailCraft-ийн IFC файлыг туршилтын багцад хамаарах бие даасан IFC уншигч буцааж уншина. Програмууд IFC-г янз бүрийн байдлаар уншдаг тул, найдахаасаа өмнө баг чинь ашигладаг програмдаа файлыг нээгээрэй. CadCraft-ийн BimCraft апп IFC файлыг бас нээдэг.

## Одоогоор биш

- Холболт, суурь, арматурыг IFC файлаас авчрахгүй. {{ui:IFC импортлох}} нь дам нуруу, багана, элемент, ялтас, тор, давхар, нүх, тайралт ба боолтыг авч, үлдээсэн зүйлсийн жагсаалтыг гаргана.
- Шинжилгээний эсвэл бүтцийн шинжилгээний мэдээлэл.
- IFC4-ийн лавлах харагдацаас бусад зүйл.

## Импортлох

{{ui:Файл}} бүлгийн {{ui:IFC импортлох}} (эсвэл `.ifc` файлыг харагдац дээр чирэх) нь IFC2X3 эсвэл IFC4 файлаас шинэ загвар үүсгэнэ:

- **Дам нуруу, багана, элемент (тулгуур) ба ялтас** нь DetailCraft-ийн мэддэг нэг экструдэн профайлтай бол каталогт тохируулагдаж эсвэл захиалгат профайл болгон хадгалагдана; **тор** ба **давхар** нь файлын тор ба давхраас.
- **Нүх:** нэг хэсгийн нэг гадаргуутай перпендикуляр оруулсан дугуй нээлт бүр (IfcOpeningElement, оруулсан хэсэгт): I хэлбэрийн эсвэл сувгийн ханыг эсвэл тавцан, хоолойн хана, ялтас, өнцгийн талууд. Хоолойн хоёр ханыг дамжсан нүх нэг удаа орно.
- **Тайралт:** I хэлбэр эсвэл сувгийн бүтэн өргөнийг нэг төгсгөлөөс авах тэгш өнцөгт нээлт, дээрээс доош эсвэл доороос дээш.
- **Боолт:** IfcMechanicalFastener эсвэл IfcFastener бүр, диаметр, урт, зэрэглэл, төрөл (боолт эсвэл анкерийн боолт)-тэйгээр, **бэхлэгдээгүй боолт** хэлбэрээр. Бэхлэгдээгүй боолт харагдац, материалын жагсаалт, IFC экспортод харагдаж, элементийг зөөхөд өөрийн байрандаа үлдэнэ. {{ui:Шинж чанар}} самбар, юу ч сонгоогүй үед тэдгээрийг тоолж, холболт нэмэхэд устгах {{ui:Бэхлэгдээгүй боолтуудыг устгах}} товчтой.

Тайлан бусад бүх зүйлийг ангиллаар нь жагсааж, орхигдсон шалтгаантай: хана ба хавтан, суурь ба арматур, урт нүх, дугуй хоолой дахь нүх, холболтууд (IFC файлд тэдний ялтас ба боолт байдаг, тэдгээрийг бий болгосон дүрэм биш).
