Тугмачаҳо дар ин роҳнамо чунин навишта мешаванд: [Тугмачаҳо, мушукҳо ва тачпадҳо](common:keys). Дар Mac {{key:Mod}} тугмаи Command аст; дар ҷои дигар Ctrl.

Инҳо вақте кор мекунанд, ки курсор дар майдони матн ё рақам набошад.

| {{key:B}} | {{ui:Балка}} |

| {{key:Esc}} | Тирезаи интихобро, ки кашида мешавад, раҳо кунед ё қисмҳои кашидашударо ба ҷои аввал баргардонед; кӯчонидан, нуқтаи аввали балка, банд ё лавҳа, ё гузоштанро бекор кунед; бори дуюм пахш кунед, то ба {{ui:Интихоб кардан}} баргардед; дар {{ui:Интихоб кардан}} интихобро тоза кунед. | Тугма | Амал |

## Нусха бардоштан ва гузоштан

Инҳо вақте кор мекунанд, ки курсор дар майдони матн ё рақам набошад (дар он ҷо матни шуморо мисли маъмул нусха бардошта, гузошта ва интихоб мекунанд). Ҳар гузоштан, буридан, нусхабардорӣ ё нест кардан як қадами Баргардондан аст. Бештар: [Нусха бардоштан, гузоштан ва нусхабардорӣ](topic:copy-paste).

| Тугма | Амал |
|---|---|
| {{key:Mod+C}} | {{ui:Нусха бардоштан}} узвҳо ва таҳкурсиҳои интихобшуда (бо сӯрохиҳо, бурришҳо ва пайвастҳои онҳо) |
| {{key:Mod+X}} | {{ui:Буридан}}: интихобро нусха бардошта, сипас нест кардан |
| {{key:Mod+V}} | {{ui:Гузоштан}}: нусха ба ишорагар пайравӣ мекунад; барои ҷойгир кардани он нуқтаи тӯрро клик кунед |
| {{key:Mod+Shift+V}} | {{ui:Гузоштан дар ҳамон ҷо}}: дар ҳамон координатҳое, ки аз онҷо нусха бардошта шуд |
| {{key:Mod+D}} | {{ui:Нусхабардорӣ}}: фавран нусха, ки бо ҷойивазкунии дар [Танзимоти DetailCraft](topic:settings) кӯчонида мешавад |
| {{key:Mod+A}} | {{ui:Ҳамаро интихоб кардан}}: ҳар узв, пайваст ва таҳкурсӣ |
| {{key:Esc}} | {{ui:Интихобро бекор кардан}} |

Агар дар саҳифа матнро интихоб карда бошед (масалан, дар ҷадвали ҳисобот) ва дар модел ҳеҷ чиз набошад, {{key:Mod+C}} мисли маъмул матнро нусха мебардорад.

{{ui:Нав}}, {{ui:Намуна}} ва содиротҳо тугмачаи алоҳида надоранд; аз панели абзор истифода баред.

Ҳеҷ яке аз ин тугмачаҳо вақте кор намекунад, ки муколама (пешнамоиши нақшаи истеҳсолӣ ё савол) кушода аст.

| {{key:Esc}} | Пешнамоиши нақшаи истеҳсолӣ ё муколамаи саволро пӯшед (мисли {{ui:Бекор кардан}}) |

| Амал | Дар 3D | Дар План ва Фасад |
|---|---|---|
| Клик | Интихоби як қисм ё ҷойгир кардан дар наздиктарин нуқта, вақте ки абзори ҷойгиркунӣ фаъол аст (ё ҳангоми гузоштан дар ҳамон ҷо гузоштан) | Ҳамин тавр |
| {{key:Shift}}, {{key:Ctrl}} ё {{key:Mod}} ва клик | Ба интихоб илова кардани қисм ё хориҷ кардани он | Ҳамин тавр |
| Ба қисми интихобшуда пахш кунед ва кашед | Интихобро дар сатҳ кӯчонидан; бо нигоҳ доштани {{key:Mod}}, боло ва поён | Интихобро кӯчонидан (дар фасад: дар тӯли он ва боло ва поён) |
| Бо тугмаи чап кашидан | Моделро гардондан | Бо {{ui:Интихоб кардан}}: тирезаи интихоб (ба тарафи рост: пурра дарун; ба тарафи чап: тамос). Ҳангоми ҷойгиркунӣ: ҷойивазкунӣ |
| {{key:Shift}} ва кашидан бо тугмаи чап | Бо {{ui:Интихоб кардан}}: тирезаи интихоб, ба интихоб илова мешавад. Ҳангоми ҷойгиркунӣ: ҷойивазкунӣ | Бо {{ui:Интихоб кардан}}: тирезаи интихоб, ба интихоб илова мешавад |
| {{key:Ctrl}} ё {{key:Mod}} ва кашидан бо тугмаи чап | Ҷойивазкунӣ | Ҳеҷ |
| Кашидан бо тугмаи рост | Ҷойивазкунӣ | Ҷойивазкунӣ |
| Чарх | Калонкунӣ ба сӯи маркази намуд | Калонкунӣ |
| Кашидан бо тугмаи миёна | Калонкунӣ | Бо {{ui:Интихоб кардан}}: ҷойивазкунӣ. Вагарна калонкунӣ |

Клик танҳо он вақт ҳисоб мешавад, ки ишорагар байни пахш ва раҳо кардан тақрибан 5 пиксел ҳаракат кунад; ҳаракати дарозтар кашидан аст.

## Тачпад

| Амал | Таъсир |
|---|---|
| Лағжонидани ду ангушт боло ё поён, ё печонидан | Калонкунӣ |
| Пахш ва кашидан | Гардондан (3D) ё ҷойивазкунӣ (План ва Фасад) |
| {{key:Shift}} ва пахш ва кашидан | Ҷойивазкунӣ дар 3D |
| Клики ду ангушт | Клики рост (дар намуд меню нест) |

## Сенсорӣ

Дар планшет ё экрани сенсорӣ:

| Амал | Таъсир |
|---|---|
| Тап | Интихоби як қисм ё ҷойгир кардан дар наздиктарин нуқтаи тӯр, вақте ки абзори ҷойгиркунӣ фаъол аст (тап дар масофаи тақрибан як ангушт ҳисоб мешавад) |
| Пахши дароз ба қисм | Ба интихоб илова кардан ё хориҷ кардан (ҳамон коре, ки {{key:Shift}}+клик бо мушук мекунад) |
| Як ангушт ба қисми интихобшуда, сипас кашидан | Интихобро кӯчонидан, ба нуқтаҳои тӯр часпондан |
| Як ангушт дар ҷои дигар | Моделро гардондан (3D) ё ҷойивазкунӣ (План ва Фасад) |
| Ду ангушт | Печонидан барои калонкунӣ, якҷоя ҳаракат кардан барои ҷойивазкунӣ |

Тугмаҳо, рӯйхатҳо ва майдонҳо вақте калонтаранд, ки экран танҳо сенсорӣ бошад. Тирезаҳои интихоб мушукро талаб мекунанд; бо ангуштҳо тап ва пахши дарозро истифода баред.

## Тугмачаҳое, ки браузер нигоҳ медорад

Баъзе сареъкунандаҳо ба браузер тааллуқ доранд ва ҳеҷ саҳифа онҳоро истифода бурда наметавонад, масалан {{key:Mod+W}} (пӯшидани варақа), {{key:Mod+T}} (варақаи нав) ва {{key:Mod+N}} (тирезаи нав). Агар {{key:Mod+Y}} ба ҷои такрор кардан таърихи браузерро кушояд, {{key:Mod+Shift+Z}}-ро истифода баред.

Сареъкунандаҳо фақат вақте ба DetailCraft мерасанд, ки саҳифа клавиатураро дошта бошад. Агар тугма кор накунад ё браузер онро иҷро кунад, аввал ба қисми холии тирезаи DetailCraft клик кунед (масалан, пас аз навиштан дар сатри нишонӣ).

## Кӯчонидан дар куҷост

Фармони Кӯчонидан нест: қисмро интихоб кунед ва дар тамоми сатҳ кашед (бо нигоҳ доштани {{key:Mod}} боло ва поён кашед), ё {{ui:Оғоз}} ва {{ui:Охир}}-и онро дар {{ui:Хусусиятҳо}} таҳрир кунед.
