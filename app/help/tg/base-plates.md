Пайвасти лавҳаи пойгоҳӣ лавҳаро дар зери сутун мегузорад, сутунро ба андозаи ғафсии лавҳа кӯтоҳ мекунад, ҳардуро бо ҳам мепайвандад ва чаҳор милҳои анкериро тавассути сӯрохиҳои лавҳа илова мекунад.

:::warning
Андозаҳо қиматҳои ибтидоӣ мебошанд, на тарҳ. DetailCraft бардоштани борро, мустаҳкамии милҳо ва чуқурии дар бетон ворид шуданро санҷида наметавонад.
:::

## Илова кардани лавҳаи пойгоҳӣ

1. Дар ҳолати {{ui:Select}} ({{key:V}}) ро фаъол кунед ва ба сутун клик кунед. Он бояд амудӣ бошад.
2. Интихоб кунед: {{ui:Base plate}} дар гурӯҳи {{ui:Connect}} ё {{ui:Add base plate}} дар панели {{ui:Properties}}.
3. Сатри ҳолат мегӯяд: «Лавҳаи пойгоҳӣ бо чаҳор мили анкерӣ илова шуд.» Пайвасти нав интихоб шудааст.

Сутун метавонад танҳо як лавҳаи пойгоҳӣ дошта бошад. Агар он аллакай дошта бошад, сатри ҳолат мегӯяд: «Ин сутун аллакай лавҳаи пойгоҳӣ дорад.»

## Тағйир додан

Лавҳаи пойгоҳиро интихоб кунед (ба лавҳа ё мил клик кунед). Дар зери {{ui:Plate, bolts and weld (mm)}}:

| Параметр | Пешфарз | Чӣ кор мекунад |
|---|---|---|
| Ғафсии лавҳа | 25 | Сутун ба ҳамин андоза кӯтоҳ мешавад |
| Дарозии лавҳа | 450 | Тавассути чуқурии сутун |
| Паҳнои лавҳа | 400 | Аз рӯи сутун |
| Диаметри мил | 20 | Андозаи милҳои анкерӣ |
| Диаметри сурох | 33 | Сурох дар лавҳа |
| Дараҷаи болт | F1554 Gr 36 | Дараҷаи мил, ҳамчун матн |
| Фосилаи милҳо (тавассути чуқурӣ) | 350 | Байни марказҳои милҳо, тавассути дарозии лавҳа |
| Фосилаи милҳо (аз рӯи паҳнӣ) | 300 | Байни марказҳои милҳо, аз рӯи паҳнӣ |
| Баромадани мил аз болои лавҳа | 100 | Аз болои лавҳа то болои мил |
| Ворид шудани мил ба зери лавҳа | 450 | Аз зери лавҳа то дохили бетон |
| Андозаи пайванди канорӣ | 8 | Дар ҳамаи атрофи пойгоҳи сутун |
| Маводи лавҳа | A36 | Матн |
| Фосилаи грут | 0 | Фосила байни болои бетон ва зери лавҳа |
| Қабурғаҳои сахткунанда | Ҳеҷ | Ҳеҷ, 2 (дар хати тори миёна) ё 4 (ҳамчунин амудан ба он); ниг. дар поён |
| Ғафсӣ, баландии қабурға | 12, 150 | |
| Чуқурии шпонкаи бурришӣ | 0 | То куҷо шпонка аз зери лавҳа фуромадааст; 0 = шпонка нест |
| Ғафсӣ, паҳнои шпонкаи бурришӣ | 25, 150 | |
| Шайбаҳои лавҳа | Ҳеҷ | Дар ҳар мил ё ҳеҷ |
| Андоза, ғафсии шайба | 0, 0 | 0 = ҳадди ақали аз AISC Design Guide 1 барои мил |

Дарозии мил = ворид шудан + фосилаи грут + ғафсии лавҳа + баромадан. Бо пешфарзҳо ин 575 mm аст.

## Тафсилоти пойгоҳ: грут, қабурғаҳо, шпонка, шайбаҳо

Ҳар чор дар лавҳаи пойгоҳии нав хомӯш ҳастанд, инчунин дар лавҳаҳои пойгоҳӣ аз моделҳое, ки пеш аз DetailCraft 0.4 сохта шудаанд.

- **Фосилаи грут.** Лавҳа ҳамин қадар аз болои бетон баландтар қарор мегирад ва милҳо ба ҳамин андоза дарозтар мешаванд. AISC Design Guide 1 (2.10) барои фарши тайёр 1 in. ва барои таҳкурсӣ ё сутуни бетонӣ 1½ то 2 in. пешниҳод мекунад; барои лавҳаҳои калон ва лавҳаҳо бо шпонкаи бурришӣ бештар.
- **Қабурғаҳои сахткунанда.** Лавҳаҳои амудие, ки ба сутун ва лавҳа пайваст шудаанд, аз рӯи сутун то канори лавҳа, ҳамчун росткунҷаҳо (ҳоло фаска ё конусшавӣ нест). **2** дар хати тори миёна, берун аз ҳар фланец меистанд; **4** ҳамчунин ду қабурғаро амудан ба тор илова мекунанд, байни фланецҳо, то канорҳои лавҳа. Дар сутуни қубурӣ онҳо дар миёнаи ҳар рӯ меистанд. Ҳар қабурға ба ҳар ду тараф ба сутун ва лавҳа пайваст мешавад.
- **Шпонкаи бурришӣ.** Лавҳае, ки дар ҳамаи атроф дар зери лавҳаи пойгоҳӣ, дар хати чуқурии сутун ва дар марказ пайваст мешавад. DetailCraft огоҳӣ медиҳад, агар он аз фосилаи грут чуқуртар набошад. Он ҷойро дар таҳкурсӣ намебурад; [санҷиши бархӯрд](topic:clash-check) шпонка ва таҳкурсиро аз ҳамин сабаб берун мегузорад.
- **Шайбаҳои лавҳа.** Шайбаи квадратии лавҳа дар ҳар мил, дар болои лавҳаи пойгоҳӣ меистад ва дар таркиби сутун ҳамчун озод рӯйхат мешавад (бо сутун интиқол мешавад, пайваст нест: Design Guide 1, 2.6). Бо андоза ва ғафсии 0, DetailCraft шайбаи ҳадди ақалро аз AISC Design Guide 1, нашри 2, Ҷадвали 2.3 барои мил мегирад; мили метрӣ андозаи инчии баландтарро мегирад (мили M20 сатри 7/8 in. -ро мегирад: 2½ in. × 5/16 in.). Панели хусусиятҳо андозаи истифодашударо нишон медиҳад. Сӯрохи шайба диаметри мил + 1/16 in. аст: ин интихоби DetailCraft аст, ҷадвал онро намедиҳад. DetailCraft огоҳӣ медиҳад, вақте ки милҳо барои шайба ва гайка кофӣ баромада наметавонанд (баромадан камтар аз ғафсии шайба + диаметри мил).

Design Guide 1, Ҷадвали 2.3, инчунин сӯрохи милро дар лавҳа тавсия медиҳад: 1-5/16 in. барои мили ¾ in., 1-9/16 in. барои ⅞ in., 1-13/16 in. барои 1 in. DetailCraft андозаи сӯрохи шуморо тағйир намедиҳад.

Инчунин огоҳиҳо пайдо мешаванд, вақте ки сӯрохҳои мил то канори лавҳа аз 1.2 × диаметри сӯрох наздиктаранд, вақте ки милҳо дар дохили хатти сутун меафтанд ё вақте ки лавҳа аз сутун хурдтар аст.

## Нусха бардоштан ба сутунҳои монанд

1. Лавҳаи пойгоҳиро интихоб кунед.
2. Интихоб кунед: {{ui:Ба монанд татбиқ кардан (n)}}, ё {{ui:Similar}} дар менюи {{ui:More}} гурӯҳи {{ui:Connect}}.
3. Ҳар сутуни амудӣ бо ҳамон профил, ки лавҳаи пойгоҳӣ надорад ва бар сутуни дигар истода нест, нусха мегирад.

## Лавҳаҳои пойгоҳӣ ва таҳкурсиҳо

Лавҳаи пойгоҳӣ ба таҳкурсӣ ниёз надорад ва таҳкурсӣ аз лавҳаи болои худ хабар надорад: милҳои анкерӣ ба арматураи таҳкурсӣ баста намешаванд. Таҳкурсиҳоро бо {{ui:Footing}} гузоред; ниг. [Гузоштани таҳкурсӣ бо арматура](topic:footings-and-rebar).
