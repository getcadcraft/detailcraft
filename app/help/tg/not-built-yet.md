DetailCraft сохтани аввал аст. Ин саҳифа рӯйхат мекунад, ки он чиро ҳоло карда наметавонад, то шумо нақшаро тартиб диҳед. Дар ин ҷо ягон сана ваъда дода намешавад.

## Моделсозӣ

| Ҳанӯз не | Имрӯз ба ҷояш |
|---|---|
| Кашидани як охири узв (чўзонидан) | Таҳрир кунед {{ui:Оғоз}} ё {{ui:Охир}} зери {{ui:Охирҳо (x, y, z mm)}} дар панели {{ui:Хусусиятҳо}} |
| Филтри интихоб (танҳо балкаҳо, танҳо як профил) | Тиреза кашед, сипас {{key:Shift}}+клик барои баровардани деталҳо |
| Массив кардани интихоб; гардондан дар меҳвари қиялӣ; инъикос дар ҳавопаймои қиялӣ | Нусха бардоред ва дар фосила гузоред, ё {{ui:Нусхабардорӣ}} кунед; гардондан ва инъикос дар план кор мекунанд ([Интихоби бо тиреза, ҷойивазкунӣ, гардонидан, инъикос ва тағйири бисёр](topic:select-and-change)) |
| Нуқтаҳо берун аз тӯр ҳангоми клик | Дар тӯр гузоред, сипас координатаҳои охирро ворид кунед |
| Фасадҳо дар хатҳои рақамдори тӯр; намудҳои захирашуда; ҳавопаймоҳои кор | Аз {{ui:3D}} истифода баред, ё {{ui:Иловакунӣ аз рӯи тӯр}} |
| Сӯрохҳо ҳамчун буриши воқеӣ дар намуди 3D | Сӯрохҳо ҳамчун пилагҳои торик нишон дода мешаванд; дар ҳар содирот воқеианд |
| Буриши доиравӣ ё кунҷдор, буриши дигар ва фитингҳо | Танҳо буриши ростқунҷа барои профилҳои I |
| Сӯрохҳое, ки ба кунҷҳо ва қубурҳои даврӣ илова мекунед | Сӯрохҳои кунҷ танҳо аз [гуссетҳои банд](topic:brace-gussets) меоянд |
| Вориди дюймӣ | Миллиметр нависед (25.4 дар як дюйм) |
| Таҳрир ё нест кардани профили фармоишӣ | Профили ислоҳшударо бо номи нав илова кунед |

## Нардбонҳо

| Ҳанӯз не | Имрӯз ба ҷояш |
|---|---|
| Поручнҳо, майдончаҳо, лавҳаҳои поин, қадамҳои грат, нардбонҳои печӣ ва дукунҷа | Танҳо нардбонҳои рост; нигаред ба [Нардбонҳо](topic:stairs) |
| Буриши охири стрингерҳо ба фарш | Стрингерҳои буриши рост; онҳоро дар нармафзори устохонаи худ бурред |

## Пайвастҳо

DetailCraft шаш пайвастро месозад: гуссети банд (нигаред ба [Гуссетҳои банд](topic:brace-gussets)); пайвасти болтӣ байни ду порчаи як профили I (нигаред ба [Пайвастҳо](topic:splices)); мичи (mitre) байни ду профили I, ки дар кунҷ мепайвандад, танҳо буриш ё бо лавҳаҳои охирини болтӣ (нигаред ба [Мичҳо](topic:mitres)); лавҳаи охирини болтии ҳамвор ё дарозшуда аз балкаи амудии сатҳӣ ба фланец ё девораи сутуни профили I; лавҳаи бурранда (shear tab) аз балка (рост, кач ё моил) ба фланец ё девораи сутун; ва лавҳаи таги сутун бо чор болти лангар.

| Ҳанӯз не | Имрӯз ба ҷояш |
|---|---|
| Лавҳаҳои охирини кач ё моил | [лавҳаҳои бурранда](topic:shear-tabs) истифода баред, ки балкаҳои кач ва моилро қабул мекунанд |
| Кунҷҳои клипӣ; лавҳаҳои пуркунандаи пайваст ва пайвастҳо байни андозаҳои гуногун; гуссетҳои кунҷии ба балка ва сутун пайвастшуда, гуссетҳои бурида | Онҳоро дар нармафзори дигар тарҳ кунед, ё лавҳаҳо ва сӯрохҳоро дастӣ ҳамчун деталҳои алоҳида илова кунед; нигаред ба [Пайвастҳо](topic:splices), [Гуссетҳои банд](topic:brace-gussets) |
| Бағалҳои таги скосӣ ё конусӣ; сӯрохҳои grout; ҷайби пойдевор барои шпонкаи бурранда | Бағалҳои росткунҷа; нигаред ба [Лавҳаҳои таг](topic:base-plates) |
| Ҷоҳои (haunches); мичи бо пайвандкории бутт; бағалҳо дар хатти фланецҳои узви дигар | [Мичи](topic:mitres) бо лавҳаҳои охирин ва бағалҳои девора, ё мичи оддии буридашуда; лавҳаҳои дигарро дастӣ ҳамчун деталҳои алоҳида илова кунед |
| Тарҳи санҷишҳои пайваст (мустаҳкамӣ) | Пайвастҳоро бо ҳисобҳои муҳандиси худ санҷед; DetailCraft танҳо дар бораи масофаи канорӣ ва фосила огоҳ мекунад |
| Сӯрохҳои дарозшакл | Танҳо сӯрохҳои даврӣ |

## Таҳлил

| Ҳанӯз не | Имрӯз ба ҷояш |
|---|---|
| Тарҳи санҷишҳо берун аз профилҳои I-и пӯлодӣ: қубурҳо, кунҷҳо, каналҳо, профилҳои пайвандшуда, узвҳои борик ё синфи 4, буришкунӣ, пайвастҳо; бетон: лоғарии sway, буришкунӣ, тарҳи зилзила, плитаҳо ва деворҳо | Вкладкаи {{ui:Таҳлил}} профилҳои I-и пӯлодиро мувофиқи AISC 360 ё EN 1993-1-1 месанҷад ([Санҷиши узвҳои пӯлодӣ мувофиқи меъёри тарҳ](topic:design-checks)); боқиро «санҷида нашуд» нишон медиҳад; муҳандис ҳамаашро мебинад |
| Таҳлили бекаршавӣ (buckling), ларзиш | Таҳлили тартиби дуюм танҳо P-Delta (эластикӣ) аст; таҳлили бекаршавӣ нест (modal, response spectrum, time history ва pushover дар вкладкаи Таҳлил ҳастанд) |
| Санҷишҳои тарҳ, ки муҳандис тасдиқ накардааст | То он вақт онҳо ёрирасонанд: ду-се узвро бо даст ё дар нармафзори муҳандиси худ санҷед, пеш аз он ки ба онҳо такя кунед |
| Бори фарш, шамол ва барф, ки аз масоҳат барои шумо сохта мешаванд | Бори узвҳоро бо даст гузоред, дар kN/m ё kN |
| Ҷобаҷогузории узв (offset), пайвасти эксентрикӣ, бандҳои фақат кашанда, лавҳаҳо ва пойдеворҳо дар чаҳорчӯба | Узвҳо дар хатҳои кории худ таҳлил мешаванд; бандҳо кашиш ва фишорро мебаранд |

## Арматура

| Ҳанӯз не | Имрӯз ба ҷояш |
|---|---|
| Сутунҳои доиравӣ, спиралҳо, балкаҳои қиялӣ ё хамшуда, плитаҳо ғайр аз росткунҷа, деворҳои ростнабуда | Балкаҳо, сутунҳо, плитаҳо ва деворҳои росткунҷа ([Тарҳи бетони арматуравӣ](topic:reinforced-concrete)) |
| Арматураҳои хамшуда ба ҳампайвандӣ, ҳампайвандии ҷойпаюстакардашуда, ҳампайвандӣ дар ҷое, ки шумо интихоб мекунед | Ҳампайвандӣ бо қадамҳои баробар, ҳар арматура дар як буриш ҳамдўш (ACI Class B, EN α6 = 1.5) |
| Арматура дар кушодагиҳо, арматураи кунҷӣ, арматураи зарбӣ (punching) ва тарҳи зилзила (ACI 318-19 боби 18) | Trimmers дар ҳар тарафи кушодагӣ; боқиро худатон санҷед |

| Шаклҳои коди ғайр аз рост, як хам ва U; навъҳои ACI 315 барои арматураи рост ва як илгак | Се шакл ҳамчун BS 8666 00, 11, 21 ё ACI Type 2 чоп мешаванд; нигаред ба [Маълумоти арматура](topic:rebar-reference) |
| Арматураи метрии ғайр аз BS 4449 H8–H40 (масалан CSA 10M–35M) | Номҳои нарми метрии ASTM #10–#36, ё арматураи BS |

## Якҷоя кор ва захира кардан

| Ҳанӯз не | Имрӯз ба ҷояш |
|---|---|
| Ҳамоҳангсозии абрӣ ва sync байни компютерҳо | Файлҳои `.detailcraft.json`-ро захира кунед ва мисли ҳар файли дигар мубодила кунед. Захираи абрӣ то ҳол дастрас нест |
| Курсорҳои дигарон ва нишонаҳои «таҳрир мекунад» дар сессияи Live TeamWork; тӯрҳо, сатҳҳо ва марҳилаҳо ҳамчун як чиз пурра якҷоя шуда намешаванд | Таҳрирҳо ҳанӯз якҷоя мешаванд (тӯрҳо, сатҳҳо ва марҳилаҳо пурра мераванд, тағйири дертар ғолиб аст); нигаред ба [Як сохторро якҷоя, зинда кор кунед](topic:work-live) |
| Даъватномаҳо ба сессияи Live TeamWork тавассути интернет | Бо рамзи кӯтоҳ дар як шабака ҳамроҳ шавед |

## Платформаҳо

- DetailCraft барои экрани мизи корӣ, лаптоп ё планшет сохта шудааст. Дар телефон ҳам кор мекунад: модел экран ва панелҳоро нигоҳ медорад ва ҳисоботҳо ҳамчун варақ аз панели поин кушода мешаванд, аммо барои панелҳо ҷой кам аст.
- Истифодаи офлайн аввал DetailCraft-ро барои офлайн захира кардан лозим аст, бо {{ui:Захира барои офлайн}} дар панели барнома; вақте ки он {{ui:Офлайн омодааст}} менависад, ҳама чиз дар ин нашр бе пайваст кор мекунад. Нигаред ба [Кор бе пайваст](common:offline).

Агар яке аз ин норасоиҳо кори шуморо бозмедорад, тавассути [саҳифаи дастгирӣ](https://getcadcraft.com/support) хабар диҳед; ин ба қарор додан кӯмак мекунад, ки баъдан чиро созем.
