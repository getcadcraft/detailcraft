## ចម្លង និងបិទភ្ជាប់

ទាំងនេះដំណើរការនៅពេលសញ្ញាកណ្ដុរមិននៅក្នុងវាលអត្ថបទ ឬលេខ (នៅទីនោះ ពួកវាចម្លង បិទភ្ជាប់ និងជ្រើសអត្ថបទរបស់អ្នកដូចធម្មតា)។ ការបិទភ្ជាប់ ការកាត់ ការថតចម្លង ឬការលុបនីមួយៗគឺជាជំហានមិនធ្វើវិញមួយ។ បន្ថែម៖ [ចម្លង បិទភ្ជាប់ និងថតចម្លង](topic:copy-paste)។

| គ្រាប់ចុច | ធ្វើអ្វី |
|---|---|
| {{key:Mod+C}} | {{ui:ចម្លង}} ធាតុ និងគ្រឹះដែលបានជ្រើស (ជាមួយរន្ធ ការកាត់ជ្រុង និងការភ្ជាប់របស់វា) |
| {{key:Mod+X}} | {{ui:កាត់}}៖ ចម្លងវត្ថុដែលបានជ្រើស បន្ទាប់មកលុបវា |
| {{key:Mod+V}} | {{ui:បិទភ្ជាប់}}៖ ច្បាប់ចម្លងដើរតាមសញ្ញាកណ្ដុរ; ចុចចំនុចប្រសព្វក្រឡាចត្រង្គសម្រាប់វា |
| {{key:Mod+Shift+V}} | {{ui:បិទភ្ជាប់នៅកន្លែងដដែល}}៖ នៅកូអរដោនេដែលវាត្រូវបានចម្លងពី |
| {{key:Mod+D}} | {{ui:ថតចម្លង}}៖ ច្បាប់ចម្លងភ្លាមៗ ផ្លាស់ទីដោយគម្លាតក្នុង[ការកំណត់ DetailCraft](topic:settings) |
| {{key:Mod+A}} | {{ui:ជ្រើសរើសទាំងអស់}}៖ ធាតុ ការភ្ជាប់ និងគ្រឹះទាំងអស់ |
| {{key:Esc}} | {{ui:មិនជ្រើសរើសអ្វីទាំងអស់}} |

ប្រសិនបើអ្នកបានជ្រើសអត្ថបទនៅលើទំព័រ (ឧទាហរណ៍ក្នុងតារាងរបាយការណ៍) ហើយគ្មានអ្វីក្នុងម៉ូដែលទេ {{key:Mod+C}} ចម្លងអត្ថបទ ដូចធម្មតា។

{{ui:ថ្មី}} {{ui:គំរូ}} និងការនាំចេញមិនមានគ្រាប់ចុចទេ; ប្រើរបារឧបករណ៍។

គ្រាប់ចុចទាំងនេះមិនធ្វើអ្វីទេ នៅពេលប្រអប់មួយ (ការមើលជាមុនគំនូរផលិត ឬសំណួរ) កំពុងបើក។
