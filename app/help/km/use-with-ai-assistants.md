## អ្វីដែលអ្នកនឹងរៀន

របៀបអនុញ្ញាតឱ្យជំនួយការ AI (ឬស្គ្រីបដែលអ្នកបានសរសេរ) ធ្វើការជាមួយ DetailCraft និងរបៀបសម្រេចថាវាអាចប៉ះអ្វីខ្លះ។

DetailCraft **មិនមាន AI ផ្ទាល់ខ្លួនទេ** ហើយមិនផ្ញើអ្វីទៅកន្លែងណាទេ។ អ្នកនាំជំនួយការមកដោយខ្លួនឯង៖ កម្មវិធីណាមួយដែលនិយាយ Model Context Protocol (MCP)។ DetailCraft គ្រាន់តែផ្ដល់ឧបករណ៍ឱ្យវា ហើយអ្នកជ្រើសរើសថាមួយណា។

## បើកវា

1. បើក {{ui:Settings}} (រូបកង់នៅរបារកម្មវិធី ឬ {{key:Mod+,}}) ហើយទៅផ្ទាំង {{ui:DetailCraft}}។
2. នៅក្រោម {{ui:Assistants}} ធីក **Let AI assistants and scripts use DetailCraft**។ វាបិទនៅឡើយ រហូតដល់អ្នកធីក។
3. ជ្រើសរើសអ្វីដែលវាអាចធ្វើ៖ **អាន** ត្រូវបានធីកតាំងពីដំបូង; ធីក **កែសម្រួល** **រក្សាទុក** ឬ **នាំចេញ** តែនៅពេលអ្នកត្រូវការវា។

ឧបករណ៍ដែលនៅក្រៅសិទ្ធិដែលអ្នកបានធីក មិនត្រូវបានផ្ដល់ឱ្យជំនួយការទេ; ហើយប្រសិនបើវាស្នើសុំមួយ DetailCraft បដិសេធ ហើយកត់ត្រាវានៅកំណត់ហេតុសកម្មភាព។ បិទប៊ូតុងនេះនឹងបញ្ចប់ការតភ្ជាប់ទាំងអស់ភ្លាមៗ។

## ភ្ជាប់ជំនួយការរបស់អ្នក

ជំនួយការភ្ជាប់តាម **CadCraft Studio** នៅលើកុំព្យូទ័ររបស់អ្នក៖ Studio ដំណើរការម៉ាស៊ីនមេតូចមួយដែលមានតែកុំព្យូទ័រនេះអាចចូលដល់បាន ការពារដោយតូកែនដែលវាបង្កើតរាល់ពេលចាប់ផ្ដើម។ នៅក្នុង Studio ជ្រើសរើស {{ui:Connect an assistant}} ហើយចម្លងអាសយដ្ឋាន និងតូកែនទៅជំនួយការរបស់អ្នក (Studio បង្ហាញការកំណត់ពិតប្រាកដដែលត្រូវបិទភ្ជាប់)។ កុំចែករំលែកតូកែនឡើយ។

:::note
ផ្ទាំងកម្មវិធីរុករកមិនអាចបើកការតភ្ជាប់សម្រាប់ជំនួយការបានទេ៖ នៅក្នុងកម្មវិធីកម្មវិធីរុករក ប៊ូតុងនេះគ្មានផលប៉ះពាល់ទេ លុះត្រាតែអ្នកប្រើ CadCraft Studio នៅលើកុំព្យូទ័ររបស់អ្នក។
:::

## អ្នកនៅតែគ្រប់គ្រង

- **ការផ្លាស់ប្ដូរនីមួយៗគឺជាជំហានមិនធ្វើវិញតែមួយ** ដែលមានស្លាកជារបស់ជំនួយការ (ឧទាហរណ៍ "ជំនួយការ៖ បន្ថែមធ្នឹម", "ជំនួយការ៖ បន្ថែមដែកជ្រុង")។ {{key:Mod+Z}} យកការផ្លាស់ប្ដូរចុងក្រោយរបស់ជំនួយការទាំងមូលមកវិញ។ ការ `undo` របស់ជំនួយការខ្លួនឯង យកតែជំហានរបស់ខ្លួនមកវិញប៉ុណ្ណោះ មិនដែលយករបស់អ្នកទេ លុះត្រាតែវាស្នើសុំយ៉ាងច្បាស់។
- **វារង់ចាំអ្នក។** ពេលអ្នកកំពុងដាក់សមាជិក ផ្លាស់ទីផ្នែក ឬបិទភ្ជាប់ DetailCraft បដិសេធការផ្លាស់ប្ដូររបស់ជំនួយការ ហើយប្រាប់វាឱ្យព្យាយាមម្ដងទៀត។
- **អ្នកដឹងនៅពេលមានការភ្ជាប់។** ប៊ូតុងមួយនៅរបារកម្មវិធីដាក់ឈ្មោះជំនួយការពេលវាភ្ជាប់; ចុចវាដើម្បីមើលអ្វីដែលវាអាចធ្វើ ឬដើម្បី **ផ្ដាច់** វា។
- **សកម្មភាព។** {{ui:Settings}} › {{ui:DetailCraft}} › {{ui:Assistants}} › {{ui:Activity}} បញ្ជីការហៅគ្រប់ប្រភេទ៖ ពេលណា ឧបករណ៍ណា រួចរាល់ ឬបដិសេធ។ {{ui:Save the log}} រក្សាច្បាប់ចម្លង។

## អ្វីដែលជំនួយការអាចស្នើសុំ

ប្រវែងទាំងអស់ជាមីលីម៉ែត្រ ចំណុចជា `[x, y, z]` ជាមួយ z ឡើងលើ ដូចក្នុងម៉ូដែល។

| ឧបករណ៍ | សិទ្ធិ | អ្វីដែលវាធ្វើ |
|---|---|---|
| `app_info`, `model_describe` | អាន | ម៉ូដែលដែលបើក៖ ក្រឡាចត្រង្គ កម្រិត ដំណាក់កាល សមាជិកតាមប្រភេទ និងប្រវែង ការតភ្ជាប់ គ្រឹះ ជណ្ដើរ ផ្នែក ទម្ងន់ដែក បញ្ហា |
| `parts_list` | អាន | សញ្ញាផ្នែកជាមួយប្រវែង ប្រភេទ ថ្នាក់ ប្រវែងកាត់ ចំនួន ទម្ងន់ ដំណាក់កាល និងសញ្ញាផ្គុំ; តាមប្រភេទ ប្រវែង សញ្ញា ឬដំណាក់កាល |
| `problems_list` | អាន | អ្វីដែលផ្ទាំង {{ui:Problems}} បញ្ជី ជាមួយអ្វីដែលវាទាក់ទង |
| `clash_check` | អាន | [ការពិនិត្យការប៉ះទង្គិច](topic:clash-check) ជាមួយការអត់ធ្មត់ និងដំណាក់កាល |
| `selection_get` | អាន | អ្វីដែលអ្នកបានជ្រើសរើស |
| `selection_set` | កែសម្រួល | ជ្រើសរើសសមាជិក ការតភ្ជាប់ គ្រឹះ ឬជណ្ដើរ (តាមលេខសម្គាល់ ឬសញ្ញាផ្នែក) ដើម្បីបង្ហាញអ្នក; មិនផ្លាស់ប្ដូរអ្វីទេ |
| `member_add` | កែសម្រួល | ធ្នឹម សសរ ដែកទ្រ ឬបន្ទះ រវាងចំណុចពីរ |
| `connection_add` | កែសម្រួល | បន្ទះចុង ផ្ទាំងកាត់ បន្ទះមូលដ្ឋាន ការតភ្ជាប់ចុង ឬដែកជ្រុង ត្រង់កន្លែងដែលសមាជិកដែលបានផ្ដល់ជួបគ្នា ដូចប៊ូតុង {{ui:Connect}} ធ្វើ |
| `undo` | កែសម្រួល | យកជំហានចុងក្រោយរបស់ជំនួយការមកវិញ |
| `model_save` | រក្សាទុក | ការរក្សាទុករបស់ DetailCraft ផ្ទាល់ |

## ប្រសិនបើអ្វីមួយមិនដំណើរការ

- **ជំនួយការមិនឃើញឧបករណ៍ DetailCraft:** ពិនិត្យថាប៊ូតុងបើកនៅក្នុងផ្ទាំងនេះ ហើយថាផ្ទាំងបើកនៅក្នុង Studio។
- **"ត្រូវការសិទ្ធិកែសម្រួល"** (ឬរក្សាទុក, នាំចេញ): ធីកវានៅក្រោម {{ui:Assistants}} បន្ទាប់មកសួរម្ដងទៀត។
- **"អ្នកកំពុងដាក់សមាជិក":** បញ្ចប់អ្វីដែលអ្នកកំពុងធ្វើ (ឬចុច {{key:Esc}}) បន្ទាប់មកឱ្យជំនួយការព្យាយាមម្ដងទៀត។
- **កំហុស "401" ឬ "token":** តូកែនបានផ្លាស់ប្ដូរ (Studio បានចាប់ផ្ដើមឡើងវិញ ឬ {{ui:New token}})។ ចម្លងតូកែនថ្មីទៅការកំណត់របស់ជំនួយការ។
