איך מקשים כתובים בעזרה הזו: [מקשים, עכברים ומשטחי מגע](common:keys). במק, {{key:Mod}} הוא מקש Command; בשאר המערכות הוא Ctrl.

## כלים

פועלים כאשר הסמן אינו בשדה טקסט או מספר.

| מקש | פעולה |
|---|---|
| {{key:V}} | {{ui:בחירה}} |
| {{key:B}} | {{ui:קורה}} |
| {{key:C}} | {{ui:עמוד}} |
| {{key:R}} | {{ui:חיזוק אלכסוני}} |
| {{key:P}} | {{ui:פלטה}} |
| {{key:F}} | {{ui:יסוד}} |
| {{key:S}} | {{ui:מדרגות}} |
| {{key:M}} | הזזת הבחירה על ידי בחירת שתי נקודות חיתוך של רשת ([בחירה בחלון, הזזה, סיבוב, שיקוף ושינוי של פריטים רבים](topic:select-and-change)) |
| {{key:Esc}} | ביטול גרירה של חלון בחירה או החזרת חלקים שנגררו; ביטול הזזה, הנקודה הראשונה של קורה, חיזוק או פלטה, או הדבקה; לחיצה נוספת חוזרת ל{{ui:בחירה}}; ב{{ui:בחירה}}, ניקוי הבחירה. כשתפריט {{ui:עוד}} פתוח, סגירתו |
| {{key:Delete}} או {{key:Backspace}} | מחיקת הבחירה (כל מה שנבחר, בצעד ביטול אחד) |

## קובץ ועריכה

| מקש | פעולה |
|---|---|
| {{key:Mod+S}} | שמירת המודל (הורדה). פועל גם בזמן הקלדה בשדה |
| {{key:Mod+O}} | פתיחת מודל. פועל גם בזמן הקלדה בשדה |
| {{key:Mod+Z}} | ביטול (מחוץ לשדות טקסט; בתוכם מבטל את ההקלדה שלכם) |
| {{key:Mod+Y}} או {{key:Mod+Shift+Z}} | ביצוע חוזר |

## העתקה והדבקה

פועלים כאשר הסמן אינו בשדה טקסט או מספר (שם הם מעתיקים, מדביקים ובוחרים את הטקסט שלכם כרגיל). כל הדבקה, גזירה, שכפול או מחיקה הם צעד ביטול אחד. עוד: [העתקה, הדבקה ושכפול](topic:copy-paste).

| מקש | פעולה |
|---|---|
| {{key:Mod+C}} | {{ui:העתקה}} של האלמנטים והיסודות שנבחרו (יחד עם החורים, החיתוכים והחיבורים שלהם) |
| {{key:Mod+X}} | {{ui:גזירה}}: העתקת הבחירה ואז מחיקתה |
| {{key:Mod+V}} | {{ui:הדבקה}}: העותק עוקב אחרי הסמן; לחצו על נקודת רשת כדי למקם אותו |
| {{key:Mod+Shift+V}} | {{ui:הדבקה במקום}}: בקואורדינטות שממנו הועתק |
| {{key:Mod+D}} | {{ui:שכפול}}: עותק מיידי, מוזז לפי ההיסט ב[הגדרות DetailCraft](topic:settings) |
| {{key:Mod+A}} | {{ui:בחירת הכול}}: כל אלמנט, חיבור ויסוד |
| {{key:Esc}} | {{ui:ביטול הבחירה}} |

אם בחרתם טקסט בדף (למשל בטבלת דוח) ולא דבר במודל, {{key:Mod+C}} מעתיק את הטקסט, כרגיל.

{{ui:חדש}}, {{ui:דוגמה}} והייצואים אין להם מקשים; השתמשו בסרגל הכלים.

אף אחד מהמקשים האלה לא פועל כשתיבת דו-שיח (התצוגה המקדימה של שרטוט ייצור או שאלה) פתוחה.

## עכבר

| פעולה | ב-3D | בתוכנית ובחזית |
|---|---|---|
| לחיצה | בחירת חלק, או הצבה בנקודת החיתוך הקרובה כשכלי הצבה פעיל (או הדבקה שם בזמן הדבקה) | אותו דבר |
| {{key:Shift}}, {{key:Ctrl}} או {{key:Mod}} ולחיצה | הוספת החלק לבחירה, או הוצאתו ממנה | אותו דבר |
| לחיצה על חלק שנבחר וגרירה | הזזת הבחירה לאורך המפלס; עם {{key:Mod}} לחוץ, למעלה ולמטה | הזזת הבחירה (בחזית: לאורכה ולמעלה ולמטה) |
| גרירה עם הכפתור השמאלי | סיבוב המודל | בעזרת {{ui:בחירה}}: חלון בחירה (ימינה: כולו בתוך; שמאלה: נוגע). בזמן הצבה: הזזה |
| {{key:Shift}} וגרירה עם הכפתור השמאלי | בעזרת {{ui:בחירה}}: חלון בחירה, שמתווסף לבחירה. בזמן הצבה: הזזה | בעזרת {{ui:בחירה}}: חלון בחירה, שמתווסף לבחירה |
| {{key:Ctrl}} או {{key:Mod}} וגרירה עם הכפתור השמאלי | הזזה | כלום |
| גרירה עם הכפתור הימני | הזזה | הזזה |
| גלגלת | זום לעבר מרכז התצוגה | זום |
| גרירה עם הכפתור האמצעי | זום | בעזרת {{ui:בחירה}}: הזזה. אחרת זום |
| גרירה אל האפליקציה של קובץ `.detailcraft.json` | פתיחתו | פתיחתו |

לחיצה נחשבת רק אם המצביע זז פחות מכ-5 פיקסלים בין הלחיצה לשחרור; תנועה ארוכה יותר היא גרירה.

## משטח מגע

| פעולה | מה היא עושה |
|---|---|
| תנועה של שתי אצבעות למעלה או למטה, או צביטה | זום |
| לחיצה וגרירה | סיבוב (3D) או הזזה (בתוכנית ובחזית) |
| {{key:Shift}} ולחיצה וגרירה | הזזה ב-3D |
| לחיצה בשתי אצבעות | לחיצה ימנית (אין תפריט בתצוגה) |

## מסך מגע

במחשב לוח או במסך מגע:

| פעולה | מה היא עושה |
|---|---|
| הקשה | בחירת חלק, או הצבה בנקודת הרשת הקרובה כשכלי הצבה פעיל (הקשה במרחק של כרוחב אצבע ממנה נחשבת) |
| לחיצה ארוכה על חלק | הוספה לבחירה, או הוצאה ממנה (מה ש-{{key:Shift}}+לחיצה עושה בעכבר) |
| אצבע אחת על חלק שנבחר, ואז גרירה | הזזת הבחירה, עם הצמדה לנקודות רשת |
| אצבע אחת במקום אחר | סיבוב המודל (3D) או הזזה (בתוכנית ובחזית) |
| שתי אצבעות | צביטה לזום, הזזה יחד להזזה |

כפתורים, רשימות ושדות גדולים יותר כשהמסך הוא מגע בלבד. חלוני בחירה דורשים עכבר; באצבעות, הקישו ולחצו לחיצה ארוכה.

## מקשים ששומר הדפדפן

יש קיצורים ששייכים לדפדפן, ואף דף לא יכול להשתמש בהם, למשל {{key:Mod+W}} (סגירת לשונית), {{key:Mod+T}} (לשונית חדשה) ו-{{key:Mod+N}} (חלון חדש). אם {{key:Mod+Y}} פותח את היסטוריית הדפדפן במקום לבצע ביצוע חוזר, השתמשו ב-{{key:Mod+Shift+Z}}.

קיצורים מגיעים ל-DetailCraft רק כשהדף מחזיק במקלדת. אם מקש לא עושה דבר, או שהדפדפן פועל בו, לחצו קודם על חלק ריק של חלון DetailCraft (למשל אחרי הקלדה בשורת הכתובת).

## איפה הזזה נמצאת

אין פקודת הזזה: בחרו חלק וגררו אותו לאורך המפלס (החזיקו {{key:Mod}} כדי לגרור למעלה ולמטה), או ערכו את ערכי {{ui:התחלה}} ו{{ui:סוף}} ב{{ui:מאפיינים}}.
